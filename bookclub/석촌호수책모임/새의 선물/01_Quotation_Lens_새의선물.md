## 0. 한 문장 영점

> 이 소설의 인용구는 진희의 날카로운 말을 ‘삶의 명언’으로 수집하는 데서 멈추지 않고, **누가 언제 말하는지, 그 말과 행동·몸·공간이 일치하는지, 진희가 본 것과 작품이 보여준 것이 어디서 갈라지는지**를 판별한다.

---

## 1. 이 렌즈가 하는 일과 하지 않는 일

### 1.1 하는 일

1. 사용자가 제공한 인용문을 맞춤법·문장부호·줄바꿈까지 그대로 보존한다.
2. 독서 날짜·시간·페이지가 독립 행으로 표시되면 메타데이터로 처리하고 문장 분석에서 제외한다.
3. 인용 묶음 전체를 먼저 훑고 장면의 사건 흐름과 기능 지도를 만든다.
4. 핵심 정의, 시점 전환, 행동의 변화, 아이러니, 반례를 담당하는 2–4개를 우선 정밀 분석한다.
5. 정밀 분석하지 않은 인용도 반복 근거·사례·분위기·전환 보조·문맥 필요로 분류한다.
6. 진희의 생각, 성인 화자의 사후 설명, 작품의 효과, 작가의 견해를 분리한다.
7. 새 장면이 H1–H6을 확인·확장·제한·수정·반전하는지 02 장부에 기록한다.
8. 사용자가 `[Cxx 종료]`, `장이 끝났다`고 명시할 때만 장 전체 종합을 만든다.

### 1.2 하지 않는 일

- 아름답고 단정적인 문장을 작품 전체의 결론으로 자동 승격하지 않는다.
- 진희가 인물을 판정한 말을 객관적 인물 소개로 바꾸지 않는다.
- 모든 장면을 ‘보여지는 나/바라보는 나’ 하나로 환원하지 않는다.
- 성장소설이라는 장르명을 결말의 성숙을 보증하는 공식으로 쓰지 않는다.
- 작가의 생애와 인물의 사건이 닮았다는 이유로 자전적 사실이라고 단정하지 않는다.
- 개정판 문장을 초판 문장처럼, 초판 문장을 개정판 문장처럼 교정하지 않는다.
- 목차 제목만으로 아직 읽지 않은 장의 사건을 추정하지 않는다.
- 외부 비평을 본문보다 먼저 정답으로 세우지 않는다.

### 1.3 분석 규모·독립 검토 게이트

분석을 시작할 때마다 내용의 난도와 별개로 **검토 규모가 실제 결과를 바꾸는지** 먼저 확인한다.

1. 단일 인용 묶음과 장 종료 종합은 기본적으로 한 분석자가 `00 → 01 → 현재 원문 → 기존 분석·02`를 대조해 처리한다.
2. 장 종료 때는 이미 끝난 묶음을 다시 정밀 분석하지 않고, 묶음 사이의 수렴·충돌·미해결점만 상위 구조로 변환한다.
3. 관점 수를 채우기 위해 새 해석·반례·외부 이론을 늘리지 않는다. 복수 증거의 관계를 설명하지 못하는 새 가설은 국소 메모로도 추가하지 않는다.
4. 독립 검토·서브에이전트·추가 리서치는 다음 중 하나가 있을 때만 사용한다.
   - 정확한 인용·발화자·판본·ID가 서로 충돌함
   - 장 전체 결론을 바꿀 강한 반례가 있으나 현재 분석만으로 판정하기 어려움
   - 복수 판본·긴 원문·외부 사실을 병렬 검증해야 함
   - 사용자가 블라인드 독립 평가나 다중 검토를 명시적으로 요청함
5. 추가 검토를 하더라도 요청 범위를 넓히지 않는다. 검토 결과가 기존 판정을 바꾸지 않으면 한계 확인으로만 남기고 새 절을 만들지 않는다.
6. 필요한 산출물·인계·장부 갱신이 끝나면 멈춘다. 후속 장이 검증할 문제를 현재 장에서 미리 해결하려 하지 않는다.

시작 전 짧은 점검은 다음 세 문장으로 충분하다.

- 현재 요청은 국소 분석인가, 장·부·전체 종합인가?
- 추가 검토가 정확성이나 최종 판정을 실질적으로 바꾸는가?
- 지금 범위에서 답할 수 없는 문제는 확장할 일인가, 다음 단계로 넘길 일인가?

## 2. 기본 독해 자세

### 2.1 논지보다 장면을 먼저 읽는다

《새의 선물》은 관념적 문장이 많지만 논픽션이 아니다. 진희가 사랑·운명·성장에 대해 무엇이라고 정의하는지만 보면 작품의 절반을 놓친다.

매 인용에서 다음 순서를 지킨다.

1. 무슨 사건이 실제로 일어났는가.
2. 누가 무엇을 원하고 무엇을 했는가.
3. 누가 그 사건을 보고 말로 해석하는가.
4. 행동·몸짓·공간은 그 해석을 지지하는가.
5. 독자는 화자보다 더 알거나 덜 알게 되는가.
6. 장면 전후에 관계와 선택지가 어떻게 달라졌는가.

### 2.2 ‘정확한 관찰자’와 ‘믿을 수 없는 화자’의 이분법을 피한다

진희는 사실을 정확히 보면서 원인을 오해할 수 있고, 타인의 허위를 꿰뚫으면서 자기 욕망에는 눈멀 수 있다. 신뢰성은 한 번에 판정하지 않고 네 칸으로 나눈다.

| 층 | 질문 |
| --- | --- |
| 사실 관찰 | 누가 무엇을 했는지 정확히 보았는가 |
| 인과 해석 | 왜 그런 일이 일어났는지 설명이 충분한가 |
| 자기 이해 | 자신의 감정·욕망·상처를 인정하는가 |
| 윤리 판단 | 타인을 판정할 때 권력·조건·모순을 공정하게 보는가 |

### 2.3 냉소는 내용이면서 형식이다

냉소는 단순 성격이 아니다.

- 상처받기 전에 먼저 의미를 붙이는 방어.
- 어른의 허세와 사회적 역할을 폭로하는 비판.
- 자신이 참여자가 아니라 관찰자라는 우월감.
- 비참한 사건을 독자가 견디게 하는 유머의 장치.
- 타인의 고통을 유형과 농담으로 소비하게 할 위험.

따라서 냉소를 긍정·부정으로 한 번에 판정하지 말고, **누구를 보호하고 누구를 대상화하는지** 묻는다.

### 2.4 회상은 복원이 아니라 현재의 편집이다

- 성인 진희가 열두 살의 언어를 그대로 재생하는지, 현재의 개념을 덧씌우는지 본다.
- “그때 이미 알았다”는 문장은 당시의 경험인가 사후의 자기 설명인가 묻는다.
- 프롤로그와 에필로그가 과거 장면의 의미를 미리 정하고 다시 봉합하는지 추적한다.
- 생략과 선택도 증거다. 무엇을 오래 말하고 무엇을 건너뛰는지 기록한다.

## 3. 화자·시점 층위 코드

인용구마다 가능한 한 발화 층위를 잠근다.

| 코드 | 층위 | 판정 기준 |
| --- | --- | --- |
| `N-A` | 회상하는 성인 진희 | 과거 전체를 정리·평가·예고하는 목소리 |
| `N-C` | 사건을 겪는 열두 살 진희 | 그 시점에 보고 듣고 추론하는 아이의 목소리 |
| `S-O` | ‘바라보는 나’ | 자신을 거리 밖에서 감시·해석하는 내적 위치 |
| `S-D` | ‘보여지는 나’ | 타인의 기대에 맞춰 말하고 행동하는 수행적 자아 |
| `D` | 등장인물의 직접 발화 | 대사, 편지, 소문 속 말 |
| `E` | 삽입된 텍스트 | 책, 신화, 노래, 기사, 편지 등 다른 서사 |
| `MIX` | 층위가 의도적으로 겹침 | 성인 어휘와 아이 경험을 분리하기 어려운 경우 |

`N-A`와 `N-C`를 억지로 가르지 않는다. 분명하지 않으면 `MIX`로 두고, 시점 혼합이 만드는 효과를 분석한다.

## 4. 고정 독해축

### A1. 거리와 참여

**핵심 질문:** 자아 분리와 관찰은 무엇을 지키고 무엇을 잃게 하는가?

- 진희는 어떤 위협 앞에서 ‘보여지는 나’를 내세우는가.
- 바라보는 위치는 실제 선택과 책임에서 빠져나가는 구실이 되는가.
- 감정·몸·욕망이 거리 유지에 실패하는 순간은 어디인가.
- 타인과의 관계가 관찰·실험에서 상호작용으로 바뀌는가.

**경보:** 거리 두기를 곧 객관성·성숙·자유로 번역할 때.

### A2. 앎과 오독

**핵심 질문:** 진희가 안다고 말하는 것과 작품이 실제로 입증하는 것은 같은가?

- 인물의 행동을 유형·신화·소설의 각본으로 너무 빨리 설명하는가.
- 독자는 진희가 모르는 정보를 받는가.
- 후속 사건이 앞선 판정을 확인하는가 반전하는가.
- 성인 화자의 지식이 아이의 경험을 지나치게 매끈하게 만드는가.

**경보:** 인용문이 명쾌하다는 이유로 장면의 모순을 지울 때.

### A3. 사랑과 역할

**핵심 질문:** 인물은 사랑하는가, 사랑의 역할을 수행하는가, 사랑으로 다른 것을 얻으려 하는가?

- 사랑·결혼·모성·정절·남성다움의 대본은 누가 만들었는가.
- 욕망, 생계, 신분 상승, 탈출, 자기 연출이 어떻게 섞이는가.
- 여러 연애가 반복되는가, 대조되는가, 서로의 환상을 깨는가.
- 말로 선언한 사랑과 실제로 감수한 비용이 일치하는가.

**경보:** 모든 연애를 ‘사랑은 환상’이라는 하나의 냉소로 평평하게 만들 때.

### A4. 일상과 구조

**핵심 질문:** 성별·계급·나이·혈연·정치가 인물의 선택과 시선을 어떻게 조직하는가?

- 누가 말하고 판단하고 떠날 수 있는가.
- 돈·직업·집·평판이 사랑과 가족의 선택지를 어떻게 제한하는가.
- 감나무집의 방·마당·가게·문·창이 정보의 흐름을 어떻게 만든다.
- 국가적 권위와 사회 규범이 일상의 말투·처벌·소문으로 내려오는가.

**경보:** 구조를 말하며 인물의 욕망과 책임을 지우거나, 반대로 모든 압력을 개인 성격으로 환원할 때.

## 5. 문장·장면 유형 코드

| 코드 | 유형 | 판정 질문 |
| --- | --- | --- |
| `EVT` | 사건 | 실제로 무엇이 발생하고 상태가 바뀌는가 |
| `ACT` | 행동·선택 | 인물이 무엇을 하거나 하지 않기로 하는가 |
| `PER` | 지각·관찰 | 무엇을 보고 듣고 감지하는가 |
| `JUD` | 판단·일반화 | 개별 사건에서 삶·사랑·인간의 법칙을 만드는가 |
| `RET` | 회상·사후 편집 | 성인 화자가 과거를 해석·예고·봉합하는가 |
| `PRF` | 연기·자기 연출 | 타인의 시선을 의식해 역할을 수행하는가 |
| `AFF` | 감정·몸 반응 | 말보다 먼저 욕망·수치·공포·애착이 드러나는가 |
| `REL` | 관계 이동 | 친밀·적대·의존·권력의 배치가 변하는가 |
| `SOC` | 사회 구조 | 성별·계급·정치·규범이 개인 장면에 개입하는가 |
| `SPC` | 공간·사물 | 배치·소유·이동이 장면의 의미를 만드는가 |
| `MOT` | 반복 모티프 | 앞의 사물·표현이 다른 의미로 돌아오는가 |
| `TRN` | 전환·경첩 | 사건이나 해석의 방향을 바꾸는가 |
| `LIM` | 유보·균열 | 화자의 확신을 제한하거나 반례를 여는가 |

한 인용에 주유형 하나, 부유형 최대 두 개만 붙인다. 모든 코드를 늘어놓지 않는다.

## 6. 장내 기능

| 역할 | 의미 |
| --- | --- |
| 닻 | 장의 출발 상태·중심 질문·핵심 관계를 고정 |
| 촉발 | 뒤 사건을 일으키는 욕망·정보·행동 |
| 경첩 | 관찰에서 참여, 희극에서 비극, 확신에서 균열로 방향 전환 |
| 시험 | 앞서 세운 자기상·관계·가설을 사건이 검증 |
| 반례 | 진희나 독자의 기존 판단을 흔듦 |
| 폭로 | 말·역할·사회 규범 뒤의 욕망과 권력을 드러냄 |
| 대가 | 선택이나 방어가 치르게 하는 손실을 보여줌 |
| 모티프 회수 | 앞의 사물·말·공간이 새 의미로 돌아옴 |
| 종결 | 장의 변화와 남은 긴장을 압축 |
| 인계 | 다음 장의 사건·질문을 열어둠 |

분위기와 재미만 만드는 장면도 작품의 리듬에는 중요할 수 있다. 다만 핵심 증거와 구분해 기록한다.

## 7. 중요도 기준

| 등급 | 선정 기준 | 처리 |
| --- | --- | --- |
| A | 시점 규칙, 핵심 관계 변화, 결정적 행동, 자아 분리의 성공·실패, 장의 반전, 결말 회수에 필수 | 반드시 정밀 분석하고 02에 등록 |
| B | 인물·모티프·사회 구조를 강화하거나 A의 의미를 제한하는 장면 | 묶음의 기능 균형에 따라 정밀 분석 |
| C | 반복 설명, 분위기, 보조 사례, 이미 확보된 성격의 변주 | 한 줄 분류 후 필요할 때 회수 |

A는 유명한 문장이나 ‘명언’과 같지 않다. 짧은 몸짓, 침묵, 방의 이동이 긴 관념문보다 더 중요한 증거일 수 있다.

## 8. 아이러니와 신뢰성 감사

### 8.1 네 열 비교

핵심 인용은 가능하면 다음 표로 읽는다.

| 층 | 기록할 것 |
| --- | --- |
| 진희의 설명 | 자신·타인·사건을 어떻게 말로 규정하는가 |
| 실제 행동 | 말과 일치하거나 어긋나는 선택은 무엇인가 |
| 몸·정동 | 설명이 통제하지 못한 감각·감정은 무엇인가 |
| 장면의 반응 | 타인·공간·후속 사건이 그 설명을 어떻게 되받는가 |

### 8.2 아이러니 유형

- **자기 아이러니:** 진희의 우월한 설명을 자신의 행동이 깨뜨림.
- **극적 아이러니:** 독자가 진희보다 더 많은 정보 또는 다른 의미를 앎.
- **회고 아이러니:** 성인 화자의 사후 지식과 아이의 당시 확신이 충돌함.
- **사회적 아이러니:** 존중받는 규범이 실제로는 약자를 해치거나 위선을 보호함.
- **희비 아이러니:** 웃기는 장면의 구조가 동시에 잔혹하거나 슬픔.

아이러니가 있다고 해서 앞 문장이 전부 거짓은 아니다. 무엇이 유지되고 무엇이 축소되는지 판정한다.

## 10. 책 특화 진단 질문

### 10.1 ‘보여지는 나/바라보는 나’

- 두 자아 가운데 하나만 ‘진짜 나’라고 할 수 있는가.
- 보여지는 자아도 반복 수행을 통해 실제 성격과 삶을 만들지 않는가.
- 바라보는 자아는 노출되지 않는 대신 검증과 관계에서도 벗어나는가.
- 분리가 실패할 때 진희는 수치, 분노, 질투, 슬픔 중 무엇을 느끼는가.

### 10.2 “열두 살 이후 성장할 필요가 없었다”

- 사실 진술, 과장, 도발, 방어 선언, 성인 화자의 반어 중 무엇인가.
- 성장 완료를 증명하는 사건과 반박하는 사건을 각각 모은다.
- ‘성장하지 않아도 됨’이 성장 거부인지 조기 노화인지 본다.
- 에필로그가 이 첫 문장을 유지·수정·반전하는가.

### 10.3 독서와 각본

- 책은 진희에게 현실을 읽을 언어를 주는가, 현실을 미리 정해진 플롯에 끼우게 하는가.
- 문학·신화의 인물형이 실제 주변인을 이해하는 데 도움 되는가.
- 인용된 이야기와 현재 사건 사이의 차이가 희극이나 비극을 만드는가.

### 10.4 연애 대위법

- 각 연애의 욕망, 경제 조건, 평판 위험, 결말을 비교한다.
- 한 서사가 다른 서사의 이상화를 깨거나 보완하는가.
- 진희는 배심원·관객·공범·참여자 가운데 어디에 서는가.
- ‘사랑은 환상’ 같은 일반화로 사라지는 차이는 무엇인가.

### 10.5 감나무집의 시선

- 누가 누구의 방·가게·마당을 볼 수 있는가.
- 비밀은 공간 때문에 보호되는가 유출되는가.
- 집안일·장사·돌봄·소문을 누가 담당하는가.
- 집에 머무름과 집을 떠남의 물질적 조건은 무엇인가.

### 10.6 웃음과 윤리

- 농담의 표적은 권력자인가 약자인가, 혹은 둘 모두인가.
- 웃음 뒤에 새로 보이는 고통이 있는가, 고통이 가려지는가.
- 진희의 재치가 타인을 이해하는 대신 유형화하는 순간은 언제인가.
- 작품은 진희의 잔혹함도 아이러니의 대상으로 삼는가.

## 11. 인용 묶음 처리 프로토콜

### 11.1 입력 잠금

- 같은 장의 인용은 한 묶음으로 본다.
- 권장량은 5–10개이지만 사용자가 한 장 전체를 한 번에 주어도 먼저 전부 훑는다.
- 인용문 사이의 독립된 날짜·시간은 메타데이터로 제외한다.
- 페이지·위치가 있으면 보존한다. 없으면 추정하지 않고 `위치 미잠금`으로 둔다.
- 사용자의 줄바꿈·구두점·오탈자처럼 보이는 표현도 임의 교정하지 않는다.

### 11.2 1차 전체 스캔

모든 인용에 다음 한 줄을 붙인다.

`ID / 화자층 / 주유형 / 장내 역할 / 중요도 / 우선축 / 연결 가설`

그리고 묶음 전체에 대해 먼저 세 가지를 적는다.

1. 사건 순서.
2. 관계 또는 인식의 출발과 도착.
3. 정밀 분석할 기능 묶음.

### 11.3 정밀 선정

보통 2–4개를 고르되 수를 기계적으로 맞추지 않는다.

- 장면의 출발 규칙 또는 핵심 판단 1개.
- 실제 행동·관계 변화를 일으키는 경첩 1개.
- 진희의 설명을 흔드는 몸·반례·아이러니 1개.
- 사회 구조나 반복 모티프를 연결하는 문장 1개.

같은 기능의 명언형 문장이 여러 개면 대표 하나만 정밀 분석하고 나머지는 반복 근거로 묶는다.

### 11.4 선택하지 않은 인용 분류

| 분류 | 의미 |
| --- | --- |
| 반복 근거 | 이미 확보된 판단·성격을 재확인 |
| 사례 | 핵심 개념을 보여주지만 장의 방향을 바꾸지 않음 |
| 분위기·리듬 | 시대감·유머·정서를 형성 |
| 연결 보조 | 앞뒤 장면을 잇지만 독립 분석 필요가 낮음 |
| 모티프 후보 | 반복 여부가 확인되면 중요도가 오를 수 있음 |
| 문맥 필요 | 앞뒤 사건·발화자·행동 없이는 판정 위험 |
| 후속 회수 | 나중 장면과 결합할 때 의미가 커질 가능성 |

### 11.5 정밀 분석 순서

1. **장면 복원:** 누가 어디서 무엇을 원하고 무엇을 하는가.
2. **최소 의미:** 문장이 실제로 말하는 가장 좁은 뜻.
3. **화자·시점:** 성인/아이/바라보는 나/보여지는 나의 층위.
4. **말–행동–몸:** 설명과 실제 반응의 일치·불일치.
5. **장내 기능:** 닻·촉발·경첩·시험·반례·대가 중 무엇인가.
6. **형식:** 아이러니, 생략, 반복, 비유, 리듬, 대화의 작동.
7. **관계·권력:** 누가 더 말하고 보고 선택할 수 있게 되는가.
8. **대안 독법:** 주류 해석과 가장 강한 경쟁 해석.
9. **책 전체 연결:** A1–A4와 H1–H6에 미치는 영향.
10. **판정:** 현재 유지 가능한 가장 좁고 강한 결론.
11. **질문:** 뒤 텍스트가 무엇을 보여주면 이 해석이 바뀌는가.

1. 문장은 명료하게 쓰되 작품의 모순을 단정적 교훈으로 정리하지 않는다.
2. 인용보다 해설이 길어져 장면의 구체성을 덮지 않게 한다.
3. ‘여성’, ‘가부장제’, ‘성장’, ‘냉소’ 같은 큰말은 구체적 행동·공간·대사의 근거와 함께 쓴다.
4. 주류 해석, 대안 해석, 비판 해석, 근거가 제한된 추측을 실제 차이가 있는 곳에서만 구분한다.
5. 사용자가 특히 붙든 문장은 책의 구조적 중요도와 독자의 개인적 중요도를 따로 기록한다.
6. 나의 판정에는 `약함 / 중간 / 강함`을 붙인다.
7. 묶음 질문은 감상 확인이 아니라 반증·윤리·현실 판단을 여는 2–3개로 제한한다.

## 19. 현재 잠금과 남은 입력

### 잠긴 것

- 2022년판의 기본 서지와 24개 분석 구간(C00–C23).
- 화자·시점 코드와 장면 유형 코드.
- 네 독해축 A1–A4.
- 여섯 초기 가설 H1–H6.
- 인용 묶음의 전체 스캔 → 2–4개 정밀 분석 → 나머지 분류 규칙.
- 장 종료 때 Cxx-A와 Cxx-B를 분리하는 원칙.

### 아직 잠그지 않은 것

- 사용자가 읽는 실제 판본과 쪽수.
- 각 제목 구간을 사용자가 ‘장’으로 부를지, 별도 묶음 단위를 사용할지.
- 성인 화자와 아이 화자의 문체가 본문에서 얼마나 분명히 분리되는지.
- 제목의 새·선물·감옥 이미지가 본문에서 실제로 반복되는 정도.
- H1–H6 가운데 어떤 축이 사용자의 밑줄 선택에서 중심이 되는지.

## 20. 나의 판단

**판단 강도: 강함.**

이 작품에서 가장 경계할 독법은 진희의 날카로운 문장들을 모아 ‘어른보다 세상을 잘 아는 아이’의 지혜로 만드는 것이다. 그런 문장들은 중요하지만, 소설의 더 깊은 층은 그 지혜가 사건 앞에서 어디까지 작동하고 어디서 무너지는지에 있다.

좋은 분석은 진희가 틀렸음을 폭로하는 데서도 끝나지 않는다. 그의 거리가 실제로 어떤 상처에서 생겼고 왜 필요했는지 인정한 뒤, 그 생존법이 타인과 자신에게 요구하는 비용까지 봐야 한다. 앞으로의 핵심 단위는 명언이 아니라 **말–행동–몸–후속 사건의 네 칸**이다.
