- 작업 상태: 인용구 분석 렌즈 v1
- 작성일: 2026-07-29
- 역할: 00 사전 리서치를 실제 문장 분석으로 변환하는 운영 규칙
- 성격: 정답지가 아니라 인용구가 들어올 때마다 수정되는 잠정 렌즈

## 0. 한 문장 영점

> 이 책의 인용구는 “이야기가 인간에게 중요하다”는 감탄으로 끝내지 않고, 그 문장이 **무엇을 이야기라 부르는지**, **어떤 증거로 현재 기능을 말하는지**, **그 기능에서 진화 기원으로 얼마나 멀리 가는지**, **같은 장치가 공감과 기만을 어떻게 함께 만드는지**를 판별한다.

---

## 1. 이 렌즈가 하는 일과 하지 않는 일

### 하는 일

1. 사용자가 표시한 문장을 원문 그대로 보존한다.
2. 문장의 주장 유형과 장 안의 기능을 먼저 판정한다.
3. 사례·실험·이론·진화 추론의 증거력을 구분한다.
4. 해당 문장이 앞선 가설을 지지·수정·반박하는지 기록한다.
5. 5–8개 인용구가 한 묶음으로 들어오면 전체를 스캔한 뒤 기능이 다른 2–4개를 우선 정밀 분석한다.
6. 선택하지 않은 문장도 버리지 않고 역할·중요도·연결 후보를 분류한다.
7. 장 종료 신호가 올 때만 장 종합을 만든다.

### 하지 않는 일

- 인용구를 저자 전체 사상의 대표문장으로 자동 승격하지 않는다.
- 출판사 소개문을 저자의 정확한 결론으로 대체하지 않는다.
- 2012년 이후의 연구를 저자가 당시에 알고 쓴 근거처럼 소급하지 않는다.
- 인용문에 없는 영문 용어를 번역본의 “정식 표현”으로 꾸미지 않는다.
- 개별 사례가 흥미롭다는 이유로 인과 증거라고 부르지 않는다.
- 사용자가 단독으로 적은 날짜·페이지 메타데이터를 하나의 인용구로 분석하지 않는다.

## 2. 기본 독해 자세

### 2.1 책의 유형

이 책은 엄밀한 단일 실험 보고서가 아니라 문학, 심리학, 인류학, 꿈 연구, 신경과학, 진화론, 개인 일화를 결합한 대중적 종합이다. 따라서 인용문마다 다음을 분리한다.

- **현상:** 인간이 실제로 무엇을 하는가.
- **기제:** 그 현상을 가능하게 하는 심리·신경 과정은 무엇인가.
- **현재 기능:** 그 현상이 지금 어떤 이익·비용을 낳는가.
- **진화 기원:** 그 기능 때문에 자연선택된 것인가.
- **문화적 효과:** 특정 매체·제도·집단에서 어떻게 증폭되는가.

### 2.2 저자의 실제 입장에 대한 잠금

갓셜은 사회적 시뮬레이션 가설에 끌리지만, 출간 당시에도 이야기의 기능이 충분히 실험되지 않았고 적응·부산물·전용이 섞였을 가능성을 인정했다. 그러므로 본문의 강한 수사와 저자의 최종 인식론적 유보를 함께 읽는다.

### 2.3 책 전체의 잠정 인과 사슬

이야기는 보편적·비자발적으로 나타난다  
→ 시간과 에너지를 많이 소비하므로 설명이 필요하다  
→ 놀이·픽션·꿈은 평온보다 곤경을 과잉 표집한다  
→ 사회적 문제를 낮은 위험으로 시뮬레이션한다는 가설이 나온다  
→ 공감·규범·협력·집단 정체성에 영향을 준다  
→ 같은 몰입·인과 구성 장치가 기억 왜곡·선동·자기기만도 낳는다  
→ 디지털 상호작용성은 효용과 위험을 함께 증폭한다

이 사슬의 어느 화살표도 앞 문장이 참이라는 이유만으로 자동 확정되지 않는다.

## 3. 고정 독해축

### A1. 범위와 정의

**핵심 질문:** 이 대목의 `story`는 정확히 무엇인가?

- 허구와 사실 서사를 구분하는가?
- 사건의 시간적 배열, 행위자, 인과, 갈등, 결말 중 무엇이 최소 조건인가?
- 꿈, 공상, 놀이, 소설, 광고, 종교, 국가, 기억을 같은 범주로 묶는 기준이 있는가?
- 범위를 넓힐수록 반례가 사라지는 것은 아닌가?

**경보:** “모든 것이 이야기다”가 설명이 아니라 정의의 팽창으로 작동할 때.

### A2. 기능과 진화

**핵심 질문:** 지금 유익한 것과 그 이익 때문에 생겨난 것은 구분되는가?

- 적응(`adaptation`), 부산물(`by-product`), 전용·외적응(`exaptation`) 가운데 어느 주장인가?
- 보편성, 비용, 즐거움, 효용이 각각 어떤 증거 역할을 하는가?
- 이야기 전용 기제를 가정해야만 설명되는 예측이 있는가?
- 언어, 마음읽기, 반사실적 상상, 놀이의 결합으로도 설명 가능한가?

**경보:** 보편성 → 유익함 → 그 기능을 위해 진화함이 한 문장처럼 붙을 때.

### A3. 영향과 권력

**핵심 질문:** 이야기는 누구를 어떤 방향으로 움직이는가?

- 서사적 운송·몰입 → 감정 → 믿음 → 의도 → 실제 행동의 어느 단계인가?
- 공감과 마음읽기를 도덕성으로 자동 환산하는가?
- 집단 결속의 수혜자는 누구이며, 외집단은 어떤 역할을 맡는가?
- 설득, 교육, 선전, 광고, 음모론은 같은 기제의 다른 사용인가?

**경보:** “친사회적”이라는 말이 내집단 협력과 보편적 선의를 섞을 때.

### A4. 일관성과 진실

**핵심 질문:** 인과적·심리적 일관성은 사실적 정확성과 어디에서 갈라지는가?

- 기억 오류, 작화, 자기합리화, 음모론, 서사적 정체성을 같은 현상으로 묶어도 되는가?
- 구성된 기억이 곧 전면적으로 거짓이라는 뜻인가?
- 유용한 삶 이야기가 책임 회피나 반증 불가능성으로 바뀌는 지점은 어디인가?
- 비서사적으로 자신을 경험하는 사람을 허용하는가?

**경보:** “이야기로 구성된다”가 “자의적 허구다” 또는 “이야기여야 건강하다”로 변할 때.

## 4. 문장 유형 판정

인용구마다 우선 하나의 주유형, 필요하면 하나의 부유형을 붙인다.

| 코드 | 유형 | 판정 질문 |
|---|---|---|
| OBS | 관찰·기술 | 무엇이 얼마나 자주 나타난다고 말하는가 |
| DEF | 정의·범주 | 핵심 용어의 포함·제외 기준은 무엇인가 |
| MEC | 심리·신경 기제 | 어떤 과정이 현상을 만들어 낸다고 말하는가 |
| FUN | 현재 기능 | 개인·집단에 어떤 효과나 이익을 준다고 말하는가 |
| ORG | 진화 기원 | 왜 그 능력이 선택되거나 생겨났다고 말하는가 |
| CAU | 인과 효과 | X가 Y를 변화시킨다고 주장하는가 |
| NOR | 규범·가치 | 무엇이 좋고 나쁘며 어떻게 살아야 한다고 말하는가 |
| MET | 비유·압축 | 설명을 기억시키는 표현인가, 검증 가능한 주장인가 |
| TRN | 장 전환·논증 연결 | 앞의 질문을 다음 가설이나 사례로 넘기는가 |
| PRD | 미래 예측 | 매체·사회가 어떻게 변할 것이라 전망하는가 |
| LIM | 한계·유보 | 저자가 자신의 주장 범위를 줄이거나 경쟁 가설을 여는가 |

복합문은 쉼표나 접속어를 기준으로 쪼갠다. 예를 들어 관찰에서 진화 기원으로 넘어가면 `OBS→ORG`로 기록하고, 가장 약한 화살표를 분석 중심으로 삼는다.

## 5. 문장의 장내 기능

| 역할 | 뜻 |
|---|---|
| 닻 | 장의 핵심 질문·개념·주장을 고정 |
| 경첩 | 앞 논의에서 다음 논의로 방향을 전환 |
| 다리 | 서로 다른 장·개념을 인과적으로 연결 |
| 증거 | 연구·자료·관찰을 통해 주장을 지지 |
| 사례 | 추상 주장을 구체화하지만 그 자체로 일반성을 입증하지 않음 |
| 반례 | 기존 설명을 흔들거나 범위를 줄임 |
| 유보 | 저자가 확신도를 낮추고 대안을 열어 둠 |
| 수사 | 독자의 정서·기억을 움직이는 비유·일화·문체 |
| 종결 | 장의 성과를 압축하거나 다음 장의 질문을 남김 |

같은 문장이 둘 이상의 역할을 할 수 있으나, 기록에는 주역할 하나와 보조역할 하나만 남긴다.

### 과잉 추론 경보

- 보편성 → 적응
- 유익함 → 그 기능을 위해 진화함
- 상관 → 인과
- 신경망 중첩 → 훈련 효과
- 서사적 형식 → 생물학적 기능
- 구성적 기억 → 자아 전체가 허구
- 규범의 묘사 → 독자의 도덕성 향상
- 영어권 정전 표본 → 인간 보편 플롯
- 즉시 측정된 작은 효과 → 장기적 인격 변화
- 집단 결속 → 포괄적 도덕성

## 8. 네 층 과학 감사 카드

과학적 주장이 핵심인 A·B 인용구는 다음 네 층으로 기록한다.

| 층 | 기록 내용 |
|---|---|
| 1. 본문 범위 | 인용구와 주변 문맥이 실제로 어디까지 말하는가 |
| 2. 당시 근거 | 2012년까지 저자가 이용할 수 있었던 연구는 무엇인가 |
| 3. 사후 검증 | 재현, 메타분석, 대안 가설이 무엇을 보강·축소했는가 |
| 4. 현재 결론 | 지금도 유지할 수 있는 가장 좁고 강한 문장은 무엇인가 |

사후 연구로 본문을 “틀렸다”고 단번에 판정하지 않는다. `당시에는 합리적`, `당시에도 과장`, `후속 연구로 축소`, `후속 연구로 보강`, `현재도 미결`을 나누어 쓴다.

## 10. 번역·원문 잠금

### 10.1 아직 확정 번역으로 만들지 않을 용어

- `transportation`: 우선 “서사적 운송(몰입 이동)”으로 설명하고, 번역본 실제 표현을 확인한 뒤 잠근다.
- `interpreter / confabulation`: “해석기 / 작화”는 개념 설명용 임시 병기다.
- `implicit rehearsal`, `threat-simulation`, `imaginative resistance`, `just-world belief`, `truthy`: 실제 번역문을 보기 전에는 따옴표 속 정식 번역어처럼 쓰지 않는다.

### 10.2 확정 가능한 것

- 제7장 “먹사람이 세상을 바꾼다”는 오자가 아니라 `Ink People Change the World`에 대한 노승영 번역의 정식 장 제목이다.
- `storytelling animal`은 단지 이야기를 잘 “말하는” 동물이 아니라, 이야기를 만들고 소비하고 그 안에서 자신과 세계를 조직하는 동물에 가깝다.

### 10.3 원문 대조 조건

다음 경우에만 영문 원문을 대조한다.

1. 핵심 개념의 번역이 논증 범위를 바꿀 수 있을 때.
2. 단정·유보의 강도가 번역에서 달라 보일 때.
3. 같은 한국어 “이야기”가 서로 다른 영어 단어를 가릴 때.
4. 페이지·문장 누락·오역 가능성이 실제 해석을 바꿀 때.

원문 대조 결과는 번역문을 대체하지 않고 별도 메모로 붙인다.

## 13. 책 특화 진단 질문

### 13.1 “이야기는 곤경이다”

- `인물 + 곤경 + 탈출 시도`는 정의인가 통계적 경향인가 수사적 압축인가?
- 서정적·명상적·비갈등적·실험적 서사를 어떻게 처리하는가?
- 폭력과 위협의 과잉 표집이 훈련 기능 외에 주의 편향·상업성으로도 설명되는가?

### 13.2 “사회적 비행 시뮬레이터”

- 허구가 사회적 추론을 **사용**하는 것과 그 능력을 **향상**하는 것을 구분하는가?
- 자기보고 공감, 마음이론 과제, 실제 도움 행동을 같은 결과로 묶는가?
- 소설과 논픽션, 장기 독서와 단회 독서를 비교하는가?
- 효과가 허구성, 언어 연습, 관점 전환, 정서 몰입, 내용 중 무엇에서 오는가?

### 13.3 꿈과 가장놀이

- 이야기 같은 형식이 있다는 사실이 생존 훈련 기능의 증거로 쓰이는가?
- 꿈 보고의 회상 편향, 작은 표본, REM/NREM 차이를 다루는가?
- 놀이의 양과 질, 혼자놀이와 사회적 놀이, 성인의 비계를 구분하는가?
- 발달한 사회인지가 놀이를 가능하게 하는 역인과를 고려하는가?

### 13.4 거울뉴런과 신경 설명

- 관련 활성에서 공감·도덕·서사 이해 전체로 도약하는가?
- 기제의 후보, 필요조건, 충분조건, 진화 기원을 분리하는가?
- 복잡한 문화 경험을 단일 뇌 회로의 이름으로 설명 완료 처리하는가?

### 13.5 이야기의 도덕

- 이야기가 규범을 **담는다**는 주장인가, 독자를 도덕적으로 **바꾼다**는 주장인가?
- 주인공과 악당의 분류가 연구 결과를 순환적으로 만들지 않는가?
- 어떤 문화·시대·말뭉치에서 나온 자료인가?
- 트릭스터, 비도덕적 주인공, 비극, 풍자, 선전이 설명 안에 들어오는가?

### 13.6 삶 이야기

- 기억 오류, 사후 이유 만들기, 장기 정체성 서사를 하나의 과정으로 과도하게 합치는가?
- 자기서사의 일관성이 안녕을 높이는 조건과 책임을 회피하는 조건은 무엇인가?
- 자아 이야기가 “진실하지 않지만 진실 같은” 것이라는 표현은 사실·의미·정당화를 어떻게 가르는가?

## 14. 인용구 묶음 처리 프로토콜

### 입력

- 권장 묶음: 같은 장의 인용구 5–8개.
- 각 인용구에는 가능한 경우 쪽수와 앞뒤 한 문장을 붙인다.
- 사용자의 줄바꿈·구두점·강조는 그대로 보존한다.
- 쪽수만 단독으로 온 항목은 직전 인용구의 메타데이터 후보로 보되 임의 결합하지 않는다.

### 1차 스캔

모든 인용구에 다음을 한 줄로 붙인다.

`ID / 주유형 / 장내 역할 / 중요도 / 우선축 / 연결 가설`

### 정밀 선정

2–4개를 선택하되 가능한 한 기능이 겹치지 않게 한다.

- 핵심 주장 또는 정의 1개
- 논증의 경첩·다리 1개
- 증거·사례 또는 반례 1개
- 유보·자기제한 1개

### 정밀 분석 순서

1. **직해:** 문장이 실제로 말하는 최소 의미.
2. **문맥:** 앞뒤 논증에서 맡는 역할.
3. **개념:** 핵심 용어와 숨은 구분.
4. **추론:** 전제 → 화살표 → 결론.
5. **증거:** 무엇을 근거로 삼고 어디까지 말할 수 있는가.
6. **반론:** 가장 강한 경쟁 설명과 반례.
7. **전체:** 앞 장·뒤 장·초기 가설과의 연결.
8. **판정:** 유지 가능한 가장 좁고 강한 문장.
9. **질문:** 독자가 토론에서 붙들 질문 1개.

### 장 종료

사용자가 `[C01 종료]`처럼 명시했을 때만 다음을 만든다.

- `C01-A`: 장의 주장·증거·한계 요약.
- `C01-B`: 책 전체에서 이 장이 바꾼 것.
- 가설 상태 갱신.
- 다음 장으로 넘어가는 미해결 질문.

## 16. 분석 결과의 표현 규칙

1. 저자의 문장을 먼저 가장 강하게 이해한 뒤 반론을 제시한다.
2. 비판은 “틀렸다”보다 어느 화살표가 약한지 지목한다.
3. 효과 크기와 불확실성이 알려져 있으면 함께 쓴다.
4. 주류 해석, 대안 해석, 소수·비판 관점을 분리한다.
5. 사변적 적용은 `[H]`로 표시하고 본문 근거와 섞지 않는다.
6. 나의 판단에는 `약함 / 중간 / 강함`의 강도를 붙인다.
7. 한 묶음마다 토론 질문은 2–3개를 넘지 않는다.
8. 날짜와 해시태그는 묶음 분석의 끝에 붙인다.

## 17. 현재 잠금과 남은 입력

### 잠긴 것

- 9장 구조와 정식 한국어 장 제목.
- 네 개 독해축 A1–A4.
- 초기 가설 H1–H7.
- 증거 위계와 과잉 추론 경보.
- 사용 판본이 최종 인용 좌표의 기준이라는 원칙.

### 아직 잠그지 않은 것

- 사용자가 가진 책의 판권면 발행일·총쪽수·쇄.
- 장별 실제 시작 쪽수.
- 번역본의 핵심 용어 선택과 반복 방식.
- 어떤 장·인용구가 사용자의 독서에서 가장 중요한지.
- 초기 가설 H4가 실제 본문 연결을 견디는지.

사용 판본 정보가 없어도 인용구 분석은 시작할 수 있다. 첫 인용구 묶음과 쪽수가 들어오면 판본 메모를 함께 좁힌다.

## 18. 현재 판단

**판단 강도: 강함.**

이 책에 가장 필요한 렌즈는 “진화론 찬반” 하나가 아니다. 갓셜의 큰 설명을 작은 화살표로 분해하는 렌즈다. 이야기의 편재성이 참이어도 전용 적응은 아닐 수 있고, 사회적 추론을 사용해도 그것을 훈련하지 않을 수 있으며, 집단을 결속해도 더 도덕적인 사회를 만들지 않을 수 있고, 삶에 의미를 줘도 사실을 정확히 보존하지 않을 수 있다.

따라서 좋은 강독은 저자의 통합을 해체하는 데서 끝나지 않는다. 어떤 약한 형태의 명제가 끝까지 살아남는지를 찾아 다시 조립해야 한다. 현재 가장 강하게 살아남을 후보는 다음이다.

> 인간은 현실을 직접 처리하는 동시에, 이야기 형식으로 현실을 모의하고 정리하며, 그 모의와 정리에 다시 행동을 지배받는 동물이다.
