# Weekly Review 운영

주간 리뷰는 작업량 보고가 아니라 다음 작업을 열기 위한 압축 노트다. `log.md`가 append-only 사건 기록이라면, Weekly Review는 작업 판단의 압축본이다.

## 기본 위치

- `wiki/shared/reviews/weekly/`

## 목적

1. Inbox를 비운다.
2. 반복 논의된 결정을 decision-note로 승격한다.
3. 새로 생긴 책 ↔ 희곡 연결을 포착한다.
4. 다음 주 집필/정리 초점을 정한다.

## 형식

매주 또는 큰 작업 묶음이 끝난 뒤 10~20분 안에 다음만 적는다.

- 가장 남은 질문
- 새로 생긴 책 ↔ 희곡 연결
- 승격할 글감/캡처
- 결정된 것
- 아직 사용자 결정이 필요한 것
- 다음 주 집필/정리 초점
- 정리할 Inbox

길어지면 실패한 형식으로 보고, 다음 Hermes 작업의 출발점으로 쓸 수 있을 만큼만 압축한다.
