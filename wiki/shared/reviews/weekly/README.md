# weekly 운영

주간 작업 리뷰 파일을 둔다. 형식은 짧게 유지한다.

- Inbox 정리
- 새 책 ↔ 희곡 연결
- 승격할 글감
- 결정된 것과 아직 사용자 결정이 필요한 것
- 다음 주 집필/정리 초점

주간 리뷰는 회사식 회고가 아니라 다음 Hermes 작업의 출발점이다.
