# A1 전건 원문 열람 전환 체크포인트

## 이번에 결정된 것

A1에 들어온 자료는 pass 여부와 관계없이 **전건을 사용자에게 보여 준다.**

- Source-hidden은 독립 심사자에게만 적용한다.
- `pass / resting / a0_recheck / blocked / not_run`은 가시성 필터가 아니라 판정 라벨이다.
- 사용자 정본은 `wiki/writing/seeds/harvests/`에 둔다.
- 원문·연극적 이유·AI 확장·판정 이유를 같은 항목에서 비교한다.
- 세부 계약은 [[wiki/writing/decisions/A1_전건_원문열람_정본_운영_2026-08-17|A1 전건 원문 열람 정본 운영]]이 소유한다.

## 저장 경계

### Vault 안

- A1 고정 표본의 공개 원글
- 제목·사이트·게시 시각·canonical URL
- 상태별 원문 지지분·AI 확장·판정 이유
- 사용자 선택·개발 권한 상태

### Vault 밖

- 원시 HTML·이미지 cache
- 크롤러 queue/opened JSON
- A0 전체 모집단 body와 전건 URL
- 댓글·답변·レス·트랙백 본문
- exact evidence/hash/review receipt/validator fixture
- 쿠키·로그인 상태·자격 증명

Vault 밖 저장은 감사·재현·크롤링 경계이지 사용자 결과를 숨기는 경계가 아니다.

[[wiki/shared/reviews/배치71_출처비귀속_변형아이디어_레인_테스트_2026-08-17|일본 71 source-detached review]]와 [[wiki/shared/reviews/배치72_출처비귀속_변형아이디어_레인_테스트_2026-08-17|한국 72 source-detached review]]는 현재 정본이 아니다. Source-open fail을 아이디어로 되살린 첫 시험 이력만 남기고, 현재 사용자 열람 권위는 두 A1 전건 원문 문서가 가진다.

- 일본 A1: 비차단 원문 일치 10/10, blocked 마스킹 2/2·표지 7개, package validator 오류 0.
- A1 원문 열람 문서를 포함한 `seed-harvest`: 7개.
- 동기화 검사 10개, 새 문서 계열 내부 링크 22개, 오류 0.
- 원문을 포함한 문서의 commit/push: 미실행.

## 남은 것

1. **배치 73·74 이관** — 두 배치는 아직 source-detached projection 중심이다. 새 결정에 맞춰 A1 전건 원문 열람 정본으로 옮겨야 한다.
2. **외부 감사 package 장기 보존** — 현재 작업 위치는 장기 archive가 아니다. Temp 정리 전에 private archive 위치를 정해야 한다.
3. **사용자 선택** — 배치 71·72 전건은 아직 미선택이다. 원문을 읽은 뒤 붙잡을 아이디어가 생길 때만 개별 `seed-note`나 다음 쓰기를 연다.
4. **Git** — 인증 변경·commit·push는 사용자 명시 요청 전 보류한다.
