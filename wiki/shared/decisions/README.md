## 남길 만한 결정

- 반복해서 다시 논의되는 구조 결정
- 미학적 방향 선택
- 글감/운반체/소재 처리 방식 결정
- 민감 소재를 어떻게 가상화할지에 대한 결정
- 집필 큐 재정렬
- 특정 개념의 계보화 방식
- 책모임에서 반복 활용될 해석 프레임

예시: 운반체 경합, 민감 소재 가상화, 집필 큐 재정렬, 서명칸 계보, 콜센터 희곡의 `고맙대` beat 처리 방식.

좋은 결정 노트는 다음을 보존한다.

- 무엇을 결정했는가
- 왜 그 결정이 필요했는가
- 어떤 선택지를 버렸는가
- 현재 미학/강독/작업 흐름상 왜 이 선택을 했는가
- 언제 다시 열 수 있는가
- 어떤 질문형 노트/희곡/책카드와 연결되는가
