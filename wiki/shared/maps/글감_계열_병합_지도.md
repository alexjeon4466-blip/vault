# 글감 계열·병합 지도

> 트리아지 완료된 글감 228편(1차 122 + 2·3차 106)을 **엔진 계열**로 묶고, 계열마다 **운반체**(우선 개발 후보)와 **부품**(공급 재료)을 표시한 지도. 3단계 산출물.

## 사용 원칙

1. **운반체 = 강제 통합이 아니라 우선순위.** 같은 엔진의 다른 씨앗도 독립 개발 가능하다 — 비슷한 씨앗에서 다른 글이 나온다.
2. **부품 = 그 계열의 극을 쓸 때 열어볼 서랍.** 병합 판정 글감은 여기서 장면·문장·오브제로 회수된다.
3. 계열 이름은 잠정이다. 극이 써지면서 계열이 갈라지거나 합쳐질 수 있다.
4. 상태 표기: `개작` = 1막 초고+개작 존재(퇴고 관할) / `조립` = 장면 초안 존재 / `대기` = 설계 완비·초고 없음 / `설계` = 노트 단계

---

## 계열 지도

### 1. 기록 — 유류품/애도

죽은 사람의 사소함이 양식에 들어가지 못하는 극.

| 역할 | 글감 | 상태 |
|---|---|---|
| 운반체 | [[wiki/writing/draft-candidates/폐기_전_확인_초고후보_scored|폐기 전 확인]] ★ | 조립 |
| 구조 모체 | [[wiki/writing/notes/한_장짜리_보고서_scored|한 장짜리 보고서]] ★ | 설계 |
| 독립 가능 | [[wiki/writing/notes/그건_관련이_있습니까_scored|그건 관련이 있습니까]] ★, [[wiki/writing/notes/라벨_없음_scored|라벨 없음]] ★, [[wiki/writing/notes/특이사항_없음_scored|특이사항 없음]], [[wiki/writing/notes/폐기_완료_scored|폐기 완료]] | 설계 |
| 독백 재료 | 기억은_별도_양식이_없습니다, 손잡이를_잡지_않는_사람, 보완_요청 | 부품 |
| 비트 | 고작이라는_말, 감정_표현으로_분류되었습니다 | 부품 |

**병합 후보 A — 유류품 인계극**: 한_장짜리_보고서(구조) + 그건_관련이(심문 변주) + 라벨_없음(인계 불가) + 특이사항_없음(마지막 칸) + 폐기_완료(종막) + 독백 3종. `폐기_전_확인`과 엔진이 겹치지만 **다른 극이 될 수 있다** — 폐기는 관련자들의 자기기만이 중심, 인계극은 애도하는 타인이 중심.

### 2. 기록 — 관계자격

관계는 있었는데 들어갈 칸이 없는 극. 기존작 `관계란`의 확장 영토.

| 역할 | 글감 | 상태 |
|---|---|---|
| 운반체 | [[wiki/writing/draft-candidates/수정된_보호자_scored|수정된 보호자]] ★ | 개작 |
| 독립 가능 | [[wiki/writing/notes/기타에_체크하겠습니다_scored|기타에 체크하겠습니다]] ★, [[wiki/writing/notes/접수되었습니다_scored|접수되었습니다]] | 설계 |
| 진행 중 | 설명란_부족 (script/에 원고) | — |
| 독백 재료 | 저장되지_않는_문장 | 부품 |
| 교차 | 원문을_첨부해_주세요 (번역 계열과 공유) | 설계 |
| 사이클4 합류 | **떠난_아버지가_몸때문에_돌아옵니다 ★** (모순 — 버림받은 쪽이 보호자 칸에 서명, 서명칸 7태도 후보), **결혼은_거래명세서였습니다 ★** (현대생활 — 축하보다 분담표가 먼저 도는 상견례) | 설계 |

**병합 후보 B — 관계자격 4부작**: 기타에_체크(관계 확인) → 접수되었습니다(접수≠인정) → 보완_요청(재증빙) → 저장되지_않는_문장(칸 밖의 말). **한 신청자의 하루**로 통합 가능. 15분 단막 넷 또는 60분 장막 하나.

### 3. 기록 — 보정 체인

기록이 좋아질수록 사람이 사라지는 극. **운반체 없음 → 신규 극 후보.**

| 역할 | 글감 | 상태 |
|---|---|---|
| 체인 순서 | 잡음이_제거되었습니다 → 해상도가_높아집니다 → 원본으로_되돌릴_수_없습니다 → 자동_저장이_완료되었습니다 → 복구_가능한_항목이_없습니다 | 부품 |
| 판정 비트 | 중요한_말만_남겼습니다, 핵심_의미는_보존되었습니다, 상호_양해함 | 부품 |
| 전환점 | 요약하지_않겠습니다 (거부의 선택) | 부품 |
| 흡수됨 | 삭제됨_미안 (→구원 목적 2장) — 겹침 OK, 재사용 가능 | 부품 |
| 사이클4 합류 | **내_마지막_모습을_수정해줘 ★** (모순 — 사후 이미지 보정 권한의 생전 위임, 계열 정점 후보), **여자의_서술은_그녀는으로_표시됩니다 ★** (희랍어시간 — 진술서 3인칭 자동 변환과 마지막 한 줄의 "나는") | 설계 |

**병합 후보 C — 보정 극**: 죽은 사람의 마지막 녹음을 보정하는 사람의 극. 체인 5단계가 그대로 5장. 결말은 `요약하지_않겠습니다`의 빈 줄. 히라타 보강 필요: B4(타인) — 보정을 의뢰한 가족 vs 기사 vs 원본을 아는 사람의 3인 구도 추천.

### 6. 노동 — 분류/시간회수

| 역할 | 글감 | 상태 |
|---|---|---|
| 운반체 | [[wiki/writing/draft-candidates/좋은_직원입니다_단막후보_맵_scored|좋은 직원입니다]] ★ | **대기** |
| 흡수된 5장치 | 쉬고_있는_사람 → 여가_이용_교육 → 4시간_근무제_면담 → 근면_확인표 → 좋은_직원입니다 | 부품 |
| 독립 가능 | [[wiki/writing/notes/그냥_앉아_있는_사람_scored|그냥 앉아 있는 사람]] (분류 불가의 몸), [[wiki/writing/notes/그러지_않는_편이_좋겠습니다_scored|그러지 않는 편이 좋겠습니다]] (바틀비 축) | 설계 |

`그냥 앉아`와 `그러지 않는 편`은 좋은_직원입니다와 엔진이 겹치지만 방향이 다르다(회수 vs 비껴섬). 독립 유지.
