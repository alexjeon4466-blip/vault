- 원문 전체보다 URL, 핵심 문장, 내 작업과 닿는 질문을 우선 남긴다.
- 바로 장기 지식으로 취급하지 않는다.
- Hermes 정리 시 질문형 노트, 창작 노트, 책카드 보강, 비교 강의 각도, archive 중 하나로 판정한다.
