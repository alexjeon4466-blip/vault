# raw-ideas 운영

아직 질문형 노트나 창작 노트로 승격하기 애매한 글감 원석을 둔다.

- 제목은 임시여도 된다.
- 책/희곡/장면/사물/공식 언어 중 어디에 걸리는지만 표시한다.
- 두 번 이상 반복되거나 다른 노트와 연결되기 시작하면 `wiki/writing/notes/` 또는 `wiki/shared/maps/`로 승격한다.
