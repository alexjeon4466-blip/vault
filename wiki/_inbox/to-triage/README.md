# to-triage 운영

분류는 되었지만 아직 승격/폐기 판정이 남은 항목을 둔다.

- 주간 리뷰에서 우선 확인한다.
- 승격 경로가 분명하지 않으면 `왜 남기려는가`를 다시 쓴다.
- 계속 애매하면 보관하지 말고 log 또는 archive로 낮춘다.
