# Inbox 운영

Inbox는 장기 보관소가 아니라 아직 정식 노트로 승격하기 전의 임시 대기실이다. 캡처 시점에는 완성도를 요구하지 않지만, 오래 머무르게 두지 않는다.

## 기본 위치

- `wiki/_inbox/quick-captures/` — 갑자기 떠오른 문장, 장면감, Hermes에게 나중에 정리해 달라고 던지는 짧은 조각
- `wiki/_inbox/web-clips/` — 기사, 트윗, 인터뷰, 웹 문장 같은 외부 자료
- `wiki/_inbox/raw-ideas/` — 아직 질문형 노트나 창작 노트로 승격하기 애매한 글감 원석
- `wiki/_inbox/to-triage/` — 분류는 되었지만 승격/폐기 판정이 남은 항목

## 승격 경로

정리 시 다음 중 하나로 판정한다.

- `wiki/bookclub/books/` 책카드/해설 보강
- `wiki/shared/questions/` 질문형 노트
- `wiki/shared/maps/` 연결 지도
- `wiki/writing/notes/` 창작 노트
- `wiki/shared/decisions/`, `wiki/writing/decisions/`, `wiki/bookclub/decisions/` 결정 노트
- archive 또는 폐기

## 운영 원칙

- Inbox는 받는 곳이고, Weekly Review는 고르는 곳이다.
- 두 번 이상 반복되면 질문형 노트·지도·창작 노트 후보로 본다.
- 작업 방향을 바꾸는 판단이면 decision-note로 승격한다.
- 웹 클립은 원문 전체보다 URL, 핵심 문장, 내 작업과 닿는 질문을 우선 남긴다.
