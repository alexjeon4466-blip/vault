# 집필 파이프라인 — 사이클 A·B·C

> 글감이 무대에 오르기까지의 세 사이클. 새 발명이 아니라 이미 vault에 있던 실천(폐기_전_확인의 조립, 거울을_옮기는_사람의 개작, 저는의 출품)을 명시적 절차로 승격한 것. 2026-07-05 설계, 사용자 승인. 같은 날 4렌즈 검토(히라타 정합·화석 정합·프로세스 설계·외부 관행)와 적대적 검증을 거쳐 보완 개정.

## 전체 지도

```
사이클 A: 트리아지        사이클 B: 구체화              사이클 C: 집필
(무엇을 쓸까)             (초고 착수 가능하게)           (완성까지)

노트 → 채점 → 계열 →     소집 → 구조 맵 → 물성 →       조립 → 연결본 → 개작 루프 →
처방 → 집필 큐            게이트(맵 검증형 재채점)        낭독 → 완성 게이트

[설계]                    [설계 → 대기]                  [대기 → 조립 → 개작 → 무대]
```

- **사이클 A**는 [[wiki/writing/aesthetics/글감_판정_루브릭|루브릭]] 보칙 2에 정의됨 (자율 완주 방식).
- **사이클 B·C는 협업 방식** — 아래 협업 규약 참조.

## 상태 조항

- **상태의 단일 진실원은 계열·병합 지도의 역할 표 '상태' 열이다.** 모든 전이(B4→`대기`, C1→`조립`, C3→`개작`, C4→`무대`, 중단·반납 포함)는 전이가 일어난 그 턴에 상태 열을 갱신하고 `tools\대시보드_갱신.bat`을 실행한다 — 사이클 종료 시가 아니라 전이 시마다. (사이클 종료 시의 검증·갱신은 안전망이지 대체가 아니다.)
- 트리아지 지도 기록은 이력 부기로만 유지한다(진실원 아님). 전이마다 적을 의무는 없고, 사이클 종료 시 일괄 부기해도 된다.
- 운반체·극 후보(카드 생성 대상) 행의 상태 값은 **설계/대기/조립/개작/무대 다섯 낱말만** 쓴다(대시보드 파서 계약). 부품·재료 행의 값은 기존 관용을 유지한다(파서가 별도 처리). 'B 진행' 같은 부가 표시는 역할 표 4번째 열(비고)에 적는다.
- 대시보드 선반은 설계→대기→조립→개작 4열이며, **`무대` 승격 시 카드는 선반에서 퇴장한다** — 완성작의 소재지는 대시보드가 아니라 `plays/<작품>/00_작품카드.md`다.
- 계열 지도의 서명칸 계보 절에는 현재 상태 행이 없다. 연작 착수(B0) 시 파서 규약을 따르는 역할 표(역할 | 글감 | 상태 | 비고)를 추가한다.

## 사이클 B — 구체화 (집필 큐 항목 1건 → 초고 착수 가능)

**입력**: 집필 큐 항목 1건 — 유망★ 단독 1편 / 연작의 1편 / 병합 후보 1건 — 과 처방 쌍둥이(병합 후보는 구조 처방 + 재료 목록이 쌍둥이를 대신). **출력**: `대기` 상태의 구조 맵 세트.

### B0. 연작 조항 (F5 불연속·연작 후보를 선택했을 때)

- B0은 글감을 처음부터 연작으로 가정하는 선행 절차가 아니다. **B1에서 사용자가 F5 후보를 선택한 뒤, B2 전에** `draft-candidates/<연작>_연작공통.md`를 작성한다. 이미 착수한 연작은 현행 공통 문서를 그대로 이어 쓴다.
- 공통 문서는 다음을 기록한다.
  ① **공유 물성표**: 공용 오브제·공간·문구의 단일 사양과 편별 변형 허용 범위.
  ② **독립성·상속표**: 각 편의 독립 행동·완결 조건 / 앞 편에서 물려받는 것 / 뒤 편에 넘기는 것.
  ③ **편간 간격·톤 곡선**: 시간·세대·장소 간격이 만드는 효과와 전체 순서. 종막의 결말을 미리 닫지 않는다.
- 편별 B4에는 `연작 공통 정합`과 `편별 독립 완결`을 확인한다. 열린 결말·닫힌 결말·직접 발화 가운데 무엇을 택할지는 작품의 약속이 결정한다.
- 연작 전체의 완성은 편별 C4와 별개다: 전 편 `무대` + 상속표 실현 검증 + 전편 연속 통독 또는 상연 순서 시험 1회.
- 부 단위가 독립 공연 불가능하고 앞 국면의 선택이 뒤를 필연적으로 제한한다면 연작이 아니라 F4 장막 구조일 수 있다. B1 비교표에서 다시 판별한다.

### B1. 소집과 형식 선택 (여러 노트의 연결이 일어나는 자리)

- **운반체 확정** — 큐/계열 지도의 경합이 남아 있으면 후보별 비교표를 제시하고 **사용자가 판정**한다. 큐 반납 후 재진입한 글감은 직전 반납 사유를 먼저 읽는다.
- **무원칙 보호 카드** — 교리를 적용하기 전에 작품의 약속, 가장 강한 이미지·행동, 온도, 장면 생성 원리, 기존 작품과 다른 점을 기록한다. 이후 표는 이 카드를 훼손하는지 검토하는 도구다.
- **부품 서랍 소집** — 계열·병합 지도의 병합 판정 부품과 교차 계열 부품을 목록화하고, 쓸 것/보류할 것/반환할 것을 사유와 함께 정한다. 부품을 많이 쓰는 것이 발전은 아니다.
- **형식 후보 비교 카드** — [[wiki/writing/aesthetics/희곡_길이별_설계_원리|길이별 설계 원리]]의 후보 카드와 비교표로 2–3안을 만든다. 가장 작은 자연 규모 후보를 포함하고, 후보끼리는 시간 연료·새 행동·관객의 기다림 가운데 둘 이상이 달라야 한다. 장막·연작은 독립 연료가 있을 때만 연다.

| 기록 | 후보 A | 후보 B | 후보 C |
|---|---|---|---|
| 자연 규모 |  |  |  |
| 시간을 만드는 연료 |  |  |  |
| 보호되는 핵심 / 손실 |  |  |  |
| 새 행동·결과 |  |  |  |
| 설명·제작·후속 비용 |  |  |  |
| 자기복제 위험 |  |  |  |
| 빠진 연료 |  |  |  |
| 판정 | 선택 / 병렬 소시험 / 보류 / 기각 |  |  |

- **사용자 선택** — 선택 형식과 선택 사유를 카드에 기록한다. 사용자가 명시적으로 병렬 탐색을 고르지 않는 한, 선택 전에 B2 구조 맵을 하나의 형식으로 잠그지 않는다. 병렬 탐색은 가지마다 별도 B2 표와 판본명을 두고 상태 열은 하나만 유지하며, 나머지는 비고에 기록한다.
- **자연 규모와 외부 제약 분리** — `현재 자연 규모 가설`과 `submission_target의 매수·시간·AI 규정`을 서로 다른 칸에 쓴다. 공모가 미정이면 외부 제약은 `미정`이며, 이를 이유로 30–40분 단막을 기본값으로 넣지 않는다.
- **AI 규정 확인** — 목표 공모가 있으면 contest/의 AI 규정을 확인한다. AI 활용 제한 공모는 C1 전에 `사용자 단독 집필 모드`로 전환하고, AI는 구조·감사·평가·체크리스트만 담당한다.
- 처방 재독과 재해석 렌즈는 보호 카드 뒤에 적용한다. 가상화 결정이 있으면 이 시점에 이행한다. F5 연작 선택 시 B0을 실행한다.

### B2. 선택 형식 구조 맵 — `draft-candidates/<작품>_구조맵.md`

네이밍은 형식 중립이다. 기존 `_단막후보_맵` / `_초고후보_scored` / `_1막구조` 계보는 소급 개명하지 않는다. 활성 작품도 링크 안정성이 더 중요하면 기존 파일명 안에서 새 절을 추가한다.

#### B2 공통 맵

- **선택 카드**: 보호할 핵심, 선택 형식, 자연 규모 가설, 시간 연료, 자기복제 위험, 빠진 연료, 외부 제출 제약을 한곳에 기록한다.
- **장소·시간 조직**: 출입·체류·이동·시간 점프·몽타주·장면 간격 가운데 작품이 실제로 쓰는 규칙을 명세한다. 한 장소·연속 시간이 아닌 것은 결함이 아니다.
- **작동 압력**: 누가 무엇을 해야 하거나 피해야 하는지, 누가/무엇이 그것을 막는지, 압력이 처음 실제 행동을 바꾸는 지점을 적는다. 절차적 질문과 첫 1/4 배치는 선택 렌즈이지 보편 의무가 아니다.
- **인물·대항력 표**: 중심/중간/외부 같은 히라타 위치는 필요할 때만 쓴다. 타인, 다른 시간의 자기, 녹음, 사물, 규칙, 자연, 관객 정보차 등 실제 대항력을 기록하며 외부자를 의무화하지 않는다.
- **정보·권한·관객 표**: 인물·장치·관객이 아는 것, 인정하지 않는 것, 가진 권한, 언제 달라지는지를 기록한다. 정보 차이가 핵심이 아닌 형식은 감각·리듬·신체 접근 차이로 대체할 수 있다.
- **몸·사물·소리·빛·매체 표**: 누가 무엇을 실제로 다루며, 그 상태나 접근권이 어디서 바뀌는지 적는다. 화면·서류는 가능한 경로일 뿐 기본 재료가 아니다.
- **행동·상태 표**: 장면/비트/국면 | 겉 행동 | 정보·관계·권한 변화 | 물질·신체 상태 | 다음에 남기는 조건. 장면 수와 장면당 매수는 고정하지 않는다.
- **결말·잔여 후보**: 작품의 약속에 맞는 1–3안을 둔다. 물성 잔여·미결만 강제하지 않으며, 직접 선택·닫힌 결말·큰 발화도 앞선 행동이 벌어들였다면 후보가 된다.
- **규모 기록**: 예상 원고지 매수와 예상 실연 시간은 서로 다른 가설로 적고 공식 환산하지 않는다. 실제 값은 C2 이후 측정한다.

#### B2 선택 형식 모듈

선택 후보가 결합형이면 실제로 시간을 만드는 모듈만 함께 쓴다. 표를 채우는 행위가 아니라 **다음 행동을 생성하는 증거**가 목적이다.

| 형식 어포던스 | 필수 B2 증거 |
|---|---|
| 최소 자연 규모 | 핵심 행동 1회가 독립 작품으로 끝나는 조건 / 더 짧으면 잃는 것 / 더 길면 새로 필요한 연료 |
| F1 연속 체류·수평 | 체류·재진입 이유 / 출입·조합 변화표 / 대기·정리·이동이 만드는 결과 |
| F2 수직 반복 | 반복의 주체·기능·권한·위험·비용·몸·사물 상태 변화표 |
| F3 다중 흐름 | 흐름별 독립 변화표 / 교차 지점 / 전경·배경·주의 배분 / 교차가 남기는 결과 |
| F4 종축·인과 장막 | 기다림–부분 성취–예상 밖 결과–다음 조건 회로 / 하위 위기 / 국면 전환 뒤 규칙·관계 변화 |
| F5 불연속·연작 | 단위별 독립 행동·완결 / 편간 시간·장소 간격 / 다음 단위가 상속·변형하는 것 / B0 공통 문서 |

시간 점프·다장면·몽타주는 F4/F5의 연료가 될 수 있다. 연속형을 택했을 때만 연속 규칙을 지키며, 그 경우에도 장면 경계와 수량은 작품이 정한다.

### B3. 물성·언어 문서 (조건부)

별도 문서는 오브제·언어 규칙이 실제 장면 생성 장치일 때 만든다. B2 공통 맵에 충분히 들어 있으면 생략하고, 조립·개작 중 필요가 확인되면 소급 작성한다.

- `<작품>_대사_어휘표.md` — 반복될 말, 설명 위험어, 인물별 어휘 결, 장면별 대표 문장 후보. `한 장면 한 문장`은 경합을 줄이는 시험값이지 문체 의무가 아니다.
- `<작품>_<대상>_물성표.md` — 실물 사양, 사용 주체, 접근권, 상태 변화, 상상력 방향. 상징 설명만 있고 누구도 다루지 않는 오브제는 행동을 부여하거나 보류한다.
- 비언어·춤·소리·빛 중심 작품은 대사 어휘표 대신 동작·리듬·음향·조명 규칙표를 쓸 수 있다.

### B4. 게이트 — 맵 검증형 재채점

`B4 맵 검증형 재채점` 표기는 대시보드 호환을 위해 유지한다. 루브릭의 가능성 판정을 다시 등급화하지 않고, **현재 선택한 형식으로 C1을 시작할 만큼 증거가 있는지**를 확인한다. ○의 근거는 B2의 행·비트·국면을 지목한다.

#### B4 공통 게이트

| 축 | 검증형 질문 |
|---|---|
| 보호 | B1 보호 카드의 약속·이미지·온도·장면 생성 원리가 구조 맵에서 살아 있는가 |
| A1 | 몸·관계·관객 지각 가운데 무엇이 어디서 달라지는가 |
| A2 | 개념이 장면을 다 설명하고도 남는 사람·욕망·우연·잡음이 있는가 |
| A3 | 실존 인물·피해·출처와 필요한 거리를 확보했는가 |
| B1 | 선택한 형식의 장소·시간 조직과 배우·관객의 접근 경로가 실행 가능한가 |
| B2 | 압력이 실제 행동을 바꾸며, 대항력이 그것을 쉽게 끝내지 못하게 하는가 |
| B3 | 반복·장면·국면이 돌아올 때 주체·기능·권한·위험·비용·물질 상태 중 하나 이상이 질적으로 달라지는가 |
| B4 | 타인·자기·사물·규칙·자연·관객 정보차 중 실제 대항력이 작동하는가 |
| B5 | 몸·사물·소리·빛·매체 중 적어도 하나가 의미가 아니라 사건을 운반하는가 |
| 규모 | 자연 규모 가설과 외부 제출 제약을 분리했고, 매수·실연 시간을 공식 환산하지 않았는가 |

#### B4 선택 형식 게이트

- **최소형**: 핵심 행동이 독립 완결되며, 더 긴 형식의 한 비트에 불과하지 않은가.
- **F1**: 체류·출입·조합 변화가 같은 관계의 반복이 아니라 다른 결과를 남기는가.
- **F2**: 반복의 주체·권한·위험·비용·몸·사물 상태가 누적 또는 전복되는가.
- **F3**: 각 흐름이 독립 변화하고, 교차가 다른 흐름의 다음 행동을 바꾸며, 관객의 주의 배분이 설계돼 있는가.
- **F4**: 기다림과 부분 성취가 다음 조건을 만들고, 하위 위기가 상위 행동의 결과를 바꾸는가.
- **F5**: 각 단위가 홀로 서면서도 편간 간격과 상속이 전체 축적을 바꾸는가.

추가 확인: 원작·책·실화 재해석이면 `원작을 몰라도 독립 / 알면 다른 작품`, 연작이면 `연작 공통 정합`, 모든 작품은 `자기복제 위험과 감수 사유`를 기록한다.

- 공통 게이트와 선택 형식 게이트에 필요한 근거가 모이면 맵 말미에 **`B2 통과 / 대기 후보`**를 기록하고 `대기`로 승격한다.
- △·✕는 작품 등급이나 자동 폐기가 아니다. 증거가 빠졌으면 B2, 선택 형식 자체가 원형을 훼손하면 B1 후보 비교로 돌아간다. 분량이 짧다는 이유만으로 장면을 패딩하지 않는다.
- 두 차례 회귀 뒤에도 같은 병목이면 자동 반납하지 않고 `다른 형식 선택 / 병렬 소시험 / 큐 반납 / 실험 초고`를 사용자가 고른다. 회귀 횟수는 진단 로그다.
- 결과는 파일명 개명(`_scored`)이 아니라 맵 파일 말미의 `판정과 방향` 절과 지도에 남긴다.

## 사이클 C — 집필 (대기 → 무대)

**입력**: `대기` 상태의 구조 맵 세트. **출력**: 출품 가능 상태의 작품 + 작품카드.

C 전 구간의 상위 기준은 [[wiki/writing/aesthetics/전용수x히라타_통합_극작노트|통합 극작노트]], 장면 퇴고 도구는 [[wiki/writing/notes/히라타_오리자식_극작_체크리스트|히라타 체크리스트]]다.

### C1. 필요한 물질을 충분히 조립 → 상태 `조립`

- 장면·국면을 나눠 탐색할 때는 `draft-candidates/<작품>_<장면명>_초안.md`를 쓴다. 최소형·독백·단일 수행처럼 분할이 작업을 방해하면 처음부터 하나의 임시 연결본으로 써도 된다.
- 두 장면 이상이면 `<작품>_연결부_퇴고표.md`, 장면 내부 규칙이 필요하면 `<작품>_자체_퇴고표.md`를 시작한다. 두 문서는 필요할 때만 만들고 역할을 섞지 않는다.
- 장면 초안 뒤에는 `무엇이 이동·변형됐는가`를 한 줄로 적는다. 정보·권한뿐 아니라 관계, 몸, 감각, 리듬, 접근권, 사물 상태도 이동으로 인정한다. 아무것도 달라지지 않으면 문장보다 B2의 압력·대항력·시간 연료를 먼저 본다.
- **충분히 쓰기** — 목표 매수에 가까워졌다는 이유로 다음 장면을 짧은 결말로 지정하지 않는다. 필요한 정보 이동, 역할 역전, 물성 변화, 반복 비용, 미해결 압력이 실제 행동을 더 만들면 계속 쓴다. 분량 보고는 진단값일 뿐 완료 판정이 아니다.
- 조립 순서는 자유다. 가장 확신 있는 장면·반복·국면부터 시작할 수 있으나, 연결본 전에는 선택 형식이 요구하는 핵심 회로가 모두 쓰였는지 확인한다.

### C2. 물질적으로 충분한 연결본 = 초고 성립

- **초고 성립의 파일 조건** = `drafts/<작품>_1-N장_연결본.md` 또는 `drafts/<작품>_1막초고.md`의 존재. 신규 작품은 연결본 네이밍을 기본으로 쓰고, 기존 1막초고 계보는 소급 개명하지 않는다.
- **초고 성립의 내용 조건** = B1에서 보호한 핵심 행동과 선택 형식의 시간 연료가 끝까지 한 번 작동하고, 주요 관계·몸·사물·관객 정보 가운데 필요한 변화가 연결돼 있다. 예정 분량 도달만으로 초고가 되지 않는다.
- 파일 머리의 `초고 측정` 절에 다음을 따로 기록한다.

| 측정 항목 | 기록 |
|---|---|
| 관찰 원고지 매수 | 계산 도구·날짜와 함께 기록 |
| 예상 발화 시간 | 낭독 전 추정임을 표시 |
| 예상 비언어 시간 | 침묵·노동·이동·빛·전환을 별도 추정 |
| 실측 공연 시간 | 낭독·동선 시험 뒤에만 입력 |
| 현재 자연 규모 판단 | 짧게 완결 / 유지 / 확장 / 분할 가설 |
| 외부 제출 규격 | 공모가 있을 때만 별도 기록 |

- 원고지 매수와 실연 시간은 공식 환산하지 않는다. 침묵극·동시 대사·가변 동선은 지면과 시간이 크게 어긋날 수 있다.
- 연결본 생성 이후의 **진본은 연결본**이다. 신규 장별 초안은 draft-candidates/에 두고, 기존 drafts/ 장별 파일은 옮기지 않는다. C4 때 `1회 재동기화` 또는 `연결본 우선 동결`을 작품카드에 기록한다.

### C3. 측정 뒤 개작 루프 → 상태 `개작` (반복, 회차 기록)

**개작 판본 규약** — ① 미세 수정은 진본에 직접 반영하고 회차를 체크리스트에 기록한다. ② 목적이 분명한 대수술은 `drafts/<작품>_<기준판본>_<목적>개작.md`로 분기한다. ③ 각 작품의 **현재 기준판 1개**를 체크리스트 첫 절에 명시한다. 기존 혼재 네이밍은 소급 개명하지 않는다. 압축 전에는 충분한 연결본을 보존한다.

#### C3-0. 이번 회차 범위 선택

1. 연결본을 읽고 **상류 병목 1–3개**만 고른다. 장소·시간 조직, 압력, 대항력, 반복 기능, 관객 정보, 물질 경로, 결말의 획득 과정 가운데 어디가 여러 증상을 만드는지 찾는다.
2. 각 병목에 `바꾸면 함께 달라지는 장면·표·오브제·어휘`를 적어 downstream 비용을 가시화한다.
3. 매수와 실연 시간을 따로 본 뒤 `현재 길이 유지 / 압축 / 확장 / 재배열 / 분할 / 다른 제출처` 가운데 이번 회차 목적을 하나 고른다. 길다는 이유만으로 압축하지 않는다.
4. 수정이 구조 병목이 아니라 이미 작동하는 선택의 취향 교체나 국소 윤문뿐이면 동결 후보로 보낸다.

#### C3-1. 진단–수정–낭독

1. **기능 감사** — `notes/<작품>_<대상>_기능감사.md`. 반복어·상수 문구·오브제·침묵·직접 발화가 무엇을 실제로 바꾸는지 본다. 경합하는 강한 문장은 자동 삭제하지 않고 낮춤·이동·행동화 여부를 사용자가 정한다.
2. **현재판 평가** — `notes/<작품>_현재판_평가_<날짜>.md`. 작품의 약속과 명료성 3층(물리·인과·해석), 선택 형식 게이트, 자기복제 위험, 상류 병목 1–3개를 기록한다. 기존 `6영역 100점` 서식은 공모·기존 계보 비교가 필요할 때 쓰는 선택 렌즈이며 완성 점수나 형식 보편 기준이 아니다.
3. **작업 체크리스트 갱신** — 현재 기준판, 이번 회차 목적, 병목별 수정 범위, 완료/보류/다음 작업, 측정값을 기록한다.
4. **본문 수정** — 문장 증상보다 상류 조건을 먼저 고친다. 설명 대사는 장소→압력→정보/감각 차이→물질 경로→그래도 필요한 말인가 순서로 진단한다. 직접 발화·닫힌 결말·범람은 작품의 약속과 앞선 획득 과정에 맞으면 보호한다. 낭독에서 걸리는 문장은 리듬 문제와 인물 콘텍스트 문제를 나눠 수리한다.
5. **낭독·실연 측정**:
   - **5a 비공개 낭독** — 사용자 단독 음독과 가능한 동작 수행. 발화 시간과 비언어 시간을 분리해 관찰한다.
   - **5b 외부 낭독** — 목적 1줄과 작가 질문 2–3개를 정한다. 진행 가능하면 약식 CRP(의미 진술→작가 질문→중립 질문→허락받은 의견), 불가능하면 질문+관찰 시트로 진행한다. 수용/기각은 사용자가 사유와 함께 기록한다.
6. **길이 결정** — 기능·주체·비용·앞뒤 상태가 같은 중복부터 자른다. 실제 노동, 수행되는 침묵, 선택을 만드는 반복, 희소하게 준비된 직접 발화는 단지 길다는 이유로 먼저 자르지 않는다.

**종료·정체·동결 조항** — 회차 상한은 두지 않는다. 3회차마다 `계속 / 동결 / C4 상정 / B1·B2 회귀`를 점검한다. 외부 피드백 2회 뒤에도 같은 상류 병목이 남으면 형식 선택 또는 구조 문제 신호로 기록하되, 회귀·계속·동결은 사용자가 정한다. 추가 수정이 증상 윤문만 반복하면 현재판을 동결하고, 재개 조건이 생길 때 새 목적 판본으로 연다.

### C4. 완성 게이트 — "잠글 수 있는 무대 판본"

세 조건 충족 시 `무대` 승격:

1. **낭독 회차(5b 외부 낭독) 1회 이상 완료** — 완료란 피드백 각 항목에 수용/기각 판정과 사유가 기록된 상태를 말한다(전부 기각도 판정이 기록되었으면 충족). 통과 여부의 **판정자는 사용자**이며, 현재판 평가에 '낭독 판정: 통과/미통과 + 근거 한 줄'로 기록될 때 성립한다. 외부 낭독 기회가 8주 이상 없으면 자가 낭독 녹음 + 청취 후 자기 피드백 기록 1회로 인정할지 사용자가 결정할 수 있다 — 인정 시 그 사실을 작품카드에 남긴다(대체였음을 은폐하지 않는다).
2. **최신 현재판 평가의 P0 전부 완료** — P0는 공통 게이트·선택 형식 게이트가 실제 판본에서 무너진 지점, 물리·인과 명료성 때문에 상연이 불가능한 지점, 안전·권리·출처 문제, 작품의 보호 약속을 훼손한 지점이다. 루브릭 한 축의 ✕, 열린/닫힌 결말의 취향, 목표 매수 편차만으로 P0를 만들지 않는다. 우선순위 중/하는 잔여 허용.
3. **완성·제출 경로 점검** — 실측/추정 시간을 구분하고 현재 자연 규모와 판본 동결 사유를 작품카드에 기록한다. submission_target이 있으면 공식 요강의 분량·접수·마감·AI 규정·판권·미발표·무기명·파일명·시놉시스 요구를 다시 확인한다. target이 없으면 `미정`으로 두어도 완성 판정을 받을 수 있다. 자연 규모와 요강이 다르면 패딩하지 않고 다른 제출처·낭독·공연·연작 편입·별도 압축본을 비교한다.

**버전 네이밍** — 신규 작품의 제출본은 `<작품>_v<N>.md/hwp`로 통일한다(하위 수정은 v6_4식 언더스코어 하위판 대신 다음 정수 버전). 저는 계보의 `_전체_` 접요사·하위판 표기는 과거 관용으로 소급하지 않는다. 파생판은 `_낭독용` / `_합평용` / `_연출안` 접미로 구분하며 버전 판정에서 제외한다(latest_version은 `v<N>` 계열만 가리킨다).

**불통과·잠금** — 게이트 불통과 시 미충족 조건을 현재판 평가에 명시하고 C3으로 회귀한다(회귀도 회차로 센다). 통과 시 해당 판본은 잠금(lock) — 이후 수정은 새 버전 `v<N+1>`로만 연다.
