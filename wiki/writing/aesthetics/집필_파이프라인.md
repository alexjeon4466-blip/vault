# 집필 파이프라인 — 사이클 A·B·C

> 글감이 무대에 오르기까지의 세 사이클. 새 발명이 아니라 이미 vault에 있던 실천(폐기_전_확인의 조립, 거울을_옮기는_사람의 개작, 저는의 출품)을 명시적 절차로 승격한 것. 2026-07-05 설계, 사용자 승인. 같은 날 4렌즈 검토(히라타 정합·화석 정합·프로세스 설계·외부 관행)와 적대적 검증을 거쳐 보완 개정.

## 전체 지도

```
사이클 A: 트리아지        사이클 B: 구체화              사이클 C: 집필
(무엇을 쓸까)             (초고 착수 가능하게)           (완성까지)

노트 → 채점 → 계열 →     소집 → 구조 맵 → 물성 →       조립 → 연결본 → 개작 루프 →
처방 → 집필 큐            게이트(맵 검증형 재채점)        낭독 → 완성 게이트

[설계]                    [설계 → 대기]                  [대기 → 조립 → 개작 → 무대]
```

- **사이클 A**는 [[wiki/writing/aesthetics/글감_판정_루브릭|루브릭]] 보칙 2에 정의됨 (자율 완주 방식).
- **사이클 B·C는 협업 방식** — 아래 협업 규약 참조.

## 상태 조항

- **상태의 단일 진실원은 계열·병합 지도의 역할 표 '상태' 열이다.** 모든 전이(B4→`대기`, C1→`조립`, C3→`개작`, C4→`무대`, 중단·반납 포함)는 전이가 일어난 그 턴에 상태 열을 갱신하고 `tools\대시보드_갱신.bat`을 실행한다 — 사이클 종료 시가 아니라 전이 시마다. (사이클 종료 시의 검증·갱신은 안전망이지 대체가 아니다.)
- 트리아지 지도 기록은 이력 부기로만 유지한다(진실원 아님). 전이마다 적을 의무는 없고, 사이클 종료 시 일괄 부기해도 된다.
- 운반체·극 후보(카드 생성 대상) 행의 상태 값은 **설계/대기/조립/개작/무대 다섯 낱말만** 쓴다(대시보드 파서 계약). 부품·재료 행의 값은 기존 관용을 유지한다(파서가 별도 처리). 'B 진행' 같은 부가 표시는 역할 표 4번째 열(비고)에 적는다.
- 대시보드 선반은 설계→대기→조립→개작 4열이며, **`무대` 승격 시 카드는 선반에서 퇴장한다** — 완성작의 소재지는 대시보드가 아니라 `plays/<작품>/00_작품카드.md`다.
- 계열 지도의 서명칸 계보 절에는 현재 상태 행이 없다. 연작 착수(B0) 시 파서 규약을 따르는 역할 표(역할 | 글감 | 상태 | 비고)를 추가한다.

---

## 사이클 B — 구체화 (집필 큐 항목 1건 → 초고 착수 가능)

**입력**: 집필 큐 항목 1건 — 유망★ 단독 1편 / 연작의 1편 / 병합 후보 1건 — 과 처방 쌍둥이(병합 후보는 구조 처방 + 재료 목록이 쌍둥이를 대신). **출력**: `대기` 상태의 구조 맵 세트.

### B0. 연작 조항 (연작·다부작에만 적용)

- 연작은 첫 편의 B 착수 전에 `draft-candidates/<연작>_연작공통.md` 1건을 작성한다 —
  ① **공유 물성표**: 공용 오브제(같은 책상·펜 등)의 단일 사양. 편별 문서는 이를 상속만 하고 재정의하지 않는다.
  ② **순서 의존표**: 각 편이 앞 편에서 물려받는 것 / 뒤 편에 넘기는 것.
  ③ **톤 곡선**: 어느 편이 종막인지의 순서 지정 포함 — 단 종막의 결말 내용은 확정하지 않으며, 편별·연작 전체의 결말은 B2 결말 후보 원칙(남는 물성/상태 + 유보되는 것 형식, 확정 금지)을 따른다.
- 편별 B4에 '연작 공통 문서와의 정합'을 확인 항목으로 추가한다.
- 연작 전체의 완성은 편별 C4와 별개의 게이트: 전 편 `무대` + 순서 의존표 최종 검증 + 전편 연속 통독 1회.
- 2·3부작은 B0을 준용하되, 부 단위가 독립 공연 불가능한 경우(원인→결과 구조 등) 구조 맵을 전체 1건으로 작성할 수 있다 — 선택은 B1에서 사용자가 확정.

### B1. 소집 (여러 노트의 연결이 일어나는 자리)

- **운반체 확정** — 큐/계열 지도의 경합이 남아 있으면 Claude가 후보별 비교표를 제시하고 **사용자가 판정**한다. 큐 반납 후 재진입한 글감은 직전 반납 사유 재독이 필수 항목이다.
- **AI 규정 확인** — 확정 시 submission_target 후보 공모의 AI 관련 규정을 contest/에서 확인한다(예: 2026 한국극작가협회 신춘문예는 AI 활용작 결격). AI 활용 제한 공모를 목표로 하는 작품은 C1 착수 전에 **'사용자 단독 집필 모드'**로 전환한다 — Claude는 구조 맵·어휘표·감사·평가·체크리스트 등 진단/도구 문서만 담당하고 본문 문장 초안은 작성하지 않는다. contest/ 공모 기준 문서에는 'AI 규정' 필드를 둔다.
- **부품 서랍 소집**: 계열·병합 지도에서 이 계열의 병합 판정 부품 전부 + 교차 계열의 관련 부품을 목록화. 쓸 것과 안 쓸 것을 표로 확정 (안 쓰는 부품은 사유 한 줄 — 서랍은 다음 극을 위해 남는다).
- 처방 재독 + 재해석 4렌즈 방향 확정 (가상화 결정이 있으면 이 시점에 이행).

### B2. 구조 맵 — `draft-candidates/<작품>_구조맵.md`

네이밍은 형식 중립: 단막이면 `_단막후보_맵`, 1막 이상이면 `_1막구조` 등 기존 관용 허용. 기존 세 계보(`_단막후보_맵` / `_초고후보_scored` / `_1막구조`)는 소급 개명하지 않는다.

두 화석(폐기_전_확인·좋은_직원입니다)을 기반으로 하되, 집필 전 3요소·표 3종·위치 열·결말 후보 형식은 이번 헌장에서 새로 의무화하는 항목:

- **집필 전 3요소** (히라타 — 미확정 시 B2 진행 불가):
  ① **장소** — 반공간 명세: 출입 통로, 인물별 떠나지 못하는 이유, 이 장소가 말을 바꾸는 규칙·금지·권한.
  ② **배경** — 인물별로 다르게 아는 과거·관계·제도 조건 목록 + 각각을 설명 대사 없이 드러낼 경로(틈·물건 상태·잘못된 기록) 1개씩.
  ③ **문제** — 작품 첫 1/4 안에 걸리는 절차적 질문 한 문장(걸리는 장 번호 명기).
- **목표 분량** — 목표 공모 기준 원고지 환산 매수(단막 통상 70~100장, 공모 미확정 시 80장 안팎 기본값)와 장별 배분 추정.
- 장 구성 (5~8장, 각 장의 문제와 출입 — **장 경계는 연속 시간을 깨지 않는 사건, 즉 인물의 출입 또는 무대 장치의 반복 주기 갱신(거울의 십오분 방식)으로만 나눈다. 시간·장소의 비약 금지.** 비약이 필요하면 사유를 맵에 기록하고 B4에서 B1 축 재검. 각 장은 플롯 표의 행으로 작성)
- 무대규칙 (하지 않을 것 포함 — 금지 목록이 미학)
- 인물표 (**위치 열 필수**: 중심/중간/외부/권한자/비인간 장치/부재자 — 통합노트 3.2. 1인극이어도 시스템·화면·부재자에 위치를 배정) + 외부자가 들어오는 통로(몇 장에서 누가) 명기
- **정보 차이 표** (체크리스트 4절 형식: 인물·장치 | 아는 것 | 모르는 것·인정하지 않는 것 | 가진 권한 | 언제부터 아는가). 마지막 행에 **관객** — 각 장 시점에서 관객이 어느 인물보다 많이/적게 아는가 한 줄(결말 후보 비교의 판단 근거).
- **구체소재 표** (체크리스트 6절 5열 + '권한 보유자 이동' 열 = 6열. 기존 오브제 권한 이동표는 이 권한 열로 병합 — 명단→출입증→의자→봉투는 예시로 유지)
- **플롯 표** (체크리스트 8절: 장면 | 겉 사건 | 정보 이동 | 권한 이동 | 남는 물성/상태)
- B5 부재축 (무대 밖에서 현재를 바꾸는 것)
- 결말 후보 2~3개 (확정하지 않음 — 조립하며 고른다. **각 후보는 사건이 아니라 '남는 물성/상태 + 유보되는 것' 형식으로 적는다.** 예: 화면 `특이사항: 없음` + 물자국 / 유보: C가 들은 말의 실재)

### B3. 물성 문서 (조건부)

물성 문서는 **오브제 구동형 작품**(물건이 사건을 만드는 극)의 표준이다. 구조 맵의 무대규칙·구체소재 표가 어휘·물성 규칙을 이미 담으면 별도 문서는 생략 가능하며, 조립·개작 중 필요가 확인되면 그 시점에 소급 작성한다(거울의 오브제/동선표 방식).

- `<작품>_대사_어휘표.md` — 상수 문구(반복될 말), 금칙어(설명어·감정어), 인물별 어휘 결, **장면별 대표 문장 후보**(한 장면 한 문장 — 조립 전 가설로 지정)
- `<작품>_<대상>_물성표.md` (대상 명시 허용) — 오브제의 실물 사양 + **상상력 방향 열**(이 오브제가 관객의 상상력을 어느 방향으로 잡는가). 방향을 한 구절로 적지 못하는 오브제는 상징 후보이므로 제외하거나, 인물이 실제로 다루는 절차를 부여한다.

### B4. 게이트 — 맵 검증형 재채점

재채점은 루브릭 원문(가능성 질문)이 아니라 **맵 검증형 질문**으로 한다 — ○의 근거는 구조 맵의 해당 위치(장 번호·표의 행)를 지목할 수 있어야 한다. (루브릭 보칙 3과 상호 링크.)

| 축 | 검증형 질문 |
|---|---|
| A1 | 떨리는 사람의 떨림이 절차와 부딪히는 장 번호를 지목할 수 있는가 |
| A2 | 인물이 기능을 넘치는 순간이 특정 장·특정 절차에 배치돼 있는가 |
| A3 | 결말 후보들이 서로 다른 상태로 닫히는가 — 전부 같은 논제 증명으로 수렴하지 않는가 |
| B1 | 장 구성 전체가 연속 시간 하나이고, 인물별 체류 이유가 인물표에 있는가 |
| B2 | 문제가 걸리는 장이 전체의 첫 1/4 안인가 |
| B3 | 플롯 표 전 장에 정보 또는 권한 이동이 기입돼 있는가 (공란 장 = △) |
| B4 | 인물표에 외부자가 있고 그 출입이 장 구성에 있는가 |
| B5 | 각 소재의 마지막 상태가 처음과 다른가, 부재축이 어느 장의 대사를 바꾸는가 |

추가 확인: **재해석 최종 검증**(판별 질문 — 원작 몰라도 완결 / 아는 관객에게 다른 작품), 연작이면 **연작 공통 문서와의 정합**.

- 전축 ○ → **`대기` 승격** (계열 지도 상태 열 갱신 + 트리아지 지도 부기).
- 하나라도 △ → B2로 회귀. 2회 회귀에도 전축 ○가 안 되면 구조가 아니라 글감·처방의 문제로 보고 큐로 반납한다(처방 재작성 대상) — 재진입 시 카운터는 리셋. 2회는 시험값이며 사례 3건 축적 후 재검토.
- 재채점 결과는 파일명 개명(`_scored`)이 아니라 맵 파일 말미의 '판정과 방향' 절 + 지도 기록으로 남긴다(링크 파손 방지).

## 사이클 C — 집필 (대기 → 무대)

**입력**: `대기` 상태의 구조 맵 세트. **출력**: 출품 가능 상태의 작품 + 작품카드.

C 전 구간의 상위 기준은 [[wiki/writing/aesthetics/전용수x히라타_통합_극작노트|통합 극작노트]], 장면 퇴고 도구는 [[wiki/writing/notes/히라타_오리자식_극작_체크리스트|히라타 체크리스트]]다.

### C1. 장면 조립 → 상태 `조립`

- 장별 초안을 **개별 파일**로: `draft-candidates/<작품>_<장면명>_초안.md` (폐기_전_확인 방식 — 장면 단위라 실패해도 국소적)
- 두 장면이 모이면 `<작품>_연결부_퇴고표.md` 시작 (이음매는 장면만큼 중요)
- 같은 시점에 `<작품>_자체_퇴고표.md`도 시작한다(폐기_전_확인 방식) — 해설 대사·과거 정보 노출·권한자 악역화·인물 상징화의 삭제 기준('이 문장을 종이가 대신 할 수 있는가' 등)과 최종 삭제 원칙(대사를 물성·절차어·행동으로 낮출 수 있으면 줄인다)을 작품별로 확정. **연결부 퇴고표(이음매)와 자체 퇴고표(장면 내부)는 별개 문서다.**
- 장면 초안 완료 시 1행 점검 — 이 장면의 말은 **대화인가 회화인가**: 새로 이동한 정보·권한·관계를 한 가지도 적을 수 없으면 회화다. 회화 판정 시 문장을 고치지 말고 B2 플롯 표의 해당 행과 대조해 조건(장소·문제·정보 차이) 쪽을 수선한다.
- 조립 순서는 자유 — 첫 장면부터일 필요 없음 (가장 확신 있는 장면부터)

### C2. 연결본 선언 = 초고 성립

- **초고 성립의 정의** = `drafts/<작품>_1-N장_연결본.md` **또는** `drafts/<작품>_1막초고.md`의 존재. 신규 작품의 표준 네이밍은 연결본 방식이며, 기존 1막초고 계보(4작품)는 소급 개명하지 않고 그대로 초고로 인정한다(링크 파손 방지).
- 선언 시 실측 분량(원고지 환산)을 파일 머리에 기록하고 목표 대비 편차를 개작 루프 입력으로 넘긴다.
- 연결본 생성 이후의 **진본은 연결본**이다. 신규 작품의 장별 초안은 draft-candidates/에 그대로 두고 drafts/로 이동·복사하지 않는다(불일치 허용 — 동기화 노동 제거). 기존 작품의 drafts/ 내 장별 파일도 옮기지 않고 확정본으로 동결한다. C4 승격 시 1회 재동기화 또는 '연결본 우선' 표기 후 동결 — 택일을 작품카드에 기록한다.

### C3. 개작 루프 → 상태 `개작` (반복, 회차 기록)

**개작 판본 규약** — ① 미세 수정(반복어 압축, 지문 행동화 등)은 진본(연결본/1막초고)에 직접 반영하고 회차를 체크리스트에 기록한다(거울 방식). ② 목적이 뚜렷한 대수술 패스는 별도 파일 `drafts/<작품>_<기준판본>_<목적>개작.md`로 분기한다(예: `_압축개작`, `_낭독리듬개작`). ③ 각 작품의 **현재 기준판 1개**를 작업 체크리스트 첫 절에 명시한다. 기존 혼재 네이밍(`_2차수정본`, `_3차개작본` 등)은 개명하지 않는다.

거울을_옮기는_사람이 확립한 4박자 + 낭독:

1. **기능 감사** — `notes/<작품>_<대상>_기능감사.md` (반복어·상수 문구·오브제가 실제로 일하는가) + 장면별 대표 문장 1개 확인(**한 장면 한 문장** — 경합하는 초과 문장은 긴장 지점으로 지목만 하고, 낮춤·전환(화면/행동/소리/물건) 여부의 결정은 사용자, 실행은 4번 본문 수정 단계에서. 전환 결과는 사후에 기능감사 문서에 부기)
2. **현재판 평가** — `notes/<작품>_현재판_평가_<날짜>.md`. 서식은 거울 2026-07-02 평가를 표준으로: **6영역 100점 채점**(극적 구조 25 / 대사 20 / 인물 20 / 장치 15 / 주제 10 / 독창성 10) + 시각별 보충(주류 심사/공연장/실험) + 사용자 미학 확인란(균열의 지속, 결말 미해결이 자산으로 유지되는가) + 다음 개작 체크 목록(각 항목 우선순위 상/중/하)
3. **작업 체크리스트 갱신** — `notes/<작품>_작업체크리스트_<날짜>.md` (완료/다음 작업, 현재 기준판 명시)
4. **본문 수정** (진본에 직접) — 설명적으로 느껴지는 대사는 문장을 바로 고치지 않고 [[wiki/writing/notes/히라타_오리자식_극작_체크리스트|체크리스트]] 9절 순서로 조건을 먼저 진단한다: 장소→문제→정보 차이→구체소재→그래도 필요한 대사인가 (통합노트 3.4의 6·7단계 — 범람은 수행인가 해설인가 / 결말은 해결을 유보하는 상태 변화인가 — 포함). 낭독에서 걸리는 문장은 두 층으로 판정: (a) **리듬** — 소리의 문제 → 문장 수리, (b) **콘텍스트 어긋남** — 이 말이 이 인물의 언어 범위 안에 있는가 → 어휘표의 '인물별 어휘 결'과 대조해 어휘표 갱신 또는 인물 콘텍스트 재확정 (연극 입문 4장 요약 확장 후 근거 링크 보강 예정)
5. **낭독** (두 단계):
   - **5a. 비공개 낭독** — 사용자 단독 음독, 관찰 시트만 기록(외부 피드백 회차로 세지 않음).
   - **5b. 외부 낭독** — 모임/지인, 콜드 리드 무방. 낭독 전 '이번 낭독의 목적 1줄'과 작가 질문 2~3개를 정한다(성공적인 낭독의 정의는 '다음 초안을 쓸 수 있게 해주는 것'). 사용자가 진행을 주도할 수 있는 자리에서는 약식 CRP 4단계를 기본형으로 한다 — ① 의미 진술(무엇이 남았는가 — 긍정·구체) ② 작가 질문 ③ 중립 질문(의견을 싣지 않은 질문만) ④ 허락받은 의견(사용자는 거절 가능). 진행 통제가 불가능한 자리에서는 '작가 질문 2~3개 + 관찰 시트 기록'만으로 외부 낭독 회차가 성립한다. 낭독용 판본 생성 시 **관찰 시트**를 동반 생성 — 쉽게 흐른 곳/걸린 곳(각각 리듬/콘텍스트 판정), 청자의 신체 반응(앞으로 기울임·웃음·산만함). 피드백 원본 보관(script/)은 사용자가 수행하고, Claude는 요지를 체크리스트에 반영한다. 수용/기각은 사용자 결정 — 기각도 사유와 함께 기록.

**종료·정체 조항** — 회차 상한은 두지 않는다(재촉 금지). 단 3회차마다 정체 점검 1행을 작업 체크리스트에 기록한다 — 계속 / 동결(사유+재개 조건 명시, 상태는 중단 조항을 따름) / C4 상정 중 사용자가 택일. '계속'은 불이익 없는 동등한 선택지다(점검은 재촉 의식이 아니다). 점검 없는 4회차 연속 진행은 하지 않는다. 외부 피드백 2회차 반영 후에도 우선순위 상 결함이 남으면 이를 구조 문제 신호로 보고 B2 회귀를 **제안**한다 — 회귀/개작 계속/동결의 택일은 사용자.

### C4. 완성 게이트 — "출품 가능 상태"

세 조건 충족 시 `무대` 승격:

1. **낭독 회차(5b 외부 낭독) 1회 이상 완료** — 완료란 피드백 각 항목에 수용/기각 판정과 사유가 기록된 상태를 말한다(전부 기각도 판정이 기록되었으면 충족). 통과 여부의 **판정자는 사용자**이며, 현재판 평가에 '낭독 판정: 통과/미통과 + 근거 한 줄'로 기록될 때 성립한다. 외부 낭독 기회가 8주 이상 없으면 자가 낭독 녹음 + 청취 후 자기 피드백 기록 1회로 인정할지 사용자가 결정할 수 있다 — 인정 시 그 사실을 작품카드에 남긴다(대체였음을 은폐하지 않는다).
2. **최신 현재판 평가의 다음 개작 체크에서 우선순위 상 항목 전부 완료 처리** — P0는 '우선순위 상'의 별칭: 공연 성립을 막는 결함(루브릭 8축 ✕ 재발, 무대규칙 위반, 사용자 미학 위반 — 균열의 봉합, 결말의 해결). 우선순위 중/하는 잔여 허용.
3. **제출 준비 점검** (C4 시점): (a) 목표 공모 요강 재확인 — 분량·접수 방법·마감·판권 귀속(예: 강원일보 희곡 판권 2년 귀속) (b) 분량 검증 — 200자 원고지 환산 매수를 작품카드에 기록 (c) 본문 무기명 판본 준비 — 인적사항은 표지/신청서 파일로 분리 (d) '미발표작' 요건 확인 — 해당 공모가 공개 낭독·온라인 게재를 발표로 간주하는지 점검. **HWP 변환 + 공모 파일명 규칙 적용, 시놉시스(원고지 10장 안팎)는 출품 시점(submission_target 확정 후)에 작성한다** — 공모별로 요구가 달라 미리 만들면 재작업이다.

**버전 네이밍** — 신규 작품의 제출본은 `<작품>_v<N>.md/hwp`로 통일한다(하위 수정은 v6_4식 언더스코어 하위판 대신 다음 정수 버전). 저는 계보의 `_전체_` 접요사·하위판 표기는 과거 관용으로 소급하지 않는다. 파생판은 `_낭독용` / `_합평용` / `_연출안` 접미로 구분하며 버전 판정에서 제외한다(latest_version은 `v<N>` 계열만 가리킨다).

**불통과·잠금** — 게이트 불통과 시 미충족 조건을 현재판 평가에 명시하고 C3으로 회귀한다(회귀도 회차로 센다). 통과 시 해당 판본은 잠금(lock) — 이후 수정은 새 버전 `v<N+1>`로만 연다.

**승격 절차**: `plays/<작품>/00_작품카드.md` 생성. frontmatter 필수 필드 = `type: play-card`, `status`, `created`, `updated`, `visibility`, `play`(작품 제목 — title 필드 아님), `form`(형식, 예: 1인극 단막), `latest_version`(파일명), `source_folder`(원고 위치, 통상 script), `submission_target`, `sources`(전 버전 경로), `connected_questions`. '저는' 카드를 서식 표준으로 삼되, 생성 시 위키 검증 기준 충족을 확인한다. → 계열 지도 상태 열 갱신(상태 조항) → 대시보드 갱신. **출품 자체는 완성과 별개** — 출품 원본 기록은 contest/submissions에 두고, 작품카드의 투고 이력 표는 그 요약 미러로 유지한다(출품/결과 발생 시 두 곳을 같은 턴에 갱신).

### 중단 조항 (C 공통)

사용자는 어느 시점이든 작품을 중단할 수 있다.
① 구조 결함이 원인이면 상태를 `설계`로 되돌리고 B2 재진입 조건을 기록.

## 협업 규약 (B·C 공통, 2026-07-05 사용자 확정)

- **둘 다 협업**: 구조 맵·어휘표·장면 초안 모두 Claude가 초안 가능(단 B1의 '사용자 단독 집필 모드' 판정 시 본문 문장 초안 제외). 단 —
- **문장의 최종 소유권은 항상 사용자.** Claude 초안은 제안이며, 사용자가 고친 문장이 그 작품의 문체 기준이 된다. 개작 루프에서 Claude는 감사·평가·체크리스트(진단)를 주도하고, 본문 수정(처방)은 사용자 우선.
- 한 턴의 작업 단위는 장면 1개 또는 도구 문서 1개 — 트리아지처럼 자율 완주하지 않는다. 매 단계 사용자 확인 후 진행. **예외**: C3 진단 3종(감사·평가·체크리스트)은 본문을 수정하지 않는 읽기 산출물이므로, 사용자가 회차 시작 시 승인하면 1턴 묶음 생성을 허용한다. 본문 수정(처방)은 이 예외에 포함되지 않는다 — 항상 별도 턴, 사용자 우선.
- **진단 발화 형식**: Claude의 감사·평가는 '원칙 위반' 판정이 아니라 '원칙과 긴장하는 지점' 지목으로 표현한다(통합노트 4.2). 중립 질문을 기본형으로 하고(대안 문장 제시는 사용자가 요청할 때만), '의도한 것 vs 지면에 있는 것'의 간극 지적을 표준 형식으로 삼는다. 긴장 지점의 유지/수정은 사용자 결정이며, 유지 결정도 사유와 함께 작업 체크리스트에 기록한다.
- **script/ 쓰기 소유권**: `script/`(vault 루트 — wiki/writing 하위 아님)에 대한 쓰기 — 제출본·낭독용 판본·피드백 원본 보관 — 는 **사용자 전담**이다. Claude는 script/를 읽기 전용으로만 참조하며, 제출본·낭독용 판본 생성 시에는 drafts/에 최종 텍스트를 준비하고 script/ 이관은 사용자가 수행한다.
- **동시 진행(WIP)**: [강행] 사이클 A는 B·C와 병행 가능하되 반드시 별도 세션에서 하고, A 배치의 지도 갱신과 B4/C4 승격의 지도 갱신을 같은 시간대에 돌리지 않는다(트리아지 지도·계열 지도 동시 수정 금지). [권고 기본값] C(조립·개작)는 최대 2편(주력 1 + 톤 전환용 1), B는 동시 1편. 새 작품의 B 착수는 진행 중인 C 작품의 `개작` 진입 이후를 권장한다 — 초과·착수 시점은 사용자가 사유 한 줄과 함께 결정하면 허용. 한도는 시험값이며 서명칸 1~2편 완주 후 재조정한다.
- 민감 소재 작품은 가상화 확정 문서(쌍둥이의 「가상화 확정」 절)를 B1에서 재확인.

## 폴더 규약 (현행 유지 + 명시화)

| 폴더 | 역할 | 사이클 |
|---|---|---|
| `notes/` | 글감·쌍둥이·감사/평가/체크리스트 | A, C3 |
| `maps/` | 원본 창작장치 지도 (재해석 4렌즈의 원천) | A, B1 |
| `draft-candidates/` | 구조 맵·어휘표·물성표·장면 초안·퇴고표·연작공통 | B, C1 |
| `drafts/` | 연결본(진본) + 장별 확정본(동결) + 개작 판본 | C2~C3 |
| `plays/<작품>/` | 작품카드 (완성작의 신분증) | C4 |
| `script/` | 제출본·낭독용·외부 피드백 원본 (vault 루트, 쓰기: 사용자 전담) | C3~C4 |
| `contest/` | 공모 기준(AI 규정 필드 포함)·제출 기록·수상 | 출품 (파이프라인 밖) |

- `revisions/`·`references/`는 현재 미사용 — 신규 산출물을 두지 않는다.
- **위키 검증**: 파일 개명·이동 또는 지도·카드류 문서 갱신이 있었던 턴 + 각 게이트(B4·C2·C4) 통과 시 `verify_bookclub_wiki.py`(bookclub-wiki-v2 스킬의 scripts/ — 명령은 거울 작업체크리스트 2026-07-02에 기록)를 실행해 broken_wikilinks 0, missing_frontmatter 0, placeholder_hits 0을 확인한 뒤 다음 단계로 넘어간다. 장면 초안 턴은 사이클 종료 검증으로 갈음한다.
