# 연극적 약속·물성 판정 카드

> **현실과 다르다는 사실은 결함이 아니다. 작품이 학습시킨 약속을 어기거나, 핵심 인과를 보존할 안전하고 반복 가능한 상연 해법이 없을 때가 결함이다.**

## 1. 모든 희곡 평가의 필수 표시

> **이 절은 약속 판정 등급(`허용/P2/P1/P0`)과 소유 층위(`본문/제작/기술`)의 단일 진실원이다.** 파이프라인 §0.7과 실행카드 §0.5는 이 절을 운영 사본으로 싣는다. 등급 정의를 그쪽에서 바꾸지 않는다.

`[약·물] 약속=허용|P2|P1|P0|미평가 / 소유=해당 없음|본문|제작|기술|미평가 / 상세=OFF|ON`

- 문제가 없으면: `[약·물] 약속=허용 / 소유=해당 없음 / 상세=OFF`
- 자료가 부족하면: `[약·물] 약속=미평가 / 소유=미평가 / 상세=ON`
- 시간 조직이 관련되면 뒤에 `시간=엄격 리얼타임|대표·압축|혼합`을 붙인다(무관하면 `해당 없음`). 이 enum의 진실원은 [[wiki/writing/aesthetics/희곡_길이별_설계_원리#1.1 세 가지 시간 계약|길이 원리 §1.1]]의 기록값이다.
- 문제가 여러 개면 합치지 않는다:  
  `[약·물] P1/본문(표면 계보) + P0/기술(젖은 바닥) / 시간=혼합 / 상세=ON`

| 약속 판정 | 기준 |
|---|---|
| 허용 | 약속 안의 크기·횟수·시간 압축, 대표 구역, 노출형 전환, 안전 대체 |
| P2 | 낮은 등급의 고증·수치 어색함, 특정 제작안에서만 생기는 난도 |
| P1 | 선포한 약속 불일치, 핵심 기호의 가독성 실패, 필수 상태 계보 모순 |
| P0 | 통제되지 않은 중대한 위험 또는 핵심 인과·발견·결말을 보존할 해법 없음 |

## 2. 상세 점검 가동문

다음 중 하나라도 `예`이면 `상세=ON`, 모두 `아니오`이면 필수 표시만 하고 멈춘다.

- [ ] 사물의 위치·상태·무게·저항이 사건, 발견, 관계 판단, 결말을 바꾸는가?
- [ ] 현실 공정시간의 보존·압축이 정보·권한·알리바이를 바꾸는가?
- [ ] 작은 글자·무늬·균열 등을 최악 시야석에서 판독해야 하는가?
- [ ] 재료의 회차별 변동이 필수 정보·큐·안전을 좌우할 수 있는가?
- [ ] 높이·칼·불·전기·물·중량·미끄럼·동선 또는 반복 리셋 병목이 있는가?
- [ ] 현재 판정이 `P2/P1/P0`인가?

## 3. 물성 병목 상세 체크

### A. 관객 판단

- 반드시 알아야 할 것: `________________________________`
- 정보 운반: `직접 지각 / 배우·소리·빛의 매개 지각 / 학습된 약속 지각`

### B. 네 층 분리

| 층 | 이번 작품에서 잠글 것 |
|---|---|
| 서사 물리 | 위치·상태·행위자·원인과 결과 |
| 지표 물리 | 판단을 만드는 최소 실제 물성 1~2개 |
| 제작 물리 | 시야·안전·반복·리셋을 만족하는 해법 범위 |
| 생활 절차 | 장면 판단에 꼭 필요한 공정·용어·수치만 검증 |

### C. 약속 지도

| 반드시 고정 | 대표·압축 허용 | 회차별 변동 허용 | 허용하지 않음 |
|---|---|---|---|
|  |  |  |  |

- [ ] 초반 첫 주요 수행에서 관객이 코드를 학습하는가?
- [ ] 우연은 결함의 모양만 바꾸고 핵심 정보·결과·안전은 바꾸지 않는가?

### D. 네 시계와 상연 해법

- 지면 분량 `___` / 객석시간 `___` / 극중시간 `___` / 현실 공정시간 `___`
- 시간 계약: `엄격 리얼타임 / 대표·압축 / 혼합`
- 안전하고 반복 가능하며 전 좌석에 인과를 보존하는 해법이 하나 이상 있는가? `예 / 아니오`

### E. 최종 귀속

- 합리적 해법이 여러 개 있음 → `제작`, 희곡 감점 금지
- 안전·큐·리셋 운용 문제 → `기술`
- 일관된 상연 해법 자체가 없음 → `본문`
- `P0/기술`은 현재 구현 중단이지 자동적인 본문 결함이 아니다.
- 텍스트·R0은 합리적 해법의 가능성까지만 말할 수 있다. 실제 저항·후열 시야·안전·리셋은 R3·R4 전에는 `미확인`으로 남긴다.

## 4. 판정 예시

| 상황 | 표시 | 판단 |
|---|---|---|
| 실제 40분 건조를 중앙 한 폭과 90초 반복으로 압축 | `허용/제작 · 대표·압축 · ON` | 핵심 저항과 하중을 남기고 초반에 `한 폭=전체`를 학습시키면 허용 |
| 공급자란 도장이 핵심 발견인데 작은 칸만 지문에 있고 매개 반응도 없음 | `P1/본문 · ON` | 직접 판독 또는 손 멈춤·낭독·빛·위치 같은 전달 경로가 필요 |
| 젖은 바닥 위 불안정한 우마에서 실제 칼 사용 | `P0/기술 · ON` | 현재 구현을 중단하고 안전 대체 시험. 대안이 전혀 없을 때만 `P0/본문` |
