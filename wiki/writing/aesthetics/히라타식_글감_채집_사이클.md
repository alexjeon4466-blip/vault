# 희곡 글감 채집·숙성 사이클 — 히라타 렌즈 포함

> 파일명은 기존 링크 호환을 위해 유지한다. 히라타의 장소·배경·정보 차이는 여러 선택 렌즈 중 하나이며, 채집의 기본 형식을 정하지 않는다.

## 한 줄 핵심

> **씨앗의 가능성을 증명하지 않는다. 설명하기 전의 말·이미지·소리·몸짓·시간을 짧게 보존하고, 한 번의 맥락 전환 뒤에도 다시 떠오르는 것 중 사용자가 지금 개발하겠다고 고른 것만 B로 이관한다.**

---

## 0. 이 문서의 역할

이 문서는 사이클 A 가운데 `포착 → 숙성 → 재접촉 → 선택 응답 포착`을 담당한다.

| 구간 | 담당 |
|---|---|
| 원자료 포착·숙성·재접촉 후보 제시·사용자 응답 포착 | **이 문서** |
| 선택 상태 확정·B 이관 판단과 패킷 | [[wiki/writing/aesthetics/글감_판정_루브릭\|글감 다음 행동 루브릭]] |
| 선택 뒤 쓰기·조사·장면쌍·물성 탐색 | [[wiki/writing/aesthetics/집필_파이프라인_실행카드\|집필 파이프라인 — 실행 정본]] B — 보호·탐색 |
| F1–F5·시간 계약·규모 규격 | [[wiki/writing/aesthetics/희곡_길이별_설계_원리\|희곡 길이·시간 조직 설계 원리]] |
| 자연 규모의 판단 | [[wiki/writing/aesthetics/집필_파이프라인\|집필 파이프라인]] §0.4 |

이 단계에서는 작품의 질, 공모 가능성, 독립 완결성, 형식, 길이, 결말을 판정하지 않는다.

희곡 평가를 하지 않으므로 **`[약·물]` 표시 대상도 아니다.** 파이프라인 §0.7의 필수 표기는 종합 평가·퇴고 판정·피드백 번역·낭독 결과에 적용되며 사이클 A에는 걸리지 않는다. 물건의 무게·소리·상태는 `raw_residue`에 사실로 남길 뿐, 약속 판정이나 소유 층위를 붙이지 않는다.

### 즉시 쓰기 예외

장면이 이미 와 있고 사용자가 지금 쓰고 싶다면 숙성을 기다리지 않는다.

> `포착 → 사용자 개발 선택 → B 이관`

으로 같은 회차에 직행할 수 있다. 사용자가 혼자 적는 개인 메모의 첫 문장은 먼저 쓰고 보호할 잔여를 소급 기록해도 된다. 숙성은 의무 대기기간이 아니라 조기 해설을 줄이는 장치다.

AI·협업자가 본문을 만들거나 정식 탐색 파일을 저장하기 전에는 추가 질문 없이 최소 권리 스크린을 하고, `clear/resolved`이면 글감 다음 행동 루브릭의 A→B 패킷과 work_id를 함께 만든다. 사용자의 정확한 요청을 `user_authorization / protected_residue`로 보존하고 아직 모를 것은 `unconfirmed`로 둘 수 있다. 출처 상세는 탐색 직후 보충할 수 있지만 유령 work_id나 패킷 없는 본문은 만들지 않는다. 명백하거나 미해결인 차단 요인이 있으면 `blocked`로 두고 공유·확장·B 이관을 멈춘다.

## 1. 상태 계약

> **이 절이 `seed_status` enum과 허용 전이의 단일 진실원이다.** 글감 다음 행동 루브릭 §3의 라우터는 그중 사용자 선택 구간만 다루는 부분집합이며, 값을 신설하거나 뜻을 바꾸지 않는다. (이관 패킷 스키마는 반대로 루브릭 §6이 진실원이다 — 두 문서가 각자 한 축씩 소유한다.)

씨앗 상태는 작업 원장의 `activity`와 다른 네임스페이스다.

| `seed_status` | 뜻 | 허용 행동 |
|---|---|---|
| `captured` | 원형을 짧게 포착함 | 출처·잔여·경계만 기록 |
| `resting` | 평가하지 않고 숙성 중 | 기본적으로 아무것도 하지 않음 |
| `resurfaced` | 맥락 전환 뒤 다시 떠오름 | 기억 잔여와 변형을 append-only로 추가 |
| `develop_now` | 사용자가 지금 개발하기로 선택 | 최소 B 이관 패킷 작성 |
| `transferred` | work_id가 생기고 B로 이관됨 | 이후 탐색은 파이프라인에서 실행 |
| `source_archive` | 지금은 끌림이 없음 | 검색 가능하게 보관하고 재등장 허용 |
| `duplicate_link` | 이미 있는 원자료와 실질적으로 같음 | 진본 씨앗에 링크 |
| `blocked` | 권리·사생활·윤리 경계가 미해결 | 해소·출처 방식 변경 전 정지 |

### 허용 전이

| 사건 | 전이 |
|---|---|
| 포착을 마치고 놓아둠 | `captured → resting` |
| 맥락 전환 뒤 다시 접촉 | `resting/source_archive → resurfaced` |
| 다시 보았으나 지금 개발하지 않기로 함 | `resurfaced → resting` |
| 사용자가 지금 개발하기로 응답 | `resurfaced/captured → develop_now` |
| 권리·사생활·안전이 `clear/resolved`이고 이관 패킷 생성 | `develop_now → transferred` |
| B 탐색 뒤 쉬기로 함 | `transferred → resting`, 기존 work_id 유지 |
| 당분간 보관 | `captured/resting/resurfaced/transferred → source_archive` |
| 중복 진본을 찾음 | 현재 상태 → `duplicate_link`, 이력 보존 |
| 차단 요인 발견 | 현재 상태 → `blocked` |
| 차단 해소 | `blocked → resting` 또는 사용자 응답 뒤 `develop_now` |

`blocked` 상태에서는 차단 해제를 위한 좁은 사실·권리 확인만 허용한다. 창작 확장과 B 이관은 허용하지 않는다.

`병합 재료`는 씨앗 상태로 쓰지 않는다. 다른 작품이 실제로 이 씨앗을 필요로 할 때 `resonance_link`만 추가한다. 아직 독립 작품이 되지 않았다는 이유로 기존 작품에 미리 흡수하지 않는다.

`제외`와 영구 삭제도 기본 상태로 쓰지 않는다. 지금 끌리지 않는 씨앗은 `source_archive`, 중복은 `duplicate_link`, 윤리·권리 문제는 `blocked`로 구분한다.

## 2. 무엇을 채집하는가

채집 단위는 `사회 이슈`나 `주제`가 아니라 설명하기 전에 남은 **잔여**다.

- 정확히 들린 한 문장 또는 말의 리듬
- 설명되지 않은 몸짓·중단·거리
- 반복되거나 갑자기 끊긴 행동
- 잘못 들은 말, 오청, 말실수, 망설임
- 물건의 위치·무게·손상·소리
- 빛·날씨·냄새·온도·시간 간격
- 한 장소의 이상한 사용법
- 불가능하거나 아직 무대화되지 않은 이미지
- 서로 다른 두 시간이 포개지는 순간
- 논리보다 오래 남는 질문

현재 행동·갈등·대항력·시간 엔진이 없어도 채집할 수 있다. 목소리, 정적, 이미지, 리듬만 남은 파편도 정식 씨앗이다.

## 3. 출처 레인

어느 레인도 다른 레인보다 우수하지 않다.

| 레인 | 예 | 기본 경계 |
|---|---|---|
| **생활 관찰** | 집, 출근길, 운동, 대기, 돌봄, 소비, 이사 | 타인의 식별정보 제거 |
| **대화·오청·기억** | 들은 문장, 가족 습관, 오래된 말, 꿈 | 사적 발화를 공유·공연할 권리 확인 |
| **책·공연·전시** | 문장, 장면, 관람 뒤 남은 이미지 | 대표 표현을 베끼지 않고 출처 기록 |
| **공개 자료** | 뉴스, 공지, 판결, 지역 기록, 블로그, 공개 SNS | 원문 확인, URL·날짜, 짧은 인용 |
| **장소·사물·감각** | 복도, 화분, 기계음, 빛, 날씨, 동식물 | 의미를 먼저 붙이지 않음 |
| **기존 작업의 잔여** | 삭제 장면, 실패한 소품, 남은 인물, 다른 결말 | 부모 작품과 판본 출처 유지 |
| **형식 충동** | 반복, 동시성, 관객 참여, 무언, 목소리 규칙 | 완성 형식으로 조기 잠그지 않음 |

로그인·가입·인증을 우회하지 않는다. 보지 못한 본문을 추정하지 않는다.

## 4. A0 — 포착

### 4.1 최소 포착 카드

```yaml
seed_id:
captured_at:
source_pointer:
raw_residue:
protect_from_explanation:
rights_privacy:
seed_status: captured
```

- `source_pointer`: 직접 관찰, 기억, 작품명·쪽수, 기사 URL·날짜처럼 다시 찾을 최소 정보.
- `raw_residue`: 정확한 말·이미지·소리·몸짓·질문. 길게 요약하지 않는다.
- `protect_from_explanation`: 지금 당장 발명하지 않을 이유·주제·전사.
- `rights_privacy`: 공개·사적·동의 필요·미확인·차단 가운데 현재 경계.

### 4.2 포착하지 않는 경우

다음 정도로 제한한다.

- 완전 중복이며 기존 씨앗에 링크할 수 있음
- 원문·사실을 확인하지 못함
- 권리·사생활상 기록 자체가 부적절함
- 아무 말·이미지·감각·질문도 남지 않음

`아직 무대 조건이 없다`, `갈등이 없다`, `짧다`, `기존 문법과 다르다`는 포착하지 않을 이유가 아니다.

### 4.3 선택 렌즈 메뉴

원형을 보존하는 데 실제로 도움이 될 때만 한두 문장을 덧붙일 수 있다.

- 장소 또는 이동 경로
- 사람·목소리·관계
- 반복·도약·기다림·동시성
- 몸·사물·소리·빛
- 정보·기억·감각의 차이
- 말의 리듬과 침묵
- 불가능한 이미지와 형식적 장난

모든 항목을 채우지 않는다. 이것은 진단표가 아니다.

## 5. A1 — 숙성

숙성은 카드 보강이나 결함 수정이 아니라 **무개입**이다.

- 고정 일수를 요구하지 않는다.
- 기본값은 한 번의 맥락 전환이다. 다른 날, 다른 장소, 다른 작업 뒤에 다시 볼 수 있다.
- 일부러 떠올리려고 반복해서 읽지 않는다.
- 그동안 다른 장면·관계·이미지로 변형되어도 원본 카드는 고치지 않는다.
- 다시 떠오르지 않아도 실패가 아니다.

즉시 쓰기 충동이 생기면 언제든 A3으로 직행한다.

---

## 6. A2 — 재접촉

재접촉 기록은 원본 아래에 append-only로 붙인다. 가능하면 원문을 다시 보기 전에 기억나는 것을 먼저 적는다.

```yaml
reencountered_at:
without_source_recall:
mutation_since_capture:
recurrence_signal: recalled | mutated | both | not_recalled
user_pull:  # 사용자 표현 그대로, 확인 전에는 unconfirmed
current_question:
next_action: resting | offer_for_selection | source_archive | blocked
```

### 재접촉 질문

필요한 것만 묻는다.

1. 출처를 보지 않고도 무엇이 남았는가.
2. 기억 속에서 무엇이 바뀌었는가.
3. 사람·목소리·시간·이미지 가운데 무엇을 더 따라가고 싶은가.
4. 설명하지 않은 채 남겨두고 싶은 것은 무엇인가.
5. 권리·사생활·실존 피해의 경계가 달라졌는가.

기억이 원문과 다르면 오류를 지우지 않는다. 사실 기록은 바로잡되, 변형된 기억은 별도의 창작 잔여로 보존할 수 있다.

---

## 7. A3 — 사용자 선택 응답 포착

AI나 협업자는 작가의 끌림을 대신 판정하지 않는다. 재접촉할 씨앗을 보여줄 때 `상위 점수`가 아니라 서로 다른 이유를 가진 소수의 카드를 제안한다. `user_pull`은 사용자가 직접 말한 표현만 기록하며, 답이 없으면 `unconfirmed`다. 자동화는 `recurrence_signal`을 기록할 수 있지만 이를 사용자의 끌림이나 순위로 환산하지 않는다.

- 시간이 지나도 기억에 남은 것
- 현재 작업과 온도·관계·형식이 다른 것
- 오래된 카드인데 새 맥락에서 다시 떠오른 것
- 설명은 약하지만 이상하게 남는 와일드카드

사용자는 0개를 고를 수 있다. 여러 개를 고를 수도 있지만, 기본 질문은 다음 하나다.

> **이 가운데 지금 주의를 배정해 한 번 써보거나 알아보고 싶은 것이 있는가?**

이 문서는 사용자의 응답을 그대로 포착한다. [[wiki/writing/aesthetics/글감_판정_루브릭|글감 다음 행동 루브릭]]이 그 응답을 `develop_now` 상태와 B 이관 패킷으로 확정한다.

선택은 작품성 승인, 완성 약속, 공모 투입 결정이 아니다. 현재 개발할 주의를 정하는 일이다.

## 8. A→B 이관 계약

`develop_now`가 되면 [[wiki/writing/aesthetics/글감_판정_루브릭|글감 다음 행동 루브릭]]으로 최소 패킷을 만든다.

이관 패킷의 단일 스키마는 글감 다음 행동 루브릭 6절이 담당한다. 이 문서는 `seed_id / source_pointer / raw_residue / protect_from_explanation / rights_privacy / 사용자 선택 응답`만 넘기고 별도 이관 양식을 복제하지 않는다.

이관할 때 `work_id`가 생긴다. 실제 쓰기·장면쌍·조사·물성 탐색은 파이프라인 B(보호·탐색)에서 실행한다.

착수 게이트는 B에 들어올 자격을 판단하는 게이트가 아니다. 그것은 정식 C1 집필로 넘어가기 전, 관리되지 않은 비가역 위험이 없는지 확인하는 착수 게이트다.

## 9. 출처와 윤리 거리

모든 원천을 반드시 허구화해야 하는 것은 아니다. 작품에 맞는 출처 방식을 명시한다.

| 방식 | 확인할 것 |
|---|---|
| 자기 경험 | 타인의 사생활이 함께 노출되는가 |
| 공개 사실의 변형 | 사실과 허구의 경계, 식별 가능성 |
| 허구화 | 고유 플롯·대표 장면·표현을 지운 뒤에도 독립하는가 |
| 동의받은 버바팀·다큐 | 동의 범위, 철회, 편집 권한, 공연 맥락 |
| 정식 각색 | 저작권·라이선스·표기 조건 |

실존 피해를 다른 장소·관계로 바꾸는 것만으로 윤리 문제가 자동 해결되지는 않는다. 반대로 공공 사실을 다룬다는 이유만으로 모두 금지하지 않는다. 미해결 경계는 `blocked`로 두고 B 이관 전에 확인한다.

## 10. 자기복제는 씨앗의 결함이 아니다

`담당자 + 없는 항목 + 화면 상태값 + 작은 공모 + 사물 잔여 + 조용한 미결`이 떠오르더라도 씨앗을 감점하거나 버리지 않는다.

- 채집에서는 원래 문장·리듬·이미지만 보존한다.
- B 탐색의 실제 장면이 다시 익숙한 해결법으로 자동 번역될 때만 자기복제 렌즈를 호출한다.
- 반복 관심과 반복 해결법을 구분한다.
- 기존 작품과의 공명은 `resonance_link`로 기록하되 병합을 선결하지 않는다.

### 사이클 단위 편향 감사

한 씨앗을 검열하지 않고 여러 회차의 분포를 본다.

- 공개 제도 기사만 계속 고르고 있지는 않은가.
- 생활·관계·놀이·자연·감각·예술 관람 레인이 비어 있지는 않은가.
- 같은 연령·직업·권력 관계만 반복하지 않는가.
- 건조한 미결과 반대되는 희극·축제·직접성·큰 사건도 포착했는가.

편향이 보여도 쿼터를 강제하지 않는다. 다음 채집 회차에서 비어 있던 레인을 **추가로 열어볼 뿐**이다.

## 11. 자동화·도구 어댑터

도구는 바뀔 수 있고 이 문서의 미학 계약은 유지된다.

자동화가 할 수 있는 일:

- 공개 소스 목록 만들기
- 이미 본 링크 중복 제거
- URL·날짜·제목 보존
- 원자료 카드 초안과 검색 가능한 큐 만들기
- 오래된 카드 중 재접촉 후보 찾기

자동화가 하지 않는 일:

- 사용자의 끌림을 점수로 대리
- `유망★` 자동 승격
- A/B/F 자동 채점
- 작품 형식·길이·결말 확정
- 자동 게시·외부 공유
- 사적 자료 접근 우회

정기 실행은 품질이 확인된 뒤 선택한다. 수동 채집과 즉시 메모가 기본 경로로 계속 유효하다.
