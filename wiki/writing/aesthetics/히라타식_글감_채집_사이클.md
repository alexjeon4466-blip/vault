# 히라타식 글감 채집 사이클

## 한 줄 핵심

> 오늘의 공개 자료를 주제로 요약하거나 실물 시험·단막 규격에 미리 끼워 맞추지 않는다. 출처의 사람·목소리·관계·시간·행동·이미지를 넓게 보존한 뒤, **작가가 더 써보고 싶은 0–3개**만 사용자 선택 대기로 보낸다.

## 왜 이 노트가 필요한가

기존 글감 작업은 책 원본·책카드·질문망에서 희곡 장치를 캐내는 데 강했다. 여기에 한 가지 루트를 더 둔다. **그날의 세계에서 들어온 사건, 뉴스, 공지, 생활 마찰**을 매일 또는 수시로 훑고, 그 안에서 희곡이 될 만한 장면 조건만 걸러내는 루트다.

이 루트의 출발점은 `autoTHREADS` 검토에서 얻은 구조다.

- 공개 소스를 주기적으로 훑는다.
- 이미 본 링크는 ledger로 중복 제거한다.
- AI가 초안을 만들지만, 판단과 저장은 사용자가 한다.
- 게시가 아니라 **검토 대기 카드**를 만든다.

하지만 이 vault에서는 Threads 글 초안이 아니라 **희곡 글감 카드**를 만든다. 핵심은 자동화가 아니라 출처에서 작동 조건을 채집한 뒤, [[wiki/writing/aesthetics/글감_판정_루브릭|가능성 진단]]으로 넘길 수 있게 구조를 보존하는 일이다. 히라타의 장소·문제·정보 차이는 강력한 렌즈지만 모든 씨앗의 필수 표면 문법은 아니다.

## 기본 기준 — 논제가 아니라 쓰고 싶은 사람·말·시간을 채집한다

피해야 할 출력:

> “이 사건은 복지 사각지대라는 주제를 다룬 희곡 소재가 될 수 있다.”

지향할 출력:

> “복지센터 대기석에 두 번호표가 있다. 한 사람은 화장실에 다녀왔을 뿐인데 화면에는 `미응답`이 떠 있다. 담당자는 다시 뽑으라고 말하고, 그는 이미 불린 번호표를 버리지 못한다.”

즉, 채집 단위는 `사회 이슈`가 아니라 다음 조건이다.

- 말·침묵·행동을 발생시키는 장소 또는 이동 경로
- 누군가의 현재 행동을 바꾸는 작동 압력
- 사람·다른 시간의 자기·관습·사물·자연·관객 사이의 대항력
- 반복·기다림·교대·누적·도약·병렬 흐름 가운데 실제 시간을 만드는 연료
- 사람·목소리·관계·침묵·행동·물질·소리·빛·매체·시간 간격 가운데 더 따라가고 싶은 것
- 출처 표면을 벗어나 독립 작품이 될 윤리적·미학적 거리

## 채집 질문 — 히라타 렌즈에서 구조 DNA까지

매 후보마다 아래를 짧게 묻는다. 답이 모든 칸에서 제도·공식 언어·미결 잔여로 수렴하면 자기복제 신호다.

1. **출처 압력** — 원문에서 실제로 누가 무엇을 하거나 견디거나 피하고 있는가?
2. **장소·경로** — 말과 행동은 어느 방·집·거리·차량·일터·자연·온라인/오프라인 경계에서 생기는가?
3. **관계 조직** — 가족, 친구, 이웃, 낯선 사람, 동료, 놀이 집단, 혼자인 몸, 비인간 존재가 어떻게 묶이는가?
4. **시간 조직** — 연속 체류, 수직 반복, 다중 흐름, 기다림과 부분 충족, 도약·생략·에피소드 상속 중 무엇이 시간을 만드는가?
5. **대항력·정보 차이** — 누가 알고/모르고/인정하지 않으며, 사람 아닌 규칙·기억·날씨·사물·관객 지식이 무엇을 막는가?
6. **행동·물질** — 손·몸·노동·놀이·의식·이동·사물·소리·빛·매체 중 상태가 실제로 달라지는 것은 무엇인가?
7. **보호 핵심** — 이 출처에서 가져오되 형식 비교 동안 잃지 말아야 할 낯선 이미지·행동·온도는 무엇인가?
8. **윤리 거리** — 실제 개인의 고통을 재연하지 않고 어떤 관계·장소·시간·물질 구조로 변형할 것인가?
9. **빠진 연료** — 지금 독립 작품이 되지 못하게 하는 행동·대항력·시간·자료는 무엇인가?
10. **자기복제 위험** — 담당자+없는 항목+화면 상태값+작은 공모+조용한 미결로 자동 번역하고 있지 않은가?

## 수집 대상

정해진 주제가 없을 때는 중요도보다 **장면성**으로 훑는다.

좋은 소스:

- 사회·생활·노동·교육·의료·복지·법원·행정·지역 기사와 공공 공지
- 집·방·부엌·욕실·옥상·작은 가게처럼 사적/반사적 공간의 생활 기록
- 가족·친구·이웃·동료·동호회·비공식 공동체의 습관, 돌봄, 오해, 교대
- 의식·놀이·축제·훈련·관람·응원·취미처럼 반복 규칙을 스스로 만드는 장면
- 자연·날씨·동식물·계절, 돌봄/수리/운반/청소/제조 같은 노동, 통근·산책·이주·여행 같은 이동
- 자동응답·앱·키오스크·번호표·출입증·알림 같은 제도/매체 마찰 — 여러 레인 중 하나이지 기본값은 아님
- 블로그/RSS/칼럼/공개 SNS 중 몸·물건·시간·관계의 구체적 마찰이 보이는 글

약한 소스:

- 큰 정치 이슈지만 무대의 방과 물건이 보이지 않는 기사
- 가해자/피해자 구도가 너무 선명해 절차의 미세한 압력이 사라지는 사건
- 논제는 강하지만 인물이 기능의 삽화로만 남는 소재
- 설명해야 이해되는 배경이 너무 많은 사건
- 실제 피해를 거의 그대로 재현해야만 성립하는 사건
- 로그인·가입·인증이 필요한 비공개 게시물. 접근을 우회하거나 보지 못한 본문을 추정하지 않는다.

## 1차 필터 — 뉴스 가치나 시험 용이성이 아니라 쓰기 충동

그날의 소스를 모은 뒤 다음 기준으로 후보를 남긴다.

| 기준 | 남기는 경우 | 버리는 경우 |
|---|---|---|
| 출처 압력 | 실제 사람·말·행동·노동·기다림·관계가 보인다 | 주제 요약만 남는다 |
| 작가 쪽 궁금함 | 다음 말·침묵·선택·시간을 조금 써보고 싶다 | 소품 시험 계획만 쉽게 떠오른다 |
| 장면 가능성 | 말·관계·행동·관점·시간·물질 중 하나가 변할 여지가 있다 | 설명을 낭독해야만 성립한다 |
| 시간의 미완 | 반복·누적·교대·도약·기억 가운데 아직 닫히지 않은 것이 있다 | 제목의 착상으로 이미 소진된다 |
| 독자성 | 기존 작품과 다른 사람·목소리·관계·온도·관점이 있다 | 익숙한 제도극·소품극 공식만 떠오른다 |
| 윤리적 거리 | 식별정보와 실제 피해를 지우고 다른 작품으로 변형할 수 있다 | 사적 고통을 그대로 빌려야 한다 |

이 표는 [[wiki/writing/aesthetics/글감_판정_루브릭|글감 판정 루브릭]]의 전 단계다. 채집 단계에서는 완성 가능성을 확정하지 않고, **무대 위에 올릴 수 있는 조건이 있는지**만 빠르게 가른다.

## 재선정과 사용자 선택 — 형식은 나중에 본다

채집 단계는 출처를 압축해 시험 명세를 만드는 단계가 아니다. 후보마다 다음만 남긴다.

- 출처 압력과 보호할 핵심
- 더 따라가고 싶은 사람·목소리·관계·시간·질문
- 기존 작업과 다른 점
- 윤리 거리와 직접 각색 위험
- `사용자 선택 대기 / 병합 재료 / 보류 / 제외`

전체를 무원칙 재독해 최대 3–4개만 사용자에게 보여준다. 사용자가 0–1개를 고르기 전에는 A/B/F, `유망★`, 자연 규모, 형식표, 구조표, 물성 시험을 만들지 않는다.

사용자가 고른 뒤에도 곧바로 형식으로 가지 않는다. 사람·말·관계가 궁금하면 2–5쪽을 먼저 쓰고, 시간 조직이 궁금하면 장면쌍을 만들고, 출처가 빈칸이면 조사한다. 물성·동선 확인은 초고가 거리·크기·무게·동시 행동·객석 가독성 질문을 만들 때만 쓴다.

## 카드 포맷

채집 결과는 짧게 유지한다. 20개를 모을 수 있지만 20개를 동일한 깊이로 개발하지 않는다.

```markdown
## [후보 N] 제목 후보

### 출처
- 제목 / 매체 / 날짜 / URL:
- 공개 접근 경계:

### 출처에서 실제로 살아 있는 것
- 사람·말·행동·관계·시간:
- 잃지 말아야 할 이미지·온도·질문:

### 희곡적 거리
- 원천 표면을 지운 뒤에도 남는 압력:
- 실제 인물·피해·고유 일화를 소비하지 않을 경계:
- 기존 글감과 다른 점 / 자기복제 위험:

### 작가 쪽 재선정
- 더 따라가고 싶은 사람·목소리·관계·시간:
- 아직 닫히지 않은 질문:
- 현재 상태: 사용자 선택 대기 / 병합 재료 / 보류 / 제외
```

선택된 한 후보에만 다음을 덧붙인다.

```markdown
## 선택 뒤 첫 탐색
- 실제 불확실성:
- 탐색: 2–5쪽 장면·독백 / 장면쌍·비트 / 추가 조사 / 물성·동선·소리 확인
- 선택 이유:
- 탐색 뒤: 더 쓰기 / 다른 장면 / 조사 / 병합 / 보류 / 형식 비교
```



`autoTHREADS`는 원래 뉴스/블로그/RSS를 Threads 초안으로 바꾸는 앱이었다. 이 vault에 흡수할 것은 앱이나 게시 기능이 아니라 다음 구조다.

| autoTHREADS | 이 vault의 글감 채집 |
|---|---|
| topic/news source | 오늘의 공개 사건·생활 마찰 풀 |
| used links | 이미 본 기사/사건 ledger |
| style samples | 히라타 + 사용자 미학 프로필 |
| draft | 글감 후보 카드 |
| queue | `wiki/_inbox/` 또는 글감 검토 대기 |
| schedule | 수동 실행 후 품질 확인, 필요 시 cron |
| post | 저장/확장/보류/폐기 판단 |

중요한 차이: 자동 게시나 자동 확정은 하지 않는다. AI는 후보를 만들고, 사용자는 **확장할 장면인지** 판단한다.

## Hermes 스킬 체크포인트

이 세션에서 Hermes 사용자 로컬 스킬 `play-seed-harvesting`을 생성했다. 스킬의 역할은 다음이다.

- 정해진 주제 없이 오늘의 뉴스/사건/공개 글/RSS/블로그를 훑는다.
- 일반 뉴스 브리핑이 아니라 출처의 사람·목소리·관계·시간·행동·이미지를 찾는다.
- 히라타 렌즈를 포함하되 사적 공간·비제도 관계·놀이·자연·노동·이동을 같은 비중으로 탐색한다.
- 작가의 끌림으로 최대 3–4개만 사용자 선택 대기에 두고, 선택 전 형식·점수·물성 시험을 만들지 않는다.
- 출처 URL과 날짜를 보존한다.
- 필요하면 Obsidian queue에 저장한다.

현재 권장 운용은 자동 cron이 아니라 **수동 실행 → 결과 품질 확인 → 카드 포맷 조정 → 필요 시 주기화**다.

## 이 노트의 위치

- [[wiki/writing/notes/히라타_오리자_연극입문_1-3장_요약과_적용|히라타 요약과 적용]] — 이론의 기준.
- [[wiki/writing/notes/히라타_오리자식_극작_체크리스트|히라타식 극작 체크리스트]] — 이미 쓰기 시작한 장면/초고를 고칠 때.
- **이 노트** — 아직 쓰기 전, 오늘의 사건에서 장면 씨앗을 채집할 때.
- [[wiki/writing/aesthetics/글감_판정_루브릭|글감 판정 루브릭]] — 작가 쪽 재선정과 사용자 선택 뒤 병목별 탐색을 고를 때. A/B/F 형식 진단은 실제로 필요해진 뒤에만 쓴다.
- [[wiki/writing/notes/글감_트리아지_지도|글감 트리아지 지도]] — 축적된 글감 전체를 배치하고 계열화할 때.

## 피해야 할 방향

1. **뉴스 요약으로 흐르기** — 중요한 사건을 설명하지 말고, 무대 위에서 바뀌는 행동·관계·물질을 찾는다.
2. **주제어로 닫기** — 복지, 노동, 혐오, 고립 같은 단어는 출발점이 아니라 너무 늦은 이름이다.
3. **피해 재현** — 실제 고통을 그대로 극화하지 말고, 장소·시간·관계·물질 구조로 변형한다.
4. **제도극 자동 번역** — 출처에 없는 담당자·접수창구·상태화면·없는 항목을 습관적으로 발명하지 않는다.
5. **잔여·미결 자동화** — 닫힌 결말·축제·놀이·큰 사건·직접 언어가 작품의 보호 핵심이면 먼저 보존한다.
6. **형식 조기 잠금** — 채집 카드에서 단막 매수·F코드·자연 규모·B2를 확정하지 않는다.
7. **시험 가능성 편향** — 소품이 눈에 보인다는 이유로 우선순위를 높이거나 채집 직후 실물 수행을 추천하지 않는다.
8. **쓰기를 너무 늦추기** — 사람·말·관계가 궁금한 후보는 짧은 쓰기가 첫 탐색일 수 있다. 모든 조건을 증명한 뒤에만 쓰게 하지 않는다.
9. **너무 많이 저장하기** — 대량 채집은 폭을 위한 풀이다. 20개 중 3–4개가 작가 쪽에서 다시 읽힐 이유를 얻으면 충분하며, 나머지를 억지로 승격하지 않는다.
