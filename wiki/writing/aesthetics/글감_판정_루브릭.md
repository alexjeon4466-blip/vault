# 글감 다음 행동 루브릭 — 숙성·개발 선택·B 이관

> 파일명은 기존 링크 호환을 위해 유지한다. 여기서 `판정`은 씨앗의 가치나 작품성을 등급화하는 일이 아니라, **지금 쉬게 둘지, 사용자에게 다시 보여줄지, B로 이관할지, 권리·윤리 때문에 멈출지** 정하는 일이다.

## 한 줄 핵심

> **점수 대신 현재 잔여·사용자 선택·실제 불확실성을 기록하고, 사용자가 지금 개발하기로 고른 씨앗만 최소 패킷과 함께 B1로 보낸다.**

---

## 0. 문서의 지위와 경계

### 이 문서가 하는 일

- 숙성된 씨앗을 다시 보여줄 이유를 말한다.
- 사용자의 현재 끌림을 확인한다.
- `resting / develop_now / source_archive / duplicate_link / blocked` 가운데 다음 상태를 고른다.
- `develop_now`인 씨앗의 최소 B 이관 패킷을 만든다.
- B1.5에서 해볼 가장 싼 첫 움직임을 **추천**한다.

### 이 문서가 하지 않는 일

- 씨앗의 희곡 가능성을 점수화하지 않는다.
- 사용자의 끌림을 AI가 추정해 대신 확정하지 않는다.
- A1–B5 ○△✕, F 프로필, `유망★`로 새 씨앗을 채점하지 않는다.
- 독백·사적 공간·시간 비약·큰 사건·직접 발화·닫힌 결말을 감점하지 않는다.
- 작품의 길이·형식·결말·극작 엔진을 잠그지 않는다.
- 쓰기·장면쌍·조사·물성 시험을 사이클 A에서 실행하지 않는다.
- `[약·물]` 약속 판정과 소유 층위를 붙이지 않는다. 희곡 평가가 아니므로 파이프라인 §0.7의 필수 표기 대상이 아니다.
- B4 착수 게이트나 C2 연결 초고 판정을 대신하지 않는다.

### 문서 간 인계

```text
채집·숙성
  → 이 문서: 사용자 개발 선택 + 최소 이관 패킷
    → 파이프라인 B1: 보호와 현재 중심 가설
      → 파이프라인 B1.5: 실제 첫 탐색
```

전체 원고가 이미 있으면 이 문서를 소급 적용하지 않는다. 파이프라인 C2 역산으로 바로 간다.

## 1. 점수 없는 근거 포맷

씨앗 하나를 판단할 때 다음 다섯 칸이면 충분하다.

```yaml
question:
current_residue:
user_pull:
unknown:
cheapest_next_move:
not_needed:
```

| 칸 | 뜻 |
|---|---|
| `question` | 지금 결정해야 할 한 가지 |
| `current_residue` | 원자료와 재접촉 기록에 실제로 남아 있는 말·이미지·감각 |
| `user_pull` | 가능하면 사용자의 표현 그대로 기록한 현재 끌림 |
| `unknown` | 설명하거나 확정하지 않은 채 탐색할 것 |
| `cheapest_next_move` | B1.5에서 할 수 있는 가역적 첫 움직임 |
| `not_needed` | 아직 정하지 않을 주제·형식·길이·결말·인물 수 등 |

합산, 순위, 통과 축 개수, 별점은 만들지 않는다.

---

## 2. 재접촉 후보를 고르는 법

협업자는 `상위 후보`를 뽑지 않는다. 한 번에 비교할 수 있는 소수의 카드를 서로 다른 이유로 제시한다.

| 제시 이유 | 확인할 것 |
|---|---|
| 기억 잔여 | 출처를 안 보고도 말·이미지·소리가 남았는가 |
| 변형 | 기억 속에서 원자료와 다른 방향으로 자랐는가 |
| 온도 차이 | 현재 작품군과 다른 관계·리듬·정서·형식을 여는가 |
| 현재 접점 | 지금의 생활·독서·관람·작업과 새로 만나는가 |
| 와일드카드 | 설명은 약하지만 이상하게 다시 보게 되는가 |

이 이유들은 작품성 점수가 아니다. 사용자는 아무것도 고르지 않거나, 하나 또는 여러 씨앗에 주의를 배정할 수 있다.

### 금지되는 대리 문장

- “작가가 이 소재를 가장 쓰고 싶어 한다.”
- “전용수 문법과 가장 잘 맞으므로 유망하다.”
- “A/B 축을 모두 통과하므로 개발 가치가 높다.”

대신 다음처럼 말한다.

- “지난 기록 없이도 이 소리의 중단이 다시 떠올랐습니다.”
- “최근 작품들과 달리 제도보다 가족의 놀이 규칙이 중심입니다.”
- “현재 끌림은 제가 판단할 수 없으니, 지금 한 번 써보고 싶은지 선택이 필요합니다.”

## 3. 다음 상태 라우터

> `seed_status` enum과 허용 전이의 단일 진실원은 [[wiki/writing/aesthetics/히라타식_글감_채집_사이클#1. 상태 계약|채집 사이클 §1]]이다. 아래는 사용자 선택 구간의 부분집합이며 값을 신설하지 않는다.

| 관찰 | `seed_status` | 다음 행동 |
|---|---|---|
| 아직 설명보다 잔여가 중요하고 지금 개발 충동은 없음 | `resting` | 원본을 고치지 않고 둔다 |
| 재접촉할 이유가 있어 사용자에게 보여줌 | `resurfaced` | 현재 끌림 확인 |
| 사용자가 지금 개발하기로 선택 | `develop_now` | 최소 B 이관 패킷 |
| 지금은 끌림이 없고 재접촉 계획도 없음 | `source_archive` | 검색 가능하게 보관 |
| 기존 씨앗과 실질적으로 같음 | `duplicate_link` | 진본 씨앗에 링크 |
| 권리·사생활·윤리 경계가 미해결 | `blocked` | 허락·자료 확인·출처 방식 변경 |

### 정상적인 0개 종료

재접촉 후보가 모두 `resting` 또는 `source_archive`로 돌아가도 사이클은 성공적으로 끝난다. 후보 수를 채우기 위해 작품을 발명하지 않는다.

### `병합 재료` 대신 공명 링크

씨앗 단계에서는 독립 가능성을 판정해 기존 작품에 흡수하지 않는다.

```yaml
resonance_link:
  target_seed_or_work:
  shared_residue:
  crucial_difference:
  no_merge_decision: true
```

실제 원고가 두 씨앗의 결합을 필요로 할 때만 파이프라인 B1의 운반체·부품 판단을 연다.

## 4. 사용자 선택 확인

다음 질문 하나로 시작한다.

> 이 씨앗에 지금 한 번의 쓰기·조사·형식 실험을 배정하고 싶은가?

`예`라면 작품에 대해 다음을 미리 약속한 것이 아니다.

- 끝까지 완성한다.
- 독립 단막으로 만든다.
- 기존 작품과 병합하지 않는다.
- 특정 공모에 낸다.
- 지금 떠오른 형식·결말을 유지한다.

선택은 현재 주의의 배정이다. B1.5 뒤 다시 숙성으로 돌려보낼 수 있다.

## 5. 실제 불확실성 → 첫 움직임 추천

아래 표는 B1.5의 실행을 대신하지 않는다. 이관 패킷에 `suggested_first_free_move`를 적기 위한 추천표다.

| 실제 불확실성 | 추천할 첫 움직임 | B1.5에서 볼 것 |
|---|---|---|
| 사람·목소리·관계 | 2–5쪽 장면·독백 | 다음 말·침묵을 더 보고 싶은가 |
| 사건의 여파·정서 | 대표 장면 하나 | 사건 설명 없이 삶의 흔들림이 보이는가 |
| 시간·인과·장면 연결 | 장면쌍·비트 스케치 | 앞 단위가 다음 조건을 만드는가 |
| 이미지·지속·리듬 | 짧은 행동·소리·빛 스코어 | 반복·정체가 관객 지각을 바꾸는가 |
| 사실·출처·윤리 | 제한된 추가 조사 | 원천 표면을 소비하지 않고 독립 가능한가 |
| 공간·거리·물성 | 안전한 모형·동선·소리 확인 | 텍스트만으로 알 수 없는 구체 질문이 있는가 |
| 형식 경합 | 서로 다른 짧은 샘플 | 보호 핵심과 손실이 실제로 달라지는가 |

사람과 말이 병목이면 글쓰기가 가장 싼 탐색일 수 있다. 소품이 보인다는 이유만으로 물성 시험을 우선하지 않는다.

## 6. A→B 최소 이관 게이트

다음 패킷을 기록하면 B1로 갈 수 있다. 이 절이 A→B 이관 스키마의 단일 진실원이다.

```yaml
seed_id:
user_authorization:
protected_residue:
user_pull:
unknown_to_preserve:
rights_safety_status: clear | resolved
unresolved_blockers: none
resolved_or_managed_boundaries: []
suggested_first_free_move:
return_to_resting_allowed: true
not_precommitted:
  - theme
  - length
  - form
  - ending
  - legacy_seed_codes
  - F1-F5
```

### 이관 조건

1. 사용자가 지금 개발할 씨앗을 명시적으로 선택했다.
2. 설명보다 먼저 보호할 잔여가 있다.
3. 아직 모르는 채로 둘 것이 있다.
4. 미해결 권리·사생활·안전 차단 요인이 0건이다.
5. 첫 움직임이 가역적이다.

다음은 이관 선결 조건이 아니다.

- 완성된 주제
- 갈등·욕망·대항력의 확정
- 길이와 F코드
- 작품의 결말
- 독립 완결 증명
- 기존 작품과의 차별성 증명
- `legacy_seed.values.A1–B5` 점수

최초 이관 시 아래 최소 작업 원장을 만들고 `seed_status`를 `transferred`로 바꾼다.

```yaml
work_id:
activity: active
canonical_branch: null
working_branch: main
latest_locked_version: null
next_lock_number: 1
workflow_phase: 설계
revision_mode: 신규집필
depth: 경량 | 표준 | 심화
module_depth: {}
current_revision: null
branches:
  main:
    workflow_phase: 설계
    revision_mode: 신규집필
    depth: 경량 | 표준 | 심화
    module_depth: {}
    parent_branch: null
    base_revision: "seed:<seed_id>"
    current_revision: null
    latest_locked_version: null
    contract_delta: null
    status: candidate
```

`workflow_phase / revision_mode / depth / module_depth / current_revision` 최상단 값은 `branches.main`의 미러다. 첫 canonical은 C4의 사용자 승인 `lock_and_promote`에서만 생긴다.

`blocked` 상태는 B 이관 대상이 아니다. 차단 해제를 위한 좁은 사실·권리 확인만 사이클 A에서 수행하고 `rights_safety_status: clear | resolved`가 된 뒤 이관한다.

## 7. B1.5 뒤의 환류

첫 탐색이 살아나지 않아도 씨앗의 실패나 제외로 기록하지 않는다.

```yaml
exploration_ref:
observed:
surprise:
decision: continue_B | another_B1_5_test | return_to_resting | source_archive | blocked
reopen_when:
```

- `continue_B`: 현재 중심 가설을 갱신하고 B2로 간다.
- `another_B1_5_test`: 서로 독립된 불확실성이 하나 더 있을 때만.
- `return_to_resting`: 작업 원장은 `activity: paused`, 씨앗은 `resting`; work_id와 탐색 이력은 보존.
- `source_archive`: 당분간 재개 조건이 없음. 이미 work_id가 있으면 원장의 phase는 유지하고 `activity: archived`와 사유를 기록.
- `blocked`: 탐색 중 새 권리·윤리·안전 문제가 드러남. 이미 work_id가 있으면 `activity: paused`, 차단 요인과 해제 조건을 기록.

`제목의 아이디어만 반복됨`, `모든 문장이 최초 이미지를 해설함` 같은 관찰은 귀중한 증거지만 영구 폐기 판정은 아니다.

### 이미 이관된 씨앗의 재선택

`return_to_resting`으로 돌아온 씨앗에는 `last_work_id`와 탐색 이력이 남는다. 사용자가 다시 개발하기로 고르면 새 work_id를 만들지 않는다.

- 기존 작업 원장의 `activity: paused/archived → active`
- 기존 working branch와 current revision 확인
- 미잠금 상태면 반증된 가설의 층에 따라 B1·B2·C1로 재진입
- 잠긴 판본을 다시 쓰면 그 기준 branch가 canonical이든 `lock_only`된 candidate든 잠금 상태로 보존하고 새 child candidate branch 생성

새 씨앗처럼 이관 패킷을 복제하지 않고, 재접촉 뒤 달라진 끌림·질문·권리 경계만 append-only로 덧붙인다.

`source_archive`나 `blocked`에서 다시 개발할 때도 같은 work_id를 재사용한다. 중복 씨앗으로 판명되더라도 이미 생긴 revision·증거 이력은 합치거나 삭제하지 않고 `duplicate_link`로 연결한다.

## 8. 출처·윤리 라우터

| 현재 경계 | 다음 행동 |
|---|---|
| 자기 경험이며 타인 식별 위험 없음 | B 이관 가능 |
| 공개 사실이나 실존 피해 식별 가능 | 허구화·다큐·비평 중 출처 방식 먼저 선택 |
| 사적 발화·초상·고유 일화 | 동의·비식별화·미사용 가운데 선택 |
| 저작물의 고유 플롯·대표 장면 의존 | 각색 권리 확인 또는 더 먼 변형 |
| 사실관계 미확인 | 제한 조사 뒤 재판정 |
| 안전·권리·사생활 위험을 현재 해소할 수 없음 | `blocked` |

`동시대화`, `허구화`, `비유화`를 모두 해야 통과하는 것은 아니다. 선택한 출처 방식 안에서 독립성과 권리를 확인한다.

여기서 제한 조사는 차단 여부를 확인하기 위한 읽기 전용 경계 조사다. `blocked`인 동안 창작 확장·사적 자료 공유·B1.5 우회는 하지 않는다.

## 9. 레거시 A1–B5·유망★ 호환

2026-07-25 이전의 `_scored` 파일과 트리아지 지도는 역사적 스냅샷으로 보존한다. 새 씨앗에는 같은 인터페이스를 생성하지 않는다.

### 네임스페이스

옛 코드를 읽거나 이관할 때 다음처럼 표기한다.

```yaml
assessment_mode: unscored_v2
legacy_seed:
  status: not_migrated
  source_snapshot:
  values: {}
legacy_label:
```

기존 값이 실제로 있는 파일을 읽을 때만 아래처럼 보존한다.

```yaml
legacy_seed:
  status: preserved
  source_snapshot:
  values:  # 기존 A1–B5 값을 변경 없이 이관
legacy_label:
```

- `legacy_seed.values.B1–B5`는 파이프라인 단계 `B1–B4`와 전혀 다른 값이다.
- `legacy_seed.status: not_migrated`는 ✕가 아니며 새 채점을 요구하지 않는다.
- `유망 / 유망★`는 `legacy_label`에만 남긴다.
- 기존 약 970건을 일괄 재채점하지 않는다.
- 기존 글감이 다시 떠오르면 과거 점수를 고치지 않고 새 재접촉·사용자 선택 기록만 붙인다.

### 옛 축의 읽기 전용 뜻

| 레거시 코드 | 과거에 보던 것 | 현재 대체 경로 |
|---|---|---|
| `legacy_seed.values.A1` | 사람·몸의 진폭 | B1.5 사람·수행 탐색 |
| `legacy_seed.values.A2` | 개념을 초과하는 행동 | 보호할 잔여 + 실제 장면 |
| `legacy_seed.values.A3` | 관찰 충동·윤리 거리 | 사용자 선택 + 출처·윤리 라우터 |
| `legacy_seed.values.B1` | 무대 조건·시간 조직 | 파이프라인 B2 + 길이 원리 |
| `legacy_seed.values.B2` | 작동 압력 | 선택 엔진의 진행 가설 |
| `legacy_seed.values.B3` | 시간 연료 | 자연 규모·F 모듈 |
| `legacy_seed.values.B4` | 차이·대항력 | 관계·언어·절차 엔진별 필요 질문 |
| `legacy_seed.values.B5` | 몸·사물·매체 경로 | B1.5 또는 C3 실연 병목 |

옛 ○△✕를 합산하거나 새 판정의 근거로 쓰지 않는다.

## 10. F1–F5 호환 규칙

F 정의의 단일 진실원은 [[wiki/writing/aesthetics/희곡_길이별_설계_원리#2. F1–F5 — 시간 조직 어포던스 (단일 진실원)|희곡 길이·시간 조직 설계 원리 §2]]다. 이 문서에서 재정의하지 않는다. F4와 F5를 가르는 판정선(**시간 점프가 아니라 편의 독립 공연 가능성**)은 그 문서 §2.4에 있다.

이 문서가 가진 권한은 하나뿐이다.

> **사용자 선택 전에는 F코드를 만들지 않는다.**

B1.5 뒤 자연 규모나 시간 조직이 실제 병목일 때만 길이 원리로 간다. 씨앗 단계에서 F를 붙이는 것은 형식을 조기에 잠그는 일이며, 6절의 `not_precommitted`가 이를 막는다.

### 10.1 F 코드 레거시 이관 (2026-08-17 신설)

2026-08-17에 F4/F5 판정선이 **독립 공연 가능성**으로 확정됐다(길이 원리 §2.4). 그 이전 판의 F5 정의는 `시간 점프·몽타주·세대·에피소드 간 상속이 핵심인가`였다 — **판정 기준이 정반대로 바뀌었다.** 구 정의로 붙은 배정이 `maps/`·`decisions/`·`structures/`에 남아 있다.

9절의 A1–B5 레거시와 같은 원칙으로 처리한다.

```yaml
legacy_form_code:
  status: not_migrated | preserved | reassessed
  source_snapshot:
  values: {}          # 구 F 배정을 변경 없이 이관
```

- **구 F 배정을 일괄 재판정하지 않는다.** 과거 지도·결정 노트의 값은 역사적 스냅샷으로 보존한다.
- **그러나 그 값을 읽고 새 작업을 열 때는 재판정한다.** 특히 `F5`가 붙은 항목은 §2.4의 판정선으로 다시 본다 — 시간 점프만으로 F5인 것은 **더 이상 F5가 아니다.**
- 재판정 없이 구 `F5` 표기를 근거로 연작 공통표를 만들지 않는다. 이것이 이 조항이 막으려는 실제 사고다.
- `structures/` 구조표처럼 편별 독립 완결을 이미 요구하고 있는 문서는 새 판정선에 부합하므로 손대지 않는다. **전부 오배정은 아니다.**
- 재판정 결과가 달라지면 원본을 고치지 말고 `reassessed`로 표시한 뒤 새 판정과 근거를 append-only로 붙인다.

## 11. 예외 보호

다음은 `resting`, `source_archive`, `blocked`의 단독 사유가 아니다.

- 짧음, 한 문장, 한 이미지
- 독백·1인극·무언
- 사적 방·빈 공간
- 낯선 외부자 없음
- 직접적인 감정 문장
- 큰 사건과 돌이킬 수 없는 선택
- 시간 비약·몽타주
- 이름 있는 인물·두꺼운 전기
- 닫힌 결말·명시적 실패·단절
- 기존 전용수 작품군과 다른 문법

자기복제 우려도 씨앗을 감점하는 근거가 아니다. 실제 B1.5 원고가 익숙한 해결법을 택했을 때 진단한다.

## 12. 짧은 사례

### 이미지·감각 씨앗

```yaml
current_residue: 엘리베이터가 설 때마다 보이지 않는 청소기 소리가 멎는다
user_pull: 아직 미확인
unknown: 사람이 있는지, 무엇을 피하는지
cheapest_next_move: 대사 없는 짧은 소리·행동 스코어
not_needed: [인물 수, 갈등, 길이, 결말]
```

현재 갈등·대항력·독립 완결이 없어도 정상 씨앗이다. 사용자가 선택하면 B1.5에서 스코어를 쓴다.

### 익숙한 기록 언어 씨앗

> “그 사람 이름은 빼도 돼요. 그런데 쉼표는 남겨주세요.”

- 씨앗에서는 문장의 리듬과 쉼표에 대한 집착만 보존한다.
- `전용수 계열과 닮음`을 감점하지 않는다.
- 사용자가 목소리를 따라가고 싶다면 B로 이관한다.
- B1.5 원고가 다시 창구·화면·빈칸으로 자동 번역될 때만 자기복제 렌즈를 연다.

### 완성 원고 「저는,」

이미 전체 원고가 있으므로 이 루브릭 대상이 아니다.

> C2 역산 → `revision_mode: 퇴고` → 필요한 미디어·발화 병목만 C3에서 진단

하루의 시간 점프는 작품 내부 몽타주인 F4이며, 각 장이 독립 완결하는 F5 연작이 아니다.
