# 희곡 길이별 설계 원리 — 한 글감에서 복수 형식 후보 만들기

> 이 문서는 글감 하나에서 **서로 다른 시간 조직을 가진 형식 후보 2–3개를 만들고 비교하는 단일 교리원**이다. 길이를 먼저 정해 장면 수와 매수를 배당하는 계산표가 아니다.

## 0. 문서의 지위와 비목표

### 이 문서가 하는 일

- 글감의 구조 DNA를 읽는다.
- 최소형·단막형·장막형·연작형 가능성을 복수로 생성한다.
- 후보마다 시간을 만드는 연료와 후속 비용을 구분한다.
- 작품의 자연 규모와 외부 제출 규격을 분리한다.
- 사용자가 형식을 선택할 수 있는 비교표를 만든다.

### 다른 문서와의 경계

1. **작품 고유성 보호** — [[wiki/writing/aesthetics/전용수x히라타_통합_극작노트|전용수 × 히라타 통합 극작 노트]]
2. **초기 가능성 진단** — [[wiki/writing/aesthetics/글감_판정_루브릭|글감 판정 루브릭]]
3. **형식 후보 생성·비교** — 이 문서
4. **선택 형식의 B2 설계와 집필·개작** — [[wiki/writing/aesthetics/집필_파이프라인|집필 파이프라인]]

이 문서는 다음을 하지 않는다.

- 모든 글감을 30–40분 단막 또는 장막으로 키우지 않는다.
- 한 장소·연속 시간·반공간을 보편 조건으로 삼지 않는다.
- 직접 고백·큰 사건·심리적 인물·시간 비약·다장면·닫힌 결말을 자동 결함으로 판정하지 않는다.
- 원고지 매수와 실연 시간을 고정 환산하지 않는다.
- 공모 규격을 작품의 자연 길이로 위장하지 않는다.
- 이미 작동하는 짧은 형식을 `덜 자란 작품`으로 취급하지 않는다.

## 1. 근거 등급

이 문서는 서로 다른 성격의 근거를 한 문장 안에서 섞지 않는다.

| 표기 | 근거 | 사용 방식 |
|---|---|---|
| **[P] 외부 1차** | 공식 공모 규정, 극단 공연 기록, 작가 강연, 희곡 텍스트 | 사실 범위를 넘지 않는다. 규정은 해당 연도·기관에만 적용한다. |
| **[T] 극작론·신뢰할 2차** | Smiley, Downs & Russin, 공연·학술 분석 | 하나의 계보 또는 진단 도구로 쓴다. 보편 정답으로 만들지 않는다. |
| **[S] 종합 해석** | 여러 외부 계보를 이 문서가 재배열한 분류 | `수평·수직·종축·불연속`처럼 이 문서가 만든 도구임을 밝힌다. |
| **[C] 내부 작품군 가설** | 전용수 작품군과 현재 vault의 성립·실패 사례 | 작가 프로필과 자기복제 위험을 읽는 가설로 쓴다. |
| **[H] 실전 휴리스틱** | 후보 수, 비교표, 장막 연료 질문, 작업 순서 | 초고·낭독 결과에 따라 버리거나 고친다. |
| **[?] 미확인** | 직접 원문·공식 환산·표기 규약이 확보되지 않은 주장 | 설계 법칙으로 승격하지 않는다. |

> **근거가 강하다는 것과 모든 작품에 적용된다는 것은 다르다.** 공식 상연 시간은 사실이지만 그 작품의 조직 원리가 다른 모든 희곡의 의무 구조가 되지는 않는다.

## 2. 형식 선택 전에 보호할 것

형식 후보를 만들기 전에 원칙 없이 글감·초고를 한 번 읽고 다음을 적는다.

| 보호 항목 | 질문 |
|---|---|
| 작품의 약속 | 관객에게 어떤 종류의 시간과 주의를 요구하는가? |
| 가장 강한 이미지·행동 | 설명 없이도 남는 몸·사물·소리·공간 변화는 무엇인가? |
| 온도·리듬 | 건조함, 희극, 침묵, 범람, 속도, 비약 중 무엇이 호흡을 만드는가? |
| 장면 생성 원리 | 다음 장면이 이전 장면과 달라지는 고유 규칙은 무엇인가? |
| 명확해야 할 물리 | 누가 무엇을 하고, 무엇이 막으며, 실패하면 무엇이 달라지는가? |
| 아직 열어둘 의미 | 전사·동기·윤리·관계 이름 중 늦게 또는 끝까지 유보할 것은 무엇인가? |

형식 후보는 이 성취를 다른 그릇에 옮겨 보는 실험이다. 후보가 원형의 가장 강한 행동을 지우고 설명만 늘리면 길어졌어도 탈락이다.

### 예외 보호

다음 요소는 실제 행동·정보·권한·관계·위험·대가를 바꿀 때 보호한다.

- 직접적인 감정 발화
- 시간 점프와 역사적 간격
- 장면 전환과 몽타주
- 큰 사건과 돌이킬 수 없는 선택
- 심리와 전기가 두꺼운 인물
- 이름을 가진 인물
- 명시적 해결·실패·단절

작가의 반복 문법은 기본 가설이다. `전용수답지 않다`는 이유만으로 후보를 버리지 않는다.

## 3. 글감의 구조 DNA

길이는 소재의 크기가 아니라 **무대에서 시간을 계속 생산할 수 있는 관계와 행동의 조직**에서 나온다. 먼저 다음 카드를 채운다.

| DNA 항목 | 기록할 것 |
|---|---|
| 압력 | 지금 누구·무엇이 무엇을 요구하거나 막는가 |
| 시간 | 연속 체류, 반복 주기, 마감, 계절·연대 간격, 기다림 중 무엇이 핵심인가 |
| 장소 | 한 공간의 규칙, 이동 경로, 다중 공간의 대비, 장소 자체의 변화 |
| 인물망 | 1인, 대면 관계, 군상, 세대·가문, 부재자·비인간 행위자 |
| 정보·권한 | 누가 알고·기록하고·판정하고·거부하며, 그 소유가 어떻게 바뀌는가 |
| 오브제·노동 | 만지고 옮기고 입력하고 기다리고 반복할 실제 행동 |
| 반복 | 무엇이 돌아오며 주체·기능·비용·위험·물성 중 무엇이 달라지는가 |
| 대기 중인 질문 | 관객이 무엇을 기다리고, 어떤 부분 성취가 다음 기다림을 만드는가 |
| 독립 연료 | 원형과 다른 두 번째 관계·압력·시간축이 실제로 있는가 |
| 빠진 연료 | 더 긴 형식에 필요하지만 아직 출처·장면·인과가 없는 것은 무엇인가 |

### DNA 판정 원칙

- **장소는 형식을 단독 결정하지 않는다.** 같은 로비가 10분극·군상 장막·시대별 연작이 될 수 있다.
- **인물 수는 길이를 단독 결정하지 않는다.** 1인극도 반복·기억·매체·행동의 층위로 긴 시간을 만들 수 있다.
- **사건 크기는 길이를 단독 결정하지 않는다.** 큰 사건 하나는 짧게 끝날 수 있고, 작은 노동은 변주가 있으면 오래 지속될 수 있다.
- **독립 연료가 없으면 장막 가설을 보류한다.** 같은 모순의 예시만 늘어나는 것은 연료가 아니다.

## 4. 네 확장 방향

네 방향은 장르나 길이 등급이 아니라 **시간을 생산하는 방식**이다. 한 작품이 둘 이상을 결합할 수 있다. **[S]**

### 4.1 수평 확장 — 같은 시간과 공간의 관계망을 넓힌다

시간을 만드는 연료:

- 인물의 들고남과 대화 조합 변화
- 전경·배경의 교대
- 복수 흐름의 동시 진행과 간섭
- 같은 물건이 다른 사람 손으로 이동하는 과정
- 사건 사이의 대기·정리·스침·잡담

히라타의 『東京ノート』가 보여 주는 단일 세트·군상 회화·동시다발 대화는 강한 실례다. 공식 공연 기록상 약 105분이지만, 그 길이는 `한 장소` 자체가 아니라 다수 관계와 주의의 교대에서 나온다. **[P/T]**

기존 호환 명칭:

- `① 연속 확장형` — 수평 확장에 체류·대기·들고남을 강조한 전술
- `③ 다중 맞물림형` — 수평 확장에 동시 흐름·교차·주의 배분을 강조한 전술

두 명칭은 유효하지만 표준 정답이 아니다. 수평 확장의 하위 선택지로만 사용한다.

### 4.2 수직 확장 — 같은 행동이 다른 상태로 돌아온다

시간을 만드는 연료:

- 같은 질문·사물·노동·침묵의 반복
- 반복할 때마다 바뀌는 주체·권한·위험·대가
- 몸·공간·오브제의 점진적 축소·손상·이동
- 같은 문장의 억양·상대·맥락 변화
- 기다림 자체가 인물의 선택을 바꾸는 과정

베케트의 『고도를 기다리며』 2막 근사 반복, 『크라프의 마지막 테이프』의 재생과 침묵, 포세의 반복 문장과 pause는 수직 변주의 서로 다른 계보다. **[P/T]**

수직 확장은 사건을 추가하지 않아도 되지만, **기능과 비용이 같은 반복**은 축적이 아니라 중복이다.

### 4.3 종축 확장 — 기다림과 부분 성취가 다음 조건을 낳는다

시간을 만드는 연료:

- 암시 → 대기 → 예상과 조금 다른 부분 성취
- 한 선택이 뒤 장면의 비용·제약·새 질문을 만드는 인과
- 여러 기다림이 서로 다른 시점에 열리고 닫히는 구조
- 국면·act의 종속 위기가 상위 행동을 바꾸는 과정
- 독립된 관계 흐름이 후반에 실제 결과를 교환하는 구조

Smiley의 `hint–wait–fulfillment`는 이 계열을 진단하는 한 도구다. 반복될수록 서스펜스가 누적될 수 있다는 설명은 인과적 장막에 특히 유용하다. 그러나 모든 장막이 이 패턴이나 단일 클라이맥스를 따라야 하는 것은 아니다. **[T]**

`큰 사건`도 종축 연료가 될 수 있다. 다만 사건이 원형의 질문을 바꾸고 이후 장면에 비용을 남겨야 하며, 매수를 늘리기 위해 별도 해결극을 붙이는 방식이면 탈락이다.

### 4.4 불연속 확장 — 독립 단위들이 간격을 사이에 두고 축적된다

시간을 만드는 연료:

- 해·세대·정권·계절·생애 국면의 간격
- 같은 가문·장소·사물·문구의 역사적 변주
- 각 편 또는 각 장면이 독립 행동을 가지면서 전체가 상위 의미를 만드는 구조
- 몽타주와 생략이 관객에게 간격을 조립하게 하는 방식

히라타의 『서울시민』 5부작은 같은 가문과 식민지 시기의 시간적 축적을 독립 작품들로 조직한 실례다. 공식 기록상 각 편이 약 90–120분이지만, 이것은 연작 일반의 최소 길이가 아니라 그 연작의 규모다. **[P/T]**

시간 비약·다장면·다른 장소는 실패의 표지가 아니다. 간격 자체가 관계·권한·기억을 바꾸고 각 단위가 독립 행동을 가지면 정당한 형식 연료다.

### 방향 조합 예

| 조합 | 가능한 형식 |
|---|---|
| 수평 + 수직 | 한 장소 단막, 군상극, 저사건 장막 |
| 수직 + 종축 | 반복 의식극, 1인극, 인과적 장막 |
| 수평 + 종축 | 다중 관계가 서로 결과를 주고받는 군상 장막 |
| 수직 + 불연속 | 같은 행동의 세대·연대별 변주, 에피소드 연작 |
| 종축 + 불연속 | 시간 점프가 부분 성취와 새 비용을 보여 주는 다장면극 |

## 5. 길이별 자연 규모

다음 표는 설계 출발점이지 할당량이 아니다. **[S/H]**

| 자연 규모 | 충분한 경우 | 부족 신호 | 유효한 조직 예 |
|---|---|---|---|
| 최소형·초단막, 흔히 약 10–15분 | 하나의 압력과 한 번의 상태 변화만으로 핵심 약속이 완결됨 | 같은 기능을 가진 장면을 덧붙여야만 길어짐 | 단일 순간, 1회 절차, 3회 이내의 기능 변주, 한 결정 |
| 단막, 흔히 약 20–50분 | 하나의 상위 행동 안에서 관계·정보·물성의 여러 국면이 필요함 | 중반이 같은 모순의 예시만 바꿈 | 연속 체류, 수직 반복, 다중 흐름, 제한된 다장면·몽타주 |
| 장막, 흔히 60분 이상 | 압축하면 사라지는 독립 관계·대기·결정·국면이 둘 이상 있고 서로 결과를 남김 | 단막의 결말 뒤 별도 해결이나 새 주제를 붙임 | 군상 축적, 인과적 종축, 반복 장막, 다막·무휴게 연속 모두 가능 |
| 연작·사이클 | 각 편이 독립 행동과 상태 변화를 가지며 편간 간격이 상위 의미를 만듦 | 한 이야기를 임의로 잘라 각 편이 홀로 서지 못함 | 가문·장소·사물·역사적 문구의 장기 변주 |

### 길이보다 먼저 묻는 질문

1. 핵심 압력이 처음과 다른 조건을 만들기까지 몇 번의 **질적으로 다른 변화**가 필요한가?
2. 각 변화가 새 행동을 만들며 뒤 장면에 비용을 남기는가?
3. 삭제하면 작품의 약속이 무너지는 독립 관계·시간축이 몇 개인가?
4. 침묵·노동·이동·겹대사가 실제로 얼마나 걸리는가?
5. 더 짧은 형식이 오히려 더 정확하지 않은가?

### 장막 가설을 열 수 있는 연료

다음은 고정 개수가 아니라 장막 가능성을 묻는 진단 항목이다. **[H]**

- 서로 압축되지 않는 관계 또는 압력 흐름이 둘 이상 진화한다.
- 하나의 부분 성취가 다른 흐름의 조건을 실제로 바꾼다.
- 돌이킬 수 없는 결정 뒤에 처리해야 할 결과가 남는다.
- 국면 전환 뒤 장소·규칙·권한·관객 정보 중 하나가 질적으로 달라진다.
- 긴 시간이 있어야만 보이는 누적·침식·학습·망각이 있다.

위 연료가 없으면 `장막 불가`가 아니라 **현재 자료로는 장막 가설 보류**라고 기록한다.

### 1인극과 짧은 장면의 예외

1인극은 비인간 상대, 녹음, 자기검열, 사물 노동, 반복되는 질문, 다른 시간의 자기 자신을 통해 어느 규모로도 갈 수 있다. 반대로 인물이 많아도 모두 같은 기능이면 짧은 극이다.

## 6. 작품의 자연 규모와 외부 규격 분리

### 외부 규격은 제출 제약이다

2026-07 심화 리서치 시점의 한국 신춘문예·협회·대학문학상 사례에는 200자 원고지 80–100매 안팎의 단막 요구가 많았다. 이는 **해당 공모의 선발 규칙**이지 희곡의 보편 적정 길이가 아니다. **[P]**

- 제출 전에는 반드시 그해 공식 요강을 다시 확인한다.
- `내외`, `안팎`, 상한, 시놉시스 포함 여부를 기관별로 구분한다.
- 규격과 자연 규모가 다르면 작품을 패딩하지 않는다.
- 더 짧은 공모, 낭독, 공연, 연작 편입, 장막 공모 등 다른 출구를 비교한다.

### 매수와 실연 시간은 별도 기록한다

원고지 매수와 실연 분의 공식 환산표는 확인되지 않았다. **[?]**

| 실연 시간을 늘리는 요소 | 지면과의 관계 |
|---|---|
| 침묵, 정리 노동, 이동, 기다림, 빛 변화 | 지면보다 실연이 길어질 수 있음 |
| 동시 대사와 복수 흐름 | 지면보다 실연이 짧아질 수 있음 |
| 빠른 공식 문답, 목록, 반복 구호 | 배우 속도와 호흡에 따라 크게 달라짐 |
| 관객 참여·가변 동선·기술 대기 | 리허설 전 추정 오차가 큼 |

초고 뒤에 낭독·스톱워치·동선 시험으로 측정한다. 매수는 제출 규격, 시간은 공연 경험의 지표로 따로 관리한다.

## 10. 장막과 연작 판별

> **판별 기준은 장소 수가 아니라 의존성과 독립 완결성이다.**

### 장막에 가까움

- 앞 국면의 선택이 뒤 국면을 필연적으로 제한한다.
- 하위 관계들이 같은 상위 행동의 결과를 교환한다.
- 중간 단위를 떼면 전체 인과·축적이 무너진다.
- 긴 시간이 있어야만 관계의 학습·침식·누적이 보인다.

### 연작에 가까움

- 각 편이 별도 공연·독해가 가능한 행동과 상태 변화를 가진다.
- 편간 시간·세대·장소 간격 자체가 의미를 만든다.
- 인물·가문·사물·문구·제도가 다음 편에서 다른 기능으로 상속된다.
- 한 편을 빼도 다른 편은 서지만 전체 축적의 모양이 달라진다.

### 아직 결정하지 못할 때

- 장막 1국면과 연작 1편을 각각 짧은 장면으로 시험한다.
- 어느 쪽이 설명 없이 더 많은 새 행동을 만드는지 본다.
- 둘 다 약하면 원형의 짧은 자연 규모를 유지한다.

## 11. 자기복제 방지

다음 결합은 전용수 작품군에서 강하게 작동했지만 자동 공식이 될 수 있다. **[C]**

> 규정 집행자 + 분류되지 않는 사람 + 없는 항목 + 실무자의 작은 공모 + 사물의 잔여 + 조용한 미결

형식 후보마다 묻는다.

- 제도·화면·서류 없이도 같은 압력을 무대화할 수 있는가?
- 규정하는 사람과 규정받는 사람을 한 인물 안에 둘 수 있는가?
- 부재자를 실제로 등장시키면 무엇이 달라지는가?
- 작은 공모 없이 실패·단절·이탈·선택으로 끝낼 수 있는가?
- 모든 사물이 주제를 운반하지 않고 생활 잡음과 우발성을 가질 수 있는가?
- 역할명이 아닌 이름·세대·계급·지역·욕망이 장면을 바꿀 수 있는가?
- 기존 작품과 다른 장면 생성 원리가 한 문장으로 말해지는가?

자기복제 위험이 있다고 후보를 자동 기각하지 않는다. 위험을 알고도 원형에 필연적이면 선택할 수 있다.

## 12. 실연 검증과 최종 길이 조정

### 충분히 쓴 뒤 잰다

1. 선택 형식의 필요한 물질·관계·정보 변화를 충분히 쓴다.
2. 연결본을 만든다.
3. 낭독으로 발화 시간을 잰다.
4. 침묵·노동·이동·전환을 실제로 수행해 별도 시간을 잰다.
5. 동시 대사는 겹친 실연 시간으로 다시 계산한다.
6. 자연 규모와 제출 규격의 차이를 확인한다.
7. `압축 / 확장 / 분할 / 다른 제출처 / 현재 길이 유지` 중 하나를 고른다.

### 압축 우선순위

- 앞뒤 상태가 같은 장면
- 기능·주체·비용이 같은 반복
- 행동이 이미 보여 준 의미의 재설명
- 같은 질문에 답하지 않는 새 사건
- 후반에 결과가 남지 않는 인물·소품·설정

### 길다는 이유만으로 먼저 자르지 않을 것

- 입력·정리·이동·기다림의 실제 노동
- 배우가 수행하는 침묵
- 선택과 자기검열이 바뀌는 범람
- 결말 상태를 준비하는 반복
- 작품 전체에서 희소하게 준비된 직접 발화

### 동결

추가 수정이 구조적 결함을 고치는 것이 아니라 이미 작동하는 선택을 다른 취향으로 바꾸는 일뿐이면 판본 동결을 검토한다.

- **작품의 약속**: 말로는 출범한 도시와 아직 출력되지 않는 서류가 같은 로비에 공존한다.
- **강한 이미지·행동**: 포토월·화분이 민원 줄을 밀고, 안내문에 작은 스티커가 누적되며, 번호는 `처리완료`가 되지만 종이는 없다.
- **온도**: 악의나 고발보다 친절하고 정확한 부분 정상화의 건조한 희극.
- **장면 생성 원리**: `완료`라는 공식 언어가 반복될수록 물리적 미완료가 더 커진다.

### 13.2 구조 DNA

| 항목 | 판정 |
|---|---|
| 압력 | 새 도시의 완료 선언과 A가 오늘 필요로 하는 증명서의 미발급 |
| 시간 | 출범식 직후의 마감·대기, 반복되는 발급 시도 |
| 장소 | 축하 동선과 민원 동선이 경쟁하는 청사 로비 |
| 인물망 | A, 안내 B, 창구 C, 방송, 발급기, 행사 참여자 흐름 |
| 정보·권한 | 방송은 완료를 선언하고, C는 부분 가능을 알며, 기계가 실제 발급 권한을 가짐 |
| 오브제·노동 | 번호표, 봉투, 스티커, 화분, 안내문, 재시도·이동·정리 |
| 반복 | 발급 시도와 `완료/가능` 문구가 돌아올 때 처리 주체와 실패 비용이 바뀜 |
| 대기 질문 | 오늘 이름의 종이가 실제로 나오는가 |
| 독립 연료 | 행사·민원·세무 세 흐름은 단막 안에서 교환 가능 |
| 빠진 연료 | 장막을 지탱할 별도 관계·결정·장기 결과는 현재 자료에 없음 |

### 13.3 후보 A — 최소 수직 변주형

- **자연 규모**: 약 12–18분 소시험
- **확장 방향**: 수직
- **조직**: A와 B, 발급기, 오프스테이지 축하 방송만 남긴다. 세 번의 발급 시도마다 기계 상태, A의 선택, B의 안내 권한이 달라진다.
- **새 행동**: 마지막에 기계가 새 이름이 아니라 이전 도시 이름의 서류를 출력한다. A는 마감을 위해 그 잘못된 종이를 가져갈지 찢을지 선택한다.
- **시간 연료**: 반복 시도의 기능 변화와 돌이킬 수 있는/없는 마지막 선택.
- **장점**: 원형을 가장 적은 요소로 시험하며, `로비 군상 + 작은 공모 + 조용한 잔여` 공식에서 벗어난다.
- **손실**: 부분 정상화의 다층 언어와 축하 동선의 희극이 줄어든다.
- **판정**: **병렬 소시험**. 원형의 최소 자연 규모를 확인할 가치가 있다.

### 13.4 후보 B — 수평·수직 단막형

- **자연 규모**: 약 30–40분 가설
- **확장 방향**: 수평 + 수직
- **조직**: 기존 지도처럼 출범식·민원·세무 흐름을 교차한다. 흐름마다 독립 변화와 다른 흐름에 남기는 결과를 명시한다.
- **새 행동**: 포토월과 화분 이동이 대기 공간을 실제로 줄이고, 세무 안내 수정이 발급기 스티커와 충돌하며, A의 번호 호출이 행사 촬영 순서와 겹친다.
- **시간 연료**: 인물 조합·동선 침범·안내문 변주·부분 처리의 연쇄.
- **장점**: 현재 출처와 B2 지도를 가장 많이 살리고, 친절한 부분 정상화의 군상 희극을 유지한다.
- **위험**: 기존 작품군의 `제도 담당자 + 처리되지 않는 사람 + 정확한 공식 문구 + 잔여` 공식과 가장 가깝다. B/C의 마지막 작은 인간화를 자동으로 넣지 않는다.
- **판정**: **현재 권장안**. 단, 매수 배당이 아니라 실제 세 흐름의 교환으로 분량을 증명해야 한다.

### 13.5 후보 C — 불연속 연작 또는 장막

- **가설**: 새 도시 이름이 출범 당일, 첫 세금 고지, 학교·주거 서류, 선거·폐지 이후에 다른 사람에게 어떤 물리적 결과를 남기는지 독립 단위로 축적한다.
- **필요한 추가 연료**: 서로 다른 시점의 공개 출처, 각 단위의 독립 인물 관계와 행동, 이전 단위의 선택이 다음 시점에 상속되는 장치.
- **장막 위험**: 현재 A의 발급 문제만으로는 별도 act와 장기 결과를 만들 근거가 없다. 시스템 장애 사례를 나열하면 설명적 이슈극이 된다.
- **연작 가능성**: 각 시점이 독립 행동을 가진다면 불연속 사이클이 될 수 있으나, 현재는 자료와 인물망이 부족하다.
- **판정**: **보류**. 현 원형을 억지로 장막화하지 않는다.

### 13.6 후보 비교

| 비교 | A 최소 수직형 | B 수평·수직 단막형 | C 불연속/장막 가설 |
|---|---|---|---|
| 보호되는 성취 | 완료/미완료와 종이의 모순 | 원형의 장소·세 흐름·물성 대부분 | 도시 이름의 시간적 축적 가능성 |
| 새 행동 | 잘못 출력된 종이에 대한 A의 선택 | 동선·안내·처리 흐름의 실제 간섭 | 시점별 독립 행동이 필요 |
| 시간 연료 | 반복 기능 변화 | 관계 조합 + 반복 상태 변화 | 역사적 간격 + 상속 |
| 설명 비용 | 낮음 | 중간 | 매우 높음 |
| 자기복제 위험 | 낮음–중간 | 높음 | 중간 |
| 빠진 연료 | 마지막 선택의 정확한 필요 | 흐름별 후속 비용의 실연 증명 | 추가 출처·인물·독립 에피소드 |
| 판정 | 병렬 소시험 | 권장 | 보류 |

**시험 결론:** 하나의 제도 글감에서 실제로 다른 두 형식이 생성됐고, 두 후보는 장 수가 아니라 `반복 선택`과 `군상 교차`라는 다른 시간 연료를 쓴다. 장막·연작은 현재 독립 연료 부족으로 보류한다.
