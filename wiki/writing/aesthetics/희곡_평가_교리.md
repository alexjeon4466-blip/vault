# 희곡 평가 교리

> **제정 방식.** 이 문서는 발명이 아니라 성문화다. 2026-07-02~07-25에 실제로 실행된 평가 22건에서 역산한 서식들을 진실원으로 확정한다. 그 전에는 파이프라인이 "6영역 평가"를 3중 참조하면서 정의는 어디에도 없었다 — F 코드와 같은 구조의 진실원 공백이었다. 유일한 신규 발명은 §4의 점수 앵커이며(사용자 결정 2026-08-17: "점수화해서 보고 싶은 게 평가"), 잠정임을 명시한다.

## 0. 평가의 지위 — 강행 규약

1. **평가는 읽기 전용 층이다.** 어떤 점수·합의·판정도 `workflow_phase` 전이, C4 통과, 잠금, canonical 승격을 자동으로 일으키지 않는다. **판정자는 사용자다.** (실사용 22건 전수에서 지켜진 규율의 성문화 — 3/3 만장일치도 사용자 미언급이면 상태 유지였다.)
2. **점수는 질의 환산이 아니다.** 진단·비교·좌표다. 구호는 이미 있다 — **"이 점수는 당선 예측이 아니라 퇴고 좌표다."**
3. **대상 revision을 고정한다.** 경로·매수·계측 추정을 헤더에 적고, 판본 비교와 C4 관련 평가는 **SHA-256 의무**다. (2026-07-25 판본 비교가 SHA 없이 진행된 것이 관측된 최약 사례 — 재발 금지.)
4. **증거 등급을 표기한다.** AI 가상 낭독·시뮬레이션은 R0이다(진실원: [[wiki/writing/aesthetics/집필_파이프라인#C3-3. 낭독·실연 증거|파이프라인 C3-3]]). 7월 기록들은 `actual_actor_read: false`로 대신했는데, 앞으로는 R0 라벨을 명기한다.
5. **`[약·물]` 한 줄을 표기한다**(파이프라인 §0.7). 점수와 무관한 물리·제작 책임의 귀속 기록이며 가산·감점 항목이 아니다. 7월 기록 전수에 이 표기가 없었다 — v2.3(08-01) 이전이라 소급 문제는 없으나 앞으로는 의무다.
6. **금지 재확인**: 엔진 층위 수, `lineage_stage`, 전용수다운 정도, 기존 작품과의 유사성은 가산·감점 항목이 아니다(파이프라인 C3-1). 자동 실행 금지 — 평가 산출물의 후속 장면·수정·시험은 사용자 선택 전에 실행하지 않는다.
7. **평가는 다중 독립 리뷰를 기반으로 한다** (사용자 결정 2026-08-17). **점수를 내는 평가(§3·§4)는 상호 비공개 독립 렌즈 3 이상이 의무**이며, 단일 평가자의 점수는 정본 점수가 아니라 초안이다. 진단(§2)은 단일 회차를 허용하되 병목 확정이 갈리면 적대적 검증(3렌즈 다수결)을 붙인다.
8. **점수 궤적을 지표로 쓰지 않는다** (사용자 결정 2026-08-17: "매 회차 점수가 오르는 평가는 무의미"). 같은 작품의 회차별 점수 시계열을 만들지 않고, 이전 점수와의 델타를 진행·성과로 읽지 않는다. 회차의 검증 대상은 점수 변화가 아니라 **증상 변화**다(피드백 번역법 §3.7). 6영역 좌표는 제출·비교 등 좌표가 실제로 필요한 시점에만 다시 연다.

## 1. 용도 라우터 — 무엇을 여는가

| 상황 | 서식 | 점수 |
|---|---|---|
| 단일 진본의 병목 진단 (C3 상시) | **§2 진단 5모듈** | 없음 (기본) |
| 다후보·다판본 비교, 판본 채택 | **§3 익명 3렌즈 6축** | 있음 — 진단값 |
| 다후보의 다음 행동 분류 (채택 아님) | §3의 무점수 변형 — 익명 3렌즈가 "가장 값싼 다음 행동"만 분류, 자연 합의 + 비교용 엄격안 병기 (07-18 재심사 서식) | 없음 |
| 외부 심사 시각·공모 좌표가 필요할 때 (사용자 요청) | **§4 6영역 100점** | 있음 — 퇴고 좌표 |
| 외부 피드백의 번역 | [[wiki/writing/aesthetics/사건_압력_피드백을_번역하는_법|피드백 번역법]] | — |
| 잠금 판정 | 파이프라인 C4 게이트 (이 문서 소관 아님 — 현행 통과 조건은 파이프라인 C4 본문) | 없음 — 조건 점검 |

라우터 원칙: **점수 서식은 비교와 좌표에만 소집한다.** 단일 진본을 상시 점수화하지 않는다 — 그것이 2026-07-11의 강등 결정이었고 이후 실사용이 증명했다.

## 2. 진단 5모듈 — 단일 진본 병목 진단의 진실원

2026-07-11~07-15 실사용 8건에서 안정 반복된 서식의 성문화. (07-24 「끊어진 뒤에만」은 약속 모듈 자리에 씨앗 대조가 든 변형이며 판정어 `⚠️`를 추가로 썼다.) 판정어는 `○ / △ / ⚠️ / 유보 N건 / 적신호 후보 N건`.

| 모듈 | 점검 내용 |
|---|---|
| **작품의 약속** | 보호 항목 열거, 약속 이행 판정. (신설 연결 2026-08-17 — 원전에는 없던 접합: 작품 동일성 계약(파이프라인 §1.3)과 대조할 수 있다) |
| **명료성 3층** | 물리층(무엇이 어디에)·인과층(무엇이 무엇을 낳는가)·해석층(열어둔 것) — 앞 두 층의 불명료를 셋째 층으로 변호하지 않는다(피드백 번역법 §9.3과 동일 원칙) |
| **선택 형식 게이트** | 선택한 F의 §2.3 증거만 점검(길이 원리). 선택하지 않은 형식을 요구하지 않는다 |
| **자기복제 위험** | 계보 내·vault 차원. 반복 관심과 반복 해결법을 구분 |
| **상류 병목** | C3 후보 1~3개 + downstream 비용. **최종 선정은 사용자** |

- 산출은 진단과 처방 후보까지다. "진단만, 수정은 사용자 우선."
- 병목의 판정이 갈릴 때는 **병목별 적대적 검증(3렌즈 다수결)**을 붙일 수 있고, 반론 소수의견을 기록한다(2026-07-24 「끊어진 뒤에만」 서식).
- **조건부 의무 모듈 — 씨앗 대조.** 씨앗이 동결된 작품은 **C3 매 회차** 씨앗 대조가 의무다([[wiki/writing/decisions/우로보로스_개념_이식_2026-07-18|우로보로스 결정]], 사용자 승인 — 삽입 위치가 "C3-1 현재판 평가"로 명시돼 있다). 실사용: 07-24 7항 전수 대조, 서명칸 C4의 6편 일괄 소급 동결. (이 문서의 초판이 이를 "자유 추가"로 잘못 강등했다 — 1차 검증에서 교정.)
- 작품별 고유 검증 절(연료 검증 등)은 자유 추가 — 5모듈은 바닥이지 천장이 아니다.

## 3. 익명 3렌즈 6축 — 다후보 비교·판본 채택의 진실원

### 3.1 수행 6축 (2026-07-23 제정, 3회 실사용)

| 평가축 | 배점 |
|---|---:|
| 무대 행동/압력 | 25 |
| 관계·정보 차이 | 20 |
| 몸·오브제·물성 | 20 |
| 생략·미결 압력 | 15 |
| 대사·가상 낭독 리듬 | 10 |
| 독립 시간 연료 | 10 |
| **합계** | **100** |

§4의 구식 6영역과 **같은 골격(25/20/20/15/10/10)에 다른 축**이다 — 문학 자질이 아니라 수행 진단을 잰다. 혼동을 막기 위해 이 축들을 **수행 6축**, §4를 **6영역 좌표**로 부른다. 파이프라인의 `six_domain_evaluation`은 §4를 가리킨다.

> **축 이름의 긴장 명시 (2026-08-17 정합 검토).** `생략·미결 압력`은 원전(07-23) 자구라 보존하지만, "개방성은 우수성 기준이 아니다"(피드백 번역법 §4.3)와 긴장한다. 해석 규칙으로 해소한다: 이 축이 재는 것은 미결 자체가 아니라 **생략·미결이 만드는 압력의 획득**이며, 닫힌 결말 후보는 같은 배점을 **종결의 획득**으로 채점한다. 종결 방식 자체를 이 축의 가감 근거로 쓰지 않는다.

### 3.2 표준 절차 (역산 7단계)

1. **이해충돌·오염원 선언** — 익명화가 왜 필요한지 명시 (예: 후보 중 하나가 AI 조립본)
2. **패킷 조립** — 고정 셔플 시드 기록, 제목·출처·frontmatter·이전 추천·작성자·설계 라벨 전부 제거, 익명 라벨 부여, **본문 SHA-256 기록**, 누출 0 검증. 익명 패킷과 숨김 매핑은 vault 밖 캐시에
3. **독립 3렌즈 위임** — 각 렌즈가 전 후보를 끝까지 읽고 6축 채점 + 압력 구간 + 가상 낭독 시간(R0 추정 — C2 측정표의 실제 발화·공연 시간 칸에 넣지 않는다) + next state 제출. 렌즈 구성은 후보 성격에 맞게 (표준: 구조/시간 연료 · 생략/미결/자기복제 · 객석 정보/물성)
4. **기계 검증** — 렌즈 보고서의 fenced JSON 독립 파싱, 축별 상한·정수·합계 검산, 집계 전 본문 SHA 재대조 (2026-07-24 완성형)
5. **집계** — 렌즈 총점의 **단순 평균**(가중 없음) + **표준편차·범위 병기**(분산 은폐 금지), 축별 평균표. next state는 강제 쿼터 없는 **자연 합의**(3/3, 2/3)만 기록
6. **라벨 복원 후 해석** — 점수 차는 진단값. "확정적 작품 가치로 해석하지 않는다." 자기복제 감사 첨부
7. **사용자 결정 대기** — 권고와 결정을 절로 분리. 미선택 항목은 상태 유지

이것이 파이프라인 §0.6이 명명한 `상호 비공개 독립 방 시뮬레이션`의 점수형이며, 증거 등급은 **R0 한 회차의 복수 시뮬레이션**이다 — 실제 여러 독자로 세지 않는다.

## 4. 6영역 100점 — 외부 심사 좌표의 진실원 (선택 렌즈)

### 4.1 호출 조건

사용자가 100점 평가·공모 심사 시뮬레이션을 요청했을 때만 연다(파이프라인 C3-1 호출 계약). 대상 revision·배점·판본을 헤더에 고정한다. 공모별 루브릭이 따로 있으면 이 표와 섞지 않는다. **채점은 §0-7에 따라 상호 비공개 독립 렌즈 3 이상으로 실행하고, 평균 + 표준편차·범위를 병기한다** — 1세대의 단일 평가 + 보충 3렌즈 구조를 독립 3렌즈 채점으로 승격한 것이다(2026-08-17 사용자 결정).

### 4.2 영역과 배점 (2026-07-02~07-10 실사용 3회, 자구 보존)

| 영역 | 만점 | 점수 앵커 (잠정 v1) |
|---|---:|---|
| 극적 구조 | 25 | **21~25** 장면 연쇄가 필연이고 종막이 앞선 시간으로 획득됨 / **16~20** 경로는 서나 국면 전환에 병목 / **~15** 연쇄가 임의적이거나 종결 방식이 미획득 |
| 대사 및 언어 | 20 | **17~20** 발화가 인물·관계·리듬을 동시에 운반하고 해설이 없음 — **범람은 수행이면 해설이 아니다**(통합노트 §2.1 시험 적용) / **13~16** 기능하나 잉여·해설 잔존 / **~12** 설명 대사가 구조를 대행 |
| 인물 형상화 | 20 | **17~20** 등장하는 모든 목소리·존재(부재자·사물·시스템 포함)가 대화 조건을 실제로 흔듦 / **13~16** 중심은 서나 주변 위치가 기능에 머묾 / **~12** 인물이 주제의 대변자 |
| 극적 장치 및 기법 | 15 | **13~15** 장치가 사건을 운반하고 반복 묶음 단위로 기능이 변함(F2 진실원 정합) / **10~12** 장치는 있으나 반복이 재진술 / **~9** 장치가 장식 |
| 주제 및 메시지 | 10 | **9~10** 질문이 수행되고 종결 방식이 **획득됨** — 미결이든 명시적 해결이든 앞선 시간이 벌어들임 / **7~8** 질문은 서나 종결이 아직 벌리지 않음 / **~6** 주제가 앞선 시간과 무관하게 선언됨 (획득된 직접 발화는 여기 해당하지 않음) |
| 독창성 및 예술성 | 10 | **9~10** 익숙한 재료의 낯선 조직 / **7~8** 견실하나 관습적 조직 / **~6** 차용 문법의 무변형 재연 — **자기 계보 유사성(자기복제·전용수다움)은 이 축의 근거가 아니다.** 그것은 §2 자기복제 모듈의 진단 대상이지 감점 축이 아니다 |

### 4.3 앵커의 지위와 등급 — 이중 잠정

- **앵커는 잠정이다.** 실사용 3회의 관측(총점 77·82·89, 영역별 분포)과 이 vault의 교리(획득된 종결, 위치 렌즈, 반복의 기능 변화)에서 세웠다. 발명분이며, 실측 3회가 더 쌓이면 재조정한다.
- **정박점이 오염돼 있다 (2026-08-17 적대 검토 확정).** 관측 3점 중 **2점(77·82)은 이후 폐기된 밀도 기준(90~110매 목표)의 감점을 포함**한다 — 「그늘」 77은 평가 스스로 "감점의 대부분은 밀도에서 나온다"고 적었고, 「죽음에」 82는 2026-07-13에 "감점 기준 자체가 바뀜"으로 기록됐다. 폐기 후 기준으로는 두 점수 모두 약 5점 상향 여지가 있다. **구기록 3점을 인용할 때는 이 사실을 전부 병기한다** — 「죽음에」만이 아니라 「그늘」 77도.
- 등급 경계(**이중 잠정** — 관측 3점에 정합하는 경계 조합은 35개 이상이라 과소결정이고, 그 관측 자체가 위처럼 오염됨): **A ≥ 87 / A- 81~86 / B+ 75~80 / B ~74**. 실측이 쌓이면 **최우선 재조정 대상**이다.
- **재현성 장치**: 밴드 폭이 4~5점이므로 밴드 내 위치는 상단 조건의 부분 충족으로 정하고, 렌즈별로는 **밴드 중앙값을 기본값**으로 한다(잠정 규칙). 독립 3렌즈가 의무이므로(§0-7) 정본 점수는 항상 **렌즈 평균 + 표준편차·범위**다. 단일 렌즈 점수는 초안으로만 남긴다.
- 보충 3렌즈를 병기할 수 있다 — `주류 심사 시각 / 소수·공연장 시각 / 실험적 시각` (1세대 서식 계승). 주류 시각의 체감 점수대 병기도 허용(관측: "84~86").
- **금지 재확인**: 분량·밀도를 이 표로 감점하지 않는다 — "억지 증량 금지"는 07-11/12 신교리로 이미 규범이었고, **2026-07-13 판정은 90~110매 규격의 폐기**였다(「죽음에」 확장검토: "감점 기준 자체가 바뀜"). 종결 방식(미결/해결/희극적 종결)과 인물 수(1인극 포함)를 가감 근거로 쓰지 않는다 — 앵커의 "획득" 기준과 "위치" 기준이 그 중립화 장치다.
- **사용자 미학 확인란을 병기한다** (1세대 서식 계승 — 07-07·07-10 실사용): `균열의 지속 / 결말 미해결 여부의 존중 / 재촉 금지·수위` 등 작가 미학 항목을 **점수와 분리해** 확인란으로 기록한다. §0-2("점수는 질의 환산이 아니다")를 서식 층위에서 집행하는 장치이며, 6영역을 복권하면서 이것만 떨어뜨리지 않는다.
- 1세대 부속(한 줄 평, "다음 개작 체크" 우선순위 목록)도 재사용할 수 있다.

### 4.4 앵커 검증 사례 (2026-08-17 적대 검토)

- **『곰』(1888, 사랑 고백으로 닫히는 희극 — 길이 원리 §3.0 표본)**: 초판 앵커로는 주제·독창성에서 구조적 감점(약 76, B+)이었다. 미결을 만점 조건으로 승격한 오류의 물증. 현행 앵커에서는 종결의 **획득** 여부로 채점한다 — 고백·키스가 언쟁·결투의 축적으로 벌어들여졌는지가 질문이 된다.
- **「저는,」(1인극)**: 초판 인물 앵커("전 인물이 행동 동사, backboard 없음")는 1인극에서 변별 붕괴 + 자동 상향이었다 — 주변 인물이 구조적으로 없어 중간 밴드가 판정 불능. 현행 앵커는 통합노트 §3.2 위치 렌즈를 계승해 **부재자·사물·시스템**(이 작품에서는 "거의 두 번째 배우"인 스크린)을 채점 대상에 넣는다.

## 5. 등재 기법

- **호흡감산** (2026-07-18) — 가상 합독 후, 새 정보·권리·물건 변화가 없는 반문만 감산 후보로 올리고, 물건 상태가 실제로 바뀌는 행동은 침묵·동선 시간으로 보호한다. 초 단위 값은 삭제 근거가 아니라 첫 테이블리딩의 시험 목표이며 지문에 고정하지 않는다.
- **자기복제 감사** — 풀 공유 공식을 명시하고 작품별 「보호할 고유 채널 / 반복하면 안 되는 것」을 표로.
- **판독 이중화** — 판독 불가 매체(화면·종이) 사용 시마다 큰 동작+대사로 되받기.
- **수용검토형** — 외부 평가의 항목별 지면 대조 검증("실재" 판정) 후 `수용/기각 결정란(사용자 기입)`으로 넘김. 상세 절차는 피드백 번역법 소관.
- **다관점 패널** (C4 낭독 대체의 실제 도구 — 이 서식도 본 문서가 승계한다) — 13관점형(첫 청자 5인·낭독자 3인·액팅코치·무대감독·제2언어 코치·심사자·연출가; 계약 투표와 중앙값·실용 범위·비율로 합산)과 3방 분리형(배우실·첫 관객실·제작실). 점수가 아니라 투표·비율이 산출이며, 낭독 회차 대체 인정은 사용자 판정 + "대체 인정 사실 명기"가 조건이다.
- next state 상태 어휘(`second-scene-recommended` / `selected-not-written` 등)와 frontmatter 서식(`review_method` / `selected_states` / `actual_actor_read`)은 07-23~25 기록의 자구를 재사용한다.

## 6. 역산 기록 — 이 문서가 성문화한 역사

- 평가 서식은 3세대를 거쳤다: **점수 서식**(07-02~10, 6영역 100점) → **진단 서식**(07-11~, 5모듈, 점수 폐지) → **C4 게이트**(07-18~, 당시 실행 형태는 3조건 — 현행 통과 조건은 파이프라인 C4 본문). 6영역은 07-11 평가 노트의 판정("이번 회차 미적용 — 선택 렌즈")으로 강등돼 이후 실사용 0회였고(독립 결정 문서는 없음), 본 제정(08-17)에서 사용자 결정으로 **외부 심사 좌표 렌즈로 복권**됐다 — 단 앵커를 갖춘 채로.
- 두 6축이 같은 골격을 공유한 것은 우연이 아니라 계승이다. 수행 6축은 "점수를 작품의 질로 환산하지 않는다"(우로보로스 07-18)는 결정 위에서 축 이름만 수행 진단으로 교체한 것이다.
- 관측된 결함과 처치: 점수 앵커 부재 → §4.2 신설 / 판본 비교의 SHA 부재 → §0-3 의무화 / R0·[약·물] 미표기 → §0-4·5 의무화 / 밀도 기준의 무단 반전 → §4.3 병기 규칙.
- **운영 프로토콜의 부재.** 파이프라인이 참조해 온 "운영 프로토콜 — 계보 판독·채점·오염 방지 규약"은 vault에 실물이 없고 `protocol_ref`는 전 기록에서 null이다(2026-08-17 수색). **채점·오염 방지 기능은 이 문서가 승계한다**(§3.2의 익명화·기계 검증이 그것이다). 계보 판독(`lineage_stage`) 기능은 여전히 소유자가 없다 — 관련 필드는 `not_assessed`로 두는 현행 관행을 유지한다.
