# 사건·압력 피드백을 번역하는 법

> 합평·심사·AI·낭독·실연에서 나온 피드백을 작품 동일성 계약 안의 수정, 제한 시험, 추가 증거, 구조개작 제안 가운데 알맞은 경로로 보내는 선택형 실무 문서다.

## 0. 문서의 위상

이 문서는 작품의 미학을 정하는 상위 교리가 아니다. 집필 파이프라인 C3에서 외부 피드백을 다룰 때 선택적으로 호출하는 **하위 번역 도구**다.

- 상태·가지·판본·승인·증거 등급은 집필 파이프라인 v2.3을 따른다.
- 작품 고유 미학·보호 자산은 현재 본문과 통합 극작노트의 작품 우선층에서 판정한다.
- 극작 엔진은 B 구조 맵에서 가설을 세우고 C2 이후 대상 revision에서 사후 관찰한다.
- 이 문서는 작품 동일성 계약, 자연 규모, 결말 형식, C4 통과, 판본 잠금을 바꾸지 않는다.
- 피드백이 작품 동일성 계약의 변경을 요구하면 이 문서 안에서 수정하지 않고, 부모판 보존과 사용자 승인을 전제로 B1/B2 새 가지를 제안한다.
- 잠긴 판본은 직접 고치지 않는다. 같은 계약의 수정도 잠긴 기준 branch를 보존한 새 child candidate에서 시작한다.
- 모든 피드백 번역 결과에는 `[약·물] 약속 판정 / 소유 층위 / 상세 가동 여부`를 한 줄로 표시한다. 물성 비병목이면 `허용 / 해당 없음 / OFF`로 닫는다.

이 문서를 여섯 활성 규약과 같은 상위 규약으로 세지 않는다. 평소에는 닫아 두고, **외부 반응을 실제 퇴고 행동으로 바꾸는 일이 병목일 때만** 연다.

---

## 1. 핵심 원칙 — 증상과 처방을 분리한다

외부 피드백 한 문장에는 서로 다른 층이 섞여 있다.

| 층 | 질문 | 예 |
|---|---|---|
| 반응 | 읽는 동안 무엇을 느꼈는가 | “중간부터 긴장이 풀렸다.” |
| 관찰된 증상 | 본문 어디에서 무엇이 도착하지 않았는가 | “같은 호출이 세 번 오지만 인물·관계·관객 주의가 달라지지 않았다.” |
| 원인 추정 | 왜 그런 현상이 생겼다고 보는가 | “외적 목표가 약해서다.” |
| 제안된 처방 | 무엇을 바꾸라고 하는가 | “큰 사고를 하나 넣어라.” |
| 취향·규격 | 어떤 연극관이나 제출 조건이 작동하는가 | “주인공은 결단해야 한다.” / “40분을 맞춰야 한다.” |

한 층이 설득력 있다고 나머지 층까지 자동으로 옳아지지 않는다.

> 관객이 감지한 불편함을 부정하지 않는다. 그러나 그 불편함에 붙은 원인과 해결책은 현재 본문에서 다시 검증한다.

가장 자주 쓰는 판정은 **증상 수용 + 처방 번역**이다. “사건이 약하다”는 반응을 받아들이면서도 큰 사고 대신 관계의 비용, 정서의 진폭, 반복의 기능, 물성의 변화, 절차의 침투를 고칠 수 있다. 반대로 작품 계약을 방패로 삼아 증상까지 기각해서도 안 된다.

## 2. 입력을 판본과 증거에 결박한다

피드백을 옮겨 적기 전에 다음을 고정한다.

```yaml
feedback_record_id:
work_id:
target_revision:
source:
received_at:
reading_or_run_conditions:
evidence_level:
independence:
original_feedback:
```

### 2.1 증거 등급

> **운영 사본이다.** 단일 진실원은 [[wiki/writing/aesthetics/집필_파이프라인#C3-3. 낭독·실연 증거|집필 파이프라인 C3-3]]이며 등급의 뜻을 여기서 바꾸지 않는다. (2026-08-17 대조에서 R0·R4·H1 행이 드리프트해 있어 진실원 문구로 맞췄다. 특히 R4에서 `시간`이 탈락해 있었다 — 실측 기록 누락으로 이어질 수 있는 차이였다.)

| 입력 | 기록 | 말할 수 있는 범위 |
|---|---|---|
| 실제 독립 인간의 묵독·서면 피드백 | H1 | 자유 회상, 정보 누락, 독자별 오독·질문 |
| AI 가상 낭독·상호 비공개 독립 방 시뮬레이션 | R0 | 오독 후보, 자유 회상 가설, 이해관계자별 병목, 질문 설계 |
| 사용자/작가 자가 음독·녹음 | R1 | 해당 독자의 발화 시간, 문장 걸림, 자기 청취 차이 |
| 실제 외부 테이블리딩 | R2 | 배우 발화성, 상호 리듬, 청자 회상, 낭독 시간 |
| 동선·오브제 런 | R3 | 비언어 시간, 물성 경로, 시야, 신체 비용 |
| 기술 런·공개 낭독·공연 | R4 | 실제 포함된 기술·동선·관객 조건의 반응과 시간 |

- 조건이 확인되지 않은 심사평·점수·전언은 억지로 H1이나 R2로 올리지 않고 `external_feedback / conditions_unknown`으로 남긴다.
- AI 여러 역할의 의견은 실제 여러 독자의 합평이 아니라 R0 한 회차의 복수 시뮬레이션이다.
- 피드백이 가리키는 범위를 넘어 실제 발화성·관객 반응·상연 가능성을 추정하지 않는다.
- 이전 revision의 피드백을 현재판에 쓸 때는 `delta_review: unaffected / partial_retest / invalid`를 적는다.

### 2.2 반복 피드백

같은 증상이 여러 번 보고되면 **우선 검증할 가치**는 올라가지만 참이 확정되지는 않는다.

- 같은 프롬프트·같은 세션·서로의 결론을 본 AI 역할들은 독립 근거로 세지 않는다.
- 서로 독립된 H1·R2·R4에서 같은 위치와 같은 증상이 반복되면 수정 또는 제한 시험의 우선순위를 높인다.
- “지루하다”가 세 번 반복돼도 세 사람이 같은 원인을 말한 것은 아니다. 지루해진 위치와 그 직전의 장면 기능을 대조한다.
- 서로 반대되는 반응은 평균내지 않는다. 독자 조건, 도착한 정보, 작품이 요구한 관객 위치의 차이로 보존한다.
- 다수결은 진실 판정이 아니다. 구체적 위치·재현 가능성·작품 계약과의 관계가 빈도보다 우선할 수 있다.

## 3. 피드백 번역 절차

### 3.1 1단계 — 원문을 보존한다

피드백 제공자의 말을 먼저 작가의 언어로 고쳐 쓰지 않는다. 원문, 대상 revision, 장면 위치, 읽기·낭독 조건을 보존한다.

“후반이 약하다”를 곧바로 “압력 축적 부족”으로 기록하면 번역 전부터 답을 정한 셈이 된다.

### 3.2 2단계 — 층을 분해한다

다음 여섯 칸을 가능한 만큼만 채운다.

```yaml
reaction:
observed_symptom:
location_or_sequence:
inferred_cause:
proposed_prescription:
taste_or_external_constraint:
```

피드백이 추상적이면 없는 원인과 위치를 만들어내지 않는다. 다음 독해·낭독에서 확인할 질문으로 바꾼다.

### 3.3 3단계 — 현재 본문에서 재현한다

다음 순서로 본다.

1. 지적된 위치를 앞뒤 장면과 함께 다시 읽는다.
2. 피드백 제공자가 실제로 놓친 정보와, 작품이 아직 보내지 않은 정보를 구분한다.
3. 선택한 엔진에서 무엇이 멈췄는지 본다.
4. 배우·객석·물성 문제라면 해당 증거 등급에서 확인 가능한지 본다.
5. 반대 독해가 있으면 어느 조건에서 갈리는지 적는다.

피드백이 `비현실적이다 / 무대에서 안 보인다 / 실제로 오래 걸린다 / 만들 수 없다 / 위험하다`를 포함하면 곧바로 본문 결함으로 번역하지 않는다.

1. 작품이 초반에 학습시킨 대표·압축·대리의 약속이 있는가.
2. 관객이 반드시 판단해야 할 서사 물리와 최소 실제 물성은 무엇인가.
3. 직접 지각이 필요한가, 배우·소리·빛의 매개 지각으로도 보존되는가.
4. 안전하고 반복 가능한 합리적 상연 해법이 하나 이상 있는가.
5. 약속 판정은 `허용/P2/P1/P0`, 소유 층위는 `본문/제작/기술` 중 무엇인가.

이 다섯 질문 중 하나라도 실제 병목이면 `상세=ON`으로 두고 판정 카드를 연다. 합리적 해법이 여러 개면 피드백의 증상은 수용할 수 있어도 처방은 제작 선택으로 번역하며 희곡 감점으로 쓰지 않는다.

한 번 재현되지 않았다고 피드백이 틀린 것은 아니다. 다만 재현되지 않은 증상은 곧바로 본문 수정 명령이 아니라 **시험 질문**이다.

### 3.4 4단계 — 작품 동일성 계약과 대조한다

다음 셋을 분리한다.

- **계약 안의 병목**: 같은 작품 안에서 장면·관계·리듬·물성·정보 경로를 고치면 된다.
- **보호 자산을 시험하는 피드백**: 직접 고치지 말고 가장 싼 반대 시험으로 비용을 비교한다.
- **계약 변경 제안**: 인물 수, 시공간, 주 형식, 핵심 결말 기제를 바꾸려면 구조개작 후보로 분리한다. 작품 동일성 계약의 6항목 정의는 [[wiki/writing/aesthetics/집필_파이프라인|파이프라인]] §1.3이 진실원이다. **자연 규모는 계약 항목이 아니다** — 파이프라인 §0.4가 계약과 분리한 별도 축이므로 자연 규모 변화만으로 구조개작을 판정하지 않는다.

“작품의 의도”라는 말만으로 보호하지 않는다. 보호 자산은 현재 본문에서 실제 힘과 비용을 만들어야 한다.

### 3.5 5단계 — 대응 코드를 고른다

| 코드 | 뜻 | 사용 조건 |
|---|---|---|
| `수용` | 관찰과 처방을 그대로 채택 | 본문에서 증상이 재현되고 처방이 계약 안의 상류 원인을 정확히 고칠 때 |
| `증상수용_처방번역` | 불편함은 인정하되 해결법을 작품 문법 안에서 다시 찾음 | 증상은 재현되지만 제안된 처방이 보호 자산을 불필요하게 훼손할 때 |
| `제한시험` | 가장 싼 가역 시험 뒤 비교 | 원인이나 계약 비용이 불명확할 때 |
| `보류` | 추가 H1·R1–R4 또는 전체 범위 독해까지 기다림 | 현재 증거로 판단할 수 없을 때 |
| `기각` | 현재 수정 근거로 쓰지 않음 | 대상판 오인, 현재 본문·선포된 약속과 명백히 모순되는 오독, 계약 밖 취향 강요, 이미 해소된 구판 피드백일 때 |
| `구조개작_후보` | 부모판을 보존하고 새 가지로 시험 | 제안이 작품 동일성 계약을 바꾸며 가능성은 별도로 검토할 가치가 있을 때 |

한 피드백 안에서도 증상과 처방에 다른 코드를 줄 수 있다. 기각 사유는 “내 취향과 다름”이 아니라 대상판·증거·계약·비용의 언어로 쓴다.

### 3.6 6단계 — 알맞은 경로로 보낸다

| 발견 | 이동 |
|---|---|
| 대사 리듬·국소 명료성·큐·동선·반복 기능 | C3 현재 회차 |
| 같은 형식 안에서 진행 가설·관계·물질 경로 실패 | B 구조 맵 회귀 |
| 자연 규모·인물 수·시공간·주 형식 변경 | B 보호, 새 파일 |
| 편별 독립성과 장막 종속성(F5↔F4) 판정 변경 | 연작 공통 / B 보호. 연작 전체 설계 무효화 |
| 발화성·외부 이해·물성·기술이 미확인 | 필요한 H1·R1–R4 |
| 현실과 다르지만 인과·약속이 보존되고 안전한 해법이 있음 | `허용/제작·기술`, 본문 수정·감점 금지 |
| 약속 불일치·필수 기호 미가시 | `P1/소유 층위`, 본문이면 C3 또는 B 구조 맵, 제작·기술이면 R3/R4 |
| 현재 구현의 중대한 안전 위험 | `P0/기술`, 구현 중단 뒤 대안 시험 |
| 안전한 대안이 없고 본문이 위험 물리를 강제 | `P0/본문`, C3 또는 B 구조 맵 또는 구조개작 검토 |
| 권리·출처의 중대한 미해결 | 해당 강행 P0 처리 우선 |
| 사용자가 요청한 100점·공모 평가 | 읽기 전용 6영역 평가층 — [[wiki/writing/aesthetics/희곡_평가_교리|희곡 평가 교리]] §4 |

피드백이나 점수는 C4 통과나 판본 잠금을 자동으로 일으키지 않는다.

### 3.7 7단계 — 수정 뒤 같은 질문으로 다시 본다

수정 사실이 아니라 증상 변화가 검증 대상이다.

```yaml
approved_scope:
operation:
output_revision:
test_question:
before:
after:
evidence_after:
side_effects:
decision:
next_condition:
```

수정 뒤 새로운 상류 병목이 생기거나 보호 자산의 힘이 사라지면 되돌리거나 다른 번역을 시험한다.

## 4. 자주 오는 피드백의 보편 번역

아래 표는 정답표가 아니다. 특정 처방을 고르기 전에 **무엇이 실제로 부족한지**를 찾는 첫 질문이다.

| 일반 피드백 | 먼저 분해할 질문 | 가능한 상류 원인 |
|---|---|---|
| “사건이 약하다” | 어느 구간에서 다음 조건이 생기지 않는가 | 사건의 후속 비용, 관계 변화, 정서 진폭, 반복 기능, 이미지 변화, 절차 압력, 관객 주의 |
| “인물이 더 행동해야 한다” | 목표·선택·시도·수행·회피·실패 중 무엇이 객석에 안 보이는가 | 욕망 부재, 행동 동사 부재, 결과 없는 미수, 동선·물성 경로 누락 |
| “결말이 더 선명해야 한다” | 물리적 결과, 관계 결과, 의미 해석 중 무엇이 불명료한가 | 앞선 축적 부족, 마지막 행동의 비용 부족, 큐·시야 모순, 의미 과잉 개방 |
| “설명이 더 필요하다” | 지금 알아야 행동을 이해하는 정보인가, 끝까지 열어둘 의미인가 | 장소·관계·사건 조건 누락, 정보 차이 부족, 배우가 딛는 사실 부재 |
| “감정이 안 보인다” | 관객의 정서 이름이 필요한가, 배우의 행동 근거가 필요한가 | 몸·거리·리듬의 진폭 부족, 모든 인물의 동일한 말투, 정서와 행동의 연결 누락 |
| “반복이 많다” | 반복 때마다 인물·관계·정보·물성·관객 주의 중 무엇이 달라지는가 | 기능 없는 재진술, 변주 간격 오류, 누적되지 않는 압력, 필요한 의례의 수행 시간 |
| “너무 직접 말한다” | 말이 이미 보인 뜻을 요약하는가, 말하는 행위 자체가 장면을 바꾸는가 | 해설, 범람, 고백, 공격, 측정, 자기검열을 구분하지 못함 |

### 4.1 사건

사건을 더 크게 만들지, 더 작게 만들지 미리 정하지 않는다.

- 외부 사건 자체가 엔진이면 원인·목표·후속 비용을 선명하게 할 수 있다.
- 관계극이면 같은 사건 뒤 접촉·거리·요구가 달라지는지 본다.
- 정서극이면 몸·말·리듬의 진폭을 본다.
- 이미지·지속극이면 같은 것을 다시 보는 관객의 지각이 달라지는지 본다.
- 절차극이면 기록·판정·책임의 위치가 달라지는지 본다.
- 언어극이면 발화 주체·호명·리듬의 변화가 장면을 진행하는지 본다.
- 의례·수행극이면 규칙의 성공·실패·변형이 공동체를 다시 배열하는지 본다.

`사건이 약하다 → 압력을 쌓는다`는 보편 공식이 아니다.

### 4.2 행동

행동은 결단과 충돌만이 아니다. 그렇다고 모든 미수를 강한 행동으로 승인하지도 않는다.

- 결단·접촉·파손·이탈
- 시도·미수·회피·보류
- 돌봄·노동·측정·기록
- 말하기·침묵하기·듣기·잘못 듣기
- 반복 수행·규칙 위반·실패

어떤 형태든 **누가 무엇을 하며, 무엇이 막고, 그 뒤 무엇이 달라지는가**가 보여야 한다. 아무 결과도 만들지 않는 머뭇거림을 “하지 못하는 몸”이라는 말로 자동 보호하지 않는다.

### 4.3 결말

개방성은 우수성 기준이 아니다.

- 잔여·미결
- 실패·단절
- 선택·이탈
- 접촉·파손
- 희극적 종결
- 명시적 해결

먼저 물리·절차·인과를 확인하고, 의미는 작품이 요구하는 만큼만 연다. 닫힌 결말·직접 발화·완전한 소진도 앞선 시간이 벌어들였다면 보호한다.

### 4.4 설명

설명을 줄이거나 늘리기 전에 층을 나눈다.

1. 지금 명확해야 하는 행동 조건
2. 늦게 밝혀도 되는 전사·관계·진위
3. 끝까지 열어둘 수 있는 윤리·의미

대사, 몸, 사물, 소리, 빛, 화면 가운데 어떤 경로가 가장 정확한지도 별도 판단한다. “오브제로 바꾸기” 역시 고정 처방이 아니다.

## 5. 선택형 프로필 PAP-1 — 압력·미수·지속

`PAP`는 `Pressure–Attempt–Persistence`의 약칭이다. 사건의 압력, 완수되지 않더라도 비용을 만드는 시도, 앞선 행동이 남긴 지속을 함께 보는 프로필이다.

### 5.1 호출 조건

이 프로필은 다음 세 조건이 현재 대상 revision에서 모두 확인될 때만 활성화한다.

1. 사건의 크기보다 압력의 누적이 실제로 장면의 다음 조건을 만든다.
2. 미수·비접촉·보류가 인물 관계와 관객 주의를 바꾸며, 단순 정체가 아니다.
3. 마지막 잔여·지속이 앞선 행동의 구체적 결과이고 작품의 관객 시간 약속을 운반한다.

작가의 이전 작품이 그랬다는 이유, 공식 언어·익명 인물·사물이 있다는 이유, 직접 행동을 쓰기 불편하다는 이유만으로 호출하지 않는다.

```yaml
activated_profile: PAP-1 | not_activated
activation_evidence:
  pressure:
  attempted_or_withheld_action:
  persistence:
counterevidence:
```

### 5.2 이 프로필에서의 번역

| 피드백 | PAP-1 번역 질문 |
|---|---|
| 사건의 압력이 약하다 | 같은 공간·상태가 더 무거워지는 구체적 변화가 있는가 |
| 인물이 더 행동해야 한다 | 시도·중단·비접촉이 객석에서 보이고 다음 비용을 만드는가 |
| 결말의 선택이 흐리다 | 남은 사물·소리·상태가 앞선 행동을 새 의미로 되돌려 주는가 |
| 설명이 부족하다 | 설명 없이 감지할 표면과 배우가 딛는 사실이 모두 있는가 |
| 반복이 많다 | 같은 요소가 매번 다른 기능과 압력으로 귀환하는가 |

### 5.3 보호할 수 있는 수법

- 공식 언어가 점점 가까이 침투하는 리듬
- 손이 가다가 멈추는 시도와 그 후속 비용
- 문 앞·칸 사이·거울 속의 비접촉 거리
- 잠그지 못함, 끊지 못함, 나가지 못함, 묻지 못함
- 인물이 떠난 뒤에도 남는 사물·소리·시스템 상태

보호 여부는 명사나 자세가 아니라 **기능**으로 판정한다.

### 5.4 오용 방지

다음 문장은 PAP-1 안에서만 성립할 수 있는 프로필 언어다.

> 사건은 설명보다 압력으로 쌓일 수 있다.  
> 행동은 결정뿐 아니라 비용을 만드는 미수로 보일 수 있다.  
> 결말은 선택뿐 아니라 앞선 행동이 남긴 지속으로 성립할 수 있다.

이를 다음과 같은 보편 규칙으로 바꾸지 않는다.

- 큰 사건을 피한다.
- 직접 접촉과 결단을 피한다.
- 시스템은 말하지 않아야 한다.
- 인물은 익명이어야 한다.
- 결말에는 반드시 사물이나 소리가 남아야 한다.
- 닫힌 결말은 설명적이다.

익숙한 해결법인지 의심되면 직접 행동, 접촉, 단절, 닫힌 결말 가운데 하나를 **가역적인 반대 시험**으로 써 본다. 반대 시험이 작품의 중심을 죽인다는 사실도 본문 증거로 확인해야 한다.

## 6. 사례 — 「모든 직원은 업무 복귀 전에 반드시 울음을 멈춰야 합니다」

### 6.1 사례의 범위

이 절은 v5·v7·v8 계열을 대상으로 2026-06-21에 작성한 번역 기록이다. 현재 canonical이나 후속 잠금판의 자동 판정이 아니다.

```yaml
case_status: historical
target_revisions:
  - v5
  - v7
  - v8
evidence_level: not_assessed
current_revision_applicability: requires_delta_review
activated_profile: PAP-1
```

당시 대상판에서 작품은 큰 사건의 해결보다, 콜센터 화장실 안에서 규정의 언어가 사람을 끝내 포착하지 못하는 시간을 물소리·신발·휴대폰·안내문으로 지속시키는 쪽에 가까웠다.

이 판단은 “전용수 희곡은 원래 그렇다”는 작가 교리가 아니라 해당 revision에서 읽힌 작품 계약 가설이었다.

### 6.2 피드백별 번역

#### “사건의 압력이 약하다”

- **관찰할 증상:** 중후반에 같은 공간에 머무는 비용과 공식 언어의 침투가 더 이상 커지지 않는가.
- **그대로 따른 처방의 비용:** C의 전사·사고 원인·즉각 해결 목표를 추가하면 규정 불가능한 상태가 해결 가능한 상황으로 좁아질 수 있다.
- **번역한 질문:** 물소리·휴대폰·신발·공식 언어가 매번 다른 기능을 얻으며 다음 조건을 만드는가.

당시의 기능 경로:

- 물소리: 고장 → 은폐 → 숨소리 보호 → 잠글 수 없음 → 끝까지 남는 소리
- 휴대폰: 진동 → 뒤집음 → 전화 → 통화 유지 → 세면대에 남음
- 신발: 보임 → 미세하게 움직임 → 그대로 남음
- 공식 언어: 화착 → 확인 중 → 복귀 예정 → 보호조치 → 이석 초과 → 미복귀 → 미응답 → 상태만

이 경로가 실제 판본에서 모두 충분히 작동했는지는 별도 판본 독해·실연 증거로 다시 확인해야 한다.

#### “인물이 더 행동해야 한다”

- **관찰할 증상:** A·B의 시도와 보류가 객석에서 보이지 않거나 아무 후속 비용도 만들지 않는가.
- **그대로 따른 처방의 비용:** 문 강제 개방, 휴대폰 탈취, 몸싸움은 비접촉의 관계 구조를 다른 작품으로 바꿀 수 있다.
- **번역한 질문:** 잠그지 못함, 끊지 못함, 문고리를 잡지 못함, 닿지 못함이 구체적 동작과 다음 관계 비용으로 보이는가.

미수라는 이유만으로 보존하지 않는다. 배우가 수행할 행동 동사, 객석의 시야, 앞뒤 물성 상태가 있어야 한다.

#### “결말의 선택이 더 선명해야 한다”

- **관찰할 증상:** 마지막의 물리 상태와 관계 결과까지 불분명한가, 아니면 미래의 의미만 열려 있는가.
- **그대로 따른 처방의 비용:** 누가 버튼을 누르고 C가 나오는지를 확정하면 작품이 쌓은 지속의 시간이 사라질 수 있다.
- **번역한 질문:** 신발·물·휴대폰·통화·콜 적체 알람이 앞선 행동의 결과로 남아 관객의 시간을 되돌려 주는가.

남는 물성과 큐가 실제로 보이고 들리는지는 R3·R4 대상이다. 텍스트의 의도만으로 결말의 힘을 승인하지 않는다.

#### “설명이 더 필요하다”

- **관찰할 증상:** 관객이 현재 행동을 이해하는 데 필요한 콜센터 규칙·관계·공간 조건이 누락됐는가.
- **처방 번역:** C의 심리와 전사를 설명하기 전에 안내문, 메신저, 시간 초과, 문과 칸의 상태가 객석에서 읽히는지 본다.
- **보호 한계:** 배우가 딛는 사실까지 비어 있거나 물리·절차·큐가 모순이면 해석적 열림으로 보호하지 않는다.

### 6.3 당시의 수정 방향

1. 사건을 자동으로 키우지 않고 공식 언어의 침투 리듬을 먼저 점검한다.
2. A·B의 직접 충돌을 자동 추가하지 않고, 닿지 못하는 거리와 거울 속 마주침이 실제 행동 비용을 만드는지 본다.
3. C의 상태를 전사로 해설하기 전에 못 잠그는 물, 못 잡는 문고리, 못 끊는 전화의 수행 경로를 확인한다.
4. 엔딩의 선택을 자동 확정하지 않고 통화·물소리·알람의 지속이 앞선 시간으로 획득됐는지 시험한다.
5. 후반의 주제어가 장면을 바꾸는 직접 발화인지, 이미 보인 뜻을 요약하는지 구분한다.

### 6.4 현재판에 재사용하는 법

후속판에 이 결론을 복사하지 않는다.

1. 정확한 `target_revision`을 고정한다.
2. v5·v7·v8과 달라진 장면·물성·결말을 delta review한다.
3. 현재 엔진과 작품 동일성 계약을 다시 읽는다.
4. PAP-1 호출 조건 세 가지를 새로 판정한다.
5. 해당하는 질문만 C3 승인 봉투 안에 넣는다.

현재판이 직접 행동·접촉·단절·닫힌 결말을 새로 획득했다면 그것을 구판 미학에 맞추기 위해 되돌리지 않는다.

## 8. 빠른 실행 카드

피드백 하나마다 다음 열 문장만 확인한다.

1. 어느 revision에 대한 말인가.
2. 실제 반응과 관찰된 증상은 무엇인가.
3. 원인 추정과 제안된 처방은 무엇인가.
4. 본문의 어느 위치에서 재현되는가.
5. 현재 증거 등급으로 말할 수 있는가.
6. `[약·물]`은 무엇이며 상세 카드를 펼쳐야 하는가.
7. 작품 동일성 계약과 보호 자산을 건드리는가.
8. `수용 / 증상수용_처방번역 / 제한시험 / 보류 / 기각 / 구조개작_후보` 중 무엇이며 어디로 보내는가.
9. 가장 싼 가역 시험은 무엇인가.
10. 수정 뒤 같은 증상이 줄고 어떤 부작용이 생겼는가.

## 9. 오용 방지

### 9.1 외부 피드백을 무력화하는 방패로 쓰지 않는다

“다른 문법의 강요”라는 판정은 마지막 단계다. 먼저 지적된 위치, 정보 누락, 반복 기능, 행동 비용을 재현한다.

### 9.2 외부 피드백을 작품보다 높은 명령으로 쓰지 않는다

구체적 불편함이 맞아도 큰 사건·직접 충돌·설명 대사·닫힌 결말이 유일한 해법은 아니다.

### 9.3 모호함을 한 덩어리로 보지 않는다

- 물리·동선·절차·큐의 불명료함
- 관계·행동 조건의 정보 누락
- 늦게 밝혀지는 전사·진위
- 끝까지 열리는 윤리·의미

앞의 두 층을 뒤의 두 층으로 변호하지 않는다.

### 9.4 취향과 위험을 구분한다

안전·권리·물리적 상연 불가능은 미학적 취향 경합이 아니다. P0로 우선 처리한다.

### 9.5 한 작품의 성공을 교리로 올리지 않는다

한 작품에서 유효했던 번역은 사례 또는 `provisional` 프로필이다. 서로 다른 두 작품 이상에서 반복되고 반례 시험을 통과하기 전에는 작가 전체의 안정 규칙으로 승격하지 않는다.

## 10. v1에서 보존·변경한 문장

| v1의 핵심 | v2.0 처리 |
|---|---|
| “일반적 피드백이 가리키는 불편함을 부정하지 않는다. 다만 그 해결책을 내 문법 안에서 찾는다.” | **보존.** 이 문서의 보편 핵심 원칙 |
| “내 희곡은 덜 하는 극이 아니라, 덜어낸 자리가 정확히 작동해야 하는 극이다.” | **조건부 보존.** 덜어냄을 선택한 작품에서만 쓰는 진단 문장 |
| 사건은 압력으로 쌓인다 | **PAP-1로 이동.** 보편 엔진이 아님 |
| 행동은 결정이 아니라 미수로 보인다 | **PAP-1로 이동·수정.** 비용을 만드는 미수만 해당 |
| 결말은 선택이 아니라 지속으로 남는다 | **PAP-1로 이동·수정.** 선택·단절·해결과 우열 없음 |
| 갈등은 제도 언어와 개인 언어 사이에서 생긴다 | **「콜센터」 사례와 선택 수법으로 제한** |
| 모든 작품의 중심 질문은 같다 | **삭제.** 반복 관심과 작품별 중심 가설을 분리 |
| 고정 번역 체크리스트 | **가변 절차로 교체.** 현재 엔진·계약·증거에 따라 경로 선택 |

## 오래 남길 문장

> 피드백의 불편함과 피드백 제공자의 해결책은 같은 것이 아니다.

> 작품의 의도를 방패로 삼아 증상을 지우지 않고, 증상을 이유로 작품의 계약을 몰래 바꾸지 않는다.

> 좋은 번역은 작품을 익숙한 정상형으로 고치는 일이 아니라, 현재 판본에서 무엇이 실제로 작동하지 않는지를 가장 싼 증거로 확인하는 일이다.
