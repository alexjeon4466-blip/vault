# 전용수 × 히라타 — 통합 극작 노트

> 향후 희곡 초고·개작·퇴고에서 기본 기준으로 삼는 통합 지침. 히라타 오리자의 작법은 그대로 채택하는 규범이 아니라, 내 희곡 미학 안으로 번역해 사용하는 진단 도구다.

## 한 줄 핵심

> **히라타로 대사가 발생할 조건을 만들고, 전용수 원칙으로 그 위에서 무엇을 비우고 무엇을 남길지 정한다.**  
> 히라타는 장소·문제·정보 차이·구체소재를 세우는 기술이고, 내 미학은 규정 불가능한 존재가 규정의 압력 안에서 어떻게 자기를 유지하는지를 다루는 좌표다.

## 이 노트의 위키 내 역할

이 문서는 다음 작업의 **상위 기준 문서**로 쓴다.

- 새 희곡 씨앗을 초고 후보로 압축할 때
- 단막 구조를 짤 때
- 초고/개작본에서 설명 대사를 덜어낼 때
- 합평·AI·심사 피드백을 내 문법 안에서 번역할 때
- 히라타식 체크리스트가 내 미학과 충돌하는 것처럼 보일 때

## 1. 공유 척추 — 이미 같은 방향인 지점

히라타 프레임워크의 많은 부분은 내 희곡의 기본 미학과 같은 방향을 가리킨다. 따라서 다음 항목은 거의 그대로 받아들여도 된다.

| 히라타의 도구 | 내 미학으로 번역 | 사용 방식 |
|---|---|---|
| 테마를 설명하지 말 것 | 덜 말하기 | 작품이 말하려는 질문을 인물이 정리하지 않게 한다. |
| 반공간/세미퍼블릭 장소 | 공식 언어 vs 사적 언어 | 병원, 콜센터, 창구, 면담실, 회의실, 양식 화면처럼 말의 자격이 바뀌는 장소를 만든다. |
| 배경은 틈으로 드러낼 것 | 말하지 못함과 부재 | 과거/관계를 해설하지 않고 물건 상태, 부재자, 기록의 빈칸으로 드러낸다. |
| 작은 문제가 절차를 만든다 | 구조적 부조리 | “이 말은 어디에 기록되는가”, “이 사람은 어느 칸에 들어가는가” 같은 작은 절차가 극을 밀게 한다. |
| 구체소재가 행동을 밀어낸다 | 무대화 가능성 / 지문 영역 | 컵·약봉지·이름표·입력칸·헤드셋·서류가 말보다 먼저 장면을 움직이게 한다. |
| 한 장면 한 문장 | 설명 덜어내기 | 무대가 보여준 것을 인물이 다시 말하지 않게 한다. |
| 플롯은 정보·권한 재배치 | 반복의 의미 축적 | 같은 절차가 반복될 때마다 누가 말하고 기록하고 판정하는지가 달라져야 한다. |
| 결말은 상태 변화 | 변하지 않는 엔딩 | 해결이 아니라 처리 완료, 저장 실패, 커서, 남은 물건 같은 무대 상태로 닫는다. |

요점은 단순하다. **히라타식 퇴고의 상당 부분은 내 원칙을 다른 어휘로 말한 것이다.** 특히 후반부의 잉여 대사, 관객이 이미 본 것을 다시 설명하는 문장, 화면/오브제가 이미 수행한 의미를 인물이 정리하는 자리는 적극적으로 솎는다.

## 2. 히라타만으로는 부족한 전용수식 추가 원칙

히라타 체크리스트를 기계적으로 적용하면 내 희곡이 평평해질 수 있다. 다음 여덟 지점은 별도 보정이 필요하다.

### 2.1 범람 — 통제된 과잉

히라타의 기본 반응은 말을 줄이는 쪽이다. 하지만 내 희곡에서는 어떤 순간 사적 언어가 공식 양식을 **넘쳐흘러야** 한다. 그 넘침 자체가 공식 언어와 사적 언어의 충돌을 몸으로 보여주기 때문이다.

판단 기준은 하나다.

> 이 말은 테마를 **해설**하는가, 아니면 인물이 양식을 **넘치는 것을 수행**하는가?

- **수행이면 유지한다.** 인물이 칸·절차·요약·글자 수 제한을 실제로 넘치고 있는 말은 남긴다.
- **해설이면 삭제한다.** 화면/오브제/상태값이 이미 보여준 것을 인물이 정리하는 말은 줄인다.

범람은 아무 데서나 허용되지 않는다. 곡선이 있어야 한다.

> 자유 → 측정 → 절삭 → 자기검열 → 잔해

즉 처음에는 사람이 많이 말하지만, 점점 외부의 절차가 안으로 들어와 인물이 스스로 말의 길이와 형태를 자르기 시작해야 한다.

### 2.2 변하지 않는 엔딩의 미완성

히라타의 “처리 완료 / 상태 변화” 엔딩은 유용하다. 다만 내 결말은 거기서 한 걸음 더 간다.

> 닫지 않음을 닫는다.

마지막 문장은 완성되지 않을 수 있고, 커서는 깜빡일 수 있으며, 저장은 실패할 수 있다. 결말은 해결이 아니라 **상태 변화 + 해결 유보**다.

### 2.3 정보 차이와 두 축은 다르다

히라타의 정보 차이는 “누가 무엇을 알고/모르는가”를 보는 도구다. 여기에 내 작업에서는 두 축을 추가한다.

- 화면 축 ↔ 오브제 축
- 현재 절차 ↔ 과거 기억
- 입력 ↔ 회상
- 공식 기록 ↔ 사적 잔여

정보 차이가 대사를 발생시킨다면, 두 축은 서로를 조명하거나 배반한다. 장면을 짤 때 둘을 따로 본다.

### 2.4 알레고리는 상징보다 공식 언어의 정확성으로

알레고리적 외피가 있는 작품에서 이중 독해의 통로는 거대한 상징이 아니라 **행정·제도 언어의 정확한 인용**이다.

나쁜 방향:

- “이 집은 사회의 축소판이다.”
- “이 양식은 인간을 지우는 상징이다.”

좋은 방향:

- `관계 설명란`
- `보완 요청`
- `특이사항 없음`
- `접수 완료`
- `관련 없음`
- `저장되지 않았습니다`

알레고리는 설명하지 않고, 정확한 공식 문구로 작동해야 한다.

### 2.5 명명 불가의 추상화

히라타는 인물을 기능으로 익명화한다. A/B/C, 중심/중간/외부 같은 위치의 익명성이다. 내 작업에서는 여기에 **규정 불가능성을 수행하는 추상화**가 더해진다.

점검할 세 층:

1. 등장인물 표기
2. 인물의 자기 진술
3. 시스템의 호명 방식

이 세 층이 서로 어긋나거나, 일관되게 이름 없음/분류 불가능성을 수행해야 한다.

### 2.6 시스템은 발화보다 상태로

시스템·화면·기계가 사람처럼 대사를 말하는 장치를 기본값으로 삼지 않는다. 장면의 말은 가능한 한 **사람 사이의 정보 차이와 책임 회피**에서 발생시킨다.

- 시스템의 압력은 표시등, 무응답, 문구, 남은 숫자, 작동음, 물건의 잠김·열림·멈춤처럼 보이거나 들리는 **상태**로 먼저 만든다.
- 공식 언어가 필요하면 정확한 문구를 화면·종이·라벨로 보여줄 수 있으나, 그것을 자동 음성의 긴 대사로 바꾸지 않는다.
- 시스템 발화는 금지가 아니라 예외다. 사람의 말로 대체할 수 없고, 그 목소리 자체가 특정 관계 비용을 만들 때만 사용한다.
- 시스템이 설명해야만 관객이 장면을 이해한다면, 먼저 장소·행동·오브제의 가독성이 부족한지 점검한다.

### 2.7 설정과 장치는 단순하게

복잡한 세계관·다단계 규칙·다수의 장치를 연극성으로 오인하지 않는다. 기본값은 **한 장소, 지금 처리할 작은 문제 하나, 소수 인물, 배우가 실제로 다룰 수 있는 사물 몇 개**다.

- 장치를 추가하기 전에 기존 사물의 위치·무게·소리·사용 순서만으로 압력이 커지는지 본다.
- 규칙은 관객이 한 번의 행동으로 이해할 수 있게 만들고, 설명을 위해 또 다른 장치를 발명하지 않는다.
- 복잡성 자체가 다른 사람에게 구체적 비용을 넘기는 경우에만 복잡한 설정을 허용한다.
- 단순함은 사건의 빈곤이 아니라, 한 행동의 결과를 객석이 놓치지 않게 하는 집중이다.

### 2.8 아이러니를 장면 생성 엔진으로

아이러니는 재치 있는 대사나 마지막 반전이 아니라, 인물이 합리적으로 문제를 해결하려 할수록 **반대 상태가 실제로 생기는 과정**이다.

- 확인하려 할수록 대상이 확인할 수 없는 상태가 된다.
- 자리를 만들수록 다른 문이나 통로가 닫힌다.
- 사용하지 않은 상태를 지키려 할수록 더 많은 사람이 물건을 만진다.
- 쉬기 위한 시간을 정하려 할수록 휴식이 새 일정과 업무가 된다.

아이러니가 행동으로 보였다면 인물이 그 역설을 요약하지 않는다. 결말은 교훈이나 통쾌한 폭로보다, 해결 행동이 만들어 낸 반대의 물리 상태를 남긴다.

## 3. 히라타가 내 작업에 주는 실전 도구

내 미학은 무엇을 지킬지 알려주지만, 히라타는 어디가 약한지 진단하는 표를 준다.

### 3.1 정보 차이 표

| 인물/장치 | 아는 것 | 모르는 것 / 부정하는 것 | 가진 권한 |
|---|---|---|---|
| 중심 인물 |  |  |  |
| 중간 인물 |  |  |  |
| 권한자 |  |  |  |
| 시스템/양식/공간 |  |  |  |
| 부재자/목소리/사물 |  |  |  |

이 표는 대사가 실제 정보 차이에서 발생하는지, 아니면 작가가 주제를 전달하려고 발생하는지 확인하는 데 쓴다.

### 3.2 인물 위치 렌즈

- **중심**: 압력을 직접 받는 사람.
- **중간**: 내부자이지만 흔들릴 여지가 있는 사람.
- **외부/권한자**: 다른 기준과 기록 권한을 가진 사람.
- **비인간 권력**: 칸·규칙·상태값을 정하는 장치.
- **부재한 외부자**: 몸은 없지만 모든 대화 조건을 흔드는 사람/목소리/물건.

1인극에도 적용한다. 한 인물만 있어도 시스템, 죽은 사람, 화면, 컵, 저장음이 서로 다른 위치를 가질 수 있다.

### 3.3 플롯 표

| 장면 | 겉 사건 | 정보 이동 | 권한 이동 | 남는 물성/상태 |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 결말 |  |  |  |  |

사건은 많은데 권한 위치가 바뀌지 않으면 장면은 반복처럼 느껴진다. 반대로 사건이 작아도 정보/권한/물성이 이동하면 플롯은 진행된다.

### 3.4 반응적 퇴고 순서

대사가 설명적으로 느껴질 때 문장을 먼저 고치지 않는다. 아래 순서로 조건을 본다.

1. 장소가 약한가.
2. 지금 처리해야 할 작은 문제가 약한가.
3. 정보 차이가 약한가.
4. 구체소재가 약한가.
5. 그래도 필요한 대사인가.
6. 범람이 수행인가 해설인가.
7. 결말이 해결을 유보하는 상태 변화인가.

## 4. 적용 순서와 핵심 긴장

### 4.1 범람 vs 최소화 — 수행이냐 해설이냐

내 희곡에서 침묵과 범람은 반대가 아니다. 둘 다 공식 언어가 사적 언어를 포착하지 못하는 순간을 보여주는 방식이다.

- 침묵: 말이 들어갈 칸이 없어서 남는 것.
- 범람: 칸보다 말이 커서 넘치는 것.

둘의 공통 기준은 “해설하지 않는다”이다. 침묵도, 범람도 장면 안에서 수행되어야 한다.

### 4.2 체크리스트 vs 직관

체크리스트는 모든 문장을 미리 검열하는 규칙이 아니다.

> 체크리스트는 이미 걸리는 지점을 진단하는 도구다.

- 직관이 “걸린다”고 신호할 때: 체크리스트로 장소·문제·정보 차이·구체소재 중 무엇이 약한지 본다.
- 직관이 “작동한다”고 말할 때: 원칙 위반처럼 보여도 함부로 깎지 않는다.

질문 방식도 바꾼다.

- 나쁜 질문: “이 원칙을 위반했는가?”
- 좋은 질문: “이 지점은 원칙과 긴장하지만, 의도된 선택인가?”

### 4.3 적용 순서 — 무원칙 독해 뒤에 작가 가설을 쓴다

작품을 처음 읽을 때는 히라타·전용수·공모 규격을 잠시 내려놓는다. 먼저 이 작품이 이미 발명한 것을 적는다.

1. **작품의 약속** — 관객에게 어떤 종류의 시간을 견디게 하거나 기대하게 하는가.
2. **가장 강한 이미지와 행동** — 설명 없이도 남는 몸·사물·소리·공간 변화는 무엇인가.
3. **온도와 리듬** — 건조함, 희극성, 범람, 침묵, 비약 중 무엇이 이 작품의 호흡인가.
4. **장면 생성 원리** — 기존 작품군에 없던 방식으로 다음 장면을 낳는 규칙은 무엇인가.

이 네 항목을 보호한 뒤에만 이 노트의 작가 프로필을 적용한다.

> 전용수식 문법은 새 작품을 판정하는 법이 아니라, 반복해서 유효했던 선택을 시험하는 **기본 가설**이다.

따라서 다음은 자동 결함이 아니다.

- 직접 고백
- 시간 비약과 다장면
- 큰 사건과 돌이킬 수 없는 선택
- 심리와 전기가 두꺼운 인물
- 이름을 가진 인물
- 닫힌 결말 또는 명시적 단절

이 요소가 실제 행동을 만들고, 정보·권한·관계·위험·대가를 바꾸며, 작품 고유의 약속을 수행한다면 보호한다. 반대로 작동하지 않는다는 근거 없이 `전용수답지 않다`는 이유만으로 삭제하지 않는다.

### 4.4 모호함의 층위와 자기복제 점검

의미를 열어두는 것과 공연 조건을 흐리는 것은 다르다. 세 층을 분리한다.

1. **지금 명확해야 하는 것** — 누가 무엇을 하며, 무엇이 그것을 방해하고, 실패하면 무대 상태가 어떻게 달라지는가.
2. **늦게 밝혀도 되는 것** — 전사, 동기, 관계의 기원, 어떤 말의 진위.
3. **끝까지 열어둘 수 있는 것** — 인물의 윤리적 의미, 관계의 최종 이름, 잔여 이미지의 해석.

객석에서 손·빛·글씨·소리·동선이 보이지 않는 상태를 `의도된 모호함`으로 정당화하지 않는다. 물리와 절차는 정확하게, 의미는 필요한 만큼 열어둔다.

또한 다음 결합이 새 작품의 자동 공식이 되지 않았는지 본다.

> 규정 집행자 + 분류되지 않는 사람 + 없는 항목 + 실무자의 작은 공모 + 사물의 잔여 + 조용한 미결

이 조합 자체가 금지는 아니다. 다만 반복될 때는 다음을 묻는다.

- 이번 작품만의 장면 생성 원리는 무엇인가.
- 제도 대리인의 작은 인간화 없이도 끝이 성립하는가.
- 주제를 운반하지 않는 생활 사물과 우발성이 있는가.
- 부재자를 실제로 등장시키거나, 규정하는 사람과 규정받는 사람을 한 인물 안에 둘 수 있는가.
- 미결이 아니라 단절·실패·선택·희극적 종결이 더 정확하지 않은가.

## 5. 통합 체크리스트

초고 전, 개작 전, 장면 퇴고 때 아래 순서로 본다. **0항은 항상 수행하고, 1–9항은 작품이 실제로 선택한 문법에 해당하는 렌즈만 고른다.** 반공간·작은 절차·공식 언어·명명 불가·미결 엔딩이 없다는 사실만으로 결함 판정을 내리지 않는다.

### 0. 적용 전 보호

- [ ] 원칙 없이 먼저 읽고 이 작품의 약속을 한 문장으로 적었는가?
- [ ] 가장 강한 이미지·행동, 온도·리듬, 새 장면 생성 원리를 기록했는가?
- [ ] 기존 작품 문법과 다른 선택을 자동 결함으로 취급하고 있지 않은가?
- [ ] 이 장면은 테마를 설명하는가, 아니면 조건이 대화를 발생시키는가?
- [ ] 의미의 모호함을 지키면서도 배우의 행동·방해·실패 후 상태는 명확한가?

### 1. 장소 — 반공간

- [ ] 완전히 사적이지도 공적이지도 않은 압력이 있는가?
- [ ] 그 압력이 공식 언어와 사적 언어의 충돌을 만드는가?
- [ ] 장소를 옮기면 대화가 무너지는가?

### 2. 배경 — 틈으로

- [ ] 배경을 설명하지 않고 틈·부재·물건 상태로 드러내는가?
- [ ] “사실은…”으로 장면이 시작하거나 해결되지 않는가?

### 3. 문제 — 작은 절차

- [ ] 장면을 끄는 작은 질문이 실제 절차로 연결되는가?
- [ ] 그 절차가 악인이 아니라 시스템의 잔인함을 드러내는가?

### 4. 정보 차이 + 두 축

- [ ] 인물/장치별 아는 것, 모르는 것, 권한을 분리했는가?
- [ ] 누가 기록·판정·요약하는가?
- [ ] 시스템 대리인이 단순 악인이 아니라 분열된 인간으로 남는가?
- [ ] 화면↔오브제, 현재↔과거, 입력↔회상이 어디서 만나고 어긋나는가?

### 5. 인물 위치 + 명명

- [ ] 중심/중간/권한자/비인간/부재자가 각각 대화를 흔드는가?
- [ ] 인물 표기, 자기 진술, 시스템 호명이 명명 불가를 일관되게 수행하는가?

### 6. 구체소재

- [ ] 인물이 만지고 입력하고 옮기는 소재가 있는가?
- [ ] 그 소재가 본론을 직접 말하지 않게 하는 우회로인가?
- [ ] 소재의 위치나 상태가 후반에 달라지는가?
- [ ] 지문은 보이거나 들리는 행동·사운드·조명·오브제에 머무는가?

### 7. 대사 — 한 장면 한 문장 + 범람 시험

- [ ] 무대/화면이 이미 보여준 것을 다시 말하지 않는가?
- [ ] 좋은 문장이 너무 많아 서로 힘을 나눠 갖지 않는가?
- [ ] 넘치는 말은 수행인가 해설인가?
- [ ] 인물의 자기 인식·공모·죄책감까지 해설로 오인해 깎고 있지는 않은가?

### 8. 플롯

- [ ] 사건 나열이 아니라 정보·권한 재배치로 진행되는가?
- [ ] 반복되는 절차가 매번 다른 권력관계를 만드는가?
- [ ] 결말은 해결이 아니라 무대 상태 변화와 해결 유보로 닫히는가?

### 9. 알레고리

- [ ] 이중 독해가 추상 상징이 아니라 정확한 공식 언어로 작동하는가?

## 6. 「설명란 부족」에서의 적용 예

이 통합 기준이 실제로 작동한 사례는 [[wiki/writing/notes/설명란_부족|설명란 부족]]이다.

- **반공간**: 행정 신청 양식. 사적 기억이 공식 칸으로 번역되는 장소다.
- **문제**: “이 사람은 어느 칸/몇 글자에 들어가는가.” 관계 선택, 50자 설명, 증빙, 필수 항목이 장면을 밀어낸다.
- **정보 차이**: 시스템은 관계명·글자 수·접수 가능 여부를 알고, 사람은 그 사람이 누구였는지를 안다. 둘은 만나지 못한다.
- **인물 위치**: 사람은 중심, 양식은 비인간 권력, 죽은 사람은 컵·물컵·약봉지로만 남은 부재자다.
- **구체소재**: 컵 손잡이, 물컵, 접힌 약봉지가 말 대신 관계를 보존한다.
- **범람 곡선**: 자유롭게 말하기 → 글자 수 측정 → 기계적 절삭 → 자기검열 → 미완성 잔해.
- **삭제 기준**: 화면이 이미 보여주는 `동거 관계 / 설명란 부족`을 인물이 다시 말하면 해설이므로 침묵으로 낮춘다.
- **엔딩**: “설명란만으로는—”이 끝나지 않고, 물컵 위치와 저장 실패만 남는다. 상태 변화 + 해결 유보다.

## 7. 앞으로의 기본 지침

1. **작품을 먼저 읽는다.** 작가 문법을 대기시키고, 이번 작품의 약속·이미지·온도·장면 생성 원리를 먼저 적는다.
2. **히라타로 조건을 점검한다.** 장소, 문제, 정보 차이, 구체소재가 필요한 행동을 실제로 만드는지 본 뒤 대사를 고친다.
3. **내 미학은 가설로 적용한다.** 무엇을 비우고 무엇을 남길지 제안하되, 작품이 새로 발명한 문법을 기존 습관으로 교정하지 않는다.
4. **공식 언어와 사적 언어의 충돌은 반복 축이지 의무 소재가 아니다.** 이번 작품이 그 축을 선택했다면 칸·절차·호명·상태값을 정확하게 만든다.
5. **범람과 침묵을 모두 시험한다.** 말의 길이가 아니라 장면 안의 수행인지 주제 해설인지로 판정한다.
6. **절차극이라면 절차는 작게, 압력은 크게 만든다.** 절차가 없는 작품에 행정 장치를 새로 발명해 넣지는 않는다.
7. **결말은 작품의 약속에 맞는 상태로 닫는다.** 잔여와 미결뿐 아니라 단절·실패·선택·희극적 종결도 정확하면 보호한다.
8. **체크리스트는 직관을 대체하지 않는다.** 작동하는 순간을 체계 때문에 죽이지 말고, 걸리는 순간을 체계로 진단한다.
9. **시스템은 기본적으로 말하지 않는다.** 문구·빛·숫자·작동음·멈춘 사물의 상태로 압력을 만들고, 자동 음성은 그 목소리 자체가 관계 비용을 만들 때만 예외적으로 쓴다.
10. **설정과 장치는 단순하게 시작한다.** 한 장소·작은 문제·소수 인물·몇 개의 사물로 먼저 쓰고, 복잡성은 실제 비용을 옮길 때만 허용한다.
11. **아이러니는 행동의 반대 결과로 만든다.** 합리적인 해결 행동이 반대의 무대 상태를 만들게 하고, 그 역설을 대사로 정리하지 않는다.

## 작업 적용 메모

이후 희곡 작업에서 “히라타식으로 보자”는 말은 **무조건 줄이자**가 아니라 다음 뜻으로 사용한다.

> 대사가 설명적으로 느껴지는 지점을 문장 차원에서 바로 고치지 말고, 장소·문제·정보 차이·구체소재·범람 곡선·엔딩 상태를 차례로 점검한다.

그리고 “내 미학으로 보자”는 말은 다음 뜻으로 사용한다.

> 이번 작품이 실제로 선택한 압력을 먼저 확인한 뒤, 규정될 수 없는 존재·공식 언어와 사적 언어의 충돌·미결의 지속·비접촉의 거리·사물과 소리의 잔여가 작동하는 지점만 가설로 점검한다. 작품이 그 문법을 선택하지 않았다면 새로 발명해 넣지 않는다.
