# 전용수 × 히라타 — 통합 극작 노트

> 향후 희곡 초고·개작·퇴고에서 기본 기준으로 삼는 통합 지침. 히라타 오리자의 작법은 그대로 채택하는 규범이 아니라, 내 희곡 미학 안으로 번역해 사용하는 진단 도구다.

## 한 줄 핵심

> **히라타로 대사가 발생할 조건을 만들고, 전용수 원칙으로 그 위에서 무엇을 비우고 무엇을 남길지 정한다.**  
> 히라타는 장소·문제·정보 차이·구체소재를 세우는 기술이고, 내 미학은 규정 불가능한 존재가 규정의 압력 안에서 어떻게 자기를 유지하는지를 다루는 좌표다.

## 이 노트의 위키 내 역할

> **지위 (2026-08-17 강등).** 이 문서는 작가의 **서명 렌즈**이지 상위 교리가 아니다. [[wiki/writing/aesthetics/집필_파이프라인|집필 파이프라인]] §B2-3과 §5는 전용수 계열 모듈을 "작가의 중요한 서명이지만 모든 작품의 보편 법칙은 아니다. 보호 기록과 현재 선택한 엔진이 **호출할 때만** 적용한다"로 규정한다. 이 문서를 근거로 다른 문법의 작품을 감점하지 않는다. 상태·판본·증거·약속 판정·형식은 frontmatter의 `does_not_govern`을 따른다.
>
> 초판은 자신을 "상위 기준 문서"로 선언했고 제동 장치가 없었다. 실제 위험은 §7-6의 결말 조항이었다 — 아래에 별도 주를 달았다.

이 문서는 다음 작업에서 **호출되는 렌즈**로 쓴다.

- 새 희곡 씨앗을 초고 후보로 압축할 때
- 단막 구조를 짤 때
- 초고/개작본에서 설명 대사를 덜어낼 때
- 합평·AI·심사 피드백을 내 문법 안에서 번역할 때
- 히라타식 체크리스트가 내 미학과 충돌하는 것처럼 보일 때

관련 실행 노트:

- 이론 요약: [[wiki/writing/notes/히라타_오리자_연극입문_1-3장_요약과_적용|히라타 오리자 『연극 입문』 1–3장 — 요약과 적용]]

## 1. 공유 척추 — 이미 같은 방향인 지점

히라타 프레임워크의 많은 부분은 내 희곡의 기본 미학과 같은 방향을 가리킨다. 따라서 다음 항목은 거의 그대로 받아들여도 된다.

| 히라타의 도구 | 내 미학으로 번역 | 사용 방식 |
|---|---|---|
| 테마를 설명하지 말 것 | 덜 말하기 | 작품이 말하려는 질문을 인물이 정리하지 않게 한다. |
| 반공간/세미퍼블릭 장소 | 공식 언어 vs 사적 언어 | 병원, 콜센터, 창구, 면담실, 회의실, 양식 화면처럼 말의 자격이 바뀌는 장소를 만든다. |
| 배경은 틈으로 드러낼 것 | 말하지 못함과 부재 | 과거/관계를 해설하지 않고 물건 상태, 부재자, 기록의 빈칸으로 드러낸다. |
| 작은 문제가 절차를 만든다 | 구조적 부조리 | “이 말은 어디에 기록되는가”, “이 사람은 어느 칸에 들어가는가” 같은 작은 절차가 극을 밀게 한다. |
| 구체소재가 행동을 밀어낸다 | 무대화 가능성 / 지문 영역 | 컵·약봉지·이름표·입력칸·헤드셋·서류가 말보다 먼저 장면을 움직이게 한다. |
| 현실의 리얼과 연극의 리얼은 다르다 | 연극적 약속 / 최소 충분 실제성 | 전 공정을 복제하지 않고 관객의 판단을 만드는 인과와 물성만 실제에 가깝게 남긴다. |
| 한 장면 한 문장 | 설명 덜어내기 | 무대가 보여준 것을 인물이 다시 말하지 않게 한다. |
| 플롯은 정보·권한 재배치 | 반복의 의미 축적 | 같은 절차가 반복될 때마다 누가 말하고 기록하고 판정하는지가 달라져야 한다. |
| 결말은 상태 변화 | 변하지 않는 엔딩 | 해결이 아니라 처리 완료, 저장 실패, 커서, 남은 물건 같은 무대 상태로 닫는다. |

요점은 단순하다. **히라타식 퇴고의 상당 부분은 내 원칙을 다른 어휘로 말한 것이다.** 특히 후반부의 잉여 대사, 관객이 이미 본 것을 다시 설명하는 문장, 화면/오브제가 이미 수행한 의미를 인물이 정리하는 자리는 적극적으로 솎는다.

## 2. 히라타만으로는 부족한 전용수식 추가 원칙

히라타 체크리스트를 기계적으로 적용하면 내 희곡이 평평해질 수 있다. 다음 다섯 지점은 별도 보정이 필요하다.

### 2.1 범람 — 통제된 과잉

히라타의 기본 반응은 말을 줄이는 쪽이다. 하지만 내 희곡에서는 어떤 순간 사적 언어가 공식 양식을 **넘쳐흘러야** 한다. 그 넘침 자체가 공식 언어와 사적 언어의 충돌을 몸으로 보여주기 때문이다.

판단 기준은 하나다.

> 이 말은 테마를 **해설**하는가, 아니면 인물이 양식을 **넘치는 것을 수행**하는가?

- **수행이면 유지한다.** 인물이 칸·절차·요약·글자 수 제한을 실제로 넘치고 있는 말은 남긴다.
- **해설이면 삭제한다.** 화면/오브제/상태값이 이미 보여준 것을 인물이 정리하는 말은 줄인다.

범람은 아무 데서나 허용되지 않는다. 곡선이 있어야 한다.

> 자유 → 측정 → 절삭 → 자기검열 → 잔해

즉 처음에는 사람이 많이 말하지만, 점점 외부의 절차가 안으로 들어와 인물이 스스로 말의 길이와 형태를 자르기 시작해야 한다.

### 2.2 변하지 않는 엔딩의 미완성

히라타의 “처리 완료 / 상태 변화” 엔딩은 유용하다. 다만 내 결말은 거기서 한 걸음 더 간다.

> 닫지 않음을 닫는다.

마지막 문장은 완성되지 않을 수 있고, 커서는 깜빡일 수 있으며, 저장은 실패할 수 있다. 결말은 해결이 아니라 **상태 변화 + 해결 유보**다.

### 2.3 정보 차이와 두 축은 다르다

히라타의 정보 차이는 “누가 무엇을 알고/모르는가”를 보는 도구다. 여기에 내 작업에서는 두 축을 추가한다.

- 화면 축 ↔ 오브제 축
- 현재 절차 ↔ 과거 기억
- 입력 ↔ 회상
- 공식 기록 ↔ 사적 잔여

정보 차이가 대사를 발생시킨다면, 두 축은 서로를 조명하거나 배반한다. 장면을 짤 때 둘을 따로 본다.

### 2.4 알레고리는 상징보다 공식 언어의 정확성으로

알레고리적 외피가 있는 작품에서 이중 독해의 통로는 거대한 상징이 아니라 **행정·제도 언어의 정확한 인용**이다.

나쁜 방향:

- “이 집은 사회의 축소판이다.”
- “이 양식은 인간을 지우는 상징이다.”

좋은 방향:

- `관계 설명란`
- `보완 요청`
- `특이사항 없음`
- `접수 완료`
- `관련 없음`
- `저장되지 않았습니다`

알레고리는 설명하지 않고, 정확한 공식 문구로 작동해야 한다.

### 2.5 명명 불가의 추상화

히라타는 인물을 기능으로 익명화한다. A/B/C, 중심/중간/외부 같은 위치의 익명성이다. 내 작업에서는 여기에 **규정 불가능성을 수행하는 추상화**가 더해진다.

점검할 세 층:

1. 등장인물 표기
2. 인물의 자기 진술
3. 시스템의 호명 방식

이 세 층이 서로 어긋나거나, 일관되게 이름 없음/분류 불가능성을 수행해야 한다.

## 3. 히라타가 내 작업에 주는 실전 도구

내 미학은 무엇을 지킬지 알려주지만, 히라타는 어디가 약한지 진단하는 표를 준다.

### 3.1 정보 차이 표

| 인물/장치 | 아는 것 | 모르는 것 / 부정하는 것 | 가진 권한 |
|---|---|---|---|
| 중심 인물 |  |  |  |
| 중간 인물 |  |  |  |
| 권한자 |  |  |  |
| 시스템/양식/공간 |  |  |  |
| 부재자/목소리/사물 |  |  |  |

이 표는 대사가 실제 정보 차이에서 발생하는지, 아니면 작가가 주제를 전달하려고 발생하는지 확인하는 데 쓴다.

### 3.2 인물 위치 렌즈

- **중심**: 압력을 직접 받는 사람.
- **중간**: 내부자이지만 흔들릴 여지가 있는 사람.
- **외부/권한자**: 다른 기준과 기록 권한을 가진 사람.
- **비인간 권력**: 칸·규칙·상태값을 정하는 장치.
- **부재한 외부자**: 몸은 없지만 모든 대화 조건을 흔드는 사람/목소리/물건.

1인극에도 적용한다. 한 인물만 있어도 시스템, 죽은 사람, 화면, 컵, 저장음이 서로 다른 위치를 가질 수 있다.

### 3.3 플롯 표

| 장면 | 겉 사건 | 정보 이동 | 권한 이동 | 남는 물성/상태 |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 결말 |  |  |  |  |

사건은 많은데 권한 위치가 바뀌지 않으면 장면은 반복처럼 느껴진다. 반대로 사건이 작아도 정보/권한/물성이 이동하면 플롯은 진행된다.

### 3.4 반응적 퇴고 순서

대사가 설명적으로 느껴질 때 문장을 먼저 고치지 않는다. 아래 순서로 조건을 본다.

1. 장소가 약한가.
2. 지금 처리해야 할 작은 문제가 약한가.
3. 정보 차이가 약한가.
4. 구체소재가 약한가.
5. 관객이 반드시 읽어야 할 물리적 인과가 선명한가.
6. 그 판단에 실제로 필요한 물성과 연극적으로 대표·압축할 부분이 구분되는가.
7. 그래도 필요한 대사인가.
8. 범람이 수행인가 해설인가.
9. 결말이 해결을 유보하는 상태 변화인가.

### 3.5 연극적 약속과 최소 충분 실제성

히라타가 말한 `현실의 리얼`과 `연극의 리얼`의 차이는 대사에만 적용되지 않는다. 무대의 사물·노동·공정·전환도 현실을 전면 복제해서가 아니라, 가공 세계 안의 절차와 순서를 관객이 납득할 때 리얼해진다.

> **현실과 다르다는 사실은 자동 결함이 아니다. 작품이 학습시킨 약속을 어기거나, 핵심 인과를 읽을 안전하고 반복 가능한 해법이 없을 때가 결함이다.**

물성과 동작은 네 층으로 나누어 본다.

| 층 | 먼저 물을 것 | 처리 |
|---|---|---|
| 서사 물리 | 무엇이 어디에 있고, 누가 무엇을 움직이며, 어떤 원인이 어떤 결과를 내는가 | 핵심 인과이면 본문에서 잠근다. |
| 지표 물리 | 관객의 추론을 만드는 무게·저항·소리·젖음·빛은 무엇인가 | 가능한 적은 핵심 물성만 실제에 가깝게 남긴다. |
| 제작 물리 | 선택한 해법이 안전하고 반복 가능하며 최악 시야석에서도 읽히는가 | 실물 시험·연출·운용표로 검증한다. |
| 생활 절차 | 실제 직업·행정·의료·노동의 공정과 수치가 정확한가 | 장면 판단에 필수면 교정하고, 아니면 낮은 등급 고증으로 둔다. |

최소 충분 실제성의 원칙은 다음과 같다.

- 관계와 판단을 발생시키는 핵심 저항은 배우의 몸에 실제로 답하게 한다.
- 나머지 면적·횟수·지속시간은 대표 행동, 소리, 빛, 스킨, 패널, 몽타주로 압축할 수 있다.
- `결함의 존재와 결과 범위`는 고정하되, 찢김·주름·얼룩의 모양 같은 미세 편차는 재료에 맡길 수 있다.
- 우연은 표면을 흔들 수 있지만 핵심 정보·필수 큐·안전을 결정해서는 안 된다.
- 실제성이 관객의 주의를 장면에서 배우의 위험이나 장치 고장 걱정으로 옮기면 양식화하거나 안전하게 대체한다.

핵심 정보의 운반 방식도 세 가지로 나눈다.

- **직접 지각**: 정확한 글자·수치·형태의 판독 자체가 사건이면 사물이 객석에서 읽혀야 한다.
- **매개 지각**: 인물의 손 멈춤·낭독·반응, 소리, 빛, 위치 변화가 같은 판단을 보존하면 작은 사물을 대신할 수 있다.
- **약속 지각**: 초반에 `한 조각=전체`, `한 번의 반복=긴 공정` 같은 코드를 학습시켰다면 이후 같은 문법으로 압축할 수 있다.

마지막으로 **소유 층위**와 **심각도**를 섞지 않는다.

| 판정 축 | 값 | 의미 |
|---|---|---|
| 소유 층위 | **본문 / 제작 / 기술** | 누가 어디에서 해결할 문제인가 |
| 약속 판정 | 허용 / P2 / P1 / P0 | 약속이 성립하는가, 결함이 얼마나 심각한가 |

> **이 두 축의 단일 진실원은 [[wiki/writing/aesthetics/연극적_약속_물성_판정_카드#1. 모든 희곡 평가의 필수 표시|판정 카드 §1]]이다.** 위는 참조 사본이며 등급 정의를 여기서 바꾸지 않는다. 2026-08-17까지 이 표는 소유 층위를 `본문 / 제작 선택 / 기술 운용`으로 적고 있었다 — `[약·물]` 한 줄에 그대로 들어가는 enum이라 오기가 발생하므로 진실원 값으로 맞췄다. §3.5의 네 층 표와 지각 3분류도 판정 카드 §3의 참조 사본이다.

안전하고 반복 가능하며 핵심 인과를 전 좌석에 보존하는 해법이 하나라도 있으면 제작 선택 또는 기술 운용에 둔다. 그런 해법이 없고 본문이 해당 물리를 강제할 때만 텍스트 결함으로 올린다. **희곡은 기술 라이더가 아니지만, 연극적 약속은 서사 물리 모순의 면허도 아니다.**

## 4. 핵심 긴장 두 개

### 4.1 범람 vs 최소화 — 수행이냐 해설이냐

내 희곡에서 침묵과 범람은 반대가 아니다. 둘 다 공식 언어가 사적 언어를 포착하지 못하는 순간을 보여주는 방식이다.

- 침묵: 말이 들어갈 칸이 없어서 남는 것.
- 범람: 칸보다 말이 커서 넘치는 것.

둘의 공통 기준은 “해설하지 않는다”이다. 침묵도, 범람도 장면 안에서 수행되어야 한다.

### 4.2 체크리스트 vs 직관

체크리스트는 모든 문장을 미리 검열하는 규칙이 아니다.

> 체크리스트는 이미 걸리는 지점을 진단하는 도구다.

- 직관이 “걸린다”고 신호할 때: 체크리스트로 장소·문제·정보 차이·구체소재 중 무엇이 약한지 본다.
- 직관이 “작동한다”고 말할 때: 원칙 위반처럼 보여도 함부로 깎지 않는다.

질문 방식도 바꾼다.

- 나쁜 질문: “이 원칙을 위반했는가?”
- 좋은 질문: “이 지점은 원칙과 긴장하지만, 의도된 선택인가?”

## 5. 통합 체크리스트

초고 전, 개작 전, 장면 퇴고 때 아래 순서로 본다.

### 0. 한 줄 점검

- [ ] 이 장면은 테마를 설명하는가, 아니면 조건이 대화를 발생시키는가?

### 1. 장소 — 반공간

- [ ] 완전히 사적이지도 공적이지도 않은 압력이 있는가?
- [ ] 그 압력이 공식 언어와 사적 언어의 충돌을 만드는가?
- [ ] 장소를 옮기면 대화가 무너지는가?

### 2. 배경 — 틈으로

- [ ] 배경을 설명하지 않고 틈·부재·물건 상태로 드러내는가?
- [ ] “사실은…”으로 장면이 시작하거나 해결되지 않는가?

### 3. 문제 — 작은 절차

- [ ] 장면을 끄는 작은 질문이 실제 절차로 연결되는가?
- [ ] 그 절차가 악인이 아니라 시스템의 잔인함을 드러내는가?

### 4. 정보 차이 + 두 축

- [ ] 인물/장치별 아는 것, 모르는 것, 권한을 분리했는가?
- [ ] 누가 기록·판정·요약하는가?
- [ ] 시스템 대리인이 단순 악인이 아니라 분열된 인간으로 남는가?
- [ ] 화면↔오브제, 현재↔과거, 입력↔회상이 어디서 만나고 어긋나는가?

### 5. 인물 위치 + 명명

- [ ] 중심/중간/권한자/비인간/부재자가 각각 대화를 흔드는가?
- [ ] 인물 표기, 자기 진술, 시스템 호명이 명명 불가를 일관되게 수행하는가?

### 6. 구체소재

- [ ] 인물이 만지고 입력하고 옮기는 소재가 있는가?
- [ ] 그 소재가 본론을 직접 말하지 않게 하는 우회로인가?
- [ ] 소재의 위치나 상태가 후반에 달라지는가?
- [ ] 지문은 보이거나 들리는 행동·사운드·조명·오브제에 머무는가?

### 7. 연극적 약속·물성·동작

- [ ] 관객이 이 행동으로 반드시 판단해야 할 서사 물리는 무엇인가?
- [ ] 그 판단을 만드는 최소 실제 물성은 무엇인가?
- [ ] 면적·횟수·시간·공정 중 대표·압축·대리해도 되는 범위를 정했는가?
- [ ] 작품은 그 코드를 초반에 학습시키고 끝까지 지키는가?
- [ ] 정확한 사물 판독이 필요한가, 배우·소리·빛을 통한 매개 지각으로도 충분한가?
- [ ] 회차별 재료 편차가 핵심 정보·필수 큐·안전을 바꾸지 않는가?
- [ ] 합리적인 상연 해법이 있는 제작 선택을 본문 오류로 고치려 하지는 않는가?
- [ ] 약속 판정과 문제의 소유 층위를 각각 기록했는가?

### 8. 대사 — 한 장면 한 문장 + 범람 시험

- [ ] 무대/화면이 이미 보여준 것을 다시 말하지 않는가?
- [ ] 좋은 문장이 너무 많아 서로 힘을 나눠 갖지 않는가?
- [ ] 넘치는 말은 수행인가 해설인가?
- [ ] 인물의 자기 인식·공모·죄책감까지 해설로 오인해 깎고 있지는 않은가?

### 9. 플롯

- [ ] 사건 나열이 아니라 정보·권한 재배치로 진행되는가?
- [ ] 반복되는 절차가 매번 다른 권력관계를 만드는가?
- [ ] 결말은 해결이 아니라 무대 상태 변화와 해결 유보로 닫히는가?

### 10. 알레고리

- [ ] 이중 독해가 추상 상징이 아니라 정확한 공식 언어로 작동하는가?

## 6. 「설명란 부족」에서의 적용 예

이 통합 기준이 실제로 작동한 사례는 [[wiki/writing/notes/설명란_부족|설명란 부족]]이다.

- **반공간**: 행정 신청 양식. 사적 기억이 공식 칸으로 번역되는 장소다.
- **문제**: “이 사람은 어느 칸/몇 글자에 들어가는가.” 관계 선택, 50자 설명, 증빙, 필수 항목이 장면을 밀어낸다.
- **정보 차이**: 시스템은 관계명·글자 수·접수 가능 여부를 알고, 사람은 그 사람이 누구였는지를 안다. 둘은 만나지 못한다.
- **인물 위치**: 사람은 중심, 양식은 비인간 권력, 죽은 사람은 컵·물컵·약봉지로만 남은 부재자다.
- **구체소재**: 컵 손잡이, 물컵, 접힌 약봉지가 말 대신 관계를 보존한다.
- **범람 곡선**: 자유롭게 말하기 → 글자 수 측정 → 기계적 절삭 → 자기검열 → 미완성 잔해.
- **삭제 기준**: 화면이 이미 보여주는 `동거 관계 / 설명란 부족`을 인물이 다시 말하면 해설이므로 침묵으로 낮춘다.
- **엔딩**: “설명란만으로는—”이 끝나지 않고, 물컵 위치와 저장 실패만 남는다. 상태 변화 + 해결 유보다.

## 7. 앞으로의 기본 지침

1. **히라타로 조건을 만든다.** 장소, 문제, 정보 차이, 구체소재 없이는 대사를 고치지 않는다.
2. **내 미학으로 비운다.** 조건이 만든 장면 위에서 무엇을 말하지 않을지, 무엇을 물건/화면/소리로 넘길지 정한다.
3. **공식 언어와 사적 언어의 충돌을 중심에 둔다.** 갈등은 인물의 심리 설명보다 칸·절차·호명·상태값에서 생긴다.
4. **범람은 허용하되 시험한다.** 넘치는 말이 양식을 넘치는 수행이면 남기고, 주제를 정리하는 해설이면 지운다.
5. **절차는 작게, 압력은 크게.** 작은 행정 절차 하나가 관계·존재·기억 전체를 압박하게 한다.
6. **결말은 상태로 닫을 수 있다.** 저장 실패, 처리 완료, 남은 컵, 꺼진 장비, 깜빡이는 커서, 계속되는 소리처럼 해결되지 않은 상태를 남기는 것은 이 계열의 강한 수법이다.
   > **보편 요구가 아니다 (2026-08-17).** [[wiki/writing/aesthetics/사건_압력_피드백을_번역하는_법|피드백 번역법]] §5.4는 "결말에는 반드시 사물이나 소리가 남아야 한다"를 **금지된 보편화 목록**에 명시했고, §10은 "결말은 선택이 아니라 지속으로 남는다"를 PAP-1 프로필 전용 언어로 이동시켰다. 닫힌 결말·명시적 해결·직접 발화·완전한 소진도 앞선 시간이 벌어들였다면 보호 대상이다. **이 항목을 근거로 닫힌 결말을 감점하지 않는다.**
7. **현실을 복제하지 말고 인과를 보존한다.** 관객이 판단해야 할 물리와 배우의 몸에 답해야 할 핵심 저항만 실제에 가깝게 남기고, 나머지는 일관된 약속으로 대표·압축한다.
8. **본문과 제작을 구분한다.** 안전·리셋·시야·소모품은 합리적인 해법이 있으면 제작 또는 기술 운용으로 보내고, 해법이 없을 때만 본문을 고친다.
9. **체크리스트는 직관을 대체하지 않는다.** 작동하는 순간을 체계 때문에 죽이지 말고, 걸리는 순간을 체계로 진단한다.

## 작업 적용 메모

이후 희곡 작업에서 “히라타식으로 보자”는 말은 **무조건 줄이자**가 아니라 다음 뜻으로 사용한다.

> 대사가 설명적으로 느껴지는 지점을 문장 차원에서 바로 고치지 말고, 장소·문제·정보 차이·구체소재·범람 곡선·엔딩 상태를 차례로 점검한다.

그리고 “내 미학으로 보자”는 말은 다음 뜻으로 사용한다.

> 규정될 수 없는 존재가 규정의 압력 안에 남는 방식, 공식 언어와 사적 언어의 충돌, 미결의 지속, 비접촉의 거리, 사물/소리의 잔여를 해치지 않는 선에서 퇴고한다.

그리고 “물성·동작을 점검하자”는 말은 현실 공정을 전부 재현할 수 있는지부터 따진다는 뜻이 아니다.

> 관객이 무엇을 판단해야 하는지, 그 판단에 무엇이 실제여야 하는지, 무엇을 연극적 약속으로 압축할 수 있는지, 남은 문제가 본문·제작·기술 중 어디에 속하는지를 차례로 판정한다.
