# writing decisions 운영

희곡/집필/퇴고/투고 판단 중 반복 논쟁이 될 만한 결정을 남긴다.

예시:
- 운반체 경합
- 민감 소재 가상화
- 집필 큐 재정렬
- 서명칸 계보의 순서와 역할
- 특정 초고 후보의 보류/승격 기준

결정 노트는 정답 선언이 아니라, 현재 미학과 작업 흐름상 잠정적으로 닫은 가능성과 재검토 조건을 보존한다.
