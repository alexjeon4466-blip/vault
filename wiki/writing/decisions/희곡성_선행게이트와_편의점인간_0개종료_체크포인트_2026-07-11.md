# 희곡성 선행 게이트와 『편의점 인간』 0개 종료 — 체크포인트

> [!warning] 역사 결정 — 현재 권위 아님
> 이 문서는 2026-07-11 당시 `활성 0개 / 전면 보류`에 도달한 근거를 보존한다. 2026-07-12 사용자가 보류를 명시적으로 해제했으며, 현재 선택 상태는 [[wiki/writing/decisions/편의점인간_원천18_글쓰기우선_재검토_2026-07-12|편의점 인간 원천 18 — 글쓰기 우선 재검토]]를 따른다.

## 한 줄 요약

> 사람·행동·대항력·비용이 분석상 존재해도 작가가 그 사람을 5분 더 보고 싶지 않으면 활성 희곡 글감이 아니다. 『편의점 인간』 4차 회귀는 글감 0개로 끝났지만, writing-note·F표·구조표·초고를 만들기 전에 멈춤으로써 과잉 승격을 차단했다.

오늘 작업은 여기서 종료한다. 자동 재개할 잔여 작업은 없고 Git 커밋·푸시도 하지 않았다.

## 왜 이 결정을 열었나

새 교리 3책 회귀는 책마다 다른 F-어포던스를 산출해 형식 자기복제를 줄였지만, 『궤도』 후속 재진단에서 구조와 물성 시험이 통과해도 실제 희곡 씨앗은 아닐 수 있다는 오탐이 드러났다. 『궤도』 후보 20과 잠정 shortlist는 결국 전부 보류됐다.

『편의점 인간』은 이 문제를 다시 시험하기 좋은 강한 대조군이었다.

- 기존 원본 지도는 창작노트 21편을 승격했다.
- downstream 후보는 교육장·상담실·복귀확인실·심사실·근무표 회의로 수렴했다.
- 원자료의 사람과 행동보다 창구·양식·상태값·등급표가 먼저 발명됐다.
- `부부용 젓가락`은 송별 선물 장면에서 `반납 창구·축하 사유 정정 양식`으로 변했다.
- `쓸 만한 도구`는 일요일 근무 수락보다 `도구 등급 스티커·갱신일·점검표`가 중심이 됐다.

따라서 이번 회귀에서는 F1–F5, 예상 길이, 새 장소, 구조표를 모두 뒤로 미루고 원자료의 사람·현재 행동·욕망/회피·대항력·후속 비용부터 다시 봤다.

## 오늘 수행한 시험

### 출처 경계

- 핵심 장면 정본: `파트2 초반/중반/중후반/후반 풍부판` 4개
- 작가론·윤리 경계: `파트1 풍부판`
- 종합·비판 대조군: `파트3`
- 핵심 MD 6개 SHA-256은 모두 달라 exact duplicate 없음
- 책카드에서 누락됐던 `파트2_중후반_풍부판.md`를 source 목록에 추가

### 희곡성 선행 판정

원천 조각 18개를 다음 순서로 판정했다.

1. 지금 무대 위에 구체적인 사람이나 몸이 있는가.
2. 그 사람이 현재 무엇을 하며 무엇을 원하거나 피하는가.
3. 무엇이 쉽게 끝내지 못하게 하는가.
4. 첫 행동 뒤 관계·비용·권한·물질 상태 중 무엇이 달라지는가.
5. 제목과 해석을 지워도 행동이 남는가.
6. 원작 표면과 고유 일화를 지워도 독립 상황이 남는가.

결과:

| 판정 | 수 |
|---|---:|
| 독립 씨앗 | 3 |
| 보류 | 8 |
| 병합 부품 | 6 |
| 제외 | 1 |
| 합계 | 18 |

F1–F5 부여, 예상 길이, 구조·시간 소시험, writing-note·초고 생성은 모두 0개였다.

## 사용자 끌림 게이트 결과

분석상 독립 씨앗 3개 가운데 기존 노동·상태 갱신 계열과 겹치는 `아직은 쓸 만해서 일요일에 나갑니다`를 먼저 shortlist에서 내렸다. 남은 두 후보만 사용자에게 보냈다.

1. 할인 튀김꼬치를 준비해야 하는데 동료들이 연애 축하부터 하는 근무
2. 퇴직 이유를 오해한 동료에게 부부용 젓가락을 받는 마지막 근무

사용자 최종 반응:

> 둘 다 궁금하지 않다.

이에 따라 분석상 독립 씨앗 3개와 shortlist 2개를 포함한 『편의점 인간』 v2.1 후보 전체를 실행 큐에서 내렸다.

## 최종 결정

### 1. 분석상의 독립성과 작가적 궁금함을 분리한다

`사람 + 현재 행동 + 욕망 + 대항력 + 비용`은 필요조건일 수 있지만 활성 글감의 충분조건은 아니다. 최종 실행 판정은 다음 질문이 우선한다.

> 이 사람을 5분 더 보고 싶은가?

아니라면 독립 씨앗이라는 분석명이 붙어 있어도 활성화하지 않는다.

### 2. 사용자 끌림 게이트를 형식 작업보다 앞에 둔다

다음 작업부터 순서는 다음과 같다.

1. 원자료에서 사람·목소리·관계·침묵·행동·시간·관점과 보호 핵심을 넓게 보존
2. 기존 계열·자기복제·직접 각색 위험 점검
3. 작가 쪽에서 더 따라가고 싶은 질문이 있는 후보를 최대 3개만 사용자에게 제시
4. 사용자가 0–1개를 선택; 전부 궁금하지 않으면 0개 종료
5. 선택된 한 후보만 실제 병목에 맞는 탐색으로 이동: 사람·말·관계는 2–5쪽 쓰기, 시간은 장면쌍, 출처는 조사, 객석 가독성은 물성 확인

사용자 선택 전에는 writing-note, 새 장소, A/B/F, `유망★`, 예상 길이, 구조표, B2, 물성 시험, 초고를 만들지 않는다. 완성된 욕망·대항력·비용은 쓰기 전에 전부 증명할 의무가 없으며 짧은 장면이 그 빈칸을 탐색할 수 있다.

### 3. 0개를 정상 결과로 인정한다

한 책이 창작 글감을 주지 않아도 책카드·해석·질문·비교 강의는 독립적으로 완료된 자산이다. 북클럽 자료를 글감 공장으로 취급하지 않는다.

이번 결과는 다음처럼 분리해 기록한다.

- 희곡 글감 발굴 성과: **0개**
- 방법론 성과: **궁금하지 않은 후보를 유망작으로 부풀리기 전에 중단**
- 추가 writing-note·F표·구조표·초고: **0개**

## 멈춘 것

- 『편의점 인간』 원자료 안에서 후보를 더 짜내는 일
- shortlist 2개를 다른 장소·제도·양식으로 변환하는 일
- 기존 `부부용 젓가락을 반납합니다`, `쓸 만한 도구입니다`를 개작하는 일
- F1–F5 비교, 예상 공연시간, B2, 장면표, 대본 작성
- 기존 V1 지도와 초고후보 파일의 삭제·대규모 수정

기존 V1 파일들은 `장치가 사람보다 먼저 발명된 과정`을 보여주는 역사 지층과 반증 자료로 보존한다.

## 재검토 조건

다음 중 하나가 명시적으로 발생할 때만 『편의점 인간』 창작 채굴을 다시 연다.

1. 사용자가 이 책의 전면 보류를 직접 해제한다.
2. 원자료 밖에서 전혀 다른 실제 사람·관계·몸·물건의 씨앗이 들어오고, 『편의점 인간』은 그 씨앗을 해석하는 렌즈로만 필요해진다.
3. 사용자가 특정 사람·목소리·관계·시간을 다시 써보고 싶다고 하거나, 초고에서 구체적인 객석 가독성 질문이 생긴다.

책 내부에서 제목만 바꾼 후보를 추가로 만드는 것은 재검토 조건이 아니다.

## 다음 세션 제안

자동 실행하지 않는다. 새 요청이 있을 때의 우선순위만 남긴다.

1. 책을 더 채굴하기보다 실제 생활·공개 사례·관계 장면에서 사람과 몸이 이미 움직이는 씨앗을 찾는다.
2. 책은 씨앗 생성 의무가 아니라 질문·해석 렌즈로 뒤에 붙인다.
3. 새 후보도 `5분 더 보고 싶은가`에서 아니면 즉시 0개로 닫는다.
4. 사용자가 고른 후보는 먼저 가장 싼 병목별 탐색을 한다. 사람·말·관계가 병목이면 2–5쪽 쓰기가 기본이며, 물성 시험 통과를 대본 허가 조건으로 두지 않는다.
