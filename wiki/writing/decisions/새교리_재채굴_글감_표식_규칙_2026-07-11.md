# 새 교리 재채굴 글감 표식 규칙 — 1차 파일럿

## 결정

기존 원본 채굴과 새 교리 재채굴을 파일명 접미사만으로 구분하지 않는다. **지도 상태값 + frontmatter 워크플로 메타데이터 + 본문 배지**의 세 층으로 표시한다.

파일명은 사람이 읽기 쉬운 평문을 유지한다. `_scored`는 실제로 `글감_트리아지_지도`에서 평가된 sidecar에만 붙인다.

## 지도 상태값

| 표식 | 뜻 | 처리 |
|---|---|---|
| `V2-신규` | 1차 장치 지도에 없던 출처 압력·행동·시간 연료 | 새 글감 후보로 보존 |
| `V2-복권` | 원본에 있었지만 옛 단막 적합성·제도 장치 편향 때문에 미기록된 재료 | 새 형식 가능성을 열어 보존 |
| `V2-재형식` | 기존 장치와 출처는 같지만 F1–F5 시간 조직과 자연 규모가 실질적으로 달라짐 | 기존 노트와 병렬 후보 또는 판본으로 보존 |
| `V2-보강` | 새 파일보다 기존 노트의 출처·행동·형식 가설을 강화하는 편이 나음 | 기존 노트에 연결하되 자동 수정하지 않음 |
| `V1-중복` | 새 압력·행동·시간 조직이 없고 기존 노트가 충분함 | 승격하지 않음 |

## 새 글감 frontmatter

```yaml
_workflow_version: play-seed-form-open-v2
_harvest_generation: v2-remine
_harvest_batch: 사람장소환대-2026-07-11-1차
_harvest_relation: new | revived | reframed
_source_kind: book-original
```

- `_harvest_relation: new` → `V2-신규`
- `_harvest_relation: revived` → `V2-복권`
- `_harvest_relation: reframed` → `V2-재형식`
- 기존 노트 보강과 중복은 새 글감 파일을 만들지 않는다.

## 본문 배지

새로 승격하는 글감 본문 첫머리에 다음 callout을 둔다.

```markdown
> [!note]+ 새 교리 재채굴 글감 — V2-신규
> 『사람, 장소, 환대』 원본 2차 채굴에서 나온 후보. 최종 형식·길이·B2는 아직 선택하지 않았다.
```

배지는 검색과 육안 구분을 위한 것이며 예술적 우열 표시가 아니다.

## 1차 지층 보존

- 기존 `사람장소환대_원본_창작장치_지도.md`와 36개 승격 노트는 수정·삭제·재채점하지 않는다.
- 새 지도는 기존 지도에서 놓친 것과 새로 보이는 형식만 기록한다.
- 같은 원문 장치를 다시 사용할 때는 왜 `V2-재형식`인지 시간 연료·관계·자연 규모 차이를 명시한다.
- 새 교리가 기존 장치를 무효화한다는 뜻이 아니다. 두 지층은 서로 다른 질문으로 원본을 읽은 기록이다.

## 파일럿 통과 조건

1. 새 후보가 창구·서류·계정 없이도 행동과 시간이 남는다.
2. 최소 자연 규모와 F1–F5 가설이 적혀 있지만 최종 형식은 잠그지 않는다.
3. 1차 지도와 중복 여부가 각 후보마다 기록된다.
4. 새 파일은 plain filename을 쓰고 `_scored`를 붙이지 않는다.
5. 파일럿 뒤 표식이 실제 검색·판별에 유용한지 검토한 후 다른 책에 확장한다.
