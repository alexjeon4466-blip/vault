# 결정 — 희곡 교리 4종과 관련 스킬 3종을 단일 체계로 정합화한다

## 결정

`희곡_길이별_설계_원리.md`를 **글감에서 복수의 희곡 형식을 생성하고 비교하는 단일 교리원**으로 재구성한다. 다른 교리와 스킬은 이 원리를 중복 보유하지 않고 자기 단계에 필요한 행동만 수행하는 얇은 어댑터로 정리한다.

새 `play-form-design` 스킬은 만들지 않는다. 다운로드한 `revise-plays-yongsu-method.zip`의 작가 프로필·평가 프레임워크·개작 프로토콜은 기존 `playwriting-dramaturgy`의 참조 자료로 흡수한다.

## 목표

1. 많은 글감에서 하나의 정답이 아니라 최소형·단막형·장막형·연작형 등 서로 다른 희곡 가능성을 꺼낸다.
2. `10~15분 한 장소 리얼타임`, `① 연속 확장형`, `③ 다중 맞물림형`을 유효한 도구로 유지하되 보편 규범으로 강제하지 않는다.
3. 길이를 목표 매수의 선입력이나 장면 할당량이 아니라 필요한 관계 변화·정보 이동·절차 반복·대기와 성취·시간적 변주의 결과로 본다.
4. 전용수의 반복 미학을 기본 가설로 사용하되, 새 작품이 기존 문법과 다를 때 그 새로움을 먼저 보호한다.
5. 세 스킬의 역할 중복을 줄여 한 교리가 바뀌었을 때 여러 참조가 함께 어긋나는 문제를 막는다.

## 비목표

- 모든 글감을 장막 또는 30~40분 단막으로 확대하지 않는다.
- 모든 작품을 반공간·제도 언어·역할명 인물·조용한 미결의 결말로 통일하지 않는다.
- 외부 극작론을 하나의 정설로 합치지 않는다.
- 현재 진행 중인 다른 vault 작업을 정리·커밋·되돌리지 않는다.
- `bookclub-wiki-v2`의 독서모임 기능을 창작 파이프라인의 부속으로 축소하지 않는다.

## 단일 교리원 구조

### 1. 미학적 헌법

`wiki/writing/aesthetics/전용수x히라타_통합_극작노트.md`

- 히라타로 장소·문제·정보 차이·구체소재의 조건을 만든다.
- 전용수 원칙으로 무엇을 비우고 무엇을 남길지 정한다.
- 작가 프로필은 규범이 아니라 기본 가설이다.
- 체크리스트 적용 전 무원칙 독해로 작품의 약속·강한 이미지·온도·새로움을 보호한다.
- 직접 고백, 시간 비약, 큰 사건, 심리적 인물, 닫힌 결말도 실제로 작동하면 제거하지 않는다.
- 자기복제 위험을 별도로 점검한다.

### 2. 가능성 진단

`wiki/writing/aesthetics/글감_판정_루브릭.md`

- 초기 글감의 사람·무대·정보·권한·물성·반복 가능성을 진단한다.
- `10~15분 한 장소 리얼타임`은 필수 관문이 아니라 최소형 시험으로 사용한다.
- 반공간, 외부자, 연속 시간은 강한 선택지이지만 의무가 아니다.
- 판정 결과에 최소형·연속형·반복 변주형·다중 맞물림형·장막형·연작형 가설을 남긴다.
- 최종 길이와 형식은 확정하지 않는다.

### 3. 형식 생성과 선택

`wiki/writing/aesthetics/희곡_길이별_설계_원리.md`

이 문서만 다음 내용을 상세히 보유한다.

- 형식 선택 전 원형 보호
- 글감의 구조 DNA: 압력, 시간, 장소, 인물망, 정보·권한, 오브제·노동, 반복, 대기 중인 질문
- 네 확장 방향:
  - 수평 확장: 들고남·인물 조합·동시 흐름
  - 수직 확장: 반복·침묵·절차의 상태 변주
  - 종축 확장: 암시–대기–부분 성취의 중첩
  - 불연속 확장: 독립 작품들의 시간적·역사적 축적
- 길이별 자연 규모: 10~15분, 30~40분 단막, 60~90분 이상 장막, 연작
- 한 글감에서 형식 후보 2~3개를 만드는 절차
- 보호되는 성취, 새 행동, 정보·권한 이동, 시간 연료, 후속 비용, 설명 비용, 자기복제 위험, 제작 가능성 비교표
- 외부 1차 자료, 극작론, 내부 작품군의 가설, 실전 휴리스틱의 근거 등급

### 4. 실행 절차

`wiki/writing/aesthetics/집필_파이프라인.md`

- B1에서 형식 후보 2~3개를 비교하고 사용자가 선택한다.
- B2에서 선택 형식에 맞는 구조 맵을 작성한다.
- B4에서 공통 게이트와 형식별 게이트를 검증한다.
- C 단계에서는 작품의 필요한 물질적·정보적 변화를 충분히 쓴 뒤 실측하고 압축·확장·분할 여부를 판단한다.
- `1단위≈15분≈40매`, `1단위당 5~8장`, `장당 6~10매`는 보편 할당량으로 사용하지 않는다.

### 운영 미러

`wiki/writing/aesthetics/히라타식_글감_채집_사이클.md`는 출처 수집, 장면 씨앗, 구조 DNA, 임시 형식 가설, 윤리 경계, 트리아지 인계만 보유한다. 형식 교리를 다시 장문으로 복제하지 않는다.

## 스킬 역할

### `play-seed-harvesting`

공개 자료를 출처가 있는 장면 씨앗으로 바꾸고 구조 DNA와 임시 형식 가설 2~3개를 붙인다. 최종 길이 확정, B2 구조 맵 완성, 모든 씨앗의 30~40분 단막화는 담당하지 않는다.

### `playwriting-dramaturgy`

작품의 고유한 약속을 보호한 뒤 형식 후보 비교, 구조 설계, 장면 진단, 개작을 담당한다. ZIP의 작가 프로필·평가 프레임워크·개작 프로토콜을 참조 자료로 흡수한다. 길이 규칙 자체는 중심 교리를 참조한다.

### `bookclub-wiki-v2`

책 원본·책카드·질문에서 나온 재료의 출처 보존, 파일 생성, 상태 전이, index/log, wikilink와 frontmatter 검증을 담당한다. 형식 선택과 개작 판단은 해당 극작 스킬과 교리로 라우팅한다. 독서모임 해석·질문·강의 기능은 창작과 독립된 축으로 유지한다.

## 작업 흐름

```text
공개 자료 / 책 원본 / 기존 글감
        ↓
장면 씨앗 + 구조 DNA
        ↓
가능성 진단
        ↓
형식 후보 2~3개
        ↓
비교·사용자 선택
        ↓
B2 구조 맵
        ↓
B4 형식별 검증
        ↓
C1–C3 충분한 초고와 개작
        ↓
실연 측정 후 최종 길이·제출처 조정
```

3. `희곡_길이별_설계_원리.md` 전면 개편

6. `히라타식_글감_채집_사이클.md` 동기화

8. `play-seed-harvesting`과 관련 참조 업그레이드

## 단계별 핵심 완료 조건

### 상위 교리

- 작가 문법의 예외와 작품 고유성 보호가 명시된다.
- 길이별 원리는 하나의 글감에서 최소 두 형식을 실제로 생성할 수 있다.
- 사실·해석·휴리스틱의 근거 등급이 구분된다.
- 루브릭이 시간 비약·사적 공간·1인극·큰 사건을 자동 탈락시키지 않는다.
- 파이프라인은 선택 형식별로 다른 B4 검증을 수행한다.

### 스킬

- `playwriting-dramaturgy`는 평가 전에 작품의 약속을 보호하고 한 판본의 상류 병목을 1~3개로 좁힌다.
- `play-seed-harvesting`은 같은 소스에서 서로 다른 형식 가설을 만들고 제도 오류·민원실·키오스크로만 수렴하지 않는다.
- `bookclub-wiki-v2`는 극작론을 중복하지 않으면서 파일·상태·링크·검증 책임을 유지한다.

### 통합 행동 시험

서로 다른 기존 글감 세 종류를 사용한다.

1. 제도·절차형
2. 반복·오브제형
3. 계보·연작형

각 시험은 다음을 만족해야 한다.

- 형식 후보가 최소 두 개다.
- 후보마다 시간을 만드는 연료가 다르다.
- 보호할 고유 성취가 명시된다.
- 자기복제 위험이 표시된다.
- 장막 가능성을 과장하지 않는다.
- 권장안과 보류안이 구분된다.

## 정적 검증

- 스킬 frontmatter, 이름, 설명, 파일 크기 검증
- `skill_view`를 통한 수정본 재독
- 현행 규칙에 남은 오래된 강제 문구 검색:
  - `①/③ 표준`
  - `1단위 40매`
  - `장당 6~10매`
  - `1단위당 5~8장`
  - 시간 비약을 자동 실패로 부르는 `비히라타적`
- 역사 기록과 현행 지침을 구분해 허용 목록 작성
- Obsidian verifier 실행

## 안전·복원 정책

- 수정 전 관련 교리·스킬·참조 파일을 로컬 ZIP으로 백업한다.
- 현재 vault의 다른 수정·미추적 파일을 정리하거나 되돌리지 않는다.
- 관련 파일만 수정하고 관련 검증 결과를 따로 보고한다.
- 커밋과 푸시는 사용자 요청 전까지 보류한다.
- 각 단계에서 문제가 생기면 다음 단계로 넘어가지 않고 해당 단계의 백업으로 복원 가능해야 한다.

## 선택하지 않은 접근

### 점진적 덧붙이기

빠르지만 `15분/①/③`의 강제 전제를 남긴 채 새 이론이 퇴적되어 우선순위가 모호해지므로 선택하지 않았다.

### 전용 `play-form-design` 스킬 신설

형식 설계의 호출 조건은 선명하지만 `playwriting-dramaturgy`와 중복되고 선택적 스킬 운용 원칙에 어긋날 가능성이 커 선택하지 않았다.

## 재검토 조건

- 세 종류의 통합 행동 시험에서 서로 다른 후보가 나오지 않고 다시 동일한 제도극으로 수렴할 때
- 중심 교리 변경 때 세 스킬의 문구를 반복해서 동시에 고쳐야 할 때
- 장막 또는 연작 작업이 실제로 누적되어 독립 전용 스킬이 더 경제적이라는 증거가 생길 때
- 외부 낭독·공연에서 현재 형식 후보 비교가 배우와 연출의 실전 판단을 충분히 지원하지 못할 때
