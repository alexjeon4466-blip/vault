# 꽃가마 《한 명 더》 — 독립 1차 장면 체크포인트

## 사용자 지시와 범위

- 사용자 지시: `여기까지 체크포인트`.
- 범위: 뉴스 글감 18번 `네 사람이 들어야 움직이는 꽃가마`에서 쓴 독립 1차 장면 《한 명 더》와 그 자체 검토 상태.
- 이 지시 뒤에는 대사·지문·구조를 더 고치지 않았다. 남은 작업은 상태 동결, 위키 연결, 수치·링크 검증으로 제한했다.

## 산출물과 측정값

- 장면 및 검토: [[wiki/writing/notes/네_사람이_들어야_움직이는_꽃가마_독립쓰기탐색_2026-07-20|네 사람이 들어야 움직이는 꽃가마 — 독립 쓰기 탐색]]
  - 파일 크기: **16,029 bytes**
  - 파일 행 수: **384행**
  - 대사: **A 30행·163자 / B 31행·213자 / 합계 61행·376자**
  - 행동 문단: **69개**
  - 내부 텍스트 시뮬레이션: **약 2.67–5.01분**. 실제 배우 낭독 시간이 아니다.
- 원 채집 카드: [[wiki/writing/notes/글감_채집_2026-07-19_뉴스20|글감 채집 2026-07-19 — 뉴스 20]] 18번.

## 최종 몸·오브제·소리 상태

| 층 | 체크포인트 상태 |
|---|---|
| A | 방 안에서 아래 몸체의 손잡이 하나를 두 손으로 잡고 놓지 못한다. |
| B | 현관 밖에서 반대 손잡이 하나를 두 손으로 잡고 놓지 못한다. 줄자는 주머니에 있다. |
| 윗장식 | 아래 몸체와 분리돼 현관 밖 바닥에 놓여 있다. |
| 아래 몸체 | 네 손잡이 중 두 개만 잡힌 채 문턱에 비스듬히 걸려 통로를 막는다. |
| 노리개 | 이동 폭을 줄이려고 다시 뗀 두 개가 아래 몸체 안에 놓여 있다. |
| 소리 | 두 번째 짧은 경적 뒤 외부 응답은 없다. 마지막에는 두 사람이 몸체를 바로 세우려는 무언의 동작만 남는다. |

## 반복 규칙·변형된 압력·새 비용

- **반복 규칙:** 통과시키기 위한 합리적 해결을 하나씩 적용할수록 완성품에서 더 많은 부분을 떼게 된다.
- **변형된 압력:** 처음에는 폭과 방향의 문제지만, 윗장식이 밖으로 나간 뒤에는 사람 수와 손의 배치 문제로 바뀐다.
- **새 비용:** 꽃가마는 완성품에서 현관 양쪽의 두 조각으로 변하고, 아래 몸체는 통로를 막으며, A와 B는 각자 손잡이를 놓을 수 없게 된다.
- **보호 약속:** 전통·노년·후계를 설명하지 않고 무게·방향·손의 수·문턱으로만 압력을 만든다. 실존 제작자의 이름·나이·자택·비용을 재현하지 않는다.

## 현재 판정

- `checkpointed / frozen / on-hold`.
- 독립 1차 장면·선택 씨앗 엄격 재판정·자체 구조/생략/물성 검토·내부 텍스트 시뮬레이션·오브제 상태표를 보존한다.
- 이 판정은 작품 등급이나 탈락이 아니라 작업 흐름의 동결 상태다.

## 의도적으로 남긴 위험

- 실제 축척에서 두 배우가 아래 몸체를 어느 각도로 들면 문턱 고정이 객석에 읽히는지 확인하지 않았다.
- A의 반말과 B의 존댓말이 실제 목소리에서 관계를 충분히 만드는지 확인하지 않았다.
- `문은 옆에 있어요`의 두 번 반복이 실제 낭독에서 기능 변화로 들리는지 확인하지 않았다.
- 위 세 항목은 결함 확정이 아니라 미실행 검사다. 체크포인트 지시 뒤 수정 근거로 사용하지 않는다.

## 실행하지 않은 것

- 꽃가마·문턱 축척 동선 시험
- 추가 대사 감산 또는 지문 수정

## 재개 조건

- 사용자가 《한 명 더》 또는 꽃가마 장면을 **명시적으로 다시 선택할 때만** 재개한다.
- 실제 낭독·축척 시험·2차 장면은 대기 작업이 아니며 자동 실행하지 않는다.
- **현재 다음 행동은 선택하지 않았다.**
