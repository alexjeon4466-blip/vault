# 희곡 교리와 스킬 정합화 — Task 0–10 완료 체크포인트

## 한 줄 요약

> 작품의 약속을 먼저 보호하고, 출처 압력·무대 행동·구조 DNA에서 복수 형식 후보를 만든 뒤, 사용자 선택 후 B2에 진입하고, 충분히 쓴 연결본을 측정해 상류 병목 1–3개씩 개작하는 체계로 다섯 교리와 세 Hermes 스킬을 정합화했다.

Task 0–10은 모두 완료됐다. 다음 작업은 이 계획의 자동 재개가 아니라, 사용자가 선택한 새 글감·초고·개작에 현행 체계를 적용하는 별도 작업이다. 커밋·푸시는 하지 않았다.

## 고정된 비강제 원칙

- 기존 작가 문법은 강한 가설이지 모든 작품의 의무 문법이 아니다.
- 공식 언어, 작은 절차, 사물 잔여, 미결 엔딩, 한 장소, 연속 시간, 반공간, 외부자는 선택 전술이다.
- 직접 고백·심리·큰 사건·시간 비약·다장면·닫힌 결말·독백·비인간 형식은 자동 결함이 아니다.
- `30–40분`, `80–100매`, ①/③, 장면당 고정 매수, 단위당 장면 수를 보편 설계 입력으로 사용하지 않는다.
- 작품의 자연 규모와 공모·제작 외부 규격을 분리한다.
- 후보들은 장면 수가 아니라 시간을 생산하는 행동·관계·구조가 달라야 한다.
- 가장 작은 자연 규모를 항상 비교하고, 장막·연작은 독립 관계·시간축·결정·후속 비용이 있을 때만 연다.
- 사용자 선택 전 B2를 하나의 형식으로 잠그지 않는다. 사용자가 병렬 탐색을 명시한 경우만 여러 B2를 분기한다.
- 충분히 쓴 연결본을 보존한 뒤 원고지 매수, 예상 발화, 비언어, 실측 공연시간을 분리 측정한다.
- 매 개작 회차는 상류 병목 1–3개와 downstream 비용을 기록한다. 증상 윤문만 남으면 판본을 동결하거나 목적별 판본을 분기한다.
- 제도·창구·사과·대기실·고지문·정보격차 문법의 자기복제를 정기적으로 검사한다.

## 스킬 경계

### `playwriting-dramaturgy`

1. 무원칙 독해
2. 보호 핵심과 자기복제 위험
3. 정본 교리 로드
4. 서로 다른 시간 연료의 형식 후보 2–3개
5. 사용자 선택 또는 명시적 병렬 탐색
6. B2
7. 세 층 명료성: 의미/행동/관객 정보
8. 상류 병목 1–3개와 downstream 비용
9. 낭독·동선·판본 비교

`revise-plays-yongsu-method.zip`의 내용은 다음으로 선별 흡수했다.

- `references/yongsu-writer-profile.md`: 고정 정체성이 아닌 수정 가능한 작가 가설·자기복제 경보
- `references/yongsu-evaluation-framework.md`: 세 층 명료성·증거 기반 평가·수정안 비용
- `references/yongsu-revision-protocol.md`: 보호→상류 병목→국소 수정→낭독/판본 비교

### `play-seed-harvesting`

- 공개 소스와 접근 경계를 보존한다.
- 로그인·가입·인증 자료를 우회하거나 보지 못한 본문을 추정하지 않는다.
- 출처 압력, 행동/물질, 구조 DNA, 빠진 연료, 윤리 거리, 자기복제 위험을 기록한다.
- 가장 작은 자연 규모를 포함한 2–3개 임시 형식 가설을 만든다.
- 카드 단계에서 최종 길이·B2를 확정하지 않는다.
- 20개 묶음은 장소·관계·절차/비절차·시간 조직·인물 조직·출처 차선이 실제로 달라야 한다.
- 20개 중 3–4개 의미 확장을 성공으로 본다.
- 실제 dry run: 오마이뉴스 시민 생활글 「옥상에서 빨래 말리는 재미를 아세요?」에서 공동 빨랫줄·익명 집게 보충·햇빛/바람·이사라는 관계/자연/노동 DNA를 추출해 최소 수직형·연속 관계형·불연속 계절 모듈을 만들었다. 제도 장치 발명 0, B2 침범 0.

### `bookclub-wiki-v2`

- 책카드·원문 채굴·해석·질문·강의는 창작 전단계가 아니어도 독립 완료다.
- 위키 파일 구조, frontmatter, parent/index/log, dashboard, verifier를 담당한다.
- 공개 자료 씨앗 생성은 `play-seed-harvesting`으로 보낸다.
- 형식 선택·B2·초고·드라마투르기·개작은 `playwriting-dramaturgy`로 보낸다.
- 역사적 작품별 참조는 증거·이행 자료이며 보편 교리원이 아니다.
