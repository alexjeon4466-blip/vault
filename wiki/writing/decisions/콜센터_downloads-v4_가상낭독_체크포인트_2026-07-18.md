# 콜센터 Downloads v4 — 가상 낭독 체크포인트

## 현재 결정

1. Downloads의 `콜센터화장실_v4.md`는 Vault의 `script/콜센터/..._v4.md`와 **다른 판본**이다.
2. Downloads v4는 Vault v9와 가장 가깝지만 동일하지 않다. 본문 유사도는 약 81.8%다.
3. 작품카드가 명시한 현재 기준판은 v8이다. v9는 파일은 존재하지만 기준판으로 확정한 카드·결정 기록이 없다.
4. 따라서 이번 가상 낭독 감산본은 **`downloads-v4-reading-branch` 비정식 파생 가지**로 위키화한다.
5. v8·v9·Downloads 가지 가운데 어느 것을 기준판으로 삼을지는 자동 결정하지 않는다.
6. `script/콜센터` 원고는 수정하지 않았다.

## 가상 낭독 판정

# **구조 유지 + 최소 감산**

네 구간의 압력 변형은 유지한다.

1. 무언 도입 — C를 인지하고도 물로 가리는 공모
2. A–C — 돌봄의 말이 계속 앉히는 말로 돌아오는 관계적 빚
3. B–C — 물과 문을 처리하지 못하고 함께 정지하는 신체 비용
4. A·B·C — 기록·수신으로 C의 은폐 공간을 외부에 여는 비용

구조 재배치나 큰 감산은 기각한다. 행동이 이미 보여준 뜻을 한 번 더 설명하는 대사만 줄인다.

## 감산 결과

- 대사 211 → 190줄
- A 80 → 70
- B 63 → 55
- C 68 → 65
- 16개 문구 단위 개입
- 장면 구분 7개 유지
- 단독 물소리 26회 유지
- 시스템 배역 발화 0

주요 감산:

- A–C의 첫 `됐어`, 전환용 호칭, 심리 재설명
- 세 번째 `숨 세 번/한 콜만/물 마시고` 목록을 `그땐 좋은 줄 알았는데`로 축소
- B–C의 넘어온 콜 확인과 보호 요청 일화의 결론문
- `그 말처럼` 삭제로 `고맙대`를 확정 원인 해설로 닫지 않음
- A–B의 상태·확인 문답 다섯 박자를 두 박자로 압축
- `다 말장난이잖아`, 상호 부러움의 두 번째 회전
- `그래서 뭐라도 보내야 돼`, `나는 그게 제일 무서워`를 행동에 맡김

## 보호선

- C는 끝까지 세 번째 칸 안에 있다.
- 무언 도입의 노크 직전 손과 B의 물 잠금/재급수는 유지한다.
- 세 호흡과 `한 콜만`의 양가성을 유지한다.
- `마시면 또 와야 되니까요`를 유지한다.
- `살린 줄/계속 앉혀 놓은 것 같기도 해요`를 판결로 닫지 않는다.
- `고맙대/사람이 받아 줘서 다행/한 콜만 더`를 구조 파편으로 유지한다.
- `아무도는 안 떠/미응답으로 떠`, B의 `하나는`을 유지한다.
- A의 수신, B의 전원 끄기, 열린 마이크를 유지한다.
- C의 `모르겠어`를 복귀·치유·붕괴의 확정 결론으로 읽지 않는다.
- 팀장·안내문·콜봇·시스템에 새 설명 대사를 주지 않는다.

## `고맙대` 판정

`고맙대`는 C의 현재를 만든 단일 원인이 아니다. 고객 감사가 C를 다시 친절·응대 위치에 붙잡는 구조 파편이다. 악성 고객과 선한 고객의 대립, 특정 고객 사연, 학대의 원인 고백으로 확대하지 않는다.

이번 감산에서 `그 말처럼`을 삭제해 `고맙대 → 한 콜만 더 → 기계 목소리`의 연결을 관객이 직접 만들도록 했다.

## 가상 호흡

- 가상 테이블 낭독: 24분 30초–31분 45초
- 행동·침묵 포함 예상 공연: 29분 13초–39분 55초

실제 배우·수도·문·신발 시야·휴대폰 동기화·스톱워치 측정값은 아니다.

필수 시간:

- 세 호흡은 실제 몸으로 수행
- `고맙대` 주변은 균등한 시적 쉼이 아닌 불규칙한 기억 공백
- B가 수도와 문을 처리하지 못하는 동작을 대사보다 먼저 보임
- A 수신→B 전원 끄기→A 미차단→열린 마이크를 각기 다른 선택으로 분리
- C의 `모르겠어`와 A/B 퇴장 뒤 소리 종지를 서두르지 않음

## 종결 두 안

### 안 A — 현재 파생 원고

작은 전화 목소리 → 종료음과 어두운 화면 → 물소리 → 닫힌 문 너머 적체 알람 → 암전.

적체 알람은 도입의 업무시간이 다시 밀려드는 절단이다. 종료음과 알람을 둘 다 큰 결말처럼 연주하지 않는다.

### 안 B — 실제 소리 큐 비교안

작은 전화 목소리 → 종료음과 어두운 화면 → 물소리 → 암전.

외부 시스템의 원형 회수를 한 번 덜고, C의 신발·어두운 전화·계속 흐르는 물만 남긴다.

현재 위키 원고에는 안 A를 유지한다. 실제 소리 큐 리딩 전에는 선택하지 않는다.

## 재개 조건

### 기준판 판정

다음 판본을 블라인드에 가깝게 대조한 뒤에만 기준판을 갱신한다.

- 작품카드 기준 v8
- 권위 미판정 v9
- Downloads v4 가상 낭독 최소 감산 가지

판정 기준:

1. C가 침묵할 때도 세 번째 칸의 몸이 중심에 남는가
2. A와 B가 선/악이 아니라 서로 다른 비용으로 들리는가
3. 자동 기록과 통화가 대사 설명보다 먼저 사건을 바꾸는가
4. `고맙대`가 원인 해설이 아니라 방향 전환 파편으로 남는가
5. 종료음·물소리·적체 알람 중 어느 것이 첫 실제 종결인가

### 실제 합독

가능할 때 3인 배우와 소리 큐로만 검증한다.

- 짧은 메시지 진동과 지속 통화를 실제로 구별
- C는 문/가림막 뒤에 있고 나오지 않음
- 수도 잠금·재급수, 젖은 손, 문 앞 정지, 열린 마이크를 실제 시간으로 수행
- 종결 안 A/B를 연속 비교

## 자동 실행 금지

- Downloads 가지를 v8·v9에 자동 병합
- 작품카드의 `latest_version` 자동 변경
- `script/콜센터` 원고 수정
- C의 사연·고객 콜·퇴사 여부 추가
- 시스템·팀장 발화 추가
- 실제 합독 전 추가 대폭 감산
- 공모전 등급·투고판 확정
