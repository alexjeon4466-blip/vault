# 식당·틀린 덧셈 — 1·2차 연결본 체크포인트

## 현재 결정

| 작품 | 2차 장면 효과 | 연결본 결정 | 3차 장면 |
|---|---|---|---|
| 《손님이 술을 사 와야 하는 식당》 | 강화 | 연결 유지 | 불필요 |
| 《세 문제 중 하나의 답이 다르다》 | 강화 | 연결 유지 | 불필요 |

두 작품 모두 1차 장면으로 축소하지 않는다. 2차 장면은 부록이 아니라 1차가 만든 미결 비용을 실제 다른 층위로 이동시킨다.

- 식당: 소유·회수 → 보관·세척 노동
- 틀린 덧셈: 사실 정정 → 혼합 필체의 기록 권한

다만 이 결정은 정식 단막·B2·30–40분 확장을 뜻하지 않는다. 다음 행동은 사용자 선택 전 자동으로 열지 않는다.

---

# 1. 검토 방법

1. 1차·2차 메타 설명을 제외하고 작품별 본문만 추출했다.
2. 2차 첫머리의 1차 마지막 상태 재진술을 제거했다.
3. 장면 표제를 지우고 실제 연결 시간으로 다시 읽었다.
4. 자체 검토에서 정확한 반복 대사·오브제 상태·시스템 발화·종지 자기복제를 확인했다.
5. 가상 에이전트 세 명이 식당 전편 / 덧셈 전편 / 두 편 횡단 비교를 독립 수행했다.
6. 세 검토가 공통으로 지적한 이음새·가독성·반복·종지만 현재 연결본에 최소 반영했다.

외부 판정은 다음처럼 갈렸다.

- 식당 단독 검토: 강화
- 덧셈 단독 검토: 강화
- 횡단 검토: 두 작품 모두 추가 감산 후 연결 유지, 3차 불필요

공통 감산을 반영했으므로 최종 상태는 `2차 장면 효과 강화 / 연결본 유지`로 기록한다.

---

# 2. 《손님이 술을 사 와야 하는 식당》

## 연결 효과

1차의 상자·냉장고·잔 소유 문답이 2차에서 실제 반출·냉장·세척으로 이동한다.

- 상자: 가격과 소유가 적힌 증거 → 기사에게 반출되는 물건
- 손님 병: 허용 여부를 묻는 물건 → 식당 냉장고가 보관하는 열린 물건
- 업체 잔: 받은 것인지 산 것인지 모르는 물건 → 손님이 사용하고 운영자가 씻는 노동 대상
- 안내문: 외부 반입을 선언하는 문장 → 끝까지 완전히 붙지 않는 상태

운영자가 숫자 적힌 상자를 보존하려다가 테이블의 잔을 보고 기사에게 상자를 가져가라고 하는 순간, 소유 문제와 노동 비용이 교환된다.

## 연결부

1차 마지막의 냉장고 모터 소리를 끊지 않고 손님이 병마개를 돌린다. `--- / 2차 장면` 표제를 삭제해 정지된 사용 허가가 즉시 재개되는 한 장면으로 만들었다.

## 오브제 장부

- 빈 병 상자 2개: 마지막에 기사와 함께 반출
- 빈 플라스틱 상자 1개: 1차 최종 상태에서 기사 발치에 복원, 숫자 적힌 상자 위에 포개 반출
- 손님 병 2개: 1개는 열린 채 냉장고, 1개는 의자 옆 봉지
- 업체 잔 4개: 1개는 사용 후 싱크대, 3개는 냉장고
- 병마개: 손님 주머니
- 안내문: 아래쪽이 끝까지 덜 붙음

## 적용한 감산과 수정

- 잔 소유 문답에서 기사의 잠정 판정 한 줄 삭제
- 건너편의 `됐어`와 퇴장 예고 대사 삭제
- 빈 플라스틱 상자의 1차 마지막 위치 명시
- 포갠 상자를 한 손에 드는 불안정한 동작을 가슴에 받치는 동작으로 변경
- 마지막 냉장고 내부·안내문 상태 재열거 삭제
- 업체 잔 위로 흐르는 물과 냉장고 모터의 중첩으로 종결

## 보호할 것

- 누구도 소유권을 판정하지 못하지만 누가 뒤처리를 하는지는 분명해지는 구조
- 네 인물의 실무적 대화 속도
- 악역·승패·법률 설명 없음
- 냉장고 모터와 싱크대 물소리의 미해결 중첩

## 판정

- **2차 장면 효과:** 강화
- **연결본:** 유지
- **3차 장면:** 불필요

새 손님이나 새 병을 더하면 같은 서비스 노동을 양적으로 반복한다. 새 교대자에게 판단 책임을 넘기는 안도 가능하지만 현재 물소리 종지가 미래 비용을 이미 충분히 연다.

# 3. 《세 문제 중 하나의 답이 다르다》

## 연결 효과

1차의 계산 사실과 화면 정정이 2차에서 종이 기록의 저자 문제로 이동한다.

- 원래 `633`: 공부하는 사람이 썼지만 지워짐
- `623`: 설명하는 사람의 다른 필체, 한 줄로 그어짐
- 다시 쓴 `6　3`: 설명하는 사람의 필체
- 가운데 `3`: 공부하는 사람이 직접 복원
- 최종 `633`: 두 사람의 필체가 섞인 채 공부하는 사람의 가방으로 이동

공부하는 사람은 자기 답을 되찾기 위해 타인이 쓴 앞뒤 숫자를 자기 가운데 숫자로 완성해야 한다. 맞음을 복구하는 행동이 혼합 저자 상태를 확정한다.

## 연결부와 귀환 동기

1차 퇴장 전에 공부하는 사람이 가위·테이프 롤을 가방에 넣고 문제지 세 장을 포개려 한다. 설명하는 사람의 `갔다 와서 이것만 다시 보자`가 그 행동을 끊는다.

설명하는 사람이 혼자 `633`을 썼다가 가운데를 지운 뒤, `암전 없이. 잠시 뒤` 공부하는 사람이 돌아온다. 종이를 두고 간 일이 2차를 만들기 위한 편의가 아니라 직전 행동 중단의 결과가 된다.

## 오브제와 객석 정보

- 화면: 발화하지 않고 정정 문장만 유지
- 연필: 설명하는 사람 → 공부하는 사람 → 식탁
- 문제지 3장: 두 번째 장을 맨 위에 둔 채 가방으로 이동
- 짧은 테이프 조각: 문제지와 식탁을 잇다가 식탁에 남음
- 가위·테이프 롤: 첫 퇴장 전에 가방으로 이동
- 라켓: 가방 안

문제지 숫자와 두 필체, 지운 자국은 객석에서 식별될 만큼 크게 만든다. 실제 공연 준비 시 큰 문제지, 둥근 필체와 각진 필체, 옆광을 우선하며 새 프로젝션이나 시스템 음성을 추가하지 않는다.

이 물성 확인은 공연 준비 조건이지 글쓰기 허가를 위한 보편 게이트가 아니다.

## 적용한 감산과 수정

- 화면의 정정 문장을 인물이 소리 내 읽는 두 지점 감산
- `네가 지웠잖아`의 2차 반복과 연필 설명 대화 삭제
- 2차 초반의 `쓰려고 했는데 / 썼잖아` 삭제
- `답은 저기 있잖아` 삭제하고 화면을 보는 사람 / 보지 않는 사람의 행동만 유지
- 가위·테이프 롤의 행선지 복원
- 혼합 `633`이 가방 입구 밖에 보인 채 문 너머로 이동하는 순간에 종결
- 마지막 화면·연필·테이프 목록 삭제

## 보호할 것

- 화면은 사실을 정정하지만 관계를 정정하지 못함
- 가운데 `3`을 직접 써 타인의 `6　3`을 완성하는 행동
- `조금 오른쪽`과 설명하는 사람이 손을 거두는 통제권 이동
- 혼합 필체가 객석에 보인 채 실제로 이동하는 마지막

## 판정

- **2차 장면 효과:** 강화
- **연결본:** 유지
- **3차 장면:** 불필요

제3자가 필체를 평가하는 장면은 교육론·AI 교훈극으로 좁아질 위험이 크다. 현재 연결본이 기록 권한의 비용을 이미 수행한다.

---

# 4. 횡단 판단

두 작품은 같은 `합리적 해결 → 반대 비용` 엔진을 사용하지만 현재 자기복제는 치명적이지 않다.

| 구분 | 식당 | 틀린 덧셈 |
|---|---|---|
| 관계 | 반공적 4인 앙상블 | 사적 2인 관계 |
| 비용 | 서비스·보관·세척 노동 | 기록 저자권 |
| 감각 | 냉기·모터·물소리 | 필체·종이 표면·가방 이동 |
| 종결 | 계속되는 세척 행동과 소리 | 혼합 기록의 물리적 퇴장 |

자기복제 위험은 엔진보다 마지막에 사물을 목록으로 다시 설명하는 습관에 있었다. 식당은 지속 행동과 소리, 덧셈은 이동으로 끝내 이 위험을 분리했다.

---

# 5. 현재 다음 행동

자동 실행하지 않는다.

가능한 다음 단계는 다음과 같다.

1. **현재 연결본을 독립 짧은 희곡으로 유지** — 추가 장면 없이 보관
2. **배우 낭독용 감산 검토** — 실제 낭독을 준비할 때만 호흡·겹침·필체 가독성을 확인
3. **한 작품만 B2/30–40분 확장 후보로 재심사** — 사용자 선택이 있을 때 전체 작품군을 다시 열어 비교

현재 금지:

- 두 작품 병합
- 공통 인물·같은 가게·같은 가족으로 연결
- 자동 3차 장면
- 새 손님·새 문제·새 AI 오류로 양적 확대
- 연결본 완성만으로 정식 단막이나 공모전 등급 확정
