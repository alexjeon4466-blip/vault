# 식당·틀린 덧셈 — 가상 낭독 호흡 감산

## 현재 결정

| 작품 | 가상 낭독 판정 | 감산 | 연결 상태 | 3차 장면 |
|---|---|---|---|---|
| 《손님이 술을 사 와야 하는 식당》 | 최소 감산 | 대사 114 → 107 | 유지 | 불필요 |
| 《세 문제 중 하나의 답이 다르다》 | 최소 감산 | 대사 97 → 91 | 유지 | 불필요 |

큰 감산은 하지 않는다. 두 작품 모두 반복이 단순 정보 중복만이 아니라 물건의 소유권과 답의 저자권을 이동시키는 엔진이다.

가상 낭독은 실제 배우 합독이나 스톱워치 측정이 아니다. 아래 초 단위·분 단위 값은 삭제 근거가 아니라 첫 실제 테이블리딩에서 시험할 목표 호흡이다.

---

# 1. 검토 방법

1. 식당은 운영자·건너편·기사·손님 4인과 연출의 가상 합독으로 읽었다.
2. 틀린 덧셈은 설명하는 사람·공부하는 사람 2인과 연출의 가상 합독으로 읽었다.
3. 별도 에이전트가 두 작품의 호흡 곡선·평탄부·감산 상한·종지 시간을 횡단 비교했다.
4. 새 정보·권리·물건이 바뀌지 않는 반문만 감산 후보로 삼았다.
5. 물건 상태가 실제로 바뀌는 행동은 대사 감산보다 침묵·동선 시간으로 보호했다.
6. 세 검토의 공통 권고와 행동이 완전히 대신하는 대사만 현재 연결본에 반영했다.

---

# 2. 《손님이 술을 사 와야 하는 식당》

## 가상 낭독 예상 범위

- 지문을 모두 읽고 배우가 행동 자리를 기다리는 테이블 리딩: **17–21분**
- 지문은 핵심 큐만 읽고 손동작으로 치환하는 낭독: **13–17분**
- 지문을 발화하지 않고 행동·침묵으로 구현하는 예상 공연 호흡: **12–16분**

상자 무게, 냉장고·문·테이블 거리, 테이프 접착력에 따라 크게 달라질 수 있다.

## 호흡 곡선

| 구간 | 속도 | 운용 |
|---|---|---|
| 상자 숫자와 주인 다툼 | 빠름 | 이미 여러 번 해 본 실무 다툼처럼 말하고 상자는 대화 중 돌림 |
| 기사 입장과 주문 없음 | 보통 | 상자를 내려놓으려다 멈추는 무게가 박자를 만듦 |
| 두 빈 병 상자 확인 | 보통 | 반문은 이어도 수량과 숫자 가린 손은 객석에 보이게 함 |
| 손님 입장과 영업 여부 | 빠름 | `합니다 / 아직 전이에요 / 해요`를 얕게 겹침 |
| 냉장고·문·전기 비용 | 빠름 | 상대 얼굴보다 냉장고·손잡이·안내문을 보며 한 사슬로 말함 |
| 상자와 잔 동시 처리 | 가장 빠름 | 책임 공방은 겹치되 병 기울기·잔 인도는 분리 |
| 따르기부터 세척 | 느림 | 대사보다 따르기·냉장·반출·문·설거지의 실제 시간을 사용 |

## 겹침 후보

- 운영자 `합니다.` 끝에 건너편 `아직 전이에요.`, 끝나자마자 운영자 `해요.`
- 운영자 `네.`가 끝나기 전 기사 `뭐가요?`
- 손님 `그냥 넣기만 하면 되는데.`의 중간부터 건너편 `넣으면 쓰는 거지.`
- 손님 `문만 여는 건데요.` → 운영자 `전원은 제가 내요.` → 건너편 `냉장고는 누가 냈는데.`를 쉬지 않고 연결
- 기사 `그럼 차에 다시 싣고요.` 끝부분에 손님 `저기,`가 들어오고 `잔은 써도 되죠?`는 선명하게 냄
- 운영자 `잔을—`을 손님 `그거 쓰면 되죠?`가 즉시 가로챔

겹쳐도 되는 것은 책임 공방이다. 상자 수량, 빈 냉장고, 잔 인도처럼 물건 상태가 바뀌는 정보는 겹치지 않는다.

## 반드시 쉬어야 할 행동

- 기사가 상자를 내려놓으려다 멈춘 뒤 `없어요?`
- 숫자를 가린 상자를 당겨 병이 기운 뒤 `깨져요.`
- 네 사람이 빈 냉장고와 잔 네 개를 본 뒤 `없네요.`
- 냉장고 불 → 찬 공기 → 안내문 들림 → 건너편 손의 순서를 마친 뒤 `넣을까요?`
- 운영자가 잔을 놓아 손님에게 넘어가는 인도 순간
- `가져갑니다 / 잠깐 / 상자와 잔 사이 이동 / 손님이 마심 / 가져가세요`의 반출 허가

마지막 `가져가세요` 뒤 설거지까지는 가상 목표 **25–35초**, 잔을 따르기 시작한 뒤 최종 물소리까지는 **55–70초**다. 실제 합독에서 다시 잰다.

## 반영한 최소 감산

- `그러니까 오늘 주문이요.` → `오늘 주문이요?`
- `그러면 제가 건너편에서 받을게요.` → `그럼 건너편에서 받을게요.`
- `상자를요? / 네. / 왜요?` → `상자를요? 왜요?`
- 두 번째 `이거 하나만 두고 가시면 안 돼요?` → `이거 하나만요.`
- `저는 잔은 몰라요.` → `잔은 몰라요.`
- 운영자가 잔을 뒤로 빼는 행동이 대신하는 `그 뜻이 아니라.` 삭제

## 보호한 것

- `안 넘치게만.` 이후의 후반 구조
- 병의 냉장과 둥근 물자국
- `나가실 때 가져가셔야 돼요 / 네`
- `가져갑니다 / 잠깐 / 가져가세요`
- 업체 잔을 씻는 행동
- 냉장고 모터와 싱크대 물소리의 중첩

# 3. 《세 문제 중 하나의 답이 다르다》

## 가상 낭독 예상 범위

- 연출이 지문을 읽고 배우가 최소 동작을 수행하는 테이블 리딩: **13–16분**
- 지문을 발화하지 않고 소품 동작과 침묵으로 치환한 예상 공연 호흡: **10–13분**
- 실제 테이프 접착력과 필체 판독 시간 때문에 소품 리딩에서 **1–2분** 늘어날 수 있음

## 호흡 곡선

| 구간 | 속도 | 운용 |
|---|---|---|
| 최초 화면 대기 | 보통→느림 | 긴 문단 뒤 실제 읽는 시간과 테이프 한 바퀴를 둠 |
| `자기가/얘가/이거` 책임 반문 | 빠름 | 질문이 답을 밀어내는 한 덩어리로 읽음 |
| 답을 다시 쓰려는 손 | 보통 | 문제지를 당긴 뒤만 멈추고 짧은 반문마다 정지하지 않음 |
| 테이프 사고와 종이 박리 | 느림 | 손과 종이 소리가 먼저, 대사로 과정을 덮지 않음 |
| 화면 정정과 남길 것 | 보통→빠름→느림 | `봐/됐지?`는 빠르게, `뭐가 남아야 돼` 뒤에서만 멈춤 |
| 혼자 쓰고 지우기 | 매우 느림 | 문 닫힘·응시·633 작성·가운데 3 삭제를 분리 |
| 귀환과 필체 판독 | 보통→느림 | 용건은 짧게, `6　3`을 본 뒤부터 속도를 낮춤 |
| 혼합 답 이동 | 느림 | 감정 정지가 아니라 포개기·걸림·손 떼기·가방 이동의 시간 |

## 반드시 쉬어야 할 행동

- 긴 화면 문단이 생긴 뒤 읽기와 테이프 한 바퀴: **가상 목표 3–5초**
- `쓰지 마.` 뒤 문제지를 빼앗기고 연필 든 채 멈춤: **1.5–2.5초**
- 테이프 끝 찾기·종이 일어남·가는 소리: **6–9초**
- 하얗게 일어난 숫자와 눌린 자국 확인: **3–4초**
- 첫 퇴장 뒤 `633` 작성·가운데 `3` 삭제: **9–13초**
- 귀환 뒤 `6　3`과 밑의 눌린 흔적 판독: **6–8초**
- 가운데 `3`을 쓰기 전후와 혼합 `633` 포개기: **8–12초**

혼합 `633` 세부 목표:

- 설명하는 사람이 손을 거둔 뒤 쓰기 전: **2.5–4초**
- `633` 완성 뒤 `이제—` 전: **3–5초**
- `이제—` 중단 뒤 두 번째 장을 맨 위에 놓기: **4–6초**
- 지퍼 걸림부터 퇴장까지: **12–18초**

초 단위 목표를 지문에 고정하지 않는다. 실제 합독에서 필체가 읽히는 만큼만 늦춘다.

## 반영한 최소 감산

- `아까도 얘가 틀린 거지.` → `아까도 얘가 틀렸지.`
- 방어적 복문 → `너 틀렸다고 안 했어. 답이 달랐다고 했지.`
- `그러니까 내가 다시 써 줄게.` → `그럼 내가 다시 써 줄게.`
- `짧게 나오게.` → `짧게.`
- 행동이 대신하는 `천천히 떼야 돼.` 삭제
- `봐. 괜찮잖아.` → `괜찮잖아.`
- `원래도 지워져 있었어.` → `원래 지워져 있었어.`
- `문제. 나머지 두 개는 맞았잖아.` → `문제. 두 개는 맞았잖아.`
- `두 개는 누가 맞았냐고.` → `누가 맞았냐고.`
- 손가락 정지와 지우개 자국 응시가 대신하는 `여기는 없어.`, `가운데가 비었잖아.` 삭제

`자기가 / 자기가 누구야 / 얘가 / 얘가 누구야 / 이거` 연쇄는 작품의 언어 엔진이라 보존했다.

## 보호한 것

- `조금 오른쪽.`과 설명하는 사람이 손을 거두는 행동
- 공부하는 사람이 가운데 `3`을 직접 쓰는 것
- 두 필체가 섞인 `633`
- `이제—`의 중단
- 두 번째 장을 맨 위에 놓는 행동
- 지퍼에 걸린 모서리를 펴 주고 손을 떼는 순간
- 문제지를 절반만 넣어 `633`을 밖에 남기는 상태
- 혼합 필체가 문 너머로 사라지는 마지막 이동

---

# 4. 횡단 판단

두 작품 모두 최소 감산이 맞다.

- 식당은 대상이 상자 → 냉장고 → 잔으로 바뀌므로 짧은 질문 대부분이 새 권리·비용을 연다.
- 덧셈은 같은 대상과 권한을 `뭐가/누가/뭘/왜`로 되묻는 중반을 식당보다 조금 넓게 감산했다.
- 두 종지는 `누군가 손을 떼고 혼합된 물건이 이동한다`는 습관을 공유하지만 기능은 다르다.
  - 식당: 물건이 빠져나간 뒤 운영자의 노동과 두 소리가 남음
  - 덧셈: 혼합 기록 자체가 문밖으로 이동

이후 새 작품에서 다시 `잠깐 → 손을 펴 줌/놓음 → 물건을 들고 퇴장`을 쓰지 않는다.

---

# 5. 현재 다음 행동

가상 낭독과 최소 감산은 완료했다.

자동 실행하지 않는다.

가능한 다음 단계:

1. 현재 두 연결본을 독립 짧은 희곡으로 동결
2. 실제 배우·소품 테이블리딩이 가능할 때만 호흡과 필체 가독성 재측정
3. 사용자 선택 시 한 작품만 B2·30–40분 확장 후보로 전체 작품군에서 재심사

현재 금지:

- 가상 시간값을 실제 공연 시간으로 확정
- 초 단위 목표를 지문에 고정
- 더 많은 반문을 기계적으로 삭제
- 식당 종결과 덧셈 종결 변경
- 자동 3차 장면·B2·길이 승격
