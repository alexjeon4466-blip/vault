# 아직까지는 영혼의 선장입니다 — 4장 초안

> 서명칸 계보 1번 C1 조립, 네 번째 장면 (펜의 순회). Claude 초안 = 제안, 문장 소유권은 사용자.

## 4장 — 펜이 돈다

**시스템 (소리)**
승인 대기 중입니다. 서두르지 않으셔도 됩니다.

이번에는 B가 손목시계를 본다.

A, 펜을 집는다. 세 번째다.

뚜껑을 확인하고 — 열린 채였다 — 승인란 앞에 종이를 바로 놓고, 앉은 자세를 고친다. 준비가 길다.

펜촉이 내려간다. 한 뼘. 손가락 하나. 그리고 —

닿는다.

종이에 닿은 펜촉에서 잉크가 점 하나로 배어난다.

A, 긋지 못한다.

펜을 든다. 승인란 왼쪽 아래에 점 하나가 남아 있다. A, 그것을 본다. 손수건을 꺼내다가 — 만다. 지워지는 것이 아니다.

**A**
(펜을 C 쪽으로 내밀며) …위원님이.

C, 펜을 받는다.

이번에는 아무 말도 하지 않는다.

C, 승인란 앞에 앉는다. 점을 본다. 펜을 쥔 손이 종이 위로 갔다가, 그대로 돌아온다. 시도의 흉내도 내지 않는다.

C, 고개를 젓는다. 옆으로 — D에게 펜을 내민다. 순서상 옆자리라는 듯이.

D의 손이 나온다. 2장의 반 뼘보다 멀리. 펜에 거의 닿는다.

**B**
(빠르게) 자문은… 서명 자격이 없습니다.

D의 손이 멈춘다. 펜과 손가락 사이, 한 치.

사이.

**D**
(승인란을 보며, 누구에게랄 것 없이) 그때는… 틀려도, 사람이 틀렸습니다.

아무도 대답하지 않는다.

C는 내민 펜을 든 채고, A는 옛 뭉치 쪽을 보고 있고, B는 단말을 들었다가 — 내린다.

D, 손을 거둔다. 무릎으로.

C, 펜을 쥔 채 남았다. 받을 사람이 없다. 책상 건너 B를 본다.

**C**
(펜을 B 쪽으로) 그럼 그쪽이 좀. 들고만 있지 말고.

**B**
대리 서명은 불가합니다.

**C**
서명 말고요. 그냥… 뭐라도.

B, 펜을 받는다. 물건으로서 받는 손이다.

B, 펜을 든 채 승인란을 본다. 점 하나. 빈 칸.

B의 손이 종이 쪽으로 아주 조금 기운다.

**B**
(펜을 두 손으로 고쳐 쥐고) …저도 자격이 없습니다.

B, 펜을 A 앞에 내려놓는다. 두 손으로. 서류를 반납하는 동작이다.

펜이 제자리로 돌아왔다. 승인란 옆. 출발한 곳.

A, C, D, B — 넷 다 펜을 쥐었다. 승인란에는 점 하나.

벽 화면: `승인 대기 중`.

**C**
(작게) 한 바퀴 돌았네요.

아무도 대답하지 않는다.

(4장 끝)

## 조립 점검 (C1 규약)

- **무엇이 이동·변형됐는가**: 정보 — 서명 자격의 지도 완성(A 자격 있음·못 씀 / C 자격 있음·못 씀 / D 자격 없음·손은 나옴 / B 자격 없음·손은 기움 — 자격과 손의 방향이 어긋나는 네 가지 방식), D의 과거형 문장이 방에 놓임(받아주는 사람 없음 — B가 단말을 들었다 내리는 것으로 기록 불가만 동작화). 권한 — 펜이 전원을 돌지만 누구도 행사 못 함(맵 플롯 표 4행). 물성 — **승인란에 잉크 점 하나**(첫 표시 — 지워지지 않음, 5장 오류 결말 후보의 씨앗), 펜이 한 바퀴 돌아 제자리(A→C→D 앞 멈춤→B→A 앞), 뚜껑은 계속 열린 채(1장부터 — 잉크가 마르는 시간 누적). 몸 — 접근 거리의 계보: A 한 뼘(1장)→손가락 하나(1장)→**닿음**(4장, 점), D 반 뼘(2장)→한 치(4장).
- **어휘표 준수**: D 유일 발화 "그때는… 틀려도, 사람이 틀렸습니다"(승인란을 보며·혼잣말에 가깝게 — 회고, 교훈조 회피, 아무도 받지 않음) ○. C 소멸형 완성("이번에는 아무 말도 하지 않는다" + 시도의 흉내도 없음 — 1·2장의 수다와 대비). B "대리 서명은 불가합니다" 3회차 + "저도 자격이 없습니다"(어휘표 예시 문장 — 자격 없음이 안도인지 두려움인지 두 손의 동작에 맡김). 금칙어 0, 제목 문장 0.
- **봉인 지문 점검**: 경구 0. "물건으로서 받는 손이다" — 연기 지시(A류)로 판단. C의 "한 바퀴 돌았네요"는 대사로 처리(관객 몫의 요약을 인물의 지친 관찰로 — 봉인 지문이 아니라 발화, 그리고 아무도 받지 않음). 잉크 점도 사실 서술만("지워지는 것이 아니다"까지 — 물성의 성질).
- **연작공통 정합**: 펜 궤적 = 맵 4장 설계 그대로(A→C→D 앞 멈춤→B). B0의 펜 상태 변화("새 펜"에서 출발) — 점 하나가 이 편 펜의 고유 흔적으로 추가(2번 편의 "잉크 번짐"과 구분되는 최소 표시 — 연작 소품 연출 시 참조).
- **플롯 표 4장 대조**: 겉 사건(펜이 돎) ○ / 정보 이동(서명 자격의 지도 완성) ○ / 권한 이동(전원 순회·전원 미행사) ○ / 남는 물성(책상을 도는 펜의 궤적 — 잉크 점이 궤적의 물증) ○.
- 다음 조립: 5장 — 5차 알림(가장 짧은 간격, 여전히 정중). 결말 국면 — 맵 후보 3종(제자리 보류/든 손/오류) 중 조립하며 택. 4장의 잉크 점이 후보 3(오류 — 획 하나·날짜만·"서명이 인식되지 않았습니다")의 물리적 전제를 이미 마련. 계보 넘기기(무거운 빈 칸 → 2번 거짓) 관점에서는 후보 1(제자리)이 가장 순수 — C2 전 사용자 판단 요청 예정.
