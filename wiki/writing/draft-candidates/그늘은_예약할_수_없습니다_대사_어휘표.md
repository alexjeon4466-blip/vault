# 그늘은 예약할 수 없습니다 — 대사 어휘표

> B3 산출물. 물성표는 생략 — 구조 맵의 구체소재 표가 실물 사양·상상력 방향·권한 이동을 이미 담음(파이프라인 B3 조건부 조항 적용). 아래 문장은 전부 **가설(제안)** — 최종 문장은 사용자 소유.

## 상수 문구 (반복될 말 — 반복마다 다른 일을 해야 함)

| 문구 | 화자 | 반복의 변화 |
|---|---|---|
| "확인이 안 됩니다" | B·시스템 | 1장: A의 체크인 → 3장: 그늘의 좌표 → 4장: B 자신의 재배정 권한. 확인 불가의 대상이 점점 시스템 쪽으로 |
| "이용 시간 30분입니다" | B → 안내판 | 처음엔 규정, 나중엔 그늘 자신이 30분을 안 지킨다는 농담이 됨 |
| "사전 예약자 우선입니다" | B·C | C가 쓸 때는 권리, B가 쓸 때는 곤란 — 같은 문장의 주인이 바뀜 |
| "저쪽으로 갔는데요" | A·C | 그늘의 위치 보고 — 매번 다른 사람이 하게 됨 |

## 금칙어 (설명어·감정어 — 쓰는 순간 논제극이 됨)

- **개념어 금지**: 공공재, 권리, 환대, 자격, 공정, 약자 — 전부 절차어·사물어로 낮춘다 (자격 → "체크인", 공정 → "순서대로").
- **감정 직접 진술 금지**: "억울해요", "불공평하잖아요", "너무하네요" — 몸으로 (부채질 속도, 자리 당겨 앉기, 물통 쥐는 손).
- **더위 형용 남용 금지**: "덥다/뜨겁다"는 각 인물당 1회 이하 — 더위는 말이 아니라 젖은 등판·반사광·마른 노즐로.
- **B의 '그늘' 발화 유예**: B는 4장까지 '그늘'이라는 단어를 피하고 '좌석'·'구역'으로만 말한다 — B가 처음으로 "그늘이…"라고 말하는 순간이 B의 전환 비트 (5장 초입 후보).

## 인물별 어휘 결

| 인물 | 결 | 예 (가설) |
|---|---|---|
| A | 나무·세월·자리의 말. 짧은 존대. 시스템 어휘를 자기 말로 바꿔 부름 | "나무가 저한테 먼저 왔는데요" / QR을 "이 네모"라고 부름 / "이십 년을 여기 앉았는데 등록은 처음 듣네요" |
| B | 규정 인용체, 명사형 종결. 사과 대신 절차 안내 | "확인되셨습니다" / "이용 완료 처리됩니다" / "그건 민원 사항입니다" |
| C | 앱·소비자 어휘. 표준 민원체 — 정중하고 집요 | "예약 내역 보여드릴게요" / "그럼 환불 규정은요" / "리뷰에 쓸 건 아니고요" |
| D | 최소 발화. 사물 주어, 완결문 회피 | "그늘이요." / "물이요." / (유일한 긴 문장) "조금 있으면 저쪽으로 갑니다" — **전체 1회** |
| 시스템(알림음·문자) | 완전 문장, 무정한 정중 | 「재배정이 완료되었습니다」 「잔여 좌석 1」 「이용에 불편을 드려 죄송합니다」 |

## 장면별 대표 문장 후보 (한 장면 한 문장 — 조립 전 가설)

| 장 | 대표 문장 후보 | 비고 |
|---|---|---|
| 1 | A: "나무가 저한테 먼저 왔는데요" | 씨앗의 정점 — 극 전체의 명함 |
| 2 | C: "예약한 그늘이 없습니다" | 문제 선언 — 이후는 절차로만 |
| 3 | D: "조금 있으면 저쪽으로 갑니다" | D의 유일한 긴 문장을 여기에 소진 |
| 4 | C: "저 지금 그늘 밖에서 그늘을 예약하고 있어요" | 규칙을 지킬수록 멀어지는 자의 자각 — 웃기고 서늘하게 |
| 5 | (대표 문장 없음 — 빛과 이동만) | 침묵이 대표. B의 마지막 발화는 낮춘 한 마디만 허용 |

경합하는 좋은 문장은 화면(앱 알림)·행동(옮겨 앉기)·소리(체크인 성공음)로 전환한다.
