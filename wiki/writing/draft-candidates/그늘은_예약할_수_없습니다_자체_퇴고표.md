# 그늘은 예약할 수 없습니다 — 자체 퇴고표

## 목적

이 극을 우화·풍자·교훈극으로 만들지 않기 위한 장면 내부 점검표. 장면 초안마다 통과시킨다.

핵심은 이것이다.

> 그늘이 상징이 되는 순간 극은 죽는다. 그늘은 시원함이고, 시원함은 지금 여기 앉을 자리 문제다. 관객이 "그늘 = 복지/공공재/자연"이라고 번역하기 시작하면, 무대의 그늘이 일을 멈춘 것이다.

## 1차 퇴고표 — 장면이 해설로 새는가

| 점검 항목 | 위험 신호 | 낮추는 방식 |
|---|---|---|
| 이 문장을 빛이 대신 할 수 있는가 | 그늘 위치를 말로 중계 — "그늘이 저쪽으로 갔네요" | 조명 전환 + 인물의 이동으로. 위치 언급은 A의 "이쪽으로 오네요"처럼 주어 없는 말까지만 |
| 이 문장을 단말·앱 소리가 대신 할 수 있는가 | B·C가 규정·잔여 시간을 대사로 설명 | 성공음, 알림 음성, "남은 시간 이십삼 분" — 시스템이 직접 말하게 |
| B가 악역이 되는가 | 비꼬기, 권한 과시, 일부러 세운 절차 | B의 곤란은 규정의 곤란. B는 정확하고 성실할수록 우스워야 한다 (안내판 5cm, 앉아서 견디기) |
| 인물이 상징으로 굳는가 | A=밀려난 세월, D=민중의 지혜, C=소비자주의 — 라는 등식이 대사에 비침 | A에게는 방석·신문·자리의 실무를, D에게는 걸레·물통·발의 실무를, C에게는 환불·리뷰·문의 버튼의 실무를 계속 준다 |
| 더위·불공평을 형용하는가 | "덥다", "너무하네요", "불공평하잖아요" | 젖은 수건, 이마의 땀, 한 뼘씩 옮겨 앉기, 부채질 속도 |
| 논제 대사가 나오는가 | "그늘은 예약할 수 없는 거잖아요" (제목의 대사화 — 최대 금기) | 제목 문장은 극 중 누구도 말하지 않는다. 무대가 증명하고 관객이 결론 낸다 |

## 2차 퇴고표 — 인물별 삭제 기준

### A — 세월이 논변이 되면 삭제

A는 권리를 주장하지 않는다. A는 앉아 있다. "이십 년"은 이력이지 논거가 아니다.

- 삭제할 결: "내가 먼저 왔잖아요" / "노인은 어디 앉으라고" / "옛날엔 이런 거 없었어"
- 남길 결: "나무가 저한테 먼저 왔는데요" / 방석을 쓸어내리는 손 / 더 깊이 앉기
- **긴장 지점 (1장)**: "이 방석이 나보다 여기 오래 있었어요" — 좋은 문장이지만 대표 문장("나무가…")과 같은 결의 경합. 유지/낮춤(방석을 쓸어내리는 행동만 남김)은 사용자 결정

### B — 규정 밖으로 나오면 삭제, 인격 밖으로 나와도 삭제

- 삭제할 결: 사과("죄송하게 됐네요")·한탄("저도 힘듭니다")·냉소("규정이 그렇다는데 어쩌겠어요")
- 남길 결: 명사형 종결, 단말 읽기, "개인 자격으로 했습니다"처럼 자격을 쪼개는 방어
- B의 '그늘' 발화 유예(어휘표) 위반 여부를 매 장면 확인 — 첫 발화는 5장 초입 후보로 아껴둔다

### C — 민원이 정의감이 되면 삭제

C는 옳아서 싸우는 게 아니라 30분을 샀기 때문에 확인한다. C의 집요함은 소비자의 집요함.

- 삭제할 결: "저 같은 사람이 말 안 하면 안 바뀌어요" / 약자 연대 선언
- 남길 결: "그럼 환불 규정은요" / 화면 내밀기 / 또박또박 받아쓰게 하기

### D — 침묵이 깊이가 되면 삭제

D의 무발화는 신비가 아니라 피로다. D는 아껴 말하는 게 아니라 말할 필요가 없다.

- 삭제할 결: 의미심장한 응시, 느린 고개 젓기, 미소 (전부 '지혜로운 침묵' 연출로 새는 길)
- 남길 결: 걸레 짜기, 물통 옮기기, 물 마시기 — 전부 일과 갈증의 실무
- 발화 예산 재확인: "그늘이요." "물이요." + 긴 문장 1회(3장 예약)뿐

## 최종 삭제 원칙

대사를 물성·절차어·행동으로 낮출 수 있으면 줄인다. 낮춘 결과가 어색하면 그 대사는 애초에 설명이었다.

## 통과 기록

- 1장 초안 (2026-07-06): 통과 — 긴장 지점 1건 지목(A의 방석 문장, 위 2차 표), 논제 대사 0, B 악역화 0. → **사용자 판정: 유지** (대표 문장과 결이 같아도 방석은 A의 유일한 소유물 논리라 따로 섬).
- 2장 초안 (2026-07-06): 통과 — "개인 자격으로 했습니다" 유지 확정. 더위 형용 0 유지 확인.
- 연결부 긴장 2건 사용자 판정 (2026-07-06): 소품 — 접힌 신문이 곧 부채(2장 "부채로"는 신문을 가리킴, 별도 소품 없음) / 쿨링포그 — 1장 멈춤은 간헐 분사의 주기 종료, 맵 4장은 '금일 가동 종료'로 구분.
