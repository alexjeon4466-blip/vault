# 관청의 일을 떠맡지 않겠습니다 — 대사 어휘표

> B3 산출물. 물성표는 생략 — 구조 맵의 구체소재 표가 실물 사양·상상력 방향·권한 이동을 담음(파이프라인 B3 조건부 조항). 아래 문장은 전부 **가설(제안)** — 최종 문장은 사용자 소유. 이 편은 계보의 부조리 희극 — 어휘의 희극성이 조롱이 아니라 전원의 무력에서 오도록.

## 상수 문구 (반복될 말 — 매 반복이 다른 일을 해야 함)

| 문구 | 화자 | 반복의 변화 |
|---|---|---|
| "보안을 위해 세션이 만료되었습니다. 처음부터 다시 인증해 주세요." | 단말 | 장 경계마다. **음색·문구 동일, 간격만 규칙적으로** — 반복이 교착을 리셋하며 매번 다른 근거를 끌어냄. 이 편 시그니처(연작 넘김 아님) |
| "마지막 확인만 누르시면 됩니다." | B | 1장 안내→2장 재안내→3장 지친 반복→5장 거의 애원. 같은 문장이 안내에서 부탁으로 무너짐 |
| "그건 당신들이 정한 거잖아요." / "제 손으로는 안 합니다." | A | 1장 항변→3장 논리→5장 그냥 사실 진술. 화냄이 빠지고 태도만 남음 |
| "제가 눌러드릴까요?" | C | 3장 호의→(본인 인증 막힘)→4장 못 하는 손. 선의가 규정에 막히는 반복 |
| "대리 확정은 규정상…" | B·D | 2장(B)→4장(D가 같은 말을 확인). 권한자 둘이 같은 벽 앞에 서는 것으로 벽의 높이를 보임 |

**연작 상속**: 펜은 이 편에서 **놓인 채 안 쓰임**. 상수 문구는 이 편 고유(세션 만료). 계보로 넘기는 것은 문구가 아니라 **놓인 펜 + "비우는 것조차 클릭으로 대체된다"는 상태**.

## 금칙어 (설명어·개념어 — 쓰는 순간 논제극이 됨)

- **개념어 금지**: 관료주의, 시스템(추상 명사), 책임(추상), 위임, 주체, 자기결정, 소외. 전부 절차어·물건으로 — 위임 → "대신 눌러주기"의 물리적 불가, 책임 → 본인 인증·확정 버튼.
- **원작 이미지 금지**: 칼, 처형, 심판, 유죄, 법원. 카프카 직수입 0. 집행의 무게는 버튼의 정적으로만.
- **감정 직접 진술 금지**: "부조리하다", "억울하다", "무력하다" — 버튼 위 허공의 손가락, 세션 만료에 한숨, 놓인 펜을 집었다 놓기로.
- **제목·명제 대사화 금지**: "관청 일을 왜 내가", "이건 당신들 책임" 류 추상 선언 금지. "그건 당신들이 정한 거잖아요"까지가 허용 상한(구체·현장 어휘).
- **시스템 위협 표현 금지**: `~하셔야 합니다` 아니라 `~하시면 됩니다`, `~해 주세요`의 정중체. 만료도 "보안을 위해"라는 배려 형식.

## 인물별 어휘 결

| 인물 | 결 | 예 (가설) |
|---|---|---|
| A | 절차엔 협조적인 담담한 말. 화내지 않음 — 거부는 태도지 항의가 아님 | "인증은 할게요." / "그건 당신들이 정한 거잖아요." / "제 손으로는 안 합니다." |
| B | 규정 인용체, 정중한 명사형. 반복될수록 안내→부탁으로 톤만 내려감 | "마지막 확인만 누르시면 됩니다." / "대리 확정은 규정상 불가합니다." / "…한 번만요." |
| C | 대기자의 참견체 → 선의가 막히며 조용해짐 | "제가 눌러드릴까요?" → "아, 본인만…" → "…저라도 못 누르겠네요." |
| D | 관리자의 해결사체 → 규정 앞에 같은 무력 확인 | "제가 보겠습니다." / "이건… 본인 절차가 맞네요." / "죄송합니다, 저도 권한이…" |
| 단말 | 완전 정중, 무정. 배려 형식의 존대 | "세션이 만료되었습니다." / "본인만 확정하실 수 있습니다." / "금일 업무가 종료되었습니다." |

## 장면별 대표 문장 후보 (한 장면 한 문장 — 조립 전 가설)

| 장 | 대표 문장 후보 | 비고 |
|---|---|---|
| 1 | A "그건 당신들이 정한 거잖아요." | 교착의 명함 — 위임 거부의 논리 씨앗 |
| 2 | B "마지막 확인만 누르시면 됩니다." (손을 뻗다 거둠) | 대리 클릭 시도가 규정에 막히는 몸 |
| 3 | C "제가 눌러드릴까요?" → "아, 본인만…" | 선의의 위임이 물리적으로 불가함 |
| 4 | D "이건… 본인 절차가 맞네요." | 해결사의 항복 — 권한자 둘이 같은 벽 앞 |
| 5 | (대표 문장 없음 — 세션 만료음과 마감 안내만) | 침묵·버튼의 정지가 대표. 결말 후보에 따라 단말의 마지막 한 줄 |

경합하는 좋은 문장은 화면 문구(`본인 확인 후 확정`)·행동(안 닿는 손가락, 집었다 놓는 펜)·소리(규칙적 세션 만료음)로 전환한다. **부조리 희극의 웃음은 워크어라운드가 매번 규정에 막히는 리듬에서** — C의 대리 시도, B의 뻗다 거둔 손, D의 해결사 등장과 항복. 웃음 뒤에 오는 서늘함은 5번(강요) 편으로 넘기는 "놓인 펜"이 담당.
