# 아직까지는 영혼의 선장입니다 — 대사 어휘표

> B3 산출물. 물성표는 생략 — 구조 맵의 구체소재 표가 실물 사양·상상력 방향·권한 이동을 이미 담음(파이프라인 B3 조건부 조항, 그늘 극에 이어 두 번째 적용). 아래 문장은 전부 **가설(제안)** — 최종 문장은 사용자 소유.

## 상수 문구 (반복될 말 — 매 반복이 다른 일을 해야 함)

| 문구 | 화자 | 반복의 변화 |
|---|---|---|
| "승인 대기 중입니다. 서두르지 않으셔도 됩니다." | 시스템 | 장 경계마다. **음색은 동일, 간격만 좁아짐** — 1장 여유→5장 촘촘. 재촉 없는 재촉. 이 편의 시그니처 문구(연작 넘김 대상 아님, 이 편 고유) |
| "형식입니다." | A | 1장 자기 확신→3장 자기 변명→5장 자기 앞에서 무너짐. 형식이라 쉽다던 말이 형식이라 못 쓴다로 |
| "그냥 하면 되잖아요." | C | 2장 큰소리→4장 자기 차례엔 말이 안 나옴(침묵으로 반전). 반복이 아니라 **소멸로 기능** |
| "대리 서명은 불가합니다." / "제가 대신 못 합니다." | B | 2·3·4장. 규정 방어→3장 보류 불가와 결합→4장 자신도 못 쓰는 사람임이 드러남 |
| "보류는 항목에 없습니다." | B·시스템 | 3장 도입→이후 침묵의 근거로 재활용. 미승인=무한 대기 |

**연작 상속**: 펜은 이 편에서 **새것**. 상수 문구 중 "승인 대기 중입니다"는 이 편 고유(다른 편은 각자 시그니처). 계보로 넘기는 것은 문구가 아니라 **무거운 빈 칸** 그 자체.

## 금칙어 (설명어·개념어 — 쓰는 순간 논제극이 됨)

- **개념어 금지**: AI, 알고리즘, 자동화(남발), 기술, 인간(명사), 영혼, 주체성, 책임(추상). 전부 절차어·물건으로 — 자동화 → `자동 처리`, 책임 → 서명란·폐회 조건.
- **감정 직접 진술 금지**: "무섭다", "두렵다", "떨린다" — 손의 머뭇거림(펜을 쥐었다 놓기), 침 삼킴, 펜을 남에게 미는 몸짓으로.
- **제목·명제 대사화 금지**: "인간이 영혼의 선장", "아직까지는 우리가" 류 — 절대 금지(계보 공통 규율). 빈 칸을 못 채우는 몸으로만.
- **시스템 위협 표현 금지**: 시스템은 협박하지 않는다. `~하셔야 합니다`가 아니라 `~하시면 됩니다`, `서두르지 않으셔도 됩니다`의 정중체 유지.

## 인물별 어휘 결

| 인물 | 결 | 예 (가설) |
|---|---|---|
| A | 의장 경력의 정돈된 말. 형식을 아는 자의 냉정 — 그러나 손은 따로 논다 | "형식입니다." / "예전엔 여기서 반대 의견을 달았죠." / (펜을 쥐고) "…." |
| B | 규정 인용체, 명사형 종결. 두려움을 규정 뒤에 숨김 | "대리 서명은 불가합니다." / "규정상 폐회는 승인 이후입니다." / "저도… 자격이 없습니다." |
| C | 신참의 자신감체 → 후반 어휘 축소가 곧 붕괴 | "그냥 하면 되잖아요." → "제가요?" → "…." |
| D | 거의 침묵. 옛 심사위원의 말은 발언권에 막혀 삼켜짐. 유일한 발화 1회(4장) | (자문 라벨을 보며) "그때는 틀려도, 사람이 틀렸습니다." |
| 시스템 | 완전 정중, 무정. 완결형 존대 | "승인 대기 중입니다." / "보류는 항목에 없습니다." / "서명이 인식되지 않았습니다." |

## 장면별 대표 문장 후보 (한 장면 한 문장 — 조립 전 가설)

| 장 | 대표 문장 후보 | 비고 |
|---|---|---|
| 1 | A "형식입니다." | 극의 명함 — 형식이라는 말이 아이러니의 씨앗 |
| 2 | C "그냥 하면 되잖아요." | 다음 장에서 자기가 못 하게 될 말 |
| 3 | B "보류는 항목에 없습니다." | 출구 없음의 선언 |
| 4 | D "그때는 틀려도, 사람이 틀렸습니다." | D의 유일한 발화(발언권 밖에서 새어 나옴) — 계보 주제를 압축, 교훈조 아닌 회고로 |
| 5 | (대표 문장 없음 — 펜의 정지와 시스템 안내만) | 침묵이 대표. 결말 후보에 따라 시스템의 마지막 한 줄 |

경합하는 좋은 문장은 화면 문구(`전 안건 자동 처리 완료`)·행동(펜 미루기)·소리(간격 좁아지는 알림음)로 전환한다. **D의 4장 발화는 이 편에서 유일하게 '판단의 책임'을 말로 건드리는 지점** — 한 번만, 그리고 아무도 받아주지 않아야 한다(발언권 없음의 확인).
