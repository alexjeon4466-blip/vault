# 운전자는 내가 될 겁니다 — 4장 초안

> 서명칸 계보 2번 C1 조립, 네 번째 장면 (대질 — C의 침묵이 선택이 되는 곳). C에게 대사를 주지 않는다(어휘표 원칙). Claude 초안 = 제안, 문장 소유권은 사용자.

## 4장 — 대질 확인

**B**
(서식을 넘긴다) 대질 확인 항목입니다. (C 쪽으로 의자를 반쯤 돌린다) 동승자분.

C, 고개를 든다.

**B**
몇 가지만 여쭙겠습니다. 진술 확인 절차라서요.

C, 끄덕인다.

**B**
사고 당시… 어디에 앉아 계셨습니까.

사이.

긴 사이.

A, 입을 연다 —

**B**
(A 쪽으로 손바닥을 든다. 시선은 C에게 둔 채.) 두 분께 각각 여쭙는 절차입니다.

A, 입을 닫는다.

사이가 이어진다. C의 손이 무릎 위에 있다. 올라가지 않는다. 어깨로 가지 않으려고 무릎을 잡고 있는 손이다.

**B**
…질문을 바꾸겠습니다. 벨트는 착용하셨습니까.

C, 끄덕인다.

**B**
사고 순간을 보셨습니까.

C, 끄덕인다. 아주 작게.

**B**
운전자가 감속하는 것을 보셨습니까.

사이.

C, 움직이지 않는다. 끄덕임도, 저음도 없다.

**B**
(볼펜을 종이 위에 세운 채) 동승자분. 제가 적을 수 있는 건 진술입니다. 끄덕임은… 적을 수가 없습니다.

사이.

C, B를 본다. 눈이 마주치는 시간이 길다.

C, 입을 연다. 숨이 들어간다.

말이 되지 않는다. 입이 닫힌다.

C의 손이 무릎에서 올라와 왼쪽 어깨에 닿는다. 두 번째다. B의 시선이 C의 손 언저리를 지나간다 — 지나갔는지, 머물렀는지, 각도로는 알 수 없다.

**B**
(서식으로 돌아앉는다) …답변 없음.

B, 적는다. 볼펜이 오래 걸린다. '답변 없음' 넉 자보다 오래.

**A**
(작게) 저 친구는 놀라서, 아직—

**B**
(적으면서) 진술은 본인만 하실 수 있습니다.

A, 입을 닫는다. 자기가 두 번 막힌 것을 안다.

B, 대질 항목을 덮는다. 다음 장이 마지막 장이다. 책임자 서명란.

B, 넘기지 않고 잠깐 그대로 있다.

**B**
…오 분 쉬었다 하겠습니다.

B, 일어나 나간다. 볼펜은 서식 위에 놓인 채.

A와 C, 둘만 남는다.

긴 사이.

둘 다 아무 말도 하지 않는다. A는 서명란이 있는 서류 쪽을 보고, C는 A의 등을 본다.

C의 입이 열리려 한다 —

문이 열린다. B가 돌아온다. 종이컵 두 개. A 앞에 하나, C 앞에 하나.

**B**
(앉으며) 마지막 항목 하겠습니다.

(4장 끝)

## 조립 점검 (C1 규약)

- **무엇이 이동·변형됐는가**: 정보 — C의 침묵이 회피에서 **능동적 선택**으로(핵심 질문 앞의 무반응 — 끄덕임조차 거부, "감속하는 것을 보셨습니까"는 예스도 노도 거짓이 되는 질문이라 침묵만 진실), '답변 없음'이 서류에 글자로(B의 볼펜이 넉 자보다 오래 걸림 — 무엇을 더 쓸지 말지의 시간, 유보 유지), A의 개입이 절차에 2회 차단(손바닥·"진술은 본인만"). 권한 — C가 무너뜨릴 힘을 쥐고 안 씀(맵 플롯 표 4행), B가 처음으로 절차를 사람에게 직접 겨눔. 물성 — 무릎을 잡는 손(어깨로 가지 않으려는), 어깨 만짐 2회차, 종이컵 둘(B의 돌아옴 — 절차 밖의 최소 온기, 설명 없음), 서명란 직전에서 멈춘 서식.
- **C 무대사 원칙 이행**: 발화 0 — 숨이 들어가고 말이 되지 않는 것까지만. 둘만 남는 사이에서도 입이 "열리려" 하는 데서 문이 열림(말의 자리를 문이 대신 — 극적 우연이되 B의 복귀 타이밍은 각도 유보와 함께 B의 앎 문제를 열어둠).
- **어휘표 준수**: 4장 대표 = C의 침묵(B의 질문 뒤 응답 없음) ○. 자백 대사 0, 원작 정서어 0. B의 시선 각도 유보("지나갔는지, 머물렀는지, 각도로는 알 수 없다" — 정보차이표의 관객 유보 지정을 지문 층에서 수행).
- **봉인 지문 점검**: 경구 0. "예스도 노도 거짓이 되는 질문" 류 해설을 지문에 쓰지 않음(점검에만 기재). "어깨로 가지 않으려고 무릎을 잡고 있는 손" — 연기 지시 판정.
- **플롯 표 4장 대조**: 겉 사건(대질) ○ / 정보 이동(침묵의 능동화) ○ / 권한 이동(C가 힘을 쥐고 안 씀) ○ / 남는 물성(오래 멈춘 볼펜) ○.
- 다음 조립: 5장 — 책임자 서명란. 결말: 맵 권고에 따라 **후보 1(번진 이름) 기반 + 후보 2의 C 유일 발화("펜, 여기요") 결합** — C가 펜을 건네는 손으로 공모가 완성되는 설계. C2 전 사용자 교체 가능.
