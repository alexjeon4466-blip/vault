# 끊어진 뒤에만 이어지는 관계 — 구조 맵

> **현재 단계: B1 소집 (2026-07-23)**. 사용자 선택 완료. 이 문서는 B1 소집 카드까지만 채워져 있고, B2 구조 맵 절은 사용자 확인 후 추가한다. 형식표·B2 구조는 아직 잠그지 않았다.

## 운반체 확정

- 경합 없음. 관계자격 계열(계열 지도 §2)의 **독립 강자**로, 계열 운반체(`수정된 보호자`, 개작 중)와 자리를 다투지 않는다. 별도 운반체로 진입한다.
- 큐 반납 이력 없음(신규 진입).

## 사용자 선택 기록

- 선택: **끊어진 뒤에만 이어지는 관계** (2026-07-23, 사용자).
- 쓰고 싶은 이유(추천 사유 승계): 아이러니 엔진 — *연락을 끊는 규칙을 지키기 위해서만 계속 연락해야 한다* — 이 vault 핵심 미학(해결 행동이 반대 상태를 만든다)에 정면으로 부합한다. 선행 결정·민감 소재가 없어 B1→B2가 매끄럽다.
- 형식 병렬 탐색은 명시적으로 고르지 않았으므로 B2를 하나의 형식으로 잠그지 않는다.

## 무원칙 보호 카드

교리·형식표를 적용하기 전에 먼저 고정한다. 이후 모든 표는 이 카드를 훼손하는지 검토하는 도구다.

| 보호 항목 | 내용 |
|---|---|
| **작품의 약속** | 재결합도 완전한 결별도 아닌, "끝내기"라는 공동 작업이 자꾸 미뤄지는 시간을 관객이 함께 견디게 한다. 감정의 폭발이 아니라 **절차의 정교화**가 관계를 연장한다. |
| **가장 강한 이미지·행동** | 주인이 불분명한 물건 하나가 나올 때마다 "마지막 연락"의 날짜가 갱신되는 것. 물건을 버리지 않고 **연락 규칙만 더 정교하게 다듬는 손**. |
| **온도·리듬** | 건조하고 사무적. 감정을 직접 말하지 않고 규칙·날짜·물건 분류의 언어로 대체한다. 반복될수록 규칙 조항이 늘어나는 **축적의 리듬**. |
| **장면 생성 원리** | `물건 하나 → 소유 판정 불능 → 규칙 보강(마지막 연락 날짜 갱신)`. 이 회로가 한 번 돌 때마다 "끝"이 한 칸 더 멀어진다. 해결하려는 행동이 정확히 반대 상태(연장)를 만든다. |

**기존 작품과 다른 점**: 『관계란』은 관계를 이름·서류·법적 자격으로 **진입/등록**하려는 방향이다. 이 작품은 관계를 **종료**하려는 시도가 실패하는 반대 벡터다. 같은 관계자격 계열이되 방향이 뒤집혀 있어 자기복제가 아니다.

## 부품 서랍 소집

관계자격 계열(§2)과 교차 계열의 자산을 목록화하고 쓸 것/보류/반환을 정한다. **부품을 많이 쓰는 것이 발전은 아니다.**

| 자산 | 출처 | 판정 | 사유 |
|---|---|---|---|
| "주인이 불분명한 물건" 모티프 | 이 글감 고유 | **쓸 것** | 회로의 트리거. 단, 물건은 규칙을 부르는 장치일 뿐 주제가 아니다(아래 위험 참조) |
| 규칙·조항 언어(사무적 문체) | 관계란 계보 + 서명칸 계보의 공식 언어 결 | **쓸 것(절제)** | 감정을 대체하는 건조한 어휘. 단 서식·창구·담당자 제도극 문법으로 수렴 금지 |
| 《하나 남는 것》(독립했던 살림이 돌아온 집, 2026-07-20) — 냄비 포개기·뚜껑 하나 남음 | 물건 배분 관계 장면 | **보류(차별화선)** | 자기복제 위험. 아래 참조 |
| 《두 가지 도망》(2026-07-21, 배치51) — 젖은 물건 배분 | 물건 배분 관계 장면 | **보류(차별화선)** | 자기복제 위험. 아래 참조 |
| 관계자격 4부작(병합 B) 재료 | 계열 §2 병합 후보 | **반환** | 등록/진입 방향이라 이 종료-방향 작품과 결이 다름. 서랍으로 돌려보냄 |

## 자기복제 위험 — 차별화선 (핵심)

`끊어진_뒤에만` · 《하나 남는 것》 · 《두 가지 도망》 세 편이 **"물건을 나누며 관계를 처리한다"**는 엔진을 공유한다. 세 편이 물건 나누기로 수렴하면 안 된다.

- 이 작품의 고유성은 물건 배분이 아니라 **"연락을 끊는 규칙 자체가 다시 연락하는 이유가 된다"는 순환**이다.
- 그러므로 이 작품은 **"마지막 연락"이라는 시간 규칙을 전면에, 물건은 최소화**한다. 물건은 규칙을 갱신시키는 방아쇠로만 등장하고, 물건의 소유·정리 자체를 클라이맥스로 만들지 않는다.
- 《하나 남는 것》은 물건의 잔여(뚜껑 하나)가, 《두 가지 도망》은 폐기/보존의 태도 대립이 중심이다. 이 작품은 **관계 종료의 절차적 불능**이 중심이다. 세 물성(냄비·젖은 상자·주인 불명 물건)이 서로 달라야 한다.

## 자연 규모와 외부 제약 (분리)

| 칸 | 값 |
|---|---|
| 현재 자연 규모 가설 | 2인 · 한 집(물건 나누는 하룻밤) · 최소형~중형 단막. "마지막 연락 갱신" 회로가 몇 번 도는지가 규모를 정함. 실측은 C2 이후 |
| 형식 어포던스 가설 | F1 연속 체류(한 밤) 안에서 F2 수직 반복("마지막 연락" 규칙의 상태 변주). **형식표는 아직 만들지 않음** — 자연 규모·시간 조직이 실제 병목으로 드러날 때만 |
| submission_target | **미정** — 외부 제약 미정. 이를 이유로 30–40분 단막을 기본값으로 넣지 않는다 |
| AI 규정 | 목표 공모 미정 → 확인 불요(미정) |

## B1.5 탐색 방식 (다음 단계 후보 — 사용자 확인 대기)

- **실제 병목**: 사람·대사·관계 — 두 사람의 말투·간격, "규칙을 정교화하는" 언어가 실제로 살아나는가, 그리고 규칙 추가가 *같은 예시의 반복*이 아니라 *다음 조건을 만드는지*.
- **우선 탐색(추천)**: 2–5쪽 실험 장면 — 물건 1~2개가 나오며 "마지막 연락" 날짜가 갱신되는 대화 조각. 물성·동선 시험 불요(물건 최소, 공간 가독성은 병목 아님).
- **대안**: 보호 핵심·장면 생성 원리가 이미 충분하다고 보면 B1.5를 생략하고 바로 B2 구조 맵으로. (다만 "규칙 축적이 다음 조건을 만드는가"가 미확인이라 짧은 쓰기 탐색이 값싸고 유용하다.)

# B2 구조 맵 (2026-07-23)

> B1.5 탐색([[wiki/writing/draft-candidates/끊어진_뒤에만_이어지는_관계_B1.5탐색_2026-07-23|《마지막 연락》]])에서 장면 생성 원리(조항 escalate)가 확인되어 작성. 선택 형식 = **F1 연속 체류 + F2 수직 반복 결합형**. 아직 B4 미통과 = 잠금 아님.

## B2 선택 카드

| 항목 | 내용 |
|---|---|
| 보호할 핵심 | "끝내기"의 절차적 정교화가 관계를 연장하는 회로. 물건은 방아쇠, **"마지막 연락" 시간 규칙이 전면**. 원문 추상어(부조리·이혼·끈) 비발화 |
| 선택 형식 | F1 연속 체류(정리하는 하룻밤·한 자리) 안에서 F2 수직 반복(조항 갱신). 결합형 |
| 자연 규모 가설 | 2인 · 한 방 · 연속 시간. **최소형**(조항 유형 사다리가 점→조건→반복 3칸에서 닫힘 — 재검토 §1). 중형은 물건을 더 넣어서가 아니라 다른 연료(종이 물성·A/B 관계 심화)로만 |
| 시간 연료 | 조항이 `점(날짜)→조건→반복`으로 escalate. 각 갱신이 다음 갱신의 근거가 됨(B1.5 검증) |
| 자기복제 위험 | 《하나 남는 것》·《두 가지 도망》과 물건-나누기 엔진 공유 → 차별화선: 시간 규칙 전면·물건 최소·물건 정리를 클라이맥스로 안 만듦 |
| 빠진 연료 | ① 왜 *지금* 끝내려 하는가(둘의 동기)가 아직 무발화 — 무발화 유지가 온도에 맞으나 최소 한 겹의 실제 압력 필요 여부 미확인 ② 세 번째 방아쇠(화분) 상투성 |
| 외부 제출 제약 | **미정**. 30–40분 기본값 넣지 않음 |

## 장소·시간 조직

- **한 장소**(정리 중인 방), **연속 시간**(하룻밤 정리). 시간 점프·몽타주 없음.
- 출입: 없음 또는 최소(B가 나가려다 멈추는 것이 유일한 출입 압력).
- **종이 한 장이 시간 축을 시각화한다** — 맨 위 오늘 날짜가 지워지고 그 아래 조항이 쌓이는 물성이 곧 "밀려나는 끝".

## 작동 압력

- **하려는 것**: 둘 다 "오늘로 정리를 완료"하려 한다.
- **막는 것**: 주인 불명 물건마다 소유 판정 불능 → 규칙으로 미봉 → **그 규칙이 다시 연락할 이유가 된다**. 대항력을 인물 스스로 생성한다(외부자 없음).
- **압력이 처음 행동을 바꾸는 지점**: 첫 물건(충전기)에서 "오늘"을 지우고 날짜를 다시 적는 순간 — "끝"이 처음으로 뒤로 밀린다. (절차적 압력은 이 작품의 자연 엔진이지 보편 의무로 넣은 것이 아니다.)

## 인물·대항력 표

| 주체 | 정체 | 대항력으로 작동하는 지점 |
|---|---|---|
| A | 방에 **남는** 사람 | 규칙을 "정확하게" 만들자고 주도(현재 가설) — 정교화가 곧 연장 |
| B | **떠나는** 사람 | "이거 점점 길어진다"며 멈칫하지만 결국 펜을 든다 — 저항과 공모를 오감 |
| (비인물) 함께 만든 규칙 · 주인 불명 물건 · 종이 | — | 실제 대항력. 서로가 적이 아니라, 둘이 합작한 절차가 끝을 막는다 |

- **A/B 비대칭**: 규칙 정교화는 A가 주도하지만, **영구(반복) 조항의 펜은 떠나는 B가 든다**(재검토 §3) — 남는 사람이 아니라 떠나는 사람이 안 끝나는 규칙을 봉인한다. 실은 떠나는 쪽이 실을 가장 필요로 한다는 답. 갱신별 주도권 교대의 세부는 C1에서.

## 정보·권한·관객 표

| 층 | 아는 것 / 권한 | 언제 달라지나 |
|---|---|---|
| 인물 | 둘 다 사실은 끝내고 싶지 않다는 것을 안다. 그러나 **인정하지 않는다** | 끝까지 무발화 유지(작품의 약속) |
| 권한 | **종이에 적는 손 = 규칙 제정권**. 갱신마다 누가 펜을 드는지가 권한 이동 | 매 사이클 |
| 관객 | 2회차(조건형)에 "끝이 안 올 것 같다"를 **의심**하고, 3회차에 인물 B가 "안 끝나잖아"라고 처음 **입 밖에 낸다** — 관객이 이미 아는 것을 인물이 뒤늦게 말하는 시차가 3회차 payload(재검토 §2) | 2회차 의심 → 3회차 자각 |

## 몸·사물·소리·빛·매체 표

| 요소 | 다루는 주체 | 상태/접근권이 바뀌는 지점 |
|---|---|---|
| **종이 + 펜**(핵심 매체) | 펜 든 사람 | 오늘 날짜 지움 → 조항 3줄 누적. 지운 자국이 물리적으로 쌓인다 |
| 방아쇠 물건 3개(충전기·책·화분/대안) | 둘 | 각 물건이 소유 판정 불능 → 조항 생성 후 상자로 or 잔류 |
| 상자 | B | **닫지 않는다** = 미결의 물성 |
| 물소리(화분에 물) / 대안 | A | 반복 의무의 시작음(결말 후보) |

## 행동·상태 표 (프레임 + 3 사이클)

| 국면 | 겉 행동 | 정보·관계·권한 변화 | 물질 상태 | 다음에 남기는 조건 |
|---|---|---|---|---|
| 프레임 | "오늘로 끝" 합의, 오늘 날짜 적음 | 종료를 공식화 | 종이에 날짜 1줄 | 지울 수 있는 날짜가 생김 |
| 1 충전기 | 소유 판정 실패 → 보증일까지 유예 | 오늘 지우고 날짜 갱신(A) | 조항 1줄(날짜형) | "끝"이 처음 밀림 |
| 2 책 | 다 안 읽음 → "다 읽으면" 조건화 | 날짜→조건으로 규칙 진화(A) | 조항 2줄(조건형) | 끝을 잴 수 없게 됨 |
| 3 화분 | 물 주기 → "열흘마다" 반복 조항 | B가 "안 끝나잖아" 자각하고도 적음 | 조항 3줄(반복형) | 끝이 무한 후퇴 |
| 종지 | A 물 줌 / B 상자 안 닫음 | 무발화 공모 확정 | 지운 날짜 위 3줄 | (미결) |

## B2 선택 형식 모듈

### F1 연속·수평 — 필수 증거
- **체류·재진입 이유**: 정리는 하룻밤 안에 끝나야 한다는 자기부과 시한. 떠나기 전 한 자리.
- **출입·조합 변화표**: 물건이 하나씩 상자로 이동(조합 축소)하는데, 조항은 반대로 늘어난다(규칙 팽창). 물리적 감소와 규칙적 증가의 엇갈림이 F1의 수평 연료.
- **대기·정리·이동이 만드는 결과**: 정리 행위 자체가 조항을 낳는다 — 치울수록 끝이 멀어진다.

## B2 재검토·보완 (2026-07-23)

`의도한 것 vs 지면에 있는 것` 간극 점검. 분석적 정정 §1–3은 위 본문에 반영, 창작 결정 §4–6은 사용자 사인 대기.

- **§1 (정정) escalation 사다리는 3칸에서 닫힌다 → 자연 규모.** 조항 유형은 점(날짜)→조건→반복 정확히 3칸. 네 번째 물건은 유형을 더 못 올린다("반복" 다음이 없음) — 넷째부터는 또 다른 반복 조항 = 같은 기능의 반복(B3 금지). 따라서 자연 규모는 **3사이클 최소형**이 정답. 중형은 물건 추가가 아니라 다른 연료(종이 물성 심화·A/B 관계 한 겹)로만. → 선택 카드·규모 기록 정정함.
- **§2 (정정) 관객 인지 vs 인물 자각의 시차가 3회차 payload.** 관객이 2회차에 "끝 안 옴"을 확정하면 3회차가 확인 반복으로 평평해진다. 재조정: 관객은 2회차에 의심, 3회차에 B가 처음 발화 — 관객이 아는 것을 인물이 뒤늦게 말하는 시차가 3회차의 사건(확인 아니라 자각). → 정보 표 정정함.
- **§3 (구조화) 펜 교대에 근거 부여.** F2 표의 3회차 펜 A→B 교대가 근거 없었음. 구조화: 떠나는 사람(B)이 영구 조항을 봉인한다 = 떠나는 쪽이 실을 가장 필요로 한다. A/B 미결을 닫는 답. → 인물 표 정정함.
- **§4 "왜 지금"의 물질적 대체 → 결정: 안 넣음 (2026-07-23 사용자).** 하드 스톱(이사/열쇠/시계)을 도입하지 않는다. "왜 오늘 끝내는가"의 무발화는 채울 빈칸이 아니라 **작품의 약속**으로 씨앗에 명시한다(관객마다 다르게 닫히는 열림, A3 예외 보호). → **열린 구조 가정 닫힘.**
- **§5 결말 안3 폐기 → 결정: 수용.** 안1(현행 미결)/안2(종이 물성)만 유지. 결말 후보 표 반영함.
- **§6 세 번째 방아쇠 → 결정: 수용.** 3회차 방아쇠 = **자동 갱신 공동 항목**(정기 배송·구독 또는 공동명의 정기 결제 등)을 1순위로, 화분은 대안. 단 무대에서 **물리적 재발 행동**(매 주기 수령·정산·처리하는 손)을 유지하는 항목으로 고른다(추상적 자동이체보다 몸이 남는 것). 구체 항목은 C1에서 확정 — 아래 본문 표의 '화분' 표기는 이 항목으로 읽는다.

**열린 구조 가정 0** (§4 닫힘). 쓰기 빈칸(§5 결말 선택·§6 구체 항목·A/B 말투)만 남음 → B4 통과 조건 충족.

## 씨앗 (동결 2026-07-23)

B1 보호 카드 4항 + B2 선택 카드 보호할 핵심을 합쳐 고정. **C 구간에서 직접 고치지 않는다**(대조 기준). 더 정확한 핵심 발견 시 조용히 덮어쓰지 않고 아래 `씨앗 개정 vN — 날짜·사유·사용자 승인` 절을 추가한다.

1. **약속** — 재결합도 결별도 아닌, "끝내기"라는 공동 작업이 미뤄지는 시간을 관객이 함께 견딤. 절차의 정교화가 관계를 연장한다.
2. **가장 강한 행동** — 주인 불명 물건이 나올 때마다 "마지막 연락" 날짜가 갱신되고, 물건은 안 버리고 규칙만 다듬는 손.
3. **온도** — 건조·사무적. 규칙·날짜·분류 언어가 감정을 대체. 조항이 늘어나는 축적 리듬.
4. **장면 생성 원리** — 물건→소유 판정 불능→규칙 보강(날짜 갱신). 돌 때마다 "끝"이 멀어진다. 해결=반대 상태.
5. **escalation 상한** — 조항 유형은 점→조건→반복 3칸에서 닫힘 → 자연 규모 최소형. 물건 추가로 늘리지 않는다.
6. **약속으로서의 무발화** — "왜 지금 끝내는가"는 발화하지 않는다. 이 부재는 채울 빈칸이 아니라 보호할 열림이다.
7. **차별화선** — 물건은 방아쇠로만, "마지막 연락" 시간 규칙이 전면. 물건 정리를 클라이맥스로 만들지 않는다.
