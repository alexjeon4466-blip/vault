# 아직까지는 영혼의 선장입니다 — 단막후보 맵

> 서명칸 계보 1번(공포). 자동화가 전 안건을 처리한 회의 끝, 마지막 최종 승인란 하나만 사람이 서명해야 한다. 아무도 그 칸에 손대지 못한다. **시스템은 재촉하지 않는다 — 그 정중한 침묵이 압력이다.**

## B1 소집 확정 (2026-07-07, 사용자 승인)

- **운반체**: 서명칸 계보 1번(연작의 첫 편). 경합 없음. 계열 = 기술/가치 역전.
- **연작공통 상속** ([[wiki/writing/draft-candidates/서명칸_계보_연작공통|B0]]): 같은 디자인 책상·같은 펜(이 편은 **새 펜**). 물려받는 것 = 없음(계보의 시작). **넘기는 것 = "이 칸은 왜 이렇게 무거운가"라는 질문 + 무거운 빈 칸**(2번에서 거짓 이름으로 채워짐). 톤 = 서늘함(빈 칸 앞의 침묵).
- **submission_target**: 미정 — 연작 특성상 편별 단막 공모 또는 연작 공연. 확정 시 AI 규정 재확인(신춘문예 계열이면 C1부터 사용자 단독 집필 모드). 현재는 협업 모드.
- **부품 서랍**(쓸 것): 원본 노트의 구체소재 중 — 마지막 인간 서명란 / 가치 칸이 빈 심사표 / 동의 버튼·일치율(맥락 소품) / 이의신청 창구 부재. 안 쓰는 것: 출입 게이트·재교육실·콜센터 교육장(다른 편·다른 극의 장소 — 여기선 회의실 하나로). 원작(알파고·바둑계) 직수입 금지.
- **재해석 가드레일**: 장강명 원작의 AI·바둑 고유 사건 직수입 금지. "인간만이 영혼의 선장"이라는 명제를 대사로 선언하지 않는다 — 빈 서명칸을 아무도 못 채우는 몸으로만 보인다. 제목 문장 대사화 금지(서명칸 계보 공통 규율).

## 집필 전 3요소

- **장소** — 자동 의결 시스템이 운영하는 심사 회의실. 안건은 전부 시스템이 처리·표결·기록했고, 벽 화면에 `전 안건 자동 처리 완료`가 떠 있다. 남은 것은 회의록 맨 끝의 **최종 승인란** 하나 — 규정상 사람이 직접 서명해야 효력이 발생한다. 반공간 명세: 결정은 이미 다 내려졌는데 책임만 사람에게 남은 방. 출입 통로: 회의 종료 후라 다들 나가려는 문(그러나 승인 전엔 폐회 처리가 안 됨). 떠나지 못하는 이유 — 폐회가 승인란 서명에 묶여 있어 아무도 못 나간다.
- **배경** — 인물별로 다르게 아는 것: ① A(의장 대행)는 이 서명이 형식일 뿐임을 알지만, 형식이기에 더 못 쓴다(경로: 예전 회의록 뭉치 — 옛날엔 토론 흔적이 있었다). ② B(시스템 운영 담당)는 서명을 누구도 대신 못 한다는 규정에 진심으로 묶여 있다(경로: 규정 화면을 띄우는 손). ③ C(신임 위원)는 시스템 결과를 신뢰해 "그냥 누르면" 된다고 여기다 자기 차례엔 못 쓴다(경로: 펜을 쥐었다 내려놓는 손). ④ D(전 심사위원, 자문 자격)는 발언권이 없다 — 서명란만 물끄러미 본다(경로: 명패에 붙은 `자문`이라는 임시 라벨).
- **문제** — "이 회의록에 최종 승인 서명을 누가 하는가." (1장 초입 = 첫 1/5 안). 시스템은 전부 처리했다. 서명은 판단이 아니라 이미 내려진 판단에 몸을 대는 일이다 — 그래서 무섭다.

## 목표 분량

원고지 100장 안팎(30~40분 단막). **그늘 초고의 교훈 반영 — 처음부터 반복(연료) 밀도를 의식**: 서명 미루기 라운드가 매번 다른 근거로 굴러야 함(형식이라서 / 책임이라서 / 대신 못 해서 / 이의 창구가 없어서). 5장 구성 기준 장별 20장 안팎.

## 장 구성 (5장 — 장 경계는 시스템의 대기 알림)

장 경계는 **시스템의 정중한 대기 알림**(재촉 아닌 재촉). 그늘의 그늘 이동 격 무대 시계 — 예고 없이, 점점 짧은 간격으로. 조명·음향 큐표가 곧 장면표.

| 장 | 대기 알림 | 문제와 출입 |
|---|---|---|
| 1 | (개막 전 1차: `승인 대기 중입니다. 서두르지 않으셔도 됩니다.`) | 회의 종료. 벽 화면 `전 안건 자동 처리 완료`. 폐회하려는데 승인란이 비어 폐회 처리 안 됨. A가 펜을 집는다 — 잠깐 보고 내려놓는다. 문제의 씨: 서명이 형식인데 왜 못 쓰나 |
| 2 | **2차 알림** | 서로 미루기 시작. C "그냥 하면 되잖아요" → 막상 펜을 쥐면 못 씀. 권한 확인(누가 서명 자격?)이 오히려 책임의 폭탄 돌리기 |
| 3 | **3차 알림**(간격 좁아짐) | 대안 모색 — 서명 안 하면? B: 미승인은 무한 보류, 다음 회의 재상정. "보류도 결정 아닌가요" / "보류는 항목에 없습니다". D가 처음 입을 떼려다 자문 라벨을 본다 |
| 4 | **4차 알림** | 펜이 돌기 시작한다 — A→C→(D 앞에서 멈춤, 자문은 서명 자격 없음)→B(대신 못 함). 펜의 동선이 곧 책임의 동선. 각자 펜을 다른 이유로 내려놓음 |
| 5 | **5차 알림**(가장 짧은 간격, 그러나 여전히 정중) | 펜이 책상을 한 바퀴 돌아 빈 칸 옆 제자리로. 결말(후보 중 택) — 아무도/누군가/이상하게 |

## 무대규칙 (하지 않을 것)

- 시스템을 위협적으로 그리지 않는다 — 목소리는 끝까지 정중하고 재촉 없음. 공포는 시스템이 아니라 빈 칸에서 온다.
- "AI가 인간을 대체했다" 류 논제 대사 금지. 기술어(알고리즘·자동화) 남발 금지 — `자동 처리 완료`, `승인 대기`, `보류` 같은 절차어만.
- B를 악역/관료 풍자로 만들지 않는다 — B도 그 서명을 무서워하는 사람. 규정에 묶인 것과 두려운 것이 겹친다.
- 펜을 상징으로 설명하지 않는다("이 펜이 인간의 마지막…" 금지). 펜은 그냥 쥐었다 놓이는 물건.
- 제목 문장("아직까지는 영혼의 선장") 대사화 금지.

## 인물표 (위치 열 필수)

| 인물 | 위치 | 기능 | 떠나지 못하는 이유 |
|---|---|---|---|
| A (의장 대행) | 중심 | 서명 자격 1순위 — 형식임을 알기에 더 못 쓰는 자 | 폐회 권한이 자기 서명에 묶임 |
| C (신임 위원) | 중간 | 시스템 신뢰자 → 자기 차례에 무너짐 | 다음 안건이 자기 소관, 폐회돼야 진행 |
| B (시스템 운영 담당) | 권한자 | 서명을 대신 못 한다는 규정의 대리 — 자신도 두려워함 | 승인 전엔 시스템 종료 불가 |

| 자동 의결 시스템 | 비인간 장치 | 전 안건 처리자·정중한 대기자 — 서명 칸만 비워둠 | — |
| 실제 영향받는 사람들 | 부재자 | 이 결정이 바꿀 무대 밖 삶 — 끝내 안 나옴 | — |

## B5 부재축

- **실제 영향받는 사람들** — 이 승인이 바꿀 무대 밖 삶. 끝내 등장하지 않아, 서명이 추상이 아니라 누군가에게 도달함을 침묵으로 상기.
- **예전의 토론** — 판단에 흔적과 책임이 있던 시절(옛 회의록). 지금은 처리만 남았다.
- **시스템 서버/상급 규정** — 대리 서명 불가·보류 무한 대기를 정한 곳. 현장 누구도 못 바꾼다.

## 결말 후보 (사건이 아니라 '남는 물성/상태 + 유보되는 것')

1. **제자리 결말** — 펜이 한 바퀴 돌아 빈 칸 옆 제자리, 잉크가 마름. 시스템 `보류 처리되었습니다. 다음 회의에 재상정됩니다.` / 유보: 다음 회의에도 같은 자리에서 같은 침묵.
2. **든 손 결말** — 누군가 손을 든다 — 서명하려는 게 아니라 물으려고. 손이 허공에 멈춤. / 유보: 질문이 항목에 있는지(아마 없음).
3. **오류 결말** — 한 사람이 끝내 뭔가 적는다. 이름이 아니라 획 하나, 또는 날짜만. 시스템 `서명이 인식되지 않았습니다. 다시 시도해 주세요.` / 유보: 서명이란 무엇이며, 인식되지 않은 그것은 용기였나 회피였나.

(확정하지 않음 — 조립하며 고른다. 계보 넘기기 상 1은 "무거운 빈 칸"을 가장 순수하게 2번에 넘김. 2·3은 인간 쪽 미동을 한 겹 남김. 연작 톤 곡선상 1번은 서늘하게 닫는 편이 6번까지의 상승에 유리.)

## 판정과 방향 — B4 게이트 (2026-07-07)

맵 검증형 재채점. ○의 근거는 이 맵의 장 번호·표의 행:

| 축 | 판정 | 근거 (맵 내 위치) |
|---|---|---|
| A1 | ○ | 형식임을 알면서 손이 안 나가는 A = 1장(펜 쥐었다 놓기)·5장. 떨림이 서명 절차와 정면 충돌 |
| A2 | ○ | C가 기능(신뢰자)을 넘쳐 무너지는 순간 = 2장 큰소리→4장 침묵(플롯 표 2·4행). A의 "형식" 붕괴 = 5장 |
| A3 | ○ | 결말 후보 3종(제자리 보류/든 손/오류)이 서로 다른 상태로 닫힘 — "인간 승리/패배" 논제로 수렴 안 함 |
| B1 | ○ | 회의 종료 후 연속 실시간, 장 경계=대기 알림. 인물별 체류 이유 = 인물표 '떠나지 못하는 이유'(폐회가 서명에 묶임) |
| B2 | ○ | 문제("누가 최종 승인 서명을 하는가") = 1장 초입, 5장의 첫 1/5 |
| B3 | ○ | 플롯 표 5행 전부 정보·권한 이동 기입. 서명 미루기가 매 장 다른 근거(형식/책임/보류불가/자격지도) |
| B4 | ○ | 인물표에 외부(D)·권한자(B)·비인간 2종·부재자. 외부자 통로 = D 3장 발언 시도(자격 막힘)+시스템 4장 개입 |
| B5 | ○ | 구체소재 6종 전부 처음≠마지막(새 펜→마른 펜, 빈 칸→비거나 거짓/오류). 부재축(영향받는 사람들)이 서명의 무게를 실음 |

**9번째 — 연작공통 정합** (B0): 공유 물성 재정의 없음(같은 책상·이 편은 새 펜) ○ / 순서 의존 성립(물려받기 없음=계보 시작, 넘기기="무거운 빈 칸") ○ / 톤 곡선 위치 일치(1번=서늘함) ○.

추가 확인: 재해석 판별 질문 통과(B1 절 — 원작 알파고·바둑 직수입 없음, 명제 대사화 0).

**전축 ○ + 연작 정합 ○ → `대기` 승격.** 계열 지도 서명칸 계보 역할 표 1번 상태 열 갱신. 다음: C1 조립(착수는 사용자 지시 대기) 또는 2번 편 B 착수 — 둘 다 WIP 한도 내(그늘 개작 + 이 편) 검토.
