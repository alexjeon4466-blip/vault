# 한시간 이내에 전화벨이 울릴것입니다 — 비트 스케치 2종

> B1.5 탐색 — 시간 연료 병목 검증용. 형식 잠금 없음, 두 스케치는 서로 다른 작품 가설. 인물·장소는 시험값(교체 가능): **A** — 두 청혼 사이에서 오늘 안에 답해야 하는 사람. **전화기 한 대, 번호 둘.** 장소 — A의 방 또는 닫힌 카페(중립 유지). 제3항 후보 — **D: 가족 반복을 관리해 온 사람**(모순의 어머니/이모 축 변형 — 직접 차용 금지).

## 공통 전제 (두 스케치 공유)

- A는 "생각해 보고 오늘 안에 연락드릴게요"라고 양쪽에 말해 뒀다. 그리고 결심한다: **먼저 걸지 않는다. 먼저 울리는 쪽으로 간다.** 타이머 60분 — 그 안에 안 울리면? 그 규칙은 A도 아직 안 정했다(구멍 ①).
- 절차 구멍 부품(만날_지하철): 두 사람 모두 "기다리겠다"고만 했지 **언제·어느 쪽이 거는지**를 정한 적이 없다 — 기다림의 근거 자체가 미결정.
- 종결은 **미수의 몸짓**(사이클4 처방): 전화가 울리는 순간과 A의 손 사이에서 끝난다 — 받는 장면은 없다.

## 스케치 A — 일치형 (실제 60분, 관객과 타이머가 같은 시간을 산다)

| 시각 | 비트 | 달라지는 것 |
|---|---|---|
| 0:00 | 타이머 점화. A가 소리 내어 규칙을 선언한다 — 방에게, 자기에게 | 결심이 발화로 물화 — 이제 어기면 보인다 |
| 0:04 | 규칙의 구멍 ① 발견: 60분 안에 안 울리면? A, 규칙을 덧붙인다 — "그럼 없던 걸로" | 규칙이 자라기 시작 — 운명 위탁이 사실은 입법 노동 |
| 0:11 | 첫 벨 — **스팸 전화.** A, 받을 뻔한 손 | 구멍 ②: '먼저 울리는 쪽'에 제3의 번호가 포함되는가. 규칙 추가 |
| 0:18 | D 입장(또는 전화). 저녁 준비/집안 문제 — 일상이 대기를 침범 | A가 대기를 숨기려 함 — 결심이 부끄러움이 됨 |
| 0:26 | A, 전화기를 뒤집어 놓는다. 다시 바로 놓는다. 다시 뒤집는다 | 보지 않을 자유와 못 보는 공포의 왕복 |
| 0:33 | **중간 정점**: A가 한쪽 번호를 눌러본다 — 통화 버튼 직전까지. 끊는다 | 운명 조작의 유혹 — 운에 맡기기로 한 결심을 지키는 것도 매 순간의 선택 |
| 0:41 | D가 눈치챈다. "누구 기다려?" A의 거짓말 또는 반토막 사실 | 대기가 처음 타인에게 목격됨 — 비용 발생 |
| 0:48 | 침묵 구간. A, 아무것도 하지 않는 일을 한다 | 몸의 변화만 — 정보 이동 없는 시간의 무게 (최대 위험 구간) |
| 0:55 | A, 타이머를 본다. 남은 5분. 규칙 재선언 — 이번엔 소리가 작다 | 결심의 부피가 줄었다 |
| 0:58~ | **벨이 울린다.** A의 손이 전화기 위로. 화면을 보기 전. | **미수의 몸짓 — 암전.** 누구인지 관객도 모른다 |

- **얻는 것**: 관객이 A와 같은 60분을 산다 — 기다림의 공모, 벨 하나하나가 실제 사건. 0:33의 유혹이 진짜 긴장이 됨.
- **위험**: 0:41~0:55 구간의 연료 부족(서명칸 낭독 패널이 실시간 18분에서 이미 관측한 "배우가 채움 행동을 제조하는 압력"이 60분 규모로). D의 재등장 회수·소리 설계 필수. 상연 부담 최대.

## 스케치 B — 압축형 (장 경계로 60분을 25~30분에)

| 장 | 비트 | 타이머 표기 |
|---|---|---|
| 1 | 결심과 점화 — 규칙 선언, 구멍 ①② 발견과 입법 | 60→51 |
| 2 | 스팸 벨과 D의 침범 — 대기의 목격, 거짓말 | 51→33 (경계 점프) |
| 3 | 조작의 유혹 — 통화 버튼 직전, D와의 정면 문답("네가 고른 거잖아") | 33→12 (경계 점프) |
| 4 | 침묵과 재선언 — 소리가 작아진 결심 | 12→2 |
| 5 | 벨 — 미수의 몸짓, 암전 | 2→0 |

- **얻는 것**: 밀도·상연 현실성. 각 장이 하나의 질적 변화를 맡아 B3가 명료.
- **잃는 것**: **기다림 자체가 극이라는 원본 장치의 핵.** 타이머가 배경 소품이 되고, 관객은 A의 시간을 사는 게 아니라 구경한다 — "60분 대기 자체가 극"(사이클4 처방)과 정면 충돌.

## 비교 판정 (Claude 제안 — 사용자 결정 대기)

| 기준 | 일치형 | 압축형 |
|---|---|---|
| 글감의 핵(대기=극) 보존 | **○** | △ — 처방과 충돌 |
| B3 시간 연료 충분성 | △ — 0:41~0:55 연료 보강 필요 | ○ |
| 자기복제 거리(만장일치 압축과) | **○ — 정반대 형식** | ✕ — 압축하면 만장일치 문법에 접근 |
| 상연·낭독 부담 | 높음 (60분 단독극급) | 낮음 |

- **제안**: 이 글감의 자연 규모 가설은 **일치형**이다 — 압축하는 순간 만장일치의 타이머 문법으로 미끄러지고, 처방("대기 자체가 극")도 무너진다. 단 일치형의 성립 조건 = 0:41~0:55 침묵 구간의 연료(D의 축, 소리 설계, A의 무행동의 행동화)이며, 이것이 **B2로 갈지 말지를 결정하는 단일 질문**이다.
- **다음 탐색 후보**: 일치형 0:48~0:55 침묵 구간만 2~3쪽 쓰기 탐색(견딤이 지면에서 서는지) — 서면 뒤 B2 착수 판단.

## 탐색 관찰 (세 줄)

- **살아난 것**: 규칙이 자라는 구조(운명 위탁 = 입법 노동의 역설) / 0:33 통화 버튼 직전 / 미수의 몸짓 종결.
- **평평한 것**: D의 축이 아직 기능(침범·목격)뿐 — D 자신의 반복(가족의 결혼 이력?)이 없음. A가 무엇을 고르는 중인지(결혼? 계약?)도 시험값.
- **새로 필요한 것**: 침묵 구간의 연료. 벨 소리의 설계(스팸·진동·무음의 위계). 60분을 무대 시계로 보여줄 물성(주방 타이머? 폰? — 만장일치 태엽과의 차별 물성).
