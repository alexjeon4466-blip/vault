# 대기 바위 — 재설계 (시스템 비발화·장치 감축)

## 경위

2026-07-20 사용자 지시: **시스템이 발화하는 것을 선호하지 않는다. 장치가 복잡한 것도 선호하지 않는다.** 기존 1~4장 초안은 시스템 음성을 주 대화 상대로 썼고(장별 발화 12·19·17·11회), 장치가 누적되었다(전광판·유리 보관함·투입구·확인증 홈·벽 개폐 기믹). 이는 [[wiki/writing/aesthetics/전용수x히라타_통합_극작노트|통합 극작노트]] 2.6(시스템은 발화보다 상태로), 2.7(설정과 장치는 단순하게), 원칙 9(시스템은 기본적으로 말하지 않는다)와 어긋난다 — 구조맵(06-21)이 원칙 명문화(07-18)보다 먼저 작성된 데서 온 표류다.

기존 1~4장 초안은 **구판 동결·보존**(삭제하지 않음). 재설계 확정 후 장별 개작(한 턴 한 장면).

## 씨앗 대조 — 이 재설계는 씨앗 개정이 아니다

| 동결 씨앗(2026-07-19) | 재설계에서 |
|---|---|
| 약속: 승인·탈출·화해 없음, 작은 자기소유의 결말 | 불변 |
| 이미지: 낙하음 / 손글씨 `내 바위` / 노란 선의 한 발 / 실물 상자 | 전부 유지 — 손글씨는 오히려 축으로 승격 |
| 온도: 차갑게 예의 바른 **문장**이 압박한다 | 문장은 존재하되 **인쇄물로 이행** — 씨앗은 문장을 요구하지 발화를 요구하지 않는다 |
| 원리: 규정집은 끝까지 열리지 않는다 | 규정집 오브제 자체를 없앤다 — 규정은 집행(사후 통보 종이)으로만 존재. `열리지 않음`의 더 강한 형태로 해석(해석 기록) |
| 경계: 직인용 재번역(C안 확정) | 유지 — C안 문장은 종이의 문장이 된다 |

## 배역 — 2인극 확정

- **대기자 / 건너편 사람.** 구조맵의 `안내자/시스템 음성` 배역 삭제(원안은 이력 보존).
- 사람 대 사람의 대화는 건너편과만 발생한다 — 이 극에서 목소리로 응답받는 유일한 관계. 시스템 무발화가 건너편의 짧은 말을 크게 만든다.
- 건너편의 대기 내용 미공개(씨앗) 유지.

## 장치 대차대조

**지운다** — 전광판(`대기 000`) / 시스템 음성 전체 / 유리 규정집 보관함 / 문 옆 투입구(종이는 문 아래 틈으로 — 1장에서 이미 확립) / 확인증 발급 홈 / 벽이 열리며 계단이 나타나는 기믹(계단은 처음부터 보이는 건축).

**남긴다** —
| 장치 | 역할 | 비고 |
|---|---|---|
| 문 + 문턱 + 노란 테이프 선 | 감금 없는 체포 | 테이프는 극 전체에서 한 재료 — 사람의 자리(문밖 선)와 상자의 자리(계단 위 네모)를 같은 테이프가 긋는다 |
| 배달 주머니 + 빈 병 1 | 평소 | 확정(07-19) 유지 |
| 벨 | 그가 시스템을 부르는 유일한 통로. **양방향** — 방이 그를 부르는 소리도 같은 전자음(방향만 반대) | 장치 하나로 호출·응답 겸용 |
| 종이(인쇄물) | 시스템의 유일한 언어 | 아래 `종이의 문법` |
| 상자 `반송 물품 B-12` + 상자에 붙은 반송장 | 바위 + 자기 서류 | 확인증 홈 대체 — **상자가 자기 서류를 지니고 다닌다**(실제 반송 물품의 송장처럼). 매일 새 반송장이 덧붙어 층이 쌓인다 |
| 도장 `완료` (닳은 손잡이) | 자기 날인 | 유지 — 찍는 곳은 상자의 반송장 |
| 계단 | 위층으로 | 상설 건축, 기믹 아님 |
| 창 + 건너편 커튼 | 목격 | 유지 |

## 종이의 문법 (시스템의 새 언어)

1. **종이는 문 아래로만 온다.** 인쇄된 짧은 문장, 항상 정중, 관용구 `본 안내문은 회신용이 아닙니다`.
2. **질문에 답하지 않는다.** 그가 허공에 물어도, 벨을 눌러도, 종이는 자기 일정대로만 온다 — 문답의 공포를 **무응답과 시차의 공포**로 전환. 실시간 경고 대신 사후 통보(`금일 대기 위치 이탈 1회가 기록되었습니다`) — 감시는 보이지 않고 기록만 도착한다.
3. **낙하음·정체불명 전자음에 대해서는 어떤 종이도 오지 않는다** (응답받지 못하는 소리 계열 유지).
4. **유일한 회신 가능 양식은 사유서다.** 사유란이 있는 양식만 문 아래로 되밀어 넣을 수 있다 — 그의 손글씨가 시스템에 들어가는 유일한 입구, 돌아오는 것은 분류(`기타`).
5. **종이는 무대에 쌓인다.** 그는 버리지 못한다. 7장에 이르면 정중한 문장의 더미가 방의 물성이 된다.

## 손글씨 vs 인쇄 — 물질 언어 축 (신설)

극 전체에서 인쇄(시스템)와 손글씨(사람)의 대립이 자란다:
- 2장 — 사유서에 그의 첫 손글씨(`요구르트를 사러`) → 인쇄로 회신(`기타`).
- 3장 — 회신용이 아닌 종이 뒷면에 항변을 쓴다 → C안 확정문이 인쇄로 돌아온다(`해당 기재는 미숙지 신고로 접수되었습니다 / 접수는 취소되지 않습니다`).
- 6장 — 손글씨 `내 바위` 이름표를 인쇄 라벨 옆에 붙인다 — 축의 완성. 주머니의 유성펜 `한 개`(1장)가 이 축의 씨앗임을 소급 확인.

## 장별 전환 스케치

| 장 | 구판의 시스템 발화 | 전환 |
|---|---|---|
| 1장 《요구르트가 오지 않았다》 | 문답 12회 | 벨 2회 → 종이 1장(`절차가 시작되었습니다 / 호출 시 즉시 응답 가능 상태를 유지하십시오 / 본 안내문은 회신용이 아닙니다` — 우측 상단 `대기번호 000`). 그의 질문(`그 둘이 같은 말입니까`)은 허공에. 먼 낙하음 1회. 빈 병을 주머니에 넣는 종지 유지 |
| 2장 (제목 재검토: 《호출은 대기 위치로 전달됩니다》는 종이의 인쇄 문장으로 생존) | 미로 문답 19회 | 한 발 나가도 **아무 일도 없다**(무발화) → 돌아오면 문 아래 이탈 기록 종이. 실제 외출 중 방에서 벨이 울린다(빈 방에) → 뛰어 돌아옴 → 종이 없음(호출이었는지 영원히 모름). 사유서 양식 → 첫 손글씨 → `기타` 회신. 스스로 문 닫고 문을 향해 앉는 종지 유지 |
| 3장 《접수는 취소되지 않습니다》 | 문답 17회 | 상자+반송장 도착(닫힌 문 안에). 작업 지시 종이. 규정 요구 → 무응답 → 벨 → `숙지 간주` 종이. 항변을 종이 뒷면에 쓰려는 순간 건너편 첫 발화 **`쓰지 마세요`**(말하지 마세요→쓰기의 세계로 전환). 그는 쓰고, 밀어 넣고, C안 인쇄문이 돌아온다. `저도 대기 중입니다` 유지 |
| 4장 《첫 번째 완료》 | 문답 11회 | 노동 침묵 유지(이제 전 장이 침묵 기조라 대비는 몸의 강도로). 상자를 테이프 네모에 안착 → **반송장에 자기 날인**(홈·확인증 삭제) → 낙하 → 문 아래 종이 한 장: `명일 작업이 배정되었습니다`(초기화조차 통보하지 않음 — 후보 ㉠, 또는 `작업이 초기화되었습니다` 포함 — 후보 ㉡). `떨어진 겁니다. 초기화된 게 아니라`는 허공/건너편 방향으로 |
| 5장 《내려오는 시간》 | (미작성) | 이 극 유일의 사람 대 사람 문답 — 건너편: `또 해야 해요? / 괜찮아요?` 맵 핵심 대사 유지. 시스템 종이 0장인 장으로 설계(사람의 장) |
| 6장 《그의 바위는 그의 것이다》 | (미작성) | 손글씨 이름표 → 인쇄 회신(`해당 명칭은 등록되어 있지 않습니다`). 그의 응답 후보 2안: ㉠ 건너편에게 말한다(`오늘 등록하겠습니다`) ㉡ 말없이 이름표를 한 번 더 눌러 붙인다 — 6장 초안 턴에서 결정 |
| 7장 《호출은 오지 않는다》 | (미작성) | **이중 결손**: 1장과 대칭 — 이번에는 종이마저 오지 않는 아침. 주머니도 비고 문 아래도 비어 있다. 그는 벨을 누르지 않는다. 상자 옆에 서서 다음 낙하음을 들을 준비. 건너편 한 걸음 진입(맵 유지) |

## 남는 대사의 재배치

- 시스템 발화 0. 대기자의 혼잣말은 반 문장 수준 최소(`안 왔네` 계열), 질문은 허공에 던져지고 답을 받지 못한다.
- 목소리 대화는 건너편과만: 3장 `쓰지 마세요` / 5장 문답 / 7장 진입. 무발화 기조가 이 몇 마디를 극의 사건으로 만든다.
- 결과: 침묵·노동·종이·소리의 극 — 《내일 먹을게》·독립 단편들의 결(시스템 비발화, 소리와 사물만)과 정합.
