# 단점을 전부 나열하는 청혼 — 구조맵

> B 사이클 진입 문서. 현재 B1 소집까지 — B2 구조 맵은 탐색 뒤 필요할 때만 연다. Claude 초안 = 제안, 소유권은 사용자.

## B1 소집 (2026-07-18)

- **사용자 선택**: 2026-07-18 — "끌린다"로 직접 선택(전화벨과 동시 선택). **B 동시 2편 초과 사유(협업 규약)**: 두 편의 톤이 상이(관계 희극 / 형식 실험)해 상호 간섭이 낮고, 무대 9편 완성 직후의 톤 전환 국면.
- **운반체 확정**: 섬에있는서점 계열 운반체 ★. 흡수 지정: `책과_대화와_온_심장을_약속합니다`(지도 병합 판정). 같은 서랍의 `전임자의_메모를_먼저_읽습니다`는 별개 운반체(인수인계 3부작) — 부품 교차만 검토, 통합하지 않는다.
- **자연 규모/외부 제약 분리**: 자연 규모 가설 미정(탐색 후). submission_target 미정 — 30–40분 기본값 금지. AI 규정: target 미정이므로 협업 기본.
- **민감 소재**: 없음.

## 무원칙 보호 카드 (Claude 제안 — 사용자 수정 우선)

| 항목 | 내용 |
|---|---|
| 작품의 약속 | 사랑 고백이 위험고지서의 형식으로 도착하는 것을 관객이 듣는다 — 결격사유 목록이 길어질수록 고백이 깊어지는 역설 |
| 가장 강한 이미지·행동 | 장점 대신 단점 목록을 소리 내어 읽는 입 / 잘못 들은 말에 맞는 물건을 건네는 손 / 메모와 다른 실제 사람 |
| 온도 | 관계 희극 — 따뜻하되 화해로 봉합하지 않는다. 원본 노트의 결말 방향: "따뜻한 화해보다 열어둔 손" |
| 장면 생성 원리 | 반공간(작은 도서관·문구점·공유서가)에서 관계가 물건과 절차를 통해 생긴다 — 같은 추천/거절/반납/오청/이름 부르기가 반복될수록 관계와 권한이 이동 |
| 기존 작품과 다른 점 | **방향 역전** — 제도가 사람을 지우는 극(서명칸·원문)이 아니라, 사람이 제도 문법(고지서·목록)을 자발적으로 전유해 사랑을 말하는 극 |

## B2 공통 맵 (2026-07-18 — Claude 초안, 사용자 수정 우선)

### 선택 카드

| 항목 | 내용 |
|---|---|
| 보호할 핵심 | 사랑 고백이 위험고지서 형식으로 도착하고, 목록이 관계의 사용설명서가 되는 것 — 화해로 봉합하지 않는 합류 |
| 선택 형식 | **불연속 3장 소품** (며칠 간격 — 조각 1→3→2 배열) |
| 자연 규모 가설 | 15~20분대 / 2인극. 매수 측정은 C2 |
| 시간 연료 | **폐업 카운트다운 — 무대가 비어갈수록 관계가 채워진다** (선반·딱지·박스의 감소가 시계) + 목록의 증식(아홉→열→A의 둘) |
| 자기복제 위험 | 서식(견적서)·목록 문법이 서명칸 어휘와 근친 — 방어선: 서식은 시스템의 요구가 아니라 인물의 선택, 도장은 죽어가는 물건의 마지막 사용(서명 아님) |
| 빠진 연료 | A 쪽 고집의 시험(시험의 일방성 해소), 조각 간 간격의 부기(며칠인지) |
| 외부 제출 제약 | 미정 — 15~20분 소품은 단막 공모 하한 미달 가능. 패딩 금지, target 확정 시 재론 |

### 장소·시간 조직

- 폐업 정리 중인 문구점 한 곳. **3장 불연속** — 1장(고백의 날) → 2장(정리를 돕는 아침, 며칠 뒤) → 3장(마지막 영업일). 장 사이 간격은 무대 상태(빈 선반·박스 수·딱지)가 말한다 — 날짜 자막 불요.
- 시계: 폐업 일정. 매 장 무대가 더 비어 있다 — 3장은 계산대만 계산대다.

### 작동 압력

- 장소의 소멸(가게가 끝난다) × B의 "오늘 말씀드려야 해서요" — 고백의 마감이 외부(폐업)에서 옴.
- 압력이 행동을 바꾸는 지점: 1장 — B가 견적서를 꺼내는 순간(오 년의 침묵이 폐업 공고로 깨짐).

### 인물·대항력 표

| 존재 | 위치 | 원하는 것 | 대항력 기능 |
|---|---|---|---|
| A | 가게를 닫는 사람 | 정리를 끝내는 것 → 목록에 합류하는 것 | 직업 반사(정정·재고 부르기)가 곧 관계의 문법 |
| B | 오 년 단골 | 목록을 다 읽는 것, 열 번째를 찾는 것 | 자기 단점들이 자기 대항력(아침 침묵·고집이 장면마다 시험됨) |
| 가게 | 사물·장소 | — | 소멸 자체가 마감 — 견적서·도장·딱지·박스가 관계의 매체 |
| 부재축 | 무대 밖 | — | 오 년의 시간(쌓인 방문), B의 어머니(목록 다섯), 이전 손님들(초록 형광펜 찾던), 가게 다음의 행선지(양쪽 다 미정) |

### 정보·권한·관객 표

- **이름**: A와 B 서로의 이름을 모름 — 관객도 모름. 3장 도장으로 A의 이름이 B에게 도착(관객에게 읽힐지는 연출 재량 — 감춤 유지 권장). B의 이름은 끝까지 미도착 — A 목록의 첫 항목으로만 존재.
- **권한 이동**: 목록 작성권 B 단독 → A 첨삭(조각 1 "하나 추가요") → A 자기 목록 개시(조각 3 끝) → 양식·도장의 증여(조각 2). 문서의 소유가 관계의 단계.
- 관객 정보차: 관객은 목록 전문을 들었으므로, 조각 3의 시험을 **예언의 성취**로 본다 — 인물보다 반 박자 먼저 아는 웃음.

### 몸·사물·소리 표

| 사물 | 경로 | 상태 변화 |
|---|---|---|
| 견적서 양식 | B의 고백 매체 → A의 첨삭 지면 → A 자신의 목록 → 재고로 증여 | 상품→문서→관계의 양식 |
| 도장+인주 | 서랍 → 봉한 박스에서 꺼냄 → 공급자 칸 → 오늘까지 | 이름의 마지막 사용 |
| 클립보드 | A의 재고 목록 → B의 목록이 끼워짐 → 참조 문서(조각 3) | 업무 도구→관계 문서고 |
| 처분/보관 딱지·박스 | 매 장 증가 | 폐업 카운트다운의 시각화 |
| 모나미 볼펜 | 오청의 손 → "열 번 다시 쓰실 거잖아요" | 관계의 첫 교환물 |

### 행동·상태 표 (3장)

| 장 | 겉 행동 | 이동·변형 | 남기는 조건 |
|---|---|---|---|
| 1 고백 | 마지막 샤프심 → 견적서 낭독(아홉+미정 하나) → A의 첨삭 | 목록의 공동 작성 개시, 오청의 손 | 열 번째의 빈칸, "열 번 다시" |
| 2 시험 | 아침 침묵·박스 재포장·사다리 | 목록이 사용설명서로 작동, 호칭 부재의 불편, B 개별성 노출 | A의 빈 견적서. **A 쪽 시험 비트 = ⓐ 확정 (2026-07-18 사용자)**: B가 안 볼 때 A가 자기 박스를 열어 무거운 것을 아래로 다시 싼다 — 말없는 수용의 행동화, 관객만 목격(정보차 웃음) |
| 3 도장 | 열 번째 낭독 → 도장 → A의 두 줄 → 재고 증여 | 이름의 편도 도착, 합류의 시작 | 유효기간 없는 견적서 묶음 |

### 결말·잔여 후보

1. **현행(조각 2 종지)**: "없는 걸로 하죠. 재고니까." — 확정도 유예도 아닌 지속의 약속. (기본안)
2. 변주: 마지막에 B가 새 견적서 첫 칸을 그 자리에서 적기 시작 — 열한 번째 판본의 개시를 보여주고 암전.

## B4 게이트 — 맵 검증형 재채점 (2026-07-18)

| 축 | 판정 | 근거 |
|---|---|---|
| 보호 | ○ | 보호 카드 5항목 구조화 — 위험고지서 형식, 사용설명서가 되는 목록, 화해 봉합 금지(결말 1안), 방향 역전(자기복제 방어선) |
| A1 진폭 | ○ | A: 정정하는 사람→합류하는 사람(첨삭→자기 목록→도장·증여) / B: 읽는 사람→겪어지는 사람(단점의 실증) — 쓰기 탐색 3조각 검증분 |
| A2 개념 초과분 | ○ | '사랑=위험고지' 명제를 넘는 잉여: "다르게 나쁩니다", 모나미 오청, 열 시 말문의 수다, ⓐ 몰래 다시 싸기 |
| A3 관찰·윤리 | ○ | 복수 해석(합류인가 유예인가 — 유효기간 없음). 원작(섬에있는서점) 표면 비차용 — 반공간·인물 전면 교체 |
| B1 무대 조건 | ○ | 문구점 한 곳, 불연속 3장 — 장 간격을 무대 상태(선반·딱지·박스)가 운반 |
| B2 작동 압력 | ○ | 폐업 마감(장소의 소멸)이 고백·시험·도장 모두의 시계 — 1장 첫 1/4 안에 걸림("오늘까지만 하신다길래") |
| B3 시간 연료 | ○ | 목록의 증식(아홉→열→A의 둘)·견적서의 신분 변화(상품→문서→증여)·낭독의 변주(B 고백→A 첨삭→A 재고 부르기와 합체) — 반복마다 권한 이동 |
| B4 대항력 | ○ | B의 단점들이 자기 대항력(침묵·고집이 실제 장면 사건) + 부재축(오 년·어머니·소멸하는 가게). 외부자 불요 — 2인극 성립 |
| B5 물리·매체 | ○ | 견적서·도장·클립보드·딱지가 의미가 아니라 사건 운반(물성 경로표) |
| 규모 | ○ | 15~20분 소품 가설과 외부 제약(미정) 분리 기록, 매수 비환산 |

**형식 게이트 (F5 불연속 + 최소형)**: 장 간격이 상태 변화를 실제로 운반하는가 ○(비어가는 무대 = 시계) / 각 장의 독립 행동·완결 ○(고백–시험–도장이 각각 한 사건) / 3장이 한 편으로 축적되는가 ○(목록의 공동 소유화).

### B4 가정 노출 점검 — 모호성 게이트

**구조 가정**: 점검 결과 **열림 0건** — ① 고백 시점의 근거(왜 지금): 폐업 마감으로 지면에 있음("오늘 말씀드려야 해서요") ② A의 수용 개연성: 오 년의 익숙함이 행동으로 지면에 있음(안 보고 아는 마지막 재고) ③ 2장에 B가 와 있는 근거: 1장 말미 A의 "하나 추가요"가 문을 열었음.

**쓰기 빈칸 (C1에서 발견 예정)**: 장 간격의 길이(며칠) / 오청 장치가 1회성인지 극의 문법인지(2~3회 변주 여부) / 폐업 사유·A의 행선지(감출 수위) / B의 아홉 항목 전문 확정 / 결말 1안·2안 사이 선택.

**작품이 열어두는 것 (게이트 대상 아님 — 보호)**: B의 이름은 끝까지 미도착 / 관계의 다음 단계는 확정하지 않음(유효기간 없는 견적서가 그 답의 형식).
