# 모욕에 동의하라는 절차 — 대사 어휘표

> B3 산출물. 물성표는 생략 — 구조 맵의 구체소재 표가 사양·상상력 방향·권한 이동을 담음(B3 조건부 조항). 아래 문장은 전부 **가설(제안)** — 최종 문장은 사용자 소유. 이 편은 냉기 — 어휘의 차가움이 폭언이 아니라 정중한 절차어에서 오도록.

## 상수 문구 (반복될 말 — 매 반복이 다른 일을 해야 함)

| 문구 | 화자 | 반복의 변화 |
|---|---|---|
| "남은 조항 N개. 천천히 읽으셔도 됩니다." | 시스템 | 조항마다. **정중체 동일, 카운트만 줄어듦** — 배려의 형식이 강요를 매끄럽게. 이 편 시그니처(연작 넘김 아님) |
| "전 조항 읽음 확인 후에 서명이 활성화됩니다." | B | 1장 안내→3장 거부 시 벽→4장 사실 확인. 부분 동의 불가의 반복 |
| "그냥 읽고 넘기면 돼요." | C | 2장 조언→4장 A를 보다 잦아듦→멈춤. 정상화가 흔들리는 소멸형 |
| "이 조항은…" (A, 낭독하다 멈춤) | A | 2장 첫 멈춤→3장 건너뛰려다→5장 그냥 읽음(체념). 멈춤의 길이가 짧아지는 게 굴복의 척도 |
| "부분 동의는 항목에 없습니다." | B·시스템 | 3장 도입→이후 거부 불가의 근거로 재활용 |

**연작 상속**: 펜은 이 편에서 **돌아온 펜**(4번 놓임 → 5번 자국 팬). 상수 문구는 이 편 고유(읽음 확인). 계보로 넘기는 것은 문구가 아니라 **자국이 팬 펜 + 강요의 기억**.

## 금칙어 (설명어·개념어 — 쓰는 순간 논제극이 됨)

- **개념어 금지**: 환대, 사람자격, 인격, 존엄, 모욕(추상 명사), 타자, 배제, 소외. 전부 물성으로 — 사람자격 → 손목띠 on/off·바닥선, 모욕 → 조항의 건조한 문장.
- **원작 용어 금지**: 데리다, 고프먼, 아렌트, 환대의 윤리, 얼굴. 철학 직수입 0.
- **감정·판단 직접 진술 금지**: "굴욕적이다", "모멸감", "부당하다", "인간적으로" — 낭독하다 멈추는 목소리, 펜을 눌러 자국 내기, 바닥선을 못 넘는 발로.
- **제목·명제 대사화 금지**: "이건 모욕이잖아요", "나를 낮추라는 거잖아요" 류 명제 선언 금지. "이 조항은…" 하고 멈추는 것까지가 상한.
- **굴욕 조항 전문 노출 금지**: 조항의 낙인 문장을 무대에서 다 읽지 않는다 — 부분·멈춤·B의 다음 안내로. 사유(어떤 특이사항인지)는 특정하지 않는다(특정 집단 표적화 회피).
- **시스템 위협 표현 금지**: `~하셔야` 아니라 `~하시면 됩니다`, `천천히 읽으셔도 됩니다`. 강요일수록 더 정중.

## 인물별 어휘 결

| 인물 | 결 | 예 (가설) |
|---|---|---|
| A | 처음엔 무심한 절차어 → 굴욕 조항에서 목소리가 멈춤 → 체념의 짧은 말 | "네, 읽을게요." / "이 조항은…" (멈춤) / "…이 조항만 빼면 안 되나요." / "…읽었습니다." |
| B | 정중한 규정 인용체. 조항을 정하지 않은 자의 미안함이 정중함 뒤에 | "전 조항 읽음 확인 후에 서명이 활성화됩니다." / "부분 동의는 항목에 없습니다." / "…천천히 하셔도 됩니다." |
| C | 정상화의 가벼운 말 → A를 보며 흔들림 | "그냥 읽고 넘기면 돼요." → "저도 그랬어요." → "…." (손목띠에서 손을 뗌) |
| D | 거의 침묵. 바닥선 밖의 몸이 곧 대사. 유일 발화 1회(4장) | (바닥선 밖에서, 낮게) "저는 그 줄을 안 읽었습니다." |
| 시스템 | 완전 정중, 무정. 배려 형식의 존대 | "남은 조항 3개." / "서명이 인식되지 않았습니다." / "자격이 활성화되었습니다." |

## 장면별 대표 문장 후보 (한 장면 한 문장 — 조립 전 가설)

| 장 | 대표 문장 후보 | 비고 |
|---|---|---|
| 1 | B "전 조항 읽음 확인 후에 서명이 활성화됩니다." | 강요의 절차적 명함 — 아직 굴욕은 안 보임 |
| 2 | A "이 조항은…" (멈춤) | 극의 심장 — 굴욕이 A의 목소리에서 처음 서는 순간 |
| 3 | B "부분 동의는 항목에 없습니다." | 출구 없음 — 전부이거나 전무 |
| 4 | D "저는 그 줄을 안 읽었습니다." | D의 유일 발화 — 거부의 대가를 자격 없는 몸으로 말함(교훈조 아닌 사실) |
| 5 | (대표 문장 없음 — 펜의 자국과 시스템 안내만) | 침묵·펜 자국이 대표. 결말 후보에 따라 시스템의 마지막 한 줄 |

경합하는 좋은 문장은 화면 문구(`남은 조항 N개`)·행동(멈추는 낭독·눌러 낸 자국·바닥선)·소리(정중한 카운트다운)로 전환한다. **D의 4장 발화는 이 편에서 유일하게 '거부'를 말로 건드리는 지점** — 한 번만, 바닥선 밖에서, 자격 없이. 아무도 그를 자리로 부르지 않아야 한다(거부의 대가 확인). 냉기는 폭언이 아니라 "천천히 읽으셔도 됩니다"라는 배려가 강요를 감싸는 데서 온다.
