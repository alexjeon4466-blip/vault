# 한시간 이내에 전화벨이 울릴것입니다 — 구조맵

> B 사이클 진입 문서. 현재 B1 소집까지 — B2 구조 맵은 탐색 뒤 필요할 때만 연다. Claude 초안 = 제안, 소유권은 사용자.

## B1 소집 (2026-07-18)

- **사용자 선택**: 2026-07-18 — "끌린다"로 직접 선택(단점청혼과 동시 선택, 초과 사유는 청혼 맵과 공유). 사이클4 처방에서 B 착수 후보(미결 결정 없음)로 이미 지목된 글감.
- **운반체 확정**: 모순 계열 타이머 대기 극 운반체 ★. 부품 지정: `만날_지하철_입구를_정하지_않았습니다`(절차 구멍 부품).
- **자연 규모/외부 제약 분리**: 원본 장치가 **60분 대기의 리얼타임 일치**라 자연 규모가 형식에 붙어 있다(약 60분?) — 단 이것은 가설이지 의무가 아니다. 압축형(대기를 압축)과 일치형(실제 60분)은 다른 작품이 된다 — **일치형 확정 (2026-07-18 사용자, 비트 스케치 2종 비교 후)**: 압축하면 만장일치 타이머 문법으로 미끄러지고 "대기 자체가 극" 처방이 무너짐. 성립 조건 = 침묵 구간(0:41~0:55) 연료, 쓰기 탐색으로 검증. submission_target 미정. AI 규정: 협업 기본.
- **민감 소재**: 없음.

| 가장 강한 이미지·행동 | 타이머를 직접 켜는 손 / 두 대의 전화기(또는 한 대와 두 번호) / **미수의 몸짓 종결**(사이클4 처방 — 울리기 전인지 뒤인지, 받기 전인지에서 끝남) |

## B2 공통 맵 (2026-07-18 — Claude 초안, 사용자 수정 우선)

### 선택 카드

| 항목 | 내용 |
|---|---|
| 보호할 핵심 | 주체적 결심이 전화벨 운으로 후퇴하는 60분 — 운명 위탁이 사실은 입법 노동이라는 역설, 미수의 몸짓 종결 |
| 선택 형식 | **일치형 리얼타임 60분** (F1 연속 체류 + F2 수직 반복 결합) |
| 자연 규모 가설 | 실연 약 60분 = 극중 60분. 매수는 대사 희박으로 낮을 것(측정은 C2) |
| 시간 연료 | 오인의 연쇄(반복마다 몸의 반응 비용이 다름) + 규칙의 증식 + 거리의 협상 |
| 자기복제 위험 | 만장일치 타이머(숙고 보장 vs 회피 도구 — 정반대 기능 각인)·죽음에/원문 견딤 대기(거부의 대기 vs 운명 위탁의 도박) — 창구·서식 어휘 전면 금지 |
| 빠진 연료 | 오인 재료 총량(아래 표), D 축의 자기 반복, 두 번호의 실체 감춤 수위 |
| 외부 제출 제약 | 미정 — 60분 1인극(+1)은 제출처가 좁을 수 있음. 패딩·절단 금지, target 확정 시 재론 |

### 장소·시간 조직

- **한 공간 연속 60분, 시공간 비약 없음.** 장 경계 없음 — 국면 경계는 벨(진짜·가짜)과 규칙 선언이 만든다.
- 장소 시험값: A의 방(세탁기 소리가 닿는). 조건: 전화기를 두는 책상/테이블과 A가 멀어질 수 있는 대각 거리(걸음 세기 성립), 외부 소리(골목)의 유입.
- **60분의 무대 시계 = 세탁기 60분 코스 (2026-07-18 사용자 승인)** — 배경 소음이자 멈출 수 없는 시계, 종료 멜로디가 60분 신호. 모래시계 기각. 벨소리 통일 의례도 같은 턴 승인 — 음향표에 확정 반영.

### 작동 압력

- 오늘 안에 답해야 한다(양쪽에 한 약속) × 먼저 걸지 않겠다는 자기 규칙 — **압력의 방향이 통상과 반대**: 무언가 하라는 압력이 아니라 아무것도 하지 않기를 지키라는 압력.
- 압력이 처음 행동을 바꾸는 지점: 0:04 규칙의 구멍 발견(안 울리면?) — 위탁이 입법이 되는 순간.

### 인물·대항력 표

| 존재 | 위치 | 원하는 것 | 대항력 기능 |
|---|---|---|---|
| A | 중심 | 선택하지 않고 선택되기 | 자기 규칙과 자기 몸이 서로 대항 |
| D | 침범자 (가족 반복 관리자) | 저녁/일상의 정상 진행, A의 결정 자체 | 대기를 목격하고 이름 붙임("네가 고른 거잖아") — D 자신의 선택 이력(가족의 반복)이 배후층. 모순 원본 구도 직접 차용 금지 |
| 번호 ①(안정) / 번호 ②(몽상) | 무대 밖 | (침묵) | **울리지 않음 그 자체가 대항력** — 부재축 |
| 전화기 | 사물 | — | 어두워지는 화면·유령 진동·스팸 — A의 몸을 훈련시키는 기계 |
| 세탁기(채택 시) | 사물 | — | 60분의 물리적 하한 — 멈출 수 없는 시계 |

### 정보·권한·관객 표

- 관객이 아는 것: A의 규칙, 규칙의 구멍들, 걸음 수. **관객이 모르는 것(끝까지)**: 두 번호의 실체(이름·조건의 구체) — 스케치 판정대로 감춤 수위 높게: 관객이 A의 선택지를 평가하지 못하게 해야 "누가 낫나"가 아니라 "위탁 자체"가 극이 된다.
- 권한 이동: 규칙의 입법권은 A에게 있으나, 매 구멍마다 입법을 강요하는 것은 사물들 — 권한이 있을수록 노동이 늘어나는 역진.
- 관객-인물 공모: 관객도 60분을 실시간으로 산다 — 모든 소리에 관객도 같이 반응(원문의 자막 공모와 다른 종류의 공모: 몸의 공모).

### 몸·사물·소리 표 — 벨 위계 음향표 (핵심 설계)

| 층 | 소리 | A의 반응 비용 | 반복 시 변화 |
|---|---|---|---|
| 0 | 방의 상시음(세탁기·냉장고) | 없음→어깨 반응 | 침묵이 깊어질수록 상시음이 커짐(지각 변화) |
| 1 | 외부 유사음(오토바이·배달 알림·윗집) | 무릎 반 박자 | 회차마다 회복 시간이 길어짐 |
| 2 | 신체 오인(유령 진동·이명) | 손바닥으로 짚음 | 전화기가 몸 안으로 들어옴 — 최고 비용 |
| 3 | 진짜 벨 — 대상 아님(스팸·D·잘못 걸림) | 전신 기동 후 붕괴 | 규칙 개정을 강제(제3 번호 조항 등) |
| 4 | 진짜 벨 — 대상(종결) | **미수의 몸짓** | 1회만. 받는 장면 없음 |

### 행동·상태 표 — 60분 오인 재료 총량 (B2 핵심 계산)

| 구간 | 국면 | 주 재료 | 남기는 조건 |
|---|---|---|---|
| 0:00~0:11 | 입법 | 규칙 선언·구멍 ①②·벨소리 통일 의례 | 규칙이 문장으로 존재 |
| 0:11~0:18 | 첫 시험 | 층3 스팸 벨 1회 | 제3 번호 조항 신설, 몸의 첫 배신 |
| 0:18~0:33 | 침범 | D 등장 — 층0~1 소음 동반, 대기의 은폐 노동 | D의 의심, A의 반토막 거짓말 |
| 0:33~0:41 | 유혹 | 통화 버튼 직전(층4의 자가 유발 미수) | 규칙 위반의 몸을 A가 목격함 |
| 0:41~0:48 | 목격 | D의 정면 문답 — "네가 고른 거잖아" / D 자신의 이력 반 컷 | 위탁의 계보화(가족의 반복), D 퇴장 |
| 0:48~0:55 | 침묵 | 층0~2 총동원(쓰기 탐색 검증분) — 걸음 세기, 소리 없는 "울려라" | 거리 협상(세 걸음 반→두 걸음 반), 결심의 감량 |
| 0:55~1:00 | 종결 | 재선언(작은 소리)→층4 | **미수의 몸짓 — 암전** |

- 계산 결과: 오인 재료는 층별 3~4회씩, 회차마다 비용이 달라지는 조건으로 **60분 지탱 가능** — 단 0:18~0:33 D 구간이 소음 공급을 겸해야 함(D 없는 판본은 불가 판정).

### 결말·잔여 후보 (판정: 사용자 — C1 전 확정 불요)

1. **벨 울림 → 손이 화면을 보기 전 — 암전** (스케치 기본. 누구인지 관객도 영원히 모름)
2. 세탁기 종료 멜로디와 벨이 **동시에** — 어느 소리에 몸이 먼저 갔는지에서 암전 (60분 시계와 운명의 충돌)
3. 60분 종료, 벨 없음 — A가 전화기 쪽으로 **걸어가는 세 걸음 반의 두 걸음째**에서 암전 (먼저 거는 자로의 전환 미수)
