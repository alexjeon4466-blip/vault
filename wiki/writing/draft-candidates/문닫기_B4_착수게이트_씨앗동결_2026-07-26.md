# W-20260725-문닫기 — B4 착수 게이트

## B4-1. 공통 게이트

판정값은 `pass / fail / waived / not-applicable`이다. **선택한 엔진과 형식 모듈의 질문만** 추가했다 — 선택하지 않은 정보 차이·대항력·제도·미결 결말은 요구하지 않는다.

| 축 | 통과 질문 | 판정 | 근거 |
|---|---|---|---|
| 쓰기 충동 | 작가가 아직 이 작품을 쓰고 싶은가 | **pass** (사용자) | 2026-07-26 `B4 착수` 지시. **이 축은 작가만 판정할 수 있다** — AI가 대신 선언하지 않는다. 아래 주 참조 |
| 살아 있는 핵 | 사람·목소리·이미지·행동·지속 중 하나가 살아 있는가 | **pass** | 두 문소리의 대비(덜컹 / 딱), 손잡이를 조금 들어올리는 손, 침묵을 재는 껍질 소리 |
| 착수 단위 | 다음에 쓸 행동·지속·목소리·이미지의 수행 단위가 있는가 | **pass** (성격 주의) | 통합 탐색본이 이미 최소 아크 한 바퀴다. **C1의 성격이 달라진다** — 아래 주 참조 |
| 진행 가설 | 무엇이 축적·교체되며 C1에서 어떻게 시험하는가 | **pass** | 축적(실패 횟수 + 껍질) → 교체(결함이 A의 몸에서 B의 몸으로). 시험 = C1 전편 통독 시 교체가 한 번으로 읽히는가. **실패 시 회귀 = B2**(진행 가설 층) |
| 배우·관객 경로 | 배우가 수행할 것과 관객이 지각할 경로가 있는가 | **pass** | 배우: 손잡이 조작 3종(실패·성공·반복), 마늘 까기, 손 멈춤. 관객: 개막 동작 목격 → 실패 → 소급 재독 → 침묵 → 이식 |
| 위험 | 관리되지 않은 비가역 가정이 없는가 | **pass** | 차단 가정 0건(B4-2). 안전 위험 없음(칼·화기·높이·전기 없음). 권리 위험 없음(형식 충동 파생, 실존 인물·사건 부재) |
| 규모 | 자연 규모와 외부 규격을 분리했는가 | **pass** | 자연 규모 = F1 최소형(가설), `submission_target: null`. §0.4에 따라 다른 칸에 두고 환산하지 않는다 |
| 권리·AI | 출처·윤리·안전·AI 이용의 현재 경계를 기록했는가 | **pass** (조건부) | `ai_provenance` 4건 append-only 기록됨. 단 아래 주 참조 |

### 엔진·형식 모듈 추가 질문 (선택한 것만)

| 모듈 | 필요한 증거 | 판정 | 근거 |
|---|---|---|---|
| 이미지·감각·지속 (주) | 반복·정체·기다림이 관객 지각을 바꾸는 방식 | **pass** | 같은 문소리가 세 번째에 다르게 들린다. 침묵의 길이가 껍질 소리로 측정된다 |
| 관계·욕망 (보조) | 원하는 것, 요구하지 못하는 것, 목격의 변화 | **pass** | 둘 다 문이 닫히기를 원한다(겹침). 요구하지 못하는 것 = 묻기. 목격 = B가 A의 손을 본다 |
| F1 연속 체류 | 체류·재진입 이유 / 출입·조합 변화 / 대기·정리의 결과 | **pass** (조건부) | 재진입 O(B가 현관을 두 번 오간다), 조합 변화 O(1인→2인), 정리의 결과 O(껍질이 쌓인다). **체류 이유는 비어 있다** — 아래 주 참조 |

### 주 — 판정에 붙는 조건 세 개

**① `쓰기 충동`은 제 판정이 아닙니다.** `B4 착수` 지시를 계속 쓰고 싶다는 뜻으로 읽고 `pass`로 적었지만, 이 축은 작가만 답할 수 있습니다. 아니라면 **여기가 가장 싸게 멈출 수 있는 자리**입니다 — C1 이후에 멈추면 본문 revision과 증거가 붙은 뒤가 됩니다.

**② `착수 단위`가 통과하는 방식이 특이합니다.** 통합 탐색본이 이미 최소 아크를 한 바퀴 돌았기 때문에, 이 작품의 C1은 `빈 곳을 새로 쓰는 일`이 아니라 **탐색본을 정식 본문 revision으로 올리면서 쓰기 발견을 허용하는 일**입니다. 파이프라인 §C1이 허용합니다 — `분할이 작업을 방해하는 최소형·독백·단일 수행은 처음부터 연결본으로 써도 된다`. C1의 정지점은 **첫 연결본**으로 두는 것이 맞습니다.

**③ `권리·AI`의 조건**: 현재 본문 후보의 문장은 **AI 초안이고 사용자가 아직 자기 문장으로 고치지 않았습니다.** §7.1에 따라 사용자가 고친 문장이 문체 기준이므로, **문장 소유권 단계가 미개시** 상태입니다(《대기 바위》에서도 같은 지점이 기록됐습니다). 지금은 차단 사유가 아닙니다 — `submission_target: null`이고 목표 공모가 없으므로 §B1의 `불명이면 추가 AI 개입 중단` 조항이 발동하지 않습니다. **다만 목표 공모가 정해지는 순간 이 축을 재판정해야 합니다.** `ai_provenance`를 소급 수정하거나 사용자 단독으로 바꾸지 않습니다.

**④ F1의 `체류 이유`가 비어 있습니다.** B가 왜 이 집에 계속 있는지 정해지지 않았습니다(관계 미결의 직접 결과). 최소형 한 장면이면 **쓰기 빈칸**입니다 — 비가 온다는 조건이 이미 있어 잠깐 들어온 사람으로도, 오늘부터 사는 사람으로도 장면이 섭니다. **그러나 자연 규모를 늘리려 하는 순간 즉시 `구조 가정`으로 승격합니다.** 체류 이유 없이는 F1의 연료가 없습니다. 이 조건을 씨앗 동결에 넣었습니다.

원작·실화·책 재해석이 아니므로 `원작을 몰라도 독립하는가` 계열 추가 항목은 **not-applicable**입니다.

## B4-2. 가정 분류

| 분류 | 항목 | 처리 |
|---|---|---|
| **비가역·차단 가정** | **0건** | — |
| 가역적 구조 가설 | ① 진행 가설(축적 → 교체)이 한 번으로 읽히는가 | C1에서 시험. 실패 시 **B2 회귀** |
| | ② 자연 규모 = F1 최소형 | C1 통독 후 판정. 변경 시 **B1 회귀**(회귀 사다리: 자연 규모 변경은 B1) |
| 리허설·제작 가정 | ③ 매 공연 반복 재현되는 `안 닫히는 문` | C1 허용, C4 전 실제 시험 |
| | ④ 두 문소리(덜컹 / 딱)가 객석 뒤까지 구별되는가 | C1 허용, R3에서 시험. **실패 시 주 엔진이 무너지므로 `module_depth` 음향 심화 후보 유지** |
| | ⑤ **껍질 소리가 객석에 들리는가** | C1 허용, R3에서 시험. 침묵을 재는 시계이므로 안 들리면 이식 ①이 죽는다 |
| 쓰기 발견 항목 | 대사 4행의 실제 문장 / B의 체류 이유 / 껍질의 양과 속도 / 세부 리듬 | 이름만 붙이고 C1 허용 |
| 의도된 해석적 열림 | `환대인가 편입인가`의 지불 / 두 사람의 관계 / 문을 고치지 않은 이유 / A의 마지막 고개 들기의 뜻 | **보호 대상** |

`waived` 판정은 쓰지 않았다. 안전·권리·출처·공모 자격은 애초에 면제할 수 없고, 창작적 위험을 알고 감수하는 항목도 이번엔 없다.

**항목 ⑤는 이번 게이트에서 새로 발견한 가정이다.** 침묵 이식으로 껍질 소리가 계량 장치가 됐기 때문에 생겼다 — 이식 전에는 없던 제작 위험이다.

## B4-1 말미 — 가정 노출 점검

> [[wiki/writing/decisions/우로보로스_개념_이식_2026-07-18|우로보로스 이식]]의 `가정 노출 점검`. 맵이 전제하는 것을 목록화하고 `쓰기 빈칸 / 구조 가정`으로 분류한다. **구조 가정만 승격을 막는다.** 게이트의 대상은 작가의 미해결 추측(공정)이지 작품의 모호성(미학)이 아니다.

| 맵이 전제하는 것 | 분류 |
|---|---|
| 객석이 두 문소리를 구별한다 | 리허설·제작 가정 (③④) |
| 껍질 소리가 침묵의 길이로 읽힌다 | 리허설·제작 가정 (⑤) |
| 관객이 개막 3행의 동작을 나중까지 기억한다 | **쓰기 빈칸** — 주의 배분 문제. C1 통독에서 판별 |
| B가 A의 손을 보고 익혔다는 것이 읽힌다 (3단) | **쓰기 빈칸** — 시선의 배치 |
| 두 사람의 관계를 몰라도 장면이 성립한다 | **쓰기 빈칸 (조건부)** — 최소형에서만. 자연 규모 확장 시 구조 가정으로 승격 |
| A가 문을 닫는 것이 시연으로 읽히지 않는다 | **쓰기 빈칸** — 비 때문이라는 물리 근거가 이미 있다 |

**구조 가정 0건.** 승격을 막는 항목이 없다.

## B4-3. 출발 스냅샷

> A→B 이관 패킷이 있으므로 `seed_snapshot_ref`로 참조하고 **같은 내용을 다시 쓰지 않는다.** B1·B1.5에서 새로 생긴 것만 덧붙인다.

```yaml
seed_snapshot_ref: "wiki/writing/notes/A2B_이관_2026-07-25_배치53_선택3#2. 문닫기"
frozen_at: 2026-07-26
design_revision: des-20260726-01

새로 생긴 장면 생성 가설:
  - 결함은 두 번 작동한다 — 한 번은 소리로, 한 번은 소급으로.
  - 개막의 무심한 동작이 뒤늦게 기술로 재독된다. 4단이 인물보다 먼저 관객의 지각에서 완결된다.
  - 침묵은 문소리의 부재로 오고, 그 길이는 껍질 소리로 측정된다.

새로 생긴 행동:
  - A가 문을 닫으러 가는 것은 시연이 아니라 자기 필요다(비가 온다).
  - B가 손잡이를 잡은 채 반 바퀴 돌았다가 아무것도 묻지 않는다.
  - B가 아무도 요구하지 않은 두 번을 더 닫는다.
  - A의 손이 먼저 멈추고 고개가 나중에 든다.

새로 생긴 윤리 경계: 없음 (이관 시 기록한 경계 유지)

당시의 온도: 아무도 그 얘기를 하지 않는 집. 고칠 수 있는데 고치지 않았고, 그것을 아무도 불편이라 부르지 않는다.

열어두기로 한 것:
  - 환대인가 편입인가
  - 두 사람의 관계
  - 문을 고치지 않은 이유
  - A의 마지막 고개 들기의 뜻
```

**동결되는 것은 과거 기록이지 작품의 의무가 아니다.** 작품이 출발점을 배반한 것이 첫 발견일 수 있다. 스냅샷 대조는 매 회차가 아니라 **① C2 연결 초고 성립 ② 대수술·구조개작 분기 ③ C4 상정** 세 번만 한다. 판정은 `중요한 것을 잃음 / 더 살아 있는 것을 발견함 / 둘이 긴장한 채 공존함`으로 기록한다.

## 씨앗 (동결) — v1

> `대기` 승격과 함께 고정한다. **변경은 삭제·덮어쓰기가 아니라 `씨앗 개정 vN`(날짜·사유·사용자 승인) 추가로만** 한다(우로보로스 이식 §불변 Seed). C3 매 회차 씨앗 대조.

1. **문은 닫는 기술로만 존재한다.** 문을 통해 아무것도 오지 않는다 — 종이·벨·배달·통보 0. (《대기 바위》 재판 방지선)
2. **종이·양식·창구·상태화면을 쓰지 않는다.** (배치 53 자기 제약 승계)
3. **요령을 말로 알려주지 않는다.** 알려주는 순간 이 작품의 시간이 끝난다.
4. **문을 고치지 않은 이유를 발명하지 않는다.**
5. **A가 문을 닫는 것은 시연이 아니라 자기 필요다.** 가르치려는 의도가 A에게 없어야 3단(아무도 의도하지 않은 전수)이 성립한다.
6. **개막의 동작은 강조 없이 지나가야 한다.** 강조하면 소급 판정이 죽는다 — 이것이 주 엔진이다.
7. **마지막 반복은 아무도 요구하지 않은 것이다.** 이것이 4단이다.
8. **`환대인가 편입인가`를 작품이 판정하지 않는다.**
9. **두 사람의 관계를 확정하지 않는다.** 단, **자연 규모를 늘리려 할 때는 B의 체류 이유가 먼저 필요하다**(F1 연료). 그때는 관계 확정이 구조 가정이 되며 씨앗 개정 대상이다.
10. **확장은 회차·장 추가가 아니라 한 장면 안의 노동·판정 불능을 두껍게 하는 쪽으로만 한다.** (직전 작품에서 에피소드 분할이 엔진을 역전시켜 실패 — 익명 3렌즈 만장일치)

`씨앗 개정 이력`: 없음 (v1 최초 동결)

> **통과.** 관리되지 않은 비가역·차단 가정 0건, 구조 가정 0건. `phase: 설계 → 대기` 승격.
