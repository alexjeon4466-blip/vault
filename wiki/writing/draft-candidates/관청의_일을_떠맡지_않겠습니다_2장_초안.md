# 관청의 일을 떠맡지 않겠습니다 — 2장 초안

> 서명칸 계보 4번 C1 조립, 두 번째 장면 (재인증 — 거부는 게으름이 아니다). Claude 초안 = 제안, 문장 소유권은 사용자.

## 2장 — 처음부터 다시

B, 단말을 초기 화면으로 돌린다.

**B**
신분증 다시 부탁드립니다.

A, 신분증을 낸다. 이미 손에 준비되어 있었다.

**B**
(스캔한다) 지문요.

A, 지문을 댄다. 각도가 정확하다. 한 번에 인식된다.

**단말 (소리)**
본인 확인이 완료되었습니다.

**B**
인증 문자 발송했습니다.

**A**
(폰을 이미 들고 있다. 화면을 보지도 않고 여섯 자리를 입력한다.) 사만 이천… 됐습니다.

**B**
…빠르시네요.

**A**
두 번째니까요.

**B**
고지사항 확인입니다. 낭독으로 대신할까요, 화면으로 보시겠습니까.

**A**
낭독해 주세요. 끝까지요.

B, A를 본다.

**B**
…끝까지요?

**A**
규정이잖아요.

B, 낭독한다. 고지사항 전문. A는 바르게 앉아 듣는다. 조는 것은 오히려 C — 대기 의자에서 번호표를 쥔 채 고개가 꺾인다.

**B**
(낭독을 마치고) …이상입니다. 확인하셨습니까.

**A**
확인했습니다.

**B**
(화면을 돌린다) 그럼, 마지막—

화면에 버튼: `본인 확인 후 확정`.

A, 손가락을 든다. 허공. 멈춘다. 내린다.

**B**
….

**A**
여기까지는 제 일이 맞으니까요. 제가 저라는 것, 들을 것 다 들었다는 것. 거기까지는 합니다.

**B**
확정도… 본인 일입니다.

**A**
아니요. 그건 그쪽 일을 저한테 시키는 겁니다.

사이.

B, 화면을 본다. 버튼이 깜빡인다.

B의 손이 화면 쪽으로 움직인다. 조금씩. 버튼 근처까지.

A, 그 손을 본다. 말리지 않는다.

B의 손가락이 버튼 바로 위에서 멈춘다.

거둔다.

**A**
누르시게요?

**B**
…아닙니다.

**A**
누르고 싶으셨잖아요.

**B**
대리 확정은 규정상 불가합니다.

**A**
그쵸. (버튼을 가리킨다) 그쪽도 못 누르고, 저만 누를 수 있고, 저는 안 누르고.

**B**
….

**A**
이 버튼, 지금 지구에서 누를 수 있는 사람이 저 하나네요.

B, 대답하지 않는다. 단말 옆에 놓인 자기 손을 본다.

**단말 (소리)**
보안을 위해 세션이 만료되었습니다. 처음부터 다시 인증해 주세요.

**A**
(신분증을 다시 꺼내며) 지문부터죠?

(2장 끝)

## 조립 점검 (C1 규약)

- **무엇이 이동·변형됐는가**: 정보 — 거부가 게으름·무능이 아님(인증 숙련도: 준비된 신분증·정확한 지문 각도·안 보고 치는 여섯 자리 — "두 번째니까요"), A의 논리 정식화("여기까지는 제 일 / 그건 그쪽 일을 저한테 시키는 겁니다" — 본인 증명과 집행의 경계선), 교착의 산수가 A의 입으로("그쪽도 못 누르고, 저만 누를 수 있고, 저는 안 누르고"), B도 누르고 싶다는 것(뻗다 거둔 손 — 규정이 B의 손도 묶음). 권한 — B의 대리 시도가 규정에 막힘(맵 플롯 표 2행). 물성 — 고지사항 완독을 A가 요청(협조의 과잉 — "끝까지요"가 거부의 반증), 조는 C(대기의 시간 유입), 만료 2회차에 A가 먼저 신분증을 꺼냄(교착의 루틴화 — 희극).
- **희극 리듬**: 인증 숙련 몽타주(빠르시네요/두 번째니까요) → 완독 요청의 역설 → B의 뻗다 거둔 손을 A가 관전("누르고 싶으셨잖아요") → 지구에서 한 사람 개그 → 만료를 A가 앞질러 수용. 웃음의 방향이 B 조롱이 아니라 상황의 대칭(둘 다 묶임)에서.
- **어휘표 준수**: B "대리 확정은 규정상 불가합니다"(상수 1회차) ○, A 담담체 유지(화내지 않음) ○. "지구에서 누를 수 있는 사람이 저 하나" — A의 결(담담한 사실 진술의 확장) 내 판정, 낭독 시 과장 여부 확인 항목.
- **봉인 지문 점검**: 경구 0. "조는 것은 오히려 C" — 사실 서술.
- **플롯 표 대조(맵 2장)**: 겉 사건(재인증 후 또 멈춤) ○ / 정보(거부≠게으름) ○ / 권한(B 대리 시도→막힘) ○ / 남는 물성(거둔 B의 손) ○.
- 다음 조립: 3장 — C의 개입("제가 눌러드릴까요")과 위임의 물리적 불가능(단말이 C를 거부), 미확정=매일 재방문의 무한 예고.
