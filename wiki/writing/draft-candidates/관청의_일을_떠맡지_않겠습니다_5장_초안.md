# 관청의 일을 떠맡지 않겠습니다 — 5장 초안

> 서명칸 계보 4번 C1 조립, 마지막 장면 (미수 결말 기반 + 오작동 후보의 스침. C2 전 교체 가능). Claude 초안 = 제안, 문장 소유권은 사용자.

## 5장 — 내일 뵙겠습니다

**단말 (소리)**
금일 업무가 곧 종료됩니다.

마지막 세션. 인증이 진행 중이다 — 이번에는 넷이 함께 한다.

C가 A의 신분증을 미리 스캐너 위치에 맞춰 준다. D가 단말 각도를 A 쪽으로 튼다. B가 인증 문자를 발송하며 —

**B**
문자 갑니다.

**C**
(A의 폰 화면을 흘끗 보고) 왔어요. 팔만 삼천—

**A**
(입력하며) 보지 마세요, 남의 인증번호.

**C**
아, 네.

**단말 (소리)**
본인 확인이 완료되었습니다.

고지사항. B가 낭독을 시작하려 하자 —

**A**
화면으로 하겠습니다. 시간 없으니까.

A, 화면의 고지문을 빠르게 확인한다. 숙련된 손. 확인 체크.

화면에 버튼: `본인 확인 후 확정`.

넷 다 멈춘다.

버튼이 깜빡인다. 벽의 표시: `금일 업무 종료 5분 전`.

**D**
(누구에게랄 것 없이) …오 분입니다.

아무도 움직이지 않는다. A의 손은 무릎에. B의 손은 단말 옆에. D의 손은 뒷짐에. C의 손은 번호표에.

사이.

A, 일어선다.

일어서며 몸을 돌리는데 — 팔꿈치가 화면 쪽으로 스친다.

전원, 숨을 멈춘다.

B의 손이 반사적으로 뻗어 나오고, C가 반쯤 일어서고, D가 "어—" 하는 소리를 낸다.

A의 팔꿈치가 화면 앞 한 치에서 지나간다.

닿지 않았다.

**단말 (소리)**
….

아무 일도 없다. 버튼은 그대로 깜빡인다.

넷 다 숨을 내쉰다. 거의 같은 박자다.

**A**
(자기 팔꿈치를 보고, 화면을 보고) …큰일 날 뻔했네요.

**C**
(주저앉듯 앉으며) 아니 그걸 그렇게…

**D**
(뒷짐을 풀며) ….

**B**
(뻗었던 손을 거두며) ….

A, 외투를 챙긴다. 서두르지 않는다.

**단말 (소리)**
금일 업무가 종료되었습니다. 미확정 건은 보류 처리되어 익일 재개됩니다. 내일 다시 방문해 주세요.

버튼이 화면에서 사라진다. 화면이 대기 화면으로 바뀐다.

**A**
(B에게, 목례) 내일 뵙겠습니다.

**B**
(일어나서, 직업적 인사가 반쯤 진심이 되어) …내일 뵙겠습니다.

A, 나간다.

C, 자기 번호표를 본다. 구겨진 번호표.

**C**
(B에게) 저는… 내일 이 번호 그대로 되나요?

**B**
새로 뽑으셔야 합니다.

**C**
(번호표를 주머니에 넣으며) …그럴 줄 알았어요.

C, 나간다. D, B의 어깨를 한 번 두드리고 나간다. 위로인지 격려인지 책임 전가인지 알 수 없는 손이다.

B, 혼자 남는다.

B, 단말을 정리한다. 창구의 불을 하나 끈다. 책상 위 — 펜꽂이의 펜. 오늘 하루 한 번 뽑혔다가 도로 꽂힌 펜.

B, 그 펜을 잠깐 본다.

그대로 둔다.

대기 화면의 빛만 남는다. 화면 속에서 내일의 첫 안내문이 이미 대기 중이다: `번호표를 뽑아 주세요.`

암전.

(끝)

## 조립 점검 (C1 규약)

- **무엇이 이동·변형됐는가**: 정보 — 교착이 하루를 이겼음(시스템의 마감이 교착을 끝내는 유일한 힘 — 사람은 아무도 못 끝냄), 스침의 미수(오작동 후보를 통과시키되 닿지 않게 — "닿지 않았다"의 확정이 A의 거부를 우연으로부터 보호), "내일 뵙겠습니다"가 인사이자 예고(무한 재방문의 수용 — 위협도 항복도 아닌 일정). 권한 — 없음: 아무도 행사하지 못한 채 시스템이 방면(ep.1 5장과 구조 각운 — 연작 통독 시 반복성 점검 항목으로 기재). 물성 — 협동 인증(넷이 한 팀 — 버튼만 빼고 전부 도울 수 있음), 한 치의 팔꿈치, 구겨진 번호표("새로 뽑으셔야 합니다" — C의 하루도 값을 치름), 한 번 뽑혔다 도로 꽂힌 펜을 B가 보고 그대로 둠, 내일의 첫 안내문.
- **희극 리듬의 정점과 하강**: 협동 인증(인증번호 훔쳐보기 개그 — "보지 마세요, 남의 인증번호") → 오 분 정지 그림 → **스침의 서스펜스**(전원 숨 멈춤·반사 동작 셋·"어—") → 안도의 동기화 → "큰일 날 뻔했네요"(A 자신이 제일 놀람 — 거부가 소중해진 역설). 웃음의 마지막이 서늘함으로 넘어가는 이음새 = B의 반쯤 진심인 "내일 뵙겠습니다".
- **결말 판정 근거**: 미수(후보 1) 기반 — 계보 넘김("놓인 펜 + 비우는 것조차 클릭으로")이 가장 순수. 오작동(후보 2)은 스침으로만 인용 — 닿았다면 A의 거부가 우연에 패배하는 것이라 부조리 희극이 잔혹극이 됨. 위임(후보 3)은 미채택(펜의 정적 훼손). C2 전 사용자 교체 가능.
- **어휘표 준수**: 단말 "금일 업무가 종료되었습니다"(어휘표 예시) ○, A 담담체 종결("내일 뵙겠습니다" — 화내지 않는 거부의 최종형) ○, B 곡선 완성(안내→부탁→반쯤 진심인 인사) ○. 제목 문장 0, 원작 어휘 0.
- **봉인 지문 점검**: 경구 0. "위로인지 격려인지 책임 전가인지 알 수 없는 손이다" — 연기 지시(모호성 지정) 판정, 낭독 확인 항목. "직업적 인사가 반쯤 진심이 되어" — 연기 지시.
- **플롯 표 대조(맵 5장)**: 겉 사건(마감·최종 만료) ○ / 정보(말보다 상태로) ○ / 권한(아무도 못/안 누름·미수) ○ / 남는 물성(놓인 펜, 사라진 버튼, 빈 창구) ○.
- **C1 완료 (5/5장)**. 다음: C2 연결본(사용자 승인 대기 — "C2 전까지" 방식 승계).
