# 병합 후보 A~G — 구조 처방

> [[wiki/shared/maps/글감_계열_병합_지도|계열·병합 지도]]의 병합 극 후보 7건에 대한 2단계 구조 처방. 각 후보의 미결 사항("다음 행동")을 결정하고, [[wiki/writing/aesthetics/글감_판정_루브릭|루브릭]] 보칙의 **재해석 4렌즈**(희곡적/동시대적/연극적/비유적)를 통과시킨다. 처방이 마음에 들면 개별 초고후보 카드로 승격한다.

---

## A. 유류품 인계극

**재료**: 한_장짜리_보고서(구조 모체) + 그건_관련이_있습니까(심문 변주 5종) + 라벨_없음(인계 불가) + 특이사항_없음(마지막 칸) + 폐기_완료(여진) + 독백 3종(기억은_별도_양식 / 손잡이 / 보완_요청)

**`폐기_전_확인`과의 차별화 (확정)**: 폐기는 관련자들의 자기기만이 중심(접힌 종이를 접는 사람들), 이 극은 **애도하는 타인과 담당자** — 기억이 양식에 들어가지 못하는 심문극. 다른 극이다. 진행.

- **장소**: 유류품 인계실 (경찰서 민원동 또는 병원 원무과 안쪽). 세미퍼블릭 — 다음 인계 순번이 계속 밀려 있는 공간.
- **문제 (초반 1/4)**: 인계받으려면 ①신원 ②관계 ③물품 대조가 통과돼야 한다. 신청자는 셋 다 애매하다.
- **인물**: 기억하는 사람(중심) / 담당자(권한) / 물품 보조자(중간 — 비닐봉투를 다루는 손) / 다음 순번 대기자(외부 — 전화 또는 노크로 압박).
- **플롯 척추**: `그건_관련이`의 5변주(컵–이름–비–물건–관련)를 인계 절차 순서로 재배열 → 신원 확인(이름) → 관련성 심문(컵/비) → 물품 대조(라벨_없음의 색상/재질 항목) → 특이사항 칸 → 인계 불가 통보와 여진(폐기_완료).
- **독백 처리 (히라타 보정)**: 독백 3종은 독백으로 쓰지 않는다. 대화의 파편으로 낮춘다 — "그 사람은 컵을 손잡이로 안 잡았어요"는 심문에 대한 대답으로만.
- **대표 문장 (하나만)**: "그러면 그 사람은 어느 항목에서 사람입니까." 나머지 좋은 문장("식고 있어" 등)은 낮추거나 물건으로 넘긴다.
- **재해석 체크**: 아체베의 치안판사("거의 한 장")는 이미 한국 행정으로 번역됨. 잔여 없음.
- **위험**: 앉은 문답극이 될 것 — 보조자의 물품 출입(가져오고, 다시 가져가고, 잘못 가져오고)으로 동선을 만든다.

## B. 관계자격 4부작 → **단일 단막으로 확정 (25분)**

**재료**: 기타에_체크하겠습니다 → 접수되었습니다 → 보완_요청 → 저장되지_않는_문장

**4부작 vs 장막 결정**: 4부작은 같은 창구의 반복 피로가 크다. **단일 25분**으로 압축한다. 근거: 동시대적으로 보완 요청은 접수 직후 자동 문자로 온다 — 접수 완료 30초 뒤 신청자의 휴대폰이 울리는 구조가 리얼타임을 지키면서 4단계를 한 자리에 모은다.

- **장소**: 기록 열람 민원 창구. 배경: 마감 30분 전(직원이 접수를 끝내야 하는 세미퍼블릭 시간).
- **플롯 척추**: 관계 확인("기타에 체크하겠습니다") → 설명란 축소(50자) → 접수 도장("접수되었습니다" — 잠깐의 안도) → **30초 뒤 자동 보완 요청 문자** → 증빙 불가 확인 → 결말: 신청자가 접수증 뒤에 저장되지 않을 문장을 손으로 쓴다(저장되지_않는_문장의 물성화 — 프로젝션 아닌 볼펜).
- **인물**: 신청자 / 직원(친절·정확) / 뒤의 대기자(번호 압박 — "저기, 마감이…"라고 말할 권리가 있는 사람) / 부재자(고인 — 봉투 속 물건).
- **대표 문장**: "작아졌습니다." (분노가 아니라 사실 확인으로.)
- **재해석 체크**: 잔여 없음. 주의 하나 — `설명란_부족`(script/ 원고)과 무대·장치가 겹친다. 겹쳐도 되지만, 이 극은 **직원 쪽 진폭**을 추가해 차별화: 직원이 마감 때문에 접수를 서두르는 자기 사정 하나(퇴근 후 가야 할 곳)를 갖게.
- **위험**: 신청자 원맨쇼 — 직원과 대기자에게 각자의 시간 압박을 줘서 3자 모두 옳게 만든다.

## C. 보정 극

**재료**: 잡음이_제거되었습니다 → 해상도가_높아집니다 → 원본으로_되돌릴_수_없습니다 → 자동_저장이_완료되었습니다 → 복구_가능한_항목이_없습니다 + 결말: 요약하지_않겠습니다

**B4(타인) 보강 — 3인 구도 확정**:
- **A 의뢰인**: 죽은 사람의 마지막 녹음을 "잘 들리게" 만들고 싶다. 문장을 원한다.
- **B 동행**: 그날 그 방에 있었다. **잡음의 정체를 아는 유일한 사람**(창밖 소리, 웃기 전 숨). 그러나 그 말을 하면 그날의 자기 위치도 말해야 한다.
- **C 기사**: 음성 복원 업체 직원. 친절하고 정확. 자기 직업 윤리가 있다 — "제 일은 잘 들리게 하는 겁니다."
- **장소**: 음성 복원 업체 작업실 (상업 공간 = 세미퍼블릭). 리얼타임 25분: 보정 작업의 시연 자체가 극.
- **플롯 척추**: 체인 5단계가 그대로 5플롯 — 잡음 제거 시연 → 선명 버전 재생(A 만족, B 침묵) → B의 원본 요청 → 자동 저장으로 덮어씀 발견 → 복구 불가 → 결말: 남은 무음 구간 30초를 지우려는 C를 B가 멈춘다. "무음 구간도 파일입니다."
- **정보차**: B만 잡음의 뜻을 알고, C만 기술을 알고, A만 비용과 목적을 안다. 셋의 앎이 전부 다르다.
- **재해석 체크 (중요)**: 기존 노트들이 공용으로 쓰던 예문 "괜찮아. 늦어도 돼."를 **이 극 고유의 원문 문장으로 교체**한다. 여러 노트에서 반복된 문구라 코퍼스 안에서 이미 닳았다.
- **위험**: 시스템 문구극 — C를 사람으로 유지(그의 직업적 자부심이 A의 요구와 B의 요구 사이에서 흔들리게).

## D. 76일의 극 → **만료일 하루로 압축**

**재료**: 76일을_벌었습니다(연장 통보) + 사건_없음·정상입니다·체크리스트형_희망(반복 점검) + 마지막_감자(작별 의식)

**장소 단일화 결정**: 연장 통보와 작별은 76일 떨어져 있어 리얼타임과 충돌한다. 해법 — **임시 거주시설의 퇴소 심사일 하루**: 오늘이 만료일이고, 연장 여부 통보를 기다리는 동안 마지막일지 모르는 배급 식사가 나온다. 통보가 오면 연장의 극, 안 오면 작별의 극 — 어느 쪽인지 모르는 채 점검과 식사가 진행된다.

- **장소**: 임시 주거시설(쉼터/전환주거) 공용 식당 겸 게시판 앞. 통보는 게시판 부착 or 문자.
- **인물**: 만료 대상자(중심) / 담당자(통보 권한 — 본인도 결과를 아직 모름) / 동료 거주자(중간 — 이미 연장된 사람 또는 이미 퇴소 확정된 사람) / 부재자(먼저 나간 사람의 빈 사물함).
- **플롯 척추**: 배급 수령 → 점검 루틴(사건_없음의 체크 동작들 — 만료일에도 하는 사람) → 동료의 어긋난 위로 → 통보 지연 → 식사 시작(마지막인지 모르는 채) → 통보 도착: **연장 ○일**. 결말: 기뻐해야 할지 모르는 채, 남은 밥을 마저 먹는다.
- **재해석 체크 (핵심)**:
  - **감자 직수입 금지** — 배급 식단(즉석밥+국 도시락)으로. 먹기 싫음, 식음, 목이 멤 같은 마찰은 유지.
  - **76일이라는 숫자도 마션 태생** — 행정적으로 그럴듯한 수치로 교체(90일, 60일, 또는 어중간해서 더 이상한 47일). 제목도 숫자를 따라 바뀐다.
- **대표 문장**: "오늘은… 안 끝난 사람처럼 앉아 있을 수 있어요."
- **위험**: 결과 통보가 클라이맥스가 되면 시나리오 문법 — 통보를 마지막 5분이 아니라 중간에 배치하고, 통보 이후의 시간(연장을 어떻게 받아들이는가)을 더 길게.

## E. 번역 극 → **운반체: 자연스럽게 고쳐 드렸습니다 (골격 확정)**

**재료**: 자연스럽게_고쳐_드렸습니다(골격) + 원문을_첨부해_주세요(중반 절차) + 그_침묵은_번역하지_마세요(위기) + 사랑하지_않아도_번역은_됩니다(결말 축) / 장치: 자막이_먼저_도착했습니다, 요약본에는_행간이_없습니다

**운반체 결정 근거**: `자연스럽게`가 장소(첨삭·교정 창구)와 절차(교정 의뢰)가 가장 구체적이고, 대표 문장("거기가 제가 온 곳이라서요")이 이미 있다.

- **장소**: 다국어 민원 지원 창구 / 행정 서류 교정 부스 (이주민 지원센터의 한 코너). 동시대 앵커: 자동 번역기 태블릿이 상주.
- **인물**: 교정 담당(선의 — 통과시키려는 사람) / 의뢰인(타인의 말 또는 자기 말을 제출해야 하는 사람) / 자동 번역 시스템(비인간) / 대기 의뢰인(외부).
- **플롯 척추**: 교정 의뢰 — 어색한 문장이 매끈해짐 → 의뢰인의 "제 말이 아닌데요" → 원문 요구 절차("원문을 첨부해 주세요" — 원문이 없는 말: "손을 잡고 말했어요") → 침묵 구간의 분류 위기(`무응답/진술 거부` 중 택일 요구) → 자동 번역 완료·오류 없음 판정 → 결말: 의뢰인이 **틀린 문장 하나를 돌려달라**고 한다.
- **부품 과적 방지**: 6편을 다 넣지 않는다. 자막이_먼저·요약본_행간은 장치 1~2개(화면이 말보다 먼저 뜨는 비트, "중복이 아니라 불러본 건데요")만 회수.
- **대표 문장**: "거기가 제가 온 곳이라서요."
- **재해석 체크**: 흰 고래(번역론)는 개념 차용 — 멜빌·셰익스피어(`will`) 어휘를 극에 남기지 않는다. 잔여 없음 확인.
- **위험**: 의뢰인의 국적/사연 과잉 — 어디서 왔는지 끝까지 말하지 않아도 되게. 틀린 조사 하나, 어순 하나가 출신을 대신한다.

## F. 늦게 도착하는 말

**재료**: 3_8초_지연(지연 자막 장치) × 굴렀음_수리_중(안/밖 상태 보고 구조)

**안/밖 공간 설계 확정**: 우주 직수입 대신 — **격리병동 화상 면회실**. 화면은 몇 초 지연되고, 문자 메시지는 글자 수 제한이 있으며, 면회 시간은 짧다.

- **장소**: 병원 면회실(밖) + 화면 속 병실(안 — 부재자적 존재). 밖이 무대, 안은 화면과 소리로만.
- **인물**: 면회 온 사람 둘(가족 — 서로 말하는 법이 다른 두 사람) / 면회 담당 직원 / 화면 속 사람(안).
- **핵심 장치**: **말과 자막의 어긋남이 리듬** — 안쪽 사람의 말이 자막보다 늦거나, 자막이 말보다 먼저 뜬다(자막이_먼저의 반대 방향도 사용 가능). 20자 제한 상태 보고: "넘어졌음. 일어나는 중." 두 문장 구조(사고+현재 동작) 유지.
- **플롯 척추**: 면회 연결 → 지연 발견(농담으로 시작) → 상태 보고의 문답(바깥의 긴 걱정 vs 안쪽의 짧은 보고) → 연결 끊김/재접속 → "아직"이 늦게 도착하는 비트 → 결말: 면회 종료 후, 화면이 꺼진 뒤 마지막 문장이 도착한다.
- **재해석 체크**: "굴렀음. 수리 중." 전보체의 **기능**(주도권 회복)은 유지하되, 문장 자체는 한국어 문자 메시지 물성으로("넘어졌음. 일어나는 중"). 3.8초라는 숫자는 버린다 — 병원 화상 시스템의 지연은 명시하지 않고 체감시킨다.
- **대표 문장**: "그 단어가 제일 늦게 오면 안 되는데." ("아직"에 대해.)
- **위험**: 감상 과잉 — 담당 직원의 절차(면회 시간 안내, 다음 면회자 대기)가 계속 끼어들게 해서 온도를 낮춘다.

## G. 크웨누 × 정중한 함정 → **1극 2부로 통합 확정**

**재료**: 응답_없는_크웨누(합창 실패) + 정중한_함정(절차 포획) — 아체베 형제작

**통합 근거**: 두 노트는 같은 붕괴의 앞뒤다. 총회에서 응답이 갈라진 공동체(1부)가 "대표자 몇 분만 들어오시죠"에 끌려 들어간다(2부). 1부는 넓고(7~8인) 2부는 좁다(4인 협의실) — 공간이 좁아지는 구조 자체가 포획이다.

- **장소**: 재개발을 앞둔 오래된 상가의 상인회 사무실 → 상생협의회 협의실. (또는 마을회관 → 조합 사무실.)
- **재해석 전면 적용 (이 극의 최우선 과제)**:
  - `우무오피아 크웨누 / 야아` **직수입 금지.** 한국 공동체의 호명–응답 등가물 후보 3개 중 택1:
    1. **상인회 개시 구호** — 수십 년 된 새벽 개시 인사("오늘도 문 엽니다!" — "엽시다!")가 재개발 국면에서 갈라진다.
    2. **이의 절차의 역전** — 총회의 "이의 없습니까" — "없습니다!"가 원래는 결속의 리듬이었는데, 이제 침묵·어긋난 대답·"저는 좀…"으로 갈라진다. (가장 행정적·가장 히라타적.)
    3. **받는 소리** — 상여/풍물의 메기고 받는 소리를 기억하는 노인과, 받을 줄 모르는 젊은 세대. (장례 배경일 때.)
  - 추천: **2번(이의 절차)** — 별도 문화 설명 없이 관객 전원이 아는 리듬이고, 2부의 서명 절차와 정확히 이어진다.
  - 원로/청년/상인/서기 구조는 유지(이미 보편형). 단 호칭·이름·의례 어휘 전부 한국 상가/조합 언어로.
- **플롯 척추**: 1부 — 구호/이의 절차 연습(웃음) → 안건 상정 → 첫 호명: 응답 갈라짐 → 각자의 이유 → 마지막 호명: 각자의 말이 겹침. 2부 — "대표자만" 초대 → 휴대폰/서류 보관(자발적 무장 해제) → 대기 → 호칭 변화(어르신→피신청인) → 문 잠기는 작은 소리 → "서명은 동의가 아니라 확인입니다."
- **대표 문장**: 1부 — "그때도 아무도 대답 안 했어요."(막내) / 2부 — "서명은 동의가 아니라 확인입니다."
- **부품 공유**: 서기의 회의록은 `회의록에는_없습니다`와 부품 공유(중복 아님 — 다른 극).
- **위험**: 1부 인원(7~8인)의 리딩 부담 — 필요시 1부를 5인으로 압축(원로/청년/상인/서기/막내).

## 승격 순서 제안

응집력과 재해석 준비도 기준:

1. **E 번역 극** — 재료 최신·응집력 최고·재해석 부담 없음
2. **A 유류품 인계극** — 부품이 가장 숙성됨 (폐기_전_확인과 병행 가능)
3. **G 크웨누×정중한 함정** — 재해석 결정(이의 절차)만 확정되면 구조는 이미 완성
4. **C 보정 극** — 3인 구도 설계 완료, 고유 원문 문장 창작 필요
5. **B 관계자격 단막** — 설명란_부족과의 차별화(직원 진폭) 확인 후
6. **D 만료일 극** — 숫자·식단 재해석 후
7. **F 늦게 도착하는 말** — 지연 장치의 기술 리허설이 필요해 마지막

각 후보를 개별 `_초고후보` 카드로 승격할 때 이 처방을 로그라인·무대 규칙·7장 구조로 확장한다.
