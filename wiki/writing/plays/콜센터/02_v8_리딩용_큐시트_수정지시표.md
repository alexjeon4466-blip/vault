# 콜센터 v8 — 리딩용 큐시트 / 수정 지시표

## 목적

이 문서는 v8 원고를 바로 고치기보다, **리딩에서 확인해야 할 소리·오브제·상태값·몸의 타이밍**을 고정하기 위한 큐시트다. 현재 판단은 “사건 추가”가 아니라 **물소리·신발·휴대폰·상태값의 기능 분화**가 우선이다.

## 리딩의 핵심 가설

> 이 작품은 C가 왜 울었는지를 밝히는 극이 아니라, C의 몸이 `울지 않는 목소리`, `복귀 가능`, `확인 중`, `미응답`으로 번역되지 못하는 시간을 관객이 같이 견디는 극이다.

따라서 리딩에서 가장 먼저 볼 것은 다음 네 가지다.

1. 물소리는 매번 다른 일을 하는가.
2. 휴대폰은 연결/감시/응답불능을 동시에 만들고 있는가.
3. 신발은 C의 대체물이 아니라 “아직 여기 있음”의 잔여로 보이는가.
4. 공식 언어는 설명이 아니라 압력 상승으로 들리는가.

### 물소리 수정 원칙

- 물소리를 “상징”으로 설명하지 않는다.
- 물소리는 매번 다르게 작동해야 한다: 배경음 → 은폐 → 정적의 반대 → 몸의 보호막 → 끄지 못하는 책임 → 엔딩의 잔상.
- 리딩에서 물소리가 단조로우면 대사를 늘리지 말고 **음량/정적/손의 위치**를 조정한다.

### 전화 수정 원칙

- 전화 너머 내용을 들려주지 않는다.
- 고객/관리자의 말을 구체화하지 않는다.
- 휴대폰은 “외부 인물”이 아니라 상태값과 연결의 물체다.
- A가 받은 전화는 응답이 아니라 **응답불능의 가시화**다.

### 신발 수정 원칙

- 신발은 C의 상징이 아니라 C의 **잔여 현존**이다.
- 신발 움직임은 적어야 하지만, 관객이 놓치면 안 된다.
- C가 나오지 않는 선택은 유지한다. 얼굴을 보여주면 이 작품의 핵심 장치가 약해진다.

### 공식 언어 수정 후보

#### 후보 A — 431행 낮추기

현재:

```text
B  확인 중. 복귀 예정. 보호조치 검토. 다 말장난이잖아.
```

리딩에서 설명처럼 들리면:

```text
B  확인 중. 복귀 예정. 보호조치 검토.
B  ...그 말들 다, 너무 잘 붙어.
```

또는 더 낮게:

```text
B  확인 중. 복귀 예정. 보호조치 검토.
B  다 붙네.
```

#### 후보 B — 501행 조절

현재:

```text
A  ...상태만 보내면 돼.
```

리딩에서 직접이면:

```text
A  ...상태만.
```

또는:

```text
A  ...상태라도.
```

단, A의 공포가 약해지면 원문 유지.

#### 후보 C — 619행 유지/삭제 판단

현재:

```text
A  나는 그게 제일 무서워.
```

판단:

- 배우가 낮게 처리하면 유지 가능.
- 너무 자기해설처럼 들리면 `미응답으로 떠` 뒤 침묵으로 대체 가능.

실험안:

```text
A  미응답으로 떠.

*긴 사이.*

*A는 전화를 받는다. 귀에 댄다. 말하지 않는다.*
```

## 6. 장면별 수정 지시표

| 장면 | 우선 지시 | 보존할 것 | 리딩 후 조절 후보 |
|---|---|---|---|
| 무언 도입 | 침묵을 충분히 둔다 | A의 손, B의 시선, 신발 발견 | 지루하면 대사 추가 금지. 시선/동선만 선명화. |
| A-C | `한 콜만`의 양가성 유지 | C의 `하지 마`, A의 `틀리기 싫어요` | A의 229–247행이 과설명인지 확인. |
| B-C | B의 과거는 행동에 기대게 | 물 잠그기 실패 | 287–299행 보호조치 설명 압축 여부 확인. |
| A-B-C | 공식 언어가 몰려오는 리듬 | `보고만 있잖아`, `기록`, `다른 말로 같은 거 해` | `다 말장난이잖아`, `상태만 보내면 돼` 직접도 체크. |
| 후반 전화 | 말보다 행동 | A는 받지만 말하지 않음, B는 하나만 끔 | `나는 그게 제일 무서워` 유지 여부. |
| 엔딩 | 물소리를 마지막 압력으로 테스트 | 신발 그대로, 휴대폰 작은 목소리 | 콜 적체 알람을 너무 크게 하지 않기. |

## 8. 수정 우선순위 결론

### 1순위: 오브제/사운드 큐 고정

- 물소리 기능 변화.
- 휴대폰 진동/통화/세면대 위치.
- 신발 방향 변화.
- 콜 적체 알람의 크기와 길이.

### 2순위: 공식 언어 직접도 조절

- `다 말장난이잖아`.
- `...상태만 보내면 돼`.
- `나는 그게 제일 무서워`.

이 셋은 삭제 확정이 아니라 **리딩 체크 후보**다. 배우가 낮게 처리하면 유지 가능하다.

### 3순위: B의 과거 설명 압축 여부

- 287–299행은 현재 기능하지만, 리딩에서 보호조치 실패담으로 극이 기울면 줄인다.
- 줄일 경우 설명을 없애고, 물을 잠그지 못하는 행동에 더 맡긴다.
