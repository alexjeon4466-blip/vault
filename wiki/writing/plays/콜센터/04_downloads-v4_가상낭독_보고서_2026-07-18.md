## 1. 최종 판정

# **구조 유지 + 최소 감산**

구조 재배치나 큰 감산은 필요하지 않다.

네 구간은 같은 문제를 반복하지 않고 비용을 다음처럼 이동시킨다.

1. **무언 도입:** 발견했으나 명명하지 못한 A와 B가 물을 다시 틀어 C의 존재를 감추는 공모
2. **A–C:** C가 A에게 건넸던 생존법이 A를 계속 업무에 붙잡았다는 관계적 빚
3. **B–C:** 확인하려던 B가 물도 문도 처리하지 못하고 C의 정지에 함께 묶이는 신체적 비용
4. **A·B·C:** 기록·미응답·수신을 처리할수록 C의 은폐 공간이 열린 마이크에 노출되는 비용

핵심 행동 아이러니도 이미 두 겹으로 성립한다.

- C를 숨기기 위해 흐르는 물이 오히려 C가 안에 있다는 표지가 된다.
- `미응답`을 피하려고 A가 받은 통화가 화장실 안쪽을 외부에 연결한다.

고쳐야 할 것은 구조가 아니라 인물들이 이 아이러니를 한 번 더 설명하는 대사다.

## 3. 작품의 보호 약속

### C는 끝까지 세 번째 칸 안에 있다

C가 나오지 않는 것은 해결을 미루는 장치가 아니라 공간 문법이다. A와 B는 출입하고 수도와 휴대폰을 만지지만, C는 신발·숨·휴지·잠금쇠·목소리로만 상태를 바꾼다.

### 물소리는 단순 배경음이 아니다

- A와 B가 C를 가리는 소리
- 물을 잠갔을 때 C의 몸을 노출하는 장치
- B가 답을 늦추는 실제 손 씻기 시간
- 대화가 C의 현재에서 벗어날 때 주의를 다시 칸으로 돌리는 소리
- 마지막 통화가 끝난 뒤에도 남는 해결되지 않은 상태

단독 `물소리` 26회는 동일한 길이의 시적 구두점으로 처리하지 않는다.

### 안내문과 시스템은 말하지 않는다

안내문은 반사로 한 번만 판단한다. 업무 시스템은 상태어·진동 패턴·내용을 알아들을 수 없는 작은 목소리·종료음·알람으로만 존재한다. 새 자동 안내, 팀장 대사, 콜봇 음성은 추가하지 않는다.

### `고맙대`는 구조 파편이다

`고맙대 / 오래 기다렸는데 / 그래도 사람이 받아 줘서 다행이라고 / 한 콜만 더`는 고객의 감사가 C를 다시 친절·응대에 묶는 순간이다.

- C가 왜 무너졌는지 설명하는 단일 원인으로 만들지 않는다.
- 악성 고객의 반대편에 착한 고객을 배치하는 도덕화로 읽지 않는다.
- 눈물 섞인 고백이나 특정 고객 서사로 확대하지 않는다.
- 너무 평범한 말이 자동으로 되돌아오듯 작고 평평하게 읽는다.

### A와 B는 정답의 양편이 아니다

- A는 보내고·누르고·받는다.
- B는 보내지 않고·누르지 않고·전원을 끈다.
- 그러나 둘 다 보냄을 받고 화장실에 왔으며, 각자 하나씩은 끊지 못한다.

A를 순응자, B를 저항자로 확정하지 않는다.

## 4. 전체 호흡 곡선

| 구간 | 속도 | 핵심 호흡 |
|---|---|---|
| A 입장–신발 발견 | 매우 빠름 → 급정지 | 입꼬리·호흡·손 씻기는 정비 절차처럼, 신발에서 첫 정지 |
| A–B 무언 공모 | 중간 → 느림 | 거울과 신발을 번갈아 보며 같은 사실을 공유하되 말하지 않음 |
| B 귀환–물 차단 | 가장 느림 | 물이 멎은 뒤 잠금쇠·작은 소리·실패한 숨을 분리 |
| A의 상태 보고 | 빠름 → 걸림 | 행정 문장은 외운 말처럼, C의 `여기 있는데`에서 갑자기 정지 |
| 호흡 세 번–한 콜만 | 느림 → 가속 → 정지 | 세 번째 호흡만 거의 겹치고 `한 콜이 왜 이렇게 많아` 뒤 충분히 쉼 |
| 돌봄의 반환 | 느림 | `살린 줄/앉혀 놓은 것 같기도`를 판결하지 않음 |
| B의 손 씻기–보호 요청 기억 | 매우 느림 → 보통 | 손 씻기가 대답을 늦추고 C의 `너 왜 왔어`에서 급정지 |
| 콜 경로–`고맙대` | 빠름 → 아주 느림 | 콜봇 경로는 한 호흡, 감사 파편은 불균등한 공백 |
| 수도·문 앞 정지 | 보통 → 짧고 날카로움 → 정지 | 소리 목록이 실제 칸 안의 몸을 만들고 B의 행동이 대사를 인수 |
| A·B 상태 논쟁 | 보통보다 빠름 | 서로의 끝을 예상하는 동료처럼, 제도어를 풍자하지 않음 |
| 신발–믿음/부러움 | 완전 정지 → 느림 | 예쁜 대칭으로 맞춰 읽지 않고 C가 현재를 되찾음 |
| 자동 기록–동시 통화 | 빠름, 점층 | 새 진동 뒤 화면 인식 시간을 확보하고 통화가 C 쪽 동선을 차단 |
| 수신·전원 끄기·열린 마이크 | 거의 무언 | 세 행동을 각기 다른 선택으로 한 박자씩 보임 |
| `모르겠어`–퇴장–소리 종지 | 매우 느림 | C의 말을 매끈하게 잇지 않고 신발·작은 목소리·종료음·물·알람을 분리 |

## 5. 겹침 후보

모두 적용하지 않는다. 전반 2–3개, 후반 3–5개만 시험한다.

### 전반

1. A `그러니까 복귀 가능—`의 끝을 C `자리 비움 아니야.`가 자름
2. A `그게 아니라—` 위로 C `자리에는 없고,`가 낮게 들어옴
3. 세 번째 호흡에서만 A와 C의 날숨이 거의 겹침
4. A `한 콜만.`의 마지막 음에 C가 같은 말을 작게 시작

### 후반

1. B의 미완 문장을 C `너 왜 왔어.`가 자름
2. A `그럼 상태라도—`를 B `또 상태.`가 끊음 — 낭독본에서는 문장 자체를 감산함
3. A `관리자 직접 확인 필요로 보내면—`을 C `눌렀어?`가 자름
4. A `아니요. 아직—` 위로 두 번째 `눌렀어?`
5. A `언니, 그게 아니라—` 위로 C `나는 아직 여기 있는데.`
6. B `아직 돌아갈 데가 있다는 거잖아.`의 끝에 A `나는 받으면, 계속 들려.`가 들어옴

`고맙대`, C의 `모르겠어`, 마지막 소리 종지에는 겹침을 넣지 않는다.

## 6. 반드시 확보할 행동·침묵

초 단위 수치는 실제 측정값이 아니라 첫 실제 합독의 목표 호흡이다.

### 무언 도입·A–C

- 노크 직전 주먹 정지: **2–4초**
- 거울 눈맞춤→신발 확인→두 번째 칸 입장: **6–10초**
- 물이 완전히 멎은 뒤 잠금쇠와 작은 소리: 각각 **2–3초**
- 신발 방향 변화와 실패한 숨 뒤: **4–7초**
- 무언 도입 말미 신발만 남은 시간: **5–9초**
- 세 호흡 전체: **18–27초**
- `하지 마` 뒤 입꼬리 실패와 다음 질문: **6–10초**
- 진동 무시→양면적 고백→사과·취소→퇴장: **15–24초의 분산된 쉼**

### B–C·A·B·C

- B의 첫 오래 손 씻기와 `오늘은 그냥 다요` 뒤 물만 남는 시간
- C `보냈다고 다 오진 않잖아` 뒤 젖은 손을 빼고 한 걸음 물러나는 동작
- `고맙대`와 `사람이 받아 줘서 다행` 뒤 서로 다른 길이의 짧은 공백
- C `잠그지 마` 뒤 수도 위에서 멈춘 B의 손
- B가 물을 못 잠근 뒤 문으로 갔다가 못 나가는 일련의 행동
- 신발이 움직인 뒤 A·B가 멈추고 물만 들리는 시간
- 새 진동 패턴 뒤 A가 화면을 읽는 시간
- A가 C 쪽으로 가려다 동시 통화에 막히는 순간
- A 수신→작은 목소리→숨 참기→B 전원 끄기→A 미차단→열린 마이크를 각각 한 박자씩
- `긴 침묵`→C의 불완전한 말→A·B 퇴장→신발→작은 목소리→종료음→물→알람

#### A·B·C

11. `상태라도/확인 중/누가/우리가 보고` 다섯 박자 → `또 상태. / 그럼 확인 중이라고라도—`
12. 상태 목록 뒤의 `다 말장난이잖아.` 삭제
13. 상호 부러움의 두 번째 회전 `나는 네가 부러운데 / 뭐가 / 너는 안 믿어도 되잖아` 삭제
14. 상태 목록 뒤 `그래서 뭐라도 보내야 돼.` 삭제
15. `이십 분 넘었어 / 장시간 이석으로 기록됐어` → `장시간 이석 떴어.`
16. `나는 그게 제일 무서워.` 삭제 — `미응답으로 떠` 직후 A가 받는 행동이 공포와 복종을 동시에 수행

### 이견 때문에 적용하지 않은 감산

- **두 단계 `하지 마`:** 대사 편집은 결합을 권했지만 배우 낭독은 두 단계를 보호했다. 낭독본에 원형 유지.
- **C의 `모르겠어` 반복:** 감산 보고서는 위험한 비교 후보로 봤으나 배우 낭독은 파편 호흡을 보호했다. 유지.
- **B의 `하나는`:** 행동 설명 가능성은 있으나 전화 하나만 끊었다는 잔여가 강해 유지.
- **마지막 적체 알람:** 드라마투르기는 중복 종결로 삭제 시험, 배우·연출은 도입 업무시간이 되밀리는 절단으로 유지. 낭독본에는 유지하고 아래 두 종결안으로 비교.

현재 파일에는 안 A를 유지했다. 실제 소리 큐 리딩에서 두 안을 연속 비교한 뒤 하나만 선택한다.
