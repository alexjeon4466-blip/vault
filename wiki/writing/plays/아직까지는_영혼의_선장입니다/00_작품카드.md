# 아직까지는 영혼의 선장입니다 — 작품카드

## 핵심 질문 / 로그라인

자격과 이해는 왜 다른 사람에게 있는가. 시스템이 표결·집계·회의록 생성까지 끝낸 회의에서 최종 승인란 한 칸만 비어 있다 — 서명 자격이 있는 사람들은 내용을 이해하지 못하고, 이해하는 운영 담당은 자격이 없고, 틀리던 시절을 아는 전 심사위원은 발언권이 없다. 펜이 A→C→D(제지)→B→A로 한 바퀴 돌고, 아무도 긋지 못한 점 하나가 남은 채 시스템이 자동 보류로 폐회한다. 오늘의 빈 칸은 내일의 첫 안건이 된다.

## 버전 상태 — C4 통과·잠금 (2026-07-18)

- **잠금 판본 = v3**: `wiki/writing/drafts/아직까지는_영혼의_선장입니다_v3.md` — 31.5매, 배우 중앙값 19:59. 이후 수정은 v4로만. 파일은 SHA-256 무결성 보존을 위해 무수정 잠금(해시는 낭독 결과 문서에 기록).
- 계보: 연결본(C2)·C3 1회차(35.1매) → vault 밖 v1(정합)→v2(권한 재배분)→v3(반복 곡선·해설 감량·종막 역점). 구 판본 동결·보존.

## C4 게이트 기록 (은폐 없는 기록)

- **낭독 대체 인정**: 다중 가상 낭독(3방 패널, 방식 ⑶) — 실제 배우·청자 아님. 판정 통과: 펜 순회·D의 인간적 오류·차기 안건 종막 다수 회상. 정식 낭독·상연 발생 시 v4 회차 입력. [[wiki/writing/notes/서명칸_계보_C4_게이트_평가_2026-07-18|일괄 게이트 평가]] 참조.
- **P0 0건**. 유지 판정: `한 바퀴 돌았네요` 유지(4/5). P2 좌표 항목: 같은 높이 펜촉 — 설명 대사 추가 금지.
- **씨앗 (소급 동결 2026-07-18)** = v3 판본 메모의 보호 항목: 승인 대기 안내의 반복, A·D의 접근 거리, `형식`의 붕괴, C의 가방·시간, D의 라벨, 옛 기록과 현재 기록의 축적, 자동 보류→서로 다른 퇴장→빈 방→차기 첫 안건 종막. 변경은 씨앗 개정 vN으로만.

## 제작 잠금값 / 연출 유의

- 장 사이 교량 4~5초, 마지막 화면 `차기 회의 안건 1` 6초 우위(다중 종결 방지).
- 반 토막 발화 2연속은 실패하는 호흡(A)과 시스템 문구를 붙잡는 회수(C)로 정조 분리.
- D의 "그때는… 틀려도, 사람이 틀렸습니다" 뒤 전원 무응답이 받친다 — 재명명 금지.
