# 거울을 옮기는 사람 — 4장 방해

## 이어지는 상태

3장 마지막. C는 컵으로 이름표를 가리고 있고, 컵 가장자리의 약한 반사광이 잎 끝에 닿아 있다. A는 거울 손잡이를 잡아 C의 팔 떨림을 따라가고, B는 기록지의 `개인` 두 글자를 손가락으로 가린다.

## 4장 — 방해

*빛은 잎 끝에 있다. 약하지만 분명하다. 이름표는 컵 뒤에 가려져 있다.*

*C의 팔이 떨린다. A는 그 떨림에 맞춰 거울을 아주 조금씩 움직인다. B는 기록지를 든 채 세 사람의 손과 컵과 이름표 사이를 본다.*

C  팔이.

A  네.

C  좀.

A  제가 잡을까요.

C  컵을요?

A  아니요. 거울을요.

C  거울은 잡고 계시잖아요.

A  더요.

B  두 분 다 손 떼시는 게 좋습니다.

A  지금 닿아서요.

B  그래서요.

C  그래서 손을 떼면 안 되는데요.

B  그래서 위험합니다.

*사이. C의 컵이 아주 조금 내려간다. 빛이 이름표 아래쪽으로 미끄러진다.*

A  조금만 올려주세요.

C  팔이 떨려서요.

A  네. 조금만.

B  컵은 원래 그 용도가 아닙니다.

C  원래 용도는 비어 있는 거였어요.

B  물을 담는 용도죠.

C  물도 없고요.

A  빛은 있어요.

*B가 A를 본다. A는 바로 고개를 내린다.*

B  보호자분.

A  네.

B  그 말은 적기 어렵습니다.

A  적지 마세요.

B  지금은 적어야 해서요.

C  뭘요.

B  방해요.

C  누가요.

B  상황상.

C  상황이 방해예요?

B  통행과 안전에 방해가 됩니다.

A  통행은 지금 아무도.

*복도 안쪽에서 누군가 걸어오는 소리. 세 사람은 동시에 멈춘다. B가 바로 움직인다.*

B  통로 비워주세요.

*C가 컵을 든 채 뒤로 물러나려 한다. 컵이 기울고, 빛이 C의 눈으로 튄다.*

C  아.

A  죄송합니다.

C  잠깐만요.

A  네.

B  컵 내려놓으세요.

C  내려놓으면 이름이 보이잖아요.

B  이름표는 제가 가리겠습니다.

C  어떻게요.

*B가 기록지를 들어 이름표 앞에 댄다. 기록지에는 `개인` 두 글자와 `보호자`가 보인다. 종이가 빛을 받아 하얗게 밝아진다.*

A  종이도.

B  압니다.

*기록지에 반사된 약한 빛이 A의 손등에 닿는다. A가 손을 조금 움찔한다.*

C  지금 손에.

A  네.

B  손은 개인정보가 아닙니다.

C  그런 말 하지 마세요.

*B가 멈춘다.*

B  죄송합니다.

*지나가던 사람의 발소리가 멀어진다. 통로는 다시 비어 있다. B는 기록지를 내리지 못한다. C는 컵을 들고 있다. A는 거울을 들고 있다. 세 사람이 모두 뭔가를 들고 있다.*

C  다 들고 있네요.

A  네.

B  내려놓으셔도 됩니다.

C  누가요.

B  모두요.

A  그러면 안 닿아요.

C  그러면 보이고요.

B  그러면 안전합니다.

*사이. `안전합니다`가 공중에 남는다.*

C  안전하면 뭐가 남아요?

B  네?

C  안전하면. 여기 뭐가 남아요.

B  사고가 안 납니다.

C  빛도 안 나고요.

B  빛은 사고가 아닙니다.

A  사고가 될 수도 있어요.

B  그렇죠.

A  아니요. 안 닿는 게요.

*B가 대답하지 못한다. C가 컵을 아주 조금 돌린다. 빛이 다시 잎 끝에 닿는다. A가 거울을 맞춘다.*

B  돌리지 마세요.

C  눈 안 부시게 한 건데요.

B  지금은 더.

C  더 닿았어요?

A  네.

B  더 위험해졌습니다.

C  같은 방향인데요.

B  결과가 달라졌습니다.

C  결과가 좋으면요?

B  좋고 나쁘고의 문제가 아닙니다.

A  닿고 안 닿고의 문제예요.

B  그것도 병동 기준은 아닙니다.

C  기준이 아닌 건 다 방해예요?

B  기록되지 않은 행동이 반복되면.

A  기록하면 돼요?

B  기록할 수 있는 항목이어야 합니다.

C  `빛`은 없고요.

B  없습니다.

A  `방해`는 있고요.

B  네.

*사이. A가 거울을 조금 내린다. 빛이 사라진다. C는 컵을 들고 있지만 더 이상 반사되지 않는다.*

C  지금은 괜찮죠.

*빛은 없고, B의 기록지만 하얗게 밝다. 복도 안쪽에서 아주 작은 기계음. 병실 문이 열렸다 닫힌다. 이번에도 손은 보이지 않는다.*

A  다시 올릴게요.

B  안 됩니다.

A  조금만요.

B  지금 방해로 기록하면 이후 사용이 제한될 수 있습니다.

C  사용이요?

B  거울이요.

C  거울 사용 제한.

B  네.

C  병원에 그런 게 있어요?

B  만들 수 있습니다.

A  지금요?

B  필요하면요.

C  필요하다는 게 누구한테 필요한 건데요.

B  병동 운영에.

C  잎에는요.

B  잎은 병동 운영 대상이 아닙니다.

*A가 그 말을 듣고 거울을 천천히 내린다. C도 컵을 내린다. B는 기록지를 든 채 서 있다.*

*빛은 어디에도 닿지 않는다.*

C  사람 눈은요.

B  네?

C  아까 사람 눈은 안 된다고 했잖아요.

B  네.

C  식물은 되고 사람은 안 돼요?

A  사람도요.

*B와 C가 A를 본다. A는 바로 덧붙이지 않는다.*

C  뭐가요.

A  닿아야죠.

C  빛이요?

A  네.

C  누구한테요.

*A는 대답하지 않는다. 복도 안쪽을 본다. C도 그쪽을 본다. B는 기록지를 내리지 못한 채 복도 쪽을 본다.*

*아주 잠깐, 커튼 아래 손이 보인다. 빛은 그 손에 닿지 않는다. 손은 다시 사라진다.*

C  저기.

B  병실 쪽은 보시면 안 됩니다.

C  봤어요?

B  보시면 안 된다는 뜻입니다.

A  봤어요?

C  모르겠어요.

A  손이요?

C  모르겠어요.

B  병실 안쪽은 사생활입니다.

C  손도요.

B  네.

A  손은 개인정보가 아니라고.

B  제가 방금 부적절하게 말했습니다.

A  네.

*사이. B가 기록지를 접는다. `방해`라고 쓰려던 칸이 접혀 보이지 않는다.*

B  일단.

C  네.

B  이건 지금 치우셔야 합니다.

A  네.

*A는 거울을 접는다. 접이식 거울이 딱 닫힌다. C가 컵을 내려놓는다. 빛이 완전히 사라진다.*

*잠시 어두워진 휴게실. 화분 선반과 이름표들은 흐릿하다.*

C  이제 안 보여요.

B  네.

A  네.

C  안전하네요.

*B가 대답하지 않는다.*

*A의 휴대폰 알림음이 아주 작게 울린다. A는 화면을 보지 않는다.*

B  알림.

A  네.

C  십오 분이에요?

A  아니요.

C  그럼요.

A  놓친 거요.

B  네?

A  아까 것.

*사이. A는 접은 거울을 가방에 넣지 못한다. 손에 들고 있다.*

C  다시 하면 방해예요?

B  네.

C  안 하면요.

B  ...

C  안 하면 뭐예요.

B  방해는 아닙니다.

A  네.

*복도 안쪽에서 다시 작은 기계음. 세 사람 모두 아무것도 들은 척하지 않는다. 그러나 모두 움직이지 않는다.*

*암전하지 않는다. 빛은 없고, 접힌 거울만 A의 손에 있다.*
