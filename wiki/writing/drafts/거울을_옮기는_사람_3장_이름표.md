# 거울을 옮기는 사람 — 3장 이름표

## 이어지는 상태

2장 마지막. C가 종이컵을 거울 아래에 받쳐 빛을 조금 올렸다. 빛은 화분 잎이 아니라 빈 이름표를 비췄다. A는 `거긴 아니고요`라고 했고, C는 `그래도 비었네요`라고 했다. B는 기록지에 아무것도 더 쓰지 못했다.

## 3장 — 이름표

*빛은 빈 이름표 위에 있다. 이름표는 흰 테이프였던 것 같지만, 오래되어 가장자리가 누렇게 떠 있다. 한쪽 끝에는 지워진 글자의 흔적이 남아 있다.*

*C는 컵을 든 채 팔을 조금 떨고 있다. A는 그 컵과 거울 사이를 본다. B는 기록지를 든 채, 빈 이름표를 보지 않으려다 본다.*

C  비었네요.

A  네.

C  원래 뭐가 있었던 거예요?

A  모르겠어요.

C  다 모르세요.

A  네.

B  이름표는 임의로 확인하시면 안 됩니다.

C  제가 확인한 게 아니라 빛이.

*B가 C를 본다. C는 컵을 들고 있다.*

B  빛은 확인 주체가 아닙니다.

C  그렇죠.

A  조금만 낮춰도 될까요.

C  컵을요?

A  네.

*C가 컵을 아주 조금 낮춘다. 빛이 빈 이름표에서 아래 화분 잎 쪽으로 내려가다가, 다른 이름표를 지난다. 거기에는 `613` 같은 숫자가 반쯤 보인다.*

B  잠깐만요.

*C가 멈춘다.*

A  왜요?

B  병실 번호가 보입니다.

C  613이요?

B  읽지 마세요.

C  이미 읽었는데요.

B  반복하지 마세요.

C  613.

B  보호자분.

C  죄송합니다.

*사이. A는 거울을 조금 돌리려다 멈춘다.*

A  그쪽은 아니에요.

B  어느 쪽이 아닌데요.

A  빛이요.

B  번호 쪽도 안 됩니다.

A  네.

C  빛도 개인정보 봐요?

B  개인정보가 노출되면 안 됩니다.

C  빛한테요?

B  사람한테요.

*A가 거울을 아주 조금 돌린다. 빛이 `613`을 지나 다른 화분으로 간다. 그 이름표에는 이름의 마지막 글자처럼 보이는 `자`만 남아 있다.*

C  자.

B  읽지 마세요.

C  글자 하나도요?

B  글자 하나도 정보가 될 수 있습니다.

C  사람 이름인지도 모르잖아요.

B  모르기 때문에요.

A  모르기 때문에 가려야 해요?

B  네.

A  모르기 때문에 비춰야 하는 건요.

*B가 A를 본다.*

B  무슨 뜻입니까.

A  아니요.

C  방금은 뜻 있었는데요.

A  없어요.

*복도 안쪽에서 카트 바퀴 소리가 지나간다. 세 사람은 조금 몸을 비킨다. C의 컵이 흔들리고 빛이 선반 위를 빠르게 쓸고 지나간다. 여러 이름표가 순식간에 보였다 사라진다.*

B  아, 잠깐.

C  제가 일부러 한 거 아니에요.

B  컵 내려놓으세요.

C  내려놓으면 빛이.

B  컵은 통행에 방해되지 않지만, 지금은.

C  지금은요.

B  지금은 반사에 관여하고 있습니다.

C  컵이요.

B  네.

C  아까는 괜찮다면서요.

B  상황이 바뀌었습니다.

A  빛이 움직여서요.

B  상황이요.

A  네.

*C가 컵을 조심스럽게 내려놓는다. 빛이 사라진다. 선반은 다시 흐려진다.*

C  이름도 안 보이고요.

A  네.

C  잎도 안 보이네요.

A  네.

*사이. B가 기록지에 `개인정보 노출 우려`라고 쓰려 한다. `개인`까지 쓰고 멈춘다.*

B  이 화분들은 병동 물품이 아닐 수 있습니다.

C  아까는 병동 화분일 수도 있다면서요.

B  그래서 확인이 필요합니다.

A  확인하면 이름을 봐야 해요?

B  담당자에게 확인합니다.

C  담당자는 이름을 봐도 돼요?

B  업무상 필요한 경우에는요.

C  빛은 업무가 없어서요.

B  보호자분.

C  네.

*A가 천가방에서 작은 종이 조각을 꺼낸다. 오래된 처방전 뒷면 같은 흰 종이다. A는 이름표 앞에 종이를 세워 가리려 한다.*

B  지금 뭐 하시는 겁니까.

A  가리려고요.

B  붙이지 마세요.

A  안 붙여요.

B  세우는 것도 설치입니다.

A  제가 들고 있을게요.

B  들고 계시면.

C  통행 방해.

B  네.

*A는 종이를 들고 선다. 종이가 빛을 받아 하얗게 밝아진다. 그 빛이 다시 화분 잎 쪽으로 약하게 퍼진다.*

C  종이도 반사돼요.

A  네.

B  종이는 거울이 아닙니다.

C  그래도요.

A  조금은요.

B  조금은 다 됩니까?

A  아니요.

*빛은 약하다. 이름표 글자는 가려졌지만, 잎에는 거의 닿지 않는다.*

C  너무 약하네요.

A  네.

C  이름 가리면 잎이 안 보이고.

B  이름을 가리는 게 우선입니다.

A  잎은요.

B  잎은 개인정보가 아닙니다.

C  그래서 덜 중요해요?

B  그런 뜻이 아닙니다.

A  덜 급해요?

B  그렇게도 아닙니다.

*사이. 복도 안쪽 병실에서 아주 작은 기침 소리인지 기계음인지 모를 소리가 난다. A가 그쪽을 본다. C도 본다. B는 이름표를 본다.*

B  저 화분은 어느 병실에서 온 겁니까.

A  몰라요.

B  그럼 왜 그 화분에.

A  제일 끝에 있어서요.

C  끝이면요?

A  제일 안 닿아요.

C  아.

B  빛이요.

A  네.

B  다른 화분도 안 닿습니다.

A  네.

B  그런데 왜 제일 끝부터.

A  제일 오래 안 닿은 것 같아서요.

C  어떻게 알아요?

A  몰라요.

C  또 몰라요.

A  네.

*B가 기록지에 `추정`이라고 쓰려다가 멈춘다.*

B  추정으로는 관리가 어렵습니다.

A  네.

B  이름이 없으면 인계도 어렵고요.

C  이름이 있으면요?

B  담당자를 찾을 수 있습니다.

C  담당자가 없어서 여기 있는 거 아니에요?

*B가 대답하지 못한다.*

A  이름이 지워진 것도 담당자가 있나요.

B  기록상으로는 있을 수 있습니다.

C  기록상으로는.

B  네.

A  빛이 안 닿은 기록은요.

B  없습니다.

A  네.

*사이. A는 종이를 내리고, 거울을 조금 돌린다. 이번에는 이름표를 비켜 잎 뒷면에 약한 빛이 닿는다. 아주 짧다.*

C  닿았어요.

B  어디에요.

C  잎 뒤요.

B  이름표는요.

C  안 보였어요.

B  확실합니까.

C  저한테요?

B  네.

C  제가 봤는데요.

B  그러니까요.

*C는 잠깐 말문이 막힌다.*

A  제가 봤어요.

B  A님도 보셨고요.

A  네.

B  그럼 노출 가능성은 있습니다.

C  아무것도 안 봐야 안전하네요.

B  병동에서는 그게 제일 안전할 때가 있습니다.

*그 말이 나오자 잠깐 정적. 복도 안쪽에서 병실 문이 아주 천천히 열린다 닫힌다. 커튼 아래 손은 보이지 않는다.*

A  아무것도 안 보면.

B  네.

A  어떻게 알아요.

B  뭘요.

A  닿았는지요.

*B는 답하지 않는다. C가 빈 이름표를 다시 본다.*

C  저 빈 거는 가릴 필요 없어요?

B  빈 것도 이전 흔적이 있을 수 있습니다.

C  그럼 다 가려야 되네요.

B  원칙적으로는요.

A  다 가리면.

C  안 닿고요.

*사이. C가 자기 컵을 다시 든다. 이번에는 컵을 빛 아래 두지 않고, 빈 이름표 앞에 살짝 세운다. 이름표가 가려진다. 동시에 컵 가장자리에 반사된 약한 빛이 잎 끝에 닿는다.*

C  이건요.

B  컵입니다.

C  네.

B  세우시면.

C  들고 있어요.

B  오래 들고 계실 겁니까.

C  조금만요.

A  십오 분은 아니에요.

*C가 A를 본다. 아주 짧게 웃을 듯하지만 웃지 않는다.*

B  팔 아프십니다.

C  네.

B  내려놓으세요.

C  아직요.

*빛이 잎 끝에 닿는다. 이름표는 컵에 가려져 보이지 않는다. A는 움직이지 않는다. B는 기록지 위에서 펜을 멈춘다.*

A  지금.

C  알아요.

B  보입니다.

A  이름이요?

B  아니요.

*사이.*

B  빛이요.

*세 사람은 화분을 본다. C의 팔이 조금 떨린다. A가 거울 손잡이를 아주 조심스럽게 잡아 C의 떨림을 따라간다. B는 기록지의 `개인` 두 글자를 손가락으로 가린다.*

*암전하지 않는다. 이름표는 컵 뒤에 있고, 빛은 잎 끝에 있다.*
