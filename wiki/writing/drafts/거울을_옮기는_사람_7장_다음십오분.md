# 거울을 옮기는 사람 — 7장 다음 십오 분

## 이어지는 상태

6장 마지막. 정리 시간인데 세 사람은 그대로 서 있다. 거울은 A의 천가방 안에 들어 있고, 빛은 없다. B는 조금 서 있어도 된다고 했다. C는 빈 종이컵을 버리지 않고 손에 들고 있다.

## 7장 — 다음 십오 분

*조용하다. 정리 안내음도 더 이상 울리지 않는다. 창밖 빛은 거의 사라진 것처럼 보인다. 하지만 완전히 없어진 것은 아니다. 맞은편 건물 유리창 어딘가가 아주 늦게, 작게 반짝인다.*

*A는 천가방을 들고 있다. B는 접은 기록지를 들고 있다. C는 빈 종이컵을 들고 있다. 셋은 모두 뭔가를 들고 있지만, 아무것도 하지 않는다.*

*A의 휴대폰에서 아주 작은 알림음이 난다.*

*셋 다 움직이지 않는다.*

C  왔네요.

A  네.

B  십오 분입니까.

A  네.

*사이. A는 가방을 열지 않는다.*

C  안 하세요?

A  정리 시간이요.

B  정리 시간은.

*B가 시계를 본다. 정리 시간은 지났다.*

B  끝났습니다.

C  끝났대요.

A  네.

B  그렇다고 다시 시작하셔도 된다는 뜻은 아닙니다.

A  네.

C  그럼 무슨 뜻이에요?

B  정리 시간이 끝났다는 뜻입니다.

C  그럼 지금은 정리 때문에 안 되는 건 아니고요.

B  그렇죠.

A  방해 때문에요.

B  네.

C  방해가 끝난 건 아니고요.

B  네.

*사이. 창밖의 작은 반짝임이 조금 움직인다. 아무도 아직 거울을 꺼내지 않는다.*

A  지금은 늦었을 거예요.

C  그래도 알림은 왔잖아요.

A  알림은 예전 시간에 맞춰둔 거라서요.

B  해가 그 시간에 맞춰 움직이지는 않습니다.

A  네.

C  병동도 그 시간에 안 맞고요.

B  네.

C  그럼 알림은 혼자 맞네요.

A  네.

*복도 안쪽에서 아주 작은 소리. 이번에는 기계음이 아니라, 손가락이 침대 난간을 건드리는 듯한 소리일 수도 있다. 셋은 반응하지 않는다. 반응하지 않으려고 한다.*

B  저 소리는.

C  네.

B  제가 확인하겠습니다.

*A가 B를 본다. C도 본다.*

B  병실 쪽은 제가.

A  네.

*B가 한 걸음 복도 쪽으로 간다. 그러나 병실 안으로 들어가지는 않는다. 커튼 아래를 보지 않으려고, 문 옆만 본다.*

B  괜찮습니다.

C  뭘요.

B  문은요.

C  문은.

B  네.

*B가 돌아온다. 아무도 손을 봤는지 묻지 않는다.*

A  문은 괜찮고요.

B  네.

C  손은.

*C가 말하다 멈춘다.*

B  환자분은 확인이 필요하면 호출하시면 됩니다.

A  누가요.

B  병실 보호자분이요.

C  여기 보호자는요.

B  여기.

*B가 A를 본다. A가 어느 병실 보호자인지 아직 모른다는 사실이 다시 돌아온다.*

A  저는 지금은.

B  네.

A  여기요.

B  네.

*이번에는 B가 적지 않는다.*

C  안 적어요?

B  네.

C  왜요.

B  항목이.

*B가 말을 멈춘다.*

B  아직 없습니다.

A  아직.

B  네.

*긴 사이. A가 천가방을 아주 조금 연다. 거울끼리 부딪히는 작은 소리. B는 막지 않는다. C는 컵을 든 손을 조금 들어 올렸다가 내린다.*

B  꺼내시면.

A  네.

B  다시 방해입니다.

A  네.

B  그리고.

A  네.

B  제가 막아야 합니다.

A  네.

C  막아야 하는 거랑, 막고 싶은 거랑 같아요?

B  다릅니다.

C  네.

*B가 아주 작게 숨을 내쉰다.*

B  다릅니다.

*A가 거울을 꺼내지 않는다. 대신 천가방을 바닥에 세운다. 가방의 불룩한 면이 창쪽을 향한다. 가방 안쪽 거울 하나가 우연히 빛을 받는다. 아주 약한 빛이 바닥에 생긴다.*

B  지금.

A  제가 꺼낸 건 아니에요.

B  네.

C  가방도 반사에 관여하네요.

B  네.

C  가방은 통행에 방해돼요?

B  그 위치면요.

*A가 가방을 들어올린다. 빛이 사라진다.*

A  네.

C  사라졌어요.

B  네.

A  방해도 사라졌고요.

B  네.

C  빛도요.

B  네.

*사이. B가 벽의 `통행에 방해되는 물품을 두지 마세요` 안내문을 본다. 안내문의 한쪽 귀퉁이가 살짝 떠 있다.*

B  안내문이.

C  네?

B  떨어졌네요.

*B가 안내문을 다시 붙이려 한다. 접착력이 약해 바로 떨어진다. B가 기록지를 작게 접어 안내문 뒤에 받쳐본다. 안내문이 조금 선다. 그 종이 각도 때문에 아주 약한 빛이 바닥으로 튄다.*

C  지금.

B  아.

A  닿아요?

C  바닥에요.

B  이건 안내문입니다.

C  네.

B  거울이 아닙니다.

A  그래도요.

*빛은 바닥에서 선반 아래로 간다. 화분 잎에는 닿지 않는다. 손등 쪽과도 멀다. 하지만 처음으로 B가 만든 빛이다.*

B  제가 한 건.

C  네.

B  붙이려고 한 겁니다.

A  네.

C  붙이려고 했는데 비췄어요.

B  네.

*B가 안내문을 떼려 한다. C가 컵을 든다.*

C  잠깐만요.

B  보호자분.

C  컵 아니고요.

*C는 컵을 바닥에 두지 않고, 안내문 아래쪽에 받쳐서 안내문이 떨어지지 않게 한다. 빛이 조금 더 안정된다. A는 천가방을 들고 있다. 아직 거울을 꺼내지 않았다.*

B  컵은.

C  안내문 받치는 거예요.

B  네.

C  반사도 해요.

B  네.

A  지금은 누가 방해예요.

*B가 대답하지 않는다. 셋은 바닥의 약한 빛을 본다.*

B  제가.

C  네?

B  제가 만든 상황입니다.

A  네.

C  상황상.

B  네.

*약한 빛이 선반 앞까지 간다. 화분 잎 끝에는 아직 닿지 않는다.*

A  조금만 높으면.

B  거울은 꺼내지 마세요.

A  네.

C  가방은요.

B  통로에 두시면 안 됩니다.

C  들고 있으면요.

B  방해는 아닙니다.

*A가 천가방을 들고 선다. 가방 안쪽 거울 하나가 우연히 빛을 받아 안내문-컵 빛과 만난다. 바닥의 빛이 조금 길어진다.*

C  길어졌어요.

B  가방을.

A  들고 있어요.

B  네.

A  방해는 아니고요.

B  네.

*빛이 화분 잎 끝 근처까지 간다. 닿지는 않는다. 셋은 숨을 크게 쉬지 않는다.*

C  조금만.

B  컵을 움직이면 안 됩니다.

C  움직이지 않을게요.

A  가방도요.

B  네.

*복도 안쪽에서 병실 문이 아주 조금 열린다. 손은 보이지 않는다. 소리만 있다.*

C  손은.

A  안 보여요.

B  네.

C  그래도요.

*약한 빛이 화분 잎 끝에 닿는다. 아주 정확하지 않다. 잎이 밝아진 것인지 바닥이 밝아진 것인지 애매하다.*

A  지금.

B  네.

C  닿았어요?

A  모르겠어요.

B  모르겠습니다.

C  그래도.

*셋은 더 말하지 않는다. 빛은 잎 끝 근처에 머문다.*

*A의 휴대폰 알림음이 다시 울린다. 이번에는 다음 알림인지, 이전 알림의 반복인지 모른다.*

A  또.

C  다음 십오 분이에요?

A  아니요.

B  그럼요.

A  늦은 거요.

B  계속 늦네요.

A  네.

*B가 안내문을 손으로 받치려 한다. C의 컵과 B의 손이 닿을 뻔한다. B가 멈춘다.*

B  제가 들겠습니다.

C  안내문을요?

B  네.

C  그럼 컵은요.

B  내려놓으셔도 됩니다.

C  내려놓으면.

B  제가 맞춰보겠습니다.

*B가 스스로 놀란다. A도 C도 바로 말하지 않는다.*

A  뭘요.

B  아니요.

C  방금.

B  안내문을요.

C  네.

B  안내문을 맞춰보겠습니다.

*B가 안내문을 아주 조금 든다. 빛이 흔들리다 잎 끝을 지나 선반 아래로 간다.*

A  너무 갔어요.

B  어디요.

C  조금 왼쪽.

B  왼쪽.

A  아니, 너무 갔어요.

C  잠깐만요. 지금 들어왔어요.

*짧은 정적. 이 말은 이전의 거울 대사와 같지만, 이번에는 C가 한다. B가 안내문을 멈춘다. A는 천가방을 들고 있다.*

*빛이 화분 잎 끝에 아주 약하게 닿는다. 손등에는 닿지 않는다. 그러나 병실 쪽 바닥이 아주 조금 밝아진다.*

B  지금.

A  네.

C  네.

*복도 안쪽에서 손이 보이지 않는다. 아무런 확인도 없다.*

B  이 정도면.

A  모르죠.

C  네.

B  네.

*셋은 그 상태로 잠깐 서 있다. 아무도 “됐다”고 말하지 않는다.*

*암전하지 않는다. 안내문, 컵, 천가방이 이상한 각도로 서 있고, 약한 빛이 잎 끝에 머물러 있다. 다음 십오 분이 이미 시작되어 있다.*
