# 수정된 보호자 — 4장 설명 순서

## 작업 메모

- 위치: 1막 중반. 3장 `설명 대상자` 이후, 출입증/보호자석 장면 이전.
- 기능: 설명 권한이 감정의 깊이가 아니라 호출 순서와 문서의 이름으로 배분되는 장면.
- 히라타식 기준: 은이 관계를 길게 설명하지 않고, 호출 화면·설명 동의서·의자 순서·접힌 담요가 대화를 발생시키게 한다.
- 대표 문장: `제가 먼저 알고 있어도, 먼저 들을 수는 없네요.`

---

## 4장. 설명 순서

*병동 설명 공간. 병실 문 옆 작은 테이블. 의자 세 개. 하나는 책상 가까이에 있고, 둘은 조금 뒤에 있다.*

*책상 위에는 설명 동의서, 볼펜, 작은 호출벨. 벽면 화면에는 설명 순서가 떠 있다.*

> 설명 대상자 확인  
> 1순위: 재  
> 동석 가능: 확인 전  
> 기존 보호자: 은 / 상태 확인 중

*은은 뒤쪽 의자에 앉아 있다. 무릎에는 접힌 담요. 목에는 오래 쓴 출입증. 재는 책상 가까운 의자 앞에 서 있다. 새 출입증은 아직 손에 들려 있다. 담당자는 서류를 정리한다.*

담당자. 설명 순서 안내드리겠습니다.

은. 순서요.

담당자. 네.

은. 설명은 같이 들으면 안 됩니까.

담당자. 먼저 설명 대상자 확인 후에 동석 여부를 확인합니다.

은. 먼저 듣는 사람이 있고요.

담당자. 네.

은. 나중에 들을 수 있는 사람이 있고요.

담당자. 동석 가능 여부에 따라 다릅니다.

*재는 가까운 의자를 본다. 앉지 않는다.*

재. 제가 먼저 앉아야 하나요?

담당자. 네. 설명 대상자석입니다.

재. 대상자석.

담당자. 네.

*은은 자기 의자를 본다. 뒤쪽 의자에는 아무 표시가 없다.*

은. 제 의자는요.

담당자. 대기석입니다.

은. 방금까지 보호자석이었는데요.

담당자. 보호자 정보가 수정되어서요.

은. 의자도 같이 수정됐네요.

*짧은 사이.*

담당자. 재님, 여기 앉아 주세요.

*재가 앉으려다 은을 본다.*

재. 은님도 같이 들으셔야 하지 않나요.

담당자. 동석 신청을 하시면 됩니다.

은. 신청.

담당자. 네.

은. 제가 아는 게 있어서가 아니라요?

담당자. 설명 대상자 권한과 정보 제공은 구분됩니다.

은. 저는 제공하는 쪽이에요?

담당자. 현재는 그렇게 볼 수 있습니다.

은. 제가 먼저 알고 있어도, 먼저 들을 수는 없네요.

*담당자는 바로 대답하지 않고 서류를 넘긴다.*

담당자. 재님, 환자분 현재 상태 설명드리겠습니다.

재. 네.

*재가 앉는다. 은은 담요 끝을 손가락으로 누른다.*

담당자. 동석은 원하십니까?

재. 네. 같이—

담당자. 설명 대상자 동의로 기록하겠습니다.

*화면.*

> 동석 가능: 재 동의  
> 동석자: 은 / 관계 확인 전

은. 관계 확인 전이면 들어가도 되는 거예요?

담당자. 동석은 가능합니다.

은. 설명은요.

담당자. 설명은 보호자분께 드립니다.

은. 어느 보호자분요.

담당자. 재님입니다.

*재는 새 출입증을 손바닥 안으로 넣는다.*

재. 제가 잘 모르는 게 있으면요.

담당자. 질문하시면 됩니다.

재. 은님이 더 잘 알면요.

담당자. 은님께 확인하실 수 있습니다.

은. 제 입으로 들어갔다가, 재님 질문으로 나와야 하는 거네요.

담당자. 설명 절차상 그렇습니다.

*은은 고개를 끄덕인다. 아주 작게.*

담당자. 들어가겠습니다.

*담당자가 설명실 문을 연다. 재가 먼저 일어난다. 은도 담요를 들고 일어난다.*

담당자. 담요는 두고 들어가셔도 됩니다.

은. 춥습니다.

담당자. 설명실은 금방 끝납니다.

은. 금방이면 들고 가면 안 됩니까.

담당자. 공간이 좁아서요.

*은은 담요를 의자 위에 둔다. 담요는 은이 앉아 있던 자리 모양으로 접혀 있다.*

*화면.*

> 설명 대상자 입실: 재  
> 동석자 입실: 은

*담당자가 재를 먼저 문 안쪽으로 안내한다. 은은 한 박자 늦게 따라간다.*

*문 안쪽. 관객에게는 설명이 낮게, 일부만 들린다.*

담당자 목소리. 현재 수치는... 오늘 밤... 결정은...

재 목소리. 네. 그건...

*짧은 침묵.*

재 목소리. 은님이 아실 것 같은데요.

*은의 목소리는 바로 들리지 않는다. 대신 병실 기계음이 조금 커진다.*

담당자 목소리. 질문은 설명 대상자께서 해주시면 됩니다.

*조용하다.*

은 목소리. 물은 찬 거 못 마십니다.

*다시 조용하다.*

담당자 목소리. 네. 참고하겠습니다.

*벽면 화면은 바깥에 남아 있다.*

> 설명 진행 중  
> 대상자: 재  
> 동석자: 은

*은의 담요만 대기석에 남아 있다.*

*장면 끝.*
