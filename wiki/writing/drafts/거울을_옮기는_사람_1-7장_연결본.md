# 거울을 옮기는 사람 — 1~7장 연결본

## 연결본 메모

이 문서는 개별 장면 초안 1~7장을 한 리딩 흐름으로 붙인 연결본이다. 각 장의 세부 개작은 원본 장면 파일에서 계속 관리하고, 이 파일은 전체 호흡·반복·정보 이동을 확인하기 위한 판본으로 둔다.

## 인물

- **A**: 작은 손거울과 접이식 거울 몇 개를 들고 다니는 사람. 환자 보호자인지 식물 담당자인지 처음엔 분명하지 않다.
- **B**: 병동 직원. 통행, 안전, 민원, 기록을 신경 쓴다.
- **C**: 다른 보호자. 휴게실 의자에서 오래 대기 중이다. 눈부심과 통행 불편을 먼저 느낀다.
- **D**: 병실 안 사람. 보이지 않는다. 커튼 아래 손만 잠깐 보일 수 있다.

## 장소

북향 병원 완화병동 복도 끝 휴게실. 창문이 있지만 직접 햇빛은 들지 않는다. 맞은편 건물 유리창에서 반사된 빛이 아주 짧게 들어오는 시간대다. 한쪽 선반에는 작은 화분들이 있고, 일부에는 병실 번호나 이름이 적힌 테이프가 붙어 있다. 창틀 아래에는 오래 붙였다 뗀 테이프 자국이 여러 개 있다. 벽에는 `통행에 방해되는 물품을 두지 마세요` 안내문.

## 1장 — 처음 각도

*휴게실은 밝지 않다. 창문 쪽에 좁고 흐린 빛이 잠깐 들어와 있다. 화분 선반은 그 빛에서 조금 비켜나 있다.*

*C는 의자에 앉아 종이컵을 두 손으로 감싸고 있다. 종이컵은 비어 있다. B는 창가 쪽 바닥을 밀대로 한 번 민다. A가 작은 천가방을 들고 들어온다. 가방 안에서 거울끼리 부딪히는 아주 작은 소리가 난다.*

B  보호자분.

*A는 듣지 못한 듯 창가를 본다.*

B  보호자분.

A  네.

B  어느 병실이세요?

A  잠깐만요.

*A가 창틀에 손을 대고 빛이 들어오는 방향을 확인한다. 손등에 빛이 잠깐 닿는다. A가 손등을 조금 움직인다.*

B  면회 시간이세요?

A  아니요.

B  대기시면 안쪽 의자 이용하시면 됩니다.

A  네.

*A는 앉지 않는다. 천가방에서 작은 손거울 하나를 꺼낸다.*

C  저기요.

A  네.

C  여기서 화장하시면.

A  아, 아니에요.

C  아니면요.

A  잠깐만요.

*A가 손거울을 창틀에 기대 세운다. 빛이 벽 쪽으로 튄다. C가 눈을 찡그린다.*

C  아.

A  죄송합니다.

*A가 거울 각도를 아주 조금 바꾼다. 빛이 안내문 아래로 내려간다.*

B  여기 물품 두시면 안 됩니다.

A  물품은 아니고요.

B  거울도 물품입니다.

A  조금만 있으면 지나가요.

B  누가요?

A  빛이요.

*C가 A를 본다. B도 본다.*

C  빛이요?

A  네.

*사이. A는 두 번째 접이식 거울을 꺼낸다. 접이식 거울을 펼치는 소리가 작게 난다.*

B  거울 여러 개는 더 안 됩니다.

A  하나가 안 닿아서요.

B  어디에요?

*A는 대답하지 않고 화분 선반 쪽을 본다. 선반의 맨 끝 화분은 잎이 축 늘어져 있다. 이름표에는 병실 번호가 반쯤 지워져 있다.*

C  저 화분요?

A  네.

C  병원에서 키우는 거예요?

B  보호자분들이 두고 가시는 경우가 있습니다.

C  두고 가요?

B  퇴원하시거나.

*B가 말을 멈춘다. A가 세 번째 거울을 꺼내려다 멈춘다.*

A  이건 안 꺼낼게요.

B  네.

*A는 이미 꺼낸 두 개로 각도를 맞춘다. 빛이 선반 아래 바닥에 닿는다. 화분에는 닿지 않는다.*

A  조금만.

C  뭐가요.

A  위로요.

B  손 조심하세요. 창틀 오래돼서.

*A가 손을 뗀다. 거울이 쓰러질 듯 흔들린다. A가 급히 잡는다. 빛이 C의 얼굴에 튄다.*

C  아, 눈.

A  죄송합니다.

C  아까부터 죄송만 하시는데요.

A  네.

C  눈은 제 눈인데.

A  네.

*사이. A는 거울을 완전히 치우지 않고, 각도를 더 낮춘다. 빛이 C의 무릎을 지나 종이컵에 닿는다. 종이컵 안쪽이 잠깐 밝아진다.*

C  컵 안에 들어갔네요.

A  아.

C  이건 되는 거예요?

A  아니요. 거긴 아니고요.

*C가 종이컵을 조금 옆으로 옮긴다. 빛이 바닥으로 떨어진다.*

B  보호자분, 성함 확인 좀 할게요.

A  제 성함이요?

B  네. 병동 물품 설치하시면 기록이 필요해서요.

A  설치는 아니고요.

B  기대어 놓으신 것도 설치로 볼 수 있습니다.

A  그럼 제가 들고 있을게요.

B  들고 계시면 통행 방해입니다.

A  그럼.

*A가 거울을 손에 든 채 가만히 선다. 빛이 흔들린다. 화분 잎에 닿았다가 금방 벗어난다.*

C  지금 닿았어요.

A  네?

C  방금. 잎 끝에.

*A가 멈춘다. 빛이 다시 잎에서 벗어난다.*

A  어디요.

C  지금은 아니고요.

A  아.

B  두 분, 창가 쪽 통로 비워주세요.

*C가 자기 의자를 조금 뒤로 민다. 의자 다리가 바닥에 끌리는 소리. A는 그 소리에 놀라 거울을 더 세게 잡는다.*

C  됐어요?

B  통로는요.

C  아니요. 빛.

*A가 다시 각도를 맞춘다. 빛이 화분 잎 끝에 아주 잠깐 닿는다.*

A  지금.

*짧은 사이. 세 사람 모두 화분을 본다.*

B  ...지금 닿긴 했네요.

C  이 정도로 돼요?

A  안 되는 것보다요.

C  식물이 알아요?

A  모르죠.

C  그런데 왜.

*A의 휴대폰에서 작고 짧은 알림음이 난다. A가 바로 화면을 끈다.*

B  병실에서 연락 오셨어요?

A  아니요.

C  뭐예요?

A  시간요.

B  약 시간이세요?

A  아니요.

*사이. A는 거울을 한 손으로 들고, 다른 손으로 창틀의 오래된 테이프 자국을 만진다.*

B  거기 손대시면 먼지 묻습니다.

A  원래 여기 붙였던 자리가 있어서요.

B  누가요?

A  모르겠어요.

C  원래 하던 사람이 있었어요?

A  있었겠죠.

B  병동에서 허가한 건 아닐 겁니다.

A  네.

*빛이 다시 벗어난다. A가 한 걸음 옆으로 간다. 그 때문에 C가 더 안쪽으로 의자를 끌어야 한다.*

C  저 더 들어가요?

A  죄송합니다.

C  아니, 물어보는 거예요.

A  조금만요.

C  조금이 얼마나인데요.

A  십오 분쯤요.

C  십오 분이요?

B  십오 분 동안 이러시는 건 곤란합니다.

A  아니요. 십오 분마다요.

*B와 C가 동시에 A를 본다.*

C  십오 분마다.

B  뭘요.

A  옮겨야 해서요.

C  해가요?

A  네.

B  해는 병동 규정에는 없어서요.

*사이. A가 웃지 않는다. C도 웃지 않는다. B는 자기가 한 말을 잠깐 듣는다.*

*복도 안쪽에서 아주 작은 기계음. 병실 문이 열렸다 닫힌다. 커튼 아래로 손 하나가 잠깐 보인다 사라진다. 아직 아무도 그 손을 보지 못한다.*

B  일단 성함만 적을게요.

A  네.

B  어느 병실 보호자세요?

*A는 대답하려다 화분 쪽을 본다. 빛이 다시 흔들린다.*

A  지금은요.

B  네?

A  지금은 여기요.

*B가 적지 못한다. C는 A의 손거울을 본다. 빛은 화분 잎 끝 바로 아래에 있다.*

*암전하지 않는다. A는 계속 아주 조금씩 각도를 바꾼다.*

---

## 이어지는 상태

1장 마지막. A는 어느 병실 보호자인지 답하지 못하고 `지금은 여기요`라고 했다. 빛은 화분 잎 끝 바로 아래에 있다. B는 성함을 적지 못했고, C는 손거울을 보고 있다.

## 2장 — 십오 분

*빛은 화분 잎 끝 바로 아래에 있다. 닿을 듯하다가 닿지 않는다.*

*B는 작은 기록지를 든 채 서 있다. 기록지 윗줄에는 `물품 설치 / 통행 방해`라고 인쇄되어 있다. B는 펜을 들었지만 쓰지 않는다. C는 의자를 조금 안쪽으로 밀어 넣은 채 앉지도 서지도 못한다. A는 손거울을 들고 있다.*

B  그러면.

A  네.

B  성함은요.

A  아.

*빛이 조금 움직인다. A가 말을 멈추고 거울을 아주 조금 위로 든다.*

B  성함.

A  네.

C  지금 또 움직였어요.

A  네?

C  거울이요.

A  아.

B  손 떼시면 위험합니다.

A  손을 떼면 안 닿아서요.

B  손을 대고 계셔도 위험합니다.

A  네.

*사이. A는 손을 떼지 않는다. 빛이 잎 끝에 아주 조금 닿는다.*

C  닿았어요.

*A가 숨을 아주 작게 멈춘다. 빛이 다시 벗어난다.*

C  빠졌어요.

A  네.

B  이걸 계속 봐야 하는 거예요?

A  아니요.

B  그럼요.

A  지나갈 때만요.

C  뭐가요.

A  빛이요.

C  빛이 자꾸 지나가네요.

A  네.

*B가 기록지에 뭔가 쓰려 한다. 쓰지 못한다.*

B  보호자분이 직접 관리하시는 화분입니까?

A  아니요.

B  그럼 병동 화분입니까?

A  아마요.

B  아마요.

A  처음부터 있던 건 아니라서요.

C  처음이 언제인데요.

A  제가 왔을 때요.

C  언제 오셨는데요.

*A가 대답하려는 순간, A의 휴대폰에서 작고 짧은 알림음이 난다. A는 바로 거울을 내린다. 빛이 사라진다.*

C  어.

B  알림 끄셔야 합니다. 병동에서는.

A  네.

*A는 알림을 끄지 않고, 화면을 보고 시간을 확인한다. 거울을 창틀에서 떼어 든다.*

B  지금 치우시는 거죠?

A  옮기는 거예요.

C  방금 했잖아요.

A  십오 분 돼서요.

C  진짜 십오 분마다 해요?

A  네.

B  아까는 십오 분 동안이라고 하셨고요.

A  제가 말을 잘못했어요.

B  지금은 십오 분마다.

A  네.

C  누가 시킨 거예요?

A  아니요.

C  병원에서요?

A  아니요.

B  병원에서 시킨 건 아닙니다.

C  그럼 누가.

*A가 두 번째 거울을 접는다. 접이식 거울이 딱, 하고 닫힌다. 그 소리에 복도 안쪽에서 작은 기계음이 겹친다.*

A  해가요.

C  해가 시켰다고요?

A  움직여서요.

B  해는 병동 시설물이 아니라서요.

*B가 말하고 나서 잠깐 멈춘다. C는 웃으려다 웃지 않는다.*

C  시설물이 아니면 안 움직여도 돼요?

B  그런 뜻은 아니고요.

A  조금만 옆으로 가면 돼요.

B  누가요.

A  제가요.

*A가 창문 옆으로 한 걸음 이동한다. C는 의자를 다시 당겨야 한다.*

C  또 들어가요?

A  죄송합니다.

C  아니요. 이번엔 제가 물어본 거예요.

A  네.

*C가 의자를 조금 안쪽으로 민다. 빈 종이컵이 흔들리며 빛을 잠깐 받는다.*

C  컵은 둬도 돼요?

B  컵은.

*B가 안내문을 본다. `통행에 방해되는 물품을 두지 마세요`.*

B  컵은 통행에 방해되지는 않습니다.

C  거울은요.

B  거울은 반사 때문에.

A  컵도 반사돼요.

*사이. C가 자기 종이컵 안쪽을 본다.*

C  얘는 빛이 들어와도 비어 있는데요.

A  네.

C  화분은 뭐가 있어요?

A  잎이요.

C  잎은 알아요?

A  모르죠.

C  아까도 그랬잖아요.

A  네.

C  모르는데 왜 그렇게 정확해야 해요?

*A가 거울을 다시 세운다. 빛이 안내문 위로 튄다. `통행`이라는 글자만 잠깐 밝아진다.*

B  아, 글자가.

A  죄송합니다.

B  글자는 괜찮습니다.

C  사람 눈은요.

B  사람 눈은 안 됩니다.

A  네.

*빛이 안내문에서 내려와 바닥을 지나 화분 선반 쪽으로 간다. 그러나 선반 바로 앞에서 멈춘다. A가 고개를 아주 조금 낮춘다.*

B  숙이지 마세요. 넘어지십니다.

A  조금만요.

B  조금만이 계속.

C  십오 분씩요.

*짧은 사이. B가 기록지에 `반복`이라고 쓰려다가 멈춘다. `반`까지만 적힌다.*

A  제가 치울게요.

B  네.

*A는 치우지 않는다. 거울을 손에 든 채, 창틀의 테이프 자국 중 하나에 맞춰본다.*

C  거기 아니에요?

A  네?

C  아까 만졌던 자리요.
