# 좋은 직원입니다 — 리딩용 압축/수정 지시표

## 리딩 목표

이번 리딩은 사건 이해보다 **절차 피로가 어느 지점에서 연극적 리듬이 되고, 어느 지점에서 단순 반복으로 느슨해지는지** 확인하기 위한 리딩이다.

확인할 핵심 질문은 세 개다.

1. 윤이 끝까지 `선언`하지 않고도 압력이 관객에게 전달되는가.
2. 민의 실용적 조언이 설명꾼이 아니라 중간 증언자로 작동하는가.
3. 서가 악역이 아니라 절차를 수행하는 노동자로 남는가.

## 1차 압축 원칙

| 항목 | 처리 |
|---|---|
| 반복되는 `네/아니요/상황에 따라` 문답 | 각 장면에서 한 번만 대표로 남김 |
| 제도 설명 대사 | 화면 문구, 저장음, 체크박스, 상태값으로 이동 |
| 민의 해설 | `대기로 해`, `회의가 제일 덜 열려`, `노란색은 오래 남아`처럼 기능 있는 문장만 보존 |
| 서의 방어적 설명 | 짧게 줄이고, 클릭/저장/파일 넘김으로 대체 |
| 윤의 질문 | 주제 대사보다 절차를 확인하는 질문만 남김 |
| 엔딩 | 윤의 선택이 아니라 기본값 자동 저장으로 닫음 |

## 장면별 리딩 큐

### 1장. 상태를 선택해 주세요 / 대기로 해

**리듬:** 퇴근 직후의 짧은 정지 → 상태 선택 화면 → 민의 `대기로 해`.  
**핵심 소리:** 퇴근 단말기, 상태 확인 요청 알림, 휴대폰 진동 지연.  
**확인할 것:** `퇴근했는데요`가 너무 많이 반복되면 줄인다. 한 번은 질문, 한 번은 항의 직전의 확인 정도면 충분하다.

**리딩 후 수정 후보:**

- `퇴근 후 라운지 체류 상태만 남아서요`가 설명으로 들리면 `라운지 체류만 남아서요`로 줄인다.
- 민의 `네트워크가 늘 위에 있어`는 살아남기 좋은 문장. 단, 두 번 반복하지 않는다.

### 2장. 여가 이용 교육 1차시

**리듬:** 교육 시작 실패 → 대기 사유 선택 → 여가/방임 슬라이드 → 계획서.  
**핵심 화면:** `여가란?`, `방임이란?`, `여가 사용 계획서`.  
**확인할 것:** 교육 풍자가 과해지면 위험하다. 서는 웃긴 사람이 아니라 매뉴얼을 믿거나 믿어야 하는 사람이어야 한다.

**리딩 후 수정 후보:**

- `희망은 거의 다 돼`는 민의 세계관을 짧게 보여주므로 보존.
- `아무것도 안 함`은 첫 칸에만 둔다. 이후에는 `회복`, `개인 회복`, `비계획형 휴식`이 그 말을 덮어야 한다.

### 3장. 남은 4시간 활용 면담

**리듬:** 현황/계획 혼동 → 자기계발 문항 → 긴급 연락 가능 상태 → 팀 성과 보완.  
**핵심 문장:** `좋은 제도라서요.`  
**확인할 것:** 이 장면이 가장 설명적으로 길어질 수 있다. 문항을 모두 설명하지 말고, 윤이 답할 수 없는 구조가 보이면 다음 문항으로 넘어간다.

**리딩 후 수정 후보:**

- `남은 4시간을 회사랑 나눠요?`는 보존.
- `사전 공유`는 장면 후반 압축 장치로 좋다. 길게 논쟁하지 않고 바로 저장되는 편이 차갑다.

### 4장. 활동 없음 20분

**리듬:** 실제 몸은 움직였는데 PC 기준 활동 없음 → 물컵 소명 → 재분류.  
**핵심 오브제:** 물컵.  
**확인할 것:** 이 장면은 몸/시스템의 차이가 이미 강하다. 대사는 더 줄여도 된다.

**리딩 후 수정 후보:**

- `제가 마우스예요?` 보존.
- `말은 활동이 아니에요?` 보존.
- 기타 사유 글자 수 장난은 3단계까지만. 길어지면 코미디가 커진다.

### 5장. 근면 확인표

**리듬:** 성과 완료 → 태도 미입력 → 체크할수록 더 얽힘 → 종합 의견 생성 중.  
**핵심 화면:** `태도 확인 0/6`, `권장 항목 미선택`, `필수 확인 항목 1개 미선택`.  
**확인할 것:** 체크박스 항목이 많아 장면이 무거워질 수 있다. 리딩 후 두 항목은 삭제 가능하다.

**삭제 후보:**

- `장래의 이익을 위해 현재 불편 감수 의사 있음` 항목은 강하지만 1차 리딩에서 장면이 늘어지면 삭제 가능.
- `동료의 업무 부담을 고려하여 개인 사정 조정`과 `여가 시간의 생산적 활용 계획 제출` 중 하나만 남겨도 구조는 유지된다.

### 6장. 좋은 직원입니다

**리듬:** 종합 의견 생성 → 좋은 직원입니다 → 확인함 → 비근무 상태 선택 → 자동 기본값 저장.  
**핵심 엔딩:** `읽음 확인 대기 중` + `좋은 직원입니다`.  
**확인할 것:** 결말에서 윤이 설명하지 않아야 한다. `그럼 그냥 둘게요. 기다리게요.`까지만 말하고, 나머지는 화면이 닫는다.

**리딩 후 수정 후보:**

- 배지 두 개(새 배지/긁힌 배지)는 좋은 물건이다. 대사보다 배치가 중요하다.
- 마지막에 민의 휴대폰만 울리지 않는 설정은 보존. 민은 이미 통과한 사람/제외된 사람/요령을 아는 사람으로 남는다.

## 압축 전후 구조 차이

| 원 연결본 | 1차 압축본 |
|---|---|
| 7개 개별 초안의 전체 대사 연결 | 절차 축 중심으로 약식 통합 |
| 각 장면의 문답 반복을 상당수 보존 | 대표 문답만 남김 |
| 1~7장 표기 | 1장 안에 있던 1/2장 기능을 통합하여 6개 큰 장으로 정리 |
| 장면별 설명 다소 많음 | 화면/오브제/저장음 중심 |

## 리딩 때 표시할 컷 후보

1. 1장: 승인자/부서별 설정 대사 일부 컷.
2. 2장: 익명/사진/홍보팀 대사 축소.
3. 3장: 자기계발 증가 문항과 향후 4주 문항 중 하나만 남기는 실험.
4. 4장: 글자 수 소명 코미디 3회 이상 반복 금지.
5. 5장: 근면 확인표 항목 6개 → 4개로 축소 실험.
6. 6장: 배지 수령 문답 축소, 대신 새 배지/긁힌 배지 배치 강화.

## 배우에게 줄 질문

1. 윤은 어느 순간부터 `나가려는 사람`이 아니라 `정확히 입력하려는 사람`이 되는가.
2. 서는 언제부터 절차를 믿는 사람에서 절차에 밀리는 사람으로 보이는가.
3. 민은 요령꾼인가, 증인인가, 이미 망가진 미래인가.
4. `좋은 직원입니다`가 칭찬으로 들리는 순간이 있는가, 아니면 처음부터 판정으로만 들리는가.
5. 물컵과 배지는 실제로 장면을 바꾸는가, 아니면 상징처럼만 보이는가.
6. 마지막 자동 저장은 윤의 패배로 보이는가, 아니면 윤이 선택하지 않음으로 남긴 작은 저항으로 보이는가.

## 작가 수정 지시

- 윤에게 주제 선언을 주지 않는다.
- 서에게 제도 해설을 길게 주지 않는다.
- 민의 요령 문장은 짧을수록 세다.
- 화면 문구는 친절해야 한다. 위협적으로 쓰지 않는다.
- `좋은 직원입니다`는 크게 외치지 않는다. 작고 정확하게 떠야 한다.
- 마지막은 윤의 말보다 `기본값으로 저장되었습니다`가 닫는다.
