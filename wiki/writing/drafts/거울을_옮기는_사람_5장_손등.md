# 거울을 옮기는 사람 — 5장 손등

## 이어지는 상태

4장 마지막. A는 거울을 접었고, 빛은 사라졌다. B는 다시 하면 방해라고 했고, 안 하면 방해는 아니라고 했다. 복도 안쪽에서 작은 기계음이 들렸지만 세 사람 모두 들은 척하지 않았다. 접힌 거울만 A의 손에 있다.

## 5장 — 손등

*휴게실은 조금 더 어둡다. 창가의 빛은 여전히 밖 어딘가에 있지만, 접힌 거울 때문에 이 안으로 들어오지 않는다. 화분 선반은 흐릿하다. 이름표도 보이지 않는다.*

*A는 접힌 거울을 손에 들고 있다. C는 빈 종이컵을 손으로 감싼다. B는 접은 기록지를 들고 있다. 아무도 앉지 않는다.*

B  방해는 아닙니다.

*아까 말의 끝처럼 들린다. 아무도 바로 대답하지 않는다.*

C  네.

A  네.

*복도 안쪽에서 아주 작은 기계음. 이번에는 조금 길다. B가 먼저 눈을 움직이지만 몸은 돌리지 않는다.*

C  저 소리.

B  기계음입니다.

C  네.

B  병실마다 납니다.

A  다 같은 소리예요?

B  비슷합니다.

C  비슷하면 같은 거예요?

B  업무상으로는요.

A  듣는 사람한테는요.

*B가 A를 본다. A는 거울을 보지 않고 복도 안쪽을 본다.*

B  병실 안쪽은 확인하시면 안 됩니다.

A  확인하려는 건 아니에요.

B  보시면 확인이 됩니다.

C  아까도 봤는데요.

B  봤다고 말하지 않으시면.

C  본 게 없어져요?

B  기록하지 않을 수 있습니다.

A  기록하지 않으면 본 게 아닌가요.

B  병동에서는.

*B가 말을 멈춘다.*

C  병동에서는요.

B  문제가 되지 않을 수 있습니다.

*사이. A의 휴대폰 알림음이 난다. A는 화면을 보지 않는다.*

C  놓친 거예요?

A  네.

B  뭘 놓치셨습니까.

A  아까 빛이요.

B  빛은 다시 올 수 있습니다.

A  같은 빛은 아니에요.

C  다르죠.

B  같은 시간대면.

A  십오 분 지나면 다릅니다.

*B는 접은 기록지를 편다. 아무것도 쓰지 않는다.*

B  그럼 지금은.

A  늦었어요.

C  늦었는데 왜 들고 있어요?

*A는 접힌 거울을 본다.*

A  다음 거요.

B  다음 십오 분입니까.

A  네.

C  아직 방해예요?

B  사용하면요.

C  들고만 있으면요.

B  들고만 있으면 방해는 아닙니다.

A  들고만 있으면 안 닿고요.

*복도 안쪽 병실 문이 아주 천천히 열린다. 보이지 않는 누군가가 커튼을 조금 만지는 듯한 소리. 커튼 아래로 손 하나가 보인다. 손등은 창가 반대쪽을 향해 있다.*

*C가 먼저 본다. 이번에는 고개를 돌리지 않는다. 눈만 복도 쪽으로 간다.*

B  보호자분.

C  네.

B  보지 마세요.

C  안 봤어요.

B  지금.

C  안 봤다고 할게요.

*B가 말을 잃는다. A는 아직 손을 보지 못했다.*

A  뭐가요.

C  아니에요.

A  손이에요?

C  아니에요.

B  확인하지 마세요.

A  어디에요.

B  확인하지 마세요.

*A는 복도 안쪽을 보지 않고, 접힌 거울을 아주 천천히 편다. 접이식 거울이 작게 딱, 열린다.*

B  안 됩니다.

A  안 볼게요.

B  거울로 보셔도 안 됩니다.

A  보려는 게 아니에요.

B  반사되면 보입니다.

A  반사되면 닿기도 해요.

B  보호자분.

C  잠깐만요.

*B와 A가 C를 본다. C는 컵을 든다.*

C  제가 보면 안 되는 거죠.

B  네.

C  이름도 안 되고, 손도 안 되고.

B  네.

C  빛은요.

B  빛은.

C  빛도 손에 닿으면 본 거예요?

B  그건.

A  닿는 거예요.

*사이. A가 창가로 한 걸음 간다. C는 본능적으로 의자를 조금 치운다. B는 막으려다 통로가 비어 있음을 본다.*

B  지금 하시면 방해로.

A  네.

B  기록될 수 있습니다.

A  네.

B  그래도 하시겠다는 겁니까.

*A는 대답하지 않는다. 거울을 창틀에 아주 낮게 세운다. 빛은 바로 들어오지 않는다. A는 실망하지 않고 기다린다.*

C  안 오네요.

A  네.

B  해가 움직였으니까요.

*A가 B를 본다.*

B  아까 그렇게.

A  네.

*복도 안쪽 손은 조금 더 나와 있다. 손가락 끝이 커튼 아래 선을 넘어온다.*

C  손이.

*말이 나와버린다. B가 C를 본다. A는 거울을 움직이지 않는다.*

B  보셨네요.

C  네.

B  네.

*짧은 정적. C가 컵을 내려놓는다.*

C  봤어요.

A  어디에요.

C  저기요.

B  병실 안쪽은.

C  손은 밖으로 나왔어요.

B  커튼 안쪽입니다.

C  선을 넘었어요.

B  선이 기준은 아닙니다.

A  빛은요.

B  네?

A  빛은 선을 넘으면요.

*B는 대답하지 않는다. A가 거울을 조금 움직인다. 빛이 바닥으로 들어와 화분 선반 앞에서 멈춘다.*

C  더 오른쪽.

B  보호자분.

C  아니요. 바닥이요.

A  오른쪽.

*빛이 바닥을 지나간다. 화분 잎을 스치지 않고, 선반 아래를 지나 복도 쪽으로 길게 뻗는다. 손등과는 아직 멀다.*

C  길어요.

A  네.

B  길면 더 방해입니다.

C  지금 통로에 아무도 없어요.

B  나올 수 있습니다.

C  손은 나왔어요.

*B가 복도 쪽을 본다. 손등이 보인다. B가 본다. 이제 세 사람 모두 본다.*

B  ...

A  봤어요?

B  네.

A  기록할 거예요?

B  손을요?

A  본 거요.

B  아니요.

C  왜요.

B  기록할 항목이 없습니다.

A  빛이 안 닿은 손.

B  없습니다.

C  그럼 닿으면요.

B  그것도 없습니다.

*사이. A는 거울을 아주 조금 들어 올린다. 빛이 화분 잎을 스치고, 빈 이름표를 지나, 바닥으로 떨어진다. 손등에는 닿지 않는다.*

A  너무 낮아요.

C  컵.

*C가 컵을 든다.*

B  컵은.

C  들고 있어요.

B  방해입니다.

C  네.

*C가 컵을 거울 아래에 받친다. 빛이 흔들린다. A가 거울을 따라간다. B는 기록지를 들었다가 내린다.*

B  지금 방해입니다.

C  네.

A  네.

B  두 분 다.

C  네.

*빛이 화분 잎 끝에 닿는다. 거기서 조금 튀어 복도 바닥에 떨어진다. 손등 바로 옆이다.*

C  조금만.

A  네.

B  더 가면 병실 안쪽입니다.

A  손이 밖에 있어요.

B  기준이.

C  선이 기준은 아니라면서요.

*B가 멈춘다.*

*빛이 손등 끝에 아주 잠깐 닿는다. 정말 잠깐. 손이 움직였는지, 빛이 움직였는지 분명하지 않다.*

C  닿았어요.

A  어디요.

C  손.

B  ...

A  봤어요?

C  네.

A  확실해요?

C  아니요.

B  확실하지 않으면.

C  그래도 봤어요.

*손가락이 아주 조금 움직인다. 빛 때문인지, 우연인지 모른다.*

A  움직였어요?

C  모르겠어요.

B  확인하지 마세요.

A  네.

C  네.

*세 사람 모두 확인하지 않으려 하지만, 이미 보고 있다.*

*빛은 다시 손등에서 벗어나 바닥으로 내려간다.*

A  내려가네요.

B  네.

C  아까처럼요.

A  네.

B  지금은 치우셔야 합니다.

A  네.

*A는 거울을 접지 않는다. C도 컵을 내리지 않는다. B도 기록지를 접지 않는다.*

B  치우셔야 합니다.

A  네.

C  손은요.

B  손은.

*B는 말하지 못한다. 복도 안쪽 손은 그대로 있다. 빛은 닿지 않는다.*

A  손은 방해가 아니죠.

B  네.

C  그럼요.

B  ...

C  그럼 뭐예요.

B  환자분 손입니다.

*처음으로 B가 `환자분`이라고 말한다. A가 아주 천천히 B를 본다.*

A  네.

*사이. C의 팔이 떨린다. 빛은 바닥에서 흔들린다.*

B  컵 내려놓으세요.

C  네.

*C가 컵을 내려놓는다. 빛이 사라진다. A가 거울을 접는다. 손등은 다시 어둡다.*

*복도 안쪽에서 손이 천천히 사라진다. 문은 닫히지 않는다.*

A  봤어요.

B  네.

C  네.

A  닿았는지는.

B  모릅니다.

C  네.

A  네.

*세 사람은 아무것도 더 보지 않는다. 그러나 모두 같은 쪽으로 몸이 조금 기울어 있다.*

*암전하지 않는다. 빛은 없고, 손도 없다. 손이 있던 자리가 남아 있다.*
