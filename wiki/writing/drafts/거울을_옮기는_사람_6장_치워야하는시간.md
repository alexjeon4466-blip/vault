# 거울을 옮기는 사람 — 6장 치워야 하는 시간

## 이어지는 상태

5장 마지막. 빛은 없고 손도 없다. 손이 있던 자리만 남아 있다. A는 손등에 빛이 닿았는지 확정하지 못했고, B는 그것을 기록할 항목이 없다고 했다. C는 봤다고 말했지만 확실하다고는 하지 못했다.

## 6장 — 치워야 하는 시간

*휴게실에는 정리 시간이 가까워졌다는 낮은 안내음이 한 번 울린다. 조명은 그대로지만, 창가의 반사광은 더 낮아져 있다. 화분 선반은 흐릿하고, 병실 쪽 커튼 아래에는 아무것도 보이지 않는다.*

*B가 벽시계를 본다. A는 접힌 거울을 손에 들고 있다. C는 빈 종이컵을 들었다가 내려놓는다.*

B  이제 정리 시간입니다.

A  네.

C  정리 시간이요.

B  휴게실 정리하고, 창가 쪽 물품 확인하고, 통로 비워야 합니다.

C  통로는 비어 있는데요.

B  비워져 있어야 해서요.

A  지금 비어 있어요.

B  앞으로도요.

*사이. B가 선반 아래, 창틀, A의 손에 든 거울을 차례로 본다.*

B  거울은 넣어주세요.

A  네.

*A는 넣지 않는다.*

B  지금요.

A  네.

*A는 천가방을 연다. 거울을 넣으려다 멈춘다. 창밖을 본다.*

B  창밖 보지 마세요.

A  네.

C  창밖은 봐도 되지 않아요?

B  지금은 정리 중이라서요.

C  정리 중에는 창밖도.

B  보호자분.

C  네.

A  몇 분만요.

B  오늘은 여기까지 하셔야 합니다.

A  몇 분만요.

B  몇 분이 계속 십오 분씩 늘어나서요.

*사이. C가 종이컵을 본다. 컵 안은 비어 있다.*

C  다음 십오 분은 언제예요?

A  이제.

B  이제면 더 안 됩니다.

A  네.

B  네가 아니라요.

A  네.

C  이제면 제일 해야 되는 거 아닌가요.

B  그래서 안 됩니다.

C  왜요.

B  정리 시간이니까요.

C  정리 시간하고 빛 시간하고 겹치면요.

B  정리 시간이 우선입니다.

A  네.

C  빛은요.

B  빛은 병동 일정이 아닙니다.

A  그렇죠.

*복도 안쪽에서 카트 바퀴 소리가 난다. B가 곧장 몸을 세운다.*

B  청소 카트 지나갑니다. 창가 물품 치워주세요.

*A가 거울을 가방에 넣으려 한다. 손이 잘 들어가지 않는다. 거울이 가방 안 다른 거울과 부딪혀 작은 소리를 낸다.*

C  깨질 것 같아요.

A  네.

B  깨지면 더 위험합니다.

C  그래서 천천히 넣는 건데요.

B  천천히 하셔도 됩니다. 지금 하시면 됩니다.

*A가 거울 하나를 넣는다. 또 다른 작은 거울이 가방 밖에 남아 있다.*

B  전부요.

A  네.

*A가 두 번째 거울을 집는다. 그 순간 창밖의 낮은 빛이 거울 가장자리에 닿아 바닥에 아주 작은 반점을 만든다. 세 사람 모두 본다.*

C  지금.

B  넣어주세요.

A  네.

*A는 반점을 본다. 반점은 선반 앞 바닥에 있다. 손등 쪽과는 멀다.*

A  저건 그냥.

B  네.

A  들어온 거예요.

B  네.

C  그냥 들어온 건 괜찮아요?

B  거울을 통해 들어왔습니다.

C  손에 들고 있었는데요.

B  그러니까요.

A  제가 움직인 건 아니에요.

B  들고 계셨습니다.

A  네.

*청소 카트가 가까워진다. 바퀴 소리, 비닐봉지 스치는 소리. B가 창가 쪽 의자를 밀려 한다.*

C  제가 할게요.

*C가 의자를 조금 옮긴다. A가 있던 자리에 공간이 생긴다. 빛 반점이 의자 다리에 가려진다.*

A  아.

C  죄송해요.

A  아니요.

B  의자는 그쪽이 맞습니다.

C  맞으면 가려지네요.

B  의자 위치는 통로 기준입니다.

A  네.

*청소 카트가 지나간다. 세 사람은 모두 몸을 조금 비킨다. 카트가 지나가며 화분 선반을 살짝 흔든다. 이름표 하나가 떨어질 듯하다가 붙어 있다.*

C  저거 떨어져요.

B  만지지 마세요.

C  떨어지면요.

B  제가 확인하겠습니다.

*B가 이름표를 누르려다 멈춘다. 개인정보 때문에 잠깐 멈춘다. 결국 손가락 끝으로 테이프 가장자리만 눌러 붙인다.*

C  보셨어요?

B  아니요.

C  안 봤다고 할게요?

B  네.

*B가 C를 본다. C도 자기가 한 말을 듣는다.*

B  아닙니다.

C  네.

B  보지 않으려고 했습니다.

A  닿지 않으려고 하는 것하고 비슷하네요.

B  네?

A  아니요.

*B는 아무것도 적지 않는다.*

B  거울 넣어주세요.

A  네.

*A가 마지막 거울을 가방에 넣는다. 이제 빛 반점은 없다. 가방이 조금 불룩하다.*

C  다 들어갔어요?

A  네.

B  가방은 의자 밑으로 두시면 안 됩니다.

A  들고 있을게요.

B  들고 계시면 됩니다.

C  들고 있으면 방해는 아니고요.

B  지금은 아닙니다.

C  지금은.

B  네.

*정리 안내음이 다시 난다. 이번에는 조금 길다.*

B  휴게실 마감 전 점검하겠습니다.

C  마감이요?

B  이 구역만요.

A  병실은요.

B  병실은 별도입니다.

A  손은요.

B  환자분 손은.

*B가 말을 멈춘다. 처음으로 `환자분` 다음을 잇지 못한다.*

C  별도예요?

B  네.

C  별도면 여기서는 아무것도 못 해요?

B  병실 안쪽으로 들어가시면 안 됩니다.

A  빛은 들어갔었어요.

B  확실하지 않습니다.

A  네.

C  확실하지 않으면 없는 거예요?

B  아닙니다.

C  그럼요.

B  확인되지 않은 겁니다.

A  확인하면 안 되고요.

B  네.

*사이. 셋은 모두 병실 쪽을 보지 않으려 한다.*

B  오늘은 여기까지 하셔야 합니다.

A  네.

C  오늘은요.

B  네.

C  내일은요.

B  내일도 운영 기준은 같습니다.

A  해는요.

B  해는.

*B가 창밖을 본다. 자신이 봤다는 것을 느끼고 바로 눈을 내린다.*

B  해는 제가 정할 수 없습니다.

C  그럼 누가 정해요.

B  아무도요.

A  움직이죠.

B  네.

*긴 사이. A가 가방 끈을 잡는다. C가 빈 컵을 구겨 버리려다 멈춘다.*

C  컵 버려도 돼요?

B  네.

C  아까 반사에 관여했는데요.

B  그래도 컵은 폐기하시면 됩니다.

C  역할이 끝났네요.

B  네.

A  아직 젖지는 않았어요.

C  컵이요?

A  네.

*C가 컵을 버리지 않는다. 손에 쥔다.*

B  컵은 가져가셔도 됩니다.

C  네.

*복도 안쪽에서 기계음이 다시 난다. 이번에는 짧다. A가 아주 조금 몸을 돌린다. B는 보지 말라고 하지 않는다. C도 본 척하지 않는다.*

B  가셔야 합니다.

A  네.

A  몇 분만요.

B  아까도.

A  아니요.

B  네?

A  여기 서 있는 거요.

*B가 시계를 본다.*

B  몇 분 정도요.

A  정리될 때까지요.

C  뭐가요.

A  가방이요.

*거울이 든 천가방 안에서 작은 소리가 난다. A가 가방을 조금 고쳐 잡는다. 더 이상 빛은 없다.*

B  가방은 정리된 것 같습니다.

A  네.

*사이.*

B  그래도.

*B가 말을 멈춘다.*

C  그래도요.

B  조금 서 계셔도 됩니다.

A  네.

*정리 시간인데, 세 사람은 그대로 서 있다. 아무도 거울을 꺼내지 않는다.*

*암전하지 않는다. 거울은 가방 안에 있고, 빛은 없고, 정리 시간만 지나가고 있다.*
