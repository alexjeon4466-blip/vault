# 좋은 직원입니다 — 첫 장면

## 인물

- 윤
- 민
- 서
- 화면

## 장소

회사 다목적 라운지. 한쪽에는 커피머신과 낮은 테이블, 빈 의자 몇 개. 다른 한쪽에는 교육용 스크린. 출입구 옆에는 퇴근 단말기. 벽에는 작은 포스터가 붙어 있다.

```text
4.5일제 시범사업 참여기업
일·생활 균형과 생산성 향상을 함께 만듭니다
```

스크린은 꺼져 있는 듯하지만, 아주 약하게 대기 화면이 떠 있다.

```text
정책효과 분석용 라운지 사용 데이터 수집 중
```

## 첫 장면

*라운지. 아무도 없다.*

*퇴근 단말기에서 짧은 소리.*

```text
퇴근 처리되었습니다.
오늘 근무시간 4:00
```

*윤이 들어온다. 가방을 멘 채 잠시 멈춘다. 단말기를 한 번 본다. 포스터를 본다. 가방끈을 고쳐 멘다.*

*나가려다가 커피머신 옆 물컵을 본다. 컵을 든다. 물을 따른다. 마시지 않고 의자에 앉는다.*

*사이.*

*스크린이 켜진다.*

```text
현재 상태를 선택해 주세요.
```

*윤은 컵을 내려놓는다.*

```text
□ 업무 중
□ 업무 준비 중
□ 대기 중
□ 승인된 휴식
□ 복귀 예정
□ 무단 이석
□ 기타
```

*윤은 화면을 본다. 컵을 다시 든다. 마신다.*

*사이.*

*화면 오른쪽 위에 작은 시간이 뜬다.*

```text
상태 미선택 00:00:15
```

*윤이 일어난다. 출입구 쪽으로 간다. 단말기에 카드를 댄다.*

```text
이미 퇴근 처리되었습니다.
퇴근 후 상태를 선택해 주세요.
```

윤  
퇴근했는데요.

*화면은 변하지 않는다.*

```text
현재 상태를 선택해 주세요.
```

*윤이 주변을 본다. 아무도 없다.*

윤  
저기요.

*대답 없음.*

*윤이 화면 가까이 간다. 손가락을 올렸다가 내린다. `승인된 휴식` 근처에서 멈춘다.*

*뒤쪽 문이 열린다. 서가 파일을 들고 들어온다. 서는 윤을 보고 웃는다. 아주 실무적인 웃음.*

서  
아, 윤 님. 아직 계셨어요?

윤  
나가려고요.

서  
네. 나가셔도 돼요.

*서가 화면을 본다.*

서  
상태만 정리해 주세요.

윤  
퇴근 찍었는데요.

서  
네. 퇴근은 되셨어요.

*서가 파일을 테이블에 내려놓는다. 포스터가 조금 비뚤어져 있는 것을 바로 잡는다.*

서  
퇴근 후 라운지 체류 상태만 남아서요.

윤  
체류요?

서  
네. 그냥 기록상.

*사이.*

윤  
저 물 마셨어요.

서  
네.

윤  
그럼 뭘 누르면 돼요?

*서가 화면을 본다. 너무 자연스럽게 말한다.*

서  
그건 윤 님 상태에 따라 선택하시면 됩니다.

윤  
제 상태요.

서  
네.

*사이.*

윤  
퇴근한 상태요.

서  
그건 이미 처리됐고요.

*화면에 시간이 바뀐다.*

```text
상태 미선택 00:01:00
```

서  
급한 건 아니에요.

*서가 파일을 펼친다. 파일 표지에는 작게 적혀 있다.*

```text
4.5일제 시범사업 1차 운영 점검
라운지/교육/면담 통합 기록
```

윤  
급한 건 아닌데 시간이 세네요.

서  
네. 자동으로 세요.

윤  
왜요?

서  
체류 시간이니까요.

윤  
퇴근 후 체류.

서  
네.

윤  
그건 일하는 시간이에요?

서  
아니요.

윤  
쉬는 시간이에요?

서  
그건 선택하시면 됩니다.

*사이.*

윤  
선택해야 쉬는 거예요?

서  
아니요. 쉬시는 건 괜찮습니다.

*서가 말하면서 파일에 체크를 하나 한다.*

서  
다만 승인된 휴식인지 대기인지가 달라서요.

윤  
누가 승인해요?

서  
시스템상으로요.

윤  
시스템이 쉬어도 된다고 하면 쉬는 거예요?

서  
그렇게까지는 아니고요.

*서가 웃는다. 윤도 따라 웃을 뻔하다가 멈춘다.*

서  
안 되는 건 아니고요.

*화면을 본다.*

서  
안 되는 걸로 뜹니다.

*사이.*

*문이 열린다. 민이 들어온다. 한 손에 텀블러, 다른 손에 휴대폰. 화면을 보자마자 상황을 안다.*

민  
대기로 해.

윤  
뭘 기다리는데.

민  
그건 나중에 정하면 돼.

*민이 자기 텀블러를 커피머신 아래에 둔다. 익숙하게 버튼을 누른다.*

민  
승인된 휴식 누르면 승인자가 떠.

윤  
누구?

민  
그때그때 달라.

서  
승인자는 부서별로 설정돼 있어요.

민  
그러니까 그때그때 달라.

*커피머신 소리.*

윤  
대기는 괜찮아?

민  
대기는 열려.

윤  
뭐가.

민  
다음 칸.

*민이 화면을 손가락으로 가리킨다. 누르지는 않는다.*

민  
대기 누르면 사유가 바로 안 떠.

윤  
바로는.

민  
응.

*화면.*

```text
상태 미선택 00:02:00
```

서  
2분 넘으면 확인 알림이 한 번 갑니다.

윤  
어디로요.

서  
본인한테요.

*서가 조금 늦게 덧붙인다.*

서  
그리고 담당자한테도요.

민  
팀장님한테도 가.

서  
팀장님은 주간 리포트로 보십니다.

민  
결국 봐.

*사이.*

윤  
대기하면.

민  
안 봐.

서  
보긴 보세요.

민  
덜 봐.

*윤이 화면 앞에 선다. 손가락이 `대기 중` 위에 머문다.*

윤  
나 퇴근했는데.

민  
그러니까 대기야.

윤  
뭘 기다려.

민  
나가는 거.

*사이.*

*윤이 누르지 않는다.*

*작은 알림음.*

```text
상태 확인 요청이 발송되었습니다.
```

*윤, 민, 서가 동시에 화면을 본다.*

*서의 휴대폰이 아주 작게 진동한다. 서는 보지 않는 척한다.*

윤  
갔어요?

서  
네.

윤  
저한테요?

*윤의 휴대폰이 울리지 않는다.*

민  
담당자한테 먼저 가.

서  
동시에 가는데요.

*윤의 휴대폰이 뒤늦게 진동한다.*

*사이.*

윤  
동시에가 아니네요.

서  
네트워크 때문에요.

민  
네트워크가 늘 위에 있어.

서  
그런 뜻은 아니고요.

*민이 커피를 들고 앉는다. 윤이 아직 서 있다.*

민  
앉아.

윤  
앉으면 또 세잖아.

민  
서 있어도 세.

*윤이 앉는다. 가방은 내려놓지 않는다.*

*서가 파일 한 장을 꺼낸다.*

서  
어차피 잠깐만 계시면 돼요.

윤  
왜요.

서  
오늘 첫날이라.

윤  
뭐가요.

서  
시범사업이요.

*서가 파일을 윤 쪽으로 돌린다.*

```text
여가 이용 교육 1차시
출석 QR
```

*윤은 파일을 본다.*

윤  
저 퇴근했는데요.

서  
네. 그래서요.

*사이.*

서  
여가 이용 교육은 퇴근 후에 들어야 맞아서요.

*민이 커피를 마시다 멈춘다. 웃지는 않는다.*

윤  
퇴근 후에요.

서  
근무시간 안에 들으면 여가가 아니잖아요.

*사이.*

*스크린이 바뀐다.*

```text
잘 쉬는 사람이 오래 일합니다.
```

*윤은 화면을 본다. 민은 텀블러 뚜껑을 닫는다.*

*아주 작은 알림음.*

```text
교육 시작 전 상태를 선택해 주세요.
```

*암전하지 않는다. 화면의 빛만 조금 더 밝아진다.*
