# 거울을 옮기는 사람 — 2장 십오 분

## 이어지는 상태

1장 마지막. A는 어느 병실 보호자인지 답하지 못하고 `지금은 여기요`라고 했다. 빛은 화분 잎 끝 바로 아래에 있다. B는 성함을 적지 못했고, C는 손거울을 보고 있다.

## 2장 — 십오 분

*빛은 화분 잎 끝 바로 아래에 있다. 닿을 듯하다가 닿지 않는다.*

*B는 작은 기록지를 든 채 서 있다. 기록지 윗줄에는 `물품 설치 / 통행 방해`라고 인쇄되어 있다. B는 펜을 들었지만 쓰지 않는다. C는 의자를 조금 안쪽으로 밀어 넣은 채 앉지도 서지도 못한다. A는 손거울을 들고 있다.*

B  그러면.

A  네.

B  성함은요.

A  아.

*빛이 조금 움직인다. A가 말을 멈추고 거울을 아주 조금 위로 든다.*

B  성함.

A  네.

C  지금 또 움직였어요.

A  네?

C  거울이요.

A  아.

B  손 떼시면 위험합니다.

A  손을 떼면 안 닿아서요.

B  손을 대고 계셔도 위험합니다.

A  네.

*사이. A는 손을 떼지 않는다. 빛이 잎 끝에 아주 조금 닿는다.*

C  닿았어요.

*A가 숨을 아주 작게 멈춘다. 빛이 다시 벗어난다.*

C  빠졌어요.

A  네.

B  이걸 계속 봐야 하는 거예요?

A  아니요.

B  그럼요.

A  지나갈 때만요.

C  뭐가요.

A  빛이요.

C  빛이 자꾸 지나가네요.

A  네.

*B가 기록지에 뭔가 쓰려 한다. 쓰지 못한다.*

B  보호자분이 직접 관리하시는 화분입니까?

A  아니요.

B  그럼 병동 화분입니까?

A  아마요.

B  아마요.

A  처음부터 있던 건 아니라서요.

C  처음이 언제인데요.

A  제가 왔을 때요.

C  언제 오셨는데요.

*A가 대답하려는 순간, A의 휴대폰에서 작고 짧은 알림음이 난다. A는 바로 거울을 내린다. 빛이 사라진다.*

C  어.

B  알림 끄셔야 합니다. 병동에서는.

A  네.

*A는 알림을 끄지 않고, 화면을 보고 시간을 확인한다. 거울을 창틀에서 떼어 든다.*

B  지금 치우시는 거죠?

A  옮기는 거예요.

C  방금 했잖아요.

A  십오 분 돼서요.

C  진짜 십오 분마다 해요?

A  네.

B  아까는 십오 분 동안이라고 하셨고요.

A  제가 말을 잘못했어요.

B  지금은 십오 분마다.

A  네.

C  누가 시킨 거예요?

A  아니요.

C  병원에서요?

A  아니요.

B  병원에서 시킨 건 아닙니다.

C  그럼 누가.

*A가 두 번째 거울을 접는다. 접이식 거울이 딱, 하고 닫힌다. 그 소리에 복도 안쪽에서 작은 기계음이 겹친다.*

A  해가요.

C  해가 시켰다고요?

A  움직여서요.

B  해는 병동 시설물이 아니라서요.

*B가 말하고 나서 잠깐 멈춘다. C는 웃으려다 웃지 않는다.*

C  시설물이 아니면 안 움직여도 돼요?

B  그런 뜻은 아니고요.

A  조금만 옆으로 가면 돼요.

B  누가요.

A  제가요.

*A가 창문 옆으로 한 걸음 이동한다. C는 의자를 다시 당겨야 한다.*

C  또 들어가요?

A  죄송합니다.

C  아니요. 이번엔 제가 물어본 거예요.

A  네.

*C가 의자를 조금 안쪽으로 민다. 빈 종이컵이 흔들리며 빛을 잠깐 받는다.*

C  컵은 둬도 돼요?

B  컵은.

*B가 안내문을 본다. `통행에 방해되는 물품을 두지 마세요`.*

B  컵은 통행에 방해되지는 않습니다.

C  거울은요.

B  거울은 반사 때문에.

A  컵도 반사돼요.

*사이. C가 자기 종이컵 안쪽을 본다.*

C  얘는 빛이 들어와도 비어 있는데요.

A  네.

C  화분은 뭐가 있어요?

A  잎이요.

C  잎은 알아요?

A  모르죠.

C  아까도 그랬잖아요.

A  네.

C  모르는데 왜 그렇게 정확해야 해요?

*A가 거울을 다시 세운다. 빛이 안내문 위로 튄다. `통행`이라는 글자만 잠깐 밝아진다.*

B  아, 글자가.

A  죄송합니다.

B  글자는 괜찮습니다.

C  사람 눈은요.

B  사람 눈은 안 됩니다.

A  네.

*빛이 안내문에서 내려와 바닥을 지나 화분 선반 쪽으로 간다. 그러나 선반 바로 앞에서 멈춘다. A가 고개를 아주 조금 낮춘다.*

B  숙이지 마세요. 넘어지십니다.

A  조금만요.

B  조금만이 계속.

C  십오 분씩요.

*짧은 사이. B가 기록지에 `반복`이라고 쓰려다가 멈춘다. `반`까지만 적힌다.*

A  제가 치울게요.

B  네.

*A는 치우지 않는다. 거울을 손에 든 채, 창틀의 테이프 자국 중 하나에 맞춰본다.*

C  거기 아니에요?

A  네?

C  아까 만졌던 자리요.

A  여기요?

C  조금 왼쪽.

*A가 왼쪽으로 옮긴다. 빛이 화분 잎을 스치고 지나간다.*

C  어.

B  닿았습니까?

C  스쳤어요.

B  스친 것도 닿은 겁니까?

A  모르죠.

C  다 모르네요.

A  네.

C  그런데 계속 하시네요.

A  네.

*복도 안쪽에서 병실 문이 열린다. 휠체어 바퀴 소리. 누군가 지나가려 한다. B가 즉시 움직인다.*

B  통로 비워주세요.

*A가 거울을 몸 쪽으로 당긴다. 빛이 사라진다. C는 의자를 더 안쪽으로 끌어당긴다. 바퀴 소리가 지나간다.*

*지나가는 동안 세 사람은 말하지 않는다. 휠체어가 지나간 뒤에도 잠시 말하지 않는다.*

C  지나갔어요.

A  네.

B  이제 치우셔도 됩니다.

A  네.

*A가 다시 창틀 쪽으로 거울을 든다.*

B  제 말은.

A  네.

B  치우셔도 된다는 말이었습니다.

A  아.

C  안 치우시겠네요.

A  조금만요.

C  또 십오 분이에요?

A  아니요.

C  그럼요.

A  지금 지나가서요.

C  누가요.

A  빛이요.

*B는 기록지에 `보호자 자의적 물품`이라고 쓰려다가, `보호자`까지만 쓴다.*

B  어느 병실이라고 적을까요.

A  적어야 해요?

B  기록은 남겨야 합니다.

A  빛도요?

B  빛은 기록하지 않습니다.

A  그럼 거울만요.

B  거울은 물품이라서요.

C  빛은 물품이 아니라서요.

*B가 C를 본다. C는 종이컵을 본다.*

B  네.

*빛이 드디어 화분 잎 끝에 조금 닿는다. 이번에는 조금 오래 머문다. A는 움직이지 않는다. B도 쓰지 않는다. C는 종이컵을 내려놓는다.*

C  지금은 좀 오래 있네요.

A  네.

B  이 정도면.

*B가 말하다 멈춘다.*

A  네?

B  아닙니다.

*A의 휴대폰을 본다. 알림은 없다. 그래도 A는 시간을 확인한다.*

C  또 봐요?

A  아직은 아니에요.

C  아직.

A  네.

B  다음은 언제입니까.

A  십삼 분쯤요.

B  방금 했는데요.

A  지나가는 시간이 있어서요.

C  빛도 대기 시간이 있네요.

A  네.

*복도 안쪽 커튼 아래로 손이 아주 잠깐 보인다. 이번에는 C가 먼저 본다. 손등은 빛에서 멀다. C는 말하지 않는다.*

B  왜요?

C  아니요.

A  닿았어요?

C  아니요.

A  어디에요?

C  아니에요.

*세 사람은 화분을 본다. C만 잠깐 복도 안쪽을 본다.*

*빛은 화분 잎 끝에 있다가 천천히 아래로 내려간다.*

A  내려가네요.

B  네.

C  보이네요.

*사이.*

B  일단 여기까지만 하시죠.

A  네.

*A는 거울을 접지 않는다.*

B  여기까지요.

A  여기까지 닿았어요.

*B가 대답하지 못한다. C가 자기 컵을 조금 들어 거울 아래쪽에 받쳐본다. 빛이 흔들린다.*

C  이러면 더 올라가요?

A  조금요.

B  컵은 통행에.

*B가 말하다가 멈춘다. 컵은 통행에 방해되지 않는다.*

B  ...컵은 괜찮습니다.

*빛이 아주 조금 위로 올라간다. 정확하지 않다. 화분 잎 옆의 빈 이름표를 비춘다.*

A  거긴 아니고요.

C  그래도 비었네요.

A  네.

*세 사람은 빈 이름표를 본다.*

*암전하지 않는다. A는 다음 각도를 찾고, C는 컵을 든 채 팔을 조금 떨고, B는 기록지에 아무것도 더 쓰지 않는다.*
