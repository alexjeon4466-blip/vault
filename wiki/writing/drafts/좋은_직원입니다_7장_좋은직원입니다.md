# 좋은 직원입니다 — 7장 좋은 직원입니다

## 이어지는 지점

[[wiki/writing/drafts/좋은_직원입니다_6장_근면확인표|6장 근면 확인표]] 마지막에서 이어진다. 화면에는 `종합 의견 생성 중`이 깜빡이고 있다. 서는 `좋은 직원입니다` 배지를 파일 안에서 꺼냈지만 아직 윤에게 주지 않았다. 민은 텀블러 뚜껑을 닫은 채 앉아 있다.

```text
다음 단계: 종합 의견 확인
상태: 근면 확인 후 대기
근면 확인 후 대기 00:00:00
```

## 7장. 좋은 직원입니다

*화면의 `종합 의견 생성 중` 문구가 깜빡인다.*

```text
종합 의견 생성 중
```

*긴 사이.*

윤  
얼마나 걸려요.

서  
보통 바로 뜹니다.

민  
보통은 바로 안 떠.

서  
네트워크 상태에 따라.

민  
네트워크가 늘 위에 있어.

*윤은 가방끈을 잡고 있다. 다른 손은 컵 옆에 있다. 물자국이 조금 넓어졌다.*

윤  
지금도 대기예요?

서  
네. 근면 확인 후 대기.

윤  
뭘 기다려요.

서  
종합 의견을요.

윤  
제 의견이에요?

서  
윤 님에 대한 의견입니다.

윤  
누구 의견이에요.

*서가 화면을 본다.*

서  
시스템 종합 의견입니다.

민  
사람이 쓴 것처럼 떠.

서  
자동 문구입니다.

윤  
자동이면 의견이에요?

서  
의견 항목입니다.

*사이.*

*화면이 바뀐다.*

```text
근면 확인표 저장 완료
근면성: 검토
협조성: 양호
조직 적합도: 양호
종합 의견: 생성 완료
```

*작은 저장음.*

서  
떴습니다.

*화면이 한 줄씩 정리된다.*

```text
종합 의견
좋은 직원입니다.
```

*아무도 바로 말하지 않는다.*

*서가 배지를 손에 들고 있다. 배지에는 같은 문구가 작게 적혀 있다.*

윤  
이거 누가 쓴 거예요.

서  
자동으로 뜨는 겁니다.

윤  
그럼 누가 알아요.

서  
네?

윤  
제가 좋은 직원인지.

서  
항목 기준으로요.

민  
좋겠다.

윤  
뭐가.

민  
좋은 직원이라고 뜨잖아.

*민은 자기 텀블러를 본다. 윤을 보지 않는다.*

윤  
민도 받았다며.

민  
응.

윤  
좋았어?

*민은 잠깐 대답하지 않는다.*

민  
처음엔.

*사이.*

서  
배지는 선택 수령입니다.

윤  
선택이에요?

서  
네.

민  
안 받으면 물어봐.

서  
홍보팀에서만요.

민  
결국 물어봐.

*서가 배지를 내려놓지 못한다.*

서  
수령하셔도 되고, 안 하셔도 됩니다.

윤  
안 받으면 좋은 직원 아닌가요.

서  
아니요. 판정은 이미 완료됐습니다.

윤  
판정.

서  
아, 의견.

윤  
아까는 의견이었는데요.

서  
네. 종합 의견.

*화면.*

```text
종합 의견 확인 여부를 선택해 주세요.
□ 확인함
□ 추후 확인
```

윤  
또 선택이네요.

서  
확인만 하시면 됩니다.

윤  
확인하면 동의예요?

서  
열람입니다.

민  
나중엔 동의처럼 보여.

서  
기록상 열람입니다.

윤

서  
알림이 갑니다.

민  
계속 와.

*윤은 `확인함`에 손을 올린다. 누르지 않는다.*

윤  
좋은 직원입니다.

서  
네.

윤  
제가요.

서  
네.

윤  
그러면 이제 가도 돼요?

서  
네. 가셔도 됩니다.

*서가 아주 조금 밝게 말한다. 정말 끝났다고 믿는 사람처럼.*

윤  
지금요.

서  
네.

민  
확인 누르고.

*사이.*

*윤이 `확인함`을 누른다.*

```text
종합 의견 열람 완료
대상자: 확인함
```

*서가 배지를 윤에게 내민다. 윤은 받지 않는다. 배지는 두 사람 사이에 떠 있다.*

서  
기념품이라고 생각하시면 됩니다.

윤  
기념할 일이에요?

서  
첫날이니까요.

윤  
첫날이 계속 기념이네요.

*민이 조용히 자기 가방에서 같은 배지를 꺼낸다. 조금 긁혀 있다. 테이블 위에 놓지는 않고 손에 쥔다.*

윤  
민은 왜 갖고 있어.

민  
가끔 필요해.

윤  
어디에.

민  
말할 때.

무슨 말.

*민은 대답하지 않는다.*

*화면이 다시 바뀐다.*

```text
퇴근 후 상태를 정리해 주세요.
현재 상태: 근면 확인 후 대기
```

윤  
아직도요?

서  
아, 이건 종료 상태만.

민  
나갈 때 한 번 더.

윤  
무슨 상태로요.

서  
퇴근 완료.

*서가 클릭한다. 화면에 오류음.*

```text
퇴근 완료는 이미 처리되었습니다.
비근무 상태를 선택해 주세요.
```

*사이.*

민  
봐.

서  
잠시만요.

윤  
비근무 상태.

*화면.*

```text
□ 비근무 중 / 연결 해제
□ 비근무 중 / 긴급 응답 가능
□ 비근무 중 / 회복 활동
□ 비근무 중 / 이동 중
```

윤  
연결 해제.

서  
가능합니다.

민  
지금은 가능해.

*윤이 `비근무 중 / 연결 해제`에 손을 올린다.*

*작은 알림음. 화면 위쪽에 새 알림이 뜬다.*

```text
팀 운영 안정성을 위해 긴급 응답 가능 상태가 권장됩니다.
```

*윤의 손이 멈춘다.*

윤  
권장.

서  
권장은 권장입니다.

민  
노란색은 오래 남아.

*화면의 권장 문구는 노란색이다.*

윤  
연결 해제를 누르면요.

서  
연결 해제 사유를 입력하시면 됩니다.

윤  
또요.

서  
네.

민  
스무 자일 거야.

*윤은 손을 옮긴다. `비근무 중 / 긴급 응답 가능` 위에 멈춘다.*

21시까지로 입력되어 있습니다.

아까 제가 했죠.

네.

*윤이 누르지 않는다.*

*서의 휴대폰이 짧게 울린다. 서는 본다. 아주 작게 숨을 들이쉰다.*

서  
아.

민  
뭐 왔어요?

서  
아니요.

*서가 바로 화면을 본다.*

윤  
뭔데요.

*서가 말을 멈춘다.*

윤

*서가 대답하지 않는다.*

*화면 오른쪽 아래.*

민

*화면.*

```text
기본값: 비근무 중 / 긴급 응답 가능
```

기본값이 있네요.

*서가 배지를 내려놓는다. 윤 앞도 아니고 자기 앞도 아닌 가운데.*

서  
그건.

*답하지 못한다.*

*민이 자기 긁힌 배지를 테이블 위에 놓는다. 새 배지와 긁힌 배지가 나란히 놓인다. 윤은 둘을 본다.*

*화면.*

```text
상태 미선택 00:01:30
```

윤  
안 누르면 자동으로 되죠.

네.

자동 저장입니다.

*사이.*

*서와 민이 윤을 본다.*

기다리게요.

*아무도 말하지 않는다.*

*화면의 시간이 간다.*


윤

```text
상태 미선택 00:01:59
```

*작은 알림음.*

```text
기본값으로 저장되었습니다.
비근무 중 / 긴급 응답 가능
```

*동시에 윤의 휴대폰이 울린다. 서의 휴대폰도 울린다. 민의 휴대폰은 울리지 않는다.*

*화면 하단에 작은 문구.*

```text
읽음 확인 대기 중
```

*윤은 휴대폰을 보지 않는다. 서도 휴대폰을 보지 않는다. 민은 두 사람을 본다.*

*화면 가운데에는 여전히 이전 문구가 작게 남아 있다.*

```text
좋은 직원입니다.
```

*윤은 가방을 멘 채 서 있다. 배지는 테이블 위에 있다. 물컵 밑의 물자국이 배지 쪽으로 조금 번진다.*

*암전.*
