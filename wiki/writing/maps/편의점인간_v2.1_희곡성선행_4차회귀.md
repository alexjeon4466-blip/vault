# 편의점 인간 — v2.1 희곡성 선행 4차 회귀

> [!warning] 역사 판정 — 현재 권위 아님
> 이 문서의 `전면 보류 / 활성 0개`는 2026-07-11의 결과다. 2026-07-12 사용자가 보류를 명시적으로 해제했으며, 전체 18개를 다시 읽은 현재 선택 상태는 [[wiki/writing/decisions/편의점인간_원천18_글쓰기우선_재검토_2026-07-12|편의점 인간 원천 18 — 글쓰기 우선 재검토]]를 따른다. 기존 표와 판정은 역사 근거로 보존한다.

## 이번 시험이 묻는 것

이 문서는 『편의점 인간』에서 새로운 제도 장치를 많이 만드는 지도가 아니다. 기존 V1이 거의 모든 원천을 교육장·상담실·심사실·창구·근무표 회의로 승격한 뒤 실제 사람보다 형식과 절차를 먼저 발명했던 오류를 되풀이하지 않는지 시험한다.

이번 순서는 다음과 같다.

1. 기존 writing-note와 초고후보 지도를 정답으로 사용하지 않고 핵심 원자료를 다시 읽는다.
2. F1–F5, 예상 시간, 새 장소, 구조표를 붙이지 않는다.
3. 원자료에 이미 있는 사람·현재 행동·욕망/회피·대항력·후속 비용만 확인한다.
4. 전 후보를 `독립 씨앗 / 보류 / 병합 부품 / 제외`로 먼저 나눈다.
5. shortlist는 최대 3개이며 0개도 허용한다.
6. 사용자가 사람과 상황에 끌린다고 고르기 전에는 writing-note·구조표·초고를 만들지 않는다.

## 출처 경계

- 핵심 장면 정본은 `파트2 초반/중반/중후반/후반 풍부판` 네 파일이다.
- `파트1 풍부판`은 작가론과 작품 배경이므로 윤리·직접각색 경계에만 쓴다.
- `파트3`은 수상·수용·비판 자료이므로 창작 후보 출처가 아니라 해석 대조군으로만 쓴다.
- 여섯 핵심 파일의 SHA-256은 모두 달라 exact duplicate는 없었다.
- 원작의 게이코·시라하·편의점 중심 관계와 결말을 그대로 가져와야만 작동하는 후보는 희곡성이 강해도 `보류`한다.

## 희곡성 선행 게이트

1. 지금 무대 위에 구체적인 사람이나 몸이 있는가.
2. 그 사람은 현재 무엇을 하며 무엇을 원하거나 피하는가.
3. 타인·몸·사물·규칙·시간 가운데 무엇이 쉽게 끝내지 못하게 하는가.
4. 첫 행동 뒤 관계·비용·권한·물질 상태 중 무엇이 달라져 다음 행동을 부르는가.
5. 제목과 해석 문장을 지워도 행동이 남는가.
6. 원작 표면과 고유 일화를 제거해도 독립 상황이 남는가.

## 4차 회귀 최종 판정

v2.1은 이번 책에서 **과잉 승격을 멈추는 데 성공했다.** `20개를 채우고 상위 3개를 뽑는 방식` 대신 18개를 읽고 2개만 사용자에게 보냈다. 원작 결말과 중심 동거 플롯처럼 극적인 장면도 직접 각색 위험 때문에 자동 승격하지 않았다.

사용자 최종 반응은 `둘 다 궁금하지 않다`였다. 따라서 분석상 독립 씨앗 3개와 shortlist 2개를 포함해 『편의점 인간』 v2.1 후보는 전부 실행 큐에서 내린다.

- 희곡 글감 발굴 성과: **0개**
- 방법론 성과: **사용자 끌림 전에 과잉 제작을 중단함**
- writing-note·F-어포던스·구조표·초고 추가 생성: **0개**
- 당시 재개 조건: 사용자가 이 책의 보류를 명시적으로 해제하거나, 원자료 밖에서 전혀 다른 사람·상황의 실제 씨앗이 들어올 때만 다시 검토
- 2026-07-12 현재: 사용자가 첫 조건을 충족해 보류를 해제했고, 새 결정에서 3개가 사용자 선택 대기다.

즉 이번 결과는 `좋은 글감을 찾은 성공`이 아니라 `궁금하지 않은 후보를 유망작으로 밀지 않은 성공`이다.
