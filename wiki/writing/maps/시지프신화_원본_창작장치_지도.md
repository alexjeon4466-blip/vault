# 시지프 신화 — 원본 창작장치 지도

> 『시지프 신화』를 `바위·반복·행정 절차`로 다시 축약하지 않고 원본 강독 전체에서 사람, 목소리, 관계, 몸의 거부, 역할, 창조와 철거, 설명을 유보하는 말, 사라지는 작업의 시간을 다시 연 지도다.

## 현재 권위와 작업 경계

- **이번 작업:** 원본 강독 재독과 늦게 완료된 독립 재독 3갈래 교차검증 → 52개 장치 후보 보존 → 신규 글감 노트 37편 생성 → 사용자 선택 대기 4개 재개방.
- **사용자 선택 전 닫힘:** A/B/F, `유망★`, 자연 규모, 형식·길이, B2, 낭독, 물성 시험, 초고.
- **활성 원고와 분리:** [[wiki/writing/drafts/대기_바위_1-7장_연결본|대기 바위 1–7장 연결본]]은 이미 『소송』×『시지프 신화』의 `바위·대기·비공개 규정` 축을 사용한 별도 활성 계보다. 이번 채굴은 그 원고의 보강 재료나 자동 개작 지시가 아니다.
- **직접 각색 방지:** 카뮈·시지프·키릴로프·돈 후안·신들의 고유명과 대표 문장을 초고의 설명 대사로 옮기지 않는다. 출처의 압력만 남기고 장소·관계·행동·사물을 다시 발명한다.

## 원본 재독에서 달라진 중심

기존 Vault의 시지프 계열은 주로 다음 네 장치를 이미 깊게 사용했다.

1. 바위가 다시 떨어지는 반복과 초기화
2. 실패 뒤 산 아래로 내려오는 의식의 시간
3. 형벌의 의미를 다시 부르는 작은 자기소유
4. 카프카식 대기·규정·호명과의 충돌

이번 재독에서는 이 네 축을 `기존 보강`으로 잠그고, 다음 지층을 새로 열었다.

- 이유보다 먼저 삶을 이어 가는 **습관과 멈춘 몸**
- 답을 만들지 않고 `잘 모르겠다`를 지키는 **목소리와 관계**
- 자기 행동을 안다는 것이 타인의 비용을 지우지 못하는 **의식과 윤리의 간격**
- 하나의 몸으로 여러 삶을 살고 벗는 **배우의 시간**
- 누구도 시대 밖에 서지 못한 뒤 남는 **사적 약속과 인간관계**
- 작품이 구원이 아니며 사라질 것을 알면서 만드는 **창조·철거·실패의 노동**
- 자유를 불가역 행동으로 입증해야 한다는 **증명 강박**
- 하늘의 질서보다 지상의 물을 택하는 **비밀과 생존의 비용**

## 작가 쪽 재독 — 사용자 선택 결과

> 늦게 완료된 독립 재독 3갈래의 45개 제안을 기존 지도와 다시 대조한 뒤 10개를 추가했다. 52개 전체를 다시 읽은 네 갈래 가운데 사용자가 세 갈래를 선택해 독립 1차 장면을 썼다. `끝나지 않는 화음`만 선택 대기에 남아 있다. 형식·길이·B2는 열지 않는다.

### 1. 세 시간 뒤에 죽은 사람의 옷

- **출처 압력과 보호할 핵심:** 배우가 끝낸 한 삶은 의상에서 바로 끝나지 않고 세탁·수선·다음 배역의 몸으로 넘어간다.
- **더 따라가고 싶은 것:** 옷을 벗지 못하는 배우, 지금 세탁해야 하는 담당자, 같은 옷을 입어야 하는 대역의 서로 다른 공연 시간.
- **아직 닫히지 않은 질문:** 한 배역이 끝났다는 사실은 누가, 어떤 몸과 노동으로 완성하는가.
- **자기복제 위험:** 연극론을 말하는 메타극이나 죽음을 아름답게 연기하는 장면으로 축소하지 않는다.
- **현재 상태:** [[wiki/writing/notes/세_시간_뒤에_죽은_사람의_옷_독립쓰기탐색_2026-07-21|1차 《한쪽 소매》]] + [[wiki/writing/notes/세_시간_뒤에_죽은_사람의_옷_2차장면탐색_2026-07-23|2차 《세 센티》]] 작성 완료 / 사용자 재독 대기.

### 2. 끝나지 않는 화음

- **출처 압력과 보호할 핵심:** 해결음으로 뛰어들지 않고 불협을 여러 사람의 실제 호흡으로 함께 견디는 시간.
- **더 따라가고 싶은 것:** 누가 틀렸는지보다 서로의 숨이 모자라는 것을 들으면서도 같은 음을 다시 잡는 합창단.
- **아직 닫히지 않은 질문:** 해결되지 않은 상태를 집단이 함께 지탱하면 그것은 고집인가 성실성인가.
- **자기복제 위험:** 음악의 아름다움이나 상징적 종지로 관계 비용을 덮지 않는다.
- **현재 상태:** 사용자 선택 대기.

### 3. 나무는 아무 설명도 하지 않았습니다

- **출처 압력과 보호할 핵심:** 인간이 자기 사연의 답을 찾더라도 나무는 어떤 설명이나 화해도 제공하지 않는 비인간적 침묵.
- **더 따라가고 싶은 것:** 마지막 물을 주는 남매가 같은 나무를 가족의 신호와 아무 답도 아닌 생물로 다르게 읽는 시간.
- **아직 닫히지 않은 질문:** 대답하지 않는 존재를 사랑하거나 돌보는 일은 해석 없이도 가능한가.
- **자기복제 위험:** 자연을 현명한 치유자나 가족사의 상징으로 만들어 침묵을 다시 인간의 뜻으로 덮지 않는다.
- **현재 상태:** [[wiki/writing/notes/나무는_아무_설명도_하지_않았습니다_독립쓰기탐색_2026-07-21|《마지막 물》]] 독립 단편 보존 / 사용자 결정 / 2차 장면 닫힘.

### 4. 의식은 면죄부가 아닙니다

- **아직 닫히지 않은 질문:** 자기 행동을 정확히 안다는 사실은 타인에게 진 빚을 어디까지 바꾸는가.
