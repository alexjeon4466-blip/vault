# 백년의 고독 — 새 교리 재채굴 2차 사이클

> [!important] 두 번째 회귀 시험
> 『사람, 장소, 환대』에서 사적 관계와 F1/F2가 복권됐다면, 『백년의 고독』에서는 세대 반복·시간 도약·물질 상속이 F4/F5를 실제로 여는지 시험한다. 기존 38개 장치와 노트는 1차 지층으로 보존하며 이번 지도는 별도 V2 지층이다.

## 출처 경계

- 읽은 파일: `bookclub/석촌호수책모임/백년의 고독 정리.md`.
- 실제 강독 본문은 약 309행이고, 뒤쪽은 첨부 이미지의 base64 데이터다.
- 이 파일은 소설 전문이 아니라 작품 강독·해석·인용 정리다. 따라서 후보의 `_source_kind`는 `bookclub-source-md`로 표시한다.
- 상세 행동이 강독 MD에 없는 경우 `희곡화를 위한 창작 보강`으로 분리하며, 원작 사실처럼 쓰지 않는다.

## 1차 지층에서 확인한 편향

- 1차 지도는 원본 장치 38개를 모두 승격했다.
- 각 노트가 같은 `가족 가계도 정리실 / 기록관 / 사망자 수 정정 창구 / 요양시설 / 관리사무소 / 유품 보관소` 목록을 공유한다.
- 모든 장치를 `한 장소 10–15분`, `이름표 오류·공식 숫자 불일치·가계도 칸 부족`으로 시작하게 했다.
- 책의 고유한 장거리 시간은 `이전 세대`라는 무대 밖 정보로만 남고, 독립 시간대의 시작→끝 변화로 조직되지 않았다.
- 여성의 경제 노동, 풍요를 유지하는 집안 리듬, 한 공간을 여러 세대가 이어 쓰는 감각은 독립 후보로 승격되지 않았다.

## 이번 재독 질문

1. 서로 멀리 떨어진 두 원본 장치가 한 세대 변화로 묶이는가?
2. 같은 장소를 다른 사람이 이어 쓸 때 물건의 기능이 달라지는가?
3. 각 시간 조각이 독립된 시작→끝 변화를 갖는가?
4. 10–15분 한 장면보다 F4/F5가 더 작은 자연 규모인 후보가 있는가?
5. 담당자·창구·서류 없이도 반복과 기억이 무대 행동이 되는가?

## 1차 지층에 그대로 두는 V1 중복

- `학살은 일어나지 않았습니다 / 공식 사망자 수 / 삼천명은 어디에도 없습니다` — 강독 MD의 정치적 핵심이지만 1차 지도·트리아지·close-reading이 이미 충분하다. 이번 사이클에서 새 시간 조직을 억지로 만들지 않는다.
- `가족은 더 큰 고독을 만듭니다 / 가계도를 다시 봐야 합니다` — 넓은 가족 압력과 기록 확인은 1차에 충분하며, 독립된 새 시간 조직이 없는 한 V1 지층에 둔다.
- `누가 올 거예요`, `나무에 몸을 묶습니다`, `마지막 두 시간에는 공포가 사라졌습니다` — 새 결합 없이 제목만 바꾸면 V1 중복이다.
- `읽는 순간 집이 사라집니다 / 두 번째 기회는 없습니다` — 1차 트리아지의 유망축이며, 이번 지도는 문서 장치보다 세대·물질 상속을 우선한다.

## 2차 사이클의 잠정 판정

- 같은 재채굴 규칙이 모든 책을 F2 대화극으로 만들지는 않았다.
- 이 책의 강한 후보는 한 장면의 절차보다 `서로 다른 몸이 같은 장소와 물건을 이어 쓰는 방식`에서 살아난다.
