# 히라타 오리자식 극작 체크리스트

## 사용법

초고를 쓰기 전, 장면을 고치기 전, 또는 대사가 설명적으로 느껴질 때 이 체크리스트를 사용한다. 목적은 “좋은 대사”를 바로 찾는 것이 아니라, **대사가 발생할 조건**을 점검하는 것이다.

관련 요약 노트: [[wiki/writing/notes/히라타_오리자_연극입문_1-3장_요약과_적용|히라타 오리자 『연극 입문』 1–3장 — 요약과 적용]].

---

## 0. 한 줄 점검

> 지금 이 장면은 테마를 설명하고 있는가, 아니면 장소·문제·정보 차이·구체소재가 대화를 발생시키고 있는가?

---

## 1. 장소 체크

- [ ] 이 장면의 장소는 단순 배경이 아니라 대화가 생길 수밖에 없는 구조인가?
- [ ] 완전히 사적인 곳도, 완전히 공적인 곳도 아닌 **반공간**의 압력이 있는가?
- [ ] 이 장소에서는 말하지 않아도 될 것을 말해야 하거나, 말해야 할 것을 말할 수 없게 되는가?
- [ ] 이 장소의 규칙이 인물의 말투와 행동을 바꾸는가?
- [ ] 장소를 다른 곳으로 옮기면 장면의 대화가 무너지는가?

### 위험 신호

- 장소가 “분위기”만 만들고 대화의 조건은 만들지 않는다.
- 인물들이 어디서든 할 수 있는 이야기를 하고 있다.
- 장소의 제도/물성/동선이 대사와 무관하다.

### `상담 종료 후 들리는 말` 적용

- 상담 품질관리실은 사적 감각이 공적 기록으로 번역되는 반공간이다.
- C는 “들었다”를 말하지만, 장소는 그것을 “면담 사유 / 음성 인지 주장 / 장비 분리 확인”으로 바꾼다.

---

## 2. 배경 체크

- [ ] 인물들이 이미 알고 있는 과거/관계/규칙이 있는가?
- [ ] 그 배경을 관객에게 직접 설명하지 않고, 대화의 틈으로 드러내고 있는가?
- [ ] 인물마다 알고 있는 배경이 조금씩 다른가?
- [ ] 관객이 몰라도 되는 정보까지 설명하고 있지 않은가?
- [ ] 배경 설명을 줄여도 장면의 행동이 이해되는가?

### 위험 신호

- 인물이 서로 이미 아는 사실을 관객에게 설명한다.
- 과거사가 현재 행동을 밀어내고 독백처럼 나온다.
- “사실은…”으로 장면이 시작되거나 해결된다.

### 고치는 법

- 배경을 설명하지 말고, 그 배경 때문에 생기는 현재 행동을 만든다.
- 과거 정보는 외부자/중간 인물의 질문, 잘못된 기록, 물건의 상태로 드러낸다.

---

## 3. 문제 체크

- [ ] 장면을 끌고 가는 작은 질문이 있는가?
- [ ] 그 질문은 인물이 실제로 해결하려고 하는 절차/행동으로 연결되는가?
- [ ] 문제가 너무 거대하거나 추상적이지 않은가?
- [ ] 문제를 해결하려는 행동이 오히려 더 큰 압력을 만드는가?
- [ ] 관객이 “이제 무엇이 어떻게 처리될까”를 궁금해할 수 있는가?

### 좋은 문제의 형태

- 이 말은 어디에 기록되는가?
- 이 사람은 어느 칸에 들어가는가?
- 이 물건은 누구의 것인가?
- 이 서명은 동의인가 확인인가?
- 이 침묵은 없음인가 거부인가?
- 이 소리는 사라진 것인가, 듣지 못하게 된 것인가?

### 위험 신호

- 문제는 있는데 인물들이 아무 절차도 밟지 않는다.
- 문제를 인물이 곧장 논리로 설명한다.
- 문제 해결이 너무 빨리 정답/폭로/결론으로 간다.

---

## 4. 정보 차이 체크

- [ ] 각 인물은 무엇을 알고 무엇을 모르는가?
- [ ] 누가 말할 권한을 갖고, 누가 기록/판정/요약할 권한을 갖는가?
- [ ] 관객은 누구보다 많이 알고, 누구보다 적게 아는가?
- [ ] 같은 사건을 인물들이 서로 다른 단어로 부르는가?
- [ ] 대사는 정보 차이 때문에 발생하는가, 아니면 작가가 정보를 전달하려고 발생하는가?

### 정보 차이 표 만들기

| 인물/장치 | 알고 있는 것 | 모르는 것 / 인정하지 않는 것 | 가진 권한 |
|---|---|---|---|
| A |  |  |  |
| B |  |  |  |
| C |  |  |  |
| 시스템/공간 |  |  |  |
| 부재한 인물/목소리 |  |  |  |

### 위험 신호

- 인물들이 모두 같은 정보를 같은 방식으로 알고 있다.
- 대화가 정보 교환이 아니라 주제 토론이 된다.
- 한 인물이 관객을 대신해 작품의 의미를 정리한다.

---

## 5. 인물 위치 체크: 중심 / 중간 / 외부

- [ ] 중심 인물은 문제의 내부에 갇혀 있는가?
- [ ] 중간 인물은 내부자이면서도 흔들릴 여지를 갖는가?
- [ ] 외부 인물은 새로운 정보나 다른 기준을 가져오는가?
- [ ] 권한자는 단순 악역이 아니라, 절차를 수행하는 사람으로 남아 있는가?
- [ ] 부재한 인물/비인간 장치도 대화를 흔드는 힘을 갖는가?

### 적용 틀

| 위치 | 기능 | 질문 |
|---|---|---|
| 중심 인물 | 압력을 직접 받는다 | 무엇을 겪었는가? 무엇을 요구받는가? |
| 중간 인물 | 내부와 외부 사이에서 흔들린다 | 처음엔 왜 회피하고, 무엇을 겪고 바뀌는가? |
| 외부 인물 | 새 기준/정보를 가져온다 | 무엇을 모르기 때문에 질문하는가? |
| 권한자 | 기록/판정/요약한다 | 무엇을 선택하고 무엇을 선택하지 않는가? |
| 비인간 장치 | 칸과 규칙을 만든다 | 어떤 말을 받아들이고 거부하는가? |

---

## 6. 구체소재 체크

- [ ] 인물들이 실제로 만지고, 입력하고, 옮기고, 확인할 수 있는 구체소재가 있는가?
- [ ] 그 소재는 본론을 직접 말하지 않게 하는 우회로인가?
- [ ] 소재가 단순 상징이 아니라 장면 진행을 바꾸는가?
- [ ] 소재의 위치/상태가 장면 후반에 달라지는가?
- [ ] 관객의 상상력이 그 소재를 통해 특정 방향으로 움직이는가?

### 구체소재 표

| 구체소재 | 처음 상태 | 중간 변화 | 마지막 상태 | 대화에 미치는 영향 |
|---|---|---|---|---|
| 컵 |  |  |  |  |
| 서류/입력칸 |  |  |  |  |
| 장비 |  |  |  |  |
| 이름/표식 |  |  |  |  |
| 소리 |  |  |  |  |

### 위험 신호

- 소재가 “상징적으로 좋아 보이기만” 한다.
- 인물이 소재를 다루지 않는다.
- 소재가 장면 끝에도 처음과 같은 의미로 남는다.

---

## 7. 대사 체크

- [ ] 이 대사는 그 인물이 이 상황에서 말할 필요가 있는 말인가?
- [ ] 이 대사는 관객에게 정보를 설명하기 위해서만 존재하지 않는가?
- [ ] 이 대사는 이미 무대가 보여준 것을 다시 해설하지 않는가?
- [ ] 같은 기능의 대사가 반복되고 있지 않은가?
- [ ] 좋은 문장이 너무 많아 서로 힘을 나눠 갖고 있지 않은가?

### 한 장면 한 문장 원칙

한 장면에는 대표 문장 하나만 남긴다. 나머지 좋은 문장은 낮추거나, 화면/행동/소리/물건으로 넘긴다.

예:

- 남길 문장: “중립이면 왜 제 말에서 멀어져요?”
- 낮출 문장: “사람 말은 기록 아니면 현상이네요.”
- 전환 방식: 화면에 `현상 분류`, `기록 아님`, `특이사항 없음`을 띄운다.

### 위험 신호

- 인물이 작품의 주제를 정확하게 말한다.
- 질문이 너무 논리적으로 완성되어 있다.
- 대사가 “좋지만” 인물의 입보다 작가의 입에 가깝다.

---

## 8. 플롯 체크

- [ ] 플롯이 사건 나열이 아니라 정보와 권한의 재배치로 진행되는가?
- [ ] 각 장면마다 누가 무엇을 새로 알게 되거나 잃는가?
- [ ] 초반 1/4 안에 작품의 핵심 규칙이 드러나는가?
- [ ] 반복되는 절차가 매번 다른 권력관계를 만드는가?
- [ ] 결말은 문제 해결보다 무대 상태의 변화로 닫히는가?

### 플롯 표

| 장면 | 겉 사건 | 정보 이동 | 권한 이동 | 남는 물성/상태 |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 결말 |  |  |  |  |

### 위험 신호

- 사건은 많지만 정보/권한의 위치가 바뀌지 않는다.
- 인물들이 계속 같은 논쟁을 반복한다.
- 결말에서 인물이 작품의 의미를 설명한다.

---

## 9. 장면 퇴고 순서

대사가 설명적으로 느껴질 때, 바로 문장을 다듬지 말고 아래 순서로 본다.

1. **장소가 약한가?**  
   → 장소의 규칙, 동선, 금지, 권한을 더 분명히 한다.

2. **문제가 약한가?**  
   → 인물이 지금 처리해야 하는 작은 절차를 만든다.

3. **정보 차이가 약한가?**  
   → 인물마다 아는 것/모르는 것/인정하지 않는 것을 분리한다.

4. **구체소재가 약한가?**  
   → 말 대신 다룰 물건, 화면, 소리, 문서, 입력칸을 만든다.

5. **그래도 필요한 대사인가?**  
   → 그때만 대사를 남긴다. 단, 한 장면에 대표 문장 하나만.

---

## 10. `상담 종료 후 들리는 말` 전용 체크

- [ ] C가 “기록은 인간의 말을 지운다”고 직접 말하지 않는가?
- [ ] C의 말이 후처리 메모 → 면담 사유 → 인지 주장 → 대상자 의견 → 요약 화면으로 변형되는가?
- [ ] A는 악역이 아니라 기록 권한자로 남는가?
- [ ] A가 들었는지 아닌지 확정하지 않는 작은 정지가 있는가?
- [ ] B는 처음엔 회피하고, 자기 말이 변형되는 경험 뒤에야 기준을 흔드는가?
- [ ] 헤드셋 분리는 “확인”이 아니라 “듣지 않게 만드는 행위”로 보이는가?
- [ ] 물컵/이름표/헤드셋은 말보다 오래 남는가?
- [ ] 결말은 `특이사항: 없음`과 무대에 남은 물성의 충돌로 닫히는가?
- [ ] 마지막 C의 말은 설명이 아니라 선택인가? 예: “지금은 안 말하는 거예요.”

---

## 11. 최종 퇴고 질문

1. 이 장면에서 삭제해도 되는 가장 좋은 문장은 무엇인가?
2. 그 문장을 화면/물건/소리/정지로 바꿀 수 있는가?
3. 인물들이 서로 이미 아는 사실을 말하고 있지 않은가?
4. 관객이 발견해야 할 것을 인물이 먼저 결론내리고 있지 않은가?
5. 결말 뒤에 남는 것은 주장인가, 상태인가?

## 요약

> 히라타식 퇴고는 대사를 현실 말투처럼 바꾸는 작업이 아니다. 대사가 굳이 설명하지 않아도 되도록 **장소, 문제, 정보 차이, 구체소재**를 다시 배치하는 작업이다.
