# 모욕에 동의하라는 절차 — 기능 감사 (C3 1회차)

> 대상 판본: 1~5장 연결본(진본, 22.1매). 반복어·오브제·침묵·직접 발화가 실제로 무엇을 바꾸는가. 진단만 — 본문 수정은 별도 턴(사용자 우선). 판정 형식은 '원칙과 긴장하는 지점' 지목 — 유지/수정의 판정자는 사용자.

## 1. 상수 문구가 일하는가

| 문구 | 등장 | 기능 변화 | 판정 |
|---|---|---|---|
| "남은 조항 N개. 천천히 읽으셔도 됩니다." (시스템) | 3회 (1장 "3개" / 2장 "2개" / 3장 "2개") | 정중체 불변, 카운트만 감소 — 배려의 형식이 진행 막대. 3장에서 카운트가 줄지 않음("2개" 2회) — 시스템이 저항의 시간을 정지된 숫자로 측정 | ○ — 이 편 시그니처. 카운트 정지는 어휘표 설계("카운트만 줄어듦") 밖의 변주 — 5절 구조 발견 |
| "규정이라서요" 계열 (B) | 4회 | 안내("낭독 확인이 규정이라서요", 1장) → 같은 문장 그대로(1장 2회째 — 방패) → "인식 기준이… 규정입니다"(2장 — 말줄임의 균열) → "전 조항 낭독이 규정이라—"(2장 — A가 자름) | ○ — B의 균열이 문장 완결도의 하강으로 수행됨 |
| "항목에 없습니다" (B) | 2회 (3장) | 부분 동의 → 읽음 취소 — 없는 항목이 늘어난다. 같은 문형으로 출구가 하나씩 소거 | ○ |
| "자리 배정 마감이 임박했습니다" (시스템) | 2회 (4장 끝 / 5장 첫) | 유일하게 장 경계를 그대로 건너는 반복 — 암전 없는 연속의 표지이자 재촉 없는 재촉의 정점 | ○ |
| "다음 분, 창구로 와 주세요" (시스템) | 2회 (결말, "(같은 음으로)" 지정) | 변주 없음이 기능 — 시스템은 A의 사건에서 아무것도 배우지 않았음을 동일음으로 | ○ — 단 꼬리 길이는 낭독 대기(기지정) |
| C 정상화 계열 | 감쇠형 | "그냥 읽고 넘기면 돼요"(2장) → "…다들 읽어요"(낮게) → "빨리 끝내는 게 나아요. 오래 들고 있으면."(3장) → 발화 소멸(4장 멈춘 손 / 5장 입 열다 닫음) | ○ — 반복이 아니라 감쇠로 기능. 어휘표의 소멸형 설계 그대로 |
| (계획 대비) A "이 조항은…" | 0회 | 어휘표의 계획 상수가 문구로 실현되지 않고 낭독 중단 3형(끊김→웅얼→또박)으로 행위 번역됨 | ○ — 감사 기록만. 문구 없는 멈춤이 명제 상한("이 조항은…까지")보다 더 안쪽 |

## 2. 오브제 감사

| 오브제 | 경로 | 실제로 바꾸는 것 | 긴장 지점 |
|---|---|---|---|
| 펜 (연작 공유·돌아온 펜) | 펜꽂이(1장 A 손 내밀다 저지)→4장 B 두 손·정중한 각도("그 펜이다")→A 외면(표시등을 봄)→"그제야 펜을 본다"(4장 끝)→5장 무게 재는 손→눌러 씀(밑장까지 자국)→내려놓음 | 강요의 물증 — 서명이 반듯할수록 종이가 파임. 4번 편의 놓인 펜 뒤 무게의 귀환(B0 정합) | **자국의 매체** — 자국은 펜이 아니라 종이(확인서·밑장)에 남고, 확인서는 파일로 퇴장. B0 넘김 사양은 "자국이 팬 펜" — 6번에 도착하는 물성이 무엇인가(펜 자체인가, 책상에 남는 밑장인가, 파일 속인가). 6번 조립 전 사용자 판정 |
| 표시등 다섯 + 확인음 | 전부 꺼짐→조항마다 점등→3조도 "다른 표시등과 같은 음"(2장)→"나란히. 같은 밝기다"(4장)→5장 전부 소등·리셋음 | 굴욕의 진행 막대 — 시스템에는 3조가 다른 조항과 구분되지 않음을 음·밝기의 균질로 | "다른 표시등과 같은 음이다"·"같은 밝기다" — 음향·조명이 실제로 수행하면 지문의 지목은 잉여인가, 연출 지시로 필요한가. 낭독·연출 검증 — 사용자 판단 |
| 손목띠 | C 착용(2장 들어 보임 — 증거)→만지작(2·3장)→멈춘 손(4장)→5장 A 착용 의례(채우고, 돌려서, 조임 확인)→C 소매 안 은폐→"하나는 소매 안에, 하나는 드러난 채" | 사람자격의 on/off를 몸에 — 착용 의례의 익숙한 손놀림이 굴욕의 일상성을, 은폐/노출의 이중 상태가 결말을 | 없음 — 이 편의 척추 |
| 바닥선 | 페인트 한 줄 — A 바로 밖(1장)→응시(3장)→5장 넘음("별일 아닌 걸음이 되게 하는 데 힘이 드는 걸음")→D는 그대로 밖 | 자격 경계의 물리 — 넘는 걸음의 부자연이 서명의 값 | ○ |
| 확인서 | 무심히 듦(1장)→"종이가 아까보다 무겁게 들린다"(2장)→내려놓음(3장 거부)→"내리지 않는다. 든 채로"(3장 끝 — 자기 주도 전환)→반듯하게 놓음(5장)→파일 속 퇴장, 새 확인서 | 종이의 무게 = 낭독의 하중. 들고 내리는 동작이 거부와 주도의 스위치 | ○ |
| D의 부동 | 처음부터 그 자리의 자세(1장)→같은 자리(3장)→발화 후에도 같은 자세(4장)→그대로(5장 결말) | 거부의 결과를 시간으로 — 움직이지 않음이 오브제급 수행 | ○ |

## 3. 침묵·정지 감사

| 지점 | 수행 내용 | 판정 |
|---|---|---|
| 1장 3조 첫 멈춤 — "눈이 먼저 조항의 끝까지 간다. 소리가 따라가지 않는다." | 앎과 발화의 분리 — 극 전체 문제의 최초 물리화 | ○ |
| 2장 3조 무성 처리(재낭독) | 가장 또박또박한 발음이 가장 들리지 않는 역설 — 조항 비노출 원칙의 심장 | ○ 보호 — 단 연출 번역 가능성은 낭독 대기(기지정) |
| 2장 B의 단말 보기 — "화면에 답이 없는 질문이다" | "다들 읽었냐"에 침묵의 방향 전환(사람→기계) — B의 균열 최소 단위 | ○ |
| 3장 C 무응답 — "오래 들고 있으면요?" | 경험담이 중단되는 지점 — C의 과거가 열리다 닫힘 | ○ |
| 4장 D 발화 후 시선 분배 — B 단말·C 바닥·A만 계속 봄 | 무응답 2 + 응시 1. ep.1의 3방향 외면과 다른 배치 — 발화가 한 사람에게는 도착 | ○ — 계보 분화 자원(평가 자기복제 절) |
| 5장 A의 "…." | 5장에서 A의 유일 발화가 침묵 — 낭독을 끝낸 입의 소진(5절 구조 발견) | ○ 보호 |
| 5장 C 입 열다 닫음 + 소매 은폐 | 말 대신 은폐 — 균열 곡선의 종점 | ○ |
| 결말 빈 창구 + 호출 2회 | 인간의 부재에 시스템이 같은 음으로 | ○ — 꼬리 길이는 낭독 대기(기지정) |

**긴장 1건**: 4장 "전원이 D를 본다. **극이 시작된 뒤 D의 첫 소리다.**" — 무대에서 자명한 사실(전원의 시선이 이미 수행)의 지면 재설명 — 이중 봉인에 근접. 삭제 시에도 서는지 낭독에서 — 사용자 판단.

## 4. 직접 발화 감사 (희소 자원)

|---|---|---|---|
| "기계가 그럽니까, 규정이 그럽니까." (A) | 2장 | 웅얼거림 반려 직후 | ○ 보호 — 책임 소재를 묻는 극 전체의 질문이 절차어로 |
| "아니, 규정 말고요. (사이) 다들, 읽었냐고요." (A) | 2장 | 규정 방패 2연속 뒤 | ○ — C의 "…다들 읽어요"(균열 1호)를 끌어내는 지렛대 |
| "그러니까 서명을 안 해도, 제가 저걸 소리 내서 읽었다는 기록은 남는 거네요." (A) | 3장 | 취소 문답 3연쇄(그만두면/읽은 건/취소는) 뒤 | **긴장** — 극의 기제(읽음 비가역)를 A가 문장으로 완성. 관객 조립 몫의 선점인가, 폐색 확정에 필요한 마디인가. B의 "…네"가 봉인을 겸함 — 사용자 판단 |

| "저는 그 줄을 안 읽었습니다." (D) | 4장 | 전 장 부동 + 3장 A의 질문("저분은 여기 왜 계십니까")으로 조명 적립 | ○ 보호 — 회고 아닌 현재 사실, 교훈조 0. 아무도 자리로 부르지 않는 처리 정확 |
| "…다들 읽어요." (C) | 2장 | "아까보다 낮게" | ○ — 정상화 어휘의 첫 감쇠 |

## 5. 구조 발견 (설계 밖 — 보호 목록 후보)

- **산형 곡선 + 최장·최무언의 5장**: 3.9 → 4.4 → 4.7 → 3.9 → 5.0매. 3장(거부 시도) 정점 후 4장 응축, 그리고 가장 긴 5장에서 A의 대사가 0 — 말의 극이 의례의 극으로 전환되는 형식적 수행. ep.1의 체감 곡선과 다른 이 편 고유 형태. C3 증량·감량 시 "5장 = 최장·최무언"을 제약으로 걸 것을 제안.
- **A의 5장 무언**: 5장 A 발화는 "…." 하나. 낭독을 완료한 입이 서명·착용·선 넘기 내내 말을 잃음 — 맵 5장 행("결말 — 말보다 상태로")의 극단 이행이자 설계 밖 발견.
- **읽음 카운트의 정지**: "남은 조항 2개"가 2장 끝과 3장에서 같은 수 — 거부 시도의 시간이 카운트 비감소로 기록됨. 어휘표 설계 밖의 변주.
- **결말 후보 1+3의 합성**: 맵은 서명 결말(가장 차가움)과 자국 결말(6번 넘김 정확)을 별개 후보로 뒀는데, 조립은 '눌러 쓴 서명'(반듯한 이름 + 팬 종이)으로 둘을 겹침 — 톤(냉기)과 넘김(자국)을 한 동작이 동시 수행.
- **손목띠 이중 상태**: "하나는 소매 안에, 하나는 드러난 채" — 맵 C행(멈춤/외면) 너머의 결말 물성. 같은 띠가 A에게는 취득이고 C에게는 은폐 대상이라는 비대칭.
