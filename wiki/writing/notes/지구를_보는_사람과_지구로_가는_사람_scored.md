# 지구를 보는 사람과 지구로 가는 사람 — 평가 완료

## 판정과 방향 (2026-07-04)

- 판정: **병합** / 채점: A1△ A2△ A3○ / B1△ B2△ B3△ B4○ B5○
- 사유: 세 우주 감각의 비교 구조 — `돌아서는_사람과_내려오는_사람`과 같은 개념 비교극 패턴(인물이 개념 대변자 위험).
- 부품 가치: **같은 지구 영상이 세 화면에서 다른 의무(관찰/지도/구조 요청)로 쓰이는** 장치 — 공동 작업 계열 극의 무대 설계로 회수.
