# 서명칸 계보 — 편별 낭독 점검표 (낭독 국면 5a)

> 목적: 각 편에 산재한 **'낭독 후 판정 대기' 항목의 실측**. 편별 낭독 = 편 단위 판정 — 전편 연속 통독(연작 게이트 ③)과 별개 국면. 낭독 주체는 사용자(그늘 선례 — 외부 낭독/서면 평가 대체 인정 가능, C4 게이트에 은폐 없이 명기). 판정은 아래 표의 판정란에 기입하거나 낭독 소감으로 보고 — 소감 기반으로 편별 마감 회차를 소집한다.
>
> **낭독 순서 권고 (자유)**: ⑤모욕(무수정 직행 1순위) → ②운전자 → ⑥만장일치 → ④관청 → ①선장 → ③죽음에(침묵극 — **사이를 실제 시간으로 세며** 읽어야 판정 가능하므로, 낭독 근육이 붙은 마지막을 권장).

## ① 아직까지는 영혼의 선장입니다 (35.1매)

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 5장 | 반 토막 발화 2연속 — A "형식—" / C "보류는… 항목에…" | 운율인가 중복인가 | |
| 2 | 4장 | C "한 바퀴 돌았네요" | 삭제 시 침묵이 더 서는가 | |
| 3 | 2장 | 지문 "아까 A가 멈췄던 그 높이다" | 동선만으로 관객이 잡는가 | |
| 4 | (병행) | ⓐ 잔여 2건 — 보류 역설 한 단어 / A 개인 층 한 줄 | 낭독 후 필요 여부 판정 | |

## ② 운전자는 내가 될 겁니다 (27.7매)

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 전장 | 지문의 회계 — "처음이다"·"두 번째다"·"세 번째다"·"극 전체에서 C의 첫 발화다" | 낭독본 기능인가, 상연 지문에서 정리할 것인가 | |
| 2 | 3장 | 물증 숫자 6종 (시각·속도·가속·제동·문 개방 2건) | 귀로 대조가 따라잡히는가 | |
| 3 | 4장 | 지문 "어깨로 가지 않으려고 무릎을 잡고 있는 손이다" | 내면 설명 없이 동작만으로 서는가 | |
| 4 | 5장 종막 | "들어올 때와 같은 간격, 반대 순서다" | 걸음 순서 역전을 관객이 스스로 잡는가 | |
| 5 | 4장 | 종이컵 두 개 | 회수 없는 소품인가, 동등 대접의 무언 표시로 족한가 | |
| 6 | 3장 | "같은 문장인데, 같은 문장이 아니다" | 봉인 경계 — 사실 서술로 서는가 | |
| 7 | 5장 | "두 사람 중 망설이지 않은 서명은 C의 것뿐이다" | 봉인 경계 | |
| 8 | 2장 (신규) | 정합 보강 확인 — A "오른쪽에서 나오는 걸 봤어요" → B "우측에서 진입했다고 하셨는데요" | 대조가 귀로 잡히는가, 구어→서식어 낙차가 사는가 | |

## ③ 죽음에 동의하지 않겠습니다 (26.2매 — r2 직후)

**낭독 규칙**: 사이·긴 사이를 실제 시간으로. 사이를 생략하면 이 편은 판정 불가.

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 5장 | "진행은, 이미, 되었다" | 반향인가 재설명인가 | |
| 2 | 1·3장 | "이제 안다" 계열 2회 (C) | 각운인가 중복인가 | |
| 3 | 2장 (r2 신규) | B의 경험 고백 "그때 왜 더 말하지 않았냐고" | 곤경인가 압박인가 — 수위 | |
| 4 | 1~3장 (r2 신규) | E1 문답 회전의 템포 / E3 상자 쓸리는 소리 | 협조의 길이가 낙차를 키우는가, 처지는가 / 신파 경계 안인가 | |
| 5 | 4장 (확인) | 해설 3문장 삭제 자리 — "사이. 긴 사이." | 침묵이 정점을 받치는가 | |

## ④ 관청의 일을 떠맡지 않겠습니다 (29.2매)

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 2장 | "이 버튼, 지금 지구에서 누를 수 있는 사람이 저 하나네요" | 과장이 A 담담체를 깨는가, 이 편 최대 웃음인가 | |
| 2 | 5장 | 지문 "위로인지 격려인지 책임 전가인지 알 수 없는 손이다" | 이중 봉인 후보 — 해석 선점으로 들리는가 | |
| 3 | 3장 | "(민망해서) …저는 왜" | 감정 지문 없이 대사만으로 서는가 | |
| 4 | 4→5장 | 웃음-냉기 이음새 — 냉기 진입 뒤 협동 인증의 재점화 | 리듬인가 무게 삭감인가 | |
| 5 | 전장 | 희극 템포 — 사이 길이 | 웃음이 냉기로 기우는 임계 실측 | |
| 6 | 3장 (신규) | 정합 수정 확인 — "입력하려다 — 항목이 없다. 단말에서 손을 뗀다" | 귀로 자연스러운가 | |
| — | (이월) | ep.1 결말 각운·3방향 침묵 동형·B 손 모티프 | 통독(게이트 ③) 전용 — 이번 낭독에서는 1차 인상만 | |

## ⑤ 모욕에 동의하라는 절차 (22.1매 — 무수정 직행)

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 5장 | 지문 "얻은 자리다" (3어) | 봉인 경계 | |
| 2 | 2장 | "방이 그 부분을 듣지 않으려는 것처럼" | 연출 번역 가능성 — 무성 처리의 지문으로 족한가 | |
| 3 | 5장 결말 | 꼬리 길이 — 리셋 표시등 + 빈 창구 호출 2회 | 잔향인가 늘어짐인가 | |
| 4 | 전장 | 민감성 가드 — 굴욕 사유 채움의 쏠림 | 낭독·외부 눈 병행 확인 | |

## ⑥ 만장일치가 아니면 가지 않습니다 (23.0매)

| # | 위치 | 들을 것 | 질문 | 판정 |
|---|---|---|---|---|
| 1 | 5장 | "아무도 반대하지 않는 것이 이 방의 대답이다" | 봉인 경계 필두 | |
| 2 | 4장 | "견디는 것이 일이 된다" | 봉인 경계 | |
| 3 | 4장 | 십 분의 압축 방식 | 연출 변수 — 상연 시간 스프레드의 주 원인 | |
| 4 | 2장 | "같은 서명이고, 다른 답입니다" + 지문 "자기도 아는 것이다" | 이중 봉인 — 지문 없이 서는가 | |
| 5 | 4장 | "숙고를 거친 서명은 빠르다" | 사실 지문("짧다")만으로 잡히는가 | |
| 6 | 5장 | E "물어봐 줘서… 아니에요" | 접힌 감사가 온기 원천 안인가 | |
| 7 | 5장 | E "십 분 뒤에" 3연속 | 각운인가 과잉인가 | |
| 8 | 4장 (신규) | 정합 보강 확인 — C 재동의 3행("읽었어요, 아까") + 통화 2회·"십오 분 뒤에 다시 겁니다" | 원칙과 자연스럽게 앉는가, 4장 템포를 해치지 않는가 | |

## 낭독 후

- 편별 소감 → 항목 판정 → 잔여 P0 없으면 **편별 C4 상정** (낭독 요건 충족 — 대체 시 작품카드에 명기).
- 전 6편 C4 후: **연작 게이트** — 순서 의존 최종 검증 + 전편 연속 통독 (잔여 판정 3건: 결말 각운 1·4·5 / 옛 서류 전달 경로 / 자국의 매체).
