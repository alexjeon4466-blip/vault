# 『편의점 인간』 연결본 2편 — 1차 압축 낭독 체크표

> [!note] 범위
> [!stop] 2026-07-12 사용자 스탑
> 1차 압축본과 체크표는 보존하되 낭독·추가 컷·새 장면을 자동 재개하지 않는다. 아래 항목은 재개 시에만 사용하는 기록 양식이다.

> [!note] 범위
> 두 작품은 서로 독립이다. 이 문서는 진행 편의를 위해 체크표만 함께 둔다. 같은 세계·인물·결말로 비교하거나 합치지 않는다. 아래 컷 후보는 **낭독 실험 항목**이며 자동 삭제 지시가 아니다.

# 1. 낭독 목표

## 《몸이 약하다는 말은 이제 안 됩니다》

1. 전화가 실제로 연결되기 전에 변명 후보가 충분히 쌓이되 리듬이 처지지 않는가.
2. `그 말은 이제 안 된대요`의 화자가 바뀔 때 말의 소유권 이동이 들리는가.
3. `움직이지 마`가 안전 지시에서 발언 제한으로 변하지만 악역의 위협처럼 과장되지 않는가.
4. `같이 있어 달라고 했어요`를 앉아 있는 사람이 채택할 때 두 사람의 관계가 설명 없이 변하는가.
5. 마지막 `반대쪽이요`가 결론보다 가위의 다음 행동으로 들리는가.

## 《몇 시에 일어나면 좋을지 모르겠습니다》

1. 시각 자막 없이 네 조각의 시간이 서로 다르다고 들리는가.
2. 국·빵·물·커튼이 매 조각의 능동 연료로 바뀌는가.
3. 먼저 깬 사람의 질문이 상태 설명이 아니라 다른 사람의 몸을 시간표로 쓰는 행동으로 들리는가.
4. 셋째 조각의 수면 오인에서 넷째 조각의 거짓 수면 신호로 비용이 변하는가.
5. 넷째 조각이 눈·무릎 따라 하기 게임이 아니라 돌보는 사람의 움직임 상실로 남는가.

# 2. 진행 순서

1. 두 작품을 연속해서 읽지 않는다. 한 작품 낭독 뒤 최소한의 메모 시간을 둔다.
2. **1회차:** 앉아서 대사와 지문을 모두 읽는다. 연기 톤을 만들지 않고 실제 소요 시간만 잰다.
3. **2회차:** 핵심 오브제 동작만 손으로 표시한다.
   - 변명: 거울 / 가위 / 수건 아래 손 / 휴대전화 방향
   - 시간: 그릇 / 빵 / 물 / 커튼 방향
4. 2회차가 끝날 때까지 대사를 즉석에서 고치지 않는다.
5. 두 번 모두 같은 지점에서 기능 중복이 느껴질 때만 컷 후보에 표시한다.

# 3. 공통 압축 원칙

| 판정 | 처리 |
|---|---|
| 같은 정보를 같은 관계 상태에서 두 번 말함 | 컷 실험 가능 |
| 같은 문장이 다른 화자·권한·기능으로 돌아옴 | 유지 |
| 지문이 오브제 위치나 몸의 제약을 바꿈 | 유지 |
| 좋은 문장이 행동보다 먼저 의미를 정리함 | 온도 낮추기 후보 |
| 원인을 설명하지 않아도 행동이 성립함 | 설명 추가 금지 |
| 압축 뒤 이음 상태가 끊김 | 풀 연결본에서 즉시 복원 |

# 4. 장면·조각별 낭독 큐

## A. 《몸이 약하다는 말은 이제 안 됩니다》

| 구간 | 핵심 소리·오브제 | 압력 전환 | 낭독에서 확인할 것 |
|---|---|---|---|
| 장면 1 시작 | 첫 진동 / 오른쪽만 짧은 머리 | 이미 쓴 병명 대신 새 말을 만들어야 함 | 제목 대사 뒤 설명이 과하지 않은가 |
| 먼 장소 | 거울을 돌렸다가 되돌림 | 장소 거짓말이 사진 증거에 막힘 | 압축 뒤에도 `반쪽 머리`가 처음 실제 비용으로 도착하는가 |
| 같이 있음 | 긴 머리 길이를 재는 손 | 같이 있다는 말이 머리 자르기의 종료 시간으로 옮겨감 | 시간 문답이 관계를 붙드는가, 말장난으로 늘어지는가 |
| 아픈 사람 교체 | 진동 정지 / 기침 한 번 | 앉은 사람의 변명이 자르는 사람의 몸을 사용함 | 기침이 코미디보다 증거 제작으로 들리는가 |
| 사진과 반지 | 가위 손 / 수건 아래 손 | 손도 증거가 되자 반지를 감춤 | 반지 낀 손의 위치를 듣는 사람이 추적할 수 있는가 |
| 통화 연결 | 진동→통화 버튼 | 변명 제작자가 실제 발화자가 됨 | 암전 없는 이음이 들리는가 |
| 사적 말 채택 | 반지 낀 손이 나와 빗을 집음 | `같이 있어 달라`가 상대의 공식 이유가 됨 | 머리를 자르는 사람이 자기 말의 사용권을 잃는 순간이 보이는가 |
| 마지막 | 계속되는 통화 / 반대쪽 가위 | 거짓말과 돌봄이 동시에 계속됨 | `반대쪽이요` 뒤 웃음이 먼저 오는가, 작업이 먼저 보이는가 |

## B. 《몇 시에 일어나면 좋을지 모르겠습니다》

| 조각 | 핵심 소리·오브제 | 압력 전환 | 낭독에서 확인할 것 |
|---:|---|---|---|
| 1 | 차가운 냄비→김 / 두 그릇 | 시각 대신 함께 먹는 몸이 시간표가 됨 | `아침이면 뭘 해요 / 일어나`가 강문장처럼 들리지 않는가 |
| 2 | 마른 국 자국 / 뜯기지 않은 빵 | 거짓 식사 신호 때문에 돌보는 사람이 억지로 먹음 | 두 번째 빵 조각이 실제 비용으로 들리는가 |
| 3 | 빈 빵 봉지 / 물 두 그릇 / 끓는 소리 | 잠든 몸을 시간으로 오인함 | `아까 말은요` 뒤 침묵이 문답보다 강한가 |
| 4 | 커튼 틈→완전히 닫힘 | 거짓 수면 신호가 돌보는 사람의 움직임을 점유함 | 눈·고개·무릎 중 어느 신호가 없어도 비용이 유지되는가 |

# 5. 낭독 때 표시할 컷 후보

## A. 변명 두 장면

- [ ] `계속 약한 사람은 와도 된대요` 뒤 자리 준비 설명이 규칙을 충분히 이해한 뒤에도 남는가.
- [ ] `그쪽이 끝나는 시간이 더 늦어요 / 네 머리가 더 늦게 끝나면` 한 쌍이 관계 비용인가, 추가 말장난인가.
- [ ] 기침 한 번 뒤 `자는 사람이 왜 기침해 / 너무 조용하면` 문답이 증거 제작을 강화하는가.
- [ ] 통화 장면의 첫 `지금 무슨 소리야 / 머리 자르는 소리요`가 마지막 반복을 준비하는가, 마지막의 힘을 미리 소진하는가.
- [ ] `지금부터는 잘 모르겠어요`가 마지막 행동을 설명하는가.
- [ ] `반대쪽이요`에서 웃음이 먼저 생기면 문장 삭제가 아니라 더 평평한 말로 바꿔 읽어본다.

## B. 시간 네 조각

- [ ] 조각 1의 `오늘 뭐 먹었는데 / 이거요 / 아직 안 먹었잖아 / 어제도 이거였어요`가 모두 필요한가.
- [ ] 조각 2의 `이건 다른 거야 / 뭐랑 달라요 / 먹은 거랑`이 생활 거짓말인가, 정리된 농담인가.
- [ ] 조각 3의 `언제부터요 / 지금부터 / 아까 말은요`가 규칙 변경 실패를 행동보다 먼저 설명하는가.
- [ ] 조각 3의 `물은 같이 마실 수 있어요 / 됐지`가 수면 규칙으로 넘어가기 위한 충분한 잔여인가.
- [ ] 조각 4에서 고개 모방과 무릎 모방을 모두 읽어야 비용이 보이는가. 2회차에는 무릎 지문을 건너뛰어 비교한다.
- [ ] 마지막에 들어오는 사람이 일어나지 않는 행동만으로 자기 수면 상실이 보이는가.

# 6. 배우에게 줄 질문

## 머리를 자르는 사람

- `움직이지 마` 두 번을 강조 없이 읽어도 두 번째의 권한이 달라지는가.
- `같이 있어 달라고 했어요`는 거짓말을 잘 만드는 순간인가, 자기도 모르게 사적인 말을 내놓는 순간인가.
- 반지 낀 손을 꺼내 빗을 집을 때 이전의 사진 논의를 기억하고 있는가.

## 앉아 있는 사람

- 언제부터 변명을 부탁하는 사람에서 다른 사람의 말을 자기 이유로 사용하는 사람으로 바뀌는가.
- 통화를 끊지 않는 선택이 가위 때문만이 아니라 변명을 잃지 않으려는 행동으로 보이는가.

## 전화 속 목소리

- 상대를 심문하는 악역이 아니라 평범하게 참석을 확인하는 사람으로 읽어도 압력이 유지되는가.
- 설명을 요구할수록 오히려 두 사람의 말이 서로 엉키는가.

## 먼저 깬 사람

- 질문을 철학적 시간 질문이 아니라 다음 행동을 정하기 위한 실무 질문으로 읽을 수 있는가.
- 넷째 조각에서 상대의 눈·고개·무릎을 관찰하는 속도가 모방 게임처럼 빨라지지 않는가.

## 들어오는 사람

- 먹고 싶지 않은데 두 번째 빵을 먹는 비용이 목소리가 아니라 씹고 삼키는 시간에 남는가.
- 넷째 조각에서 상대를 재우려는 돌봄과 자기 몸을 회수하고 싶은 욕구가 동시에 보이는가.

# 8. 작가 수정 지시

1. 첫 낭독 직후에는 새 대사를 쓰지 않는다.
2. 두 번 모두 같은 기능으로 들린 문답만 2차 컷 후보로 옮긴다.
3. 컷 뒤 오브제 위치·전화 소유자·몸 자세가 끊기면 풀 연결본에서 복원한다.
4. 전화 속 사람의 정체·모임 사연, 시간표 상실의 원인·회복 목표를 추가하지 않는다.
5. 대표 강문장은 작품마다 하나만 남긴다.
   - 변명: 우선 `반대쪽이요`
   - 시간: 우선 제목 대사
6. 두 작품을 같은 미결 엔딩이나 같은 관계로 평준화하지 않는다.
7. 낭독 전에는 정식 초고·B2·단막 형식을 결정하지 않는다.
