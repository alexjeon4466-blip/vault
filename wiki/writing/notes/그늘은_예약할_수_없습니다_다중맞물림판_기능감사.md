# 그늘은 예약할 수 없습니다 (다중맞물림판) — 기능 감사 (C3 1회차)

> 대상 판본: 다중맞물림판 1~5장 연결본(③판 진본, 71.0매). 반복어·오브제·침묵·직접 발화·[동시] 블록이 실제로 무엇을 바꾸는가. 진단만 — 본문 수정은 별도 턴(사용자 우선). 판정 형식은 '원칙과 긴장하는 지점' 지목.

## 1. 상수 문구가 일하는가 (매 반복이 다른 일을 하는가)

| 문구 | 등장 | 기능 변화 | 판정 |
|---|---|---|---|
| "없습니다" (목록 개그) | 2장 시설물 목록 → 3장 환불 사유·동반견·맨땅·공제 예고 → 4장 적을 항목 없음 | 물건의 부재 → 절차의 부재 → **말의 부재**(B 자신의 말을 적을 항목이 없음)로 상승 | ○ — 변주 성립 |
| "삼십 분" | 1장 C 개시 → 3장 E "삼십 분 그늘요" → 4장 "제 삼십 분이 저기서 혼자 가고" → 5장 "남은 시간, 십오 분"×2 | 서비스 단위 → 요구의 이름 → 소유와 분리된 시간 → 극 밖으로 이어지는 시간 | ○ |
| "시설물이 아니라서" | 2장(그늘 — 함의) → 3장(개 — 발화) | 같은 논리가 결핍(그늘 접수 불가)과 자유(개 제거 불가)를 동시에 생산 — 규정의 양날 | ○ — ③판 고유 장치 |
| 착 (접이의자 의성) | 2장×2 → 3장×2 → 5장×2 | 합류의 기동 → 선제의 기동 → 마지막 착은 **앉지 않는 착** | ○ — 6회 모두 상이 |
| 앱/안내 음성 | 1장 1회 → 2장 2회 → 3장 1회 → 4장 **7회** → 5장 3회 | 4장 정점의 크레셴도 설계 이행. 5장 3회는 전부 '허공'(아무도 반응 안 함) | ○ — 단 4장 밀집이 낭독에서 소음화되는지 5a에서 확인 |

## 2. 오브제 감사

| 오브제 | 경로 | 실제로 바꾸는 것 | 긴장 지점 |
|---|---|---|---|
| 접이의자 (E) | 펴다 맒(1) → 옮겨 폄(2) → 선제 설치(3) → 그늘을 받음(4) → 비워 둠(5) | 대기 구역의 부재를 몸으로 보완하는 사유 좌석 → 마지막에 좌석 개념 자체를 비움 | 없음 — ③판의 척추 |
| 개 | 이동 6회(2장 2·4장 1·5장 2 + 3장 부동) | 그늘 속도의 시계, E의 예보 데이터, 측정 방해물, 미등록의 자유 | **무대 실현 방식 미정** — 평가 문서 물리층 참조 |
| 물통 (D) → 생수 (E) | 예보 이동(2) → 반 발짝 비킴(3) → C에게 두 번째 건넴 + 생수 합류(4) → 개 옆 나란히(5) | 결말 소품의 증식(물 두 개) — 돌봄의 복제 | 생수 합류(4장)가 지문 한 줄 — 관객이 '물이 두 개가 된 것'을 지각할 물리 시간이 있는가? |
| E의 폰 (받아적기) | 기록 개시(1~2) → 절차 추적 4회(3) → 멈춤 2회(4) → "적을 것이 없다"(5) | 기록하는 시스템이 기록당함 → 기록 불가능한 것(규정 밖의 말, 예습 불가한 민원) 앞에서 침묵 | ○ — 하강 곡선이 E 압력 이완과 겹침(평가 병목 3) |
| 대장 반사 | 3장 확인 불가 → 3장 이상한 자세 → 4장 비스듬히 읽기 | 서류가 햇빛에 지는 물리 개그의 지속 | 4장에서 반사 장치가 '민원 낭독'과 겹치는데, 낭독 순간의 무게를 개그 잔상이 깎는지 5a에서 확인 |
| 방석 십 센티 (A) | 3장 끝 1회 | A의 조용한 예보 동참 | **1회뿐** — ①판의 A 물성(신문 접기 의식 등)이 ③판에서 대부분 탈락. A 축 지분 병목의 물성 층위 |

## 3. 침묵·정지 감사 (수행되는 침묵인가)

| 지점 | 수행 내용 | 바꾸는 것 | 판정 |
|---|---|---|---|
| 3장 B의 벤치 견디기 | 규정처럼 앉아 있음 + F·G 내기 논평 | 체감의 강제 — "개인 자격으로 했습니다"의 전제 | ○ — 배경 논평이 침묵을 희극으로 이중화 |
| 4장 전 흐름 정지 | F·G 잡담 절단, E 엄지 정지, 개 박자 거름 | "장시간이라"의 보호 — 유일하게 전원이 같은 것을 안 보는 순간 | ○ — 설계 규정 이행. 단 직전 대장-반사 개그와의 간격 확인(위 2절) |
| 5장 무언극 | 이주 순서 6단 + B 발끝 | 규정 밖으로의 이주가 일상 동작임을 증명 | ○ — 비언어 63%의 정점. 예상 비언어 시간의 최대 지분 |

## 4. 직접 발화 감사 (희소 자원의 배치)

| 발화 | 위치 | 획득 과정이 있는가 | 판정 |
|---|---|---|---|
| "나무가 저한테 먼저 왔는데요" (A) | 1장 | ①판 상속 — 확인 문답의 누적 뒤 | ○ 보호 |
| "환불 말고 그늘로 주세요" (E) | 3장 | 환불 사유 코드 목록의 부재 → 시작 전 취소 문답 뒤 | ○ 보호 — ③판의 주제 문장 |
| "장시간이라" (A) | 4장 | 민원 대장 낭독 중단 + 전 흐름 정지 뒤 | ○ 보호 |
| "쟤는 되고?" (G) | 4장 | 정지 해제 후, 규정을 모르는 자의 번역으로 | ○ — 서늘함의 반사경. 단 "장시간이라"와 너무 가까워 여운을 나눠 갖는지 사용자 판단 |
| "그늘이 구역 밖입니다" (B) | 5장 | 측정 3회 무효 + 단말 끔 뒤 | ○ 보호 |

## 5. [동시] 블록 감사 — 형식 약속의 지면 분포

- 분포: 1장 2회 / 2장 1회 / 3장 1회 / 4장 1회 / 5장 0회. 배경 흐름의 나머지는 지문 서술로 처리.
- **긴장 지점 (이번 회차 최대)**: B2가 약속한 F3의 시간 연료는 "동시 진행·교차·주의 배분"인데, 동시다발의 정점(3장 — B가 두 민원 사이를 오가는 국면)에서 [동시] 블록이 1회(B 견디기)뿐이고, C–E–B 삼자 국면 자체는 **순차 대사**로 진행된다. 의도한 것(맞물림의 밀도)과 지면에 있는 것(순차 + 요약 지문) 사이의 간극인가, 아니면 정점에서는 전원이 한 사건에 집중하므로 동시성이 오히려 꺼지는 것이 옳은가? — 중립 질문으로 사용자에게.
- 같은 질문의 각론: (a) 3장 측정 국면에서 E의 받아적기·F·G의 관전·D의 걸레 사이클은 전부 접혀 있다 — 펴면 밀도가 오르고 가청성이 내려간다. (b) 4장 알림 일제의 [동시]는 성립했으나 그 전후(재예약 문답, B–D 교신)는 단선. (c) 5장 0회는 무언극이므로 정합 — 여기는 긴장 아님.
