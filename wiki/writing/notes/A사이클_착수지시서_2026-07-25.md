# 사이클 A 착수 지시서 — 새 채집 배치

> **이 문서는 새 세션에서 A를 시작하기 위한 브리핑이다.** 작성 시점(2026-07-25) 세션은 사이클 C 작업(《끊어진 뒤에만 이어지는 관계》 v4 판본 동결 + **계열 지도 갱신**)을 했다. 파이프라인 협업 규약 **[강행]**: 사이클 A는 B·C와 병행 가능하되 **반드시 별도 세션**에서 하고, **트리아지 지도·계열 지도 동시 수정 금지**. 따라서 이 배치는 계열 지도를 만지지 않는 새 세션에서 돌린다.

## 0. 직전 상황 (인계)

- 《끊어진 뒤에만 이어지는 관계》 **v4 판본 동결**(2026-07-25). 상태 `개작` 유지, C4 미충족(5b 외부 낭독 0회) — **완성 아님**. 재개 조건: 5b 기회 / 3장 계량기 보강 / submission_target 확정 → 재개 시 `v5`.
- WIP 조항 상태: 이 작품이 동결되어 C 슬롯에 여유가 생겼다(권고 기본값 = C 최대 2편, B 동시 1편).
- **이 배치는 A만 한다.** 새 후보를 B로 넘기는 판단은 사용자 선택 이후, 별도로.

## 1. 이 배치의 범위 — 루브릭 §9의 1~2단계

**1단계 채집·원본 보존** → **2단계 작가 쪽 재선정** 까지만. 3단계(선택 후보 탐색)는 사용자가 고른 뒤 별도.

- A는 **자율 완주** 방식이다(B·C처럼 매 단계 확인받지 않는다). 배치를 끝까지 돌리고 결과를 한 번에 보고한다.
- 출력은 **최대 3~4개**만 `사용자 선택 대기`로 올린다. **0개도 정상이다.**

## 2. 원천 지정 — 사용자 몫 (착수 전 확정 필요)

vault에 있는 채집 루트:

| 루트 | 참고 문서 | 비고 |
|---|---|---|
| 공개 커뮤니티 게시물 | [[wiki/writing/decisions/공개커뮤니티_채집풀_운영규칙_2026-07-18\|채집풀 운영규칙]] | 사이트별·전체 건수 쿼터, 본문 우선, URL·날짜·제목 직접 확인 규칙이 이미 정해져 있음 — **착수 전 반드시 재독** |
| 책 원본 | [[wiki/shared/maps/책_묶음_글감_후보_지도\|책 묶음 글감 후보 지도]], `maps/<책>_원본_창작장치_지도` | 북클럽 계열과 연동 |

## 3. 수집 대상 (채집 사이클 §수집대상)

정해진 주제가 없으면 중요도가 아니라 **장면성**으로 훑는다.

**좋은 소스**: 사회·생활·노동·교육·의료·복지·법원·행정 기사와 공공 공지 / 집·방·부엌·욕실·옥상·작은 가게 같은 사적·반사적 공간의 생활 기록 / 가족·이웃·동료·동호회의 습관·돌봄·오해·교대 / 의식·놀이·훈련·응원처럼 **반복 규칙을 스스로 만드는** 장면 / 자연·계절, 돌봄·수리·운반·청소 노동, 통근·이주 같은 이동 / 자동응답·키오스크·번호표 같은 제도·매체 마찰(**여러 레인 중 하나이지 기본값 아님**) / 몸·물건·시간·관계의 구체적 마찰이 보이는 공개 글.

**약한 소스**: 방과 물건이 안 보이는 큰 정치 이슈 / 가해·피해 구도가 너무 선명해 절차의 미세한 압력이 사라지는 사건 / 인물이 기능의 삽화로만 남는 소재 / 설명해야 이해되는 배경이 많은 사건 / 실제 피해를 거의 그대로 재현해야 성립하는 사건 / **로그인·인증이 필요한 비공개 게시물(우회 금지, 본문 추정 금지)**.

## 4. 1차 필터 (6기준 — 뉴스 가치·시험 용이성 아님)

| 기준 | 남긴다 | 버린다 |
|---|---|---|
| 출처 압력 | 실제 사람·말·행동·노동·기다림·관계가 보인다 | 주제 요약만 남는다 |
| 작가 쪽 궁금함 | 다음 말·침묵·선택·시간을 써보고 싶다 | 소품 시험 계획만 쉽게 떠오른다 |
| 장면 가능성 | 말·관계·행동·관점·시간·물질 중 하나가 변할 여지 | 설명을 낭독해야 성립한다 |
| 시간의 미완 | 반복·누적·교대·도약·기억에 아직 닫히지 않은 것 | 제목의 착상으로 이미 소진 |
| 독자성 | 기존 작품과 다른 사람·목소리·관계·온도 | 익숙한 제도극·소품극 공식만 떠오름 |
| 윤리적 거리 | 식별정보·실제 피해를 지우고 변형 가능 | 사적 고통을 그대로 빌려야 함 |

## 5. 카드 포맷 (채집 사이클 §카드 포맷 — 짧게 유지)

```markdown
## [후보 N] 제목 후보

### 출처
- 제목 / 매체 / 날짜 / URL:
- 공개 접근 경계:

### 출처에서 실제로 살아 있는 것
- 사람·말·행동·관계·시간:
- 잃지 말아야 할 이미지·온도·질문:

### 희곡적 거리
- 원천 표면을 지운 뒤에도 남는 압력:
- 실제 인물·피해·고유 일화를 소비하지 않을 경계:
- 기존 글감과 다른 점 / 자기복제 위험:

### 작가 쪽 재선정
- 더 따라가고 싶은 사람·목소리·관계·시간:
- 아직 닫히지 않은 질문:
- 현재 상태: 사용자 선택 대기 / 병합 재료 / 보류 / 제외
```

- 20개를 모을 수 있지만 20개를 같은 깊이로 개발하지 않는다.
- 상태별 최소 조건(루브릭 §7): `사용자 선택 대기`엔 작가 쪽 질문 / `병합 재료`엔 내놓을 부품과 받을 계열 / `보류`엔 재개 조건 / `제외`엔 단순 취향이 아닌 중복·윤리 근거. **어느 상태든 자기복제 위험을 적는다.**

## 6. 금지 사항 (사용자 선택 전)

- **A/B/F 점수·`유망★`·자연 규모·형식표·구조표·물성 시험 금지.** 채집은 완성 가능성을 확정하는 단계가 아니다.
- 비공개 게시물 접근 우회·본문 추정 금지. URL·날짜·제목은 직접 확인한 것만.
- 소품 시험 계획이 쉽게 떠오른다는 이유로 후보를 남기지 않는다(1차 필터 2번의 '버린다' 열).

## 7. 출력 위치·정합

- 채집 카드: `notes/` (글감 노트). 배치 요약: 이 문서 계열 또는 `notes/글감_채집_<날짜>_<루트>.md` 관용.
- **트리아지 지도**(`notes/글감_트리아지_지도.md`) 부기는 A 배치의 몫이다. 이 배치 턴에는 **계열 지도(`shared/maps/글감_계열_병합_지도.md`)를 만지지 않는다** — [강행] 조항.
- 지도·카드류 갱신 턴에는 위키 검증 실행. **운영 메모**: 검증 스크립트는 콘솔 cp949에서 UnicodeEncodeError로 죽는다 → `PYTHONIOENCODING=utf-8` 필요.
- `log.md`에 배치 기록(루트·건수·최종 선택 대기 목록·검증 결과). Git 커밋·푸시는 사용자 지시 전까지 안 함.

## 8. 직전 사이클에서 얻은 교훈 (B로 넘어갈 때만 참고)

- **확장은 장·시간을 쪼개는 게 아니라 한 장면 안의 물리 노동·판정 불능을 두껍게 하는 쪽이 이 작가에게 맞다.** 에피소드 분할은 엔진(해결=반대 상태)의 방향을 역전시켜 실패했다(익명 3렌즈 만장일치, [[wiki/writing/decisions/끊어진뒤에만_판본비교_익명가상낭독_2026-07-25|판정]]).
- 조항·규칙이 누적되는 구조라면 결합 논리는 **AND/나중인 쪽**이어야 한다(`먼저인 쪽`은 엔진 역방향).
- 종결 동력을 인물 밖(세계·회사·제도)으로 넘기면 인물의 선택이 소급 무효화된다.
