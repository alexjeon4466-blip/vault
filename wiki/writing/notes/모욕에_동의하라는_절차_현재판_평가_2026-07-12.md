# 모욕에 동의하라는 절차 — 현재판 평가 (2026-07-12)

> 대상 판본: 1~5장 연결본(진본, 22.1매 / 발화 추정 5~7분 / 비언어 추정 8~12분). 신서식(약속·명료성 3층·형식 게이트·자기복제 위험·상류 병목). 진단만, 수정은 사용자 우선 — 유지/수정의 판정자는 사용자.

## 작품의 약속

**자기를 낮추는 문장을 자기 입으로 또박또박 읽게 하는 절차 — 읽었다는 사실이 굴욕의 완성.** 냉기는 폭언이 아니라 배려체에서 온다. 보호 항목: 시스템·B의 끝까지 정중함, 조항 핵심 비노출(3조 무성 처리), 굴욕 사유 비특정, 제목 문장 비발화, D의 침묵 예산(유일 발화 1회).

**약속 이행 판정**: ○ — 전 장 폭언 0. 냉기의 정점 3곳이 전부 배려·중립체(재낭독 요구의 "…또박또박, 부탁드립니다" / 착용 의례의 "불편하시면 말씀해 주세요" / "이용해 주셔서 감사합니다"). 시스템의 유일한 지시형 "다시 읽어 주세요"(2장)도 요청체 안에 있고, 기계 중립음이 가장 차가운 마디(굴욕의 명료한 재수행 강제)를 집행 — 배려체 원칙의 예외가 아니라 정점으로 기능. 원작 개념어 0, 논제 대사 0, 제목 문장 0.

## 명료성 3층

- **물리층**: ○ — 단일 창구·책상·펜·바닥선·표시등 다섯·손목띠. 기술 요구 = 표시등 5 + 확인음·리셋음 + 시스템 음성 — 계보 내 최저난도급. **유보 1건**: 2장 3조 무성 처리 — "방이 그 부분을 듣지 않으려는 것처럼"은 효과의 기술이지 방법의 지시가 아님(음향 드롭인가, 입모양 연기인가, 마스킹 톤인가). 극의 심장이 연출 번역에 달려 있음 — 낭독 5a에서 선행 판정 가능(기지정 대기 항목과 동일 지점).
- **인과층**: 폐색 논리 4중(부분 동의 불가 / 읽음 취소 불가 / 미서명 = 자격 불활성 / 자리 배정 마감)이 각각 3~4행 문답으로 추적 가능 ○. D의 지위(비이용자 = 앞서 거부한 자)도 3장 문답이 준비하고 4장 유일 발화가 확정 ○. **유보 1건**: 3장 "읽음 기록은 유지됩니다" ↔ 5장 표시등 전소등 + 리셋음 — 벽의 기록이 지워지는 그림이 '읽음 기록 삭제'로 오독될 위험. 의도(보이는 기록만 지워지고 보이지 않는 기록은 남는다 — 냉기의 마지막 겹)를 지면에서 구분하는 표지가 없다. 보강한다면 지문 한 줄 이내, 설명 대사 금지 — 사용자 판단.
- **해석층**: 열림 ○ — 눌러 쓴 서명(분노인가 정돈인가 — "반듯하다. 읽기 쉽다. 다만 종이가 팼다"), C의 은폐(수치인가 배려인가), 빈 창구(우연인가 거부의 확산인가), D의 잔류. **적신호 후보 1건(민감성 가드)**: 굴욕 사유 비특정은 유지 ○(노출 파편 = "…에 해당함을, 인지하며" / "상시 확인에… 동의" / "재확인 요구에… 응하며" / "이용 자격이 조정") — 단 손목띠 + 상시 확인 + 시설의 물성 조합이 특정 제도(전자감독·시설 격리 등)로 좁혀 읽힐 여지가 있다. 관객이 각자의 낙인을 채워 넣는 것이 설계인데, 채움이 한 방향으로 쏠리면 비특정이 무너진다. 낭독·외부 눈에서 채움의 분포 확인 — 사용자 판단.

## 선택 형식 게이트 (F1 연속)

| 항목 | 판정 |
|---|---|
| 단일 공간·실시간 연속 | ○ — 장 경계 = 시스템 소리·읽음 카운트(암전 불요). "자리 배정 마감이 임박했습니다" 반복이 4/5장 경계를 봉합 |
| 체류 이유 | ○ — A(자격 활성), B(접수 마감), C(이용 구역 안 — 무언 처리), D(떠나면 인정하는 셈 — 몸으로만). C·D의 체류가 대사 없이 성립하는지는 낭독에서 확인 |
| 반복의 변주 | ○ — 낭독 시도 7회(1·2조 무심 / 3조 3회: 끊김→웅얼→또박 / 4조 또박 / 5조 자기 주도)가 전부 다른 속도·상태 |
| 시간 연료 | ○ — 카운트 감소·정지 + 마감 임박 2회 + 표시등 진행 막대 |

## 자기복제 위험

1. **계보 내 — D형 인물의 '4장 유일 발화' 각운**: ep.1 D(자문 라벨, 회고형 "그때는… 사람이 틀렸습니다", 무응답 3방향)와 이 편 D(부동, 현재 사실형 "저는 그 줄을 안 읽었습니다", B·C 외면 + A의 지속 응시). 유일 발화의 장 위치까지 동일(4장). 분화 자원: 회고 vs 현재 사실 / 완전 외면 vs 한 사람에게는 도착 / 라벨(반경 축소) vs 바닥선(진입 거부). 현재 분화 성립으로 판단 — 단 6편 중 '침묵 인물의 4장 발화' 배치가 몇 편에서 반복되는지 연작 통독(연작 게이트 3항) 때 계수 필요.
2. **계보 내 — 결말 리셋 꼬리 각운**: ep.1(벽 화면 "차기 회의 안건 1")과 이 편(표시등 리셋 + 새 확인서 + "다음 분" 호출 2회) — 둘 다 '시스템이 다음 사이클을 호출하며 닫힘'. 연속 관람 시 결말 문법의 관성으로 읽힐 위험. 이 편 단독으로는 ○(빈 창구 + D의 잔류가 리셋에 저항을 남김 — 다음 사람이 오지 않는다). 6편 결말 꼬리 형태(리셋형/잔류형/개방형)의 분포를 연작 게이트에서 대조 — 사용자 판단.
3. **계보 내 — 배려체 시스템 + "형식" 어휘 교차**: ep.1 "서두르지 않으셔도 됩니다" / 이 편 "천천히 읽으셔도 됩니다" — 같은 장치 계열(배려가 압력). 단 B0 무대규칙(시스템 비악역·정중)의 설계 상속이므로 자기복제가 아니라 공유 규칙 — 분화는 기능 층위에서 성립(ep.1 간격 단축 = 시간 압박 / 이 편 카운트 감소·정지 = 진행 막대). 부기: ep.1 A의 붕괴어 "형식입니다"와 이 편 C의 정상화어 "어차피 형식이잖아요" — 연속 관람 시 의도된 반향(관성어의 계보)으로 읽히는가, 재사용으로 읽히는가 — 사용자 판단.
4. **vault 차원**: 그늘 극의 B(집행자의 몸이 규정을 배반 — 벤치·발끝)와 이 편 C(통과자의 몸이 자기 부인을 배반 — 만지작→멈춘 손→은폐) — 같은 원칙 계열(몸의 배반). 차별 자원: 배반의 주체(집행자/통과자)와 방향(규정을 어김/부인을 들킴)이 다름. 성립으로 판단, 연작 통독 때 재검.

## 상류 병목 (C3-0 후보 — 사용자 선정)

1. **3조 무성 처리의 연출 번역** (물리층 유보) — 극의 심장(2장)이 연출 불능이면 장면 하중 전체가 흔들림. downstream: 보강 시 지문 1행(방법 명시) — 단 낭독 5a가 같은 지점을 검증하므로(기지정 대기 항목) 선낭독-후판정이 저비용 경로.
2. **표시등 리셋의 가독성** (인과층 유보) — '기록 삭제' 오독 위험 vs 보이는 것만 지워지는 냉기. downstream: 지문 한 줄 이내. 설명 대사 금지.
3. **자연 규모 14~19분 — 계보 최단** — 단독 공연 규격으로 얇을 수 있음 vs 냉기는 짧을수록 응축(연작 톤 곡선상 4번 희극 뒤의 급랭 — 길이 대비가 곧 온도 대비). 증량이 톤을 해칠 위험이 계보 중 최대 — 관찰만, 억지 증량 금지(신교리). 연작 전체 게이트에서 재판정. downstream: 없음.

> 회차 범위 권고(제안): 병목 1·2 모두 낭독 5a에서 판정 가능한 성격(1은 기지정 대기 항목과 동일 지점) — 이 편은 **무수정 낭독 직행(ⓑ)**이 1순위 후보로 보임. ⓐ를 택한다면 병목 2 한 줄만. 병목 3은 관찰. 최종 선정은 사용자.
