# 관청의 일을 떠맡지 않겠습니다 — 기능 감사 (C3 1회차)

> 대상 판본: 1~5장 연결본(진본, 29.2매). 반복어·오브제·침묵·직접 발화가 실제로 무엇을 바꾸는가. 진단만 — 본문 수정은 별도 턴(사용자 우선). 판정 형식은 '원칙과 긴장하는 지점' 지목.

## 1. 상수 문구가 일하는가

| 문구 | 등장 | 기능 변화 | 판정 |
|---|---|---|---|
| "보안을 위해 세션이 만료되었습니다. 처음부터 다시 인증해 주세요." (단말) | 4회 (1~4장 장 경계) + 5장 부재(마감 계열이 대체) | 문구·음색·간격 전부 불변 — 변하는 것은 수신자다. 놀람("없어졌네요") → A의 선수("지문부터죠?") → 동기화 한숨(C 합류) → D만 놀람("이게 계속 이럽니까?") → 만료 대신 마감. 루틴화 곡선이 반복의 기능 | ○ — 이 편 시그니처 성립. ep.1(간격 단축=가속)과 반대 설계(등속 반복) — 계보 내 분화 ○ |
| "마지막 확인만 누르시면 됩니다" (B) | 5회 축약 곡선 | 안내(1장) → 당혹(1장 말 "…되는데요") → 중단(2장 "그럼, 마지막—") → 부탁(4장 "…한 번만요"). 문장이 짧아지는 것으로 B가 무너짐 | ○ — 단, 어휘표가 설계한 '5장 거의 애원'은 미발화. 5장에서 그 자리를 뻗은 손과 "…."가 대신 — 결락이 아니라 상향으로 읽히나, 낭독에서 확인 |
| A 거부 계열 | 동일 문구 2회(1·4장 "제 손으로는 안 합니다") + 변주 2회(2장 "그쪽 일을 저한테 시키는 겁니다" / 3장 "그건 제 일이 아니라서요") + 5장 무발화 | 항변 → 논리 → 사실 진술 → 신입(D)에게 재선언 → 침묵(손만 무릎에). 4장의 동일 문구 재등장은 처음부터 다시 말해야 하는 루틴화의 대사판 | ○ |
| "제가 눌러드릴까요?" (C) | 1회(3장) + 4장 손이 펜으로 이동 | 선의가 시스템(본인 인증 세션)에 차단된 뒤, 변주가 대사가 아니라 오브제(집었다 놓는 펜)로 감 — 반복의 자리를 몸이 상속 | ○ |
| 대리 확정 계열 (B·D) | 2장 B "대리 확정은 규정상 불가합니다" → 4장 D "권한이… 있을 겁니다" → 멈춘 스크롤 → "…예전엔 있었는데" / B "(보지 않고) 없죠" | 아는 자(B)와 확인해야 아는 자(D)의 낙차가 희극 — 권한자 둘이 같은 벽 앞에 서는 것으로 벽의 높이를 보임 | ○ — 어휘표 설계 그대로 |

## 2. 오브제 감사

| 오브제 | 경로 | 실제로 바꾸는 것 | 긴장 지점 |
|---|---|---|---|
| `본인 확인 후 확정` 버튼 | 활성·깜빡임("정중하게") → 만료로 소멸·재등장 ×4 → 5장 팔꿈치 한 치 → 마감으로 최종 소멸 | "누가"의 과녁. 전 극에서 버튼에 가장 가까이 간 것이 의지가 아니라 우연(팔꿈치)이라는 역설 | 없음 — 이 편의 척추 |
| 펜 (연작 공유·안 쓰임) | 펜꽂이(무대 지문 "쓰이지 않을 것이다") → 4장 C 집음·돌림·쓸 데 없음·도로 꽂음 → 5장 B 응시 → 그대로 둠 | 서명 시대의 무게가 증발한 자리를 부재로 증언 — B0 지정 사건("그 부재가 4번의 사건") 성립 ○. 5번 편 넘김 물성 | **긴장 1**: 3장 "B, 그 말을 적으려다 — 적을 서식이 없다. 볼펜을 놓는다" — 이 볼펜이 연작 펜과 별개면 무대 위 펜 2자루(B0 '하나의 펜'과 긴장), 같은 펜이면 5장 "오늘 하루 한 번 뽑혔다가 도로 꽂힌 펜"과 모순. **긴장 2**: 무대 지문 "쓰이지 않을 것이다"는 예고형 서술 — 지면 독자에게 사건을 선고. 둘 다 사용자 판단 |
| 번호표 (C) | 쥠(1장) → 졸며 쥔 채(2장) → 접음(3장 "평생 오시겠네") → 구겨짐(5장) → 주머니("새로 뽑으셔야 합니다") | 대기의 시간에 몸을 줌. C의 번호표 리셋이 A의 세션 리셋과 각운 — 교착의 비용이 제3자에게 같은 형식(리셋)으로 도착 | ○ |
| 신분증·지문·인증번호 | 1장 절차 → 2장 숙련(각도 정확·화면 안 보고 입력) → 5장 협동 인증(C 신분증·D 각도·B 문자) | 협조 곡선의 물증 — 거부가 게으름이 아님을 반복 그 자체가 증명 | ○ |
| 마감 시각 표시 | 영업 중 → `30분 전` 점등(4장) → `5분 전`(5장) → 종료 | 등속 만료 위에 유한한 시계를 겹침 — 이중 시계가 5장의 서스펜스 | ○ |
| 벽 번호 표시기 | 무대 지문에 도입 → 전 장 무언급 | (밀리는 순번은 C의 대사·번호표가 전담) | **긴장** — 도입되고 안 쓰인 무대 요소. 진행하지 않는 표시기가 침묵의 소품인가 삭제 대상인가 — 사용자 판단 |

## 3. 침묵·정지 감사

| 지점 | 수행 내용 | 판정 |
|---|---|---|
| 1장 B "…." (버튼 소멸 직후) | 규정의 대변인이 규정의 시스템에 처음 배신당하는 순간 — 이마에 손을 얹으려다 마는 반동작과 세트 | ○ |
| 2장 B 무응답 + 자기 손 응시 ("지구에서" 발화 뒤) | 대답 대신 손을 보는 것으로 방금 거둔 유혹의 잔상을 연장 | ○ |
| 3장 "아무도 웃지 않는다. 웃을 뻔한 것은 B다" | 무대 위 웃음 억제가 객석 웃음을 여는 장치 — '조롱 아닌 연대' 원칙의 무대 문법화 | ○ — 보호 후보 (5절) |
| 4장 A의 질문 뒤 3방향 침묵 (D 대답 못함 / B 단말 / C 펜) | 대답 불가능성을 세 방향 시선 분산으로 | ○이되 — ep.1 4장(D 발화 후 셋이 각자 다른 곳을 봄)과 동형. 자기복제 위험으로 이관(평가 문서) |
| 5장 넷의 정지 그림 → 스침 → 전원 반사 → 같은 박자 숨 | 손 넷의 위치 열거(무릎/단말 옆/번호표/뒷짐)가 정지의 절정 — 전원이 동시에 움직이는 유일한 순간이 확정을 '막는' 반사라는 역전 | ○ — 보호 |
| 5장 단말 "…." | 비인간 장치에 침묵 발화 배정 — 관객이 "확정되었습니다"를 기다리는 자리에 무음. 오작동 결말 후보(맵 2번)를 부정형으로 스침 | ○ — 보호 후보 |
| 5장 D "…." / B "…." 연속 | 무언 발화 2연속 — ep.1 5장의 반 토막 발화 2연속과 같은 자리(5장·2연속) | **긴장** — 계보 습관인가 각 편의 필연인가, 사용자 판단 |
| 3장 봉인 "(민망해서) …저는 왜." | 동기화 한숨의 뒷정리 — 장을 닫는 대사에 감정 지문이 부착 | **긴장** — 봉인 대사 앞의 감정 설명. 지문 없이 대사만으로 서는지 낭독 확인 |
| 5장 D의 어깨 두드림 + "위로인지 격려인지 책임 전가인지 알 수 없는 손이다" | 몸짓은 열려 있으나 지문이 모호함 자체를 서술로 고정 — 무대에서는 증발, 지면·낭독에서는 해석 선점 | **긴장** — 이중 봉인 후보이자 지문 내 유일 개념어('책임') 노출 지점. C2 기지정 낭독 대기 승계 |

## 4. 직접 발화 감사 (희소 자원)

이 편은 대사 56%(계보 최고)라 희소 자원은 발화량이 아니라 **논리를 입 밖에 내는 발화**다. 통과 건수 5.

| 발화 | 위치 | 획득 과정 | 판정 |
|---|---|---|---|
| "그건 당신들이 정한 거잖아요." (A) | 1장 | 버튼 접근 실패 + "그게 무슨 차이입니까" 문답 끝 | ○ 보호 — 어휘표 허용 상한 문장, 위임 거부의 명함 |
| "이 버튼, 지금 지구에서 누를 수 있는 사람이 저 하나네요." (A) | 2장 | B의 뻗다 거둔 손 목격 직후 | **긴장** — C2 기지정: '지구'의 과장이 A 담담체를 깨는가, 이 편 최대 웃음인가 — 낭독 판정 |
| "누가 하느냐가 다르잖아요." + "다르니까 저한테 시키는 거 아니겠습니까." (A) | 4장 | D의 웃음기 없는 정면 질문("어차피 결과는 같은데") — 4장까지 아무도 정면으로 묻지 않았음 | ○ 보호 — 극 전체의 논리가 대사가 되는 유일 지점. 단 허용 상한의 끝 — 여기서 반 걸음 더 가면 논제극 |
| "이건… 본인 절차가 맞네요." (D) | 4장 | 멈춘 스크롤 | ○ 보호 — 해결사의 항복이 한 문장 |
| "평생 오시겠네." (C, 혼잣말) | 3장 | 무한 보류 문답 5행 | ○ — 웃음 억제 지문("아무도 웃지 않는다")과 세트로 보호 |
| "내일 뵙겠습니다." 미러 (A→B) | 5장 | B 곡선의 종점 — 직업 인사가 반쯤 진심으로 | ○ 보호 — 단, 지문 "직업적 인사가 반쯤 진심이 되어"가 승격을 서술 — 배우 몫인가 지문 몫인가, 낭독 확인(경미) |

## 5. 구조 발견 (설계 밖 — 보호 목록 후보)

- **점증 곡선**: 5.5 → 5.0 → 5.7 → 6.1 → 6.6매. 등장 인원 증가(2→3→4인)와 동기 — 사람이 늘수록 교착이 커진다는 것을 장 길이가 수행. ep.1의 체감 곡선과 정확히 대칭(계보 내 두 번째 시간 프로필). 맵에 없던 조립 발견 — C3 증량·감량 시 이 곡선을 깨지 않는 것을 제약으로 제안.
- **5장 협동 인증**: 맵 5장 설계("마감 알림 + 마지막 세션")에 없던 발견 — C가 신분증을 맞추고 D가 각도를 틀고 B가 문자를 보냄. 확정만 빼고 전부 공유 가능하다는 주제의 역상을 희극 최정점에 배치.
- **A의 절차 태도 반전**: 2장 "낭독해 주세요. 끝까지요" → 5장 "화면으로 하겠습니다. 시간 없으니까." 절차 최대주의자가 교착 도달을 위해 스스로 가속 — 넷이 협력해 도달하는 것이 결국 아무도 안 누르는 자리라는 것. 왜 서두르는지는 지면에 설명 없음(열림 자산).
- **십오 분 주기의 소급 수량화**: 4장 "십오 분마다요" — 세 번 겪은 반복의 시계가 신입(D) 앞에서야 숫자가 됨. 루틴화의 완성이 대사 한 마디.
- **웃음 억제 지문(3장)**: "아무도 웃지 않는다. 웃을 뻔한 것은 B다 — 입가를 고치고" — 어휘표의 '연대의 웃음' 원칙을 연출 지시로 번역한 무대 문법. 보호 후보.
