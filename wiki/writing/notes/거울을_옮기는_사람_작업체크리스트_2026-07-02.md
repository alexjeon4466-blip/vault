- [x] 1~7장 연결본 생성.

## 완료된 개작 패스

- [x] 7장 `지금 들어왔어요` 반복 오류 수정.
  - 1장에 A의 `잠깐만요. 지금 들어왔어요.`를 심음.
  - 7장 C의 같은 대사가 무대 위 반복으로 들리게 조정.
  - 7장의 메타 지문 `이 말은 이전의 거울 대사와 같지만...` 삭제.
- [x] 내면 설명형 지문 행동화/절제.
  - `듣지 못한 듯`, `본능적으로`, `실망하지 않고`, `개인정보 때문에`, `반응하지 않으려고`, `스스로 놀란다`, `확인하지 않으려 하지만` 계열을 삭제/행동화.
- [x] 7장 결말 온도 조절.
  - `제가 맞춰보겠습니다`를 `제가 한번 잡아보겠습니다` 계열로 낮춤.
  - B의 변화가 전향보다 업무 행동의 각도 변경처럼 들리게 조정.
- [x] 최종 이미지에 접힌 기록지 추가.
  - 기록지가 안내문 뒤를 받치고, 컵과 천가방이 이상한 각도로 서 있는 이미지로 정리.
- [x] 반복어 기능 감사 작성.
  - `닿`, `방해`, `십오 분`, `모르`, `죄송`의 기능과 압축 후보 분류.
- [x] 반복어 압축 1차 적용.
  - 1장 첫 `죄송합니다` 행동화.
  - 2장 `십오 분마다` 규칙 반복 한 호흡 축소.
  - 3장 `다 모르세요` 중복 삭제.
  - 4장 `방해` 논증부 일부 감축.
- [x] 낭독감 미세 조정.
  - `아까부터 죄송만 하시는데요` → `죄송 말고요`.
  - 2장 휴대폰 지문 주어 수정.
  - 4장 기록지 이미지 중복 정리.
  - 7장 `안내문을요. 잡아보겠습니다`로 발화 호흡 정리.

## 현재 유지해야 할 원칙

- [ ] A가 돌봄의 의미를 직접 설명하지 않게 둘 것.
- [ ] D/병실 안 사람은 끝까지 감사하거나 깨어나지 않게 둘 것.
- [ ] 빛의 성공은 확정하지 말고, `닿았는지 / 머무는지 / 보였는지`를 미결로 둘 것.
- [ ] 거울·컵·기록지·안내문·천가방이 실제 사건을 만들게 둘 것.
- [ ] B를 차가운 직원으로만 만들지 말고, `막아야 함`과 `막고 싶지 않음`의 분열을 유지할 것.
- [ ] C를 단순 민폐 항의자로 만들지 말고, 컵/의자/시선/대사 이양을 통해 중간 인물로 남길 것.
- [ ] 화면/설명보다 조명, 손, 컵, 기록지, 안내문, 알림음의 위치 변화를 우선할 것.
