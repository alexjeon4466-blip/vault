# 아직까지는 영혼의 선장입니다 — 기능 감사 (C3 1회차)

> 대상 판본: 1~5장 연결본(진본, 32.2매). 반복어·오브제·침묵·직접 발화가 실제로 무엇을 바꾸는가. 진단만 — 본문 수정은 별도 턴(사용자 우선). 판정 형식은 '원칙과 긴장하는 지점' 지목.

## 1. 상수 문구가 일하는가

| 문구 | 등장 | 기능 변화 | 판정 |
|---|---|---|---|
| "승인 대기 중입니다. 서두르지 않으셔도 됩니다." | 6회 (장 경계 5 + 5장 연속 2회째) | 음색·문구 불변, 간격만 단축 — 배려가 압력이 되는 곡선. 5장 연속 2회("같은 문구다. 더 빨리 왔다")가 정점 | ○ — 이 편 시그니처 성립 |
| "형식입니다." (A) | 3회 변주 | 확신(1장 "그럼 이건… 형식입니다") → 변명(3장 "형식이니까 누가 해도") → 반 토막(5장 "형식—") | ○ — 어휘표 설계 그대로, 낱말 하나의 붕괴 아크 |
| "그냥 하면 되잖아요" (C) | 1회 + 소멸 | 2장 발화 → 4장 자기 차례에 무언(시도의 흉내도 없음) — 반복이 아니라 부재로 기능 | ○ |
| "대리 서명은 불가합니다" 계열 (B) | 3회 | 규정 방어(2장) → 자격 없음 고백("저는 서명 자격이 없습니다") → 4장 "저도 자격이 없습니다"(펜을 쥔 채 — 고백이 몸과 함께) | ○ |
| 반 토막 발화 | 2회 (5장) | A "형식—" / C "보류는… 항목에…" — 문장이 끝까지 못 가는 것으로 붕괴를 수행 | **긴장** — 같은 수법 2회가 한 장 안에 연속. 의도된 운율인가 중복인가 — 사용자 판단 |

## 2. 오브제 감사

| 오브제 | 경로 | 실제로 바꾸는 것 | 긴장 지점 |
|---|---|---|---|
| 펜 (연작 공유·새것) | 꽂이→A(한 뼘)→승인란 옆→C(같은 높이)→반 뼘 옆→무접촉(3장)→순회 A·C·D한치·B(4장)→제자리→마름(5장) | 책임의 동선을 몸으로 — 접근 거리의 장부(A: 뼘→손가락→닿음·점 / D: 반 뼘→한 치)가 수치화된 공포 | 없음 — 이 편의 척추 |
| 잉크 점 | 4장 발생 → 지워지지 않음 → 5장 B가 일별 → 빈 방에 남음 | 승인란의 첫 표시가 사고라는 것 — 의지로 못 쓴 칸에 우연만 닿음 | ○ — 2번 편(잉크 번짐)으로의 계보 예고를 겸함 |
| 옛 회의록 뭉치 | 1장 무심코 펼침(손글씨·반대 의견·답글) → 3장 검색(`이견 있음` 부기) → 덮임 → 5장 A가 새 회의록을 그 위가 아니라 따로 놓음 | 서명과 이견이 공존하던 시절의 물증 — A의 못 씀에 개인 층을 실음 | 2회 발견이 A 단독 경로 — C·D는 못 봄. 관객만 아는 정보로 남는데, 이것이 A의 무게로 충분한가(평가 병목 2) |
| `자문` 라벨 | 비뚤게 붙음 → D 모서리 잡음 → 도로 눌러 붙임(3장) → 붙은 채 퇴장(5장) | 발언권의 경계를 몸에 붙임 — 떼지 않는 선택이 D의 존엄 | ○ |
| C의 가방 | 어깨(1장) → 의자(2장) → 바닥(3장) → 메고 퇴장(5장) | 장기전의 몸을 3단으로 | ○ |
| 벽 화면 | 전 안건 자동 처리 완료 → 승인 대기 중 → 폐회 완료 → 차기 회의 안건 1 | 시스템의 상태가 곧 극의 상태 — 마지막 문구가 유보를 사실로 | ○ |

## 3. 침묵·정지 감사

| 지점 | 수행 내용 | 판정 |
|---|---|---|
| 1장 "A, 끄덕인다. / 쓰지 않는다." | 결정-효력 분리의 수용과 거부가 한 몸에 | ○ |
| 3장 D 발화 차단("저—") | 한 음절 + 이중 폐색 — 4장 유일 발화의 적립 | ○ |
| 4장 D 발화 후 무응답 | 셋이 각자 다른 곳을 봄(펜/뭉치/단말) — 받지 않음이 세 방향 | ○ |
| 5장 전원 정지 → 새 알림음 | 인간의 정지가 시스템의 개입 조건이 됨 | ○ |

## 4. 직접 발화 감사 (희소 자원)

| 발화 | 위치 | 획득 과정 | 판정 |
|---|---|---|---|
| "제 서명이 들어가면, 이건 누구 결정이 됩니까?" (A) | 1장 | 두 번의 접근 실패 뒤 | ○ 보호 — 극 전체의 질문이 절차어로 |
| "그때는… 틀려도, 사람이 틀렸습니다." (D) | 4장 | 3장 차단 + 펜 한 치 | ○ 보호 — 회고형 유지, 무응답 처리 정확 |
| "한 바퀴 돌았네요." (C) | 4장 | 순회 목격 | **긴장** — 관객이 이미 본 것의 요약. 무응답 처리로 완화됐으나, 삭제 시 순회의 침묵이 더 서는지 사용자 판단 |

## 5. 구조 발견 (설계 밖 — 보호 목록 후보)

- **장 길이 체감**: 8.2 → 7.4 → 6.9 → 5.4 → 4.2매. 알림 간격 단축을 장 지속 시간이 수행 — 맵에 없던 조립 발견. C3 증량·감량 시 이 곡선을 깨지 않는 것을 제약으로 걸 것을 제안.
- **2장 "아까 A가 멈췄던 그 높이다"**: 반복의 명시(사실 서술)로 판정했으나, 관객이 스스로 알아볼 수 있는 것의 지목이라는 점에서 봉인에 근접 — 삭제해도 배우 동선이 동일하면 관객이 잡는지, 낭독에서 확인.
