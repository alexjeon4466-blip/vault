# 도움을 받으려면 차가 필요합니다 — 평가 완료

## 판정과 방향 (사이클 3 — 재채굴)

- 판정: **유망** / "대신 올 사람이 있으면 여기 안 왔습니다" — 가장 절박한 사람이 접근 못 하는 지원.
- 계열: 노동-몸/비용 · 자리 교차.
