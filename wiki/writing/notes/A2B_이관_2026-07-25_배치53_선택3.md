# A→B 이관 2026-07-25 — 배치 53 사용자 선택 3건

> [[wiki/writing/aesthetics/글감_판정_루브릭#6. A→B 최소 이관 게이트|루브릭 §6]]이 이관 스키마의 단일 진실원이다. 이 문서는 A쪽 기록(선택 응답 + 패킷)이고, B쪽 상태는 작품별 작업 원장 세 파일이 갖는다. 사이클 A는 이 문서로 끝난다.

## 사용자 선택 응답 (A3) — 표현 그대로

```yaml
responded_at: 2026-07-25
user_response_verbatim: |
  없어진 물건이 몸에 자세로 남았다
  두 번 해야 닫히는 문을 아무도 고치지 않는다
  아무도 시키지 않았는데 내가 끝자리에 앉는다
  3개 정도
selected_count: 3
reason_unconfirmed: true   # 끌리는 이유는 제시되지 않았다. 추정하지 않는다.
```

세 카드가 왜 골라졌는지는 기록하지 않는다. [[wiki/writing/aesthetics/글감_판정_루브릭#금지되는 대리 문장|루브릭의 금지 대리 문장]] 조항에 따라 AI가 끌림의 근거를 발명하지 않는다. 선택 자체가 기록이다.

관찰만 하나 적어 둔다 — 이것도 판정이 아니다.

> 고른 세 카드는 모두 **몸이 이미 프레임을 실행하고 있는** 쪽이다(기울어진 어깨 / 손잡이를 드는 손 / 끝자리에 앉는 몸). 사진·못·나무·규칙처럼 **바깥 사물이 기준을 쥔** 카드는 선택되지 않았다.

## 이관 게이트 판정 (§6 이관 조건 5항)

| 조건 | 몸자세 | 문닫기 | 끝자리 |
|---|---|---|---|
| 1. 사용자가 명시적으로 선택 | pass | pass | pass |
| 2. 설명보다 먼저 보호할 잔여 | pass | pass | pass |
| 3. 아직 모르는 채로 둘 것 | pass | pass | pass |
| 4. 미해결 권리·사생활·안전 차단 0건 | pass (경계 관리) | pass | pass (경계 관리) |
| 5. 첫 움직임이 가역적 | pass | pass | pass |

이관 선결 조건이 **아닌** 것은 확인하지 않았다: 완성된 주제, 갈등·대항력 확정, 길이·F코드, 결말, 독립 완결 증명, 기존 작품과의 차별성 증명, 레거시 A1–B5 점수.

### 권리·윤리 스크린

세 건 모두 형식 충동 파생이라 실존 인물·사건을 재현하지 않는다. `blocked` 0건. 다만 두 건에 **관리 경계**를 명시해 원장에 옮겼다.

- **몸자세**: 특정인의 질병·장애를 재현하지 않는다. 원인을 특정 직업으로 확정하지 않고, 의학적 진단·치료를 판정하는 대사를 쓰지 않는다.
- **끝자리**: 사용자 자기 경험이 섞일 수 있다. 실제 모임·지인·자리의 식별 단서를 옮기지 않는다. 동의해 준 사람들을 무례한 인물로 만들지 않는다(그 호의는 진짜다).

## WIP 권고 초과 — 기록하고 진행한다

[[wiki/writing/aesthetics/집필_파이프라인#7.5 동시 진행|파이프라인 §7.5]]의 권고 기본값은 **B 1편**이다. 이번 선택은 3편이므로 권고를 초과한다. §7.5가 `한도는 운영 권고이지 작품 게이트가 아니다`라고 명시하므로 차단하지 않고 초과 사실만 기록한다(선례: 2026-07-19 대기 바위 C1 착수의 WIP 초과 기록).

- **이관 3건은 그대로 진행한다.** 이관 자체는 가역적이고(`return_to_resting_allowed: true`) work_id·패킷은 나중에 재사용된다.
- **비용이 실제로 발생하는 지점은 B1.5 소시험이다.** 세 건을 동시에 굴리면 각 소시험의 판정이 서로 오염된다(같은 회차에 읽은 세 장면은 서로를 기준으로 읽힌다).
- **권고**: B1.5는 한 건씩. 순서는 사용자가 정한다. 굳이 권고를 달면 **문닫기 → 끝자리 → 몸자세** 순이 싸다 — 문닫기는 대사 없는 소리 스코어라 가장 싸고, 끝자리는 `이름 무발화` 제약이 실제로 버티는지 한 장면으로 판별되며, 몸자세는 부재를 무대에 세우는 문제라 앞의 두 건에서 배운 것을 쓸 수 있다.
- 세 건을 굳이 병렬로 해야 한다면 §B1.5의 `독립된 위험이 둘이면 소시험도 둘까지` 조항이 상한이다.

  - 기울어짐을 유지하는 편이 그 사람에게 더 싼 선택인지

rights_safety_status: clear

suggested_first_free_move: |
  2–5쪽 장면. 병목은 `지적하는 사람이 무엇을 요구하는가`라는 관계이므로 글쓰기가 가장 싸다.
  그 장면 안에서 몸의 행동 동사만 지정하고, 없어진 물건은 무대에 두지 않는다.

### 2. 문닫기 — `W-20260725-문닫기`

```yaml
seed_id: S-20260725-형식충동-03
work_id: W-20260725-문닫기
user_authorization: 2026-07-25 사용자 선택 3건 중 1건 (표현 그대로 "두 번 해야 닫히는 문을 아무도 고치지 않는다")
protected_residue:
  - 손잡이를 조금 들어올리며 닫아야 닫힌다
  - 사는 사람들은 아무도 그 얘기를 하지 않는다. 그냥 그렇게 닫는다
  - 새로 온 사람은 두 번 시도하고, 그 소리가 방 안까지 들린다
  - 문을 왜 고치지 않았는지 이유를 발명하지 않는다
user_pull: unconfirmed
unknown_to_preserve:
  - 결함을 고치면 무엇이 사라지는가
  - 요령을 익히는 것이 환대인가 편입인가
  - 요령을 알려 주는 대사가 나와야 하는지 (알려 주는 순간 이 카드의 시간이 끝난다)
rights_safety_status: clear
unresolved_blockers: none
resolved_or_managed_boundaries:
  - 《대기 바위》 인접 경보 — 문이 `무언가 오는 통로`가 되면 그 작품의 재판이 된다. 문은 닫는 기술로만 존재한다
  - 종이·양식·창구·상태화면을 쓰지 않는다 (배치 53 자기 제약 승계)
suggested_first_free_move: |
  대사 없는 짧은 소리 스코어. 두 번 닫히는 소리 / 한 번에 닫히는 소리의 차이만으로
  방 안 사람이 누가 왔는지 아는 구조가 서는지 본다.
  이 카드의 주장(`대사 없이 객석이 먼저 안다`)을 가장 싸게 반증할 수 있는 자리다.
return_to_resting_allowed: true
not_precommitted: [theme, length, form, ending, legacy_seed_codes, F1-F5]
```

`module_depth`에 음향·물성 심화를 지금 올리지 않는다. 소리가 엔진 후보인 것은 맞지만, 소시험 전에 모듈 깊이를 올리는 것은 조기 잠금이다. 후보로만 원장에 적었다.

### 3. 끝자리 — `W-20260725-끝자리`

```yaml
seed_id: S-20260725-형식충동-08
work_id: W-20260725-끝자리
user_authorization: 2026-07-25 사용자 선택 3건 중 1건 (표현 그대로 "아무도 시키지 않았는데 내가 끝자리에 앉는다")
protected_residue:
  - 저는 그런 거 잘 못해서요
  - 아무도 자리를 정해 주지 않았는데 문에서 가장 가까운 자리에 앉는다
  - 겉옷을 벗지 않고 무릎에 둔 채 앉는다
  - 다들 웃으면서 그렇지, 하고 넘어간다. 아무도 말리지 않는다
  - 1단의 저자와 4단의 집행자가 같은 사람이라는 구조 (카드 0 structural_mutation)
user_pull: unconfirmed
unknown_to_preserve:
  - 그 사람이 실제로 남고 싶은지
  - 사양이 편함인가 손실인가
  - 비켜 주려는 사람의 호의가 왜 부담이 되는가
  - 한 번이라도 안쪽에 앉으면 무엇이 깨지는가
rights_safety_status: clear
unresolved_blockers: none
resolved_or_managed_boundaries:
  - 사용자 자기 경험이 섞일 수 있다 — 실제 모임·지인·자리의 식별 단서를 옮기지 않는다
  - 동의해 준 사람들을 무례한 인물로 만들지 않는다
  - "[강행] 분류의 이름은 무대에서 한 번도 발화되지 않고 기재되지 않는다" — 어기면 담론극·계몽극·양식 레인 회수
  - 자기다움을 찾는 성장 서사로 닫지 않는다. 끝까지 그 자리에 앉아 있어도 된다
suggested_first_free_move: |
  2–5쪽 장면. 분류의 이름을 한 번도 발화·기재하지 않고 의자·문까지의 거리·무릎의 겉옷만으로
  4단(자기 집행)이 객석에 읽히는지 본다. 제약이 실제로 버티는지가 이 장면의 판정 질문이다.
return_to_resting_allowed: true
not_precommitted: [theme, length, form, ending, legacy_seed_codes, F1-F5]
```

## 신설 선례 — work_id 표기와 원장 파일

이 vault에 작업 원장 파일이 존재한 적이 없다. 파이프라인 §2.1과 루브릭 §6이 스키마만 정의해 뒀고 실제 인스턴스는 이번이 처음이다. 다음 두 규약을 **선례로 신설**한다.

- **파일 위치·이름**: `notes/작업원장_<work_id>.md`. 저장소 어댑터가 `notes/`를 작업 원장 자리로 지정한다.
- **`work_id` 표기**: `W-<YYYYMMDD>-<재료 지칭>`. 재료 지칭은 **제목이 아니다.** 제목은 B에서 열리고 바뀔 수 있으며, work_id는 바뀌지 않는다. 날짜는 이관일이다.
- **작품마다 별도 파일**: §2.1의 `작품마다 고정 work_id와 작업 원장을 둔다`와 §7.5의 `상태 원장을 동시에 고치지 않는다`를 함께 만족시키려면 원장을 한 파일에 합치면 안 된다. 세 건을 다른 세션에서 굴릴 수 있다.

> **지금이 개명 비용이 0인 유일한 시점이다.** revision·증거가 붙기 시작하면 work_id는 고정된다. 표기가 마음에 들지 않으면 이 턴에 바꾸는 편이 낫다.
