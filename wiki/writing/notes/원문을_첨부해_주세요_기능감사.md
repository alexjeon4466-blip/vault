# 원문을 첨부해 주세요 — 기능 감사 (C3 1회차, 2026-07-15)

> 대상: 1~5장 연결본(진본, 42.1매). 구조 장치들이 실제 지면에서 작동하는지 축별 검증. 진단만 — 본문 무수정. 판정자는 사용자.

## ① 상수·곡선 축

| 축 | 지면 검증 | 판정 |
|---|---|---|
| "다시 들어주세요" 4단 | 2장 요구("다시 들어주세요"×2) → 3장 사람에게("한 번만 다시요. 소리로요") → 4장 철회("다시 안 들으셔도 됩니다. 제가 들었으니까요") → 5장 B의 역전("한 번만, 다시 틀어 주시겠어요") | ○ — 기능·방향·주체 모두 변주, 어휘표 곡선 자구 이행 |
| A2 비껴가기 (매 장 1) | 1 서류의 프로·순응 / 2 자기 교정 칭찬·즉시 승인 / 3 인간 검수의 기계 손 / 4 재청취 거부 / 5 무해결+시스템의 관대함 | ○ — 게이트 조건 완주 |
| 두 손 각운 | 1장 "서류는 한 손으로 냈는데, 이것은 두 손이다" → 5장 확인증 "두 손으로 받는다"·B의 반환 두 손 | ○ |
| 정중함 상승 (태그) | 1장 "안내가 필요할 가능성" → 4장 "감정 동요 가능성" — 도움 제안→감정 판정 | ○ — 2회, 상한 내 |
| 재생 3회 | 1장 끝부분(시스템 경유·자막) → 3장 앞부분(시스템 경유·자막·C 중단) → 5장 처음부터(기기 직결·무자막) | ○ — 구간·매체·중단 주체 모두 변주. 내부 지도(C2 점검) 모순 0 |
| 무늬 노출 경로 | 어휘표 3규칙 → 2장 교정 대조 3행으로 관객 학습 → 3장 C의 낭독으로 복권 | ○ — 단 **무늬 1(을/를→에)은 A의 입에서 0회**(글에만 존재). 설계인가 공백인가 — 낭독 판정 |

## ② 오브제 지도

- **녹음기(천)**: 1장 두 손 등장 → 1장 끝 기계 연결·천만 남음 → 5장 반환·매듭에서 잡히는 손 → 책상 가운데. 극의 심장 ○.
- **화면**: 자막·대조·태그·카운트·목록 — 다섯 기능이 한 면에. **유보: 4장에서 카운트와 태그 목록 동시 노출 — 화면 설계 과밀 위험(상연 조건: 프로젝션 필수). 연출 몫으로 열되 기재.**
- **보류 확인증**: 종이 최초의 두 손 — 멈춘 것의 물증 ○.
- **천**: 개킴/폄/개킴(1장 끝) → 무릎(2·3장) → 매듭(5장) — A의 손이 하는 말 ○.

## ③ 대표 문장 5 차별

| 장 | 문장 | 화자·성격 |
|---|---|---|
| 1 | "손은 첨부가 안 됩니다" | B — 규정이 시가 되는 순간 |
| 2 | "오류가 없어서요" | A — 정확함의 역설 |
| 3 | "그 사람이 그렇게 틀리게 말했으니까요" | C — 직업 윤리의 판정문 |
| 4 | "말이 오고 있었어요" | A — 증언 (C 개시→A 완성 이양) |
| 5 | 없음 지정 | 행동(재청취)이 대표 |

화자 분산 A2·B1·C1+무언1 ○. 다섯 문장이 다섯 기능(규정·역설·윤리·증언·행동) ○.

## ④ 시계 감사

3중 시계: 처리 단계(장 경계) + 마감 카운트(25→0) + 침묵 타이머(3.8초). **판정: 기능 분리 성립** — 단계는 구조, 카운트는 압력, 타이머는 주제. 타이머 규칙(입력 대기 침묵만) C2 명문화 ○. **유보: 서명칸 ep.4(세션 만료)·ep.6(마감 시각)과 '당일 마감' 겹침 — 이 극은 카운트가 표적이 아니라 배경이고 마지막 18분을 사람이 그냥 보내는 것으로 역전 — 차별 성립하나 통독급 대조 시 재확인.**

## ⑤ 인물 기능

- **A**: 번역되는 통역자 — 행정어 정확/마음의 말 무늬 분열 ○. 담담 규율 유지(울음 지문 0) ○.
- **B**: 세는 손 — 아크 비트 3(이름 검색·"그럼 뭐였습니까"·최단 요청문) ○. **긴장: B의 비용이 지면에 없음** — 마감 넘긴 보류 건이 B에게 무엇인지 0(계보의 B들은 전부 비용이 있었다). 선의가 공짜로 보일 위험.
- **C**: 정확→보존 아크 ○(전환이 청취라는 직업 행위로만). **긴장: 3장 말미 이후 잔류 이유 무근거** — 촉탁 일은 검수 의견 등록으로 종료. "일어나지 않는다"가 두 번 지문으로만 처리됨(체류 이유 축 △). 부수: C가 해당 언어권 번역사라는 표지 0(보존안 작성 능력의 전제).
- **시스템**: 완료 통보체 일관, "없습니다" 0회(기계 검증), 마지막 발화가 관대("재개 시 이어서 진행됩니다") ○.

## ⑥ 계열 내 중복 점검

| 대조 | 판정 |
|---|---|
| 서명칸 계보 전반 | ○ 극성 반전 유지(빈칸을 채우라 vs 채워버림) — 정점 문답 동형 회피 이행(4장 화면의 목록 반복, "없습니다" 0) |
| 그늘 ①판 물통 종지 | **△** — 제도 밖 사적 행위로 닫는 극성 유사. 차별: 물통은 혼자·무언·유예, 재청취는 셋·요청의 방향 역전·이미 끝난 것의 반복. 낭독에서 기시감 확인 |
| ep.5 강요 낭독 / ep.3 D 완독 | ○ — C의 낭독은 존중의 완독(제3 극성). 통독급 대조 시 의도 각운 |
| 요약하지_않겠습니다(부품) | ○ — 거부의 선택 vs 수행된 뒤 남은 사람. 축 분리 |
