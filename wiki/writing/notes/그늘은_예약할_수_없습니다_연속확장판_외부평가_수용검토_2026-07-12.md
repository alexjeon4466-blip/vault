# 그늘은 예약할 수 없습니다 (연속확장판) — 외부 평가 수용 검토 (2026-07-12)

> ①판(64.4매) 종합 외부 평가의 수용 검토. 원문 보관은 사용자 몫(script/ 규약). 수용/기각 판정자는 사용자. 정합 오류·오탈자 3건은 검증 후 즉시 적용 완료(아래 5절).

## 1. 보호 목록 승격 (이견 없음)

1. **2·4·8장의 '그 외 시간' 기능 분화** — 2장: C가 A의 언어를 처음 듣는다 / 4장: 낮은 시점의 노동과 관계 / 8장: 배움의 무언 행동화.
2. **C의 물통 반복** — 4장 거절 → 6장 수락: 관계 변화가 같은 사물의 다른 수용으로.
3. **C의 불완전한 변화선** — 배우고도 다시 예약하고 약관에 동의하는 사람. 2장의 업무 연락(간신히 확보한 휴식)이 민원을 소비자적 떼쓰기에서 구함.
4. **A의 이중성** — 앱에서 밀려나는 피해자이자 20년 관습 점유자일 수 있음. 원민원이 A를 재맥락화하는 정서적 여파는 ③판(직접 충돌)보다 ①판(가까워진 뒤 뒤늦게 앎)이 더 큼.
5. **A–D 물성** — 신문지·물통 자국·권유·부채 답례. ③판 대비 확실한 우위 지점.

## 2. 병목과 처방 (사용자 판정 대기)

### 2-1. 3장 — 절차의 과완성: 왕관 지정

- 진단: 거의 모든 단계가 완성된 행정 부조리 경구로 닫힘 — 상승이 아니라 잘 만든 풍자 비트의 연속이 될 위험.
- **왕관 3축 (보호)**: "그건 서비스 명칭입니다" / "체감 사항은 접수 항목이 아닙니다" / "백엽상은… 그늘에 있습니다".
- 감량: "온도계는 그늘에 있고, 그늘은 목록에 없다"(관객이 연결 가능). 환불 코드 완독은 **유지**(B의 실제 업무 + C의 코드 오용 행동).

### 2-2. 4·8장 — 해설 감량 (③판 봉인 해제와 동일 원리)

- 4장 후보: "앉은 높이가 달라지니 다르게 보인다" / "그런데 D는 농담을 한 게 아니다. 그냥 답이다" / "시원한 것과 그늘 있는 것은 다른 것이었다" / "이십 년이 어떻게 생겼는지 처음 본 사람의 얼굴" / "오래된 동작이다".
- 8장: 좋은 지문 4개가 경쟁 — **왕관 1개만**: 평가 추천 = "이주는 부채질 두 번 사이에 끝났다"(가장 구체적). 감량: "오늘 배운 글자를 읽듯이" / "몸들이 빛보다 먼저 안다" / "오늘 오후에 생긴, 그러나 오래된 것 같은 순서".
- B 내면 지문: "'현재 기준'이라는 말이 무엇을 인정하는 것인지 잠깐 생각한다" / "자기가 방금 뭘 했는지 잠깐 생각한다" — 감량 후보 (대사 "현재 기준."은 유지).

### 2-3. A·D 미화 위험

- 새 갈등 불요 — 깨는 장치 이미 존재(A의 민원 대상 가능성, C의 재예약, D 지식 = 새벽 노동의 결과, B도 결국 예측). **지혜 찬미형 해설 지문만 감량**하면 균형 회복.

### 2-4. 대사 감량/비언어화 후보 2건

- "이제 그쪽도 안 되네요"(3장 A) / "저 지금 그늘 밖에서 그늘을 예약하고 있어요"(6장 C — ③판에도 동일 문장 존재, ③판은 잠금 상태이므로 ①판만 판정). 관객 친절성 중시 시 유지 가능 4건은 목록 유지: "몸으로 배운 약관" / "자기 점수를 보태지 못한다" / "적을 항목이 없는 말이었다" / "보고할 곳이 없는 보고다".

## 3. 구조·시간 — 증량 계획의 지위 (핵심 판정)

- 평가 계측: 발화 ~2,500자·184턴 ≈ 10분 + 사이 12~14분 + 비언어 15~22분 = **자연 실연 28~35분**.
- **권고: "80~100매까지 30매 추가" 계획 폐기** — 9장 아크 완결, 추가 회전은 배움을 교과 과정화할 위험. 추가한다면 새 비트가 아니라 기존 행동의 실제 시간 확보(D 청소·C 무응답 시간·B 업무·재정착·이동 학습), 8~12매 이내.
- 정합: 새 파이프라인 교리("자연 규모 존중, 페이지가 완료를 결정하지 않음")와 일치. r2 개시 때 이미 80~100매를 역사적 목표로 강등해 둠 — 이 권고 수용 시 연결본 메모의 "2차 증량 방향" 절을 종결 처리.

## 4. 결말 — 경계적 종지 (③판보다 급진적)

- ①판도 세 종지 공존. 권고: 경계적 종지 + **B의 발끝 뒤에 오는 재배정 알림·물통 이동을 삭제**하고 바로 암전 ("발끝만, 그늘에 넣는다. / 사이. / 천천히 암전."). 개가 없어 물통이 최종 상징을 독점하기 쉬움 — 꼬리 자체를 제거. 최종 tableau 해설도 불요(물건들은 이미 바깥에).
- ③판과의 차이: ③판은 재배열(앞당겨 소진), ①판은 삭제 — 판본 차별화에도 부합.

## 5. 정합 오류·오탈자 — 적용 완료 (2026-07-12)

| 지적 | 검증 | 적용 |
|---|---|---|
| 7장 소리 분류 부정확 (D 작업 알림=앱, 문자는 A뿐, B는 단말·폰 아님) | 실재 | 평가 제안 문장 그대로: "기기 네 대가 거의 동시에 운다 — 앱 알림음 둘, 문자음 하나, 단말음 하나. C의 손에서, A와 D의 주머니에서, B의 단말에서." |
| 8장 "걸레 짜던 손 그대로" — 7장에서 이미 걸레를 갬 | 실재 | "D의 손이 먼저 물통에 가 있다. 보지도 않고." (단순형 채택) |
| "사點 팔" 오탈자 | 실재 | "사 점 팔"로 통일 |

## 6. 판본 전략 (사용자 결정 — 최대 항목)

- **평가 의견: 최종 발전 판본 = ①연속확장판 (확신도 75%)** — 근거: 관계(A·C·D), 원민원의 재맥락화 힘, 4인·단일세트·동물 없음의 상연 가능성. ③판은 형식 실험·대안 판본으로 보존 가치.
- 현 상태와의 관계: ③판은 C4 통과·잠금·무대 상태. 이 권고는 ③판의 지위를 되돌리는 것이 아니라 **공모·낭독·공연에 한 편만 가져간다면 ①판**이라는 출구 전략. 수용 시: ①판을 C4까지 발전(감량 회차 → 낭독 → 게이트) + 작품카드에 판본 전략 기재. 기각/보류 시: 양판 병행 유지.
