# 그늘은 예약할 수 없습니다 (다중맞물림판) — 현재판 평가 2026-07-11

> 대상 판본: 다중맞물림판 1~5장 연결본(③판 진본, 71.0매 / 발화 추정 14~17분 / 비언어 추정 23~28분). 새 파이프라인 서식(약속·명료성 3층·형식 게이트·자기복제 위험·상류 병목) — 6영역 100점은 이번 회차 미적용(선택 렌즈). 진단만, 수정은 사용자 우선.

## 작품의 약속

**그늘은 누구에게도 예약되지 않는다 — 그늘 이동은 공원 전체의 날씨다.** 예약자(C)·다음 예약자(E)·비이용자(F·G)·관리자(B)·무등록 선주민(A·D)·개가 같은 이동 앞에 평등하게 우스워진다. 보호 항목: A의 서늘함 축("장시간이라"), 어휘 규율(B의 '그늘' 발화 유예, D의 발화 예산, E 선제형, F·G 규정어 제로), 무언 종결, 논제 대사 없음.

**약속 이행 판정**: 골격 층위 ○ — 세 흐름이 세워졌고, 교차 6지점이 전부 실현됐으며(아래 게이트), 결말에서 전 흐름이 하나의 그림이 된다. 유보 — "평등하게 우스워짐"의 희극 배가가 3~4장에서는 성립하나, 1~2장의 배경 흐름이 지문 서술 위주라 '동시에 우스운' 장면의 밀도는 설계 예측보다 얇다(병목 1).

## 명료성 3층

### 물리층

- 그늘 이동 4회(조명 큐 5)·도색선·벤치 3·임시 구역·접이의자 동선 — 전부 상연 가능, 동선 충돌 없음.
- **적신호 후보 1건: 개.** ③판에서 개는 3중 기능(측정 방해·예보 시계·미등록의 자유)의 핵심 장치인데, 실연 방식이 미정이다 — 실견(통제 불가)·인형/조종(양식 선택)·부재 처리(시선·소리로만). 어느 쪽이든 성립하지만 **선택이 연출 양식 전체를 결정**하므로 C4 전에 정해야 한다. 특히 5장 "개만, 일어난다"는 개가 관객에게 보이는 존재일 것을 전제한다.
- 7인 동선: 4장 알림 일제에서 7인+개가 동시에 무대 위 — 각자의 위치가 지문에 특정돼 있어 추적 가능 ○.
- [동시] 가청성: 병기 구간의 배경 대사는 전경보다 짧게 유지(어휘표 규약) ○ — 단 상연 검증은 낭독 이후.

### 인과층

- 시간 산수 전장 통과(14:05 → 14:12 → 잔여 10분 → 14:30 연쇄 → "남은 시간 십오 분" ≈ 14:46). 재배정 연쇄(C 만료 → 재예약 → 전체 재배정 → E 슬롯 개시)의 순서가 관객 추적 가능 ○.
- 유보 1건: 4장에서 B가 "임시 구역 좌표를 새 그늘 위치로 입력·전송"한 것이 전체 재배정 알림의 원인인지, 시스템의 독립 동작인지 지면상 모호 — 모호가 의도(시스템의 불투명)라면 보호, 인과 실선이 필요하면 한 뼘 보강. 사용자 판단.

### 해석층

- 열림 유지 ○: 미등록 3건의 함의(B의 묵살이 저항인가 피로인가), 빈 접이의자(좌석 개념의 반납), 극 밖으로 이어지는 두 개의 삼십 분, F·G가 끝까지 모름.
- "쟤는 되고?"(4장)가 해석층을 한 번 열고 — 개는 미등록이라 자유롭고 A는 미등록이라 민원 대상 — 이 비대칭이 작품의 가장 날카로운 진술이 됐다. 보호 권장.

## 선택 형식 게이트 (F3 다중 흐름)

| 게이트 항목 | 판정 |
|---|---|
| 흐름의 독립성 (각자의 문제·아크) | ○ — 주(재배정 소동)·부1(E의 선제 민원)·부2(F·G 규정 밖) 각각 완결 |
| 교차 지점의 설계 (우연처럼 보이되 초 단위) | ○ — 설계표 6지점 전부 실현: 공통 박자(이동 4회) / E 엿듣기→합류 / 물통 예보의 다중 수신 / 재배정 폰 일제 / F·G 자유 이동의 대조 / 접이의자의 소유-사용 어긋남 |
| 주의 배분 (전경/배경 교대) | △ — 표의 행 단위로는 이행. **긴장**: 배경이 '진행되는 흐름'이 아니라 '요약되는 지문'인 구간이 1~2장에 많음. 기능감사 5절 참조 |
| 공통 박자의 재편 기능 | ○ — 이동마다 세 흐름이 실제로 재배치됨 (2장 분화 / 4장 집결 / 5장 이주) |

## 자기복제 위험

1. **판본 간**: ①판과 골격·자산 문장을 다수 공유한다(2장 민원 문답, 4장 알림·민원 그림자, 5장 무언극). 두 판본이 '다른 작품'으로 서려면 ③판의 고유 층(E·F·G·개·동시성)이 공유 자산과 최소 대등한 지면 지분이어야 한다는 가설 — 현재 고유 층 지분은 약 40%(추정). 이 수치가 문제인지 아닌지는 사용자 판단 사항이나, ①판 C3 2차 증량이 진행되면 두 판본의 거리가 더 벌어질지 좁혀질지 함께 볼 것.
2. **vault 내**: 제도 희극 + 다중 맞물림형은 「큰 불편은 없습니다」(행정체제 개편 로비)도 예약된 조합 — 규정어 시스템과 무고한 시민의 구도가 자기복제로 흐를 위험. ③판의 차별 자원은 '자연(태양)이 시스템의 상대'라는 점과 개.

## 상류 병목 (C3-0 후보 — 1~3개, 사용자 선정)

1. **동시 직조 밀도** — F3 약속(매수>실연) vs 지면 실제(지문 63%, 매수<실연). 여러 증상의 상류: 배경 흐름의 지문 요약화(1~2장), 두 "혼자 가는 삼십 분"의 배경 시계가 4~5장에서 소리로만 유지되는 것, 희극 배가의 밀도. downstream: [동시] 병기 확대 시 어휘표 가청성 규칙·주의 배분 표·낭독 시간 전부 연동.
2. **A 축의 지분** — 1장 확인 문답이 압축 지문으로 접혀 있고(①판 중복 회피), A의 물성(신문 의식 등)이 ③판에서 방석 십 센티 1회로 축소. "장시간이라"가 도착할 때 관객이 A의 이십 년을 충분히 알고 있는가? downstream: 1장 복원/변형 시 ①판과의 중복 재발생, E·F·G 지면과의 균형.
3. **E 압력의 이완 곡선** — 4장 "시작도 안 했는데" 정점 후 5장 "적을 것이 없다"까지의 하강. 전원 이완(무언 종결)의 일부로 의도된 것인가, 부1 흐름의 조기 종료인가. downstream: 5장 무언극의 순도 — E에게 미해결 압력을 남기면 결말의 정적이 변질될 수 있음.

> 회차 범위 권고(제안): 병목 1을 주로, 병목 2를 부로 — 병목 3은 이번 회차 '관찰만'(낭독 5a 이후 판정)이 다운스트림 비용상 안전해 보인다. 최종 선정은 사용자.

## C4 판정 기록 (2026-07-12)

- **낭독 판정: 통과(대체)** — 근거: 외부 서면 평가 2회의 전 항목이 검증·수용/기각·사유 기록으로 완결(모순 5건 수리, 구조 과제 2건 반영, 잔여 오류 3건 수정, 종지 확정). 외부 '낭독'이 아닌 서면 평가의 대체 인정은 사용자 결정(2026-07-12) — 작품카드에 대체 사실 명기.
- **P0 해소**: 개의 실연 방식 확정(사용자, 2026-07-12) — 양식화된 인형/오브제, 위치·무게의 가독 우선, 실견 비전제. 문안은 연결본 등장인물 절.
- **게이트 3조건 충족 → 무대 승격.** 잠금 판본 = 연결본(2026-07-12), 이후 수정은 새 버전으로만.
