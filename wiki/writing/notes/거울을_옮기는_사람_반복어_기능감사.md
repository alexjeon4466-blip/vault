# 거울을 옮기는 사람 — 반복어 기능 감사

## 감사 기준

대상은 [[wiki/writing/drafts/거울을_옮기는_사람_1-7장_연결본|1~7장 연결본]] 개작본이다. 반복어를 단순히 줄일 대상이 아니라, **무대 행동·정보 이동·제도 언어의 마모·인물 관계 이동**을 만드는 장치인지 기준으로 분류했다.

감사어:

| 반복어 | 연결본 빈도 | 장별 분포 |
|---|---:|---|
| `닿` | 66 | 1장 9 / 2장 10 / 3장 12 / 4장 11 / 5장 13 / 6장 2 / 7장 9 |
| `방해` | 40 | 앞부분 2 / 1장 1 / 2장 4 / 3장 2 / 4장 13 / 5장 8 / 6장 1 / 7장 9 |
| `십오 분` | 22 | 1장 5 / 2장 7 / 3장 1 / 4장 1 / 5장 2 / 6장 2 / 7장 4 |
| `모르` | 18 | 1장 2 / 2장 4 / 3장 6 / 4장 2 / 5장 1 / 7장 3 |
| `죄송` | 10 | 1장 4 / 2장 2 / 3장 1 / 4장 2 / 6장 1 |

## 총평

반복어 대부분은 **기능적 반복**이다. 이 작품의 언어는 의미를 설명하기보다, 같은 단어가 장면을 지나며 권한과 위치를 바꾸는 방식으로 작동한다.

- `닿`은 빛의 성공 여부가 아니라, 관객이 무엇을 확인할 수 있고 무엇을 확인하면 안 되는지 묻는 동사다.
- `방해`는 병동 규정어에서 출발하지만, 7장에서는 B 자신이 만든 상황으로 돌아오며 제도 언어가 자기 몸을 가리키게 된다.
- `십오 분`은 반복 노동의 타이머이면서, 6~7장에서는 이미 늦은 시간/다음 시간/정리 시간과 어긋난다.
- `모르`는 무지가 아니라 미결 보존 장치다. 다만 2~3장의 일부는 기능 중복 가능성이 있다.
- `죄송`은 초반 A의 사과 습관으로 기능하지만, 1~2장에 조금 밀집되어 있어 리딩 압축 때 한두 개 덜어낼 수 있다.

따라서 지금 단계에서는 대량 삭제보다 **후반부의 기능적 변형을 살리고, 초반부의 동일 기능 반복만 줄이는 방식**이 적절하다.

## 1. `닿` — 핵심 동사, 유지 중심

### 기능

`닿`은 이 작품의 주 동사다. 빛이 실제로 어디에 도착하는지 확인하는 물리 동사이면서, 동시에 제도상 기록할 수 없는 접촉을 가리킨다.

장면별 이동:

1. **1장**: 빛이 손등/바닥/컵/잎에 실제로 닿는지 확인하는 물리 동사.
2. **2장**: `스친 것도 닿은 겁니까?`처럼 닿음의 기준이 흔들림.
3. **3장**: 이름표와 잎 사이에서 닿음이 개인정보/가림과 충돌함.
4. **4장**: 안 닿는 것도 사고일 수 있다는 전환.
5. **5장**: 손등에 닿았는지 확정할 수 없는 상태가 핵심 사건이 됨.
6. **6장**: 빈도가 줄어든다. 거울이 가방에 들어가면서 닿음이 정리 시간 밖으로 밀려남.
7. **7장**: `닿았다`보다 `머문다`, `모르겠습니다`와 결합하며 결말의 미결을 만든다.

### 유지해야 할 반복

```text
A  하나가 안 닿아서요.
```

초반 규칙을 여는 말이다. A가 거울을 꺼내는 이유가 설명이 아니라 물리적 결핍으로 제시된다.

```text
B  스친 것도 닿은 겁니까?
```

B가 제도 기준으로는 판단할 수 없는 물리 감각을 처음 묻는 지점이라 중요하다.

```text
A  빛이 안 닿은 손.
B  없습니다.
C  그럼 닿으면요.
B  그것도 없습니다.
```

기록 언어가 닿음 앞에서 무력해지는 핵심 축이다. 유지.

```text
C  닿았어요.
A  확실해요?
C  아니요.
```

5장의 중심. 유지.

### 줄일 수 있는 후보

1~2장 초반에 `닿았다/빠졌다/닿았어요`가 다소 촘촘하다. 다만 이것은 관객에게 빛의 규칙을 익히게 하는 구간이라 지금은 유지해도 된다. 20분 압축 때만 아래처럼 하나로 묶을 수 있다.

```text
C  닿았어요.
*빛이 다시 벗어난다.*
C  빠졌어요.
```

→ 압축 가능:

```text
C  닿았다가 빠졌어요.
```

그러나 현재 연결본에서는 유지 권장.

### 판단

**유지.** 삭제보다 후반으로 갈수록 `닿음`을 `확인 불가`, `머묾`, `기록 불가`와 붙이는 방향을 더 선명히 하는 것이 좋다.

## 2. `방해` — 제도어의 마모 아크, 유지하되 4장 밀도 점검

### 기능

`방해`는 병동의 공식 언어다. 처음에는 통행/안전의 합리적 기준이지만, 장면을 지나며 점점 무엇을 방해하는지 불분명해진다.

장면별 이동:

1. **1~2장**: `통행 방해`, `물품 설치`와 함께 병동 기준으로 제시.
2. **3장**: 컵은 방해가 아니지만 반사에 관여한다는 예외를 만든다.
3. **4장**: 제목 자체가 `방해`. `상황이 방해예요?`, `기준이 아닌 건 다 방해예요?`로 공식어가 흔들림.
4. **5장**: `손은 방해가 아니죠`로 방해의 반대편에 환자분 손이 놓인다.
5. **7장**: `지금은 누가 방해예요` 뒤 B가 `제가 만든 상황입니다`로 받는다. 공식어가 B 자신에게 돌아온다.

### 유지해야 할 반복

```text
B  들고 계시면 통행 방해입니다.
```

초기 기준. 유지.

```text
C  기준이 아닌 건 다 방해예요?
```

작품 전체의 제도어를 찌르는 질문. 유지.

```text
A  손은 방해가 아니죠.
B  네.
C  그럼요.
B  ...
C  그럼 뭐예요.
B  환자분 손입니다.
```

5장의 구조적 전환. 반드시 유지.

```text
A  지금은 누가 방해예요.
B  제가.
```

7장 결말의 핵심 전도. 반드시 유지.

### 점검할 후보

4장은 `방해`가 13회로 가장 높다. 의도적 장 제목/충돌 축이라 대부분 기능적이지만, 리딩 압축 때 아래 계열은 하나 덜 수 있다.

```text
C  지금은 방해 안 되죠.
B  네.
C  그런데 아무것도 안 되네요.
```

이 대사는 좋지만, 4장 전체가 길어질 경우 `방해` 논증을 반복하는 중간부에서 가장 먼저 압축 후보가 될 수 있다. 단, “안전하지만 아무것도 안 됨”을 살리는 기능이 있어 삭제는 신중.

### 판단

**유지.** 4장 밀도는 의도된 제목-장면 압력이다. 다만 20분 압축 때 4장 중간 논증부에서 1~2회 덜 수 있다.

## 3. `십오 분` — 시간 장치, 초반 설명 밀도만 소폭 점검

### 기능

`십오 분`은 행동을 반복시키는 타이머다. A의 내면 설명을 대신해 무대 시간을 만든다.

장면별 이동:

1. **1장**: 관객에게 규칙을 최초 공개. `십오 분 동안`과 `십오 분마다`의 오해가 생김.
2. **2장**: 실제 알림과 행동 전환. 작품의 리듬을 확정.
3. **3~5장**: 낮은 빈도로 이어져 시간이 지나고 있음을 유지.
4. **6장**: 정리 시간과 충돌. 병동 시간표와 빛 시간이 맞지 않음.
5. **7장**: 알림이 늦은 것인지 다음 것인지 알 수 없게 되며, `다음 십오 분이 이미 시작`된 결말로 확장.

### 유지해야 할 반복

```text
A  아니요. 십오 분마다요.
```

작품의 규칙을 여는 말. 유지.

```text
B  몇 분이 계속 십오 분씩 늘어나서요.
```

정리 시간과 돌봄 시간의 충돌. 유지.

```text
*다음 십오 분이 이미 시작되어 있다.*
```

결말의 시간 감각. 유지.

### 줄일 수 있는 후보

1~2장에 `십오 분`이 12회 집중된다. 관객에게 규칙을 학습시키는 기능은 있지만, 낭독 때 설명이 과하면 1장 또는 2장에서 하나 줄일 수 있다.

후보:

```text
C  십오 분이요?
B  십오 분 동안 이러시는 건 곤란합니다.
A  아니요. 십오 분마다요.
```

이 셋은 오해를 만드는 기능이 있어 유지 쪽.

더 후순위 압축 후보:

```text
B  지금은 십오 분마다.
A  네.
```

앞에서 이미 잡혔기 때문에 20분 압축 때 삭제 가능.

### 판단

**유지 우세, 2장 한 줄 압축 가능.** 현재 초안 단계에서는 타이머 규칙을 안정시키기 위해 유지해도 된다.

## 4. `모르` — 미결 보존 장치, 3장 일부 중복만 점검

### 기능

`모르`는 무지나 회피가 아니라, 이 작품이 확정하지 않기로 한 것들을 지키는 말이다.

장면별 이동:

1. **1장**: 식물이 아는지, 원래 하던 사람이 있었는지 모름.
2. **2장**: 스친 것이 닿은 것인지 모름. `다 모르네요`로 C가 이 작품의 인식 조건을 말함.
3. **3장**: 이름/개인정보/모르는 것 때문에 가려야 하는가, 비춰야 하는가의 핵심 논쟁.
4. **4~5장**: 손을 봤는지, 움직였는지 확정하지 않음.
5. **7장**: 결말에서 `모르겠어요 / 모르겠습니다 / 모르죠`로 성공을 닫지 않음.

### 유지해야 할 반복

```text
C  모르는데 왜 그렇게 정확해야 해요?
```

A의 반복 노동을 찌르는 초반 질문. 유지.

```text
C  다 모르네요.
A  네.
C  그런데 계속 하시네요.
A  네.
```

작품의 중심 윤리. 유지.

```text
A  모르기 때문에 가려야 해요?
B  네.
A  모르기 때문에 비춰야 하는 건요.
```

3장의 핵심 변증. 유지.

```text
A  모르겠어요.
B  모르겠습니다.
```

7장 결말의 과잉 성공 방지. 유지.

### 점검할 후보

3장에 `모르`가 6회로 밀집한다. 논리상 필요하지만, 아래 두 줄은 기능이 겹칠 수 있다.

```text
A  모르겠어요.
C  다 모르세요.
```

이후 2장에도 `다 모르네요`가 있으므로, 3장에서 `다 모르세요`는 낭독 시 반복감이 크면 삭제 가능하다. 단, C가 A의 모름을 공격하는 순간이라 인물 기능은 있다.

### 판단

**대부분 유지.** 3장의 `다 모르세요`만 20분 압축 때 후보.

## 5. `죄송` — 초반 A의 습관, 일부 압축 후보

### 기능

`죄송`은 A가 자기 행동을 설명하지 못한 채 민폐로 받아들이는 초반 방어어다. 시간이 지나며 A의 사과는 줄고, B와 C가 각도를 맡기 시작한다.

분포가 중요하다.

- 1장 4회
- 2장 2회
- 3장 1회
- 4장 2회
- 6장 1회
- 5장/7장 0회

후반으로 갈수록 사과가 사라진다. 이는 좋은 아크다.

### 유지해야 할 반복

```text
A  죄송합니다.
C  아까부터 죄송만 하시는데요.
```

초반에 A의 사과 습관을 명시적으로 찌르는 기능. 유지.

```text
B  죄송합니다.
```

4장에서 B가 `손은 개인정보가 아닙니다` 뒤 사과하는 장면은 B의 언어가 처음 금이 가는 지점이라 유지.

### 줄일 수 있는 후보

1장 초반의 A 사과는 4회라 낭독 시 조금 촘촘할 수 있다. 다만 C의 `아까부터 죄송만`이 작동하려면 최소 2~3회는 필요하다.

압축 후보:

```text
C  아.
A  죄송합니다.
```

이후 바로 또 사과가 나오므로, 20분 압축 때 첫 번째 사과 하나는 행동으로 대체 가능하다.

예:

```text
C  아.
*A가 거울 각도를 낮춘다.*
```

그러나 현재 초안에서는 C의 지적을 위한 누적이 있으므로 유지 가능.

### 판단

**초안 유지, 압축본에서 1회 감축.** 후반으로 갈수록 사라지는 아크가 이미 살아 있다.

## 기능/중복 분류표

| 반복어 | 현재 판단 | 이유 | 20분 압축 시 후보 |
|---|---|---|---|
| `닿` | 유지 | 주 동사. 물리 접촉/확인 불가/기록 불가를 모두 담당 | 1~2장 초반의 `닿았어요/빠졌어요` 일부 결합 |
| `방해` | 유지 | 제도어가 B 자신에게 돌아오는 마모 아크 | 4장 중간 논증부 1~2회 |
| `십오 분` | 유지 우세 | 타이머 규칙과 병동 시간 충돌을 만듦 | 2장 `지금은 십오 분마다` 계열 |
| `모르` | 유지 | 미결 보존의 핵심 언어 | 3장 `다 모르세요` |
| `죄송` | 초안 유지 | A의 민폐 인식과 후반 사라짐의 아크 | 1장 첫 사과 1회 행동화 |

## 우선 개작 권고

### 지금 당장 수정하지 말 것

- `닿`, `방해`, `모르`는 작품의 구조어다. 지금 줄이면 장면의 인식 장치가 약해질 수 있다.
- 특히 5~7장의 `모르겠습니다`, `방해`, `닿지 않는다/머문다`는 결말의 미결을 지키므로 유지한다.

### 다음 압축 패스에서만 볼 것

1. **1~2장 초반의 규칙 학습 반복**
   - 관객이 이미 빛의 규칙을 이해한 뒤에도 같은 정보가 남는지 점검.
2. **4장 `방해` 논증부**
   - 논리적으로 설명하는 느낌이 드는 대사 1~2개만 덜기.
3. **3장 `모르` 밀집부**
   - `다 모르네요`와 `다 모르세요`의 기능 차이가 낭독에서 살아나는지 확인.
4. **1장 `죄송` 누적**
   - C의 `아까부터 죄송만`이 성립할 만큼만 남기고, 하나는 행동으로 전환 가능.

## 결론

반복어들은 현재 대부분 **기능적 모티프 규모**다. 대량 감축보다, 다음 단계에서는 **20분 리딩용 압축본을 만들 때 초반 규칙 설명부와 4장 논증부를 줄이는 방식**이 효율적이다.

이번 감사 기준으로는 원본 연결본을 바로 고치기보다, 이 노트를 바탕으로 별도 압축 패스에서 덜어내는 것을 권한다.
## 2026-07-02 적용된 1차 압축 패스

위 감사의 압축 후보 중 일부를 원본 장면과 연결본에 반영했다.

- 1장: 첫 번째 `죄송합니다`를 삭제하고 거울 각도 수정 행동으로 대체했다. C의 `아까부터 죄송만 하시는데요`가 작동할 만큼의 누적은 남겼다.
- 2장: `아까는 십오 분 동안` 이후 `지금은 십오 분마다 / 네` 반복을 삭제해 규칙 학습부를 한 호흡 줄였다.
- 3장: 초반 `다 모르세요 / 네`를 삭제해 2장의 `다 모르네요`와의 중복을 줄였다. `모르기 때문에 가려야/비춰야` 축은 유지했다.
- 4장: `기준이 아닌 건 다 방해예요?` 뒤의 짧은 문답을 줄이고, `지금은 방해 안 되죠`를 `지금은 괜찮죠`로 낮춰 논증부와 반복어 밀도를 함께 압축했다.

이 패스는 반복어 자체를 대량 삭제하기보다, 같은 기능을 반복하는 초반/중반 문답을 행동 지문이나 다음 논점으로 흡수하는 방식으로 적용했다.
