# 끊어진 뒤에만 이어지는 관계 — 5b 외부 낭독 킷 (C3)

> **⚠ 대상 판본 변경됨 (2026-07-25).** 이 킷은 5분 최소형(r2판) 단독 검증용으로 작성됐다. 진본이 [[wiki/writing/drafts/끊어진_뒤에만_이어지는_관계_연속판_연결본|연속판 연결본]](사용자 v1)으로 승계되었으므로, **§0 목적 2의 게이트 잔여①②는 그 판본에서 재확인해야 하고, 실측 대상도 연속판 전막이다.** 낭독 방법·관찰 프로토콜·기록 서식(§1~§4)은 그대로 재사용 가능. 연속판 전용 킷은 필요 시 별도 작성.
>
> **이 회차는 실제 사람의 목소리로 읽어야 성립한다.** 5a(가상 통독)가 답 못한 것 — 실측 공연 시간, `응` 종지가 실연에서 서는지, 보증일 계산이 늘어지는지 — 은 배우 delivery·스톱워치로만 나온다. AI 가상 낭독으로 대체 불가(그건 5a에서 이미 소진). 대상: [[wiki/writing/drafts/끊어진_뒤에만_이어지는_관계_연결본|연결본]] **r2판**(2026-07-24, 대사 53행·~14.6매).

## 0. 목적 (이 낭독에서 확인할 것)

1. **실측 시간** — 발화 시간 / 비언어(사이·행동·빛) 시간 분리. 가상 추정 8~12분(발화 5~7·비언어 3~5)이 실연에서 맞는지. 최소형(10~15분 자립) 범위 확인.
2. **5b 게이트 잔여 2건** (5a에서 텍스트 무수정·소리 보류)
   - **① 코다 `응` 종지 무게** — 마지막 A `응`이 허전한가 / 충분한가.
   - **② 보증일 계산 페이스** — 66–78행 3박이 건조를 넘어 늘어지는가.
3. **r2 재분배 검증** — 상자 알아챔 A 이관(`A 저건 안 쌌네` → `B 이것도 넣어?`)이 턴 균형을 실제로 개선했는지, A 알아챔이 자연스러운지.

## 1. 대본 준비

- **낭독 대본 = 연결본 《마지막 연락》 장면(38–160행)만.** 프론트매터·측정표·다음행동 섹션은 빼고 장면 텍스트만 출력. (진본이 계속 진화하므로 킷에 대본을 복제하지 않는다 — 드리프트 방지. 클린 추출본이 필요하면 별도 요청.)
- 배역: **A / B 2인 권장.** 불가 시 1인 2역(A·B 톤 구분해서).
- 지문 처리: 지문은 **소리 내어 읽지 말 것.** 대신 행동 시간(날짜 긋기·적기·펜 놓기/들기·상자 보기)과 정지(사이·멈춘다·잠시·`……`)·최종 빛을 **실제 멈춤/동작으로 반영**. 이게 비언어 시간의 실체다.

## 2. 낭독 방법

- **스톱워치 2개(또는 랩 기능)**: (a) 발화만(대사 나올 때만 카운트), (b) 전체(막 오름~빛 페이드). 비언어 = 전체 − 발화.
- **2회독**: 1차 콜드 리드(첫인상·처지는 곳), 2차 조정 리드(사이·delivery 실어서). 두 회독 시간 다 기록.
- 신파 경계: 감정 얹지 말고 **사무적 온도** 유지(공식언어 건조 미학). 정지는 정지대로 두기.

## 3. 관찰 프로토콜 (무엇을 들을지)

| 구간 | 행 | 들을 것 |
|---|---|---|
| **① 코다 종지** | 156–160 | `세 줄이네` → `응` → 빛. `응`이 착지로 서는가, 허전한가. 배우가 무게 실을 여지 있나. 최종 지문 빛이 아크를 받는가 |
| **② 보증일 계산** | 66–78 | `육 개월…이월에 샀나` / `이월 구일` / `팔월 구일까지 보증이야` 3박. 건조가 지루로 넘어가나. 버릴 박 있나. `팔월 구일` 재기입이 서는가 |
| **r2 재분배** | 111–119 | `이게 정확한 거지`(B 착지) 뒤 `A 저건 안 쌌네`(알아챔)로 넘어가는 게 자연스러운가. B `이것도 넣어?`가 가볍게 붙나. 턴 교대 개선 체감되나 |
| **클라이맥스 침묵** | 140–150 | `놓인 펜을 든다. 멈춘다` / `안 끝나잖아` / (사이) / `안 끝나지` / `……` / `안 적어도 돼`. 정지가 자각을 운반하는가, 늘어지는가 |
| **1회차 전반 온도** | 42–83 | 사무적 스타카토가 사나 vs 밋밋한가. 겹침(동시 발화) 시험할 지점 있나(선택) |
| **전체** | — | 가장 처지는 지점 1~3곳 / 신파로 새는 지점 / 관객이 퍼즐로만 읽고 정서 못 타는 초·중반 위험 |

## 5. 결과 반영 경로

- **실측 시간** → [[wiki/writing/drafts/끊어진_뒤에만_이어지는_관계_연결본|연결본]] 초고 측정 표 `실측 공연 시간` 칸.
- **관찰** → 작업 체크리스트 수렴 신호 표에 5b 행 추가. ①② 판정에 따라: 유지(무수정)면 게이트 해제·수렴, 수정 필요면 r3 후보(가드레일: ①은 냉각 코다·씨앗6 보호 / ②는 건조 미학 보호, 감산만).
- **낭독 결과를 여기(또는 세션)에 붙여 주면** 위 경로대로 정합화하고 r3/C4를 판정한다.

## 판정자·소유권

- 5b는 실측 회차 — 문장 수정 아님. 낭독이 가리키는 유지/수정의 판정자는 사용자.
- 실제 낭독 전까지 이 노트 status = `awaiting-real-reading`. AI가 대신 읽어 채우지 않는다.
