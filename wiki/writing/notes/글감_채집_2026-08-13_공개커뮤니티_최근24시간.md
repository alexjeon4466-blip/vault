# 글감 채집 2026-08-13 — 공개 커뮤니티 최근 24시간

## 재독 렌즈

1. 작은 불편을 넘어 다음 말·침묵·관계의 역할을 바꾸는 사건이 있는가.
2. 물건의 신기함보다 사람의 호칭, 호의, 실패, 시간차가 오래 남는가.
3. 기존 제도·서식·기록·기술 계열의 무대 장치를 말만 바꿔 반복하지 않는가.
4. 실제 직장·가족·친구를 알아볼 단서를 지우고도 보호할 핵심이 남는가.
5. 정치·혐오·연예·스포츠·주식·범죄·사고·미성년자·사적 고통·얇은 질문·퍼옴·이미지 의존을 제외해도 사건이 서는가.

## 1. 쉬는 동안 돕지 않았다는 말은 이전의 호의를 의무로 바꾼다

- **원문:** 「알바 휴게시간에 알바 언니 혼자 일하는거 나가서 굳이 안도와줬는데 내가 잘못한거야?」 / 인스티즈 `일상` / 2026-08-13 20:56:49 KST / https://www.instiz.net/name/67243130
- **확인 사실:** 두 노동자는 번갈아 휴게시간을 갖는다. 한 사람은 과거 상대의 근무가 몰렸을 때 몇 차례 자발적으로 도왔다. 이번에는 상대가 그 정도로 바쁘지 않다고 판단한 사람이 예정된 휴식을 계속했고, 그 선택에 대한 불만이 관리자를 통해 돌아왔다.
- **본문 근거:** `나 쉴거 쉬었거든 그거 가지고 욕먹음` / `나도 언니가 휴게시간에 나와서 도와주는걸 딱히 안바랐는데`.
- **보호 핵심:** 어제의 호의가 오늘의 기준이 되는 순간. 쉬는 사람이 동료를 직접 보고도 나오지 않는 시간과, 상대가 그 부재를 어떻게 기억하는지가 함께 남는다.
- **작가가 따라갈 것:** 두 사람이 다음 교대 때 다시 마주쳤을 때, 먼저 꺼내는 말이 `휴게시간`인지 `전에 나는 도와줬잖아`인지.
- **윤리 거리:** 실제 업종·지역·나이·성별·관리자 구조를 복제하지 않는다. 법정 휴게시간이나 어느 쪽의 잘못을 판정하는 노동 상담으로 만들지 않는다.
- **자기복제 판정:** **`merge`**. 새 제도극으로 만들지 않고 [[wiki/writing/notes/휴식은_복귀를_전제로_합니다|휴식은 복귀를 전제로 합니다]], [[wiki/writing/notes/교대자를_찾으셔야_합니다|교대자를 찾으셔야 합니다]], 2026-07-19의 `쉬라고 한 한 시간이 입금액에서 빠진다`에 **자발적 호의가 동료 규범으로 굳는 관계 변형**만 돌려보낸다.
- **상태:** `merge` / 사용자 선택 미확인 / 미채점.

## 2. 정성은 알아보았지만 선물은 먹히지 않았다

- **원문:** 「이제서야 말하는데 예전에 친구가 생일선물로 도시락싸줬는데」 / 인스티즈 `일상` / 2026-08-13 20:54:00 KST / https://www.instiz.net/name/67243083
- **확인 사실:** 한 사람은 친구가 생일선물로 손수 만든 도시락을 받았다. 만든 사람이 장식과 준비에 들인 애씀은 알아보았지만 음식은 한입 뒤 주변 사람들에게도 먹히지 않고 버려졌다. 사과는 당시에 상대에게 전달된 말이 아니라 시간이 지난 뒤 당사자 없는 공개 글에서 나온다.
- **본문 근거:** `예쁘라고 비엔나 문어다리 만들고 열심히 애는 썼던데` / `가족들도 아무도 안먹고 한입먹고 버림`.
- **보호 핵심:** 사랑의 노동과 결과물의 실패가 동시에 참인 순간. 선물을 버리는 행동보다, 애쓴 흔적을 정확히 알아본 사람이 그 사실을 말하지 못한 시간차를 보호한다.
- **작가가 따라갈 것:** 만든 사람과 다시 만났을 때 이미 했을 법한 `맛있었어`를 고칠 수 있는지, 고치지 않는다면 어떤 다른 말이 나오는지.
- **윤리 거리:** 실제 음식의 모양, 가족 구성, 생일 시점, 친구의 신원을 복제하지 않는다. 만든 사람의 위생·요리 능력이나 관계의 진위를 조롱하지 않는다.
- **자기복제 판정:** **`captured`**. 기존 `도시락` 계열은 돌봄의 운반·보관·식사 신호가 중심이었다. 여기서는 **정성을 알아본 수령인이 실패한 결과를 숨긴 채 뒤늦게 사과하는 관계의 시간차**가 중심이라 분리한다.
- **상태:** `captured` / 사용자 선택 미확인 / 미채점.

## 3. 장난감을 만지는 선배를 꾸짖는 후배

- **원문:** 「99 인데 06한테 한소리 들었네」 / 인스티즈 `일상` / 2026-08-13 20:45:41 KST / https://www.instiz.net/name/67242972
- **확인 사실:** 먼저 들어온 사람과 새로 온 사람이 가까워진 뒤, 선배는 업무 밖 이동·휴식 시간에 작은 장난감을 자주 만졌다. 후배는 그 행동을 나이와 결부해 유아적이라고 평가했고, 선배는 모욕감을 느끼면서도 자신이 예민한지 되묻는다.
- **본문 근거:** `그런거 갖고 노세요` / `되게 아기같아요`.
- **보호 핵심:** 조직상 선배인 사람이 사적인 취향을 평가받는 순간 후배처럼 작아지는 역할 역전. 친해졌기 때문에 가능한 말인지, 친해졌다고 착각했기 때문에 나온 말인지 결정되지 않은 관계를 보호한다.
- **작가가 따라갈 것:** 평가 직후 선배가 물건을 주머니에 넣을지 계속 만질지, 후배가 농담이었다고 물러날지 판단을 고수할지, 다음 휴식시간에 누가 먼저 말을 거는지.
- **윤리 거리:** 실제 출생연도·연령 차이·직종·사업장·제품명을 지운다. 세대 일반론이나 취향 조롱으로 확대하지 않는다.
- **자기복제 판정:** **`captured`**. 인사평가·사내 기록 같은 기존 제도 장치를 덧붙이지 않고, **친밀감과 직장 위계가 한 문장으로 뒤집히는 순간**만 분리해 남긴다.
- **상태:** `captured` / 사용자 선택 미확인 / 미채점.

## 4. 직원이 된 대표님의 키보드는 2주째 같은 소리를 낸다

- **원문:** 「사무실에서 도각도각 키보드(조약돌) 허용하시나요?」 / 클리앙 `kin` / 2026-08-13 15:42:45 KST / https://www.clien.net/service/board/kin/19246452
- **확인 사실:** 거래처 대표였던 사람이 회사를 접은 뒤 다른 회사의 직원으로 들어왔다. 사장은 그를 직원이라고 설명하지만 기존 직원들은 계속 `대표님`이라 부르고 외부인처럼 대한다. 그는 조용한 사무실에 소리 큰 키보드를 가져왔고, 동료와 사장이 교체를 요청했지만 2주 동안 바꾸지 않았다.
- **본문 근거:** `저희 회사 사장님 말로는 직원이라고 하는데, 저희 업무랑 겹치지 않는 새로운 분야라.. 호칭도 '~대표님'이고` / `지금 2주 지났는데 안 바꾸네요`.
- **보호 핵심:** 지위는 바뀌었지만 호칭은 바뀌지 않은 사람. 키보드 소리는 단순 층간소음이 아니라 그 사람이 아직 손님인지 동료인지 아무도 직접 말하지 못하는 동안 계속되는 리듬이다.
- **작가가 따라갈 것:** 누군가 처음으로 `대표님` 대신 다른 호칭을 부르는 순간, 키보드 교체 요구가 더 쉬워지는지 더 무례해지는지.
- **윤리 거리:** 실제 회사 규모·업종·거래처·제품명·성별을 지운다. 폐업 원인이나 당사자의 경제 사정, 고집의 동기를 발명하지 않는다.
- **자기복제 판정:** **`captured`**. 기존 키보드 소리 노트들은 녹취·기록 노동의 잔여가 중심이고, 기존 호칭 노트는 공식 분류가 사람을 낮추는 방향이다. 여기서는 **낮아진 공식 지위와 그대로 남은 존칭이 서로 충돌하는 역할 지연**을 중심으로 분리한다.
- **상태:** `captured` / 사용자 선택 미확인 / 미채점.

## 가까이 갔지만 남기지 않은 것

- 식사시간을 아껴 쉬려고 급히 먹는 몸은 구체 행동이 있었지만 건강 사연과 습관 설명이 앞서고, 기존 식사 신호·시간 배분 계열과의 차이가 충분하지 않았다.
- 첫 출근에 면접 때 신었던 구두로 하루를 버틸지 묻는 글은 몸과 역할의 경계가 있었지만 아직 사건이 일어나기 전의 얇은 질문이었다.
- 신입 급여를 주며 과장급을 요구하는 말, 결과물보다 일을 더 드러내라는 조언은 노동 아이러니가 선명했지만 한 문장 설명에 머물고 기존 `좋은 직원`·근면 증빙 계열을 반복했다.
- 먹지 않은 진통제가 책상 위에 그대로 있다는 반전은 짧고 명료했지만 한 비트의 착각에서 관계나 다음 선택으로 자라지 않았다.
- 실내에서 놓친 곤충과 보여주지 못하는 사진은 즉각적인 시간 압력은 있었지만 한 비트의 공포와 이미지 의존이 강하고, 지속할 관계가 원문에 없어 채집하지 않았다.
- 게임 종료의 집단 작별, 연예·스포츠·정치, 건강·사적 고통, 이미지 의존, 회원 전용 안내 본문은 채집하지 않았다.
