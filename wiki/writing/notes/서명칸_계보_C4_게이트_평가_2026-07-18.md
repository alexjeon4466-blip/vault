# 서명칸 계보 — 편별 C4 게이트 평가 (2026-07-18)

> 대상: v3 여섯 편 (`drafts/<작품>_v3.md`). 편별 C4 세 조건 일괄 점검 — 근거는 [[wiki/writing/notes/서명칸_계보_다중가상낭독_결과_2026-07-18|다중 가상낭독 결과]]와 [[wiki/writing/notes/서명칸_계보_낭독_점검표_2026-07-13|낭독 점검표]](35건 전건 판정). 판정자 사용자, 2026-07-18 승인.

## 조건 1 — 낭독 회차 (6편 공통)

**낭독 판정: 통과 — 근거: 3방 분리 가상 패널(배우 5·첫 관객 7·제작)에서 실패 과반 항목 0/35, 핵심 인과 재구성 38/42(오독 9.5%), 편별 정점·종막 이미지 다수 회상.** (사용자, 2026-07-18)

- **대체 인정 사실 명기**: 실제 배우·청자·공간 없는 가상 패널(방식 ⑶). 각 작품카드에 명기. 정식 외부 낭독·상연 발생 시 각 편 v4 회차로 입력.
- **판본 무결성**: 낭독 대상과 vault 기준판의 SHA-256 6/6 일치 — 판정이 정확히 잠금 대상 텍스트에 대해 성립.
- 피드백 처리: 35건 전건 판정·사유 기록(점검표). 유지 판정 1건 — ① `한 바퀴 돌았네요` 유지(패널 4/5 근거, 소수 삭제 의견 기각).

## 조건 2 — P0 점검 (6편 공통 + 편별)

**본문 P0: 6편 전부 0건** (결과 문서 종료 카드). 본문 수정 0자 — v3 유지, v4 없음.

- 조건부 통과 16건은 전부 배우·동선·소품·기술 **운용 조건** — 텍스트 결함 아님. 편별 잠금값은 결과 문서 `제작 잠금값` 표가 진실원.
- P2 미도달 2건(① 같은 높이 펜촉, ② 입·퇴장 역전)은 놓쳐도 인과·종막이 무너지지 않는 취향·좌표 항목 — P0 아님, 설명 대사 추가 금지.
- 민감성: ⑤ 굴욕 내용 비특정 관례 작동 확인(구경거리화 미발생), ② 제작 내부 사실 블라인드 유지.
- **씨앗 소급 동결 (6편 일괄, 2026-07-18)**: 각 편 v3 `판본 메모`의 `보호 항목`(및 보존 판정 목록)을 그 편의 씨앗으로 동결한다. v3 파일은 해시 보존을 위해 무수정 — 동결 선언의 소재지는 이 평가와 각 작품카드다. 변경은 각 편 `씨앗 개정 vN` 기록으로만. 연작 통독 게이트의 편간 정합 대조 기준을 겸한다.

## 조건 3 — 완성·제출 경로 (6편 공통)

- **시간 구분**: 실측 공연 시간 없음. 가상 계측(추정) — 편별 배우 중앙값 13:14~19:59, 전편 자연주의 세션 약 2:13. 확정은 실제 배우·전환 설계 뒤.
- **매수**: 계 161.4매 (모욕 21.5 / 운전자 26.2 / 만장일치 26.5 / 관청 31.7 / 선장 31.5 / 죽음 24.0 — 200자 환산).
- **판본 동결 사유**: v1(정합)→v2(권한 재배분)→v3(반복 곡선·해설 지문·종막 역점) 3단계 퇴고 완료 + 낭독 재판정에서 본문 수정 필요 0.
- **submission_target: 미정** — 미정 상태 완성 판정 허용 조항. 연작 패널 규격(90~110매 폐기, 2026-07-13 판정 0) 유지. target 확정 시 편별/연작 제출 형태와 AI 규정 재점검.

## 판정

**6편 전부 C4 통과 — v3 잠금.** 이후 수정은 각 편 v4로만 연다. 실제 극장 첫 큐투큐 재확인 2건(⑤ 3조 거리별 음향, ④ 검지 8m·12m 시야)은 실패해도 첫 대응이 본문 수정이 아닌 운용 재설계임을 각 카드에 명기.

**연작 전체의 완성은 별개** — 남은 게이트: 순서 의존 최종 검증 + 전편 무중단 통독 + 상속표 실현 검증. 잔여 판정 4건(결말 각운 1·4·5 / 옛 서류 전달 경로 / 자국의 매체 / 원문 v5와의 자구 극성).
