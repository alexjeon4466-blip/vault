# 글감 트리아지 지도

> [[wiki/writing/aesthetics/글감_판정_루브릭|글감 판정 루브릭]]의 관문 A(A1 사람의 진폭 / A2 개념 초과분 / A3 기술 충동)와 관문 B(B1 시공간 / B2 문제 / B3 연료 / B4 타인 / B5 우회로)로 `notes/`·`draft-candidates/` 전 글감을 채점한 지도. 채점 완료한 파일은 `_scored` 접미사로 표시한다. 배치별로 누적한다.

## 채점 기호

- ○ 충족 / △ 부분 충족·보강 필요 / ✕ 부재
- 판정: **유망**(설계도 작성) / **병합**(부품 등록) / **보류**(처방만 남김) / **제외**

### 배치 1 병합 씨앗 메모 (3단계 입력)

- **3.8초 지연 × 굴렀음 수리 중** — 지연 자막 장치 + 안/밖 상태 보고 구조. "늦게 도착하는 말"의 극.
- **고작이라는 말 + 감정 표현으로 분류되었습니다** → 위로/분류가 고통을 축소하는 장면 부품 세트로 기록/애도 계열 운반체에 공급.
- **관심 지도의 구조 + (사람이 있는 씨앗)** — 회의실 구조는 완성형인데 중심 인물의 사적 진폭이 비어 있음. C에게 부재자를 붙일 것.

### 배치 2 병합 씨앗 메모 (3단계 입력)

- **76일을 벌었습니다 × 마지막 감자** — 연장 통보(시작)와 마지막 배급품 섭취(결말). 유예의 극 한 편의 처음과 끝이 이미 있다.

- **누워야지 × 바닥이 대답했다 × 등의 자국** — 귀환-눕기-흔적 3연속 비트. 궤도 계열 극의 종결부 세트.

### 배치 4 병합 씨앗 메모 (3단계 입력)

- **보정 체인이 하나의 극** — 잡음 제거 → 해상도 → 원본 복구 불가 → 자동 저장 → 복구 항목 없음 → 삭제됨: 미안 → 상호 양해함. "기록이 좋아질수록 사람이 사라진다"의 단계별 절차가 이미 완성돼 있음. 운반체는 `궤도_확장_초고후보_맵`과 대조해 판정한다.
- **소송 계열 도입-중반-결말 확보** — 아침식사가 오지 않았다(도입: 반복 결손) → 그런 법은 모릅니다/방으로 돌아가(중반: 절차) → 요제프 K(결말: 자기호명). 세 유망작이 한 극의 3막일 가능성.
- **자리/환대 1비트 세트** — 자리가 남아 있습니다 + 잔여 좌석 1 + 여기 있어도 됩니까: `서로_더_신경_써야`(의자 라벨극)의 부품으로 직결.

- **자리/환대 계열 완성형** — 운반체: 서로_더_신경_써야★(의자 라벨극) + 그늘은_예약할_수_없습니다★(야외 희극 버전). 부품: 앉아_있는_동안/이_자리는_아직/분실물로_접수하기_전까지/머무름은/자리가_남아/잔여_좌석_1/좌석을_선택해.
