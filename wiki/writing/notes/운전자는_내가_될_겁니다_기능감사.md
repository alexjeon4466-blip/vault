# 운전자는 내가 될 겁니다 — 기능 감사 (C3 1회차)

> 대상 판본: 1~5장 연결본(진본, 27.7매). 반복어·오브제·침묵·직접 발화가 실제로 무엇을 바꾸는가. 진단만 — 본문 수정은 별도 턴(사용자 우선). 판정 형식은 '원칙과 긴장하는 지점' 지목.

## 1. 상수 문구가 일하는가

| 문구 | 등장 | 기능 변화 | 판정 |
|---|---|---|---|
| "운전은 제가 했습니다." (A) | 3회 | 선제 선언(1장 — 안 물었는데 대답) → 공허(3장 — "아무도 그 말을 받지 않는다") → 주문(5장 — 서명 직전, "세 번째다") | ○ — 어휘표 설계 그대로. ep.1 "형식입니다"가 문장 자체의 붕괴(반 토막)였다면 이 편은 문장은 온전한 채 의미만 비는 반대 방향 — 연작 차별 자원 |
| "다시 한 번 확인하겠습니다." (B) | 2회 + 변주 1회 | 절차(2장 — 좌우 확인) → 의심의 완곡(3장 — 말줄임표가 문장 안에 들어옴, "혼잣말이 아니게") → "다시 써주시겠어요"(5장 — 대상이 진술에서 서명으로) | ○ — 단 3장의 지문 "같은 문장인데, 같은 문장이 아니다"는 기지정 낭독 대기(§5·체크리스트) |
| "잘 기억이 안 납니다." (A) | 2회 + 변주 1회 | 회피(2장 브레이크) → B의 기록물이 됨("기억 안 남, 이라고 적겠습니다") → 회피가 C의 몸을 건드림(2회차 직후 어깨 1회) → 미완 변주(3장 "몇 초였는지는…" — 물증 앞에서 회피조차 문장을 못 끝냄) | ○ |
| (침묵) (C) | 전장 | 숨(1장)→어깨 1회(2장)→정면 시선(3장)→능동 무반응(4장)→유일 발화(5장) — 회피→목격→선택→공모의 곡선 | ○ 보호 — 이 편 시그니처. 세부는 §3 |
| "바로 내렸습니다." (A) | 2회(2장) + 반박(3장) | 유일하게 막힘없이 적히는 진술 — 그리고 그 유창함의 진실 내용은 조수석의 것(구 초에 열린 문). 가장 잘 나온 말이 가장 정확하게 반박됨 | ○ — 거짓의 이자 구조의 이음쇠(§5) |

## 2. 오브제 감사

| 오브제 | 경로 | 실제로 바꾸는 것 | 긴장 지점 |
|---|---|---|---|
| 그 펜 (연작 공유·잉크 뭉침) | 펜꽂이→1장 A 손 접근·차단("그건 마지막에요")→5장 A가 뽑음→손끝 잉크→번짐 2회→긁힘·마름→펜꽂이 밖에 누운 채 종막 | 거짓의 물성 — 이름이 얼룩이 됨. 서명 강행(썼는데 안 굳음)이 ep.1(못 씀)과 정확히 다른 사건 | 마름이 B0 사양("잉크 번짐")을 넘어감 — 3번 편이 물려받는 펜이 '번지는 펜'인가 '죽은 펜'인가. 3번 연결본에서 뚜껑이 한 번도 안 열리므로 무대 모순은 없음 — 연속 관람 시 해석층이 하나 늘어남(거부인가 불능인가). 자산/위험 판정은 사용자(평가 자기복제 절) |
| C의 펜 (설계 밖 — 맵 구체소재 표에 없음) | C 주머니→5장 내밀어짐("펜, 여기요")→A의 깨끗한 세 번째 서명→C 확인란 서명→(C 소지 퇴장 추정) | 깨끗한 서명 도구가 공모자의 주머니에서 나옴 — 거짓이 이름으로 굳는 데 필요한 마지막 부품을 침묵하던 사람이 공급 | 없음 — §5 보호 후보. 단 C의 펜의 퇴장 경로(돌려받는 지문 이후 소재)가 지면에 없음 — 상연 시 동선만 정하면 됨 |
| B의 볼펜 | 규칙(1장)→반 박자(2장 기억 안 남)→멈춤·앞 장 대조(2장 핸들)→멈춤·내려놓음(3장 — "처음이다")→넉 자보다 오래(4장 답변 없음)→하단 부기(5장 — 내용 비공개)→두 이름 사이 멈춤(종막) | B의 앎의 지진계 — 아는 것을 어디까지 적는가가 손의 리듬으로만 | 없음 — 하단 부기의 내용 비공개가 B 유보의 핵. 끝까지 유지됨 ○ |
| 출입 대장 | 1장 A가 자기 이름 + C의 이름까지 적으려다 펜을 넘김 → 5장 B의 퇴실 기입, 두 이름 사이 멈춤 | 개막 1분 안에 극 전체(대리 기입)의 예고편 — 맵의 "정정 시도"가 조립에서 더 정확한 비트로 교체됨 | 없음 — §5 보호 후보 |
| C의 왼쪽 어깨 | 2장 1회("본인은 모르는 손")→4장 2회(무릎을 잡다 결국 올라감)→B의 시선이 지나감("지나갔는지, 머물렀는지, 각도로는 알 수 없다") | 진실은 몸에 있는데 종이엔 없음 — 설명 0 유지(안전벨트·자국이라는 단어가 지면 전체에 없음) | 없음 — 설명 0이 이 오브제의 생명. 단 4장 지문 "어깨로 가지 않으려고 무릎을 잡고 있는 손이다"는 내면 설명 — 낭독 대기(§5) |
| 경위서 + 주행 기록 | 항목 순차 기입 → 3장 두 종이가 나란히("두 종이. 같은 사고.") → 번진 이름 → 파일에 꽂힘 | 항목 진행 = 시계, 나란한 두 종이 = 정보 격차의 물화 | 주행 기록 출력물의 5장 소재가 지문에 없음 — 서명 국면에서 물증이 책상 위에 보이는가는 상연 결정 사항. 소규모 |
| 종이컵 두 개 (4장) | B가 휴식 후 반입 — A 앞에 하나, C 앞에 하나. 이후 언급 없음 | 두 사람을 동등하게 대하는 무언의 표시 — 진술자와 침묵자에게 같은 컵 | **긴장** — 등장 후 아무도 마시지 않고 재등장 없음. 동등 대접 그 자체로 족한가, 회수 없는 소품인가 — 낭독에서 확인 |

## 3. 침묵·정지 감사

| 지점 | 수행 내용 | 판정 |
|---|---|---|
| 1장 C의 숨 ("말이 되려다 — 숨으로 끝난다") | 첫 발화 시도가 발성 이전에 소멸 — 침묵 곡선의 0점 | ○ |
| 3장 C의 정면 시선 (A의 등, B의 볼펜, D의 출력물 — 다시 내린다) | 회피가 목격으로 바뀌는 힌지 — 보고 나서 내리는 것이므로 이후의 침묵은 몰라서가 아니라 알고서가 됨 | ○ |
| 4장 대질 침묵 | 벨트·목격은 끄덕이고 감속만 무반응 — 침묵의 정밀도(거짓 확인만 거부, 부작위로만 공모) | ○ 보호 — C를 비겁/보호로 확정하지 않는 무대규칙의 실행부 |
| 4장 A의 발화 차단 2회 (손바닥 / "진술은 본인만") | 서명 대리는 관철되고 발화 대리는 차단됨 — "자기가 두 번 막힌 것을 안다" | ○ — 대리의 한계를 절차가 긋는 아이러니 |
| 4장 B 퇴장 후 둘의 정지 → C의 입이 열리려는 순간 문소리 | 진실의 유일한 창이 우연(또는 B의 복귀 타이밍)에 잘림 — 열림 유지 | ○ |
| 5장 "(즉시) 네." / 손은 즉시 나오지 않는다 | 말과 몸의 시차 — 이 편의 공포 단위 | ○ |
| 종막 B의 볼펜, 두 이름 사이 멈춤 → 적는다, 덮는다 | B가 아는지·눈감는지의 유보가 마지막 동작까지 유지 | ○ 보호 |

## 4. 직접 발화 감사 (희소 자원)

| 발화 | 위치 | 획득 과정 | 판정 |
|---|---|---|---|
| "물어보실 거잖아요." (A) | 1장 | 볼펜의 반 박자 + B의 첫 시선 | ○ 보호 — A의 동기에 가장 근접하는 유일 문장인데 내용은 절차 예측뿐 — 동기 미언어화 규율과 공존하는 정확한 거리 |
| "제가 적을 수 있는 건 진술입니다. 끄덕임은… 적을 수가 없습니다." (B) | 4장 | C의 끄덕임 3연속 뒤 | ○ 보호 — 2장 "적겠습니다"와 쌍을 이루는 기록 권한의 지도. 극의 기제(적히는 것만 사실이 됨)에 가장 가까운 문장이나 절차어 내부에 머묾 — 낭독에서 음색만 확인 |
| "펜, 여기요." (C) | 5장 | 4개 장의 침묵 + 마른 펜의 물리적 필연 | ○ 보호 — 자백도 변명도 아닌 실무어로 공모 완성(어휘표 설계 그대로). 이 발화의 희소성이 이 편의 예산 전부 |
| D — 직접 발화 0 (숫자 낭독체 전건 유지) | 3장 | — | ○ — "기록은 육십칠" / "기록은 가속입니다"의 응답조차 술어 최소. 사람 관계 무지가 문체로 유지됨 |

## 5. 구조 발견 (설계 밖 — 보호 목록 후보)

- **종착 정점 프로필**: 5.7 → 5.4 → 4.5 → 5.3 → 6.8매. ep.1(체감 8.2→4.2)과 정반대 — 남은 항목이 줄수록 장이 길어진다(부담의 반비례). 3장 최저는 물증 낭독의 속도. 연작 연속 관람 시 같은 책상에서 다른 시간 형태가 도는 것 자체가 자기복제 회피 자산 — C3 증량·감량 시 이 프로필을 깨지 않는 것을 제약으로 제안.
- **거짓의 이자 구조 (3장)**: 봉합마다 새 거짓, 반박 간격 단축 — 속도(진술 대 기록)→가속(감속 진술 반박)→사십오 초("바로" 반박)→"문을 열어줬습니다"(새 거짓 즉석 발행)→파손 기록 없음(발행 몇 초 만에 부도). 맵의 "항목마다 다른 부담"이 조립에서 이자율 가속 구조로 구체화 — 보호 후보.
- **입·퇴장 반 발짝 대칭**: 입장은 C 먼저·A 반 발짝 뒤, 퇴장은 A 먼저·C 반 발짝 뒤 — "들어올 때와 같은 간격, 반대 순서다". 제목 문장("운전자는 내가 될 겁니다")의 이행이 대사 0으로 걸음 순서에 실림 — 보호 후보. 단 마지막 지문의 "같은 간격, 반대 순서다"가 관객이 스스로 잡을 수 있는 것의 지목인가 — 낭독 대기.
- **'허위'의 유일한 등장 = 서식 낭독문 안 (5장)**: 거짓·거짓말이라는 단어가 인물의 입에 0회 — 유일한 '허위'가 B가 읽어주는 양식 문구 속에만 있음. "아무도 거짓말이라 부르지 않는 채로"라는 약속이 어휘 수준에서 완성 — 보호 후보.
- **지문의 회계**: "처음이다"(3장 볼펜), "두 번째다"(4장 어깨), "세 번째다"(5장 상수) — 낭독본에서는 축적의 표지, 상연 지문으로는 비가시. 이중 봉인 후보 1건 포함(3장 "아무도 그 말을 받지 않는다. 질문된 적 없는 대답이다." — 뒤 문장이 앞 문장을 재설명). 일괄 낭독 대기 — 유지/정리의 판정은 사용자.
