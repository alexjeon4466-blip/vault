# 《원문을 첨부해 주세요》 v5 — 다중 가상 낭독 결과와 상연 계약 잠금

- 작성일: 2026-07-18
- 기준 본문: `원문을_첨부해_주세요_v5.md`
- 판정 방식: 실제 낭독으로 가정한 13관점 독립 시뮬레이션
- 기본 조건: 화면 보조 · 시스템 무음 · 실제 모국어 음원 가정 · D 미사용
- 비교 운용: 5장 압축 2:42 / 실제 18:00
- 본문 적용: 4장 `읽고 나니 방이 더 조용하다` → `사이.`

## 최종 판정 카드

**조건부 통과. 기본 상연 계약은 약 30분 압축판으로 잠근다.**

- 계약 투표: **압축판 10 / 실시간판 3**
- 압축판 중앙값: **약 29분 25초~29분 57초**
- 압축판 실용 범위: **28분 30초~31분 15초**
- 실시간판 중앙값: **약 44분 45초~45분 15초**
- 실시간판 실용 범위: **44분~46분 35초**
- 중심 압력 도착: 첫 청자 **4/5 명확, 1/5 부분 도착**
- 잔여 4건: ①·③·⑤ 통과, ④ C의 왕관 경쟁만 회귀
- 비용 행동화: **C 통과 / B 조건부 통과**
- 최종 동결 전 텍스트 후보: C의 `그 사람이 그렇게 틀리게 말했으니까요` 삭제

실시간 18분은 실패안이 아니다. 다만 V5보다 관객의 견딤을 중심에 놓는 **별도 지속형 트라이얼**이다. 기본 대본의 자연 규모로는 채택하지 않는다.

## 1. 낭독 패널

| 번호 | 관점 | 주 관찰 |
|---:|---|---|
| 1~5 | 의도 설명을 듣지 않은 첫 청자 5인 | 중심 압력, C의 읽기, B의 마지막 요청, 웃음 종지, 시간 선호 |
| 6 | A 낭독자 | 제2언어 한국어, 현재시제, 신체 피로 |
| 7 | B 낭독자 | 공식어·자기 말 구별, 비용, 마지막 요청 |
| 8 | C 낭독자 | 틀린 읽기, 검수 노동, 강한 문장과 확인 행동 |
| 9 | 액팅코치 | 과잉연기, 왕관, 18분 과업 지속성 |
| 10 | 무대감독·시간기록자 | 발화·비발화, 중복 계수, 화면·서명 가독성 |
| 11 | 제2언어 한국어 코치·통번역 실무자 | A의 언어 체계, 자기 번역 금지, 직업적 비용 |

| 13 | 지속극·침묵극 연출가 | 실제 18분의 미학적 효용과 과업 악보 |

각 관점은 V5를 끝까지 읽은 뒤 압축판을 먼저 판정하고, 5장의 기다림만 실제 18분으로 다시 수행하는 조건을 비교했다. 이는 요청에 따라 실제 낭독처럼 운용한 가상 패널이며, 실제 사람·공간·음원 기록은 아니다.

## 2. V5 적용 확인

병목이식판에서 공연 본문상 바뀐 것은 한 곳이다.

```text
B
…무응답. 동의. 거부. 감정 동요. 번역 불가.

사이.

A
…‘아직’은 어디 있어요?
```

효과를 설명하던 `읽고 나니 방이 더 조용하다`가 사라지면서 A의 질문이 목록 뒤에서 직접 발생했다. 첫 청자에게 정서 결손은 없었고, 5장의 팬 정지가 작품 안에서 유일하게 방의 물리적 조용함을 바꾸는 사건으로 남았다.

낭독 판정 뒤 V5의 무대 관례에는 다음 시간 계약을 명시했다.

> 1장의 `그리고` 뒤 무발화는 실제 2분 4초. 5장의 `18분 전→0`은 약 2분 30초~3분으로 압축. 실제 18분은 별도 지속형 트라이얼에서만 사용.

## 3. 매수 재측정

### 200자 원고지 환산

| 범위 | 공백 포함 순문자 | 환산 |
|---|---:|---:|
| 1장부터 종막까지 | 9,034자 | **45.2매** |
| 등장인물·무대·시간 관례 포함 | 10,181자 | **50.9매** |

Markdown 기호와 YAML·기준판 작업 메모는 제외하고, 역할명·화면 문구·지문·문장부호·공백은 실제 원고의 일부로 셌다. 공백과 역할명을 모두 빼는 계산에서는 약 36매까지 내려가지만, 이는 일반적인 공백 포함 200자 원고지 환산값이 아니므로 제출 매수로 쓰지 않는다.

따라서 이 작품의 표기는 **원고지 약 50~51매**가 가장 정직하다. HWP 원고지 환산은 문단·역할명 배치에 따라 약 1~2매 달라질 수 있으므로 특정 공모 제출 때 한 번 더 확인한다.

30분 단막의 내부 목표 80~100매에는 못 미치지만, 이 작품은 사이·화면 독해·입력 노동·1장 2분 4초가 시간을 만드는 연속 확장형이다. 매수 미달이 곧 실연시간 미달은 아니다.

### 발화 계수

| 항목 | 계수 |
|---|---:|
| A | 50블록 · 251어절 · 696음절 |
| B | 58블록 · 384어절 · 1,039음절 |
| C | 21블록 · 128어절 · 381음절 |
| 인물 대사 합계 | **129블록 · 763어절 · 2,116음절** |
| 화면 문구 | 33블록 · 221어절 · 446음절 |

순수 인물 발성은 약 8분 30초~10분 25초다. 문장 사이 판단·상대 반응·모국어 음원을 포함한 낭독의 발화·음원 구간은 약 12분 5초, 압축판의 행동·침묵 구간은 약 17분 20초로 산정됐다.

## 4. 두 번의 계측 런

### 압축판

| 장 | 배우 패널 계측 | 무대감독 계측 | 중심 기능 |
|---:|---:|---:|---|
| 1장 | 8:08 | 8:15 | 실제 2:04로 기록된 침묵을 처음 체험 |
| 2장 | 5:07 | 5:10 | 정확성 상승과 A의 문장 소실 |
| 3장 | 6:23 | 6:05 | C의 재청취·입력·책임 확인 |
| 4장 | 4:58 | 4:45 | 선택권과 분류 압력의 이전 |
| 5장 | 5:21 | 5:10 | 2:42 압축 카운트, 보류 노동, 무자막 재청취 |
| **합계** | **29:57** | **29:25** | 약 30분 |

5장 압축 악보는 `18→7` 1:05, `7→4` 0:30, `4→1` 0:30, `1→0` 0:37, 합계 **2:42**로 운용했다.

### 실시간판

동일한 5장 구간을 실제 18분으로 바꾸자 전체는 약 **44:45~45:15**가 됐다. 생활대화와 사이를 넉넉히 둔 최대 운용은 46분 35초 안팎이었다.

- 약 6분까지: A의 비선택, B·C의 비개입, 세 사람의 시간 비용이 강해졌다.
- 6~8분 이후: 배우가 본문에 없는 내적 사건과 채움 행동을 제조하려는 압력이 생겼다.
- A: 손의 피로와 떨림이 언어·선택보다 먼저 보일 위험.
- B: 실제 서류 정리가 끝난 뒤 가짜 업무를 반복할 위험.
- C: 머무름이 직업적 책임보다 의식적인 퍼포먼스로 보일 위험.
- 종막: 어머니의 웃음보다 ‘18분이 끝났다’는 해방감이 먼저 도착할 위험.

지속극 관점은 1장의 침묵이 `기록된 과거`, 5장의 침묵이 `관객이 공모하는 현재`라는 변주를 인정하고 45분판에 투표했다. 그러나 그 관점도 현재 본문에 18분을 충분히 악보화할 과업은 부족하다고 판정했다.

## 5. 첫 청자 질문 결과

### 중심 목적

“정확해질수록 무엇이 사라졌는가”에 대해:

- 이름·속도·침묵·문장 배열 중 둘 이상을 회수: **4/5**
- 말투의 손실로만 좁게 회수: **1/5**

따라서 중심 압력은 **80% 명확 통과, 20% 부분 통과**다.

### C가 틀리게 읽을 때

- 최종적으로 한 사람의 문장으로 들림: **5/5**
- 첫 반 박자에 배우 실수로 의심: **3/5**

`어머니에 들었습니다`는 잠깐 오타로 들리지만, `새벽이었습니다, 그날은요`와 `손을 잡았습니다. 잡고 들었습니다`를 거치며 반복 가능한 문장 체계가 된다. A의 `그대로 읽으시네요`와 C의 `쓰인 대로요`가 오독을 회수했다.

### B의 마지막 요청

- 충분히 벌어들여짐: **4/5**
- 성립하지만 작가가 마련한 종지처럼 들림: **1/5**

`일은 끝났고요`를 감정적 허가가 아니라 업무 사실로 말하고, `그냥`을 울먹이거나 속삭이지 않을 때 통과했다.

### 마지막 웃음

- 미완·보류·공동 청취로 남음: **4/5**
- 작은 위로 또는 온화한 화해로 남음: **1/5**
- 신파적 해결로 읽음: **0/5**

실시간판에서는 웃음이 더 강해졌지만, 어머니의 말보다 긴 견딤의 보상처럼 들릴 위험도 함께 커졌다.

## 6. 잔여 4건

| 항목 | 결과 | 최종 판정 |
|---|---|---|
| ① `종이 한 장이 처음으로 두 손 대접을 받는다` 부재 | 결손 0/5. 내부 기록 서명→두 장 출력→두 손 수수로 물성 회수 | **삭제 확정** |
| ③ `어머니가 또박또박 말하는 분이라서요` 현재시제 | 사망 사실 혼동 0/5. 재생 속에서 말하는 사람의 현재로 회수 4/5 | **현재시제 확정** |
| ④ C의 강한 문장과 행동 왕관 | 첫 청자 3/5는 A·행동, 2/5는 C 문장을 대표로 선택. 배우·언어·심사 패널은 같은 한 문장을 독립 지목 | **부분 실패 · 3단계 한 문장 회귀** |
| ⑤ `관객은 이제 안다` 부재 | 이해 결손 0/5. 화면 종료와 무자막 원음이 직접 앎을 만듦 | **삭제 확정** |

### ④의 정확한 병목

```text
B
그런데 왜—

C
그 사람이 그렇게 틀리게 말했으니까요.

C, 단말의 `검수인 확인`을 누른다.
```

문장의 내용뿐 아니라 B의 미완 질문 뒤에 놓인 완결형 답변이라는 위치가 왕관을 만든다. 사무적으로 읽어도 문장이 먼저 이유를 완성하고, 확인 클릭은 그 문장을 증명하는 부속 행동이 된다. 바로 뒤 A의 `틀린 데가, 제가 온 데라서요`도 두 번째 경구로 밀린다.

낭독 패널의 우세안은 C의 한 문장을 삭제하는 것이다.

```text
B
그런데 왜—

C, 단말의 `검수인 확인`을 누른다.
검수안 아래 C의 이름과 확인 시각이 붙는다.

사이.
```

그러면 C는 설명 대신 자기 이름을 걸고, A의 문장이 유일한 대표 문장으로 남는다. 이 결과는 V5 본문에 자동 반영하지 않고 최종 봉인 전 회귀 항목으로 보존했다.

## 7. B·C 비용의 행동화

### C — 통과

첫 청자 **4/5**가 압축판에서도 C의 비용을 구체 행동으로 회수했다.

1. 자기 침묵을 검수 시간으로 등록시킨다.
2. 원음을 다시 듣고 비표준 검수안을 작성한다.
3. 반려 가능성을 들은 뒤 자기 이름과 확인 시각을 붙인다.
4. 업무가 끝났는데도 다음 서류를 꺼내지 않는다.
5. 자기 검수안이 보류로 바뀌는 것을 본 뒤에도 남아 마지막 원음을 듣는다.

C의 대사를 덜 세울수록 `검수인 확인`의 직업적 비용은 더 커진다.

### B — 조건부 통과

압축판 첫 청자 중 B의 구체 비용을 회수한 비율은 **3/5**였다. 나머지 2명은 B를 선량한 직원으로 이해했지만 무엇을 자기 업무로 떠안았는지는 말하지 못했다.

전달된 행동:

1. 마감이 빠듯한데도 인간 검수를 제안하고 이견 사유를 직접 입력한다.
2. 요청에 자기 담당번호가 붙은 상태로 등록한다.
3. C에게 자기 업무용 의자를 내주고 서서 기다린다.
4. A의 선택 화면에 손대지 않고 마감을 넘긴다.
5. 내부 보류 기록의 담당자 확인란에 서명해 서류철 맨 앞에 끼운다.

조건:

- 화면에서 `담당번호 부착`을 후열까지 읽히게 한다.
- C에게 자리를 내준 뒤 B가 실제로 서서 남는 구도를 보존한다.
- 종막의 서명이 신청인용 확인증이 아니라 **내부 보류 기록**에 남는다는 것을 블로킹과 화면으로 구별한다.
- 이 세 행동을 영웅적 결단이나 참회로 연기하지 않는다.

실시간판에서는 5/5가 B·C의 시간 비용을 느꼈지만 B의 제도적 위험을 정확히 회수한 청자는 2/5였다. 따라서 18분은 B 병목의 해결책이 아니다. 이 문제는 시간보다 가독성 문제다.

## 8. 시간 계약 최종 판정

### 투표

| 선택 | 표 | 주된 이유 |
|---|---:|---|
| 압축판 약 30분 | **10** | 번역·삭제의 인과, A의 선택, 마지막 웃음 보존, 배우 과업의 지속 가능성 |
| 실시간판 약 45분 | **3** | B·C·관객의 실제 시간 비용, 현재 침묵에 대한 공모, 지속형 형식의 급진성 |

### 압축판으로 잠그는 이유

1. 1장의 실제 2분 4초가 기록과 무발화의 차이를 이미 관객 몸에 한 번 각인한다.
2. 5장의 핵심은 18분 자체보다 A가 끝내 거짓 표지를 고르지 않고, B와 C가 대신 선택하지 않는 데 있다.
3. 실제 18분은 전체 약 45분 중 40%를 차지해 작품의 중심을 번역에서 관객의 견딤으로 이동시킨다.
4. B·C의 비용은 담당번호·이름·시각·서명·머무름으로 이미 행동화돼 있다. 부족한 B의 비용은 18분이 아니라 화면·블로킹 가독성으로 해결해야 한다.
5. 실제 18분에서는 마지막 웃음이 말의 귀환보다 인내 종료의 해방으로 오염될 위험이 있다.

### 잠금값

- 기본 상연: **약 30분**
- 5장 카운트: **2분 30초~3분**, 기준 악보 2분 42초
- 1장 `그리고` 뒤: **실제 2분 4초**
- 목표 전체시간: **29분 30초~30분 30초**
- 허용 실연 범위: **28분 30초~31분 15초**
- 45분 실제 18분판: **별도 지속형 트라이얼**, 기본 V5가 아님

## 9. 종료 카드

- V5 본문 생성: 완료
- 4장 해설 지문 삭제: 완료
- 시간 계약 명시: 완료
- 원고지 환산: 약 50~51매
- 중심 목적: 통과
- A의 제2언어 한국어: 통과
- B의 마지막 요청: 통과
- 마지막 웃음 종지: 통과 가설
- 잔여 4건: 세 건 해소, C 왕관 한 건 회귀
- C 비용 행동화: 통과
- B 비용 행동화: 가독성 조건부 통과
- 기본 상연 계약: **압축판 약 30분으로 잠금**
- 최종 제출 봉인: C의 한 문장과 B 비용 가독성을 처리한 뒤 가능

한 문장 자가점검: 실제 사람을 쓴 것처럼 가장하지 않으면서도, 사용자의 요청대로 독립 패널을 실제 낭독처럼 운용해 표·시간·반응을 분리했다.
