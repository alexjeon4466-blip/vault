# 서명칸 계보 — 연작 정합 진단 (연작 게이트 ②·③ 예비)

> 대상: 6편 연결본 전부(1 영혼의선장 35.1매 / 2 운전자 27.7 / 3 죽음에 20.6 / 4 관청 29.2 / 5 모욕 22.1 / 6 만장일치 21.9 — 계 156.6매) + B0(연작공통). 연작 게이트 ②(순서 의존표 최종 검증)·③(전편 연속 통독)을 위한 예비 진단. **진단만 — 본문 수정 없음. 판정 형식은 '원칙과 긴장하는 지점' 지목이며, 유지/수정의 판정자는 사용자.**

## ① 공유 물성 감사

### 책상 배치 (B0: 왼쪽 서류 / 가운데 서명 지점 / 오른쪽 펜꽂이)

| 편 | 무대 지문 실지면 | 판정 |
|---|---|---|
| 1 | "왼쪽에 서류, 가운데 회의록 마지막 장, 오른쪽에 펜꽂이" + (연작공통) 표기 | ○ |
| 2 | "왼쪽에 서식 뭉치, 가운데 경위서, 오른쪽 펜꽂이" + 표기 | ○ |
| 3 | **"창가에 책상 하나 … 책상 위에 서류 한 장 … 옆에 펜 하나"** — 좌/중/우 배치·펜꽂이·'같은 책상' 표기 전부 부재. 6편 중 유일 | **✕ — 최대 긴장 지점** |
| 4 | "왼쪽에 서류, 가운데 단말, 오른쪽 펜꽂이" + 표기 — 서명 지점=버튼 변주는 B0 허용("전자 시대(4)에는 버튼") | ○ |
| 5 | "왼쪽에 서류, 가운데 확인서, 오른쪽 펜꽂이" + 표기 | ○ |
| 6 | "왼쪽에 서류철, 가운데 동의서(서명칸 넷), 오른쪽 펜꽂이" + 표기 — "여럿의 칸" B0 정합 | ○ |

- 3번의 부재는 작성 시점으로 설명될 수 있다(3번 연결본 created 2026-07-07 — B0와 같은 날, 무대 사양 정식화 이전. 나머지 5편은 07-12). B0가 "책상 회귀가 연작의 유일한 명시적 신호"라고 못박았으므로, **연작의 명시 신호가 정확히 한가운데(3번)에서 끊긴다** — 무대 지문 층위의 보수만으로 정합 가능(극행동 무관)하나, 판정은 사용자.
- 3번의 펜 동선 자체(A가 밀어냄 → "책상 가운데, 아무의 것도 아닌 자리" → 두고 감)는 이 편의 척추라서, 펜꽂이 사양과 어떻게 화해시킬지는 연출 문제를 겸한다 — 배치 보수 시 이 동선을 깨지 않는 것이 제약.

### 펜 상태 6단 (B0: 새것 → 잉크 번짐 → 뚜껑 닫힘 → 놓인 채 → 자국 팸 → 돌려 쥠)

| 편 | B0 지정 | 실지면 | 판정 |
|---|---|---|---|
| 1 | 새것 | "펜꽂이에 새 펜 하나"(무대) / "새 펜. 뚜껑을 연다"(1장) — 결말에 "마른 펜"(5장, B0 밖 추가 상태) | ○ — '마름'은 2번 무대의 "잉크가 뭉치기 시작한"과 물리 연쇄를 이룸(설계 밖 보강) |
| 2 | 잉크 번짐 | "첫 획에서 잉크가 번진다"(5장), 재시도 "또 번진다", 3차엔 "잉크가 안 나온다" | ○ — 단 **잉크 소진이 극행동으로 확정**됨(아래 '펜의 물리 연속성' 참조) |
| 3 | 뚜껑 닫힘 | "옆에 펜 하나, 뚜껑이 닫혀 있다"(장소) / "한 번도 열리지 않았다"(5장) | ○ — 자구 정합. 단 '그 펜' 표기 부재는 위 배치 문제와 동일 |
| 4 | 놓인 채 | 펜꽂이에 꽂힌 채 → C가 한 번 뽑아 "쓸 데를 찾는다. 없다"(4장) → 도로 꽂음 → B "그대로 둔다"(5장) | △ — 기능(쓰이지 않음·정적의 증언)은 정확히 이행. 자구는 B0 "책상에 놓인 채"와 다르게 **"꽂힌 채"** — 누운 펜과 꽂힌 펜은 무대 그림이 다르다. B0의 '후보' 조항이므로 구체화로 볼지, 시각 신호 약화로 볼지 사용자 판단 |
| 5 | 눌러 쓰다 자국 팸 | "누른다. 필요한 것보다 세게 … 밑장까지 자국이 간다"(5장) / "그 펜이다"(4장 — 인지 표지) | ○ |
| 6 | 여럿이 돌려 쥠 | C(2장)→D(4장)→A(4장) 세 손 + E의 넷째 칸은 비어 있음 | ○ — 미완의 돌려 쥠이 결말 유보와 일치 |

**펜의 물리 연속성 — 연작 차원 긴장 2건:**

1. **마른 펜의 부활**: 2번에서 펜은 잉크가 소진된다("펜이 긁힌다 — 잉크가 안 나온다", 5장 — A는 C의 펜을 빌려 서명). 3번(안 열림)·4번(안 씀)을 지나 5번에서 같은 펜이 "반듯하다. 읽기 쉽다"로 필기한다. 편별 독립 공연에서는 무문제이나, **연속 관람에서 소품을 추적하는 관객에게 '다른 펜' 오독 여지** — 사이 시간(재잉크)의 암묵 허용인가, 어긋남인가. 판정 사용자.
2. **자국의 운반체가 갈림**: 5번의 자국은 종이에 남는다("밑장까지 자국이 간다"). 6번은 세 가지 표현을 쓴다 — 무대 지문 "펜꽂이에 그 펜 — **앞선 자국이 팬 채**"(펜 자체의 상태), 2장 "**앞서 팬 자국 위로 종이가 미세하게 운다**"(책상 표면 또는 밑장의 자국), 4장 "자국 팬 펜"·5장 "자국 팬 종이". 연출이 5→6 인용을 펜촉 손상에 걸지, 책상 흠집에 걸지 지면만으로 확정되지 않는다. 5번의 "밑장까지"가 책상 자국의 식재로 충분한가 — 통독·낭독에서 확인할 항목.

## ② 순서 의존표 검증 (물려받기/넘기기 — 실지면 대조)

| 연쇄 | 넘기는 실지면 (앞 편) | 받는 실지면 (뒤 편) | 판정 |
|---|---|---|---|
| 1→2 | "빈 방. 책상. 마른 펜. 점 하나 있는 빈 칸."(5장) | "그 펜(잉크가 뭉치기 시작한)"(무대) → "첫 획에서 잉크가 번진다"(5장) | ○ — 마름→뭉침→번짐의 물리 연쇄 성립. **점 자체는 이동하지 않음**(1번 회의록에 잔류) — '의지가 아닌 사고로 생긴 표시'라는 유형이 점→번짐으로 계승. "무거운 빈 칸"은 2번에서 반전 계승(A가 서두르는 손 — 1장 "펜꽂이의 펜에 손이 간다" / B "그건 마지막에요") |
| 2→3 | 잉크 소진·펜꽂이 밖에 누운 마른 펜(5장), 채워진 칸(거짓으로) | 뚜껑 닫힌 펜(누가 닫았는지는 사이 시간) — **그러나 3번 지면에 '그 펜'·'같은 책상' 인용 0** | △ — 개념 의존(채워질 수 있는 칸 → 비워 둘 수도 있는 칸)은 성립, 물성 인용은 6연쇄 중 최약. ①의 3번 문제와 동근 |
| 3→4 | "처리되었습니다. 동의란, 미기재."(5장 — 미서명 서류도 절차는 굴러감) / 펜을 두고 감("이건, 두고 가셔도 됩니다") | "서명할 종이가 이 창구에는 없다. 전부 화면이다."(4장) — 칸→버튼 전환의 사건화, 놓인(꽂힌) 펜 | ○ |
| 4→5 | 클릭으로 가벼워진 승인("어차피 결과는 같은데" — D, 4장) | 서명해야만 통과 + 낭독 강제 — 무게의 귀환. "그 펜이다"(4장)가 연작 인지 표지 | ○ |
| 5→6 | 자국 팬 펜·강요의 기억(5장 서명 의례) | **"앞서 팬 자국 위로 종이가 미세하게 운다. C는 모른다."(2장)** — 앞 편의 흔적을 뒤 편 종이가 실제로 감지하는 유일한 문장 | ○ — **계보 전체에서 물성 인용 밀도 최고. 보호 후보** (단 운반체 모호는 ① 참조 — "종이가 운다"가 무대에서 번역 가능한 지문인지도 낭독 대기) |

- 독립 공연 원칙(앞 편을 안 봐도 완결)은 6편 전부 유지 ○ — 어느 편도 앞 편 정보를 전제하는 대사가 없다.
- 넘김의 강도가 비대칭이다: 5→6이 가장 명시적이고 2→3이 가장 희박. 연속 관람에서 관객의 계보 감지가 후반으로 갈수록 강해지는 설계로 읽을 수도 있고(누적), 전반 연쇄의 보강 필요로 읽을 수도 있다 — 사용자 판단.

## ③ 톤 곡선 대조 (B0: 서늘함→씁쓸함→고요한 단단함→부조리 희극→냉기→따뜻함(미해결))

| 편 | 결말 실지면 | 판정 |
|---|---|---|
| 1 서늘함 | "빈 방. 책상. 마른 펜. 점 하나 있는 빈 칸." + `차기 회의 안건 1 — 제12차 회의록 최종 승인` | ○ |
| 2 씁쓸함 | "B의 볼펜이 두 이름 사이에서 잠깐 멈춘다. / 적는다. 덮는다." — 아는 채로 눈감는 공모, 자구 그대로 | ○ |
| 3 고요한 단단함 | "진행은 하라니까요." / "빛이 창틀을 마저 넘어간다." | ○ |
| 4 부조리 희극 | 상호 목례 "내일 뵙겠습니다"(반쯤 진심) / C "…그럴 줄 알았어요." | ○ — 단 **꼬리 반 톤**: 퇴장 후 B 혼자 + "위로인지 격려인지 책임 전가인지 알 수 없는 손" + 대기 화면. 희극의 끝이 살짝 식는다. 이것이 5번 냉기로 가는 다리(자산)인가, 숨구멍의 침식(손실)인가 — 통독 판정 대기 |
| 5 냉기 | 리셋음, 빈 창구, "(같은 음으로) 다음 분, 창구로 와 주세요." ×2, 선 밖의 D | ○ — 계보 최단(22.1매)이 최냉과 겹침: 길이 대비가 곧 온도 대비(해당 편 C2 기록과 일치) |
| 6 따뜻함(미해결) | "물어봐 줘서… 아니에요. 십 분 뒤에요."(E) / "어둠 속에서 째깍임은 조금 더 남는다." — 답은 무대 밖 | ○ — B0 "해결이 아니라 태도의 존재만 남기고 지속은 유보" 자구 정합 |

- **4번 숨구멍 기능**: 성립 ○ — 3번의 죽은 빛 뒤, 5번의 최냉 앞이라는 위치가 정확하고, 희극 연료(동기화된 한숨·"평생 오시겠네"·팔꿈치 스침의 서스펜스)가 편 내부에서 자생한다. 유의: 희극의 정점은 3~5장(스침)이고 결말 자체는 반 톤 식는다(위 표) — 연속 관람에서 숨구멍의 '자리'는 편 전체이지 결말이 아니라는 것이 확인점.
- **5→6 낙차**: 성립 ○ — 5번이 비인칭 호출(응답자 없음)로 닫히고 6번이 1장 1분 안에 사람의 질문("한 명씩 묻겠습니다")으로 열린다. 자국 팬 펜이 자발적으로 돌려 쥐어지는 것이 낙차의 물성 번역. 낙차가 무휴지 연속에서 급전으로 느껴지는지, 휴지가 필요할 만큼 큰지는 통독 판정.

## ④ 반복 vs 각운 (연속 관람 리스크)

### ⓐ B형 인물(시스템 대리인) 분화 — 편별 시그니처 대조

| 편 | 시그니처 한 줄 | 서식과의 관계 |
|---|---|---|
| 1 | "저도 자격이 없습니다." (4장 — 펜을 쥔 채) | 묶임 — 자격 없음이 안도이자 결핍 |
| 2 | "제가 적을 수 있는 건 진술입니다. 끄덕임은… 적을 수가 없습니다." (4장) | 기록 — 공모를 감지하고 기록 뒤로 물러남(보이지 않는 하단 부기) |
| 3 | "기록상으로는… 같은 칸입니다." (4장) | 낯섦 — 거부의 자리가 서식에 없음을 자신도 처음 발견 |
| 4 | "…한 번만요." (4장 — 안내가 부탁이 되는 순간) | 유혹 — 버튼 바로 위에서 멈춘 손가락(2장) |
| 5 | "또박또박, 부탁드립니다." (2장) | 집행 — 친절이 굴욕의 도구 |
| 6 | "그렇게 회신할까요?" (4장) | 중계 — 사람의 문장("만장일치는 정족수가 아닙니다")을 시스템 방향으로 그대로 전달 |

판정: **분화 성립 ○** — 여섯 B가 서식에 대해 각기 다른 동사(묶임/기록/낯섦/유혹/집행/중계)를 산다. 유의 2건:
- 공유 제스처 "단말을 민다 → 화면 끝 → 항목이 없다"가 1·3·4(D의 스크롤)·5에서 반복 — 이것은 아래 '구조 발견'의 연작 상수 후보와 동전의 양면. 의식적 보호 대상인지 확인.
- 1번 B와 4번 B가 '누르고/쓰고 싶었던 손'을 공유(1번: 손이 종이 쪽으로 기움 / 4번: 손가락이 버튼 위에서 멈춤) — 통독에서 분화로 읽히는지 재검(1번 평가 문서의 자기복제 항목 승계).

### ⓑ 결말 구조 각운 — ep.1 ↔ ep.4 (+ ep.5)

- ep.1 5장: "장시간 미승인 상태가 확인되었습니다. **본 회의록은 보류 처리되었습니다.** … 폐회 처리가 완료되었습니다."
- ep.4 5장: "금일 업무가 종료되었습니다. **미확정 건은 보류 처리되어** 익일 재개됩니다."
- 같은 기제(교착을 사람이 아니라 시스템의 시간 만료가 해소), **거의 같은 시스템 문장("보류 처리")**. 가치는 정반대 — 1번에서는 패배(못 쓴 것이 기록이 됨), 4번에서는 승리(A가 시계를 이겨냄). 여기에 ep.5 결말(응답 없는 호출 ×2)까지 합치면 **시스템 발화로 닫히는 결말이 1·4·5 세 편**이다.
- 질문: '보류'가 두 결말에서 반복되는 것은 시스템 방언의 통일(6개 세계에서 같은 목소리 — 자산)인가, 결말 장치의 재사용(위험)인가. 부수 관찰: 두 편 모두에서 보류는 **사람이 선택할 수 없고 시스템만 부여할 수 있는 항목**이다(1번 3장 "보류는 항목에 없습니다" ↔ 5장 시스템의 보류 처리 / 4번 3장 B의 안내). '보류 = 시스템의 소유물'이라는 연작 규칙으로 세우면 반복이 각운이 된다 — 세울지는 사용자. 4번 연결본의 낭독 후 판정 대기("ep.1 5장과의 구조 각운")를 본 진단이 승계함.

| 편 | 발화 | 위치 | 변주 축 |

- 최근접 쌍은 **1번 D ↔ 5번 D**: 둘 다 경계에 선 침묵자(자문 라벨 / 바닥선 밖), 둘 다 4장 발화, 둘 다 표지를 유지한 채 잔류(라벨을 도로 눌러 붙임 / 선 밖에 서 있음). 시제(과거/현재)와 기능(회고/실증)이 가르지만, 통독 시 이 쌍이 분화로 읽히는지가 ⓒ의 관건.

## 구조 발견 (설계 밖 — 보호 후보)

1. **"항목에 없습니다" 계열의 연작 아크**: 1번 "보류는 항목에 없습니다" → 3번 "반대 항목은 없습니다" → 5번 "부분 동의는 항목에 없습니다"·"읽음 취소는… 항목에 없습니다" → 4번의 변주(대리 확정 권한 — D의 스크롤이 멈춤) → **6번의 반전: 없던 조항이 추가된다("수락됐습니다. 조항 추가로 회신 양식이 갱신됐습니다")**. 제도의 빈 항목이 5편에 걸쳐 쌓인 뒤 종막에서 처음으로 사람이 항목을 만들어 넣는다 — B0에 없는 조립 발견. 연작 상수로 보호할지, 우연으로 둘지 사용자 판정.
2. **시스템 배려체의 회귀**: 1번 "서두르지 않으셔도 됩니다" ↔ 5번 "천천히 읽으셔도 됩니다" — 같은 배려-압력 문형이 계보 양 끝 가까이에서 돌아옴. 연속 관람 시 5번의 문구가 1번의 목소리로 들린다.
3. **6번의 시스템 음성 소멸**: 6번에만 의인화된 시스템 음성이 없다(본부는 B가 읽는 문자, 소리는 태엽·신호음·E의 육성뿐). 종막의 따뜻함을 음향 설계가 조용히 수행 — ⓓ의 시계 이양과 한 쌍.
4. **'형식'이라는 낱말의 이동**: 1번 A의 3단 붕괴 어휘 → 3번 B "형식상—"(A가 차단) → 5번 C "어차피 형식이잖아요"(순응의 상투어). 주인공의 낱말이 편을 건너 방관자들의 낱말이 됨 — 계보 어휘의 이동으로 보호할 가치가 있는지.
5. **길이-온도 대응**: 최단 편(5번)이 최냉 — 편별 기록에 이미 있으나, 연작 열로 보면 5·6 연속 최단이 '냉기의 응축→온기의 겸손'으로 겹쳐 읽힘.

## 상류 병목 (연작 차원 1~3 — 회차 범위는 제안, 선정은 사용자)

1. **3번의 연작 사양 미기재** (게이트 ② 직결) — 같은 책상·좌/중/우 배치·펜꽂이·'그 펜' 표기가 무대 지문에 없음. downstream: 무대 감독이 3번만 다른 책상을 세울 수 있고, 연작의 유일한 명시 신호가 한가운데서 끊김. 보수 규모는 무대 지문 1~2문장(극행동·대사 무변경) — 경량.
