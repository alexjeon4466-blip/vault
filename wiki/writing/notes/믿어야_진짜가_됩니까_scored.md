# 믿어야 진짜가 됩니까 — 평가 완료

## 판정과 방향 (2026-07-04)

- 판정: **병합** / 채점: A1○ A2○ A3△ / B1△ B2○ B3△ B4△ B5△
- 사유: 믿음/진짜의 심급 질문이 장면보다 큼(증언석 추상 위험).
- 부품 가치: "믿지 않았으면 없었을 겁니다 / 그건 답변이 아닙니다" 문답 + 믿음이 거짓말의 면죄부가 되지 않게 하는 균형 원칙 — 진짜/출처 계열 극의 심문 장면 재료.
