# 작업별 진입 경로

가드레일 문서 `wiki/writing/aesthetics/희곡_설계_연극성_가드레일.md`의 **어떤 장을 어떤 순서로 여는가**만 적는다. 내용은 옮기지 않는다. 절 제목은 `scripts/verify-doctrine-anchors.py`가 대조한다.

## 1. 채집 노트 → 복수 설계(기본 3안)

| 순서 | 장 | 무엇을 얻나 |
|---|---|---|
| 1 | §20.2 복사 가능한 실행 키트 | run_config, 13항목 출력 순서, 독립성 5축 |
| 2 | §8 설계 요청에 붙이는 실행문 | 모든 안에 적용되는 공통 블록 |
| 3 | §0.2 모드 선택 방식 | 자연선택 vs 의무배정, 라우터 출력표 |
| 4 | §0.3 모드 경계 라우터 | 7문항 + `mode_boundary_router` YAML + 빠른 판정 |
| 5 | §2 필수 설계 카드 | `theatricality_entry_card` + 작성 기준 |
| 6 | 라우터가 고른 §13~§18 중 **하나** | 작품 계약·성공 기준·모듈 카드·적합성 20점·하드 실패·실행문 |
| 7 | §12 모드별 평가 운용 | 표준 100점표 또는 기존 평가표 매핑, 총점 밖 게이트 |
| 8 | §3 반복 실패 유형 | F1~F10 대조 |

보조 모드를 두면 §19 혼합 모드 규칙을 추가로 연다.

**§13~§18 모듈 실행문을 단독으로 쓰지 않는다.** 실행 프롬프트 = §20 키트 + §8 공통 블록 + 선택된 모듈 블록.

## 4. 도입부 냉관객 시험

| 순서 | 장 |
|---|---|
| 1 | §2 필수 설계 카드 — `one_sentence_cold_entry` 확인 |
| 2 | §4 공통 연극성 20점 — 시험 전 점수 기록 |
| 3 | §5 도입부 3~5분 냉관객 시험 — 시험 입력 금지 목록, 자유 회상 8문항, `cold_entry_test` YAML |

**시험자에게 시놉시스·중심 질문·용어 해설·비용표·결말을 주지 않는다.** 제목, 등장인물 표기, 도입부 본문뿐이다.

## 6. 설계안 비교

§6 `복수 설계안 비교`의 표를 쓴다. 총점만 나란히 두지 않고 `공통 연극성 20`·`설정·관람법 부채`·`증거 등급`을 별도 열로 둔다.

이어 §20.2의 독립성 5축 비교표를 작성한다: 중심 관계 또는 주체 구성 / 촉발 사건 / 사건 운반체 / 핵심 무대 경험 / 종막의 비가역적 결과 또는 고착.

## 참고 — 사례
