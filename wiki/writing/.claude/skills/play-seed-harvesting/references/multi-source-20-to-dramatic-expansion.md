# Multi-source 20-card harvest → diverse dramatic expansion

Use when the user asks for a broad batch such as 20 public-source seeds and a second pass on the strongest materials.

## Source and ethics boundary

Use public news/RSS, blogs, accessible community snippets, public SNS/forums, notices, and international sources when accessible. Do not bypass login/join/API walls or paraphrase unseen bodies. Keep title, source, date, URL, and access boundary. Transform private suffering rather than reenacting it.

## Diversity gate for a 20-seed run

A count of 20 is insufficient unless the pool varies materially across:

1. locations: private, shared, public, natural, mobile, mediated;
2. relations: family, friend, neighbor, coworker, informal group, stranger, solitary/nonhuman;
3. procedure/non-procedure;
4. temporal shapes: stay, repetition, wait, journey, ritual, parallel flow, consequence, discontinuity;
5. character organizations: solo, pair, group, relay, chorus, distributed/absent/nonhuman;
6. source lanes.

Include private routines, non-institutional relations, ritual/play, nature/labor/mobility, and institutional materials when sources support them. A pool dominated by service desks, forms, device errors, or status values fails diversity even at 20.

## Workflow

1. **Harvest broad pool.** Dedupe by source/title; keep provenance and a one-line source pressure.
2. **Save 20 compact cards.** Path pattern: `wiki/writing/notes/글감_채집_<date>_다중소스20.md`. Each card contains source pressure, action/material, structural DNA, 2–3 provisional hypotheses, missing fuel, self-copy risk, and ethical distance. It stops before B2.
3. **Score diversity.** Add a top or bottom matrix for the six dimensions and repair thin lanes before declaring the batch complete.
4. **Expand only 3–5.** A successful batch needs 3–4 meaningful expansions, not 20 promotions. Research exact actions, relations, time patterns, sensory/material facts, and language.
5. **Compare forms per expanded seed.** Candidates must differ by time-producing action, not scene count. Include the smallest natural scale; open full-length/cycle only with independent fuel.
6. **Promote at most the strongest current selection.** Invoke canonical doctrine and `playwriting-dramaturgy`, obtain user choice unless parallel branches were requested, or return `hold`.
7. **Update/verify wiki artifacts.** Preserve the broad pool, update index/log when needed, and run targeted/full verification as appropriate.

## Source roles

| Lane | Best contribution |
|---|---|
| News/RSS/notices | events, dates, public facts, exact language, changing conditions |
| Public blogs/reviews | bodies, routine, waiting, workarounds, objects, sensory texture |
| Public community snippets | signals of repeated friction; no unseen private-body paraphrase |
| Public SNS/forums | compact state sentences, temporal perception, ritual/repetition fragments |
| Nature/labor/mobility sources | non-institutional counterforce, routes, cycles, weather, material work |

## Self-copy regression

For every promoted seed ask whether the output automatically became:

`institutional agent + unclassifiable person + missing field + status screen + small complicity + object residue + quiet unresolved ending`

If the source did not supply that structure, regenerate at least one candidate from its own relation/time/material organization. Do not invent a government desk to make a seed feel theatrical.

## Verification

- requested seed count exists;
- six-dimension diversity matrix has no unexplained collapse;
- 3–4 expansions are considered a successful batch;
- every expanded card has 2–3 structurally different hypotheses;
- full-length/cycle claims name independent fuel;
- recommendation and hold option are distinct;
- public-only and provenance rules are visible;
- index/log links are verified when saved;
- no commit/push unless requested.
