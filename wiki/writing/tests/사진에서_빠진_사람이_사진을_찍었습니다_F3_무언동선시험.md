# 사진에서 빠진 사람이 사진을 찍었습니다 — F3 무언 동선 시험

> [!warning] 판정 범위
> 이 문서는 실제 배우 리허설이 아니라 8m × 6m 소극장을 가정한 축척 좌표·화각·충돌·객석 시야 시험이다. `DESK_TEST_PASS`는 받았지만 배우 속도, 즉석사진 배출 시간, 실제 객석의 가시성은 현장에서 확인해야 한다.

## 시험 질문

1. A·B 또는 A·C가 카메라의 가상 수평 화각 60° 안에 들어오는가?
2. B가 카메라를 잡을 때 비는 의자 자리가 객석 좌·중·우에서 보이는가?
3. `카메라 전달 → 빈자리 → 반환` 동선이 식탁을 관통하지 않는가?
4. C가 촬영 위치와 프레임 안 위치를 오갈 때 역할 변화가 충분한 거리로 보이는가?
5. 대사·프로젝션·기술 고장 없이 세 흐름의 교환이 읽히는가?

## 축척 가정

| 항목 | 값 |
|---|---:|
| 무대 | 폭 8m × 깊이 6m |
| 객석 대표 시점 | 다운스테이지 밖 x=2m / 4m / 6m |
| 식탁 범위 | x=3.0–5.2m, y=3.0–4.0m |
| 인물 위치 | 식탁 뒤 y≈4.7m |
| 촬영 위치 | x=1.5m, y=1.8m |
| 카메라 전달 위치 | x=2.2m, y=2.6m |
| 좌측 우회점 | x=2.45m, y=4.4m |
| 가상 카메라 수평 화각 | 60° |
| 인물 충돌 반경 | 0.32m |

## 1차 배치 — 실패

처음에는 A·B·C를 식탁 중심선에 두고 각 이동을 직선으로 계산했다.

| 경로 | 길이 | 식탁 충돌 |
|---|---:|---|
| C 촬영 위치 → 전달점 | 1.00m | 없음 |
| B 자리 → 전달점 | 2.51m | **있음** |
| C 전달점 → 프레임 안 | 3.26m | **있음** |
| C 프레임 안 → 촬영 위치 | 4.23m | **있음** |

### 실패 원인

- 배우가 직선으로 움직이면 식탁을 관통한다.
- 실제 무대에서는 식탁을 돌게 되므로 구조표보다 시간이 늘어난다.
- 우회 방향을 정하지 않으면 B와 C가 서로 다른 쪽으로 돌아 카메라 전달이 매회 달라질 수 있다.

### 수정

- A·B·C를 식탁 뒤 업스테이지 y≈4.7m에 둔다.
- 식탁 왼쪽 끝보다 0.55m 바깥에 공통 우회점 x=2.45m를 둔다.
- 카메라 전달은 항상 좌측 통로에서 한다.
- 오른쪽 통로는 의자와 사진 받침을 위해 비워 둔다.

## 수정 배치 — 축척 통과

### 카메라 화각

| 촬영 상태 | 중심에서 가장 먼 인물의 각도 | 60° 화각 안 |
|---|---:|---|
| C가 A+B 촬영 | 6.2° | 통과 |
| B가 A+C 촬영 시도 | 10.9° | 통과 |

두 상태 모두 허용 반각 30°보다 충분히 작다. 실제 렌즈 선택보다 중요한 것은 인물 배치가 화각을 핑계로 결락을 만들지 않는다는 점이다.

### 빈 B 의자 가시성

| 객석 대표 구역 | B의 빈자리 보임 |
|---|---|
| 좌 | 통과 |
| 중앙 | 통과 |
| 우 | 통과 |

축척 원형 충돌 모델에서는 A와 C가 B의 빈 의자 시선을 가리지 않았다.

### 수정 동선

| 경로 | 구간 길이 | 총거리 | 식탁 충돌 |
|---|---|---:|---|
| B 자리 → 좌측 우회점 → 전달점 → 카메라 위치 | 2.07m + 1.82m + 1.06m | 4.95m | 없음 |
| C 촬영 위치 → 전달점 → 좌측 우회점 → 프레임 안 | 1.06m + 1.82m + 2.91m | 5.79m | 없음 |
| C 프레임 안 → 좌측 우회점 → 전달점 → 촬영 위치 | 2.91m + 1.82m + 1.06m | 5.79m | 없음 |

- 프레임 안 인물 최소 간격: **0.85m** — 설정한 0.75m 최소값 통과.
- C의 촬영 위치↔프레임 안 역할 변화 이동거리: **5.79m** — 작은 손짓이 아니라 객석에서 읽을 수 있는 위치 변화.

## 세 프레임 무언 큐

| 큐 | A | B | C | 물질·시야 결과 | 통과 조건 |
|---|---|---|---|---|---|
| F1-1 | 식탁 뒤 구도 정리 | 자기 의자를 안쪽으로 이동 | 좌측 촬영 위치로 물러남 | B 의자에 몸 있음, C 자리 없음 | C의 자발적 이탈이 보임 |
| F1-2 | 첫 사진을 받침 1에 놓음 | 사진 앞면 확인 | 촬영 위치 유지 | 사진 앞면은 객석에 보이지 않음 | 이미지 없이 C 부재를 앎 |
| F2-1 | 첫 구도 복원 | 좌측 통로로 이동해 카메라를 받음 | 좌측 통로 뒤 프레임 안으로 이동 | B 의자가 비고 C가 들어옴 | 빈 B 의자가 좌·중·우에서 보임 |
| F2-2 | 자세를 유지하며 기다림 | 자기 빈자리를 봄 | A 옆에 멈춤 | 초대가 다른 결락을 만듦 | B가 사진을 찍기 전 문제를 몸으로 앎 |
| F2-3 | 흐트러진 의자 간격을 복원 | 좌측 통로에서 카메라 반환 후 자리 복귀 | 카메라를 받아 촬영 위치 복귀 | B의 자리는 채워지고 C는 다시 빠짐 | 반환 이유를 대사 없이 읽음 |
| F3-1 | 세 번째 받침을 준비 | 카메라를 끝까지 들고 프레임 밖에 서 봄 | B 자리 쪽 프레임 안에 섬 | 이번에는 B가 빠짐 | 둘째와 같은 문제의 반복이 보임 |
| F3-2 | 자세가 무너지지 않도록 의자만 붙듦 | 카메라를 넘김 | 스스로 좌측 통로를 돌아 촬영 위치 복귀 | C가 역할을 선택해 복구 | 희생 강요가 아닌 역할 내면화가 보임 |
| F3-3 | 첫 두 사진을 자기 쪽으로 놓음 | 셋째 사진 앞면을 C 쪽으로 돌림 | 카메라를 든 채 사진 밖에 섬 | C는 자기 없는 사진을 봄 | 칭찬·해결 없이 끝남 |

## 무언 정보 가시성 판정

| 정보 | 축척 판정 | 현장 판정 필요 |
|---|---|---|
| C가 첫 사진에서 자발적으로 빠짐 | 통과 | 이동 속도·머무는 시간 |
| B가 카메라를 받자 B 자리가 빔 | 통과 | 실제 의자와 의상에 따른 시야 |
| 카메라 반환이 식탁을 우회함 | 수정 후 통과 | 좌측 통로 최소 폭 0.55m가 충분한지 |
| C가 프레임 안에 들어갔다 스스로 돌아감 | 통과 | 5.79m 이동이 장면을 늘어뜨리지 않는지 |
| 사진 앞면을 관객에게 보이지 않음 | 설계 통과 | 즉석사진 배출·현상 대기 시간 |

## 판정

> **축척 동선 시험: 수정 후 통과.**

- **ADOPT:** 식탁 뒤 인물 배치, 좌측 단일 통로, 전달점 고정.
- **ADJUST:** 실제 공간이 8m보다 좁으면 식탁 폭부터 줄이고 통로 폭 0.55m는 보존한다.
- **HOLD:** 즉석카메라 실제 모델, 사진 배출 시간, 셔터 소리 크기.
- **REJECT:** 식탁을 가로지르는 직선 전달, 자동 촬영 실패, 프로젝션으로 결락 설명.
