# 아무도 생일이 아닌데 축하합니다 — 끈 절단·펠트 낙하·테이블 받침 물성 시험

> [!warning] 판정 범위
> 낙하 위치·객석 가시성·C의 도달 범위와 가상 펠트 압축 범위만 계산했다. 실제 테이블의 다리 틈, 바닥 마찰, 펠트 밀도, 압축률, 테이블 하중은 측정하지 않았다. 따라서 `끈 절단 → 펠트 낙하 → 받침 전환`의 무대 인과는 통과했지만 **실제 테이블 안정은 pending**이다.

## 시험 질문

1. 끈을 자르면 펠트 원이 관객에게 보이는 곳으로 떨어지는가?
2. 떨어진 펠트를 C가 무리 없이 집을 수 있는가?
3. 펠트가 자동으로 다리 밑에 들어가는 우연 없이 C의 선택으로 받침이 되는가?
4. 포일 처짐·펠트 낙하·C의 도달 동작이 객석 5–7m에서 보이는가?
5. 실제 다리 틈과 펠트 압축 두께가 맞지 않을 가능성을 현장 게이트로 남기는가?
6. 가위·접이식 테이블의 별도 안전 위험을 통제하는가?

## V1 — 식탁 중앙 아래 0.75m 낙하: 실패

펠트 원을 식탁 중앙 아래 y=3.5m에 걸고 0.75m 높이에서 떨어뜨렸다. 초기 수평 속도 ±0.25m/s와 낙하 뒤 ±0.06m 흔들림을 가정했다.

| 항목 | 결과 |
|---|---:|
| 낙하 시간 | 0.391초 |
| 착지 y 5–95백분위 | 3.391–3.609m |
| 식탁 아래가 아닌 비율 | 0.0% |
| C의 0.8m 도달 범위 안 | 0.0% |
| 보이면서 닿는 비율 | **0.0%** |

### 실패 원인

- 펠트가 식탁 아래 그늘에 머문다.
- C가 허리를 깊게 넣거나 무릎으로 기어가야 한다.
- 관객은 펠트가 왜 사라졌다가 받침으로 나오는지 볼 수 없다.
- `낙하 → 발견 → 전환`이 아니라 마술처럼 소품이 바뀐다.

### 판정

**REJECT:** 식탁 중앙 아래에서 떨어뜨리기.

## V2 — 다운스테이지 가장자리 바깥 0.28m 낙하: 통과

펠트를 식탁 다운스테이지 모서리보다 0.15m 앞인 y=2.85m에 건다. 높이는 바닥에서 0.28m다. 초기 수평 속도 ±0.08m/s와 ±0.03m의 작은 튐을 가정했다.

| 항목 | 결과 |
|---|---:|
| 낙하 시간 | 0.239초 |
| 착지 y 5–95백분위 | 2.816–2.884m |
| 식탁 아래가 아닌 비율 | 100.0% |
| C의 0.8m 도달 범위 안 | 100.0% |
| 보이면서 닿는 비율 | **100.0%** |

펠트는 다리 밑에 자동으로 들어가지 않는다. C가 펠트를 본 뒤 집어 짧은 다리 밑으로 밀어 넣어야 한다. 이 선택이 장식에서 생활 도구로의 기능 전환이다.

## 객석 가시성

| 사건 | 물리 변화 | 5m | 6m | 7m | 2° 설계값 |
|---|---:|---:|---:|---:|---|
| 펠트 원의 정지 크기 | 0.12m | 1.38° | 1.15° | 0.98° | 실패 |
| 펠트 낙하 | 0.28m | 3.21° | 2.67° | 2.29° | 통과 |
| 포일 한쪽 처짐 | 0.25m | 2.86° | 2.39° | 2.05° | 통과 |
| C의 줍기·밀어 넣기 | 0.65m | 7.44° | 6.20° | 5.32° | 통과 |

### 해석

- 펠트 자체를 오래 보여주는 것으로는 부족하다.
- 끈을 자르는 순간 포일이 0.25m 처지고 펠트가 0.28m 떨어져야 한다.
- C가 0.65m의 큰 동작으로 펠트를 주워 다리 밑으로 민다.
- 펠트 색은 바닥과 명도 대비가 커야 한다. 작은 소품의 형태보다 이동이 정보를 전달한다.

## 펠트 받침 적합성 가설

실제 압축 데이터를 얻지 못했으므로, 펠트가 공칭 두께의 55–75%로 남는다는 **가상 범위**만 사용했다. 이는 재료 사실이 아니라 실물 선택을 위한 예시다.

| 공칭 펠트 두께 | 가정한 압축 후 범위 | 맞을 수 있는 다리 틈 예시 |
|---:|---:|---|
| 3mm | 1.65–2.25mm | 2mm |
| 6mm | 3.30–4.50mm | 4mm |
| 9mm | 4.95–6.75mm | 5–6mm |

예를 들어 다리 틈이 실제로 4mm이고 선택한 6mm 펠트가 가정 범위처럼 압축된다면 안정 가능성이 있다. 그러나 다음을 측정하기 전에는 통과가 아니다.

- 실제 짧은 다리의 틈
- 실제 펠트의 하중 전·후 두께
- 바닥과 펠트 사이의 미끄럼
- 테이블 상판 하중과 접이식 다리 잠금 상태

## 가위 안전 수정

- 날 끝이 둥근 무대용 가위를 사용한다.
- 팽팽한 하중을 받는 끈을 자르지 않는다.
- 끈의 절단 구간을 미리 느슨하게 만들고 표시한다.
- B의 보조 손과 다른 배우의 몸에서 0.10m 이상 떨어진 구간만 자른다.
- 한 번의 절단 뒤 즉시 가위를 닫아 지정 위치에 둔다.
- 초콜릿 얼룩은 실제 음식 대신 닦이는 갈색 무대 재료를 우선 검토한다. 실제 음식은 바닥·손잡이 미끄럼과 알레르기 문제를 추가한다.

## 접이식 테이블 안전 수정

- 장면 전 다리를 완전히 펴고 잠금 장치를 확인한다.
- 공연 중 테이블을 접거나 잠금 장치에 손을 넣지 않는다.
- 손가락을 힌지·접힘 구역에서 멀리 둔다.
- 받침 시험 전 상판에는 깨지는 물건·뜨거운 액체·실제 케이크를 두지 않는다.
- 펠트를 넣을 때 C는 테이블 아래로 머리를 넣지 않고 다운스테이지 쪽 짧은 다리만 다룬다.
- 테이블을 기울여 다리를 드는 배우와 펠트를 넣는 배우를 분리한다면 공통 중단 신호를 정한다.

## 현장 물성 게이트 — pending

### A. 낙하

- [ ] 실제 펠트가 y=2.8–2.9m 가시 구역에 떨어짐.
- [ ] 펠트가 의자·테이블 다리·배우 신발 아래로 튀지 않음.
- [ ] 포일 0.25m 처짐과 펠트 0.28m 낙하가 같은 절단 결과로 읽힘.
- [ ] C가 한 번의 자연스러운 동작으로 펠트를 집을 수 있음.

### B. 받침

- [ ] 테이블 짧은 다리 틈을 실측함.
- [ ] 펠트 압축 후 두께를 실측함.
- [ ] 빈 테이블을 네 모서리에서 눌러 흔들림을 비교함.
- [ ] 펠트가 빠지거나 미끄러지지 않음.
- [ ] 반복 10회 뒤에도 잠금 장치·받침 위치가 유지됨.

### C. 절단

- [ ] 느슨한 표시 구간만 한 번에 잘림.
- [ ] 끈의 절단 끝이 배우 얼굴이나 손으로 튀지 않음.
- [ ] 가위가 한 번에 닫혀 지정 위치에 놓임.
- [ ] 소품 초기화가 반복 가능함.
