# bookclub decisions 운영

강독/책모임/비교 강의 판단 중 나중에 반복해서 다시 열릴 수 있는 결정을 남긴다.

예시:
- 어떤 책을 먼저 카드화할지
- 책카드와 원본 창작장치 채굴의 우선순위
- 특정 비교 강의 축을 채택하거나 버리는 이유
- 질문형 노트로 승격할지 지도/해설에 머물지의 판단

결정 노트는 `왜 지금 이 해석/순서/형식을 택했는가`를 남겨 이후 책모임 작업의 반복 설명을 줄인다.
